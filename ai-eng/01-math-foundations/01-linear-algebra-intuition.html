线性代数直觉

线性代数直觉

每个 AI 模型,说到底不过是戴着 fancy 帽子的矩阵运算。

类型: 学习
编程语言: Python, Julia
前置要求: 第 0 阶段
预计耗时: 约 60 分钟

学习目标

  • 用 Python 从零实现向量与矩阵运算(加法、点积、矩阵乘法)
  • 从几何上解释点积、投影、Gram-Schmidt 过程到底在做什么
  • 用行化简判断一组向量的线性无关性、秩和基
  • 把线性代数概念与 AI 应用对应起来:嵌入(embedding)、注意力分数、LoRA

问题

随便翻开一篇机器学习论文,第一页之内,你必然会看到向量、矩阵、点积和变换。没有线性代数直觉,这些只是符号;有了它,你就能看清神经网络到底在干什么——不过是在空间里搬动点而已。

你不需要成为数学家。你需要的是从几何上理解这些运算的含义,然后亲手把它们写出来。

概念

向量就是点(也是方向)

向量就是一串数字。但这些数字是有含义的——它们是空间中的坐标。

二维向量 [3, 2]:

xy点
32该向量从原点 (0,0) 指向平面上的 (3, 2)

这个向量的模长是 sqrt(3^2 + 2^2) = sqrt(13),指向右上方。

在 AI 里,向量可以表示一切:

  • 一个词 → 768 个数字组成的向量(它在嵌入空间里的"含义")
  • 一张图片 → 数百万像素值组成的向量
  • 一个用户 → 一组偏好组成的向量

矩阵就是变换

矩阵把一个向量变成另一个向量。它可以旋转、缩放、拉伸,也可以投影。

在 AI 里,矩阵就是模型本身:

  • 神经网络权重 → 把输入变换成输出的矩阵
  • 注意力分数 → 决定该关注什么的矩阵
  • 嵌入 → 把词映射成向量的矩阵

点积衡量相似度

两个向量的点积告诉你它们有多相似。

a · b = a₁×b₁ + a₂×b₂ + ... + aₙ×bₙ

Same direction:      a · b > 0  (similar)
Perpendicular:       a · b = 0  (unrelated)
Opposite direction:  a · b < 0  (dissimilar)

搜索引擎、推荐系统、RAG 的工作原理,说白了就是:找点积高的向量。

线性无关

如果一组向量中没有任何一个能写成其他向量的线性组合,它们就是线性无关的。v1、v2、v3 若线性无关,就能张成一个三维空间;若其中一个是其他两个的组合,它们就只能张成一个平面。

为什么这对 AI 重要:你的特征矩阵应该列线性无关。如果两个特征完全相关(线性相关),模型就无法区分它们各自的影响。这会在回归中造成多重共线性——权重矩阵变得不稳定,输入的微小变化会引起输出的剧烈波动。

具体例子:

v1 = [1, 0, 0]
v2 = [0, 1, 0]
v3 = [2, 1, 0]   # v3 = 2*v1 + v2

v1 和 v2 线性无关——谁也不是另一个的倍数或组合。但 v3 = 2*v1 + v2,所以 {v1, v2, v3} 是线性相关的。这三个向量都落在 xy 平面内,无论怎么组合都够不到 [0, 0, 1]。你有三个向量,却只有两个维度的自由度。

放到数据集里:如果 feature_3 = 2*feature_1 + feature_2,加入 feature_3 没有给模型带来任何新信息。更糟的是,它会让正规方程奇异——权重没有唯一解。

基与秩

基是一组最小的线性无关向量,能张成整个空间。基向量的个数就是空间的维数。

三维空间的标准基是 {[1,0,0], [0,1,0], [0,0,1]}。但任意三个三维空间中的线性无关向量都构成一组合法的基。选基就是选坐标系。

矩阵的秩 = 线性无关的列数 = 线性无关的行数。如果秩 < min(行数, 列数),矩阵就是秩亏的,这意味着:

  • 方程组有无穷多解(或无解)
  • 变换中丢失了信息
  • 矩阵不可逆
情况秩对机器学习意味着什么
满秩(rank = min(m, n))最大可能值存在唯一的最小二乘解,模型条件良好
秩亏(rank < min(m, n))低于最大值特征冗余,权重有无穷多解,需要正则化
秩 11每一列都是同一个向量的缩放副本,所有数据落在一条直线上
接近秩亏(奇异值很小)数值上很低矩阵病态,微小的输入噪声导致巨大的输出变化,应使用 SVD 截断或岭回归

投影

把向量 a 投影到向量 b 上,得到的是 a 在 b 方向上的分量:

proj_b(a) = (a dot b / b dot b) * b

残差 (a - proj_b(a)) 与 b 垂直。这种正交分解是最小二乘拟合的基础。

投影在机器学习里无处不在:

  • 线性回归最小化观测值到列空间的距离——它的解本身就是一个投影
  • PCA 把数据投影到方差最大的方向上
  • Transformer 中的注意力机制计算的是 query 在 key 上的投影

例子: a = [3, 4], b = [1, 0]

proj_b(a) = (31 + 40) / (11 + 00) * [1, 0] = 3 * [1, 0] = [3, 0]

投影丢掉了 y 分量。这就是降维最简单的形式——把你不关心的方向扔掉。

Gram-Schmidt 过程

把任意一组线性无关向量变成一组标准正交基。标准正交意味着每个向量长度为 1,且任意两个互相垂直。

算法步骤:

  1. 取第一个向量,归一化
  2. 取第二个向量,减去它在第一个向量上的投影,归一化
  3. 取第三个向量,减去它在之前所有向量上的投影,归一化
  4. 对剩余向量重复
Input:  v1, v2, v3, ... (linearly independent)

u1 = v1 / |v1|

w2 = v2 - (v2 dot u1) * u1
u2 = w2 / |w2|

w3 = v3 - (v3 dot u1) * u1 - (v3 dot u2) * u2
u3 = w3 / |w3|

Output: u1, u2, u3, ... (orthonormal basis)

QR 分解内部就是这么做的:Q 是标准正交基,R 记录投影系数。QR 分解用于:

  • 解线性方程组(比高斯消元更稳定)
  • 计算特征值(QR 算法)
  • 最小二乘回归(标准的数值方法)

第 1 步:从零实现向量(Python)

class Vector:
    def __init__(self, components):
        self.components = list(components)
        self.dim = len(self.components)

    def __add__(self, other):
        return Vector([a + b for a, b in zip(self.components, other.components)])

    def __sub__(self, other):
        return Vector([a - b for a, b in zip(self.components, other.components)])

    def dot(self, other):
        return sum(a * b for a, b in zip(self.components, other.components))

    def magnitude(self):
        return sum(x**2 for x in self.components) ** 0.5

    def normalize(self):
        mag = self.magnitude()
        return Vector([x / mag for x in self.components])

    def cosine_similarity(self, other):
        return self.dot(other) / (self.magnitude() * other.magnitude())

    def __repr__(self):
        return f"Vector({self.components})"


a = Vector([1, 2, 3])
b = Vector([4, 5, 6])

print(f"a + b = {a + b}")
print(f"a · b = {a.dot(b)}")
print(f"|a| = {a.magnitude():.4f}")
print(f"cosine similarity = {a.cosine_similarity(b):.4f}")

第 2 步:从零实现矩阵(Python)

class Matrix:
    def __init__(self, rows):
        self.rows = [list(row) for row in rows]
        self.shape = (len(self.rows), len(self.rows[0]))

    def __matmul__(self, other):
        if isinstance(other, Vector):
            return Vector([
                sum(self.rows[i][j] * other.components[j] for j in range(self.shape[1]))
                for i in range(self.shape[0])
            ])
        rows = []
        for i in range(self.shape[0]):
            row = []
            for j in range(other.shape[1]):
                row.append(sum(
                    self.rows[i][k] * other.rows[k][j]
                    for k in range(self.shape[1])
                ))
            rows.append(row)
        return Matrix(rows)

    def transpose(self):
        return Matrix([
            [self.rows[j][i] for j in range(self.shape[0])]
            for i in range(self.shape[1])
        ])

    def __repr__(self):
        return f"Matrix({self.rows})"


rotation_90 = Matrix([[0, -1], [1, 0]])
point = Vector([3, 1])

rotated = rotation_90 @ point
print(f"Original: {point}")
print(f"Rotated 90°: {rotated}")

第 5 步:从零实现线性无关判定与投影(Python)

def is_linearly_independent(vectors):
    n = len(vectors)
    dim = len(vectors[0].components)
    mat = Matrix([v.components[:] for v in vectors])
    rows = [row[:] for row in mat.rows]
    rank = 0
    for col in range(dim):
        pivot = None
        for row in range(rank, len(rows)):
            if abs(rows[row][col]) > 1e-10:
                pivot = row
                break
        if pivot is None:
            continue
        rows[rank], rows[pivot] = rows[pivot], rows[rank]
        scale = rows[rank][col]
        rows[rank] = [x / scale for x in rows[rank]]
        for row in range(len(rows)):
            if row != rank and abs(rows[row][col]) > 1e-10:
                factor = rows[row][col]
                rows[row] = [rows[row][j] - factor * rows[rank][j] for j in range(dim)]
        rank += 1
    return rank == n


def project(a, b):
    scalar = a.dot(b) / b.dot(b)
    return Vector([scalar * x for x in b.components])


def gram_schmidt(vectors):
    orthonormal = []
    for v in vectors:
        w = v
        for u in orthonormal:
            proj = project(w, u)
            w = w - proj
        if w.magnitude() < 1e-10:
            continue
        orthonormal.append(w.normalize())
    return orthonormal


v1 = Vector([1, 0, 0])
v2 = Vector([1, 1, 0])
v3 = Vector([1, 1, 1])
basis = gram_schmidt([v1, v2, v3])
for i, u in enumerate(basis):
    print(f"u{i+1} = {u}")
    print(f"  |u{i+1}| = {u.magnitude():.6f}")

print(f"u1 · u2 = {basis[0].dot(basis[1]):.6f}")
print(f"u1 · u3 = {basis[0].dot(basis[2]):.6f}")
print(f"u2 · u3 = {basis[1].dot(basis[2]):.6f}")

PyTorch —— 张量就是带自动微分的向量

import torch

x = torch.randn(3, requires_grad=True)
y = torch.tensor([1.0, 0.0, 0.0])

similarity = torch.dot(x, y)
similarity.backward()

print(f"x = {x.data}")
print(f"y = {y.data}")
print(f"dot product = {similarity.item():.4f}")
print(f"d(dot)/dx = {x.grad}")

点积对 x 的梯度就是 y。PyTorch 自动算出了这个结果。神经网络里的每一个操作,都是由矩阵乘法、点积、投影这样的基本操作搭起来的,而自动微分(autodiff)会追踪穿过所有这些操作的梯度。

你刚刚从零造了一遍 NumPy 一行就能搞定的东西。现在你知道轮子底下在发生什么了。

关联

本课的每个概念,都对应着现代 AI 的具体部件:

概念出现在哪里
点积Transformer 的注意力分数、RAG 中的余弦相似度
矩阵乘法每一个神经网络层、每一次线性变换
线性无关特征选择、避免多重共线性
秩判断方程组是否有解、LoRA(低秩适配)
投影线性回归(投影到列空间)、PCA
Gram-Schmidt / QR数值求解器、特征值计算
标准正交基稳定的数值计算、白化变换

LoRA 值得单独一提。它通过把权重更新分解成低秩矩阵来微调大语言模型(LLM):不去更新 4096×4096 的权重矩阵(1600 万参数),而是更新 4096×16 和 16×4096 两个矩阵(13.1 万参数)。"秩为 16"这个约束意味着 LoRA 假设权重更新只活在完整 4096 维空间的一个 16 维子空间里。这就是线性代数在真刀真枪地干活。
