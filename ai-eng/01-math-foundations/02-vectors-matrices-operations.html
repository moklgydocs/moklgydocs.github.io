向量、矩阵与运算

向量、矩阵与运算

每个神经网络,都只是多了几步花哨操作的矩阵乘法。

类型: 动手构建
编程语言: Python, Julia
前置要求: 第 1 阶段,第 01 课(线性代数直觉)
预计耗时: 约 60 分钟

学习目标

  • 构建一个 Matrix 类,支持逐元素运算、矩阵乘法、转置、行列式和逆矩阵
  • 区分逐元素乘法与矩阵乘法,并解释各自适用的场景
  • 只用从零实现的 Matrix 类,实现一个稠密神经网络层(relu(W @ x + b))
  • 解释广播(broadcasting)规则,以及神经网络框架中偏置加法是如何工作的

问题

你想构建一个神经网络。读代码时看到这一行:

output = activation(weights @ input + bias)

那个 @ 就是矩阵乘法。weights 是一个矩阵,input 是一个向量。如果你不知道这些运算在做什么,这一行就是黑魔法;如果你知道,它就是一个层完整的前向传播——三步搞定。

模型处理的每张图片是一个像素值矩阵,每个词嵌入是一个向量,每个神经网络的每一层都是一次矩阵变换。不熟悉矩阵运算就建不了 AI 系统,就像不懂变量就写不了代码一样。

本课从零打造这份熟练。

概念

向量:有序的数字列表

向量是一串有方向和模长的数字。在 AI 中,向量表示数据点、特征或参数。

v = [3, 4]        -- a 2D vector
w = [1, 0, -2]    -- a 3D vector

二维向量 [3, 4] 指向平面上的坐标 (3, 4),它的长度(模长)是 5(3-4-5 直角三角形)。

矩阵:数字的网格

矩阵是一个二维网格,有行有列。m × n 的矩阵有 m 行 n 列。

A = | 1  2  3 |     -- 2x3 matrix (2 rows, 3 columns)
    | 4  5  6 |

在神经网络中,权重矩阵把输入向量变换成输出向量。一个有 784 个输入、128 个输出的层,使用 128×784 的权重矩阵。

为什么形状很重要

矩阵乘法有一条铁律:(m x n) @ (n x p) = (m x p)。内维必须相等。

(128 x 784) @ (784 x 1) = (128 x 1)
  weights       input       output

Inner dimensions: 784 = 784  -- valid

如果你在 PyTorch 里遇到形状不匹配报错,原因就是这个。

运算一览

运算作用神经网络中的用途
加法逐元素相加给输出加偏置
标量乘法缩放每个元素学习率 × 梯度
矩阵乘法变换向量层的前向传播
转置行列互换反向传播
行列式汇总成单个数字检查是否可逆
逆矩阵撤销一次变换解线性方程组
单位矩阵什么都不做的矩阵初始化、残差连接

逐元素乘法 vs 矩阵乘法

这个区别不断绊倒初学者。

逐元素:对应位置相乘。两个矩阵形状必须相同。

| 1  2 |   | 5  6 |   | 5  12 |
| 3  4 | * | 7  8 | = | 21 32 |

矩阵乘法:行与列做点积。内维必须相等。

| 1  2 |   | 5  6 |   | 1*5+2*7  1*6+2*8 |   | 19  22 |
| 3  4 | @ | 7  8 | = | 3*5+4*7  3*6+4*8 | = | 43  50 |

不同的运算,不同的结果,不同的规则。

广播

当你把一个偏置向量加到一个输出矩阵上时,两者形状并不匹配。广播会把较小的数组拉伸到合适的大小。

| 1  2  3 |   +   [10, 20, 30]
| 4  5  6 |

Broadcasting stretches the vector across rows:

| 1  2  3 |   | 10  20  30 |   | 11  22  33 |
| 4  5  6 | + | 10  20  30 | = | 14  25  36 |

每个现代框架都会自动做这件事。理解它能避免困惑——不然形状看着不对,代码却跑通了。

动手构建

第 1 步:Vector 类

class Vector:
    def __init__(self, data):
        self.data = list(data)
        self.size = len(self.data)

    def __repr__(self):
        return f"Vector({self.data})"

    def __add__(self, other):
        return Vector([a + b for a, b in zip(self.data, other.data)])

    def __sub__(self, other):
        return Vector([a - b for a, b in zip(self.data, other.data)])

    def __mul__(self, scalar):
        return Vector([x * scalar for x in self.data])

    def dot(self, other):
        return sum(a * b for a, b in zip(self.data, other.data))

    def magnitude(self):
        return sum(x ** 2 for x in self.data) ** 0.5

第 2 步:带核心运算的 Matrix 类

class Matrix:
    def __init__(self, data):
        self.data = [list(row) for row in data]
        self.rows = len(self.data)
        self.cols = len(self.data[0])
        self.shape = (self.rows, self.cols)

    def __repr__(self):
        rows_str = "\n  ".join(str(row) for row in self.data)
        return f"Matrix({self.shape}):\n  {rows_str}"

    def __add__(self, other):
        return Matrix([
            [self.data[i][j] + other.data[i][j] for j in range(self.cols)]
            for i in range(self.rows)
        ])

    def __sub__(self, other):
        return Matrix([
            [self.data[i][j] - other.data[i][j] for j in range(self.cols)]
            for i in range(self.rows)
        ])

    def scalar_multiply(self, scalar):
        return Matrix([
            [self.data[i][j] * scalar for j in range(self.cols)]
            for i in range(self.rows)
        ])

    def element_wise_multiply(self, other):
        return Matrix([
            [self.data[i][j] * other.data[i][j] for j in range(self.cols)]
            for i in range(self.rows)
        ])

    def matmul(self, other):
        return Matrix([
            [
                sum(self.data[i][k] * other.data[k][j] for k in range(self.cols))
                for j in range(other.cols)
            ]
            for i in range(self.rows)
        ])

    def transpose(self):
        return Matrix([
            [self.data[j][i] for j in range(self.rows)]
            for i in range(self.cols)
        ])

    def determinant(self):
        if self.shape == (1, 1):
            return self.data[0][0]
        if self.shape == (2, 2):
            return self.data[0][0] * self.data[1][1] - self.data[0][1] * self.data[1][0]
        det = 0
        for j in range(self.cols):
            minor = Matrix([
                [self.data[i][k] for k in range(self.cols) if k != j]
                for i in range(1, self.rows)
            ])
            det += ((-1) ** j) * self.data[0][j] * minor.determinant()
        return det

    def inverse_2x2(self):
        det = self.determinant()
        if det == 0:
            raise ValueError("Matrix is singular, no inverse exists")
        return Matrix([
            [self.data[1][1] / det, -self.data[0][1] / det],
            [-self.data[1][0] / det, self.data[0][0] / det]
        ])

    @staticmethod
    def identity(n):
        return Matrix([
            [1 if i == j else 0 for j in range(n)]
            for i in range(n)
        ])

第 3 步:跑起来看看

A = Matrix([[1, 2], [3, 4]])
B = Matrix([[5, 6], [7, 8]])

print("A + B =", (A + B).data)
print("A @ B =", A.matmul(B).data)
print("A^T =", A.transpose().data)
print("det(A) =", A.determinant())
print("A^-1 =", A.inverse_2x2().data)

I = Matrix.identity(2)
print("A @ A^-1 =", A.matmul(A.inverse_2x2()).data)

第 4 步:接上神经网络

import random

inputs = Matrix([[0.5], [0.8], [0.2]])
weights = Matrix([
    [random.uniform(-1, 1) for _ in range(3)]
    for _ in range(2)
])
bias = Matrix([[0.1], [0.1]])

def relu_matrix(m):
    return Matrix([[max(0, val) for val in row] for row in m.data])

pre_activation = weights.matmul(inputs) + bias
output = relu_matrix(pre_activation)

print(f"Input shape: {inputs.shape}")
print(f"Weight shape: {weights.shape}")
print(f"Output shape: {output.shape}")
print(f"Output: {output.data}")

这就是一个稠密层:output = relu(W @ x + b)。每个神经网络里的每个稠密层,做的就是这件事,一模一样。

投入使用

NumPy 用更少的行数做完上面所有事,而且快上几个数量级。

import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

print("A + B =\n", A + B)
print("A * B (element-wise) =\n", A * B)
print("A @ B (matrix multiply) =\n", A @ B)
print("A^T =\n", A.T)
print("det(A) =", np.linalg.det(A))
print("A^-1 =\n", np.linalg.inv(A))
print("I =\n", np.eye(2))

inputs = np.random.randn(3, 1)
weights = np.random.randn(2, 3)
bias = np.array([[0.1], [0.1]])
output = np.maximum(0, weights @ inputs + bias)

print(f"\nNeural network layer: {weights.shape} @ {inputs.shape} = {output.shape}")
print(f"Output:\n{output}")

Python 的 @ 运算符调用的是 __matmul__。NumPy 用 C 和 Fortran 写的优化 BLAS 例程来实现它。同样的数学,快 100 倍。

NumPy 中的广播:

matrix = np.array([[1, 2, 3], [4, 5, 6]])
bias = np.array([10, 20, 30])
print(matrix + bias)

NumPy 自动把一维的偏置广播到两行上。所有神经网络框架中的偏置加法,都是这么工作的。

关键术语

术语人们常说的实际含义
向量"一个箭头"有序的数字列表。在 AI 中:高维空间里的一个点
矩阵"一张数字表格"一种线性变换,把向量从一个空间映射到另一个空间
矩阵乘法"把数字乘一乘就行"第一个矩阵的每一行与第二个矩阵的每一列做点积。顺序很重要
转置"翻一下"行列互换,把 m × n 矩阵变成 n × m。反向传播中的关键操作
行列式"从矩阵算出来的某个数"衡量矩阵对面积(2D)或体积(3D)的缩放程度。为零意味着变换压扁了一个维度
逆矩阵"撤销这个矩阵"逆转该变换的矩阵,只在行列式非零时存在
单位矩阵"无聊的矩阵"相当于乘法里的 1。用于残差连接(ResNet)
广播"魔法般修复形状"沿缺失的维度重复,把小数组拉伸到与大数组匹配
逐元素"普通乘法"对应位置相乘。两个数组形状必须相同(或可广播)
