线性回归

线性回归

线性回归,就是在数据中画出那条最贴合的直线。它是机器学习世界的 "hello world"。

类型: 动手构建
编程语言: Python
前置要求: 第 1 阶段(线性代数、微积分、优化),第 2 阶段第 1 课
预计耗时: 约 90 分钟

学习目标

  • 推导均方误差下的梯度下降更新规则,并从零实现线性回归
  • 从计算复杂度的角度比较梯度下降与正规方程,知道各自适用的场景
  • 构建带特征标准化的多元线性回归模型,并解读学出的权重
  • 解释岭回归(L2 正则化)如何通过惩罚大权重来防止过拟合

问题

你手上有一份数据:房屋面积和对应的成交价。现在给你一套新房子的面积,你想预测它的价格。你可以在散点图上目测一个大概,但你需要的是一个公式——一条最贴合数据的直线,这样代入任意面积,就能得到价格预测。

线性回归给你的正是这条直线。更重要的是,它引出了机器学习的完整训练闭环:定义模型、定义代价函数、优化参数。每一种机器学习算法都遵循这个模式。在最简单的例子里把它吃透,之后你到处都能认出它。

这可不只是玩具问题。线性回归广泛用在生产系统中:需求预测、A/B 测试分析、金融建模,也是每一个回归任务的基线模型。

概念

模型

线性回归假设输入(x)与输出(y)之间是线性关系:

y = wx + b
  • w(权重/斜率):x 每增加 1,y 变化多少
  • b(偏置/截距):x = 0 时 y 的值

有多个输入(特征)时,扩展为:

y = w1*x1 + w2*x2 + ... + wn*xn + b

向量形式:y = w^T * x + b

目标:找到一组 w 和 b,使得在所有训练样本上,预测的 y 与真实的 y 尽可能接近。

代价函数(均方误差)

怎么衡量"尽可能接近"?你需要一个数字,概括预测到底有多离谱。最常用的选择是均方误差(MSE):

MSE = (1/n) * sum((y_predicted - y_actual)^2)

为什么要平方?两个原因。第一,平方对大误差的惩罚远超小误差(误差 10 的代价是误差 1 的 100 倍,而不是 10 倍)。第二,平方函数处处光滑可微,优化起来很顺手。

代价函数构成一个曲面。对单个权重 w 和偏置 b 来说,MSE 曲面像一只碗(凸抛物面)。碗底就是 MSE 最小的位置。训练,就是找到这个碗底。

梯度下降

梯度下降通过一步步往山下走,找到碗底。

梯度告诉你两件事:每个参数该往哪个方向动,以及动多少。

对于 y_hat = wx + b 下的 MSE:

dMSE/dw = (2/n) * sum((y_hat - y) * x)
dMSE/db = (2/n) * sum(y_hat - y)

更新规则:

w = w - learning_rate * dMSE/dw
b = b - learning_rate * dMSE/db

学习率(learning rate)控制步长。太大:会越过最低点,直接发散;太小:训练慢得没边。常见的起手值:0.01、0.001 或 0.0001。

正规方程(闭式解)

对线性回归这个特例,存在一个直接公式,不用迭代就能算出最优权重:

w = (X^T * X)^(-1) * X^T * y

它通过矩阵求逆一步解出 w,在小数据集上非常好用。数据量大时(上百万行或上千个特征),梯度下降更合适,因为矩阵求逆在特征维度上是 O(n^3)。

多元线性回归

有多个特征时,模型变成:

y = w1*x1 + w2*x2 + ... + wn*xn + b

其他一切都一样:代价函数仍是 MSE,梯度下降同时更新所有权重。唯一的区别是,你拟合的不再是一条直线,而是一个超平面。

这时特征缩放很重要。如果一个特征的取值范围是 0 到 1,另一个是 0 到 1,000,000,代价曲面会被拉得又细又长,梯度下降会很吃力。训练前先把特征标准化(减去均值,除以标准差)。

多项式回归

如果关系不是线性的怎么办?你仍然可以用线性回归——构造多项式特征就行:

y = w1*x + w2*x^2 + w3*x^3 + b

它之所以仍算"线性"回归,是因为模型对权重(w1、w2、w3)而言是线性的,你只是用了 x 的非线性特征。

更高次的多项式可以拟合更复杂的曲线,但有过拟合的风险。一个 10 次多项式可以穿过 10 个点数据集中的每一个点,但在新数据上预测得一塌糊涂。

R 方分数

MSE 告诉你错得有多离谱,但这个数字依赖于 y 的量纲。R 方(R^2)给出一个与量纲无关的度量:

R^2 = 1 - (sum of squared residuals) / (sum of squared deviations from mean)
    = 1 - SS_res / SS_tot
  • R^2 = 1.0:预测完美
  • R^2 = 0.0:模型跟"每次都预测均值"一样好
  • R^2 < 0.0:模型还不如直接预测均值

正则化预告(岭回归)

特征很多时,模型可能通过给特征配上大权重而过拟合。岭回归(Ridge regression,即 L2 正则化)加了一项惩罚:

Cost = MSE + lambda * sum(w_i^2)

惩罚项会抑制大权重。超参数 lambda 控制权衡:lambda 越大,权重越小,正则化越强。后面的课程会深入讲。现在只需知道它的存在,以及它为什么有用。

第 2 步:用梯度下降从零实现线性回归

class LinearRegression:
    def __init__(self, learning_rate=0.01):
        self.w = 0.0
        self.b = 0.0
        self.lr = learning_rate
        self.cost_history = []

    def predict(self, X):
        return [self.w * x + self.b for x in X]

    def compute_cost(self, X, y):
        predictions = self.predict(X)
        n = len(y)
        cost = sum((pred - actual) ** 2 for pred, actual in zip(predictions, y)) / n
        return cost

    def compute_gradients(self, X, y):
        predictions = self.predict(X)
        n = len(y)
        dw = (2 / n) * sum((pred - actual) * x for pred, actual, x in zip(predictions, y, X))
        db = (2 / n) * sum(pred - actual for pred, actual in zip(predictions, y))
        return dw, db

    def fit(self, X, y, epochs=1000, print_every=200):
        for epoch in range(epochs):
            dw, db = self.compute_gradients(X, y)
            self.w -= self.lr * dw
            self.b -= self.lr * db
            cost = self.compute_cost(X, y)
            self.cost_history.append(cost)
            if epoch % print_every == 0:
                print(f"  Epoch {epoch:4d} | Cost: {cost:.4f} | w: {self.w:.4f} | b: {self.b:.4f}")
        return self

    def r_squared(self, X, y):
        predictions = self.predict(X)
        y_mean = sum(y) / len(y)
        ss_res = sum((actual - pred) ** 2 for actual, pred in zip(y, predictions))
        ss_tot = sum((actual - y_mean) ** 2 for actual in y)
        return 1 - (ss_res / ss_tot)


print("=== Training Linear Regression (Gradient Descent) ===")

print(f"True:    y = {TRUE_W}x + {TRUE_B}")
print(f"R-squared: {model.r_squared(X, y):.4f}")

第 3 步:正规方程(闭式解)

class LinearRegressionNormal:
    def __init__(self):
        self.w = 0.0
        self.b = 0.0

    def fit(self, X, y):
        n = len(X)
        x_mean = sum(X) / n
        y_mean = sum(y) / n
        numerator = sum((X[i] - x_mean) * (y[i] - y_mean) for i in range(n))
        denominator = sum((X[i] - x_mean) ** 2 for i in range(n))
        self.w = numerator / denominator
        self.b = y_mean - self.w * x_mean
        return self

    def predict(self, X):
        return [self.w * x + self.b for x in X]

    def r_squared(self, X, y):
        predictions = self.predict(X)
        y_mean = sum(y) / len(y)
        ss_res = sum((actual - pred) ** 2 for actual, pred in zip(y, predictions))
        ss_tot = sum((actual - y_mean) ** 2 for actual in y)
        return 1 - (ss_res / ss_tot)


print("\n=== Normal Equation (Closed-Form) ===")

model_normal.fit(X, y)

print(f"R-squared: {model_normal.r_squared(X, y):.4f}")

class MultipleLinearRegression:
    def __init__(self, n_features, learning_rate=0.01):
        self.weights = [0.0] * n_features
        self.bias = 0.0
        self.lr = learning_rate
        self.cost_history = []

    def predict_single(self, x):
        return sum(w * xi for w, xi in zip(self.weights, x)) + self.bias

    def predict(self, X):
        return [self.predict_single(x) for x in X]

    def compute_cost(self, X, y):
        predictions = self.predict(X)
        n = len(y)
        return sum((pred - actual) ** 2 for pred, actual in zip(predictions, y)) / n

    def fit(self, X, y, epochs=1000, print_every=200):
        n = len(y)
        n_features = len(X[0])
        for epoch in range(epochs):
            predictions = self.predict(X)
            errors = [pred - actual for pred, actual in zip(predictions, y)]
            for j in range(n_features):
                grad = (2 / n) * sum(errors[i] * X[i][j] for i in range(n))
                self.weights[j] -= self.lr * grad
            grad_b = (2 / n) * sum(errors)
            self.bias -= self.lr * grad_b
            cost = self.compute_cost(X, y)
            self.cost_history.append(cost)
            if epoch % print_every == 0:
                print(f"  Epoch {epoch:4d} | Cost: {cost:.4f}")
        return self

    def r_squared(self, X, y):
        predictions = self.predict(X)
        y_mean = sum(y) / len(y)
        ss_res = sum((actual - pred) ** 2 for actual, pred in zip(y, predictions))
        ss_tot = sum((actual - y_mean) ** 2 for actual in y)
        return 1 - (ss_res / ss_tot)

def standardize(X):
    n_features = len(X[0])
    means = [sum(X[i][j] for i in range(len(X))) / len(X) for j in range(n_features)]
    stds = []
    for j in range(n_features):
        variance = sum((X[i][j] - means[j]) ** 2 for i in range(len(X))) / len(X)
        stds.append(variance ** 0.5)

    for i in range(len(X)):
        row = [(X[i][j] - means[j]) / stds[j] if stds[j] > 0 else 0 for j in range(n_features)]
        X_scaled.append(row)
    return X_scaled, means, stds

第 5 步:多项式回归

class PolynomialRegression:
    def __init__(self, degree, learning_rate=0.01):
        self.degree = degree
        self.weights = [0.0] * degree
        self.bias = 0.0
        self.lr = learning_rate

    def make_features(self, X):
        return [[x ** (d + 1) for d in range(self.degree)] for x in X]

    def predict(self, X):
        features = self.make_features(X)
        return [sum(w * f for w, f in zip(self.weights, row)) + self.bias for row in features]

    def fit(self, X, y, epochs=1000, print_every=200):
        features = self.make_features(X)
        n = len(y)
        for epoch in range(epochs):
            predictions = [sum(w * f for w, f in zip(self.weights, row)) + self.bias for row in features]
            errors = [pred - actual for pred, actual in zip(predictions, y)]
            for j in range(self.degree):
                grad = (2 / n) * sum(errors[i] * features[i][j] for i in range(n))
                self.weights[j] -= self.lr * grad
            grad_b = (2 / n) * sum(errors)
            self.bias -= self.lr * grad_b
            if epoch % print_every == 0:
                cost = sum(e ** 2 for e in errors) / n
                print(f"  Epoch {epoch:4d} | Cost: {cost:.6f}")
        return self

    def r_squared(self, X, y):
        predictions = self.predict(X)
        y_mean = sum(y) / len(y)
        ss_res = sum((actual - pred) ** 2 for actual, pred in zip(y, predictions))
        ss_tot = sum((actual - y_mean) ** 2 for actual in y)
        return 1 - (ss_res / ss_tot)

第 6 步:岭回归(L2 正则化)

class RidgeRegression:
    def __init__(self, n_features, learning_rate=0.01, alpha=1.0):
        self.weights = [0.0] * n_features
        self.bias = 0.0
        self.lr = learning_rate
        self.alpha = alpha

    def predict_single(self, x):
        return sum(w * xi for w, xi in zip(self.weights, x)) + self.bias

    def predict(self, X):
        return [self.predict_single(x) for x in X]

    def fit(self, X, y, epochs=1000, print_every=200):
        n = len(y)
        n_features = len(X[0])
        for epoch in range(epochs):
            predictions = self.predict(X)
            errors = [pred - actual for pred, actual in zip(predictions, y)]
            mse = sum(e ** 2 for e in errors) / n
            reg_term = self.alpha * sum(w ** 2 for w in self.weights)
            cost = mse + reg_term
            for j in range(n_features):
                grad = (2 / n) * sum(errors[i] * X[i][j] for i in range(n))
                grad += 2 * self.alpha * self.weights[j]
                self.weights[j] -= self.lr * grad
            grad_b = (2 / n) * sum(errors)
            self.bias -= self.lr * grad_b
            if epoch % print_every == 0:
                print(f"  Epoch {epoch:4d} | Cost: {cost:.4f} | L2 penalty: {reg_term:.4f}")
        return self


print("\n=== Ridge Regression (L2 Regularization) ===")
print("Same data as multiple regression, with alpha=0.1")

from sklearn.linear_model import LinearRegression as SklearnLR
from sklearn.linear_model import Ridge
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score
import numpy as np

np.random.seed(42)
X_sk = np.random.uniform(0, 10, (100, 1))
y_sk = 3.0 * X_sk.squeeze() + 7.0 + np.random.normal(0, 2.0, 100)

X_train, X_test, y_train, y_test = train_test_split(X_sk, y_sk, test_size=0.2, random_state=42)

lr = SklearnLR()
lr.fit(X_train, y_train)
y_pred = lr.predict(X_test)

print("=== Scikit-learn Linear Regression ===")
print(f"Coefficient (w): {lr.coef_[0]:.4f}")
print(f"Intercept (b): {lr.intercept_:.4f}")
print(f"R-squared (test): {r2_score(y_test, y_pred):.4f}")
print(f"MSE (test): {mean_squared_error(y_test, y_pred):.4f}")

poly = PolynomialFeatures(degree=2, include_bias=False)
X_poly_sk = poly.fit_transform(X_train)
X_poly_test = poly.transform(X_test)

lr_poly = SklearnLR()
lr_poly.fit(X_poly_sk, y_train)
print(f"\nPolynomial degree 2 R-squared: {r2_score(y_test, lr_poly.predict(X_poly_test)):.4f}")

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

ridge = Ridge(alpha=1.0)
ridge.fit(X_train_scaled, y_train)
print(f"Ridge R-squared: {r2_score(y_test, ridge.predict(X_test_scaled)):.4f}")
print(f"Ridge coefficient: {ridge.coef_[0]:.4f}")

关键术语

术语人们常说的实际含义
线性回归(Linear regression)"在数据上画条线"找到权重 w 和偏置 b,使 wx+b 与真实 y 之间的平方差之和最小
代价函数(Cost function)"模型有多差"把模型参数映射为一个数字来度量预测误差的函数,优化的目标就是把它最小化
均方误差(MSE)"误差平方的平均"(1/n) * (预测值 - 真实值)^2 之和,对大误差的惩罚远超比例
梯度下降(Gradient descent)"往山下走"利用偏导数,沿减小代价函数的方向迭代调整参数
学习率(Learning rate)"步长"控制每一步梯度下降中参数变化幅度的标量
正规方程(Normal equation)"直接解出来"闭式解 w = (X^T X)^-1 X^T y,无需迭代即得最优权重
R 方(R-squared)"拟合得有多好"模型解释了 y 中多大比例的方差,取值从负无穷到 1.0
特征缩放(Feature scaling)"让特征可比"把特征变换到相近的范围(如零均值、单位方差),让梯度下降更快收敛
正则化(Regularization)"惩罚复杂度"在代价函数中加入压缩权重的项,防止过拟合
岭回归(Ridge regression)"L2 正则化"在 MSE 上加上 lambda * sum(w_i^2) 惩罚项的线性回归
多项式回归(Polynomial regression)"用线性的数学拟合曲线"在多项式特征(x, x^2, x^3, ...)上做线性回归,对权重仍是线性的
过拟合(Overfitting)"把训练数据背下来了"模型复杂到把训练数据中的噪声也拟合了进去,在新数据上失败
