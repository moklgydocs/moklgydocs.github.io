LLM 的差分隐私

LLM 的差分隐私

DP-SGD 仍是标准——注入噪声的梯度更新提供形式化的 (ε, δ) 保证。算力、显存和效用的开销都很可观;参数高效的 DP 微调(LoRA + DP-SGD)是 2025 年的常见配置(ACM 2025)。两组证据互相拉扯:基于金丝雀的成员推断(Duan 等,2024)报告对语言模型成功率有限;训练数据抽取(Carlini 等,2021;Nasr 等,2025)则能恢复大量逐字记忆。调和方案(arXiv:2503.06808,2025 年 3 月):差距在于测的东西不同——插入的金丝雀 vs "最易被抽取"的数据。新的金丝雀设计实现了无影子模型的基于损失的 MIA,并给出了首个"在真实数据上、带现实 DP 保证训练的 LLM"的非平凡 DP 审计。替代路线:PMixED(arXiv:2403.15638)——通过在下一 token 分布上做专家混合,在推理时做隐私预测;DP 合成数据生成(Google Research 2024)。新兴攻击:经由 LLM 反馈的差分隐私逆转——置信度分数泄露。

类型: 动手构建
编程语言: Python(标准库,DP-SGD 噪声注入与 ε-δ 会计器演示)
前置要求: 第 01 阶段 · 09(信息论)、第 10 阶段 · 01(大模型训练)
预计耗时: 约 60 分钟

学习目标

  • 定义 (ε, δ)-差分隐私,陈述 DP-SGD 配方。
  • 解释 2024–2025 年的拉扯:金丝雀 MIA 与训练数据抽取给出不同图景。
  • 描述 PMixED,以及为什么推理时隐私预测是 DP 训练的替代方案。
  • 描述"经由 LLM 反馈的差分隐私逆转"攻击。

问题

LLM 会背。Carlini 等人 2021 证明:生产语言模型能按要求逐字复现训练文本。DP 是形式化防御:让输出对任何单条训练样本可证不敏感。2024–2025 年的证据表明:DP-SGD 是必要的,但部署中的 ε 值可能与威胁模型不匹配。

概念

(ε, δ)-差分隐私

随机算法 M 是 (ε, δ)-DP 的,若对任意两个只差一条样本的数据集和任意事件 S:
P(M(D) in S) <= e^ε * P(M(D') in S) + δ。

解读:输出分布足够接近(由 ε 参数化),以至于任何单个个体的贡献都无法被可靠推断——除了以 δ 的概率。

DP-SGD

Abadi 等人 2016。标准配方:

  1. 采一个小批次。
  2. 计算逐样本梯度。
  3. 把每个逐样本梯度裁剪到阈值 C。
  4. 对裁剪后的梯度求和,加标准差 σ * C 的高斯噪声。
  5. 用带噪和更新参数。

隐私成本由会计器(Moments Accountant、Rényi DP 会计器)跟踪。LLM 文献中报告的 ε 值随威胁模型、数据敏感度和效用目标差异巨大;没有普适"安全"的默认 ε。已发表的例子在某些 LLM 训练设置下大致落在 ε ≈ 1–10,但这些只是示例——不是推荐默认值。更低的 ε 一般需要更多噪声,效用损失也更大。

LoRA + DP-SGD

对前沿模型做全量 DP-SGD 代价过高。LoRA(Hu 等,2022)把梯度更新限制在小适配器上,减少逐样本梯度存储。LoRA + DP-SGD 是 2025 年的常见配置。DP 保证作用于适配器;基座模型保持冻结。

2024–2025 年的拉扯

两条证据线:

  • 金丝雀 MIA(Duan 等,2024)。 往训练数据插入唯一金丝雀,测量成员推断攻击者能否认出它们。报告在语言模型上成功率有限,似乎说明 MIA 很难。
  • 训练数据抽取(Carlini 2021,Nasr 等 2025)。 用前缀提示模型,测量它能否逐字恢复训练文本。报告了大量记忆,似乎说明 MIA 在相关意义上很容易。

2025 年 3 月的调和(arXiv:2503.06808):两者测的东西不同。MIA 在插入的金丝雀上问"样本 e 在 D 里吗";抽取问的是"我能恢复 D 的什么"。对隐私要紧的是"最易被抽取"的那条样本;金丝雀低估了它,因为金丝雀不是为"易被抽取"而优化的。

新的金丝雀设计:无影子模型的基于损失 MIA;首个在真实数据、现实 DP 保证下对 LLM 的非平凡 DP 审计。

DP 训练的替代方案

  • PMixED(arXiv:2403.15638)。 推理时隐私预测。在下一 token 分布上做专家混合;每个专家只见训练数据的一个分片;聚合时加噪声实现 DP。完全绕开 DP 训练。
  • DP 合成数据生成(Google Research 2024)。 用 DP-SGD 做 LoRA 微调,采样合成数据,在合成数据上训练下游分类器。

两者都绕开全量 DP 训练的效用代价,代价是换成另一个威胁模型。

经由 LLM 反馈的差分隐私逆转

2025 年新兴攻击。把 DP 训练模型的置信度分数当作神谕,重新识别个体。即便输出不泄露,置信度分布也可能泄露。

防御:不暴露置信度,或在暴露前截断/量化。这是 (ε, δ)-DP 训练之外的额外要求。

投入使用

code/main.py 在玩具二分类数据集上模拟 DP-SGD。你可以扫噪声乘子 σ 和裁剪范数 C,跟踪 (ε, δ) 预算与准确率代价。"金丝雀攻击"插入一条唯一训练样本,测量对数损失检验在 DP 前后能否检出它。

交付

本课产出 outputs/skill-dp-audit.md。给定语言模型部署上的 DP 宣称,它审计:(ε, δ) 数值、所用会计器、MIA 评估协议,以及置信度暴露向量是否评估过。

练习

  1. 运行 code/main.py。在 σ ∈ {0.5, 1.0, 2.0} 上扫描,报告 (ε, δ)-准确率权衡。指出效用崩塌的拐点。

  2. 实现金丝雀插入和对数损失检验。测量 σ = 1.0 的 DP-SGD 前后的检出率。

  3. 读 Nasr 等人 2025 关于训练数据抽取的论文。为什么在中等 ε 下抽取成功率不崩塌?这对"以 MIA 做评估"意味着什么?

  4. 设计一个完全在推理时运行的 PMixED(arXiv:2403.15638)部署。PMixED 应对了哪个 DP-SGD 没应对的威胁模型?

  5. 草拟"经由 LLM 反馈的 DP 逆转"攻击。设计一个限制置信度分数泄露的对策,并估算部署成本。

术语人们常说的实际含义
DP"(ε, δ)-差分隐私"形式隐私:相邻数据集变化下输出分布接近
DP-SGD"注噪 SGD"梯度裁剪 + 高斯噪声;标准 DP 训练
LoRA + DP-SGD"高效隐私微调"在低秩适配器上做 DP-SGD;2025 标准配置
MIA"成员推断"判定某样本是否在训练数据中的攻击
