创建对象

创建对象

C# 的 new 关键字是一个多面手——创建引用类型、值类型、数组和字符串时，编译器会选择完全不同的 IL 指令。理解这些指令，才能真正掌握 .NET 对象创建的全貌。

核心要点

  • newobj：调用构造函数创建对象（引用类型堆分配 / 值类型初始化）
  • initobj：零初始化值类型（无构造函数调用，更快）
  • newarr：创建数组
  • ldstr：创建字符串（字符串驻留优化）

一、newobj 指令 —— 构造新对象

1.1 指令行为

newobj ctor：

  1. 分配内存（引用类型：GC 堆；值类型：栈/内联）
  2. 初始化内存为零/null
  3. 调用构造函数 ctor
  4. 将对象引用（引用类型）或值（值类型）压入评估栈

1.2 引用类型 vs 值类型

特性引用类型（class）值类型（struct）
内存位置GC 堆栈或内联（作为字段/数组元素）
分配开销GC 分配 + 类型对象指针 + 同步块无额外开销
构造函数必须调用可选（可用 initobj 替代）
结果类型对象引用 (O)值类型 (ValueType)

二、newobj 创建引用类型

2.1 C# 示例

class Person
{
    public string Name;
    public int Age;

    public Person(string name, int age)
    {
        Name = name;
        Age = age;
    }
}

// 创建对象
var p = new Person("Alice", 30);
IL_0000: ldstr "Alice"
IL_0005: ldc.i4.s 30
IL_0007: newobj instance void Person::.ctor(string, int32)
IL_000c: stloc.0

2.2 内存布局

2.3 newobj 的执行步骤

内存零初始化

CLR 保证所有新分配的对象内存被零初始化。这意味着即使构造函数没有设置某个字段，它的值也是确定的：数值为 0，引用为 null，布尔为 false。这是 .NET 消除"未初始化内存"漏洞的关键机制。

三、newobj 创建值类型

3.1 带自定义构造函数

struct Point
{
    public int X, Y;

    public Point(int x, int y)
    {
        X = x;
        Y = y;
    }
}

// 创建值类型
var p = new Point(3, 4);
IL_0000: ldloca.s p         // 加载局部变量地址
IL_0002: ldc.i4.3
IL_0003: ldc.i4.4
IL_0004: call instance void Point::.ctor(int32, int32)
// 注意：值类型的 newobj 在某些情况下编译为 call 而非 newobj
// 具体取决于上下文（局部变量 vs 表达式）

3.2 无自定义构造函数

struct Point
{
    public int X, Y;
}

// C# new 语法
var p = new Point();    // 编译为 initobj
IL_0000: ldloca.s p
IL_0002: initobj Point       // 零初始化，不调用构造函数

四、initobj 指令 —— 零初始化值类型

4.1 指令行为

initobj typeToken：

  1. 将指定地址处的值类型初始化为零/null
  2. 所有数值字段 → 0，引用字段 → null，布尔字段 → false
  3. 不调用任何构造函数

4.2 newobj vs initobj 对比

特性newobjinitobj
构造函数调用不调用
初始化内容构造函数决定全部置零
适用类型引用类型 + 值类型仅值类型
性能较慢（方法调用开销）更快（直接内存清零）
C# 对应new T(args)new T() / default(T)

4.3 C# 中的 initobj 场景

// 1. 无参 new 值类型
Point p1 = new Point();         // initobj Point

// 2. default 关键字
Point p2 = default(Point);      // initobj Point
Point p3 = default;             // initobj Point（C# 7.1+）

// 3. 泛型 default
T GetDefault<T>() => default;   // initobj !!0（泛型参数）
// Point p1 = new Point();
IL_0000: ldloca.s p1
IL_0002: initobj Point

// Point p2 = default(Point);
IL_0007: ldloca.s p2
IL_0009: initobj Point

性能建议

对于没有自定义构造函数的值类型，initobj 比 newobj 更快（省去方法调用开销）。C# 编译器自动选择最优指令，无需手动干预。

五、sizeof 指令 —— 获取值类型大小

5.1 指令行为

sizeof valueType：

  1. 将值类型的字节大小压入评估栈（作为 int32）
  2. 包含对齐填充（padding）
  3. 不包含对象开销（类型对象指针、同步块索引）

5.2 C# 示例

using System;

struct Point3D
{
    public double X;   // 8 bytes
    public double Y;   // 8 bytes
    public double Z;   // 8 bytes
}

unsafe
{
    int size = sizeof(Point3D);    // 24
}
IL_0000: sizeof Point3D
IL_0006: stloc.0

5.3 sizeof 的用途

场景说明
不安全指针算术计算指针偏移量
MemoryMarshal直接内存操作
Span<T> 切片按元素大小计算范围
互操作确定 P/Invoke 结构体布局

sizeof vs Marshal.SizeOf

  • sizeof（IL 指令）：返回 CLR 内部的托管大小，包含对齐填充
  • Marshal.SizeOf：返回非托管互操作的大小，受 StructLayout 属性影响
  • 二者结果可能不同！

六、字符串创建：ldstr

6.1 为什么不用 newobj？

字符串是 .NET 中最特殊的引用类型：

  • 字符串驻留（String Interning）：相同内容的字符串共享同一实例
  • 不可变性：创建后不可修改
  • 特殊优化：CLR 对字符串有专门的分配路径
string s1 = "hello";
string s2 = "hello";
// s1 和 s2 引用同一对象（驻留）
IL_0000: ldstr "hello"        // 不是 newobj！
IL_0005: stloc.0

IL_0006: ldstr "hello"        // 相同的 token → 相同的对象
IL_000b: stloc.1

6.2 ldstr 的行为

  1. 从元数据的 用户字符串堆（#US） 中查找 token
  2. 如果字符串已驻留，返回现有引用
  3. 如果未驻留，在 GC 堆分配新字符串对象并驻留
  4. 压入对象引用

字符串驻留的性能影响

ldstr 对字面量字符串自动驻留，但运行时拼接的字符串（如 "hel" + "lo"）不一定驻留。C# 编译器会将常量拼接优化为单个 ldstr，但变量拼接则不会。

七、数组创建：newarr

7.1 一维数组

int[] numbers = new int[10];
IL_0000: ldc.i4.s 10          // 数组长度
IL_0002: newarr [mscorlib]System.Int32
IL_0007: stloc.0

7.2 多维数组

int[,] matrix = new int[3, 4];    // 不用 newarr，用 newobj
IL_0000: ldc.i4.3              // 维度1
IL_0001: ldc.i4.4              // 维度2
IL_0002: newobj instance void int32[0...,0...]::.ctor(int32, int32)

一维数组 vs 多维数组

  • 一维零基数组（int[]）→ newarr：JIT 特殊优化，性能最佳
  • 多维数组（int[,]）→ newobj：无 JIT 优化，性能较差
  • 交错数组（int[][]）→ 多次 newarr：介于两者之间

7.3 newarr 内存布局

int[5] 数组的内存布局：

┌───────────────────────────────────────────────────┐
│ 类型对象指针 → Int32[] Type                        │
├───────────────────────────────────────────────────┤
│ 同步块索引                                        │
├───────────────────────────────────────────────────┤
│ 长度 = 5                                          │
├──────┬──────┬──────┬──────┬──────┬────────────────┤
│ [0]  │ [1]  │ [2]  │ [3]  │ [4]  │                │
│  0   │  0   │  0   │  0   │  0   │                │
└──────┴──────┴──────┴──────┴──────┴────────────────┘

十、面试要点

面试高频问题

  1. new 创建引用类型和值类型在 IL 层的区别？

    • 引用类型：newobj 在 GC 堆分配 + 构造函数；值类型：newobj/call 栈上初始化 + 构造函数，或 initobj 零初始化

  2. newobj 和 initobj 的区别？

    • newobj 分配内存 + 调用构造函数；initobj 仅零初始化，不调用构造函数；initobj 更快但只能初始化为默认值

  3. C# 的 default(T) 编译成什么 IL？

    • 值类型 → initobj；引用类型 → ldnull

  4. 字符串为什么用 ldstr 而不是 newobj？

    • 字符串驻留优化：相同内容的字面量共享同一实例，ldstr 自动查找驻留池

  5. 一维数组和多维数组的 IL 指令区别？

    • 一维零基数组 → newarr（JIT 优化，更快）；多维数组 → newobj（无特殊优化）

  6. sizeof 和 Marshal.SizeOf 的区别？

    • sizeof（IL 指令）返回托管大小含对齐；Marshal.SizeOf 返回非托管互操作大小，受 StructLayout 影响，二者可能不同
