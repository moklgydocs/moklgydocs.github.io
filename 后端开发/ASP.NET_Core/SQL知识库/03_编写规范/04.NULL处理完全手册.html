NULL 处理完全手册

NULL 处理完全手册

NULL 是 SQL 里最坑人的东西，没有之一。它不等于空字符串，不等于 0，甚至不等于它自己。很多 Bug 都是 NULL 引起的，这篇把常见的坑和正确处理方式理一遍。

NULL 的三值逻辑

普通编程语言是两值逻辑：TRUE / FALSE。SQL 是三值逻辑：TRUE / FALSE / UNKNOWN。

任何和 NULL 的比较运算结果都是 UNKNOWN，WHERE 条件只取 TRUE 的行：

-- 假设 Remark 列有些行是 NULL
SELECT * FROM Orders WHERE Remark = NULL;     -- 返回 0 行！
SELECT * FROM Orders WHERE Remark <> NULL;    -- 也返回 0 行！
SELECT * FROM Orders WHERE Remark = Remark;   -- NULL 行也不会出来！

-- 正确写法
SELECT * FROM Orders WHERE Remark IS NULL;
SELECT * FROM Orders WHERE Remark IS NOT NULL;

常见的坑

坑 1：NOT IN 遇到 NULL

-- 子查询结果里有 NULL
SELECT * FROM Customers
WHERE CustomerId NOT IN (1, 2, NULL);
-- 返回 0 行！因为 CustomerId NOT IN (..., NULL) 永远是 UNKNOWN

-- ✅ 用 NOT EXISTS
SELECT * FROM Customers c
WHERE NOT EXISTS (SELECT 1 FROM BlackList b WHERE b.CustomerId = c.CustomerId);

坑 2：聚合函数忽略 NULL

-- 有 5 行数据：10, 20, NULL, 30, NULL
SELECT AVG(Amount) FROM Orders;  -- = (10+20+30)/3 = 20，不是 (10+20+0+30+0)/5 = 12
SELECT COUNT(Amount) FROM Orders;  -- = 3（只数非 NULL 的）
SELECT COUNT(*) FROM Orders;       -- = 5（数所有行）
SELECT SUM(Amount) FROM Orders;    -- = 60（忽略 NULL）

如果你想让 NULL 当 0 算：

SELECT AVG(ISNULL(Amount, 0)) FROM Orders;  -- = (10+20+0+30+0)/5 = 12

坑 3：字符串拼接

SELECT 'Hello ' + NULL + ' World';  -- 结果是 NULL！
-- 任何值和 NULL 拼接都是 NULL

-- ✅
SELECT 'Hello ' + ISNULL(MiddleName, '') + ' World' FROM Users;
-- 或者
SELECT CONCAT('Hello ', MiddleName, ' World') FROM Users;
-- CONCAT 会自动把 NULL 当空字符串处理

坑 4：排序中 NULL 的位置

SELECT * FROM Products ORDER BY Price ASC;
-- NULL 排在最前面（SQL Server 把 NULL 视为最小值）

SELECT * FROM Products ORDER BY Price DESC;
-- NULL 排在最后面

-- 如果想让 NULL 排最后（升序时）
SELECT * FROM Products
ORDER BY CASE WHEN Price IS NULL THEN 1 ELSE 0 END, Price ASC;

坑 5：CASE WHEN 和 NULL

-- ❌
CASE Status WHEN NULL THEN '未知' ...
-- 这永远不会匹配，因为 Status = NULL 是 UNKNOWN

-- ✅
CASE WHEN Status IS NULL THEN '未知' ELSE ... END

坑 6：唯一索引和 NULL

SQL Server 的唯一索引允许一个 NULL 值。第二个 NULL 就违反唯一约束了。

CREATE UNIQUE INDEX UIX ON Users(Email);
INSERT INTO Users (Email) VALUES (NULL);  -- OK
INSERT INTO Users (Email) VALUES (NULL);  -- 报错：重复键

-- 如果想允许多个 NULL，用筛选索引
CREATE UNIQUE INDEX UIX ON Users(Email) WHERE Email IS NOT NULL;

NULL 处理函数

ISNULL

-- 如果是 NULL 就替换成指定值
SELECT ISNULL(Phone, '未填写') FROM Customers;
SELECT ISNULL(Amount, 0) FROM Orders;

注意：ISNULL 返回类型跟第一个参数一样。如果第一个是 VARCHAR(10)，第二个是 VARCHAR(50)，结果会被截断到 10 个字符。

COALESCE

-- 返回第一个非 NULL 的值，可以传多个参数
SELECT COALESCE(Phone, Mobile, Email, '无联系方式') FROM Customers;

COALESCE 比 ISNULL 灵活，支持多个参数。返回类型按最高优先级的参数类型。

NULLIF

-- 两个值相等就返回 NULL，不等就返回第一个
SELECT NULLIF(Amount, 0);  -- Amount 是 0 就返回 NULL

-- 常用于防止除零错误
SELECT Total / NULLIF(Count, 0) AS Avg;
-- Count 是 0 → NULLIF 返回 NULL → 除以 NULL = NULL（不报错）

IIF（SQL Server 2012+）

SELECT IIF(Score IS NULL, '缺考', CAST(Score AS NVARCHAR)) FROM Exam;

可空列的设计建议

什么时候允许 NULL

  • 确实有"没有值"的业务含义：客户的传真号（现在谁还有传真）
  • 外键可选关联：订单的 CouponId（没用优惠券就是 NULL）

什么时候不允许 NULL

  • 主键、外键（强关联）
  • 状态字段：用 0 代替 NULL
  • 金额字段：用 0 代替 NULL
  • 创建时间：DEFAULT GETDATE()
CREATE TABLE Orders (
    OrderId INT PRIMARY KEY IDENTITY,
    CustomerId INT NOT NULL,
    Amount DECIMAL(10,2) NOT NULL DEFAULT 0,
    Status TINYINT NOT NULL DEFAULT 0,
    Remark NVARCHAR(500) NULL,  -- 备注可以为空
    CreateTime DATETIME NOT NULL DEFAULT GETDATE()
);

空字符串 vs NULL

这是个永恒争论。我的建议：

  • 统一用 NULL 表示"没有值"。空字符串 '' 和 NULL 混用会导致查询条件很难写
  • 如果你选了空字符串，那就全部用空字符串，不要混
-- 混用的痛苦
SELECT * FROM Customers WHERE Phone IS NULL OR Phone = '';
-- 如果统一用 NULL，只需要
SELECT * FROM Customers WHERE Phone IS NULL;

查询中处理 NULL 的模式

可选条件参数

-- 传 NULL 表示不过滤
CREATE PROCEDURE usp_SearchOrders
    @CustomerId INT = NULL,
    @Status INT = NULL
AS
    SELECT * FROM Orders
    WHERE (@CustomerId IS NULL OR CustomerId = @CustomerId)
        AND (@Status IS NULL OR Status = @Status);

LEFT JOIN 后的 NULL 处理

SELECT c.CustomerName,
    ISNULL(o.OrderCount, 0) AS OrderCount
FROM Customers c
LEFT JOIN (
    SELECT CustomerId, COUNT(*) AS OrderCount
    FROM Orders GROUP BY CustomerId
) o ON c.CustomerId = o.CustomerId;

GROUP BY 时 NULL 算一组

SELECT City, COUNT(*) FROM Customers GROUP BY City;
-- City 为 NULL 的行会归为一组
-- 如果不想要 NULL 组
SELECT City, COUNT(*) FROM Customers WHERE City IS NOT NULL GROUP BY City;
