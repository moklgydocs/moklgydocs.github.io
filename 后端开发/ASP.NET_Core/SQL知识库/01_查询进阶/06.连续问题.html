连续问题（连续登录、连续增长）

连续问题

"连续登录 N 天""连续增长的天数""连续缺勤"——这类问题看着简单，但用 SQL 写出来并不直觉。核心技巧就一个：用 ROW_NUMBER 把连续的行变成同一个分组。

核心思路：差值分组法

一句话解释：如果日期是连续的，那么日期减去行号的差值是固定的。

日期        行号    日期 - 行号
01-01       1       01-00  → 12-31
01-02       2       01-00  → 12-31
01-03       3       01-00  → 12-31
01-05       4       01-01  → 01-01  ← 断了，差值变了
01-06       5       01-01  → 01-01
01-07       6       01-01  → 01-01

连续的日期减去行号后得到的值是一样的！拿这个差值做 GROUP BY，就能把连续的行分成一组。

题型一：连续登录 N 天的用户

数据

CREATE TABLE #Login (
    UserId INT,
    LoginDate DATE
);
INSERT INTO #Login VALUES
(1, '2024-01-01'), (1, '2024-01-02'), (1, '2024-01-03'),  -- 连续 3 天
(1, '2024-01-05'), (1, '2024-01-06'),                      -- 连续 2 天
(1, '2024-01-10'),                                          -- 独立 1 天
(2, '2024-01-01'), (2, '2024-01-02'), (2, '2024-01-03'),
(2, '2024-01-04'), (2, '2024-01-05');                       -- 连续 5 天

解法

;WITH numbered AS (
    -- 第 1 步：去重 + 编号
    SELECT DISTINCT UserId, LoginDate,
        DATEADD(DAY,
            -ROW_NUMBER() OVER (PARTITION BY UserId ORDER BY LoginDate),
            LoginDate
        ) AS grp
    FROM #Login
),
streaks AS (
    -- 第 2 步：按 grp 分组，统计每段连续登录的天数
    SELECT UserId, grp,
        MIN(LoginDate) AS StartDate,
        MAX(LoginDate) AS EndDate,
        COUNT(*) AS ConsecutiveDays
    FROM numbered
    GROUP BY UserId, grp
)
SELECT * FROM streaks;

结果：

找连续登录 >= 3 天的用户

-- 在上面的基础上加个 HAVING 或 WHERE
SELECT DISTINCT UserId FROM streaks WHERE ConsecutiveDays >= 3;
-- 结果：用户 1 和用户 2

找每个用户最长连续登录天数

SELECT UserId, MAX(ConsecutiveDays) AS MaxStreak
FROM streaks
GROUP BY UserId;
-- 用户 1：3 天，用户 2：5 天

题型二：连续增长

"找出股票连续上涨的天数"或"销售额连续增长的时间段"。

CREATE TABLE #Stock (
    TradeDate DATE,
    Price DECIMAL(10,2)
);
INSERT INTO #Stock VALUES
('2024-01-01', 100), ('2024-01-02', 102), ('2024-01-03', 105),  -- 涨
('2024-01-04', 103),                                              -- 跌
('2024-01-05', 106), ('2024-01-06', 108),                        -- 涨
('2024-01-07', 107);                                              -- 跌

解法

;WITH withPrev AS (
    -- 第 1 步：和前一天比较，标记涨跌
    SELECT *,
        CASE WHEN Price > LAG(Price) OVER (ORDER BY TradeDate) THEN 1 ELSE 0 END AS IsUp
    FROM #Stock
),
grouped AS (
    -- 第 2 步：差值分组。只对"涨"的行编号
    SELECT *,
        ROW_NUMBER() OVER (ORDER BY TradeDate)
        - ROW_NUMBER() OVER (PARTITION BY IsUp ORDER BY TradeDate) AS grp
    FROM withPrev
)
-- 第 3 步：只取 IsUp = 1 的分组
SELECT MIN(TradeDate) AS StartDate, MAX(TradeDate) AS EndDate,
    COUNT(*) AS ConsecutiveUpDays
FROM grouped
WHERE IsUp = 1
GROUP BY grp
ORDER BY StartDate;

01-0201-032
01-0501-062

题型三：连续缺勤/缺失日期

"找出员工连续旷工超过 3 天的时间段"——其实就是找日历上的空洞。

-- 先得到一个日历表（或者用递归 CTE 生成）
-- 然后把员工出勤日期和日历表对比，缺失的就是旷工
-- 再对旷工日期做差值分组

;WITH Calendar AS (
    SELECT CAST('2024-01-01' AS DATE) AS dt
    UNION ALL
    SELECT DATEADD(DAY, 1, dt) FROM Calendar WHERE dt < '2024-01-31'
),
Absent AS (
    SELECT c.dt, e.EmpId
    FROM Calendar c
    CROSS JOIN (SELECT DISTINCT EmpId FROM Attendance) e
    WHERE NOT EXISTS (
        SELECT 1 FROM Attendance a
        WHERE a.EmpId = e.EmpId AND a.AttendDate = c.dt
    )
),
Grouped AS (
    SELECT *,
        DATEADD(DAY, -ROW_NUMBER() OVER (PARTITION BY EmpId ORDER BY dt), dt) AS grp
    FROM Absent
)
SELECT EmpId, MIN(dt) AS AbsentFrom, MAX(dt) AS AbsentTo,
    COUNT(*) AS ConsecutiveDays
FROM Grouped
GROUP BY EmpId, grp
HAVING COUNT(*) >= 3
OPTION (MAXRECURSION 31);

题型四：最大连续区间

"用户最长的一次连续活跃时间是多少？"

;WITH numbered AS (
    SELECT DISTINCT UserId, ActiveDate,
        DATEADD(DAY,
            -ROW_NUMBER() OVER (PARTITION BY UserId ORDER BY ActiveDate),
            ActiveDate
        ) AS grp
    FROM UserActivity
),
streaks AS (
    SELECT UserId, COUNT(*) AS Len
    FROM numbered
    GROUP BY UserId, grp
)
SELECT UserId, MAX(Len) AS LongestStreak
FROM streaks
GROUP BY UserId;

差值分组法为什么有效

画个图就明白了。假设日期序列是 1, 2, 3, 5, 6, 8：

日期:    1  2  3  5  6  8
行号:    1  2  3  4  5  6
差值:    0  0  0  1  1  2

连续的日期差值相同 → 用差值做分组键 → 同一组就是一段连续区间。

注意：

  • 一定要先 DISTINCT 去掉重复日期，不然同一天登录两次会打断连续性
  • PARTITION BY 要按用户（或其他分组维度）分开编号
  • 差值本身不重要，重要的是相同差值表示连续

另一种思路：LAG 判断断点

不用差值分组，用 LAG 判断每行和前一行是不是连续的，然后用 SUM 累加断点来分组：

;WITH marked AS (
    SELECT DISTINCT UserId, LoginDate,
        CASE
            WHEN DATEDIFF(DAY,
                LAG(LoginDate) OVER (PARTITION BY UserId ORDER BY LoginDate),
                LoginDate
            ) = 1 THEN 0
            ELSE 1  -- 断了，新的一段开始
        END AS IsNewGroup
    FROM #Login
),
grouped AS (
    SELECT *,
        SUM(IsNewGroup) OVER (PARTITION BY UserId ORDER BY LoginDate) AS grp
    FROM marked
)
SELECT UserId, MIN(LoginDate) AS StartDate, MAX(LoginDate) AS EndDate,
    COUNT(*) AS ConsecutiveDays
FROM grouped
GROUP BY UserId, grp;

这种写法更直觉——"如果和前一天差 1 天就是连续的，否则就是新的一段"。两种方法结果一样，用哪个看你习惯。
