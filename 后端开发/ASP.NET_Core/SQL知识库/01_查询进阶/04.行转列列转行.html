行转列列转行

做报表的时候经常碰到：数据库里存的是一行一行的明细，但报表要显示成横着的列。或者反过来。这就是行转列（PIVOT）和列转行（UNPIVOT）。

先准备数据

CREATE TABLE #Scores (
    StudentName NVARCHAR(20),
    Subject NVARCHAR(20),
    Score INT
);
INSERT INTO #Scores VALUES
('张三', '语文', 85), ('张三', '数学', 92), ('张三', '英语', 78),
('李四', '语文', 90), ('李四', '数学', 88), ('李四', '英语', 95),
('王五', '语文', 75), ('王五', '数学', 80), ('王五', '英语', 82);

原始数据长这样（9 行）：

StudentNameSubjectScore
张三语文85
张三数学92
张三英语78
.........

我们想要的结果（3 行）：

StudentName语文数学英语
张三859278
李四908895
王五758082

行转列：三种写法

写法一：CASE WHEN（最通用）

SELECT StudentName,
    MAX(CASE WHEN Subject = '语文' THEN Score END) AS 语文,
    MAX(CASE WHEN Subject = '数学' THEN Score END) AS 数学,
    MAX(CASE WHEN Subject = '英语' THEN Score END) AS 英语
FROM #Scores
GROUP BY StudentName;

为什么要 MAX？因为 GROUP BY 后每组有多行，需要一个聚合函数把值"提取"出来。CASE WHEN 只对匹配的行返回值，其他行返回 NULL，MAX 就把那个唯一的非 NULL 值挑出来了。用 MIN、SUM 也行，反正每组只有一个值。

优点：所有数据库都支持，写起来灵活
缺点：列要硬编码，科目多了写起来又臭又长

写法二：PIVOT（SQL Server 专属语法）

SELECT StudentName, [语文], [数学], [英语]
FROM #Scores
PIVOT (
    MAX(Score)
    FOR Subject IN ([语文], [数学], [英语])
) AS pvt;

PIVOT 语法三要素：

  • 聚合函数(值列)：MAX(Score)，对哪列做聚合
  • FOR 转换列 IN (列值列表)：Subject 的哪些值变成列名
  • 没写在 PIVOT 里的其他列自动变成分组依据（这里就是 StudentName）

小心多余列

PIVOT 会把源表里没出现在 PIVOT 子句里的所有列当作分组依据。如果源表有个 Id 列，每行 Id 不同，结果就不会合并——每行还是一行。

解决办法：先用子查询或 CTE 只选需要的列。

SELECT StudentName, [语文], [数学], [英语]
FROM (
    SELECT StudentName, Subject, Score FROM #Scores  -- 只选这 3 列
) src
PIVOT (MAX(Score) FOR Subject IN ([语文], [数学], [英语])) AS pvt;

写法三：动态 PIVOT（列不固定时）

如果科目不固定（今天有语数英，明天加了物理化学），得用动态 SQL：

DECLARE @cols NVARCHAR(MAX), @sql NVARCHAR(MAX);

-- 1. 先查出所有科目，拼成 [语文],[数学],[英语] 的格式
SELECT @cols = STRING_AGG(QUOTENAME(Subject), ',')
FROM (SELECT DISTINCT Subject FROM #Scores) t;

-- 2. 拼动态 SQL
SET @sql = N'
SELECT StudentName, ' + @cols + '
FROM (SELECT StudentName, Subject, Score FROM #Scores) src
PIVOT (MAX(Score) FOR Subject IN (' + @cols + ')) AS pvt;';

-- 3. 执行
EXEC sp_executesql @sql;

STRING_AGG 是 SQL Server 2017+ 的函数。老版本用 FOR XML PATH：

SELECT @cols = STUFF((
    SELECT ',' + QUOTENAME(Subject)
    FROM (SELECT DISTINCT Subject FROM #Scores) t
    ORDER BY Subject
    FOR XML PATH(''), TYPE
).value('.', 'NVARCHAR(MAX)'), 1, 1, '');

列转行：UNPIVOT

把上面那个宽表变回长表。假设有这么张表：

CREATE TABLE #ScoreWide (
    StudentName NVARCHAR(20),
    语文 INT,
    数学 INT,
    英语 INT
);
INSERT INTO #ScoreWide VALUES
('张三', 85, 92, 78),
('李四', 90, 88, 95);

写法一：UNPIVOT

SELECT StudentName, Subject, Score
FROM #ScoreWide
UNPIVOT (
    Score FOR Subject IN ([语文], [数学], [英语])
) AS unpvt;

结果：

StudentNameSubjectScore
张三语文85
张三数学92
张三英语78
李四语文90
李四数学88
李四英语95

写法二：CROSS APPLY + VALUES（更灵活）

SELECT s.StudentName, t.Subject, t.Score
FROM #ScoreWide s
CROSS APPLY (VALUES
    ('语文', s.语文),
    ('数学', s.数学),
    ('英语', s.英语)
) t(Subject, Score);

CROSS APPLY + VALUES 的好处：

  • 可以同时转多组列
  • 可以处理不同数据类型
  • NULL 值也会保留（UNPIVOT 会自动过滤 NULL）

实战场景

月度销售交叉表

-- 原始数据：销售员、月份、金额
-- 要做成：每个销售员一行，1-12月每月一列

DECLARE @cols NVARCHAR(MAX), @sql NVARCHAR(MAX);

SELECT @cols = STRING_AGG(QUOTENAME(CONCAT(MONTH(SaleDate), '月')), ',')
    WITHIN GROUP (ORDER BY MONTH(SaleDate))
FROM (SELECT DISTINCT MONTH(SaleDate) AS m, SaleDate FROM Sales) t;

-- 实际上你得先造出月份标签
;WITH MonthData AS (
    SELECT SalesMan,
        CONCAT(MONTH(SaleDate), '月') AS MonthLabel,
        Amount
    FROM Sales
    WHERE YEAR(SaleDate) = 2024
)
SELECT SalesMan, [1月],[2月],[3月],[4月],[5月],[6月],
                 [7月],[8月],[9月],[10月],[11月],[12月]
FROM MonthData
PIVOT (SUM(Amount) FOR MonthLabel IN (
    [1月],[2月],[3月],[4月],[5月],[6月],
    [7月],[8月],[9月],[10月],[11月],[12月]
)) AS pvt;

配置表键值对转一行

很多系统有个 Settings 表，存的是 Key-Value 格式：

-- Key           Value
-- SiteName      我的网站
-- MaxUpload     10
-- AllowRegister true

SELECT
    MAX(CASE WHEN [Key] = 'SiteName' THEN Value END) AS SiteName,
    MAX(CASE WHEN [Key] = 'MaxUpload' THEN Value END) AS MaxUpload,
    MAX(CASE WHEN [Key] = 'AllowRegister' THEN Value END) AS AllowRegister
FROM Settings;

多行合并成一个字段

严格说不是行转列，但经常一起被问到：

-- 每个部门的员工名用逗号拼起来
-- SQL Server 2017+
SELECT DeptId,
    STRING_AGG(EmpName, ', ') WITHIN GROUP (ORDER BY EmpName) AS Members
FROM Employees
GROUP BY DeptId;

-- 老版本
SELECT DeptId,
    STUFF((
        SELECT ', ' + EmpName
        FROM Employees e2
        WHERE e2.DeptId = e1.DeptId
        ORDER BY EmpName
        FOR XML PATH('')
    ), 1, 2, '') AS Members
FROM Employees e1
GROUP BY DeptId;

总结选型

需求推荐写法
列固定，写一次就行PIVOT 或 CASE WHEN
列不固定，要自动适应动态 SQL + PIVOT
列转行CROSS APPLY + VALUES（最灵活）
多行合并成字符串STRING_AGG（2017+）或 FOR XML PATH
跨数据库兼容CASE WHEN（哪儿都能用）
