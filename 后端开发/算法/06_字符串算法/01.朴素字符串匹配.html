朴素字符串匹配

1. 算法定位

朴素字符串匹配（Brute Force）是最基本的字符串搜索算法，通过逐位滑动模式串与文本串对比，是理解KMP等高级算法的基础。

2. 一句话理解

将模式串在文本串上逐位滑动，每个位置从头到尾逐字符比较，匹配失败就后移一位重新来过。

3. 生活化比喻

就像在一本书中找某个特定的词：

  • 把尺子（模式串）放在书（文本串）的开头
  • 逐字对比，发现不一样就把尺子整体往右挪一格
  • 从尺子的第一个字开始重新对比
  • 直到找到完全匹配或者到达末尾

4. 核心思想

  • 两层循环：外层控制模式串在文本串中的起始位置，内层逐字符比较
  • 匹配失败时，文本串指针回退，模式串从头开始
  • 不利用已匹配的信息，存在大量冗余比较

5. 图解推演

指针移动示意

朴素算法指针回退问题：

匹配成功时:  i++, j++  （两个指针同时前进）
匹配失败时:  i = i - j + 1, j = 0  （i回退到下一起始位，j回到开头）

           i
T: [A][B][A][B][D]...
P: [A][B][A][B][C]
                j
       失配！
           ↓
      i（回退到位置1）
T: [A][B][A][B][D]...
P:    [A][B][A][B][C]
       j（重置为0）

6. 执行步骤

  1. 设文本串长度为n，模式串长度为m
  2. 外层循环：i 从 0 到 n-m（滑动窗口起始位置）
  3. 内层循环：j 从 0 到 m-1（模式串中的字符索引）
  4. 比较 T[i+j] 和 P[j]
  5. 如果 j 走完了都匹配 → 找到一个匹配位置
  6. 如果中途不匹配 → 跳出内层循环，i后移一位

7. C# 实现

using System;
using System.Collections.Generic;

/// <summary>
/// 朴素字符串匹配算法
/// </summary>
public class BruteForceStringMatch
{
    /// <summary>
    /// 方法1：双层循环实现
    /// 返回模式串在文本串中所有出现的起始位置
    /// </summary>
    public List<int> SearchAll(string text, string pattern)
    {
        var result = new List<int>();
        int n = text.Length;     // 文本串长度
        int m = pattern.Length;  // 模式串长度

        // 外层：模式串可以对齐的所有起始位置
        for (int i = 0; i <= n - m; i++)
        {
            int j = 0;

            // 内层：逐字符比较
            while (j < m && text[i + j] == pattern[j])
            {
                j++;
            }

            // 如果j走完了整个模式串，说明完全匹配
            if (j == m)
            {
                result.Add(i);  // 记录匹配位置
            }
        }

        return result;
    }

    /// <summary>
    /// 方法2：单循环+指针回退实现（展示指针回退问题）
    /// </summary>
    public int SearchFirst(string text, string pattern)
    {
        int n = text.Length;
        int m = pattern.Length;
        int i = 0;  // 文本串指针
        int j = 0;  // 模式串指针

        while (i < n && j < m)
        {
            if (text[i] == pattern[j])
            {
                // 当前字符匹配，两个指针同时前进
                i++;
                j++;
            }
            else
            {
                // 不匹配：i回退到本次匹配开始位置的下一位
                i = i - j + 1;
                // 模式串指针重置为开头
                j = 0;
            }
        }

        // 如果j走完了模式串，说明找到匹配
        if (j == m)
            return i - m;  // 返回匹配的起始位置

        return -1;  // 未找到
    }

    /// <summary>
    /// 方法3：带详细过程输出（教学用）
    /// </summary>
    public int SearchWithTrace(string text, string pattern)
    {
        int n = text.Length;
        int m = pattern.Length;
        int compareCount = 0;  // 比较次数计数器

        Console.WriteLine($"文本串: {text}");
        Console.WriteLine($"模式串: {pattern}");
        Console.WriteLine();

        for (int i = 0; i <= n - m; i++)
        {
            Console.Write($"位置{i}: ");
            bool matched = true;

            for (int j = 0; j < m; j++)
            {
                compareCount++;

                if (text[i + j] != pattern[j])
                {
                    Console.WriteLine($"比较到第{j + 1}个字符失败 " +
                        $"('{text[i + j]}' ≠ '{pattern[j]}')");
                    matched = false;
                    break;
                }
            }

            if (matched)
            {
                Console.WriteLine($"完全匹配！");
                Console.WriteLine($"\n总比较次数: {compareCount}");
                return i;
            }
        }

        Console.WriteLine($"\n未找到匹配，总比较次数: {compareCount}");
        return -1;
    }
}

/// <summary>
/// 测试程序
/// </summary>
public class Program
{
    public static void Main()
    {
        var bf = new BruteForceStringMatch();

        // 基本测试
        Console.WriteLine("=== 查找所有匹配位置 ===");
        string text1 = "ABABABABC";
        string pattern1 = "ABAB";
        var positions = bf.SearchAll(text1, pattern1);
        Console.WriteLine($"文本: \"{text1}\"");
        Console.WriteLine($"模式: \"{pattern1}\"");
        Console.WriteLine($"匹配位置: [{string.Join(", ", positions)}]");

        // 详细过程演示
        Console.WriteLine("\n=== 详细匹配过程 ===");
        bf.SearchWithTrace("ABABDABABC", "ABABC");

        // 最差情况
        Console.WriteLine("\n=== 最差情况演示 ===");
        string worstText = "AAAAAAAAAB";
        string worstPattern = "AAAAB";
        Console.WriteLine($"文本: \"{worstText}\" (长度{worstText.Length})");
        Console.WriteLine($"模式: \"{worstPattern}\" (长度{worstPattern.Length})");
        bf.SearchWithTrace(worstText, worstPattern);
    }
}

9. 复杂度分析

情况时间复杂度说明
最好O(n)第一个字符就不匹配，快速滑过
平均O(n+m)自然语言文本中通常很快失配
最差O(n*m)如 T="AAAAAB" P="AAAB"
空间O(1)只需要几个指针变量

最差情况：文本串和模式串高度重复时（如全是A），每次都要比较到模式串末尾才失配

10. 易错点

  1. 外层循环边界：i 只需到 n-m（不是n-1），超过就不可能匹配了
  2. 指针回退：单指针写法中 i = i - j + 1 容易写错
  3. 空串处理：模式串为空时应返回0（约定）
  4. 重叠匹配：找所有位置时，找到一个后i只加1（不是加m），允许重叠
  5. 与KMP的区别：朴素算法文本串指针会回退，KMP不会

11. 对比表

对比维度朴素匹配KMPRabin-Karp

12. 前置知识与延伸

前置知识

  • 字符串基本操作
  • 双重循环
  • 指针/索引概念

延伸学习

  • KMP算法 → 利用已匹配信息避免回退
  • Boyer-Moore → 从后向前比较，跳过更多字符
  • Rabin-Karp → 滚动哈希快速比较
  • Sunday算法 → 简单高效的实用算法

为什么朴素算法慢？

关键问题：冗余比较

T: A B A B D ...
P: A B A B C     ← 比较4个字符后失配

朴素: 回到位置1重新比较
但实际上：我们已经知道 T[2..3] = "AB" = P[0..1]
所以可以直接从位置2开始，P从位置2继续比较！

这就是KMP的核心思想：利用已匹配的前缀信息

13. 记忆口诀

朴素匹配最暴力，逐位滑动逐字比。
匹配失败回原点，下一位置从头起。
最差情况n乘m，高度重复最惨淡。
简单好写是优点，长文本里效率低。
想要优化学KMP，不回退来是关键。

14. 面试常问点

  1. 朴素匹配的时间复杂度？ → 最差O(n*m)，平均O(n)
  2. 为什么朴素匹配效率低？ → 文本串指针回退，浪费已匹配信息
  3. 手写朴素字符串匹配 → 双层循环，注意边界i<=n-m
  4. 与C# string.IndexOf的关系？ → .NET内部使用优化算法
  5. 什么时候朴素匹配也够用？ → 文本短、字符集大、实际失配快
  6. 如何从朴素改进到KMP？ → 预处理模式串，避免指针回退
