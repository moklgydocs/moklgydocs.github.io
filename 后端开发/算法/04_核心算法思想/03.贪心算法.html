贪心算法

Moklgy2026/4/19大约 10 分钟算法CSharp核心算法思想

一、算法定位

维度说明
所属分类核心算法思想 / 贪心策略
解决的问题在每一步都做出当前最优选择，期望最终达到全局最优
典型场景活动选择、找零问题、Huffman 编码、最小生成树（Kruskal/Prim）、Dijkstra 最短路

二、一句话理解

贪心算法就是"目光短浅但运气好"——每一步只选当前看起来最好的，最终却能得到全局最优解。

三、生活化比喻

用最少的硬币找零：

假设你要找零 41 分，有 25 分、10 分、5 分、1 分的硬币。你的策略是：每次尽量用最大面额的硬币。

41 分 → 先拿 25 分（剩 16 分）
16 分 → 再拿 10 分（剩 6 分）
 6 分 → 再拿  5 分（剩 1 分）
 1 分 → 再拿  1 分（剩 0 分）

结果：25 + 10 + 5 + 1 = 41 分，共 4 枚硬币 ✓（确实是最少的）

注意：贪心不是万能的！如果硬币面额是 [1, 3, 4]，找零 6 分，贪心会选 4+1+1=3枚，但最优解是 3+3=2枚。

四、核心思想

4.1 贪心的核心特征

特征说明
贪心选择性质每步的局部最优选择能够导出全局最优解
最优子结构问题的最优解包含子问题的最优解
不可回退一旦做出选择就不再改变，不像回溯法会撤销
高效通常 O(n) 或 O(n log n)，比动态规划快

4.2 贪心 vs 暴力 vs 动态规划

暴力：尝试所有可能 → 一定能找到最优解 → 太慢
动态规划：记录所有子问题的解 → 保证最优 → 较快
贪心：只看当前最优 → 不一定最优 → 最快

关键问题：怎么判断贪心策略能得到全局最优？
答案：需要证明（或凭经验判断）问题具有"贪心选择性质"

4.3 贪心正确性证明方法

  1. 交换论证法：假设最优解和贪心解不同，通过交换证明贪心解不会更差
  2. 归纳法：证明每一步贪心选择后，剩余子问题仍可用贪心求解
  3. 反证法：假设贪心解不是最优的，推导出矛盾

六、执行步骤

贪心算法通用步骤

  1. 确定贪心策略：明确在每一步如何做"最优"选择
  2. 排序或预处理：按照贪心策略需要的顺序排列数据
  3. 逐步选择：遍历数据，每步做出贪心选择
  4. 判断可行性：检查当前选择是否满足约束条件
  5. 记录结果：将可行的选择加入结果集
  6. 验证正确性：（重要）证明或验证贪心策略能得到最优解

七、C# 实现

7.1 活动选择问题

using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    /// <summary>
    /// 活动选择问题：选出最多互不冲突的活动
    /// 贪心策略：按结束时间排序，优先选结束最早的
    /// </summary>
    static List<(int start, int end, string name)> ActivitySelection(
        List<(int start, int end, string name)> activities)
    {
        // 第1步：按结束时间升序排序
        var sorted = activities.OrderBy(a => a.end).ToList();

        // 第2步：贪心选择
        var selected = new List<(int start, int end, string name)>();
        int lastEnd = 0; // 上一个选中活动的结束时间

        foreach (var activity in sorted)
        {
            // 如果当前活动的开始时间 >= 上一个活动的结束时间，可以选
            if (activity.start >= lastEnd)
            {
                selected.Add(activity);
                lastEnd = activity.end; // 更新结束时间
            }
        }

        return selected;
    }

    static void Main()
    {
        var activities = new List<(int start, int end, string name)>
        {
            (1, 4, "A"), (3, 5, "B"), (0, 6, "C"),
            (5, 7, "D"), (3, 9, "E"), (5, 9, "F"),
            (6, 10, "G"), (8, 11, "H"), (8, 12, "I"), (2, 14, "J")
        };

        var result = ActivitySelection(activities);

        Console.WriteLine("选中的活动：");
        foreach (var a in result)
        {
            Console.WriteLine($"  活动 {a.name}: [{a.start}, {a.end})");
        }
        Console.WriteLine($"最多可选 {result.Count} 个活动");
        // 输出：
        // 活动 A: [1, 4)
        // 活动 D: [5, 7)
        // 活动 H: [8, 11)
        // 最多可选 3 个活动
    }
}

7.2 分数背包问题（贪心可行）

using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    /// <summary>
    /// 分数背包问题：物品可以分割取一部分
    /// 贪心策略：优先选性价比（价值/重量）最高的物品
    /// 注意：0/1 背包不能用贪心，必须用动态规划
    /// </summary>
    static double FractionalKnapsack(int capacity, List<(int weight, int value, string name)> items)
    {
        // 第1步：按性价比（价值/重量）降序排序
        var sorted = items
            .Select(item => new
            {
                item.weight,
                item.value,
                item.name,
                ratio = (double)item.value / item.weight // 性价比
            })
            .OrderByDescending(x => x.ratio)
            .ToList();

        double totalValue = 0;    // 总价值
        int remainCapacity = capacity; // 剩余容量

        Console.WriteLine("贪心选择过程：");
        Console.WriteLine($"{"物品",-6} {"重量",-6} {"价值",-6} {"性价比",-8} {"取量",-6}");

        foreach (var item in sorted)
        {
            if (remainCapacity <= 0) break;

            if (item.weight <= remainCapacity)
            {
                // 整个物品都能放进去
                totalValue += item.value;
                remainCapacity -= item.weight;
                Console.WriteLine($"{item.name,-6} {item.weight,-6} {item.value,-6} {item.ratio,-8:F2} {"全部",-6}");
            }
            else
            {
                // 只能放一部分
                double fraction = (double)remainCapacity / item.weight;
                totalValue += item.value * fraction;
                Console.WriteLine($"{item.name,-6} {item.weight,-6} {item.value,-6} {item.ratio,-8:F2} {fraction:P0}");
                remainCapacity = 0;
            }
        }

        return totalValue;
    }

    static void Main()
    {
        var items = new List<(int weight, int value, string name)>
        {
            (10, 60, "物品A"),   // 性价比 6.0
            (20, 100, "物品B"),  // 性价比 5.0
            (30, 120, "物品C"),  // 性价比 4.0
        };

        int capacity = 50;
        double maxValue = FractionalKnapsack(capacity, items);
        Console.WriteLine($"\n背包容量：{capacity}，最大价值：{maxValue}");
        // 输出：最大价值：240
        // 物品A 全部(10) + 物品B 全部(20) + 物品C 的 2/3(20)
        // = 60 + 100 + 80 = 240
    }
}

7.3 Huffman 编码（贪心构建最优前缀码）

using System;
using System.Collections.Generic;

class Program
{
    /// <summary>
    /// Huffman 树节点
    /// </summary>
    class HuffmanNode : IComparable<HuffmanNode>
    {
        public char Character { get; set; }  // 字符（叶子节点才有）
        public int Frequency { get; set; }   // 频率
        public HuffmanNode Left { get; set; }
        public HuffmanNode Right { get; set; }

        // 比较器：按频率升序排列
        public int CompareTo(HuffmanNode other)
        {
            return Frequency.CompareTo(other.Frequency);
        }
    }

    /// <summary>
    /// 构建 Huffman 树
    /// 贪心策略：每次选频率最低的两个节点合并
    /// </summary>
    static HuffmanNode BuildHuffmanTree(Dictionary<char, int> frequencies)
    {
        // 用排序列表模拟优先队列（小根堆）
        var pq = new SortedSet<(int freq, int id, HuffmanNode node)>();
        int id = 0;

        // 初始化：每个字符作为一个叶子节点
        foreach (var kvp in frequencies)
        {
            var node = new HuffmanNode { Character = kvp.Key, Frequency = kvp.Value };
            pq.Add((kvp.Value, id++, node));
        }

        // 贪心：每次取频率最小的两个节点合并
        while (pq.Count > 1)
        {
            // 取出频率最小的两个节点
            var min1 = pq.Min; pq.Remove(min1);
            var min2 = pq.Min; pq.Remove(min2);

            // 合并为新节点
            var merged = new HuffmanNode
            {
                Character = '\0', // 内部节点无字符
                Frequency = min1.freq + min2.freq,
                Left = min1.node,
                Right = min2.node
            };

            pq.Add((merged.Frequency, id++, merged));
        }

        return pq.Min.node;
    }

    /// <summary>
    /// 递归生成 Huffman 编码
    /// 左走加 '0'，右走加 '1'
    /// </summary>
    static void GenerateCodes(HuffmanNode root, string code, Dictionary<char, string> codes)
    {
        if (root == null) return;

        // 叶子节点：记录编码
        if (root.Left == null && root.Right == null)
        {
            codes[root.Character] = code.Length > 0 ? code : "0";
            return;
        }

        GenerateCodes(root.Left, code + "0", codes);
        GenerateCodes(root.Right, code + "1", codes);
    }

    static void Main()
    {
        // 统计字符频率
        var frequencies = new Dictionary<char, int>
        {
            { 'a', 5 }, { 'b', 9 }, { 'c', 12 },
            { 'd', 13 }, { 'e', 16 }, { 'f', 45 }
        };

        Console.WriteLine("字符频率：");
        foreach (var kvp in frequencies)
            Console.WriteLine($"  '{kvp.Key}': {kvp.Value}");

        // 构建 Huffman 树
        var root = BuildHuffmanTree(frequencies);

        // 生成编码
        var codes = new Dictionary<char, string>();
        GenerateCodes(root, "", codes);

        Console.WriteLine("\nHuffman 编码：");
        foreach (var kvp in codes)
            Console.WriteLine($"  '{kvp.Key}': {kvp.Value}");

        // 计算加权路径长度
        int totalBits = 0;
        foreach (var kvp in codes)
            totalBits += frequencies[kvp.Key] * kvp.Value.Length;
        Console.WriteLine($"\n总编码位数：{totalBits}");
        // 高频字符编码短，低频字符编码长 → 总编码最短
    }
}

八、示例演示

手动推演找零问题

面额 [25, 10, 5, 1]，找零 63 分：

步骤1：63 ÷ 25 = 2 余 13  → 取 2 个 25分硬币
步骤2：13 ÷ 10 = 1 余  3  → 取 1 个 10分硬币
步骤3： 3 ÷  5 = 0 余  3  → 取 0 个  5分硬币
步骤4： 3 ÷  1 = 3 余  0  → 取 3 个  1分硬币

结果：25×2 + 10×1 + 1×3 = 63，共 6 枚硬币 ✓

贪心失败的反例

面额 [1, 3, 4]，找零 6：

贪心：6 → 取4（剩2）→ 取1（剩1）→ 取1（剩0）= 3枚 ✗
最优：6 → 取3（剩3）→ 取3（剩0）= 2枚 ✓

贪心失败！此时应该用动态规划。

十、易错点

易错点后果正确做法
未验证贪心策略的正确性得到非最优解先证明或用反例验证
把 0/1 背包当分数背包结果错误0/1 背包必须用动态规划
排序规则写反贪心方向错误明确是升序还是降序
忽略相等情况边界错误开始时间 = 上一个结束时间也算不冲突
贪心策略选错得到非最优解活动选择应按结束时间排，不是按持续时间

十二、前置知识与延伸学习

前置知识

  • 排序算法：贪心通常需要先排序
  • 优先队列（堆）：部分贪心算法需要高效取最值

延伸学习

  • 最小生成树：Kruskal（贪心选最短边）、Prim（贪心选最近点）
  • Dijkstra 最短路：贪心扩展最近的未访问节点
  • 区间调度问题：各种区间贪心变体
  • 拟阵理论：贪心正确性的数学基础

十三、记忆口诀

贪心算法口诀：
每步只看眼前利，
局部最优选到底。
不回头来不后悔，
前提是要能证明。

何时用贪心？
能排序、有策略、子问题独立，
局部最优 = 全局最优。

十四、面试常问点

  1. 什么是贪心算法？它有什么特点？

    • 每步选局部最优；贪心选择性质 + 最优子结构

  2. 贪心和动态规划的区别？

    • 贪心不考虑未来，DP 记录所有子问题；贪心更快但不一定适用

  3. 如何判断一个问题能否用贪心？

    • 证明贪心选择性质；或者先假设能用，再用反例验证

  4. 举一个贪心失败的例子

    • 面额 [1, 3, 4] 找零 6：贪心得到 3 枚，最优只需 2 枚

  5. 0/1 背包能用贪心吗？为什么？

    • 不能。因为物品不可分割，按性价比贪心可能浪费背包空间
