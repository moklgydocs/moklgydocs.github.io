位运算

一、算法定位

维度说明
所属分类核心算法思想 / 底层优化技巧
解决的问题直接操作二进制位，实现极致高效的计算和状态压缩
典型场景判断奇偶、交换变量、找唯一数、权限系统、状态压缩DP

二、一句话理解

位运算就是直接操作数字的二进制表示——比加减乘除快，比数组省空间，是计算机语言中最接近底层的"魔法"。

三、生活化比喻

开关面板（位掩码）：

房间里有8个开关，每个控制一盏灯。用一个字节（8位）就能表示所有灯的状态：1=开，0=关。要开第3盏灯？对第3位做 OR 操作。要关掉第5盏灯？对第5位做 AND NOT 操作。比存8个布尔变量高效多了！

灯的状态：  0 1 0 1 1 0 0 1
位编号：    7 6 5 4 3 2 1 0

第4盏灯（位3）是开着的（=1）

四、核心思想

4.1 六大基本位运算

运算符名称规则C#示例
&按位与两者都1才1a & b5 & 3 = 1（101 & 011 = 001）
|按位或有一个1就1a | b5 | 3 = 7（101 | 011 = 111）
^按位异或不同为1，相同为0a ^ b5 ^ 3 = 6（101 ^ 011 = 110）
~按位取反0变1，1变0~a~5 = -6（补码）
<<左移高位丢弃，低位补0a << n5 << 1 = 10（乘2）
>>右移低位丢弃，高位补符号位a >> n5 >> 1 = 2（除2取整）

4.2 常用技巧速查

技巧写法含义
判断奇偶n & 1结果为1奇数，0偶数
乘以2^kn << k比 * 快
除以2^kn >> k向下取整
取最低位1n & (-n)只保留最低位的1
消去最低位1n & (n-1)将最低位的1变为0
判断是否2的幂n > 0 && (n & (n-1)) == 02的幂只有一个1
交换两数a^=b; b^=a; a^=b无需临时变量
取第k位(n >> k) & 1获取第k位的值
将第k位置1n | (1 << k)设置第k位为1
将第k位清0n & ~(1 << k)清除第k位

五、图解推演

5.1 基本运算图解

a = 5 = 0101
b = 3 = 0011

a & b:  0101
        0011
        ----
        0001 = 1

a | b:  0101
        0011
        ----
        0111 = 7

a ^ b:  0101
        0011
        ----
        0110 = 6

~a:     0101 → 取反 → 1010 1010（补码）= -6

5.2 n & (n-1) 消去最低位1

n = 12 = 1100
n - 1  = 1011
n & (n-1) = 1000  ← 最低位的 1 被消去了！

应用：统计二进制中1的个数
  12 = 1100 → & 11 → 1000  （1次）
  8  = 1000 → & 7  → 0000  （2次）
  0  结束，count = 2

5.3 异或的"自我消除"特性

a ^ a = 0  （相同的数异或为0）
a ^ 0 = a  （与0异或不变）
a ^ b ^ a = b  （a被消除！）

应用：找数组中唯一出现奇数次的数
  [2, 3, 2, 1, 3] → 2^3^2^1^3 = 0^0^1 = 1
                                ↑   ↑
                             2出现2次消掉  3出现2次消掉  剩下1

六、执行步骤

以"找数组中只出现一次的数"为例：

  1. 初始化 result = 0
  2. 遍历数组，result ^= nums[i]
  3. 出现两次的数会被异或消掉（a ^ a = 0）
  4. 只出现一次的数最终留在 result 中

七、C# 实现

7.1 基础位运算演示

using System;

class BitBasics
{
    static void Main()
    {
        int a = 5, b = 3;

        Console.WriteLine($"a={a} (二进制:{Convert.ToString(a, 2)})");
        Console.WriteLine($"b={b} (二进制:{Convert.ToString(b, 2)})");
        Console.WriteLine($"a & b = {a & b}");  // 1
        Console.WriteLine($"a | b = {a | b}");  // 7
        Console.WriteLine($"a ^ b = {a ^ b}");  // 6
        Console.WriteLine($"~a = {~a}");         // -6
        Console.WriteLine($"a << 1 = {a << 1}"); // 10 (a*2)
        Console.WriteLine($"a >> 1 = {a >> 1}"); // 2  (a/2)

        // 判断奇偶
        Console.WriteLine($"\n{a} 是{((a & 1) == 1 ? "奇" : "偶")}数");

        // 判断是否2的幂
        int n = 16;
        Console.WriteLine($"{n} 是否2的幂：{(n > 0 && (n & (n - 1)) == 0)}");

        // 无临时变量交换
        int x = 10, y = 20;
        x ^= y; y ^= x; x ^= y;
        Console.WriteLine($"\n交换后：x={x}, y={y}"); // x=20, y=10
    }
}

7.2 找只出现一次的数

using System;

class SingleNumber
{
    /// <summary>
    /// 数组中除了一个数出现一次，其余所有数出现两次，找出那个数
    /// 原理：a ^ a = 0，a ^ 0 = a
    /// 出现两次的数异或后消为0，只出现一次的数保留下来
    /// 时间 O(n)，空间 O(1)
    /// </summary>
    static int FindSingle(int[] nums)
    {
        int result = 0;
        foreach (int n in nums)
            result ^= n; // 出现两次的数互相抵消
        return result;   // 剩下的就是只出现一次的数
    }

    static void Main()
    {
        Console.WriteLine(FindSingle(new int[] { 2, 3, 2, 1, 3 })); // 输出 1
        Console.WriteLine(FindSingle(new int[] { 4, 1, 2, 1, 2 })); // 输出 4
    }
}

7.3 统计二进制中1的个数（汉明重量）

using System;

class HammingWeight
{
    /// <summary>
    /// 方法一：n & (n-1) 每次消去最低位的1
    /// </summary>
    static int CountBits_v1(int n)
    {
        int count = 0;
        while (n != 0)
        {
            n &= (n - 1); // 消去最低位的1
            count++;
        }
        return count;
    }

    /// <summary>
    /// 方法二：逐位检查（慢但直观）
    /// </summary>
    static int CountBits_v2(int n)
    {
        int count = 0;
        while (n != 0)
        {
            count += n & 1; // 取最低位
            n >>= 1;        // 右移一位
        }
        return count;
    }

    static void Main()
    {
        Console.WriteLine(CountBits_v1(12)); // 12=1100，有2个1
        Console.WriteLine(CountBits_v1(255)); // 255=11111111，有8个1
    }
}

7.4 位掩码：用整数表示状态集合

using System;

class BitMask
{
    // 用一个 int 的各个位表示8种权限
    const int READ    = 1 << 0; // 0001 = 1
    const int WRITE   = 1 << 1; // 0010 = 2
    const int EXECUTE = 1 << 2; // 0100 = 4
    const int DELETE  = 1 << 3; // 1000 = 8

    static void Main()
    {
        int userPermission = 0; // 初始无权限

        // 授予读写权限
        userPermission |= READ;   // 设置 READ 位为1
        userPermission |= WRITE;  // 设置 WRITE 位为1
        Console.WriteLine($"权限值：{userPermission}"); // 3 (0011)

        // 检查是否有读权限
        bool canRead = (userPermission & READ) != 0;
        Console.WriteLine($"可以读：{canRead}"); // True

        // 检查是否有执行权限
        bool canExecute = (userPermission & EXECUTE) != 0;
        Console.WriteLine($"可以执行：{canExecute}"); // False

        // 撤销写权限
        userPermission &= ~WRITE; // 将 WRITE 位清0
        Console.WriteLine($"撤销写权限后：{userPermission}"); // 1 (0001)

        // 切换删除权限
        userPermission ^= DELETE; // XOR：有就删，没有就加
        Console.WriteLine($"切换删除权限后：{userPermission}"); // 9 (1001)
    }
}

7.5 快速幂（位运算加速）

using System;

class FastPower
{
    /// <summary>
    /// 快速幂：用二进制分解指数，避免循环 n 次
    /// base^13 = base^(1101₂) = base^8 × base^4 × base^1
    /// 时间复杂度：O(log n)
    /// </summary>
    static long Power(long baseNum, int exp, long mod)
    {
        long result = 1;
        baseNum %= mod;

        while (exp > 0)
        {
            if ((exp & 1) == 1)    // 当前位为1，乘进结果
                result = result * baseNum % mod;

            baseNum = baseNum * baseNum % mod; // 底数平方
            exp >>= 1;             // 指数右移，处理下一位
        }

        return result;
    }

    static void Main()
    {
        Console.WriteLine(Power(2, 10, 1000000007)); // 2^10 = 1024
        Console.WriteLine(Power(3, 13, 1000000007)); // 3^13 = 1594323
    }
}

八、示例演示

手动推演：Power(2, 13, MOD)

exp = 13 = 1101₂

循环过程：
exp=13(1101), exp&1=1 → result *= base=2, result=2; base=4; exp>>1=6
exp= 6(0110), exp&1=0 → 不乘; base=16; exp>>1=3
exp= 3( 011), exp&1=1 → result *= base=16, result=32; base=256; exp>>1=1
exp= 1(  01), exp&1=1 → result *= base=256, result=8192; base=...; exp>>1=0
exp= 0，结束

2^13 = 8192 ✓（2^1 × 2^4 × 2^8 = 2 × 16 × 256 = 8192）

九、复杂度分析

操作时间复杂度备注
所有基础位运算O(1)单次操作
统计1的个数O(k)，k为1的个数n & (n-1) 每次减少一个1
快速幂O(log n)比普通循环 O(n) 快
状态压缩DP枚举O(2^n)n 个元素的所有子集

十、易错点

易错点后果正确做法
运算符优先级a & b == c 实为 a & (b==c)多加括号：(a & b) == c
负数右移（>>）高位补符号位（算术右移）无符号右移用 >>> 或转为 uint
取反 ~n 与 -n 混淆~n = -n-1（补码）~5 = -6，不是 -5
无临时变量交换同一变量a ^= a 结果为0确保 a != b 时才用异或交换
位掩码位数超过 int 范围溢出超过32位用 long 或 1L << k

前置知识

  • 二进制：整数的二进制表示

延伸学习

  • 格雷码：相邻数只有一位不同的编码方式

十三、记忆口诀

AND(&) 清零，OR(|) 置1，XOR(^) 取反切换；
左移乘2，右移除2，n&1判奇偶；
n&(n-1)消最低1，n&(-n)取最低1；
异或自消找单数，位掩码管权限集合。

十四、面试常问点

  1. 如何不用临时变量交换两个整数？

    • a^=b; b^=a; a^=b;

  2. 如何判断一个数是否是2的幂？

    • n > 0 && (n & (n-1)) == 0

  3. n & (n-1) 有什么用？

    • 消去 n 的最低位1，可以统计二进制中1的个数

  4. 异或的特殊性质？

    • a ^ a = 0（自我消除），a ^ 0 = a（与0不变）

  5. 位运算在权限系统中如何应用？

    • 每个权限占一位，OR 授权，AND NOT 撤权，AND 检查
