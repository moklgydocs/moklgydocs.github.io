滑动窗口

Moklgy2026/4/20大约 8 分钟算法CSharp核心算法思想滑动窗口双指针

一、算法定位

维度说明
所属分类核心算法思想 / 线性扫描技巧
解决的问题在数组/字符串中寻找满足条件的连续子数组/子串
典型场景最长无重复子串、最小覆盖子串、定长窗口最大和、含K个不同字符的最长子串

二、一句话理解

滑动窗口就是用一个可伸缩的"框"在数组上从左向右滑动——框住满足条件的连续区间，右边扩展探索新元素，左边收缩排除不满足条件的元素。

三、生活化比喻

火车车厢窗口：

火车行驶时，你从窗口向外看，窗框框住了一段风景。窗口向前移动（右指针扩张），新的风景进入视野；当视野中某样东西不符合要求时，就从左边收缩窗口（左指针前移）。

数组：[a, b, c, d, e, f, g]
       ↑左                ↑右
       └──────窗口─────────┘
       
右扩：新元素进窗口
左缩：不满足条件时，移除左端元素

四、核心思想

4.1 固定窗口 vs 可变窗口

类型说明典型题
固定大小窗口大小 k 不变，整体右移定长子数组最大和
可变大小根据条件动态扩展/收缩最长无重复子串、最小覆盖子串

4.2 滑动窗口模板

int left = 0;
for (int right = 0; right < n; right++) {
    // 1. 将 nums[right] 加入窗口
    window.Add(nums[right]);
    
    // 2. 当窗口不满足条件时，收缩左边
    while (窗口不满足条件) {
        window.Remove(nums[left]);
        left++;
    }
    
    // 3. 此时窗口满足条件，更新答案
    ans = Math.Max(ans, right - left + 1);
}

4.3 为什么比暴力快？

暴力：枚举所有起点，内层循环枚举长度 → O(n²)
滑动窗口：left 和 right 都只向右移动，合计最多移动 2n 次 → O(n)

五、图解推演

5.1 最长无重复子串

字符串："a b c a b c b b"
下标：   0 1 2 3 4 5 6 7

right=0: 窗口=[a], 无重复, 长度=1
right=1: 窗口=[a,b], 无重复, 长度=2
right=2: 窗口=[a,b,c], 无重复, 长度=3  ← 最长3
right=3: 窗口=[a,b,c,a], 有重复'a'!
  收缩：移除left=0的'a', left→1
  窗口=[b,c,a], 无重复, 长度=3
right=4: 窗口=[b,c,a,b], 有重复'b'!
  收缩：移除left=1的'b', left→2
  窗口=[c,a,b], 无重复, 长度=3
...

最终答案：3（子串 "abc"）

5.2 固定窗口大小（k=3）求最大和

数组：[2, 1, 5, 1, 3, 2]，k=3

初始窗口：[2,1,5]，和=8
滑动一步：移出2，加入1 → [1,5,1]，和=7
滑动一步：移出1，加入3 → [5,1,3]，和=9  ← 最大
滑动一步：移出5，加入2 → [1,3,2]，和=6

最大和 = 9

六、执行步骤

可变窗口（通用）：

  1. 初始化 left = 0，窗口状态（哈希表/计数器）
  2. right 从 0 遍历到 n-1：
    • 将 arr[right] 加入窗口，更新状态
    • 当窗口不满足约束时，循环收缩左边：
      • 从窗口移除 arr[left]，更新状态
      • left++
    • 此时窗口满足约束，更新最优解

七、C# 实现

7.1 最长无重复子串

using System;
using System.Collections.Generic;

class LongestSubstring
{
    /// <summary>
    /// 找最长的不含重复字符的子串
    /// 用哈希表记录窗口内每个字符最后出现的位置
    /// </summary>
    static int LengthOfLongestSubstring(string s)
    {
        // 记录每个字符最近一次出现的下标
        Dictionary<char, int> lastIndex = new Dictionary<char, int>();

        int maxLength = 0;
        int left = 0; // 窗口左边界

        for (int right = 0; right < s.Length; right++)
        {
            char c = s[right];

            // 如果字符 c 在窗口内已出现（且在 left 右边），收缩左边界
            if (lastIndex.ContainsKey(c) && lastIndex[c] >= left)
                left = lastIndex[c] + 1; // 左边界跳到重复字符的下一位

            lastIndex[c] = right; // 更新字符最新位置

            // 当前窗口 [left, right] 无重复，更新最大长度
            maxLength = Math.Max(maxLength, right - left + 1);
        }

        return maxLength;
    }

    static void Main()
    {
        Console.WriteLine(LengthOfLongestSubstring("abcabcbb")); // 3 ("abc")
        Console.WriteLine(LengthOfLongestSubstring("bbbbb"));    // 1 ("b")
        Console.WriteLine(LengthOfLongestSubstring("pwwkew"));   // 3 ("wke")
    }
}

7.2 定长窗口最大和

using System;

class MaxSumSubarray
{
    /// <summary>
    /// 大小为 k 的连续子数组的最大和
    /// 维护一个大小固定为 k 的窗口，整体右移
    /// </summary>
    static int MaxSumOfSizeK(int[] nums, int k)
    {
        int n = nums.Length;
        if (n < k) return -1;

        // 计算第一个窗口的和
        int windowSum = 0;
        for (int i = 0; i < k; i++)
            windowSum += nums[i];

        int maxSum = windowSum;

        // 滑动窗口：每次加入右侧元素，移除左侧元素
        for (int right = k; right < n; right++)
        {
            windowSum += nums[right];       // 加入右侧新元素
            windowSum -= nums[right - k];   // 移除左侧旧元素
            maxSum = Math.Max(maxSum, windowSum);
        }

        return maxSum;
    }

    static void Main()
    {
        int[] nums = { 2, 1, 5, 1, 3, 2 };
        Console.WriteLine($"k=3 时最大和：{MaxSumOfSizeK(nums, 3)}"); // 9
    }
}

7.3 最小覆盖子串

using System;
using System.Collections.Generic;

class MinWindow
{
    /// <summary>
    /// 最小覆盖子串：在 s 中找包含 t 所有字符的最短子串
    /// 用两个哈希表：need（t中各字符需要的数量）、window（当前窗口内各字符数量）
    /// </summary>
    static string MinWindowSubstring(string s, string t)
    {
        // need：目标字符串 t 中每个字符需要的数量
        Dictionary<char, int> need = new Dictionary<char, int>();
        foreach (char c in t)
            need[c] = need.ContainsKey(c) ? need[c] + 1 : 1;

        // window：当前窗口内每个字符的数量
        Dictionary<char, int> window = new Dictionary<char, int>();

        int left = 0;
        int valid = 0;          // 已满足条件的字符种类数
        int start = 0;          // 最小覆盖子串的起始下标
        int minLen = int.MaxValue; // 最小覆盖子串的长度

        for (int right = 0; right < s.Length; right++)
        {
            char c = s[right];

            // 将右侧字符加入窗口
            if (need.ContainsKey(c))
            {
                window[c] = window.ContainsKey(c) ? window[c] + 1 : 1;
                // 该字符的数量刚好满足 need，valid++
                if (window[c] == need[c]) valid++;
            }

            // 当所有字符都满足数量要求时，尝试收缩左边
            while (valid == need.Count)
            {
                // 更新最小覆盖子串
                if (right - left + 1 < minLen)
                {
                    minLen = right - left + 1;
                    start = left;
                }

                // 移除左侧字符
                char leftChar = s[left];
                left++;
                if (need.ContainsKey(leftChar))
                {
                    if (window[leftChar] == need[leftChar]) valid--; // 不再满足
                    window[leftChar]--;
                }
            }
        }

        return minLen == int.MaxValue ? "" : s.Substring(start, minLen);
    }

    static void Main()
    {
        Console.WriteLine(MinWindowSubstring("ADOBECODEBANC", "ABC")); // "BANC"
        Console.WriteLine(MinWindowSubstring("a", "a"));               // "a"
        Console.WriteLine(MinWindowSubstring("a", "aa"));              // ""
    }
}

九、复杂度分析

问题时间复杂度空间复杂度对比暴力
最长无重复子串O(n)O(字符集大小)暴力 O(n²)
定长最大和O(n)O(1)一样 O(n)
最小覆盖子串O(n + m)O(字符集)暴力 O(n²)

left 和 right 各自最多走 n 步，总共 2n 步，所以是 O(n)。

十、易错点

易错点后果正确做法
收缩条件写错（用 if 而非 while）窗口收缩不彻底收缩循环用 while
更新答案在收缩之前可能记录了不满足条件的窗口确认满足条件后再更新
最小覆盖子串：移除字符后忘记更新 valid计数错误先判断是否影响 valid，再减计数
固定窗口：忘记处理初始窗口漏掉前 k 个元素先单独计算第一个窗口

十三、记忆口诀

滑动窗口两指针，左缩右扩一方向；
右指针先往前走，加入元素更新状；
不满条件左收缩，满足条件记答案；
一趟扫完 O(n)，连续子数组全搞定。

十四、面试常问点

  1. 滑动窗口和双指针的区别？

    • 滑动窗口是同向双指针的特例，专注于连续子数组/子串问题

  2. 什么时候用固定窗口，什么时候用可变窗口？

    • 题目给定窗口大小 k → 固定；求满足条件的最长/最短 → 可变

  3. 收缩左边界的条件是什么？

    • 当窗口不满足约束时收缩（不同题目条件不同）

  4. 最小覆盖子串的核心思路？

    • 右扩直到覆盖所有字符，再左缩到极限，记录最小长度

  5. 滑动窗口时间复杂度为什么是 O(n)？

    • left、right 各自只向右移动，合计最多 2n 次操作
