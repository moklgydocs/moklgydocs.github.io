前缀和与差分

一、算法定位

维度说明
所属分类核心算法思想 / 预处理技巧
解决的问题区间求和 O(1) 查询；区间批量加减 O(1) 更新
典型场景区间和查询、子数组和、二维区间和、区间加法（差分）

二、一句话理解

前缀和是"提前做好加法，查询时直接相减"；差分是"记录变化量，最后一次性还原"——两者都是用预处理换取快速查询。

三、生活化比喻

前缀和 → 累计里程表：

长途驾车，里程表记录了从出发到当前的总里程。想知道从第3个加油站到第7个加油站跑了多少路？用里程表[7] - 里程表[2] 就行，不需要重新数。

差分 → 工资调整单：

HR 不直接记录每个人的工资，而是记录"涨了多少"或"降了多少"。最后统一结算，累加所有调整才得到最终工资。批量加薪时只需改两个数，而不是逐人修改。

四、核心思想

4.1 前缀和

原数组：  a[0]  a[1]  a[2]  a[3]  a[4]
前缀和：  p[0]  p[1]  p[2]  p[3]  p[4]  p[5]
           0   a[0] a[0]+a[1] ...

其中 p[i] = a[0] + a[1] + ... + a[i-1]

区间 [l, r] 的和 = p[r+1] - p[l]    → O(1) 查询

4.2 差分

原数组：   a[0]  a[1]  a[2]  a[3]  a[4]

差分数组： d[i] = a[i] - a[i-1]（d[0] = a[0]）

对区间 [l, r] 整体加 k：
    只需 d[l] += k，d[r+1] -= k
    
最后对 d 求前缀和，还原为操作后的 a

4.3 互为逆运算

操作前缀和差分
构建对原数组求前缀对原数组求差
用途O(1) 区间求和O(1) 区间修改
关系前缀和的原数组是差分数组差分数组的前缀和还原原数组

五、图解推演

5.1 一维前缀和

原数组 a：[3, 1, 4, 1, 5, 9, 2]
下标：     0  1  2  3  4  5  6

前缀和 p：[0, 3, 4, 8, 9, 14, 23, 25]
下标：     0  1  2  3  4   5   6   7
（p[0]=0, p[i] = p[i-1] + a[i-1]）

查询 a[2..4] 的和（即 4+1+5=10）：
  p[5] - p[2] = 14 - 4 = 10  ✓

查询 a[0..6] 的和：
  p[7] - p[0] = 25 - 0 = 25  ✓

5.2 差分数组区间修改

原数组 a：[1, 2, 3, 4, 5]
差分数组 d：[1, 1, 1, 1, 1]（d[i]=a[i]-a[i-1]，d[0]=a[0]）

操作：对 a[1..3] 全部加 10
    d[1] += 10 → d = [1, 11, 1, 1, 1]
    d[4] -= 10 → d = [1, 11, 1, 1, -9]

对 d 求前缀和还原：
    a'[0] = 1
    a'[1] = 1 + 11 = 12
    a'[2] = 1 + 11 + 1 = 13
    a'[3] = 1 + 11 + 1 + 1 = 14
    a'[4] = 1 + 11 + 1 + 1 - 9 = 5

结果：[1, 12, 13, 14, 5]  ✓（a[1..3] 各加了10）

5.3 二维前缀和

矩阵：
  1 2 3
  4 5 6
  7 8 9

前缀和矩阵 p（p[i][j] = 左上角 (0,0) 到 (i-1,j-1) 的矩形和）：
   0  0  0  0
   0  1  3  6
   0  5 12 21
   0 12 27 45

查询 (1,1) 到 (2,2) 的矩形和（即 5+6+8+9=28）：
  p[3][3] - p[1][3] - p[3][1] + p[1][1]
= 45 - 21 - 12 + 1 = 13... 

正确查询 (r1,c1)=(1,1) 到 (r2,c2)=(2,2)：
  p[r2+1][c2+1] - p[r1][c2+1] - p[r2+1][c1] + p[r1][c1]
= p[3][3] - p[1][3] - p[3][1] + p[1][1]
= 45 - 6 - 12 + 1 = 28  ✓

六、执行步骤

前缀和：

  1. 构建：p[0] = 0，p[i] = p[i-1] + a[i-1]
  2. 查询 [l, r]：p[r+1] - p[l]

差分：

  1. 构建：d[0] = a[0]，d[i] = a[i] - a[i-1]
  2. 区间 [l, r] 加 k：d[l] += k，if (r+1 < n) d[r+1] -= k
  3. 还原：对 d 求前缀和

七、C# 实现

7.1 一维前缀和

using System;

class PrefixSum
{
    private int[] prefix; // 前缀和数组，长度为 n+1

    /// <summary>
    /// 构建前缀和数组
    /// prefix[i] = nums[0] + nums[1] + ... + nums[i-1]
    /// prefix[0] = 0（哨兵，简化边界处理）
    /// </summary>
    public PrefixSum(int[] nums)
    {
        int n = nums.Length;
        prefix = new int[n + 1];
        prefix[0] = 0;

        // 逐步累加：prefix[i] 等于前 i 个元素之和
        for (int i = 0; i < n; i++)
            prefix[i + 1] = prefix[i] + nums[i];
    }

    /// <summary>
    /// O(1) 查询 [left, right] 区间和（闭区间）
    /// 公式：prefix[right+1] - prefix[left]
    /// </summary>
    public int RangeSum(int left, int right)
    {
        return prefix[right + 1] - prefix[left];
    }

    static void Main()
    {
        int[] nums = { 3, 1, 4, 1, 5, 9, 2 };
        var ps = new PrefixSum(nums);

        Console.WriteLine($"[0,2] 区间和：{ps.RangeSum(0, 2)}"); // 3+1+4=8
        Console.WriteLine($"[2,4] 区间和：{ps.RangeSum(2, 4)}"); // 4+1+5=10
        Console.WriteLine($"[0,6] 区间和：{ps.RangeSum(0, 6)}"); // 25
    }
}

7.2 差分数组（区间批量更新）

using System;

class DifferenceArray
{
    private int[] diff; // 差分数组
    private int n;

    /// <summary>
    /// 构建差分数组
    /// diff[i] = nums[i] - nums[i-1]，diff[0] = nums[0]
    /// </summary>
    public DifferenceArray(int[] nums)
    {
        n = nums.Length;
        diff = new int[n];
        diff[0] = nums[0];
        for (int i = 1; i < n; i++)
            diff[i] = nums[i] - nums[i - 1];
    }

    /// <summary>
    /// 对区间 [left, right] 的所有元素加 val
    /// O(1) 操作！只改两个位置
    /// </summary>
    public void RangeAdd(int left, int right, int val)
    {
        diff[left] += val;            // 从 left 开始加 val
        if (right + 1 < n)
            diff[right + 1] -= val;   // 从 right+1 开始取消 val 的影响
    }

    /// <summary>
    /// 将差分数组还原为修改后的原始数组
    /// 对 diff 求前缀和
    /// </summary>
    public int[] Restore()
    {
        int[] result = new int[n];
        result[0] = diff[0];
        for (int i = 1; i < n; i++)
            result[i] = result[i - 1] + diff[i];
        return result;
    }

    static void Main()
    {
        int[] nums = { 1, 2, 3, 4, 5 };
        var da = new DifferenceArray(nums);

        // 对 [1,3] 加 10
        da.RangeAdd(1, 3, 10);
        // 对 [0,2] 加 5
        da.RangeAdd(0, 2, 5);

        int[] result = da.Restore();
        Console.WriteLine("修改后：" + string.Join(", ", result));
        // [1+5, 2+10+5, 3+10+5, 4+10, 5] = [6, 17, 18, 14, 5]
    }
}

7.3 二维前缀和

using System;

class Matrix2DPrefixSum
{
    private int[,] prefix;

    /// <summary>
    /// 构建二维前缀和矩阵
    /// prefix[i][j] = 以 (0,0) 为左上角，(i-1,j-1) 为右下角的矩形元素和
    /// </summary>
    public Matrix2DPrefixSum(int[,] matrix)
    {
        int rows = matrix.GetLength(0);
        int cols = matrix.GetLength(1);
        prefix = new int[rows + 1, cols + 1];

        for (int i = 1; i <= rows; i++)
        {
            for (int j = 1; j <= cols; j++)
            {
                // 容斥原理：加上左和上的，减去重复计算的左上角
                prefix[i, j] = matrix[i - 1, j - 1]
                              + prefix[i - 1, j]
                              + prefix[i, j - 1]
                              - prefix[i - 1, j - 1];
            }
        }
    }

    /// <summary>
    /// O(1) 查询矩形区域 (r1,c1) 到 (r2,c2) 的元素和
    /// 同样用容斥原理
    /// </summary>
    public int RangeSum(int r1, int c1, int r2, int c2)
    {
        return prefix[r2 + 1, c2 + 1]
             - prefix[r1, c2 + 1]
             - prefix[r2 + 1, c1]
             + prefix[r1, c1];
    }

    static void Main()
    {
        int[,] matrix = {
            { 1, 2, 3 },
            { 4, 5, 6 },
            { 7, 8, 9 }
        };

        var ps = new Matrix2DPrefixSum(matrix);

        // 查询 (1,1) 到 (2,2) 的矩形和 = 5+6+8+9 = 28
        Console.WriteLine($"(1,1)到(2,2)的和：{ps.RangeSum(1, 1, 2, 2)}"); // 28

        // 查询 (0,0) 到 (1,1) 的矩形和 = 1+2+4+5 = 12
        Console.WriteLine($"(0,0)到(1,1)的和：{ps.RangeSum(0, 0, 1, 1)}"); // 12
    }
}

八、示例演示

子数组和为 k 的个数（前缀和 + 哈希表）

问题：找数组中和为 k 的连续子数组个数
输入：nums=[1,1,1]，k=2

前缀和：p[0]=0, p[1]=1, p[2]=2, p[3]=3

遍历前缀和，检查 p[j] - p[i] == k，即 p[i] == p[j] - k：
  j=1, p[j]=1, 需要 p[i]=1-2=-1，哈希中无 → 0个
  j=2, p[j]=2, 需要 p[i]=2-2=0，哈希中有1个(p[0]=0) → +1
  j=3, p[j]=3, 需要 p[i]=3-2=1，哈希中有1个(p[1]=1) → +1

总共 2 个子数组：[1,1](下标0-1) 和 [1,1](下标1-2)
static int SubarraySum(int[] nums, int k)
{
    // map 存储：前缀和 → 出现次数
    var map = new Dictionary<int, int>();
    map[0] = 1; // 空数组的前缀和为0，有1种

    int prefixSum = 0, count = 0;
    foreach (int num in nums)
    {
        prefixSum += num;
        // 找有多少个 i 使得 prefixSum - k == p[i]
        if (map.ContainsKey(prefixSum - k))
            count += map[prefixSum - k];
        // 记录当前前缀和
        map[prefixSum] = map.ContainsKey(prefixSum) ? map[prefixSum] + 1 : 1;
    }
    return count;
}

九、复杂度分析

操作朴素方法前缀和/差分
一维区间查询O(n)O(1)（预处理 O(n)）
一维区间修改O(n)O(1)（差分，还原 O(n)）
二维矩形查询O(n×m)O(1)（预处理 O(n×m)）

十、易错点

易错点后果正确做法
前缀和下标偏移搞混查询结果错误统一用 p[r+1]-p[l]，p 长度为 n+1
差分 r+1 越界数组越界异常判断 if (r+1 < n) 才写 d[r+1]
二维前缀和容斥写错多加或少加记住：加(i,j)+(i-1,j-1)，减(i-1,j)-(i,j-1)
差分还原后没有重新求前缀和结果未还原对差分数组求前缀和才是最终结果

十二、记忆口诀

前缀和：先预处理，查询相减一步到位；
差分法：记录变化，两点操作区间更新；
互为逆：前缀和的逆是差分，差分的前缀和还原数组。

十三、面试常问点

  1. 前缀和数组为什么要多一位（长度 n+1）？

    • 统一处理边界，p[0]=0 充当哨兵，避免 l=0 时的特判

  2. 差分数组区间 [l,r] 加 k，为什么是 d[l]+=k，d[r+1]-=k？

    • 对差分求前缀和还原时，d[l]+=k 使 l 及之后所有元素+k；d[r+1]-=k 抵消 r+1 之后的影响

  3. 如何用前缀和求子数组和为 k 的个数？

    • 哈希表记录前缀和出现次数，枚举右端点时查 prefixSum-k 的个数

  4. 二维前缀和的容斥公式是什么？

    • sum(r1,c1,r2,c2) = p[r2+1][c2+1] - p[r1][c2+1] - p[r2+1][c1] + p[r1][c1]
