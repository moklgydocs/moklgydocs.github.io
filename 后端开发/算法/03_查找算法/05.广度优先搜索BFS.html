广度优先搜索 BFS

Moklgy2026/4/20大约 10 分钟算法CSharp查找算法图算法BFS

一、算法定位

维度说明
所属分类查找算法 / 图与树的遍历
解决的问题按层次逐步向外扩展，寻找最短路径或层序遍历
典型场景最短路径、层序遍历、连通性判断、迷宫求最短路、好友推荐（社交网络）

二、一句话理解

BFS 就是"层层推进"，先访问离起点最近的所有节点，再访问次近的，像水波纹一样向外扩散。

三、生活化比喻

水波纹扩散：

往平静的水面扔一块石头，水波纹从落点开始，一圈一圈向外扩散——第一圈、第二圈、第三圈……BFS 就是这样工作的：从起点出发，先访问"距离为1"的所有节点，再访问"距离为2"的，以此类推。

起点 → 第1层邻居 → 第2层邻居 → 第3层邻居 → ...

        [起点]
       /   |   \
     [1]  [2]  [3]    ← 第1层（距离=1）
    /  \        |
  [4]  [5]     [6]    ← 第2层（距离=2）

关键优势：BFS 找到目标时，保证走的是最短路径（在无权图中）。

四、核心思想

4.1 为什么想到 BFS？

  • 需要找最短路径（跳数最少）
  • 需要按层次处理问题（层序遍历）
  • 需要探索所有"距离为 k"的节点

4.2 核心工具：队列（Queue）

BFS 用队列来维护"待访问节点"的顺序：

操作说明
入队（Enqueue）发现新节点，加入队列末尾
出队（Dequeue）取出队首节点处理
已访问标记防止重复访问同一节点

4.3 BFS vs DFS

对比BFS（广度优先）DFS（深度优先）
数据结构队列（FIFO）栈（LIFO）/ 递归
遍历顺序按层次向外扩展一条路走到底再回溯
最短路径保证（无权图）不保证
空间复杂度O(宽度)，宽图费内存O(深度)，深图费内存
适用场景最短路径、层序遍历拓扑排序、回溯、全路径

图结构：

BFS 遍历（从节点 1 开始）：

步骤 | 当前节点 | 队列状态         | 已访问

初始 |    -    | [1]             | {}
 1  |    1    | [2, 3]          | {1}
 2  |    2    | [3, 4, 5]       | {1,2}

 6  |    6    | []              | {1,2,3,4,5,6}

遍历顺序：1 → 2 → 3 → 4 → 5 → 6  （按层次！）

5.2 最短路径示意（迷宫）

迷宫（S=起点，E=终点，#=墙）：
S . . #
. # . .
. . . #
# . . E

BFS 扩展过程（数字表示步数）：
0 1 2 #
1 # 3 4
2 3 4 #
# 4 5 6   ← E 在步数6处被找到，最短路径=6步

六、执行步骤

  1. 初始化：将起始节点加入队列，标记为已访问
  2. 循环：当队列不为空时执行以下操作：
    • 取出队首节点（出队）
    • 处理该节点（访问/记录/判断是否为目标）
    • 遍历该节点的所有未访问邻居
    • 将未访问邻居入队并标记为已访问
  3. 结束：队列为空时遍历完成，或找到目标时提前结束

七、C# 实现

7.1 图的 BFS 遍历（邻接表）

using System;
using System.Collections.Generic;

class BFSGraph
{
    private int vertexCount;                    // 顶点数量
    private List<int>[] adjacencyList;          // 邻接表：每个顶点的邻居列表

    /// <summary>
    /// 初始化图
    /// </summary>
    public BFSGraph(int vertexCount)
    {
        this.vertexCount = vertexCount;
        adjacencyList = new List<int>[vertexCount];
        // 为每个顶点创建空的邻居列表
        for (int i = 0; i < vertexCount; i++)
            adjacencyList[i] = new List<int>();
    }

    /// <summary>
    /// 添加无向边
    /// </summary>
    public void AddEdge(int u, int v)
    {
        adjacencyList[u].Add(v);
        adjacencyList[v].Add(u); // 无向图两个方向都要添加
    }

    /// <summary>
    /// 广度优先搜索遍历
    /// 从 startVertex 出发，按层次遍历所有可达节点
    /// </summary>
    public void BFS(int startVertex)
    {
        // visited 数组：记录每个节点是否已被访问过
        bool[] visited = new bool[vertexCount];

        // 使用队列维护待处理节点（先进先出保证层次顺序）
        Queue<int> queue = new Queue<int>();

        // 第一步：将起始节点入队并标记为已访问
        visited[startVertex] = true;
        queue.Enqueue(startVertex);

        Console.Write("BFS 遍历顺序：");

        while (queue.Count > 0)
        {
            // 取出队首节点
            int current = queue.Dequeue();
            Console.Write($"{current} ");

            // 遍历当前节点的所有邻居
            foreach (int neighbor in adjacencyList[current])
            {
                // 只处理未访问过的邻居
                if (!visited[neighbor])
                {
                    visited[neighbor] = true;  // 入队时就标记，防止重复入队
                    queue.Enqueue(neighbor);
                }
            }
        }
        Console.WriteLine();
    }

    static void Main()
    {
        // 构建示例图：
        //   0 - 1 - 2
        //   |   |
        //   3 - 4
        BFSGraph g = new BFSGraph(5);
        g.AddEdge(0, 1);
        g.AddEdge(0, 3);
        g.AddEdge(1, 2);
        g.AddEdge(1, 4);
        g.AddEdge(3, 4);

        g.BFS(0); // 输出：0 1 3 2 4
    }
}

7.2 BFS 求最短路径（无权图）

using System;
using System.Collections.Generic;

class BFSShortestPath
{
    private int vertexCount;
    private List<int>[] adjacencyList;

    public BFSShortestPath(int vertexCount)
    {
        this.vertexCount = vertexCount;
        adjacencyList = new List<int>[vertexCount];
        for (int i = 0; i < vertexCount; i++)
            adjacencyList[i] = new List<int>();
    }

    public void AddEdge(int u, int v)
    {
        adjacencyList[u].Add(v);
        adjacencyList[v].Add(u);
    }

    /// <summary>
    /// BFS 求从 source 到所有节点的最短路径
    /// 无权图中，BFS 保证第一次到达某节点时就是最短路径
    /// </summary>
    public int[] ShortestPath(int source)
    {
        // distance[i] = 从 source 到节点 i 的最短步数
        // 初始化为 -1 表示未访问
        int[] distance = new int[vertexCount];
        Array.Fill(distance, -1);

        // prev[i] 记录路径：i 节点的前一个节点，用于还原路径
        int[] prev = new int[vertexCount];
        Array.Fill(prev, -1);

        Queue<int> queue = new Queue<int>();

        // 起点距离为 0
        distance[source] = 0;
        queue.Enqueue(source);

        while (queue.Count > 0)
        {
            int current = queue.Dequeue();

            foreach (int neighbor in adjacencyList[current])
            {
                if (distance[neighbor] == -1) // 未访问过
                {
                    // 最短距离 = 当前节点距离 + 1
                    distance[neighbor] = distance[current] + 1;
                    prev[neighbor] = current; // 记录路径
                    queue.Enqueue(neighbor);
                }
            }
        }

        return distance;
    }

    /// <summary>
    /// 还原从 source 到 target 的具体路径
    /// </summary>
    public List<int> GetPath(int source, int target)
    {
        int[] distance = new int[vertexCount];
        int[] prev = new int[vertexCount];
        Array.Fill(distance, -1);
        Array.Fill(prev, -1);

        Queue<int> queue = new Queue<int>();
        distance[source] = 0;
        queue.Enqueue(source);

        while (queue.Count > 0)
        {
            int current = queue.Dequeue();
            if (current == target) break; // 找到目标，提前结束

            foreach (int neighbor in adjacencyList[current])
            {
                if (distance[neighbor] == -1)
                {
                    distance[neighbor] = distance[current] + 1;
                    prev[neighbor] = current;
                    queue.Enqueue(neighbor);
                }
            }
        }

        // 通过 prev 数组反向还原路径
        List<int> path = new List<int>();
        if (distance[target] == -1) return path; // 不可达

        for (int node = target; node != -1; node = prev[node])
            path.Add(node);

        path.Reverse(); // 反转得到从 source 到 target 的正向路径
        return path;
    }

    static void Main()
    {
        BFSShortestPath g = new BFSShortestPath(6);
        g.AddEdge(0, 1); g.AddEdge(0, 2);
        g.AddEdge(1, 3); g.AddEdge(2, 3);
        g.AddEdge(3, 4); g.AddEdge(4, 5);

        int[] dist = g.ShortestPath(0);
        Console.WriteLine("从节点 0 到各节点的最短距离：");
        for (int i = 0; i < 6; i++)
            Console.WriteLine($"  到节点 {i}: {dist[i]} 步");

        var path = g.GetPath(0, 5);
        Console.WriteLine($"\n从 0 到 5 的最短路径：{string.Join(" → ", path)}");
        // 输出：0 → 1 → 3 → 4 → 5（或 0 → 2 → 3 → 4 → 5）
    }
}

7.3 二叉树层序遍历

using System;
using System.Collections.Generic;

class TreeNode
{
    public int Value;
    public TreeNode Left, Right;
    public TreeNode(int val) { Value = val; }
}

class BFSTree
{
    /// <summary>
    /// 二叉树层序遍历（BFS）
    /// 返回每一层的节点值列表
    /// </summary>
    public List<List<int>> LevelOrder(TreeNode root)
    {
        List<List<int>> result = new List<List<int>>();
        if (root == null) return result;

        Queue<TreeNode> queue = new Queue<TreeNode>();
        queue.Enqueue(root);

        while (queue.Count > 0)
        {
            int levelSize = queue.Count; // 当前层的节点数量
            List<int> currentLevel = new List<int>();

            // 处理当前层的所有节点
            for (int i = 0; i < levelSize; i++)
            {
                TreeNode node = queue.Dequeue();
                currentLevel.Add(node.Value);

                // 将下一层节点入队
                if (node.Left != null) queue.Enqueue(node.Left);
                if (node.Right != null) queue.Enqueue(node.Right);
            }

            result.Add(currentLevel);
        }

        return result;
    }

    static void Main()
    {
        // 构建树：      1
        //             / \
        //            2   3
        //           / \   \
        //          4   5   6
        TreeNode root = new TreeNode(1);
        root.Left = new TreeNode(2);
        root.Right = new TreeNode(3);
        root.Left.Left = new TreeNode(4);
        root.Left.Right = new TreeNode(5);
        root.Right.Right = new TreeNode(6);

        BFSTree bfs = new BFSTree();
        var levels = bfs.LevelOrder(root);

        Console.WriteLine("层序遍历结果：");
        for (int i = 0; i < levels.Count; i++)
            Console.WriteLine($"  第 {i + 1} 层：[{string.Join(", ", levels[i])}]");
        // 输出：
        // 第 1 层：[1]
        // 第 2 层：[2, 3]
        // 第 3 层：[4, 5, 6]
    }
}

手动推演：图中 BFS（5个节点）

图：0-1, 0-3, 1-2, 1-4, 3-4

从节点 0 开始 BFS：

时刻 | 操作           | 队列     | 已访问
-----|---------------|---------|--------
  0  | 初始化          | [0]     | {0}
  1  | 出队 0，入队邻居 1,3 | [1,3]   | {0,1,3}
  2  | 出队 1，入队邻居 2,4 | [3,2,4] | {0,1,3,2,4}

  4  | 出队 2，无新邻居   | [4]     | 不变
  5  | 出队 4，无新邻居   | []      | 不变

遍历顺序：0 → 1 → 3 → 2 → 4
距离：0→0步，1→1步，3→1步，2→2步，4→2步

九、复杂度分析

项目复杂度说明
时间复杂度O(V + E)V=顶点数，E=边数，每个节点和每条边各处理一次
空间复杂度O(V)队列最多存 V 个节点，visited 数组 O(V)
最短路径O(V + E)无权图最短路径
层序遍历（树）O(n)n 为节点总数

空间是 BFS 的软肋：对于"很宽"的图，队列可能同时存储大量节点。

十、易错点

易错点后果正确做法
入队时才标记 visited，出队后才标记同一节点被重复入队入队时就标记已访问
不处理不连通图部分节点遍历不到对所有未访问节点都启动一次 BFS
层序遍历时不记录层大小无法区分哪些节点在同一层每轮循环前记录 queue.Count 为当前层大小
有向图和无向图混淆边方向处理错误建图时明确方向，无向图两端都添加
最短路径还原时忘记 prev 数组只知道距离，不知道路径BFS 时同步维护 prev 数组

对比项BFSDFSDijkstra

十二、前置知识与延伸学习

前置知识

  • 队列（Queue）：BFS 的核心数据结构，先进先出
  • 图的表示：邻接表 / 邻接矩阵
  • DFS：与 BFS 相辅相成，对比理解更深

延伸学习

  • Dijkstra 最短路径：带权图的最短路径
  • 拓扑排序：BFS 的经典应用（Kahn 算法）
  • 0-1 BFS：边权只有 0 或 1 的特殊 BFS
  • 双向 BFS：从起点和终点同时出发，加速搜索

十三、记忆口诀

BFS 用队列，层层向外扩；
先进先出保顺序，入队即标记；
无权最短路，BFS 有保障；
宽度优先遍，水波纹荡漾。

十四、面试常问点

  1. BFS 和 DFS 的区别，各自适用什么场景？

    • BFS：队列、按层扩展、最短路径；DFS：栈/递归、深入探索、全路径搜索

  2. 为什么 BFS 能保证无权图的最短路径？

    • 因为按层次扩展，第一次到达某节点时经过的层数最少

  3. BFS 的时间复杂度？

    • O(V + E)，每个节点和每条边各处理一次

  4. 如何用 BFS 实现二叉树的层序遍历？

    • 用队列，每次处理一整层（记录入队时的队列大小）

  5. visited 标记应该在入队时设置还是出队时设置？为什么？

    • 入队时！出队时设置会导致同一节点被多次入队
