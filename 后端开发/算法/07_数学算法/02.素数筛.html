素数筛

1. 算法定位

素数筛是高效找出一定范围内所有素数的算法。埃拉托斯特尼筛法（Sieve of Eratosthenes）是经典方法，线性筛（欧拉筛）进一步优化到O(n)。是数论、密码学的基础工具。

2. 一句话理解

从2开始，把每个素数的所有倍数都标记为合数，剩下的未标记数就是素数。

3. 生活化比喻

想象操场上站着编号2到100的学生：

  • 2号站出来说"我是素数"，然后把所有2的倍数（4,6,8...）淘汰
  • 3号站出来说"我是素数"，然后把所有3的倍数（6,9,12...）淘汰
  • 4号已被淘汰，跳过
  • 5号站出来继续淘汰5的倍数...
  • 最终留下来的就是所有素数

4. 核心思想

埃氏筛（Sieve of Eratosthenes）

  • 从2开始遍历到sqrt(n)
  • 对每个素数p，标记 p², p²+p, p²+2p, ... 为合数
  • 从p²开始（更小的倍数已被之前的素数标记过）

线性筛（欧拉筛）

  • 保证每个合数只被其最小质因子筛掉一次
  • 严格O(n)时间
  • 同时可以求出每个数的最小质因子
方法时间复杂度空间特点
试除法O(n√n)O(1)逐个判断
埃氏筛O(n log log n)O(n)经典高效
线性筛O(n)O(n)最优，每个数只标记一次

线性筛与埃氏筛的区别

埃氏筛: 12被2筛一次(2×6), 被3筛一次(3×4) → 重复!
线性筛: 12只被其最小质因子2筛掉一次(2×6)

关键: 当 i % primes[j] == 0 时停止内层循环
原因: 如果继续，下一个 i * primes[j+1] 的最小质因子是primes[j]而非primes[j+1]
     这个合数应该由将来的 (i*primes[j+1]/primes[j]) * primes[j] 来筛

6. 执行步骤

埃氏筛步骤

  1. 创建布尔数组 isPrime[0..n]，初始化全部为true
  2. isPrime[0] = isPrime[1] = false
  3. 从 i = 2 开始遍历到 √n
  4. 如果 isPrime[i] 为 true（i是素数）
  5. 将 i², i²+i, i²+2i, ... 标记为 false
  6. 遍历完后，isPrime[k] = true 的 k 就是素数

线性筛步骤

  1. 维护素数列表 primes 和标记数组
  2. 遍历 i 从 2 到 n
  3. 如果 i 未标记，加入 primes
  4. 对每个已知素数 p（p ≤ n/i）：
    • 标记 i * p 为合数
    • 如果 i % p == 0，停止（关键！保证每个数只被最小质因子筛）

7. C# 实现

using System;
using System.Collections.Generic;

/// <summary>
/// 素数筛算法
/// </summary>
public class PrimeSieve
{
    /// <summary>
    /// 埃拉托斯特尼筛法
    /// 时间复杂度: O(n log log n)
    /// 空间复杂度: O(n)
    /// </summary>
    public List<int> SieveOfEratosthenes(int n)
    {
        // 创建标记数组，true表示可能是素数
        var isPrime = new bool[n + 1];
        Array.Fill(isPrime, true);
        isPrime[0] = false;
        isPrime[1] = false;

        // 从2开始筛选，只需遍历到√n
        for (int i = 2; (long)i * i <= n; i++)
        {
            if (isPrime[i])
            {
                // i是素数，将其所有倍数标记为合数
                // 从i²开始（更小的倍数已被更小的素数标记过）
                for (long j = (long)i * i; j <= n; j += i)
                {
                    isPrime[(int)j] = false;
                }
            }
        }

        // 收集所有素数
        var primes = new List<int>();
        for (int i = 2; i <= n; i++)
        {
            if (isPrime[i])
                primes.Add(i);
        }

        return primes;
    }

    /// <summary>
    /// 线性筛（欧拉筛）
    /// 每个合数只被其最小质因子筛掉一次
    /// 时间复杂度: 严格O(n)
    /// </summary>
    public List<int> LinearSieve(int n)
    {
        var isPrime = new bool[n + 1];
        Array.Fill(isPrime, true);
        isPrime[0] = false;
        isPrime[1] = false;

        var primes = new List<int>();        // 存储发现的素数
        var minFactor = new int[n + 1];      // 每个数的最小质因子

        for (int i = 2; i <= n; i++)
        {
            if (isPrime[i])
            {
                primes.Add(i);        // i是素数
                minFactor[i] = i;     // 素数的最小质因子是自身
            }

            // 用已知的素数来筛掉 i 的倍数
            foreach (int p in primes)
            {
                long product = (long)i * p;
                if (product > n) break;  // 超出范围

                isPrime[(int)product] = false;
                minFactor[(int)product] = p;  // 最小质因子是p

                // 关键：如果i能被p整除，停止
                // 保证每个合数只被最小质因子筛掉一次
                if (i % p == 0) break;
            }
        }

        return primes;
    }

    /// <summary>
    /// 判断单个数是否为素数（试除法）
    /// 时间复杂度: O(√n)
    /// </summary>
    public bool IsPrime(long n)
    {
        if (n <= 1) return false;
        if (n <= 3) return true;
        if (n % 2 == 0 || n % 3 == 0) return false;

        // 只需检查6k±1形式的因子
        for (long i = 5; i * i <= n; i += 6)
        {
            if (n % i == 0 || n % (i + 2) == 0)
                return false;
        }

        return true;
    }

    /// <summary>
    /// 分解质因数
    /// </summary>
    public List<(int factor, int count)> Factorize(int n)
    {
        var factors = new List<(int, int)>();

        for (int i = 2; (long)i * i <= n; i++)
        {
            if (n % i == 0)
            {
                int count = 0;
                while (n % i == 0)
                {
                    count++;
                    n /= i;
                }
                factors.Add((i, count));
            }
        }

        if (n > 1)
        {
            factors.Add((n, 1));  // 剩余的大于1的因子本身是素数
        }

        return factors;
    }

    /// <summary>
    /// 带过程展示的埃氏筛
    /// </summary>
    public void SieveWithTrace(int n)
    {
        var isPrime = new bool[n + 1];
        Array.Fill(isPrime, true);
        isPrime[0] = false;
        isPrime[1] = false;

        Console.WriteLine($"对 2 到 {n} 进行埃氏筛:");

        for (int i = 2; (long)i * i <= n; i++)
        {
            if (isPrime[i])
            {
                var eliminated = new List<int>();
                for (long j = (long)i * i; j <= n; j += i)
                {
                    if (isPrime[(int)j])
                    {
                        eliminated.Add((int)j);
                        isPrime[(int)j] = false;
                    }
                }
                if (eliminated.Count > 0)
                {
                    Console.WriteLine($"  素数{i}: 筛掉 {string.Join(", ", eliminated)}");
                }
            }
        }

        var primes = new List<int>();
        for (int i = 2; i <= n; i++)
            if (isPrime[i]) primes.Add(i);

        Console.WriteLine($"  结果: {string.Join(", ", primes)}");
        Console.WriteLine($"  共 {primes.Count} 个素数");
    }
}

/// <summary>
/// 测试程序
/// </summary>
public class Program
{
    public static void Main()
    {
        var sieve = new PrimeSieve();

        // 详细过程
        Console.WriteLine("=== 埃氏筛详细过程 (n=30) ===");
        sieve.SieveWithTrace(30);

        // 两种筛法对比
        Console.WriteLine("\n=== 埃氏筛 vs 线性筛 (n=50) ===");
        var primes1 = sieve.SieveOfEratosthenes(50);
        var primes2 = sieve.LinearSieve(50);
        Console.WriteLine($"埃氏筛: {string.Join(", ", primes1)}");
        Console.WriteLine($"线性筛: {string.Join(", ", primes2)}");
        Console.WriteLine($"结果一致: {primes1.Count == primes2.Count}");

        // 大范围统计
        Console.WriteLine("\n=== 素数统计 ===");
        int[] ranges = { 100, 1000, 10000, 100000 };
        foreach (int r in ranges)
        {
            var primes = sieve.SieveOfEratosthenes(r);
            Console.WriteLine($"  [2, {r}] 范围内素数个数: {primes.Count}");
        }

        // 质因数分解
        Console.WriteLine("\n=== 质因数分解 ===");
        int[] nums = { 12, 60, 100, 97 };
        foreach (int num in nums)
        {
            var factors = sieve.Factorize(num);
            var parts = new List<string>();
            foreach (var (f, c) in factors)
            {
                parts.Add(c > 1 ? $"{f}^{c}" : $"{f}");
            }
            Console.WriteLine($"  {num} = {string.Join(" × ", parts)}");
        }
    }
}

9. 复杂度分析

算法时间复杂度空间复杂度每个合数标记次数
埃氏筛O(n log log n)O(n)可能多次
线性筛O(n)O(n)恰好1次
试除法(逐个)O(n√n)O(1)-

素数定理：n以内约有 n/ln(n) 个素数

10. 易错点

  1. 起始位置：埃氏筛从 i² 开始标记（不是 2*i），因为更小的倍数已被处理
  2. 溢出问题：i*i 可能溢出int，需要 (long)i * i
  3. 线性筛的break：if (i % p == 0) break 是正确性的关键，不能省略
  4. 0和1：0和1不是素数，初始化时要标记
  5. 大范围内存：n=10^8时bool数组需100MB，可用BitArray优化

13. 记忆口诀

埃氏筛法找素数，从二开始筛倍数。
素数的倍数都合数，标完看剩就是素。
从i方开始标记起，小倍数早被前面筛。
线性筛只筛一次，最小因子是关键。
整除即停保正确，严格线性O(n)成。

14. 面试常问点

  1. 如何高效求n以内所有素数？ → 埃氏筛 O(n log log n)
  2. 埃氏筛为什么从i²开始？ → 更小的倍数已被更小的素数筛过
  3. 线性筛的核心思想？ → 每个合数只被最小质因子筛一次
  4. 为什么 i%p==0 时要break？ → 保证之后的数由其真正的最小质因子来筛
  5. 如何判断一个大数是否素数？ → 试除到√n 或 Miller-Rabin
  6. n以内大约有多少素数？ → 约 n/ln(n) 个
