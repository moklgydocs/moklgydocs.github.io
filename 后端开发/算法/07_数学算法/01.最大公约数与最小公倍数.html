最大公约数与最小公倍数

1. 算法定位

最大公约数（GCD）和最小公倍数（LCM）是数论中最基础的算法，欧几里得算法（辗转相除法）是求GCD的高效方法。是密码学、分数运算、调度问题等的基础工具。

2. 一句话理解

GCD通过反复用较小数对较大数取余，直到余数为0，此时的除数就是最大公约数；LCM = a * b / GCD(a, b)。

3. 生活化比喻

  • GCD：两根绳子（长度a和b），用一把尺子去量，能同时整量两根绳子的最长尺子就是GCD
  • LCM：两个齿轮（齿数a和b）同时转动，最少转多少齿后又同时回到起始位置，答案就是LCM

4. 核心思想

欧几里得算法（辗转相除法）

核心定理：gcd(a, b) = gcd(b, a % b)

证明直觉：如果 d 能整除 a 和 b，那么 d 也能整除 a - b，也能整除 a % b

方法时间复杂度说明
暴力枚举O(min(a,b))从min(a,b)往下试
辗转相除法O(log(min(a,b)))每次余数至少缩小一半
扩展欧几里得O(log(min(a,b)))同时求出 ax + by = gcd 的x,y

5. 图解推演

辗转相除法过程：gcd(48, 18)

gcd(48, 18)
= gcd(18, 48 % 18) = gcd(18, 12)
= gcd(12, 18 % 12) = gcd(12, 6)
= gcd(6, 12 % 6)   = gcd(6, 0)
= 6

过程展示:
┌─────────────────────────────────┐
│  48 ÷ 18 = 2 ... 余 12          │
│  18 ÷ 12 = 1 ... 余 6           │
│  12 ÷  6 = 2 ... 余 0  ← 停止  │
│  最大公约数 = 6                   │
└─────────────────────────────────┘

另一个例子：gcd(252, 105)

252 ÷ 105 = 2 ... 余 42
105 ÷  42 = 2 ... 余 21
 42 ÷  21 = 2 ... 余 0

gcd(252, 105) = 21

验证: 252 = 21 × 12, 105 = 21 × 5 ✓

LCM计算：lcm(12, 18)

gcd(12, 18) = 6
lcm(12, 18) = 12 × 18 / 6 = 216 / 6 = 36

验证: 36 = 12 × 3 = 18 × 2 ✓

扩展欧几里得算法：求 48x + 18y = gcd(48,18) = 6

gcd(48, 18):
  48 = 2 × 18 + 12    →  12 = 48 - 2×18
  18 = 1 × 12 + 6     →   6 = 18 - 1×12
  12 = 2 × 6  + 0     →  停止

回代:
  6 = 18 - 1×12
    = 18 - 1×(48 - 2×18)
    = 18 - 48 + 2×18
    = 3×18 - 1×48
    = (-1)×48 + 3×18

所以 x=-1, y=3
验证: (-1)×48 + 3×18 = -48 + 54 = 6 ✓

6. 执行步骤

辗转相除法步骤

  1. 如果 b == 0，返回 a（递归终止）
  2. 否则返回 gcd(b, a % b)

扩展欧几里得步骤

  1. 递归到底层 gcd(a, 0) = a 时，x=1, y=0
  2. 回溯时更新：x = y', y = x' - (a/b) * y'

LCM步骤

  1. 先求 gcd(a, b)
  2. lcm = a / gcd * b（先除后乘防溢出）

7. C# 实现

using System;

/// <summary>
/// 最大公约数和最小公倍数算法
/// </summary>
public class GCDAlgorithm
{
    /// <summary>
    /// 欧几里得算法（递归版）
    /// 时间复杂度: O(log(min(a,b)))
    /// </summary>
    public long GcdRecursive(long a, long b)
    {
        if (b == 0) return a;         // 递归终止条件
        return GcdRecursive(b, a % b); // 辗转相除
    }

    /// <summary>
    /// 欧几里得算法（迭代版，推荐使用）
    /// 避免递归开销和栈溢出
    /// </summary>
    public long Gcd(long a, long b)
    {
        // 确保处理负数
        a = Math.Abs(a);
        b = Math.Abs(b);

        while (b != 0)
        {
            long temp = b;
            b = a % b;    // 用余数替换
            a = temp;     // 用除数替换被除数
        }

        return a;  // 当b=0时，a就是GCD
    }

    /// <summary>
    /// 最小公倍数
    /// 注意：先除后乘，避免溢出
    /// </summary>
    public long Lcm(long a, long b)
    {
        if (a == 0 || b == 0) return 0;
        return Math.Abs(a) / Gcd(a, b) * Math.Abs(b);
    }

    /// <summary>
    /// 扩展欧几里得算法
    /// 求解 ax + by = gcd(a,b) 中的 x, y
    /// 返回 (gcd, x, y)
    /// </summary>
    public (long gcd, long x, long y) ExtendedGcd(long a, long b)
    {
        if (b == 0)
        {
            // 基础情况: a*1 + 0*0 = a
            return (a, 1, 0);
        }

        // 递归求解
        var (g, x1, y1) = ExtendedGcd(b, a % b);

        // 回代计算当前层的 x, y
        // 因为: b*x1 + (a%b)*y1 = g
        // 而:   a%b = a - (a/b)*b
        // 所以: b*x1 + (a - (a/b)*b)*y1 = g
        //       a*y1 + b*(x1 - (a/b)*y1) = g
        long x = y1;
        long y = x1 - (a / b) * y1;

        return (g, x, y);
    }

    /// <summary>
    /// 多个数的GCD
    /// gcd(a, b, c) = gcd(gcd(a, b), c)
    /// </summary>
    public long GcdMultiple(params long[] numbers)
    {
        if (numbers.Length == 0) return 0;

        long result = numbers[0];
        for (int i = 1; i < numbers.Length; i++)
        {
            result = Gcd(result, numbers[i]);
            if (result == 1) return 1;  // 提前终止优化
        }

        return result;
    }

    /// <summary>
    /// 多个数的LCM
    /// lcm(a, b, c) = lcm(lcm(a, b), c)
    /// </summary>
    public long LcmMultiple(params long[] numbers)
    {
        if (numbers.Length == 0) return 0;

        long result = numbers[0];
        for (int i = 1; i < numbers.Length; i++)
        {
            result = Lcm(result, numbers[i]);
        }

        return result;
    }

    /// <summary>
    /// 带详细过程输出
    /// </summary>
    public long GcdWithTrace(long a, long b)
    {
        Console.WriteLine($"计算 gcd({a}, {b}):");
        long origA = a, origB = b;

        while (b != 0)
        {
            long quotient = a / b;
            long remainder = a % b;
            Console.WriteLine($"  {a} ÷ {b} = {quotient} ... 余 {remainder}");
            a = b;
            b = remainder;
        }

        Console.WriteLine($"  余数为0，gcd({origA}, {origB}) = {a}");
        return a;
    }
}

/// <summary>
/// 测试程序
/// </summary>
public class Program
{
    public static void Main()
    {
        var algo = new GCDAlgorithm();

        // 基本GCD演示
        Console.WriteLine("=== 辗转相除法详细过程 ===");
        algo.GcdWithTrace(48, 18);
        Console.WriteLine();
        algo.GcdWithTrace(252, 105);

        // GCD和LCM
        Console.WriteLine("\n=== GCD 和 LCM ===");
        var pairs = new (long a, long b)[] { (12, 18), (35, 14), (100, 75), (17, 13) };
        foreach (var (a, b) in pairs)
        {
            Console.WriteLine($"gcd({a}, {b}) = {algo.Gcd(a, b)}, lcm({a}, {b}) = {algo.Lcm(a, b)}");
        }

        // 扩展欧几里得
        Console.WriteLine("\n=== 扩展欧几里得算法 ===");
        var (gcd, x, y) = algo.ExtendedGcd(48, 18);
        Console.WriteLine($"48x + 18y = gcd(48,18) = {gcd}");
        Console.WriteLine($"x = {x}, y = {y}");
        Console.WriteLine($"验证: 48×({x}) + 18×({y}) = {48 * x + 18 * y}");

        var (gcd2, x2, y2) = algo.ExtendedGcd(35, 15);
        Console.WriteLine($"\n35x + 15y = gcd(35,15) = {gcd2}");
        Console.WriteLine($"x = {x2}, y = {y2}");
        Console.WriteLine($"验证: 35×({x2}) + 15×({y2}) = {35 * x2 + 15 * y2}");

        // 多个数的GCD/LCM
        Console.WriteLine("\n=== 多个数的 GCD/LCM ===");
        Console.WriteLine($"gcd(12, 18, 24) = {algo.GcdMultiple(12, 18, 24)}");
        Console.WriteLine($"lcm(4, 6, 10) = {algo.LcmMultiple(4, 6, 10)}");
    }
}

9. 复杂度分析

算法时间复杂度空间复杂度说明
欧几里得(递归)O(log min(a,b))O(log min(a,b))递归栈深度
欧几里得(迭代)O(log min(a,b))O(1)推荐使用
扩展欧几里得O(log min(a,b))O(log min(a,b))递归实现
暴力法O(min(a,b))O(1)效率低

Lame定理：欧几里得算法的步数不超过较小数的十进制位数的5倍

10. 易错点

  1. 参数顺序：gcd(a,b) 中 a 和 b 的顺序无所谓，算法会自动处理
  2. LCM溢出：a * b / gcd 可能溢出，应该 a / gcd * b（先除后乘）
  3. 零的处理：gcd(0, b) = b，gcd(0, 0) 一般定义为0
  4. 负数处理：应先取绝对值
  5. 扩展GCD的x,y：不是唯一的，通解为 x + b/gt, y - a/gt

13. 记忆口诀

辗转相除求公约，大数除小取余数。
余数为零除数答，递推直到b为零。
最小公倍有公式，a除GCD乘b得。
扩展算法求系数，回代公式要记牢。
先除后乘防溢出，负数先绝对值搞。

14. 面试常问点

  1. 手写欧几里得算法 → 递归和迭代都要会
  2. GCD的时间复杂度？ → O(log min(a,b))
  3. 如何求LCM？ → lcm(a,b) = a / gcd(a,b) * b
  4. 扩展欧几里得有什么用？ → 求模逆元、解线性同余方程
  5. gcd(0, n)等于什么？ → n
  6. 如何求多个数的GCD？ → 逐对求解 gcd(gcd(a,b), c)
