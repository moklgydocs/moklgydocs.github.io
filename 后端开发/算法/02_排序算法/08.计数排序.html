计数排序

算法定位

计数排序（Counting Sort）属于非比较排序算法，是线性时间排序的代表之一。

它解决的问题是：当数据范围有限时（比如考试成绩 0~100），不需要逐个比较元素大小，通过统计每个值出现的次数来直接确定每个元素在排序结果中的位置。

计数排序打破了比较排序 O(n log n) 的下界，可以达到 O(n+k) 的线性时间（k 为数据范围）。

一句话理解

数每个数字出现了几次，然后按照数字从小到大依次"铺开"，出现几次就写几个。

生活化比喻

假设老师要统计全班 50 名同学的考试成绩（0~100 分）排名：

  • 老师不需要两两比较成绩
  • 只需要准备 101 个"桶"（0分桶、1分桶、...、100分桶）
  • 每收到一份试卷，就在对应分数的桶里放一个标记
  • 最后从 0 分桶开始，依次把标记读出来，就是排好序的结果

这就是"计数"的思想——不比较，只统计。

核心思想

  1. 找范围：确定数据的最小值和最大值
  2. 计数：创建计数数组，统计每个值出现的次数
  3. 前缀和（稳定版本）：计算每个值的累积计数，确定元素在结果中的位置
  4. 输出：根据计数/前缀和，将元素放到正确位置

为什么会想到这种方法？ 当数据范围有限时，"数一数有几个"比"谁大谁小"更高效。这是用空间换时间的典型策略。

图解推演

以数组 [4, 2, 2, 8, 3, 3, 1] 为例：

原始数组：[4, 2, 2, 8, 3, 3, 1]
最小值=1，最大值=8，范围 k=8

=== 第 1 步：统计每个值的出现次数 ===

值:    1  2  3  4  5  6  7  8
次数:  1  2  2  1  0  0  0  1

count = [0, 1, 2, 2, 1, 0, 0, 0, 1]
         ↑  ↑  ↑  ↑  ↑  ↑  ↑  ↑  ↑
         0  1  2  3  4  5  6  7  8

=== 第 2 步：计算前缀和（累加计数）===

count[i] 表示值 <= i 的元素总数
count = [0, 1, 3, 5, 6, 6, 6, 6, 7]

含义：
  值 <= 1 的有 1 个 → 1 应放在位置 0
  值 <= 2 的有 3 个 → 最后一个 2 放在位置 2
  值 <= 3 的有 5 个 → 最后一个 3 放在位置 4
  值 <= 4 的有 6 个 → 4 放在位置 5
  值 <= 8 的有 7 个 → 8 放在位置 6

=== 第 3 步：从后往前放置元素（保证稳定性）===

原始数组从右往左扫描：

arr[6]=1 → count[1]=1 → 放到 output[0] → count[1]=0
  output: [1, _, _, _, _, _, _]

arr[5]=3 → count[3]=5 → 放到 output[4] → count[3]=4
  output: [1, _, _, _, 3, _, _]

arr[4]=3 → count[3]=4 → 放到 output[3] → count[3]=3
  output: [1, _, _, 3, 3, _, _]

arr[3]=8 → count[8]=7 → 放到 output[6] → count[8]=6
  output: [1, _, _, 3, 3, _, 8]

arr[2]=2 → count[2]=3 → 放到 output[2] → count[2]=2
  output: [1, _, 2, 3, 3, _, 8]

arr[1]=2 → count[2]=2 → 放到 output[1] → count[2]=1
  output: [1, 2, 2, 3, 3, _, 8]

arr[0]=4 → count[4]=6 → 放到 output[5] → count[4]=5
  output: [1, 2, 2, 3, 3, 4, 8]

最终结果：[1, 2, 2, 3, 3, 4, 8] ✓

执行步骤

  1. 找到数组中的最小值 min 和最大值 max
  2. 创建计数数组 count，大小为 max - min + 1
  3. 遍历原数组，统计每个值的出现次数
  4. 对计数数组求前缀和
  5. 从后往前遍历原数组，根据前缀和确定每个元素的位置，放入结果数组
  6. 将结果复制回原数组

C# 实现

using System;

class CountingSortDemo
{
    /// <summary>
    /// 计数排序 - 简单版本（适合快速理解）
    /// 直接根据计数数组展开结果，不保证稳定性
    /// </summary>
    static void CountingSortSimple(int[] arr)
    {
        if (arr.Length <= 1) return;

        // 找最大值和最小值
        int min = arr[0], max = arr[0];
        foreach (int num in arr)
        {
            if (num < min) min = num;
            if (num > max) max = num;
        }

        // 创建计数数组
        int range = max - min + 1;
        int[] count = new int[range];

        // 统计每个值的出现次数
        foreach (int num in arr)
        {
            count[num - min]++;
        }

        // 根据计数数组直接填充结果
        int index = 0;
        for (int i = 0; i < range; i++)
        {
            while (count[i] > 0)
            {
                arr[index++] = i + min;
                count[i]--;
            }
        }
    }

    /// <summary>
    /// 计数排序 - 稳定版本（标准实现）
    /// 使用前缀和确定位置，从后往前放置保证稳定性
    /// </summary>
    static int[] CountingSortStable(int[] arr)
    {
        if (arr.Length <= 1) return (int[])arr.Clone();

        int n = arr.Length;

        // 第 1 步：找最大值和最小值
        int min = arr[0], max = arr[0];
        for (int i = 1; i < n; i++)
        {
            if (arr[i] < min) min = arr[i];
            if (arr[i] > max) max = arr[i];
        }

        // 第 2 步：创建计数数组并统计
        int range = max - min + 1;
        int[] count = new int[range];

        for (int i = 0; i < n; i++)
        {
            count[arr[i] - min]++;
        }

        // 第 3 步：计算前缀和
        // count[i] 变为值 <= (i+min) 的元素总数
        for (int i = 1; i < range; i++)
        {
            count[i] += count[i - 1];
        }

        // 第 4 步：从后往前遍历原数组，放置元素
        // 从后往前是为了保证稳定性
        int[] output = new int[n];
        for (int i = n - 1; i >= 0; i--)
        {
            int value = arr[i];
            int pos = count[value - min] - 1; // 确定位置（0-indexed）
            output[pos] = value;
            count[value - min]--; // 计数减 1
        }

        return output;
    }

    /// <summary>
    /// 计数排序 - 处理负数的版本
    /// 通过偏移量处理负数范围
    /// </summary>
    static void CountingSortWithNegative(int[] arr)
    {
        if (arr.Length <= 1) return;

        int min = arr[0], max = arr[0];
        foreach (int num in arr)
        {
            if (num < min) min = num;
            if (num > max) max = num;
        }

        // 用 min 作为偏移量，将所有值映射到非负范围
        int range = max - min + 1;
        int[] count = new int[range];

        foreach (int num in arr)
        {
            count[num - min]++; // 偏移映射
        }

        int index = 0;
        for (int i = 0; i < range; i++)
        {
            while (count[i] > 0)
            {
                arr[index++] = i + min; // 还原偏移
                count[i]--;
            }
        }
    }

    /// <summary>
    /// 打印数组内容
    /// </summary>
    static void PrintArray(int[] arr)
    {
        Console.WriteLine("[" + string.Join(", ", arr) + "]");
    }

    static void Main(string[] args)
    {
        Console.WriteLine("===== 计数排序演示 =====\n");

        // 简单版本
        int[] arr1 = { 4, 2, 2, 8, 3, 3, 1 };
        Console.Write("简单版 - 排序前：");
        PrintArray(arr1);
        CountingSortSimple(arr1);
        Console.Write("简单版 - 排序后：");
        PrintArray(arr1);

        Console.WriteLine();

        // 稳定版本
        int[] arr2 = { 4, 2, 2, 8, 3, 3, 1 };
        Console.Write("稳定版 - 排序前：");
        PrintArray(arr2);
        int[] result = CountingSortStable(arr2);
        Console.Write("稳定版 - 排序后：");
        PrintArray(result);

        Console.WriteLine();

        // 包含负数的版本
        int[] arr3 = { -5, -3, 0, 2, -1, 4, 1, -2 };
        Console.Write("含负数 - 排序前：");
        PrintArray(arr3);
        CountingSortWithNegative(arr3);
        Console.Write("含负数 - 排序后：");
        PrintArray(arr3);

        Console.WriteLine();

        // 考试成绩排序
        int[] scores = { 85, 92, 78, 92, 85, 100, 65, 78, 92 };
        Console.Write("成绩排序前：");
        PrintArray(scores);
        CountingSortSimple(scores);
        Console.Write("成绩排序后：");
        PrintArray(scores);
    }
}

示例演示

以输入 [3, 1, 3, 2, 1] 手动推演（稳定版）：

原始数组：[3, 1, 3, 2, 1]
min=1, max=3, range=3

--- 第 1 步：计数 ---
值:  1  2  3
次数: 2  1  2
count = [2, 1, 2]

--- 第 2 步：前缀和 ---
count = [2, 3, 5]
含义：值<=1 的有 2 个，值<=2 的有 3 个，值<=3 的有 5 个

--- 第 3 步：从后往前放置 ---
i=4：arr[4]=1 → count[0]=2 → output[1]=1 → count[0]=1
  output: [_, 1, _, _, _]

i=3：arr[3]=2 → count[1]=3 → output[2]=2 → count[1]=2
  output: [_, 1, 2, _, _]

i=2：arr[2]=3 → count[2]=5 → output[4]=3 → count[2]=4
  output: [_, 1, 2, _, 3]

i=1：arr[1]=1 → count[0]=1 → output[0]=1 → count[0]=0
  output: [1, 1, 2, _, 3]

i=0：arr[0]=3 → count[2]=4 → output[3]=3 → count[2]=3
  output: [1, 1, 2, 3, 3]

最终结果：[1, 1, 2, 3, 3] ✓

稳定性验证：
  原数组两个 1：位置 1 和位置 4
  结果中两个 1：位置 0（来自 arr[1]）和位置 1（来自 arr[4]？）
  因为从后往前遍历，arr[4] 的 1 先放到 output[1]，arr[1] 的 1 放到 output[0]
  相对顺序保持！✓

复杂度分析

指标复杂度说明
时间复杂度O(n + k)n 是元素个数，k 是数据范围（max - min + 1）
空间复杂度O(n + k)需要计数数组 O(k) 和输出数组 O(n)
稳定性稳定前缀和 + 从后往前放置保证稳定

通俗解释：

  • 当 k 远小于 n 时（如 100 万个 0~100 的成绩），时间接近 O(n)，比任何比较排序都快
  • 当 k 远大于 n 时（如 10 个元素范围 0~100万），空间浪费严重，不适合使用
  • 适用条件：数据范围 k 不能太大，最好 k = O(n) 或 k 远小于 n

易错点

  1. 忽略负数：直接用值作下标会导致数组越界，需要用 value - min 做偏移
  2. 简单版本不稳定：直接展开计数数组的写法不保证稳定性，稳定版需要前缀和 + 从后往前放置
  3. 数据范围过大时不适用：如果最大值是 10 亿，计数数组需要 10 亿空间，完全不可行
  4. 前缀和计算错误：前缀和是从 count[1] 开始累加，不是从 count[0]
  5. 输出位置 off-by-one：count[value - min] - 1 是 0-indexed 的位置，容易忘记减 1

延伸学习：

  • 桶排序：计数排序的泛化版本，桶内可以用其他排序算法
  • 基数排序：对每一位使用计数排序，可以处理更大范围的整数
  • 比较排序下界定理：比较排序最优为 O(n log n)，计数排序通过"不比较"突破了这个限制

记忆口诀

不比大小数个数，计数数组存频次。前缀和定位置，从后往前保稳定。

面试常问点

  1. 计数排序的时间复杂度是多少？它是比较排序吗？

    • O(n + k)，不是比较排序。它通过统计计数而非元素比较来确定顺序

  2. 计数排序在什么情况下不适用？

    • 数据范围 k 远大于 n 时（如 10 个元素范围 0~10亿），空间浪费极大
    • 数据不是整数或不能映射为有限范围的整数时

  3. 如何保证计数排序的稳定性？

    • 使用前缀和确定每个元素的最终位置，从后往前遍历原数组放置元素

  4. 计数排序和桶排序有什么关系？

    • 计数排序是桶排序的特殊情况：每个桶恰好只装一种值，桶的数量等于数据范围

  5. 能否用计数排序对浮点数排序？

    • 不能直接使用，但可以先将浮点数映射到整数范围（如乘以 100 变成分），或使用桶排序
