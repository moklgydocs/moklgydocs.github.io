基数排序

算法定位

基数排序（Radix Sort）属于非比较排序算法，是一种利用"按位分配和收集"来实现排序的方法。

它解决的问题是：对于整数或字符串等可以分解为多个"位"的数据，不需要逐个比较大小，而是逐位排序，每一位的排序用计数排序（或桶排序）完成，最终实现整体有序。

基数排序常与计数排序配合使用，是处理大量整数或定长字符串排序的利器。

一句话理解

从最低位（个位）开始，对每一位进行稳定排序，逐位处理直到最高位，所有数就排好了。

生活化比喻

想象你要按数字大小排列一堆三位数的卡片（如 170, 045, 075, 090, 802, 024, 002, 066）：

  • 第一轮：只看个位数字，按个位排成 10 堆（0堆、1堆、……、9堆），然后按堆顺序收集
  • 第二轮：只看十位数字，同样分 10 堆，再收集
  • 第三轮：只看百位数字，分堆收集

三轮之后，所有卡片就按数值从小到大排好了。

关键是每轮必须用稳定排序，这样前面几轮排好的相对顺序不会被打乱。

核心思想

  1. 确定最大位数：找到最大值，确定需要排几轮
  2. 逐位排序（LSD，从最低位开始）：
    • 第 1 轮按个位排序
    • 第 2 轮按十位排序
    • 第 3 轮按百位排序
    • ……
  3. 每轮使用稳定排序（通常是计数排序），保证之前位数的排序结果不被破坏
  4. 处理完最高位后，数组完全有序

为什么会想到这种方法？ 多关键字排序可以拆解为多次单关键字排序。从低位到高位排序（LSD），高位优先级更高，最终高位决定大小。

执行步骤

  1. 找到数组中的最大值，确定最大位数 d
  2. 从最低位（个位）开始，共执行 d 轮
  3. 每轮对当前位使用计数排序：
    • 统计当前位上 0~9 各数字出现的次数
    • 计算前缀和
    • 从后往前将元素放到正确位置（保证稳定性）
  4. d 轮结束后，数组有序

C# 实现

using System;
using System.Collections.Generic;

class RadixSortDemo
{
    /// <summary>
    /// 基数排序 - LSD（Least Significant Digit，从最低位开始）
    /// 标准实现，使用计数排序作为每一位的排序子过程
    /// </summary>
    static void RadixSort(int[] arr)
    {
        if (arr.Length <= 1) return;

        // 找到最大值，确定最大位数
        int max = arr[0];
        foreach (int num in arr)
        {
            if (num > max) max = num;
        }

        // 从个位开始，逐位排序
        // exp 表示当前位的权值：1（个位）、10（十位）、100（百位）...
        for (int exp = 1; max / exp > 0; exp *= 10)
        {
            CountingSortByDigit(arr, exp);
        }
    }

    /// <summary>
    /// 对数组按指定位进行计数排序
    /// exp = 1 表示按个位，exp = 10 表示按十位，以此类推
    /// </summary>
    static void CountingSortByDigit(int[] arr, int exp)
    {
        int n = arr.Length;
        int[] output = new int[n]; // 输出数组
        int[] count = new int[10]; // 计数数组（0~9 共 10 个数字）

        // 第 1 步：统计当前位上各数字出现的次数
        for (int i = 0; i < n; i++)
        {
            int digit = (arr[i] / exp) % 10; // 提取当前位的数字
            count[digit]++;
        }

        // 第 2 步：计算前缀和
        for (int i = 1; i < 10; i++)
        {
            count[i] += count[i - 1];
        }

        // 第 3 步：从后往前放置元素（保证稳定性）
        for (int i = n - 1; i >= 0; i--)
        {
            int digit = (arr[i] / exp) % 10;
            output[count[digit] - 1] = arr[i];
            count[digit]--;
        }

        // 第 4 步：将结果复制回原数组
        Array.Copy(output, arr, n);
    }

    /// <summary>
    /// 基数排序 - 使用桶（List）实现
    /// 更直观的实现方式，便于理解
    /// </summary>
    static void RadixSortWithBuckets(int[] arr)
    {
        if (arr.Length <= 1) return;

        int max = arr[0];
        foreach (int num in arr)
        {
            if (num > max) max = num;
        }

        // 创建 10 个桶（对应数字 0~9）
        List<int>[] buckets = new List<int>[10];
        for (int i = 0; i < 10; i++)
        {
            buckets[i] = new List<int>();
        }

        for (int exp = 1; max / exp > 0; exp *= 10)
        {
            // 清空所有桶
            foreach (var bucket in buckets)
            {
                bucket.Clear();
            }

            // 分桶：按当前位的数字放入对应桶
            foreach (int num in arr)
            {
                int digit = (num / exp) % 10;
                buckets[digit].Add(num);
            }

            // 收集：按桶顺序取出所有元素
            int index = 0;
            for (int i = 0; i < 10; i++)
            {
                foreach (int num in buckets[i])
                {
                    arr[index++] = num;
                }
            }
        }
    }

    /// <summary>
    /// 基数排序 - 支持负数的版本
    /// 思路：将正数和负数分开排序，负数取绝对值后排序再反转
    /// </summary>
    static void RadixSortWithNegative(int[] arr)
    {
        // 分离正数和负数
        List<int> positives = new List<int>();
        List<int> negatives = new List<int>();

        foreach (int num in arr)
        {
            if (num >= 0)
                positives.Add(num);
            else
                negatives.Add(-num); // 取绝对值
        }

        // 对正数进行基数排序
        int[] posArr = positives.ToArray();
        if (posArr.Length > 0)
            RadixSort(posArr);

        // 对负数的绝对值进行基数排序，然后反转
        int[] negArr = negatives.ToArray();
        if (negArr.Length > 0)
        {
            RadixSort(negArr);
            Array.Reverse(negArr); // 反转得到从大到小（对应负数从小到大）
        }

        // 合并：先放排好序的负数（还原负号），再放正数
        int index = 0;
        for (int i = 0; i < negArr.Length; i++)
        {
            arr[index++] = -negArr[i];
        }
        for (int i = 0; i < posArr.Length; i++)
        {
            arr[index++] = posArr[i];
        }
    }

    /// <summary>
    /// 基数排序 - 详细演示版（带日志输出）
    /// </summary>
    static void RadixSortVerbose(int[] arr)
    {
        int max = arr[0];
        foreach (int num in arr)
            if (num > max) max = num;

        int round = 0;
        for (int exp = 1; max / exp > 0; exp *= 10)
        {
            round++;
            string placeName = exp == 1 ? "个位" : exp == 10 ? "十位" : exp == 100 ? "百位" : exp + "位";
            Console.WriteLine($"\n  第 {round} 轮（按{placeName}排序）：");

            // 显示每个元素当前位的数字
            Console.Write("    当前位数字：");
            foreach (int num in arr)
            {
                Console.Write($"{(num / exp) % 10} ");
            }
            Console.WriteLine();

            CountingSortByDigit(arr, exp);

            Console.Write("    排序结果：  ");
            Console.WriteLine("[" + string.Join(", ", arr) + "]");
        }
    }

    /// <summary>
    /// 打印数组内容
    /// </summary>
    static void PrintArray(int[] arr)
    {
        Console.WriteLine("[" + string.Join(", ", arr) + "]");
    }

    static void Main(string[] args)
    {
        Console.WriteLine("===== 基数排序演示 =====\n");

        // 标准 LSD 基数排序
        int[] arr1 = { 170, 45, 75, 90, 802, 24, 2, 66 };
        Console.Write("LSD 基数排序 - 排序前：");
        PrintArray(arr1);
        Console.WriteLine("排序过程：");
        RadixSortVerbose(arr1);
        Console.Write("\nLSD 基数排序 - 排序后：");
        PrintArray(arr1);

        Console.WriteLine("\n" + new string('-', 50) + "\n");

        // 桶实现版本
        int[] arr2 = { 329, 457, 657, 839, 436, 720, 355 };
        Console.Write("桶实现版 - 排序前：");
        PrintArray(arr2);
        RadixSortWithBuckets(arr2);
        Console.Write("桶实现版 - 排序后：");
        PrintArray(arr2);

        Console.WriteLine();

        // 支持负数的版本
        int[] arr3 = { -5, 3, -2, 8, -1, 0, 7, -9, 4 };
        Console.Write("含负数 - 排序前：");
        PrintArray(arr3);
        RadixSortWithNegative(arr3);
        Console.Write("含负数 - 排序后：");
        PrintArray(arr3);
    }
}

复杂度分析

指标复杂度说明
时间复杂度O(n * d)n 是元素个数，d 是最大位数
空间复杂度O(n + k)k 为基数（通常是 10），n 为输出数组
稳定性稳定每轮使用稳定排序（计数排序），保持相对顺序

通俗解释：

  • 每轮（每一位）需要 O(n) 时间做计数排序，共 d 轮，总时间 O(n * d)
  • 当 d 是常数（如 32 位整数最多 10 位十进制数）时，时间复杂度接近 O(n)
  • 空间上需要 O(n) 的输出数组和 O(10) 的计数数组

与 O(n log n) 的比较：

  • 如果 d < log n，基数排序更快
  • 例如对 100 万个不超过 999 的三位数排序：基数排序 O(3n) vs 快排 O(n * 20)

易错点

  1. 忘记每轮使用稳定排序：如果某一轮的排序不稳定，之前轮次建立的相对顺序会被破坏，最终结果错误
  2. 提取数字写错：(num / exp) % 10 而不是 num % (exp * 10) / exp（虽然结果相同但前者更清晰）
  3. 最大位数计算错误：使用 max / exp > 0 作为循环条件比计算位数更简洁不易错
  4. 不支持负数：标准基数排序只能处理非负整数，处理负数需要额外逻辑
  5. 基数选择：默认以 10 为基数，实际上可以选择其他基数（如 256）来优化性能
// 提取第 k 位数字的正确写法
int digit = (num / exp) % 10;
// exp = 1   → 个位
// exp = 10  → 十位
// exp = 100 → 百位

  • 后缀数组构造：基数排序是构造后缀数组的关键步骤

记忆口诀

个十百位轮流排，每位都用计数来。低位先排高位后，稳定排序不能少。

面试常问点

  1. 基数排序的时间复杂度是多少？什么时候比 O(n log n) 快？

    • O(n * d)，其中 d 是最大位数。当 d < log n 时，比快排更快。例如对 100 万个三位数排序

  2. LSD 和 MSD 有什么区别？

    • LSD（Least Significant Digit）：从最低位开始，逐位排序，适合等长数据
    • MSD（Most Significant Digit）：从最高位开始，递归排序，适合变长字符串

  3. 为什么基数排序要求每轮必须用稳定排序？

    • 因为低位排好的顺序需要在高位排序时保持。如果不稳定，低位排好的相对顺序会被打乱
    • 例如 329 和 355 经过前两轮已确定 329 < 355，第三轮百位都是 3，必须保持它们的相对顺序

  4. 基数排序能排浮点数吗？

    • 不能直接排。需要先转换为整数（如乘以固定倍数），或利用浮点数的 IEEE 754 表示特性

  5. 基数排序和计数排序的关系？

    • 基数排序是多轮计数排序的组合。每一位的排序就是一次计数排序（基数为 10）

  6. 如何处理负数？

    • 方法一：将正数和负数分开排序，负数取绝对值排序后反转
    • 方法二：加偏移量将所有数变为非负数
