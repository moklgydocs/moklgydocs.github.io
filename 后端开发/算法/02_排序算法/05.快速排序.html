快速排序

算法定位

快速排序（Quick Sort）属于交换类排序算法，是实际应用中最广泛使用的排序算法之一。

它解决的问题是：给定一个无序数组，通过分治法（Divide and Conquer）高效地完成排序。

快速排序由 Tony Hoare 于 1960 年提出，是大多数编程语言标准库排序的基础（如 C 语言的 qsort）。

一句话理解

选一个基准元素（pivot），把比它小的放左边，比它大的放右边，然后对左右两边分别递归执行同样的操作。

生活化比喻

想象一个班级要按身高排队：

  • 班长站在中间，喊一声："比我矮的站左边，比我高的站右边！"
  • 然后左边的人中再选一个"小班长"，重复同样的操作
  • 右边也是如此
  • 每组人数越来越少，最终每个人都在正确的位置上

就像分拣快递：先按省份分大堆，再在每个省内按城市分小堆，逐步细化。

核心思想

  1. 选择基准（Pivot）：从数组中选择一个元素作为基准
  2. 分区（Partition）：把数组分为三部分——比 pivot 小的、等于 pivot 的、比 pivot 大的
  3. 递归排序：对左、右两部分分别递归执行快速排序
  4. 合并：不需要合并操作，因为分区完成后元素已在正确的相对位置

为什么会想到这种方法？ 分治思想是解决大规模问题的利器——把大问题拆成小问题，小问题更容易解决。快速排序巧妙地用 pivot 实现了"拆分"。

以数组 [6, 3, 8, 2, 9, 1] 为例（选最后一个元素作为 pivot）：

       ✓   |← 待排序 →|

=== 递归右半部分 [3, 8, 2, 9, 6] ===
选 pivot = 6

分区过程：
  3 < 6 → 放入左区
  8 > 6 → 不动
  2 < 6 → 放入左区
  9 > 6 → 不动
  pivot=6 放到正确位置

       ✓   左区    ✓    右区

选 pivot = 2
  3 > 2 → 不动
  结果：[2, 3] ✓

=== 递归 [8, 9] ===
选 pivot = 9
  8 < 9 → 放入左区
  结果：[8, 9] ✓

最终结果：[1, 2, 3, 6, 8, 9] ✓

执行步骤

  1. 如果数组长度小于等于 1，直接返回（基本情况）
  2. 选择一个基准元素 pivot
  3. 将数组分为三部分：小于 pivot、等于 pivot、大于 pivot
  4. 对"小于 pivot"的部分递归快速排序
  5. 对"大于 pivot"的部分递归快速排序
  6. 排序完成（原地分区不需要合并步骤）

C# 实现

using System;

class QuickSortDemo
{
    /// <summary>
    /// 快速排序 - 入口方法
    /// </summary>
    static void QuickSort(int[] arr, int left, int right)
    {
        if (left < right)
        {
            // 分区操作，返回 pivot 的最终位置
            int pivotIndex = PartitionLomuto(arr, left, right);

            // 递归排序左半部分（不包含 pivot）
            QuickSort(arr, left, pivotIndex - 1);

            // 递归排序右半部分（不包含 pivot）
            QuickSort(arr, pivotIndex + 1, right);
        }
    }

    /// <summary>
    /// Lomuto 分区方案
    /// 选最后一个元素作为 pivot，用 i 维护"小于区域"的边界
    /// 简单直观，适合教学
    /// </summary>
    static int PartitionLomuto(int[] arr, int left, int right)
    {
        int pivot = arr[right]; // 选最后一个元素为基准
        int i = left - 1;       // i 是"小于区域"的右边界

        for (int j = left; j < right; j++)
        {
            // 如果当前元素小于 pivot，放入"小于区域"
            if (arr[j] < pivot)
            {
                i++;
                Swap(arr, i, j);
            }
        }

        // 将 pivot 放到"小于区域"的右边（即正确位置）
        Swap(arr, i + 1, right);
        return i + 1; // 返回 pivot 的最终位置
    }

    /// <summary>
    /// Hoare 分区方案
    /// 用双指针从两端向中间扫描，效率高于 Lomuto
    /// 注意：Hoare 分区返回的位置含义与 Lomuto 不同
    /// </summary>
    static int PartitionHoare(int[] arr, int left, int right)
    {
        int pivot = arr[left]; // 选第一个元素为基准
        int i = left - 1;
        int j = right + 1;

        while (true)
        {
            // 从左向右找到第一个大于等于 pivot 的元素
            do { i++; } while (arr[i] < pivot);

            // 从右向左找到第一个小于等于 pivot 的元素
            do { j--; } while (arr[j] > pivot);

            // 如果两个指针相遇或交叉，返回 j
            if (i >= j) return j;

            // 交换两个不在正确区域的元素
            Swap(arr, i, j);
        }
    }

    /// <summary>
    /// 使用 Hoare 分区的快速排序
    /// 注意递归调用方式与 Lomuto 不同
    /// </summary>
    static void QuickSortHoare(int[] arr, int left, int right)
    {
        if (left < right)
        {
            int p = PartitionHoare(arr, left, right);

            // Hoare 分区：p 位置的元素不一定是 pivot
            // 所以左半部分包含 p，右半部分从 p+1 开始
            QuickSortHoare(arr, left, p);
            QuickSortHoare(arr, p + 1, right);
        }
    }

    /// <summary>
    /// 快速排序 - 随机化 pivot 优化版本
    /// 通过随机选择 pivot 来避免最坏情况
    /// </summary>
    static void QuickSortRandomized(int[] arr, int left, int right)
    {
        if (left < right)
        {
            // 随机选择 pivot 并将其交换到末尾
            Random rand = new Random();
            int randomIndex = rand.Next(left, right + 1);
            Swap(arr, randomIndex, right);

            int pivotIndex = PartitionLomuto(arr, left, right);

            QuickSortRandomized(arr, left, pivotIndex - 1);
            QuickSortRandomized(arr, pivotIndex + 1, right);
        }
    }

    /// <summary>
    /// 快速排序 - 三数取中优化版本
    /// 选择 left、mid、right 中的中间值作为 pivot
    /// 有效避免已排序数组导致的最坏情况
    /// </summary>
    static void QuickSortMedianOfThree(int[] arr, int left, int right)
    {
        if (left < right)
        {
            // 三数取中：选择 left、mid、right 的中间值
            int mid = left + (right - left) / 2;

            // 排序这三个位置的元素，使 arr[mid] 成为中间值
            if (arr[left] > arr[mid]) Swap(arr, left, mid);
            if (arr[left] > arr[right]) Swap(arr, left, right);
            if (arr[mid] > arr[right]) Swap(arr, mid, right);

            // 将中间值（pivot）放到 right-1 的位置
            Swap(arr, mid, right - 1);
            int pivot = arr[right - 1];

            // 对 left+1 到 right-2 进行分区
            int i = left;
            int j = right - 1;

            while (true)
            {
                while (arr[++i] < pivot) { }
                while (arr[--j] > pivot) { }
                if (i < j)
                    Swap(arr, i, j);
                else
                    break;
            }

            // 将 pivot 放回正确位置
            Swap(arr, i, right - 1);

            QuickSortMedianOfThree(arr, left, i - 1);
            QuickSortMedianOfThree(arr, i + 1, right);
        }
    }

    /// <summary>
    /// 交换数组中两个位置的元素
    /// </summary>
    static void Swap(int[] arr, int i, int j)
    {
        if (i != j)
        {
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
    }

    /// <summary>
    /// 打印数组内容
    /// </summary>
    static void PrintArray(int[] arr)
    {
        Console.WriteLine("[" + string.Join(", ", arr) + "]");
    }

    static void Main(string[] args)
    {
        Console.WriteLine("===== 快速排序演示 =====\n");

        // Lomuto 分区版本
        int[] arr1 = { 6, 3, 8, 2, 9, 1 };
        Console.Write("Lomuto 分区 - 排序前：");
        PrintArray(arr1);
        QuickSort(arr1, 0, arr1.Length - 1);
        Console.Write("Lomuto 分区 - 排序后：");
        PrintArray(arr1);

        Console.WriteLine();

        // Hoare 分区版本
        int[] arr2 = { 10, 7, 8, 9, 1, 5 };
        Console.Write("Hoare 分区 - 排序前：");
        PrintArray(arr2);
        QuickSortHoare(arr2, 0, arr2.Length - 1);
        Console.Write("Hoare 分区 - 排序后：");
        PrintArray(arr2);

        Console.WriteLine();

        // 随机化 pivot 版本
        int[] arr3 = { 1, 2, 3, 4, 5, 6, 7, 8 }; // 已排序数组（朴素版最坏情况）
        Console.Write("随机化 pivot - 排序前：");
        PrintArray(arr3);
        QuickSortRandomized(arr3, 0, arr3.Length - 1);
        Console.Write("随机化 pivot - 排序后：");
        PrintArray(arr3);

        Console.WriteLine();

        // 三数取中版本
        int[] arr4 = { 38, 65, 97, 76, 13, 27, 49 };
        Console.Write("三数取中 - 排序前：");
        PrintArray(arr4);
        QuickSortMedianOfThree(arr4, 0, arr4.Length - 1);
        Console.Write("三数取中 - 排序后：");
        PrintArray(arr4);
    }
}

复杂度分析

指标复杂度说明
最好时间O(n log n)每次 pivot 恰好把数组分成相等的两半
最坏时间O(n²)每次 pivot 是最大或最小值（已排序/逆序数组）
平均时间O(n log n)随机数据下的期望复杂度
空间复杂度O(log n)递归调用栈深度，最坏 O(n)
稳定性不稳定分区操作可能改变相等元素的相对顺序

通俗解释：

  • 最好情况：每次 pivot 都是中位数，把数组分成两半，递归深度 log n，每层处理 n 个元素
  • 最坏情况：每次 pivot 都是极值（如已排序数组选第一个），递归 n 层，变成 O(n²)
  • 如何避免最坏情况：随机选 pivot 或三数取中，使最坏情况几乎不可能出现
  • 空间：虽然是原地排序，但递归调用需要栈空间

易错点

  1. 递归边界遗漏：必须判断 left < right，否则无限递归
  2. Lomuto 和 Hoare 递归调用方式不同：
    // Lomuto：pivotIndex 位置已确定，不参与后续递归
QuickSort(arr, left, pivotIndex - 1);
QuickSort(arr, pivotIndex + 1, right);

// Hoare：p 位置的元素可能不是 pivot，需要包含在左半部分
QuickSort(arr, left, p);
QuickSort(arr, p + 1, right);
  3. 已排序数组导致栈溢出：朴素版本对有序数组退化为 O(n²)，递归深度 O(n)，可能栈溢出
  4. pivot 选择不当：始终选第一个或最后一个元素，遇到有序数据就退化
  5. 分区时相等元素处理不当：如果数组中有大量重复元素，需要用三路分区（Dutch National Flag）

记忆口诀

选个基准分两堆，小的左边大右推。递归分治层层拆，平均效率 n log n。

面试常问点

  1. 快速排序的平均时间复杂度是多少？最坏情况呢？

    • 平均 O(n log n)，最坏 O(n²)（当 pivot 每次选到极值时）

  2. 如何避免快速排序的最坏情况？

    • 随机选择 pivot（最简单有效）
    • 三数取中（取 left、mid、right 的中间值）
    • 对于大量重复元素，使用三路分区

  3. 快速排序是稳定排序吗？

    • 不稳定。分区操作中的交换可能改变相等元素的相对顺序

  4. Lomuto 分区和 Hoare 分区有什么区别？

    • Lomuto：单向扫描，简单但交换次数多；Hoare：双向扫描，交换次数少，实际更快
    • Hoare 分区的递归调用方式与 Lomuto 不同，需要注意

  5. 快速排序和归并排序怎么选？

    • 内存敏感选快排（O(log n) vs O(n)）
    • 需要稳定性选归并
    • 需要保证最坏时间选归并或堆排
    • 一般情况选快排（常数因子小，缓存友好）

  6. 快排的空间复杂度是多少？

    • 平均 O(log n)（递归栈深度），最坏 O(n)。可以通过尾递归优化始终保持 O(log n)
