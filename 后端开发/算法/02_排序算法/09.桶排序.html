桶排序

算法定位

桶排序（Bucket Sort）属于非比较排序算法，是计数排序的泛化版本。

它解决的问题是：当数据分布较为均匀时，通过把元素分散到若干个"桶"中，每个桶内单独排序，再将所有桶的结果合并，达到接近线性时间的排序效果。

桶排序是一种分治思想的排序，核心在于"分桶"策略。

一句话理解

把数据按范围分到不同的桶里，每个桶内部分别排序，最后按桶的顺序把数据拼起来。

生活化比喻

假设你有一堆学生的考试卷子（成绩 0~100），要按分数排序：

  • 准备 10 个箱子，贴上标签：09分、1019分、2029分、……、90100分
  • 把每张卷子按分数扔到对应的箱子里
  • 在每个箱子内部，把卷子按分数排好
  • 最后从第一个箱子开始，按顺序把所有卷子取出来

这就是桶排序——先按大类分桶，再桶内精排，最后合并。

核心思想

  1. 确定桶数量：根据数据范围和数据量，确定需要多少个桶
  2. 分桶：把每个元素根据值映射到对应的桶中
  3. 桶内排序：对每个桶内部进行排序（可以用插入排序、快排等）
  4. 合并：按桶的顺序，依次取出所有元素

为什么会想到这种方法？ 如果数据均匀分布，分桶后每个桶的数据量很少，桶内排序代价小，整体效率就很高。

图解推演

以数组 [0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51] 为例（7个 0~1 之间的小数）：

原始数组：[0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51]
选择 5 个桶，桶范围各 0.2

=== 第 1 步：分桶 ===

桶的范围：
  桶0：[0.0, 0.2)
  桶1：[0.2, 0.4)
  桶2：[0.4, 0.6)
  桶3：[0.6, 0.8)
  桶4：[0.8, 1.0)

分配结果：
  桶0：[]              （空桶）
  桶1：[0.32, 0.33, 0.37]
  桶2：[0.42, 0.52, 0.47, 0.51]
  桶3：[]              （空桶）
  桶4：[]              （空桶）

=== 第 2 步：桶内排序 ===

  桶0：[]
  桶1：[0.32, 0.33, 0.37]  ← 已有序
  桶2：[0.42, 0.47, 0.51, 0.52]  ← 排序后
  桶3：[]
  桶4：[]

=== 第 3 步：合并所有桶 ===

结果：[] + [0.32, 0.33, 0.37] + [0.42, 0.47, 0.51, 0.52] + [] + []
    = [0.32, 0.33, 0.37, 0.42, 0.47, 0.51, 0.52] ✓

执行步骤

  1. 确定桶的数量（通常取数组长度或 sqrt(n)）
  2. 确定每个桶的范围（(max - min) / bucketCount）
  3. 遍历数组，将每个元素放入对应的桶中
  4. 对每个非空桶进行排序（通常用插入排序）
  5. 按桶的顺序，依次将桶中的元素取出，放回原数组

C# 实现

using System;
using System.Collections.Generic;

class BucketSortDemo
{
    /// <summary>
    /// 桶排序 - 处理 [0, 1) 范围内的浮点数
    /// 经典实现，适合均匀分布的小数
    /// </summary>
    static void BucketSortFloat(double[] arr)
    {
        int n = arr.Length;
        if (n <= 1) return;

        // 创建 n 个桶
        List<double>[] buckets = new List<double>[n];
        for (int i = 0; i < n; i++)
        {
            buckets[i] = new List<double>();
        }

        // 将元素分配到桶中
        // 元素值 * n 就是桶的编号
        foreach (double num in arr)
        {
            int bucketIndex = (int)(num * n);
            // 处理边界情况：值恰好等于 1.0
            if (bucketIndex >= n) bucketIndex = n - 1;
            buckets[bucketIndex].Add(num);
        }

        // 对每个桶内部排序（使用 List 自带排序，底层是插入排序/快排）
        foreach (var bucket in buckets)
        {
            bucket.Sort();
        }

        // 合并所有桶
        int index = 0;
        foreach (var bucket in buckets)
        {
            foreach (double num in bucket)
            {
                arr[index++] = num;
            }
        }
    }

    /// <summary>
    /// 桶排序 - 处理任意整数范围
    /// 通用版本，支持负数
    /// </summary>
    static void BucketSortInt(int[] arr)
    {
        int n = arr.Length;
        if (n <= 1) return;

        // 找最大值和最小值
        int min = arr[0], max = arr[0];
        foreach (int num in arr)
        {
            if (num < min) min = num;
            if (num > max) max = num;
        }

        // 如果所有元素相同，直接返回
        if (min == max) return;

        // 确定桶的数量（取数组长度或 sqrt(n)）
        int bucketCount = Math.Max(1, (int)Math.Sqrt(n));
        double bucketRange = (double)(max - min + 1) / bucketCount;

        // 创建桶
        List<int>[] buckets = new List<int>[bucketCount];
        for (int i = 0; i < bucketCount; i++)
        {
            buckets[i] = new List<int>();
        }

        // 分桶
        foreach (int num in arr)
        {
            int bucketIndex = (int)((num - min) / bucketRange);
            // 防止最大值落到范围外
            if (bucketIndex >= bucketCount) bucketIndex = bucketCount - 1;
            buckets[bucketIndex].Add(num);
        }

        // 桶内排序（使用插入排序，适合小数据量）
        foreach (var bucket in buckets)
        {
            InsertionSort(bucket);
        }

        // 合并所有桶
        int index = 0;
        foreach (var bucket in buckets)
        {
            foreach (int num in bucket)
            {
                arr[index++] = num;
            }
        }
    }

    /// <summary>
    /// 对 List 进行插入排序
    /// 桶内元素通常较少，插入排序效率高
    /// </summary>
    static void InsertionSort(List<int> list)
    {
        for (int i = 1; i < list.Count; i++)
        {
            int key = list[i];
            int j = i - 1;

            while (j >= 0 && list[j] > key)
            {
                list[j + 1] = list[j];
                j--;
            }

            list[j + 1] = key;
        }
    }

    /// <summary>
    /// 桶排序 - 用于演示的详细版本（带日志输出）
    /// </summary>
    static void BucketSortVerbose(int[] arr)
    {
        int n = arr.Length;
        if (n <= 1) return;

        int min = arr[0], max = arr[0];
        foreach (int num in arr)
        {
            if (num < min) min = num;
            if (num > max) max = num;
        }

        int bucketCount = 5; // 固定 5 个桶方便演示
        double bucketRange = (double)(max - min + 1) / bucketCount;

        Console.WriteLine($"  范围：[{min}, {max}]，桶数：{bucketCount}，每桶范围：{bucketRange:F1}");

        List<int>[] buckets = new List<int>[bucketCount];
        for (int i = 0; i < bucketCount; i++)
            buckets[i] = new List<int>();

        foreach (int num in arr)
        {
            int bucketIndex = (int)((num - min) / bucketRange);
            if (bucketIndex >= bucketCount) bucketIndex = bucketCount - 1;
            buckets[bucketIndex].Add(num);
        }

        // 打印分桶结果
        Console.WriteLine("  分桶结果：");
        for (int i = 0; i < bucketCount; i++)
        {
            Console.WriteLine($"    桶{i}: [{string.Join(", ", buckets[i])}]");
        }

        // 桶内排序
        foreach (var bucket in buckets)
            bucket.Sort();

        Console.WriteLine("  桶内排序后：");
        for (int i = 0; i < bucketCount; i++)
        {
            Console.WriteLine($"    桶{i}: [{string.Join(", ", buckets[i])}]");
        }

        // 合并
        int index = 0;
        foreach (var bucket in buckets)
            foreach (int num in bucket)
                arr[index++] = num;
    }

    /// <summary>
    /// 打印数组内容
    /// </summary>
    static void PrintArray(int[] arr)
    {
        Console.WriteLine("[" + string.Join(", ", arr) + "]");
    }

    static void PrintArray(double[] arr)
    {
        Console.WriteLine("[" + string.Join(", ", Array.ConvertAll(arr, x => x.ToString("F2"))) + "]");
    }

    static void Main(string[] args)
    {
        Console.WriteLine("===== 桶排序演示 =====\n");

        // 浮点数版本
        double[] arr1 = { 0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51 };
        Console.Write("浮点数版 - 排序前：");
        PrintArray(arr1);
        BucketSortFloat(arr1);
        Console.Write("浮点数版 - 排序后：");
        PrintArray(arr1);

        Console.WriteLine();

        // 整数版本（带详细输出）
        int[] arr2 = { 29, 25, 3, 49, 9, 37, 21, 43 };
        Console.Write("整数版 - 排序前：");
        PrintArray(arr2);
        BucketSortVerbose(arr2);
        Console.Write("整数版 - 排序后：");
        PrintArray(arr2);

        Console.WriteLine();

        // 通用整数版本
        int[] arr3 = { 78, 17, 39, 26, 72, 94, 21, 12, 23, 68 };
        Console.Write("通用版 - 排序前：");
        PrintArray(arr3);
        BucketSortInt(arr3);
        Console.Write("通用版 - 排序后：");
        PrintArray(arr3);
    }
}

以输入 [23, 11, 35, 17, 28, 42, 5] 手动推演（3 个桶）：

原始数组：[23, 11, 35, 17, 28, 42, 5]
min=5, max=42, range=38
桶数=3，每桶范围 ≈ 12.67

桶范围：
  桶0：[5, 17.67)   即值 5~17
  桶1：[17.67, 30.33) 即值 18~30
  桶2：[30.33, 43)   即值 31~42

--- 分桶 ---
  5  → (5-5)/12.67 = 0 → 桶0
  11 → (11-5)/12.67 = 0 → 桶0
  17 → (17-5)/12.67 = 0 → 桶0
  23 → (23-5)/12.67 = 1 → 桶1
  28 → (28-5)/12.67 = 1 → 桶1
  35 → (35-5)/12.67 = 2 → 桶2
  42 → (42-5)/12.67 = 2 → 桶2

  桶0：[5, 11, 17]
  桶1：[23, 28]
  桶2：[35, 42]

--- 桶内排序 ---
  桶0：[5, 11, 17]   ← 已有序
  桶1：[23, 28]       ← 已有序
  桶2：[35, 42]       ← 已有序

--- 合并 ---
  [5, 11, 17] + [23, 28] + [35, 42]
= [5, 11, 17, 23, 28, 35, 42] ✓

复杂度分析

指标复杂度说明
最好时间O(n + k)数据均匀分布，每个桶只有 1~2 个元素
最坏时间O(n²)所有元素落入同一个桶（退化为桶内排序的复杂度）
平均时间O(n + n²/k + k)k 为桶数，数据均匀时约 O(n + k)
空间复杂度O(n + k)桶的空间
稳定性取决于桶内排序算法桶内用稳定排序则整体稳定

通俗解释：

  • 理想情况：n 个元素均匀分到 n 个桶，每个桶 1 个元素，无需排序，直接合并，O(n)
  • 最坏情况：所有元素都落入一个桶，桶内排序退化为 O(n²)（如果用插入排序）
  • 关键因素：数据分布越均匀，桶排序效果越好

易错点

  1. 桶编号计算越界：当元素值等于最大值时，桶编号可能等于桶数量，需要 min(index, bucketCount - 1)
  2. 桶数量选择不当：桶太少退化为普通排序，桶太多浪费空间
  3. 忽略数据分布：数据严重偏斜时桶排序效率低下
  4. 空桶处理：合并时需要跳过空桶
  5. 浮点数精度：桶边界计算时浮点除法可能产生精度问题

特征桶排序计数排序基数排序

记忆口诀

按值分桶各排序，均匀分布效率高。桶多浪费桶少慢，数据分布是关键。

面试常问点

  1. 桶排序的时间复杂度取决于什么？

    • 取决于数据分布和桶的数量。均匀分布时 O(n+k)，最坏 O(n²)

  2. 桶排序和计数排序有什么关系？

    • 计数排序是桶排序的特殊情况：每个桶只对应一个值。桶排序更通用，每个桶对应一个范围

  3. 桶排序适合什么样的数据？

    • 数据分布均匀（或接近均匀），且数据范围已知。例如：0~1 之间的小数、已知范围的整数

  4. 桶排序是稳定的吗？

    • 如果桶内使用稳定排序算法（如插入排序），且按顺序合并，则整体是稳定的

  5. 如何选择桶的数量？

    • 常见策略：桶数 = 数组长度 n，或 sqrt(n)
    • 桶数越多，每个桶的元素越少，但空间开销越大
    • 需要在时间和空间之间权衡
