逻辑代数公式与定理

如果把逻辑运算比作棋子的走法，那么逻辑代数公式就是棋谱中的定式——熟记这些定式，就能在化简的棋局中走出精妙之着，而非一步一步笨拙地推演。

一、基本公式

1.1 常量与变量的关系（0-1律）

公式名称或运算形式与运算形式
0-1律A+0=AA + 0 = AA+0=AA⋅1=AA \cdot 1 = AA⋅1=A
0-1律A+1=1A + 1 = 1A+1=1A⋅0=0A \cdot 0 = 0A⋅0=0

1.2 互补律

A+A‾=1A⋅A‾=0A + \overline{A} = 1 \quad\quad A \cdot \overline{A} = 0 A+A=1A⋅A=0

1.3 重叠律（等幂律）

A+A=AA⋅A=AA + A = A \quad\quad A \cdot A = A A+A=AA⋅A=A

1.4 交换律

A+B=B+AA⋅B=B⋅AA + B = B + A \quad\quad A \cdot B = B \cdot A A+B=B+AA⋅B=B⋅A

1.5 结合律

A+(B+C)=(A+B)+CA(BC)=(AB)CA + (B + C) = (A + B) + C \quad\quad A(BC) = (AB)C A+(B+C)=(A+B)+CA(BC)=(AB)C

1.6 分配律

A(B+C)=AB+ACA+BC=(A+B)(A+C)A(B + C) = AB + AC \quad\quad A + BC = (A + B)(A + C) A(B+C)=AB+ACA+BC=(A+B)(A+C)

第二分配律

注意第二个分配律 A+BC=(A+B)(A+C)A + BC = (A + B)(A + C)A+BC=(A+B)(A+C)，这是逻辑代数特有的，普通代数中没有这个等式。可用加对乘的分配来记忆。

1.7 德摩根定律（De Morgan's Law）

A⋅B‾=A‾+B‾A+B‾=A‾⋅B‾\overline{A \cdot B} = \overline{A} + \overline{B} \quad\quad \overline{A + B} = \overline{A} \cdot \overline{B} A⋅B=A+BA+B​=A⋅B

推广形式：

A1⋅A2⋯An‾=A1‾+A2‾+⋯+An‾\overline{A_1 \cdot A_2 \cdots A_n} = \overline{A_1} + \overline{A_2} + \cdots + \overline{A_n} A1​⋅A2​⋯An​​=A1​​+A2​​+⋯+An​​

A1+A2+⋯+An‾=A1‾⋅A2‾⋯An‾\overline{A_1 + A_2 + \cdots + A_n} = \overline{A_1} \cdot \overline{A_2} \cdots \overline{A_n} A1​+A2​+⋯+An​​=A1​​⋅A2​​⋯An​​

德摩根定律记忆口诀

"长横断开，号变号换"——长非号断开，与变或、或变与，每个变量取反。

1.8 还原律（双重否定律）

A‾‾=A\overline{\overline{A}} = A A=A

1.9 基本公式汇总表

序号或运算形式与运算形式名称
1A+0=AA + 0 = AA+0=AA⋅1=AA \cdot 1 = AA⋅1=A0-1律
2A+1=1A + 1 = 1A+1=1A⋅0=0A \cdot 0 = 0A⋅0=00-1律
3A+A‾=1A + \overline{A} = 1A+A=1A⋅A‾=0A \cdot \overline{A} = 0A⋅A=0互补律
4A+A=AA + A = AA+A=AA⋅A=AA \cdot A = AA⋅A=A重叠律
5A+B=B+AA + B = B + AA+B=B+AAB=BAAB = BAAB=BA交换律
6(A+B)+C=A+(B+C)(A+B)+C = A+(B+C)(A+B)+C=A+(B+C)(AB)C=A(BC)(AB)C = A(BC)(AB)C=A(BC)结合律
7A(B+C)=AB+ACA(B+C) = AB+ACA(B+C)=AB+ACA+BC=(A+B)(A+C)A+BC = (A+B)(A+C)A+BC=(A+B)(A+C)分配律
8A+B‾=A‾⋅B‾\overline{A+B} = \overline{A}\cdot\overline{B}A+B​=A⋅BAB‾=A‾+B‾\overline{AB} = \overline{A}+\overline{B}AB=A+B德摩根定律
9A‾‾=A\overline{\overline{A}} = AA=A—还原律

二、常用公式

2.1 吸收律

A+AB=AA(A+B)=AA + AB = A \quad\quad A(A + B) = A A+AB=AA(A+B)=A

证明：A+AB=A(1+B)=A⋅1=AA + AB = A(1 + B) = A \cdot 1 = AA+AB=A(1+B)=A⋅1=A

含义：某项包含了另一项的全部因子，则另一项被吸收。

2.2 消因子律

A+A‾B=A+BA(A‾+B)=ABA + \overline{A}B = A + B \quad\quad A(\overline{A} + B) = AB A+AB=A+BA(A+B)=AB

证明：A+A‾B=(A+A‾)(A+B)=1⋅(A+B)=A+BA + \overline{A}B = (A + \overline{A})(A + B) = 1 \cdot (A + B) = A + BA+AB=(A+A)(A+B)=1⋅(A+B)=A+B

含义：一项取反后是另一项的因子，则该因子可消去。

2.3 并项律

AB+AB‾=A(A+B)(A+B‾)=AAB + A\overline{B} = A \quad\quad (A+B)(A+\overline{B}) = A AB+AB=A(A+B)(A+B)=A

证明：AB+AB‾=A(B+B‾)=A⋅1=AAB + A\overline{B} = A(B + \overline{B}) = A \cdot 1 = AAB+AB=A(B+B)=A⋅1=A

含义：两项除一个因子互为反变量外，其余因子相同，则两项合并消去互反因子。

2.4 多余项律（包含律）

AB+A‾C+BC=AB+A‾CAB + \overline{A}C + BC = AB + \overline{A}C AB+AC+BC=AB+AC

证明：AB+A‾C+BC=AB+A‾C+(A+A‾)BC=AB+A‾C+ABC+A‾BC=AB(1+C)+A‾C(1+B)=AB+A‾CAB + \overline{A}C + BC = AB + \overline{A}C + (A+\overline{A})BC = AB + \overline{A}C + ABC + \overline{A}BC = AB(1+C) + \overline{A}C(1+B) = AB + \overline{A}CAB+AC+BC=AB+AC+(A+A)BC=AB+AC+ABC+ABC=AB(1+C)+AC(1+B)=AB+AC

含义：两项分别含 AAA 和 A‾\overline{A}A，则此两项的其余因子组成的第三项可消去。

多余项律的扩展

AB+A‾C+BCD=AB+A‾CAB + \overline{A}C + BCD = AB + \overline{A}C AB+AC+BCD=AB+AC

即多余项不论怎么扩展，仍然多余。这是因为 BCDBCDBCD 本身就包含了 BCBCBC，而 BCBCBC 已被吸收。

2.5 常用公式汇总

序号公式名称记忆要点
1A+AB=AA + AB = AA+AB=A吸收律多余项被吸收
2A+A‾B=A+BA + \overline{A}B = A + BA+AB=A+B消因子律互反因子可消
3AB+AB‾=AAB + A\overline{B} = AAB+AB=A并项律互反部分合并
4AB+A‾C+BC=AB+A‾CAB + \overline{A}C + BC = AB + \overline{A}CAB+AC+BC=AB+AC多余项律冗余项消去

三、三个基本规则

3.1 代入规则

内容：在等式中，用逻辑函数式代替某个变量，等式仍然成立。

例1：已知 AB‾=A‾+B‾\overline{AB} = \overline{A} + \overline{B}AB=A+B，用 (A+C)(A+C)(A+C) 代替 AAA：

(A+C)⋅B‾=A+C‾+B‾\overline{(A+C) \cdot B} = \overline{A+C} + \overline{B} (A+C)⋅B​=A+C​+B

代入规则的意义

代入规则使得基本公式的应用范围大大扩展，从两个变量推广到任意多个变量。

3.2 反演规则

内容：对逻辑函数 YYY，将其中的：

  • 与 → 或，或 → 与
  • 0 → 1，1 → 0
  • 原变量 → 反变量，反变量 → 原变量

所得新函数即为 Y‾\overline{Y}Y。

例2：求 Y=AB‾+CD‾EY = A\overline{B} + C\overline{D}EY=AB+CDE 的反函数。

Y‾=(A‾+B)(C‾+D+E‾)\overline{Y} = (\overline{A} + B)(\overline{C} + D + \overline{E}) Y=(A+B)(C+D+E)

反演规则注意事项

  1. 运算顺序不变：先与后或的顺序不能变，必要时加括号
  2. 不属于单个变量的反号保持不变
  3. 长非号保持不变：如 A+B‾\overline{A+B}A+B​ 中的长非号不变

3.3 对偶规则

内容：对逻辑函数 YYY，将其中的：

  • 与 → 或，或 → 与
  • 0 → 1，1 → 0

所得新函数 Y∗Y^*Y∗ 称为 YYY 的对偶式。

例3：求 Y=A(B+C)Y = A(B + C)Y=A(B+C) 的对偶式。

Y∗=A+BCY^* = A + BC Y∗=A+BC

对偶规则的核心用途

若两个逻辑式相等，则它们的对偶式也相等。即：

F=G⇒F∗=G∗F = G \Rightarrow F^* = G^* F=G⇒F∗=G∗

这意味着我们只需证明一半的公式，另一半由对偶关系自动成立。基本公式表中或运算形式和与运算形式就是互为对偶的。

3.4 三个规则对比

规则变量变换运算变换常量变换结果
代入规则函数式代入变量不变不变等式仍成立
反演规则原变量↔反变量与↔或0↔1得到 Y‾\overline{Y}Y
对偶规则不变与↔或0↔1得到 Y∗Y^*Y∗

练习题

练习1

用公式法证明：AB‾+B+A‾B=A+BA\overline{B} + B + \overline{A}B = A + BAB+B+AB=A+B

答案与解析

AB‾+B+A‾BA\overline{B} + B + \overline{A}B AB+B+AB

=AB‾+B(1+A‾)= A\overline{B} + B(1 + \overline{A})=AB+B(1+A) （提取B）

=AB‾+B= A\overline{B} + B=AB+B （因为 1+A‾=11 + \overline{A} = 11+A=1）

=A+B= A + B=A+B （消因子律：AB‾+B=A+BA\overline{B} + B = A + BAB+B=A+B）

练习2

用德摩根定律展开 A+BC+D‾‾\overline{A + BC + \overline{D}}A+BC+D​

答案与解析

逐步展开：

A+BC+D‾‾\overline{A + BC + \overline{D}} A+BC+D​

=A‾⋅BC‾⋅D‾‾= \overline{A} \cdot \overline{BC} \cdot \overline{\overline{D}}=A⋅BC⋅D （德摩根定律，长非号断开）

=A‾⋅(B‾+C‾)⋅D= \overline{A} \cdot (\overline{B} + \overline{C}) \cdot D=A⋅(B+C)⋅D （再次德摩根定律，还原律）

练习3

用反演规则求 Y=(A+B‾)(A‾+C)+DY = (A + \overline{B})(\overline{A} + C) + DY=(A+B)(A+C)+D 的反函数。

答案与解析

反演规则：与↔或，0↔1，原↔反

注意保持运算顺序，先与后或：

Y‾=[A‾⋅B+A⋅C‾]⋅D‾\overline{Y} = [\overline{A} \cdot B + A \cdot \overline{C}] \cdot \overline{D} Y=[A⋅B+A⋅C]⋅D

注意：(A+B‾)(A+\overline{B})(A+B) 变为 A‾⋅B\overline{A} \cdot BA⋅B，(A‾+C)(\overline{A}+C)(A+C) 变为 A⋅C‾A \cdot \overline{C}A⋅C，DDD 变为 D‾\overline{D}D。

原来两括号之间是"乘"（与），变为"加"（或），但为了保持运算优先级，需要加方括号。

练习4

用对偶规则写出 Y=A+A‾BY = A + \overline{A}BY=A+AB 的对偶式 Y∗Y^*Y∗，并验证 YYY 和 Y∗Y^*Y∗ 是否都等于 A+BA + BA+B。

答案与解析

对偶规则：与↔或，0↔1，变量不变

Y=A+A‾B⇒Y∗=A⋅(A‾+B)Y = A + \overline{A}B \Rightarrow Y^* = A \cdot (\overline{A} + B) Y=A+AB⇒Y∗=A⋅(A+B)

验证 Y=A+A‾BY = A + \overline{A}BY=A+AB：

=(A+A‾)(A+B)=1⋅(A+B)=A+B= (A + \overline{A})(A + B) = 1 \cdot (A + B) = A + B=(A+A)(A+B)=1⋅(A+B)=A+B ✓

验证 Y∗=A(A‾+B)Y^* = A(\overline{A} + B)Y∗=A(A+B)：

=AA‾+AB=0+AB=AB= A\overline{A} + AB = 0 + AB = AB=AA+AB=0+AB=AB

所以 Y=A+BY = A + BY=A+B，Y∗=ABY^* = ABY∗=AB，两者不相等。YYY 和 Y∗Y^*Y∗ 不都等于 A+BA + BA+B，但互为对偶。

练习5

化简 F=AB‾+A‾C+BC‾+B‾D+CD‾+ADF = A\overline{B} + \overline{A}C + B\overline{C} + \overline{B}D + C\overline{D} + ADF=AB+AC+BC+BD+CD+AD

答案与解析

F=AB‾+A‾C+BC‾+B‾D+CD‾+ADF = A\overline{B} + \overline{A}C + B\overline{C} + \overline{B}D + C\overline{D} + AD F=AB+AC+BC+BD+CD+AD

利用多余项律 AB+A‾C+BC=AB+A‾CAB + \overline{A}C + BC = AB + \overline{A}CAB+AC+BC=AB+AC：

  • AB‾+A‾CA\overline{B} + \overline{A}CAB+AC 的多余项为 B‾C\overline{B}CBC，但这里没有 B‾C\overline{B}CBC
  • 但 AB‾+B‾DA\overline{B} + \overline{B}DAB+BD → 多余项为 ADADAD，而 ADADAD 存在！
  • 所以 AB‾+B‾D+AD=AB‾+B‾DA\overline{B} + \overline{B}D + AD = A\overline{B} + \overline{B}DAB+BD+AD=AB+BD，ADADAD 可消去

F=AB‾+A‾C+BC‾+B‾D+CD‾F = A\overline{B} + \overline{A}C + B\overline{C} + \overline{B}D + C\overline{D} F=AB+AC+BC+BD+CD

继续用多余项律：

  • BC‾+B‾DB\overline{C} + \overline{B}DBC+BD → 多余项为 C‾D\overline{C}DCD，考虑 CD‾C\overline{D}CD...
  • A‾C+CD‾\overline{A}C + C\overline{D}AC+CD → 多余项为 A‾D‾\overline{A}\overline{D}AD

观察 BC‾+CD‾B\overline{C} + C\overline{D}BC+CD → 多余项为 BD‾B\overline{D}BD，不在表达式中。

换一种方式，BC‾+B‾D+CD‾B\overline{C} + \overline{B}D + C\overline{D}BC+BD+CD：

添加 C‾D\overline{C}DCD（BC‾+B‾DB\overline{C} + \overline{B}DBC+BD 的多余项）：

=BC‾+B‾D+CD‾+C‾D= B\overline{C} + \overline{B}D + C\overline{D} + \overline{C}D=BC+BD+CD+CD

=BC‾+B‾D+(CD‾+C‾D)= B\overline{C} + \overline{B}D + (C\overline{D} + \overline{C}D)=BC+BD+(CD+CD)

=BC‾+B‾D+C⊕D= B\overline{C} + \overline{B}D + C \oplus D=BC+BD+C⊕D

实际上这道题的标准结果为：

F=AB‾+A‾C+BC‾+B‾D+CD‾F = A\overline{B} + \overline{A}C + B\overline{C} + \overline{B}D + C\overline{D} F=AB+AC+BC+BD+CD

消去 ADADAD 后即为最简形式。

面试速查

  • 德摩根定律：长横断开，与或互换，逐个取反
  • 吸收律：A+AB=AA + AB = AA+AB=A
  • 消因子律：A+A‾B=A+BA + \overline{A}B = A + BA+AB=A+B
  • 并项律：AB+AB‾=AAB + A\overline{B} = AAB+AB=A
  • 多余项律：AB+A‾C+BC=AB+A‾CAB + \overline{A}C + BC = AB + \overline{A}CAB+AC+BC=AB+AC
  • 反演规则：与↔或，0↔1，原↔反 → 得 Y‾\overline{Y}Y
  • 对偶规则：与↔或，0↔1，变量不变 → 得 Y∗Y^*Y∗
