基本逻辑运算

如果把数字电路比作一场精密的交响乐，那么与、或、非就是三种最基本的音符——它们各自简单，却能组合出无穷的逻辑旋律。

一、三种基本逻辑运算

1.1 与运算（AND）

逻辑含义：所有条件都满足时，结果才成立。"同真则真，有假则假"。

逻辑表达式：Y=A⋅B=ABY = A \cdot B = ABY=A⋅B=AB

逻辑符号：

真值表：

ABY = AB
000
010
100
111

生活中的类比：串联开关——两个开关同时闭合，灯才亮。

// Verilog 与门
assign Y = A & B;

1.2 或运算（OR）

逻辑含义：任一条件满足，结果就成立。"有真则真，同假则假"。

逻辑表达式：Y=A+BY = A + BY=A+B

逻辑符号：

真值表：

ABY = A+B
000
011
101
111

生活中的类比：并联开关——任一开关闭合，灯就亮。

// Verilog 或门
assign Y = A | B;

1.3 非运算（NOT）

逻辑含义：条件取反。"真变假，假变真"。

逻辑表达式：Y=A‾Y = \overline{A}Y=A 或 Y=A′Y = A'Y=A′

逻辑符号：

真值表：

AY = A'
01
10
// Verilog 非门
assign Y = ~A;

1.4 三种基本运算对比

运算表达式口诀逻辑含义
与 ANDY=ABY = ABY=AB同真则真所有条件都满足
或 ORY=A+BY = A+BY=A+B有真则真任一条件满足
非 NOTY=A‾Y = \overline{A}Y=A取反条件取反

二、复合逻辑运算

2.1 与非运算（NAND）

定义：先与后非。Y=AB‾Y = \overline{AB}Y=AB

ABABY = AB‾\overline{AB}AB
0001
0101
1001
1110

与非门的特殊地位

与非门被称为万能门（Universal Gate），因为仅用与非门就可以实现与、或、非三种基本运算。同理，或非门也是万能门。

仅用与非门实现三种基本运算：

// Verilog 与非门
assign Y = ~(A & B);

2.2 或非运算（NOR）

定义：先或后非。Y=A+B‾Y = \overline{A+B}Y=A+B​

ABA+BY = A+B‾\overline{A+B}A+B​

0110
1010

// Verilog 或非门
assign Y = ~(A | B);

2.3 与或非运算（AND-OR-NOT）

定义：先与后或再非。Y=AB+CD‾Y = \overline{AB + CD}Y=AB+CD​

// Verilog 与或非
assign Y = ~(A & B | C & D);

2.4 异或运算（XOR）

定义：两输入不同时输出1，相同时输出0。Y=A⊕B=A‾B+AB‾Y = A \oplus B = \overline{A}B + A\overline{B}Y=A⊕B=AB+AB

ABY = A⊕B
000
011
101
110

异或的记忆

异或——"异则1，同则0"。两输入相异输出1，相同输出0。

异或的重要性质：

  1. A⊕0=AA \oplus 0 = AA⊕0=A（与0异或，不变）
  2. A⊕1=A‾A \oplus 1 = \overline{A}A⊕1=A（与1异或，取反）
  3. A⊕A=0A \oplus A = 0A⊕A=0（自异或为0）
  4. 交换律、结合律成立
// Verilog 异或门
assign Y = A ^ B;

2.5 同或运算（XNOR）

定义：两输入相同时输出1，不同时输出0。Y=A⊙B=A⊕B‾=AB+A‾B‾Y = A \odot B = \overline{A \oplus B} = AB + \overline{A}\overline{B}Y=A⊙B=A⊕B​=AB+AB

ABY = A⊙B
001
010
100
111

同或的记忆

同或——"同则1，异则0"。与异或互为反运算。

// Verilog 同或门
assign Y = A ~^ B;  // 或 assign Y = ~(A ^ B);

运算表达式特征记忆口诀

或非 NORA+B‾\overline{A+B}A+B​全0出1有1出0，全0出1
与或非 AOIAB+CD‾\overline{AB+CD}AB+CD​先与后或再非—

三、逻辑符号

3.1 国标符号与美标符号

逻辑门电路的符号有国标（中国标准GB/T）和美标（ANSI/IEEE）两种常见表示。

逻辑门国标符号特点美标符号特点
与门方框内 &类D形
或门方框内 ≥1类盾形
非门方框后小圆圈三角形+小圆圈
与非门与门+小圆圈D形+小圆圈
或非门或门+小圆圈盾形+小圆圈
异或门方框内 =1类盾形+异或线

国标符号中的标记

  • &：与运算
  • ≥1：或运算（输入≥1时输出1）
  • =1：异或运算（输入恰好=1时输出1）
  • 1：缓冲/非运算
  • 小圆圈表示取反

3.3 正逻辑与负逻辑

  • 正逻辑：高电平 = 1，低电平 = 0（最常用）
  • 负逻辑：高电平 = 0，低电平 = 1

正负逻辑的转换

同一个电路，采用正逻辑是"与门"，采用负逻辑可能变成"或门"。正逻辑的与非门 = 负逻辑的或非门。这就是对偶关系的物理体现。

练习2

证明仅用与非门可以实现或运算 Y=A+BY = A + BY=A+B。

答案与解析

根据德摩根定律：A+B=A‾⋅B‾‾A + B = \overline{\overline{A} \cdot \overline{B}}A+B=A⋅B

实现方法：

  1. 用与非门实现非门：AAA 两端接入与非门 → A⋅A‾=A‾\overline{A \cdot A} = \overline{A}A⋅A=A
  2. 同理 BBB → B‾\overline{B}B
  3. 将 A‾\overline{A}A 和 B‾\overline{B}B 接入与非门 → A‾⋅B‾‾=A+B\overline{\overline{A} \cdot \overline{B}} = A + BA⋅B=A+B
// 仅用与非门实现或门
wire na = ~(A & A);  // 等价于 ~A
wire nb = ~(B & B);  // 等价于 ~B
assign Y = ~(na & nb);  // 等价于 A | B

练习3

已知 A=1A = 1A=1，B=0B = 0B=0，C=1C = 1C=1，求下列逻辑表达式的值：

(1) Y1=AB‾Y_1 = \overline{AB}Y1​=AB
(2) Y2=A⊕BY_2 = A \oplus BY2​=A⊕B
(3) Y3=A+C‾Y_3 = \overline{A + C}Y3​=A+C​
(4) Y4=A⊙CY_4 = A \odot CY4​=A⊙C

答案与解析

(1) Y1=1⋅0‾=0‾=1Y_1 = \overline{1 \cdot 0} = \overline{0} = 1Y1​=1⋅0=0=1

(2) Y2=1⊕0=1Y_2 = 1 \oplus 0 = 1Y2​=1⊕0=1（异则1）

(3) Y3=1+1‾=1‾=0Y_3 = \overline{1 + 1} = \overline{1} = 0Y3​=1+1​=1=0

(4) Y4=1⊙1=1Y_4 = 1 \odot 1 = 1Y4​=1⊙1=1（同则1）

面试速查

  • 三种基本运算：与（同真则真）、或（有真则真）、非（取反）
  • 与非门/或非门是万能门，可替代所有基本门
  • 异或：异则1，同则0；同或：同则1，异则0
  • 异或性质：A⊕0=AA \oplus 0 = AA⊕0=A，A⊕1=A‾A \oplus 1 = \overline{A}A⊕1=A，A⊕A=0A \oplus A = 0A⊕A=0
  • 国标符号：&（与）、≥1（或）、=1（异或）、○（取反）
