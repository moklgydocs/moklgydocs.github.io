化简与分析题

化简与分析如同数字电路的侦探术——公式法与卡诺图是化繁为简的利器，真值表与状态图是洞悉电路行为的放大镜。掌握这些基本功，才能在设计的海洋中游刃有余。

一、逻辑函数化简

1.1 公式法化简

常用公式：

公式名称表达式
互补律A+A‾=1A + \overline{A} = 1A+A=1，A⋅A‾=0A \cdot \overline{A} = 0A⋅A=0
吸收律1A+AB=AA + AB = AA+AB=A
吸收律2A+A‾B=A+BA + \overline{A}B = A + BA+AB=A+B
消因律AB+A‾C+BC=AB+A‾CAB + \overline{A}C + BC = AB + \overline{A}CAB+AC+BC=AB+AC
消项律AB+A‾C+BCD=AB+A‾CAB + \overline{A}C + BCD = AB + \overline{A}CAB+AC+BCD=AB+AC

化简目标

最简与或式的要求：

  1. 乘积项最少
  2. 每个乘积项中变量最少

两个要求有优先级：先满足项数最少，再满足变量数最少。

1.2 卡诺图化简

卡诺图原则：逻辑相邻的格子，其对应的变量取值只有一位不同。

二、逻辑函数化简习题

习题1：公式法化简

化简 Y=ABC‾+AB‾C+A‾BC+ABCY = AB\overline{C} + A\overline{B}C + \overline{A}BC + ABCY=ABC+ABC+ABC+ABC

解：

Y=ABC‾+AB‾C+A‾BC+ABCY = AB\overline{C} + A\overline{B}C + \overline{A}BC + ABC Y=ABC+ABC+ABC+ABC

提取公因子：

=ABC‾+ABC+AB‾C+A‾BC= AB\overline{C} + ABC + A\overline{B}C + \overline{A}BC =ABC+ABC+ABC+ABC

=AB(C‾+C)+AC(B‾+B)+BC(A‾+A)= AB(\overline{C} + C) + AC(\overline{B} + B) + BC(\overline{A} + A) =AB(C+C)+AC(B+B)+BC(A+A)

=AB+AC+BC= AB + AC + BC =AB+AC+BC

再利用消因律 AB+AC+BC=AB+ACAB + AC + BC = AB + ACAB+AC+BC=AB+AC（消去BC）：

Y=AB+AC\boxed{Y = AB + AC} Y=AB+AC​

习题2：公式法化简

化简 Y=AB‾+A‾C+BC‾+CD‾+B‾DY = A\overline{B} + \overline{A}C + B\overline{C} + C\overline{D} + \overline{B}DY=AB+AC+BC+CD+BD

解：

逐步化简：

Y=AB‾+A‾C+BC‾+CD‾+B‾DY = A\overline{B} + \overline{A}C + B\overline{C} + C\overline{D} + \overline{B}D Y=AB+AC+BC+CD+BD

由消因律，AB‾+A‾C+BC‾A\overline{B} + \overline{A}C + B\overline{C}AB+AC+BC：不能直接消

观察 A‾C+CD‾+B‾D\overline{A}C + C\overline{D} + \overline{B}DAC+CD+BD：

由冗余项：A‾C+B‾D+A‾D\overline{A}C + \overline{B}D + \overline{A}DAC+BD+AD 可消 A‾D\overline{A}DAD（但此处无A‾D\overline{A}DAD）

重新分组：

AB‾+B‾D=B‾(A+D)A\overline{B} + \overline{B}D = \overline{B}(A + D)AB+BD=B(A+D)

A‾C+CD‾=C(A‾+D‾)=CAD‾\overline{A}C + C\overline{D} = C(\overline{A} + \overline{D}) = C\overline{AD}AC+CD=C(A+D)=CAD

还有 BC‾B\overline{C}BC

实际上，由消项律 AB‾+A‾C+BC‾=AB‾+A‾CA\overline{B} + \overline{A}C + B\overline{C} = A\overline{B} + \overline{A}CAB+AC+BC=AB+AC（消BC‾B\overline{C}BC，因为AB‾⋅A‾C=0A\overline{B} \cdot \overline{A}C = 0AB⋅AC=0? 不对）

使用消因律：AB‾+BC‾+A‾C=AB‾+A‾CA\overline{B} + B\overline{C} + \overline{A}C = A\overline{B} + \overline{A}CAB+BC+AC=AB+AC（因AB‾A\overline{B}AB含B‾\overline{B}B，BC‾B\overline{C}BC含BBB，A‾C\overline{A}CAC含A‾\overline{A}A，BC‾⋅A‾CB\overline{C} \cdot \overline{A}CBC⋅AC → 需检查冗余）

AB‾A\overline{B}AB的冗余项为BC‾B\overline{C}BC部分中的AC‾A\overline{C}AC，但这里没有。

更直接的化简：原式 = AB‾+A‾C+BC‾+CD‾+B‾DA\overline{B} + \overline{A}C + B\overline{C} + C\overline{D} + \overline{B}DAB+AC+BC+CD+BD

由消因律逐步消去冗余项：

AB‾+BD‾+A‾D=AB‾+A‾DA\overline{B} + B\overline{D} + \overline{A}D = A\overline{B} + \overline{A}DAB+BD+AD=AB+AD 类推

Y=AB‾+CD‾+A‾C+B‾D\boxed{Y = A\overline{B} + C\overline{D} + \overline{A}C + \overline{B}D} Y=AB+CD+AC+BD​

习题6：公式法+卡诺图综合

化简 Y=A‾BC‾D‾+A‾BCD‾+AB‾C‾D+AB‾CD+ABC‾D+ABCDY = \overline{A}B\overline{C}\overline{D} + \overline{A}BC\overline{D} + A\overline{B}\overline{C}D + A\overline{B}CD + AB\overline{C}D + ABCDY=ABCD+ABCD+ABCD+ABCD+ABCD+ABCD

解：

先分组提取公因子：

=A‾BD‾(C‾+C)+AB‾D(C‾+C)+ABD(C‾+C)= \overline{A}B\overline{D}(\overline{C}+C) + A\overline{B}D(\overline{C}+C) + ABD(\overline{C}+C) =ABD(C+C)+ABD(C+C)+ABD(C+C)

=A‾BD‾+AB‾D+ABD= \overline{A}B\overline{D} + A\overline{B}D + ABD =ABD+ABD+ABD

=A‾BD‾+AD(B‾+B)= \overline{A}B\overline{D} + AD(\overline{B}+B) =ABD+AD(B+B)

=A‾BD‾+AD= \overline{A}B\overline{D} + AD =ABD+AD

Y=A‾BD‾+AD\boxed{Y = \overline{A}B\overline{D} + AD} Y=ABD+AD​

习题8：分析译码器应用电路

用3-8译码器74HC138实现 Y1=∑m(1,3,5,7)Y_1 = \sum m(1,3,5,7)Y1​=∑m(1,3,5,7)，Y2=∑m(0,2,4,6)Y_2 = \sum m(0,2,4,6)Y2​=∑m(0,2,4,6)，分析其功能。

解：

Y1=m1+m3+m5+m7=A‾B‾C+A‾BC+AB‾C+ABCY_1 = m_1 + m_3 + m_5 + m_7 = \overline{A}\overline{B}C + \overline{A}BC + A\overline{B}C + ABC Y1​=m1​+m3​+m5​+m7​=ABC+ABC+ABC+ABC

提取公因子：Y1=C(A‾B‾+A‾B+AB‾+AB)=CY_1 = C(\overline{A}\overline{B} + \overline{A}B + A\overline{B} + AB) = CY1​=C(AB+AB+AB+AB)=C

Y2=m0+m2+m4+m6=C‾Y_2 = m_0 + m_2 + m_4 + m_6 = \overline{C} Y2​=m0​+m2​+m4​+m6​=C

面试速查

  • 公式法核心：吸收律（A+AB=AA+AB=AA+AB=A）、消因律（AB+A‾C+BC=AB+A‾CAB+\overline{A}C+BC=AB+\overline{A}CAB+AC+BC=AB+AC）
  • 卡诺图：圈2的幂次方个1，优先大圈，注意四角可圈
  • 无关项（d）：可圈可不圈，以得到最简为原则
  • 时序分析三步曲：驱动方程→状态方程→状态转换表/图
  • 自启动判断：检查所有无效状态是否能回到有效循环
