数制转换

如果把数制比作各国货币，那么数制转换就是汇率换算——虽然面值不同，但价值相等。掌握"汇率"的算法，就能在不同数制间自由穿梭。

一、任意进制转十进制——按权展开法

1.1 基本原理

将任意 R 进制数按权展开求和：

(dn−1dn−2⋯d1d0.d−1d−2⋯ )R=∑idi×Ri(d_{n-1}d_{n-2}\cdots d_1 d_0 . d_{-1} d_{-2}\cdots)_R = \sum_{i} d_i \times R^i (dn−1​dn−2​⋯d1​d0​.d−1​d−2​⋯)R​=i∑​di​×Ri

其中 did_idi​ 为第 iii 位上的数字，RiR^iRi 为该位的权。

1.2 转换流程

1.3 示例

例1：将 (1011.01)2(1011.01)_2(1011.01)2​ 转换为十进制。

1×23+0×22+1×21+1×20+0×2−1+1×2−21 \times 2^3 + 0 \times 2^2 + 1 \times 2^1 + 1 \times 2^0 + 0 \times 2^{-1} + 1 \times 2^{-2} 1×23+0×22+1×21+1×20+0×2−1+1×2−2

=8+0+2+1+0+0.25=11.25= 8 + 0 + 2 + 1 + 0 + 0.25 = 11.25 =8+0+2+1+0+0.25=11.25

例2：将 (2A.4)16(2A.4)_{16}(2A.4)16​ 转换为十进制。

2×161+10×160+4×16−1=32+10+0.25=42.252 \times 16^1 + 10 \times 16^0 + 4 \times 16^{-1} = 32 + 10 + 0.25 = 42.25 2×161+10×160+4×16−1=32+10+0.25=42.25

例3：将 (37.2)8(37.2)_8(37.2)8​ 转换为十进制。

3×81+7×80+2×8−1=24+7+0.25=31.253 \times 8^1 + 7 \times 8^0 + 2 \times 8^{-1} = 24 + 7 + 0.25 = 31.25 3×81+7×80+2×8−1=24+7+0.25=31.25

二、十进制转任意进制

2.1 整数部分——除基取余法

方法：将十进制整数反复除以基数 R，直到商为0，将每次得到的余数逆序排列。

例4：将 (25)10(25)_{10}(25)10​ 转换为二进制。

步骤运算商余数
125 ÷ 2121
212 ÷ 260
36 ÷ 230
43 ÷ 211
51 ÷ 201

逆序读取余数：(25)10=(11001)2(25)_{10} = (11001)_2(25)10​=(11001)2​

2.2 小数部分——乘基取整法

方法：将十进制小数反复乘以基数 R，取整数部分，将小数部分继续乘，直到小数为0或达到所需精度，整数部分正序排列。

例5：将 (0.625)10(0.625)_{10}(0.625)10​ 转换为二进制。

步骤运算整数部分小数部分
10.625 × 2 = 1.2510.25
20.25 × 2 = 0.500.5
30.5 × 2 = 1.010.0

正序读取整数部分：(0.625)10=(0.101)2(0.625)_{10} = (0.101)_2(0.625)10​=(0.101)2​

精度问题

并非所有十进制小数都能精确转换为二进制小数！例如 (0.1)10(0.1)_{10}(0.1)10​ 在二进制中是无限循环小数 0.0001100110011⋯0.0001100110011\cdots0.0001100110011⋯，这是浮点数误差的根本来源。

三、二进制、八进制、十六进制之间的直接转换

3.1 转换关系

由于 8=238 = 2^38=23，16=2416 = 2^416=24，因此：

  • 二 → 八：每3位二进制 → 1位八进制（不足补0）
  • 二 → 十六：每4位二进制 → 1位十六进制（不足补0）
  • 八 → 二：每位八进制 → 3位二进制
  • 十六 → 二：每位十六进制 → 4位二进制

3.2 二进制转八进制示例

例6：将 (11010.1011)2(11010.1011)_2(11010.1011)2​ 转换为八进制。

整数部分从小数点向左，每3位一组：011 010 → 3 2

小数部分从小数点向右，每3位一组：101 100 → 5 4

所以 (11010.1011)2=(32.54)8(11010.1011)_2 = (32.54)_8(11010.1011)2​=(32.54)8​

3.3 二进制转十六进制示例

例7：将 (11010.1011)2(11010.1011)_2(11010.1011)2​ 转换为十六进制。

整数部分从小数点向左，每4位一组：0001 1010 → 1 A

小数部分从小数点向右，每4位一组：1011 → B

所以 (11010.1011)2=(1A.B)16(11010.1011)_2 = (1A.B)_{16}(11010.1011)2​=(1A.B)16​

3.4 八进制与十六进制互转

八进制与十六进制之间的转换通常以二进制为桥梁：

八进制→1位→3位二进制→4位→1位十六进制\text{八进制} \xrightarrow{1位→3位} \text{二进制} \xrightarrow{4位→1位} \text{十六进制} 八进制1位→3位​二进制4位→1位​十六进制

四、数制转换总结

练习题

练习1

将 (10110.11)2(10110.11)_2(10110.11)2​ 转换为十进制。

答案与解析

按权展开：

1×24+0×23+1×22+1×21+0×20+1×2−1+1×2−21 \times 2^4 + 0 \times 2^3 + 1 \times 2^2 + 1 \times 2^1 + 0 \times 2^0 + 1 \times 2^{-1} + 1 \times 2^{-2}1×24+0×23+1×22+1×21+0×20+1×2−1+1×2−2

=16+0+4+2+0+0.5+0.25=22.75= 16 + 0 + 4 + 2 + 0 + 0.5 + 0.25 = 22.75=16+0+4+2+0+0.5+0.25=22.75

所以 (10110.11)2=(22.75)10(10110.11)_2 = (22.75)_{10}(10110.11)2​=(22.75)10​

练习2

将 (100)10(100)_{10}(100)10​ 转换为二进制。

练习3

将 (0.3)10(0.3)_{10}(0.3)10​ 转换为二进制，保留6位小数。

答案与解析

乘2取整：

步骤运算整数部分小数部分
10.3 × 2 = 0.600.6
20.6 × 2 = 1.210.2
30.2 × 2 = 0.400.4

可以看到这是一个无限循环小数，循环部分为 010011...，说明 0.3 无法精确表示为二进制。

练习4

将 (3F2)16(3F2)_{16}(3F2)16​ 转换为十进制。

答案与解析

按权展开：

3×162+15×161+2×1603 \times 16^2 + 15 \times 16^1 + 2 \times 16^03×162+15×161+2×160

=3×256+15×16+2×1= 3 \times 256 + 15 \times 16 + 2 \times 1=3×256+15×16+2×1

=768+240+2=1010= 768 + 240 + 2 = 1010=768+240+2=1010

所以 (3F2)16=(1010)10(3F2)_{16} = (1010)_{10}(3F2)16​=(1010)10​

练习5

将 (537.1)8(537.1)_8(537.1)8​ 转换为十六进制。

答案与解析

先转二进制（1位八进制 → 3位二进制）：

5 → 101，3 → 011，7 → 111，1 → 001

所以 (537.1)8=(101011111.001)2(537.1)_8 = (101 011 111 . 001)_2(537.1)8​=(101011111.001)2​

再转十六进制（4位二进制 → 1位十六进制）：

整数部分：0001 0101 1111 → 1 5 F

小数部分：0010 → 2

所以 (537.1)8=(15F.2)16(537.1)_8 = (15F.2)_{16}(537.1)8​=(15F.2)16​

面试速查

  • R → 十进制：按权展开求和
  • 十进制 → R（整数）：除 R 取余，逆序排列
  • 十进制 → R（小数）：乘 R 取整，正序排列
  • 二 ↔ 八：3位一组
  • 二 ↔ 十六：4位一组
  • 八 ↔ 十六：以二进制为桥梁
  • 注意：并非所有十进制小数都能精确转换为二进制
