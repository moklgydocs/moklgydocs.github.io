深度学习革命（2010–2017）

为什么是 2012 年？

深度学习的数学基础早在 1980 年代就有了，但三个条件同时满足才引爆了革命：

  1. 数据：ImageNet（2009）—— 120 万张标注图片，14 个种类，斯坦福李飞飞团队 3 年手工标注
  2. 算力：GPU 计算 —— NVIDIA CUDA（2006）让 GPU 做通用计算，单卡算力比 CPU 高 10-100 倍
  3. 算法：ReLU 激活函数 + Dropout 正则化 + 更好的初始化方法

缺一不可。缺了任何一个，2012 年就不会发生。

2012 — AlexNet：深度学习元年

人物：Alex Krizhevsky（博士生）、Ilya Sutskever（今 OpenAI 联创）、Geoffrey Hinton（导师）

背景：ImageNet 大规模视觉识别挑战（ILSVRC）是图像识别领域的"奥运会"，每年的最佳成绩是研究界的基准。

2011 年最佳成绩：Top-5 错误率 25.8%（SVM + 手工特征）。

AlexNet 的成绩：Top-5 错误率 15.3%，把第二名甩开 10 个百分点。这不是进步，是降维打击。

AlexNet 的技术创新

输入图片 (224×224×3)
    ↓
卷积层 1 (96 个 11×11 滤波器) → ReLU
    ↓
最大池化 → LRN（局部响应归一化）
    ↓
卷积层 2 (256 个 5×5 滤波器) → ReLU
    ↓
最大池化 → LRN
    ↓
卷积层 3 (384 个 3×3) → ReLU
卷积层 4 (384 个 3×3) → ReLU
卷积层 5 (256 个 3×3) → ReLU
    ↓
最大池化
    ↓
全连接 4096 → Dropout(0.5) → ReLU
全连接 4096 → Dropout(0.5) → ReLU
全连接 1000 → Softmax
    ↓
1000 类分类结果

关键技术点：

技术问题效果
ReLU（替换 Sigmoid）Sigmoid 梯度消失、训练慢训练速度提升 6 倍
Dropout（随机丢弃 50% 神经元）过拟合大幅提升泛化能力
数据增强（随机裁剪、翻转）数据不足相当于扩展数据集 2048 倍
双 GPU 并行单 GPU 内存不足首次大规模 GPU 并行训练
LRN（局部响应归一化）激活值过大模拟神经元侧抑制（后续被 BN 取代）

历史意义：

  • AI 领域数十年的 SVM 主导时代结束
  • NVIDIA 股价开始了长达 10 年的上涨（深度学习 = GPU 需求）
  • 全球顶尖科技公司开始大规模招募深度学习研究者

后记：2013 年，Google 以 4400 万美元收购了 Hinton 和两位学生的公司 DNNresearch（当时只有 3 个人）。这是 AI 领域"人才溢价"时代的开始。

2013 — Word2Vec：词语的几何学

人物：Tomas Mikolov，Google

问题：如何让机器理解词语的意义？

Word2Vec 的洞见：把每个词映射成一个高维向量，让语义相近的词在向量空间里也相近。

# 训练结果（神奇的向量运算）
vec("国王") - vec("男人") + vec("女人") ≈ vec("女王")
vec("巴黎") - vec("法国") + vec("中国") ≈ vec("北京")
vec("最大") - vec("大") + vec("小") ≈ vec("最小")

为什么这有意义：

  • 词向量捕捉到了概念之间的关系
  • 类比关系在向量空间里成了平行四边形
  • 这是语言模型走向"理解"的第一步

影响：

  • NLP 进入"预训练词向量"时代
  • GloVe、FastText 等相继出现
  • 为后来 BERT 的 Contextual Embedding 奠定概念基础

2014 — GAN：AI 开始"创造"

人物：Ian Goodfellow，在一次酒吧聚会后在一个晚上写出了论文

核心思想：让两个神经网络互相博弈：

生成器 G：随机噪声 → 生成假图片
      ↓
判别器 D：真图片/假图片 → 判断真假

训练目标：
- G 的目标：骗过 D
- D 的目标：识破 G

两者不断博弈，G 生成越来越逼真的图片

数学表达（极小极大博弈）：

$$\min_G \max_D V(D,G) = \mathbb{E}{x \sim p{data}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$$

GAN 的进化史：

年份版本突破
2014原始 GAN模糊的小图像，难以训练
2015DCGAN用 CNN 架构，生成清晰人脸
2017WGAN解决训练不稳定、模式崩塌
2018StyleGAN分层控制风格，高分辨率人脸
2019BigGAN有条件生成各类高清图像
2021StyleGAN3消除伪影，视频生成更稳定

应用爆炸：

  • DeepFake（2017）：换脸技术，引发伦理争议
  • thisPersonDoesNotExist.com（2019）：无限生成不存在的人脸
  • 医学图像合成：生成稀有病例训练数据
  • 游戏资产生成：贴图、地形自动生成

意义：AI 第一次从"分类/预测"变成了"创造"。这是生成式 AI 的起点。

2015 — ResNet：解决梯度消失，让网络"无限深"

人物：何恺明（Kaiming He）等，Microsoft Research

问题：网络越深越好——但为什么直接叠层数反而越来越差？

观察：56 层网络在训练集上的误差居然比 20 层更高——这不是过拟合，是欠拟合。深层网络连简单的恒等映射都学不好。

残差连接（Residual Connection / Skip Connection）：

不直接学 H(x)，而是学残差 F(x) = H(x) - x

         x ──────────────────┐
         ↓                   ↓
    卷积层 → ReLU → 卷积层   +  → ReLU
                             ↑
                          加法合并

为什么有效：

  • 反向传播时，梯度可以通过短路连接直接流回浅层
  • 最坏情况：如果 F(x) ≈ 0，整个块就是恒等映射，不会变差
  • 可以堆叠到 150 层以上（甚至 1000 层）

ResNet 的成绩（2015 ImageNet）：

  • Top-5 错误率 3.57%，首次超越人类（5-10%）
  • 同年获 CVPR 最佳论文，引用次数超过 18 万次

ResNet 的遗产：

  • EfficientNet、DenseNet、MobileNet 都基于残差思想
  • ResNet 成为视觉任务的默认 backbone
  • 残差连接的思想后来也影响了 Transformer 的设计

2015 — LSTM 与序列数据的统治

人物：LSTM 由 Hochreiter & Schmidhuber（1997）提出，但在 2014-2016 年达到顶峰

问题：普通 RNN（循环神经网络）有梯度消失——长序列中，早期信息无法传递到后期。

LSTM（长短期记忆网络）的解法：引入"细胞状态"（Cell State）作为高速公路：

           遗忘门         输入门          输出门
             ↓              ↓               ↓
以前的记忆 ─→ × ─→ + ─────────────────→ × → 输出
                   ↑
              新信息 × tanh

三个门控机制：

  • 遗忘门：决定丢弃之前记忆的哪些部分
  • 输入门：决定加入哪些新信息
  • 输出门：决定输出记忆的哪些部分

LSTM 的统治时期（2014-2016）：

  • 机器翻译：Google 将 Gmail 自动回复从规则系统改为 LSTM，准确率大幅提升
  • 语音识别：Apple Siri 2014 年后台换成 LSTM，识别率提升 25%
  • 文本生成："The Unreasonable Effectiveness of Recurrent Neural Networks"（Karpathy，2015）展示了 LSTM 可以自动写 Linux 内核代码、莎士比亚戏剧、奥巴马演讲
  • Google 翻译（2016）：全系统换成 LSTM-based Seq2Seq，BLEU 分数大幅提升

局限：LSTM 是序列处理，天然串行，无法并行，长序列依然有信息损失。2017 年 Transformer 出现后逐渐退出主流。

2016 — AlphaGo：AI 征服围棋，人类最后的智识高地

人物：DeepMind 团队，首席研究员 David Silver

背景：围棋的搜索空间有 10^170 种可能（宇宙原子数量约 10^82）。传统搜索算法对围棋完全无能为力。

专家曾预测：AI 要达到围棋职业水平至少还需要 10 年。

2016 年 3 月，AlphaGo vs 李世石，4:1。

AlphaGo 的三层架构

第一层：监督学习策略网络

  • 输入：当前棋盘状态
  • 训练数据：16 万局人类专家对局，3000 万个落子位置
  • 输出：下一步落子的概率分布
  • 准确率：57%（人类专家之间互猜约 44%）

第二层：强化学习策略网络

  • 用监督学习网络作为初始策略
  • 让 RL 网络和 SL 网络对弈，根据胜负奖励调整
  • 经过数百万局自弈，RL 网络击败 SL 网络的胜率：80%

第三层：价值网络

  • 输入：棋盘状态
  • 输出：当前局面的胜率估计（-1 到 +1）
  • 用于替代耗时的蒙特卡洛模拟

搜索算法：蒙特卡洛树搜索（MCTS）：

策略网络决定"往哪里看"（剪枝）
价值网络 + 快速模拟决定"局面好不好"（评估）
MCTS 平衡探索和利用（UCB 公式）

技术突破的核心

不是蛮力搜索，而是学到了人类围棋直觉。Value Network 在毫秒内给出李世石也会认同的局面评估。

AlphaGo Zero（2017）：

  • 完全不用人类对局数据，从零开始自弈
  • 3 天后击败第一代 AlphaGo，40 天后比 AlphaGo Master 强
  • 发现了人类从未用过的新棋型（"五路跳"等）

意义：

  • 第一次证明 AI 在复杂策略游戏上超越人类顶尖水平
  • 强化学习 + 深度学习的组合成为 AI 研究的新范式
  • DeepMind 的方法论（从游戏到科学）影响了整个领域

2014–2017 — 迁移学习：让知识可以复用

核心思想：在大数据集上预训练的网络可以作为其他任务的起点。

以 ImageNet 预训练为例：

# 在 PyTorch 中，5 行代码实现迁移学习
import torchvision.models as models

model = models.resnet50(pretrained=True)    # 加载 ImageNet 预训练权重

# 冻结浅层（通用特征提取器），只训练最后一层
for param in model.parameters():
    param.requires_grad = False

model.fc = nn.Linear(2048, 2)   # 替换输出层为自己的任务（如猫狗识别）

# 只需要少量数据（几百张）+ 短时间训练（几分钟）就能达到好效果

为什么有效：

  • ResNet 底层学到的是边缘、纹理、颜色等通用视觉特征
  • 这些特征在任何图像任务中都有用
  • 只需微调（Fine-tune）高层，不需要从头学习

迁移学习的范式：

  1. 预训练（Pre-train）：在大数据上训练通用特征
  2. 微调（Fine-tune）：在特定任务上小幅调整参数

这个范式在 NLP 中的终极形态就是 BERT 和 GPT。

2016–2017 — 工具生态的爆发

深度学习框架的战争决定了这个时代的技术栈：

框架发布支持方特点
Theano2010MILA（蒙特利尔大学）最早的神经网络框架，学术界用
Caffe2014UC Berkeley / Facebook计算机视觉专用，工业界用
TensorFlow2015Google静态计算图，工业部署强
Keras2015Francois CholletTF 上层封装，易用
PyTorch2016Facebook动态计算图，研究界最爱
MXNet2015Apache分布式训练强，Amazon 支持

结局：

  • TensorFlow 1.x 因为静态图调试困难，研究界转向 PyTorch
  • TensorFlow 2.x 引入 Eager Execution（和 PyTorch 一样的动态图）但太晚
  • 今天的格局：研究 = PyTorch，生产 = 两者都用

CUDA 生态：

  • cuDNN（2014）：NVIDIA 的深度学习 GPU 加速库
  • 优化了卷积运算，速度提升 3-10 倍
  • 成为所有框架的底层基础

2017 — 图像到达"实用"水平

到 2017 年，计算机视觉已经达到：

任务人类水平AI 水平（2017）
ImageNet 分类~5% 错误率2.25% 错误率
人脸识别~1% 错误率<0.1% 错误率
皮肤癌诊断专业皮肤科医生与医生持平（斯坦福 2017 研究）
眼底糖尿病视网膜病变眼科专家超过平均眼科医生

工业落地：

  • 人脸解锁：iPhone X Face ID（2017）
  • 无人驾驶感知层：Tesla Autopilot、Waymo
  • 安防监控：商汤、旷视的人脸识别部署
  • 医学影像：肺结节检测、病理切片分析

这个时代的教训

成功的共同元素

每一次突破都有相同的结构：

  1. 站在巨人肩膀上：AlexNet 用了 LeNet 的 CNN 思想，ResNet 用了 AlexNet 的 ReLU
  2. 数据 × 算力 × 算法的临界点：ImageNet 数据 + GPU 算力 + 新技巧 = AlexNet
  3. 一个关键洞见：残差连接解决梯度消失，GAN 用对抗博弈实现生成

遗留问题（为 Transformer 的出现埋下伏笔）

  1. RNN/LSTM 无法并行：序列处理天然串行，长序列训练慢
  2. 长距离依赖：即使 LSTM，超过几百 token 后信息还是衰减
  3. 特征工程没有完全消失：很多任务还需要人工设计输入特征
  4. 可解释性缺失：模型为什么做这个决定？没有人能解释

这些问题促使了 Transformer 的诞生。

这个时代的遗产

技术今天的形态
CNN（AlexNet 之后）EfficientNet、ConvNeXt，视觉任务的基础
残差连接（ResNet）几乎所有现代网络都用跳跃连接
GANStable Diffusion 的判别器、StyleGAN
强化学习 + DLChatGPT 的 RLHF 核心机制
迁移学习范式预训练 + 微调是今天 LLM 的基本模式
GPU 计算NVIDIA 市值从 1000 亿到 3 万亿美元

深度学习革命证明了一件事：规模 + 数据 + 正确的架构，可以涌现出惊人的智能。 这个洞见在大语言模型时代被推到了极致。
