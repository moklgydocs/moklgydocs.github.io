供应链协同模式

VMI (Vendor Managed Inventory)

供应商管理库存模式，供应商基于共享的销售和库存数据自主决定补货时机和数量。

VMI运作流程:
1. 买方共享: 销售数据、库存水位、预测信息
2. 供应商决策: 基于数据确定补货量和时机
3. 供应商执行: 安排生产和配送
4. 信息反馈: 实际销售与预测对比
5. 持续优化: 调整预测和补货策略

VMI实施关键：

要素要求难点
数据共享实时、准确、完整数据接口、信任
预测能力供应商具备预测分析能力技术门槛
补货权限供应商自主决策补货参数权责划分
绩效考核服务水平、库存周转指标设计
利益分配库存节约共享谈判博弈

CPFR (Collaborative Planning, Forecasting and Replenishment)

协同计划、预测与补货，是最高级别的供应链协同模式。

CPFR四阶段流程:
1. 战略与计划: 共同制定商业计划、品类目标
2. 需求与供应管理: 协同预测、识别异常
3. 执行: 下单、生产、配送、收货
4. 分析: 绩效评估、持续改进

CPFR异常管理：

def identify_cpfr_exceptions(
    supplier_forecast: list,
    buyer_forecast: list,
    tolerance: float = 0.15,
) -> list:
    """
    识别供需预测的异常差异

    Args:
        supplier_forecast: 供应商预测序列
        buyer_forecast: 买方预测序列
        tolerance: 容差比例

    Returns:
        异常列表
    """
    exceptions = []
    for i, (sf, bf) in enumerate(zip(supplier_forecast, buyer_forecast)):
        if bf == 0 and sf == 0:
            continue
        base = max(abs(bf), abs(sf), 1)
        diff_ratio = abs(sf - bf) / base
        if diff_ratio > tolerance:
            exceptions.append({
                "period": i,
                "supplier_forecast": sf,
                "buyer_forecast": bf,
                "deviation": round(diff_ratio, 3),
                "action": "review" if diff_ratio < 0.3 else "escalate",
            })
    return exceptions

SRM (Supplier Relationship Management)

供应商关系管理，通过系统化的供应商评估和发展提升供应链整体效率。

SRM核心流程：

  1. 供应商发现与准入
  2. 供应商评估与分级
  3. 采购协同(询价/报价/订单/交付)
  4. 绩效监控与反馈
  5. 供应商发展与淘汰

import numpy as np
from pydantic import BaseModel, Field
from typing import List, Optional, Dict


class SupplierScore(BaseModel):
    """供应商评分项"""
    quality_score: float = Field(..., ge=0, le=100, description="质量评分")
    price_score: float = Field(..., ge=0, le=100, description="价格评分")

    service_score: float = Field(..., ge=0, le=100, description="服务评分")

class SupplierEvaluationRequest(BaseModel):
    """供应商评估请求"""
    supplier_id: str = Field(..., description="供应商ID")
    supplier_name: str = Field(..., description="供应商名称")
    scores: SupplierScore = Field(..., description="各维度评分")
    weights: Optional[Dict[str, float]] = Field(default=None, description="权重配置")
    quality_metrics: Optional[Dict[str, float]] = Field(default=None, description="质量明细")
    price_metrics: Optional[Dict[str, float]] = Field(default=None, description="价格明细")
    delivery_metrics: Optional[Dict[str, float]] = Field(default=None, description="交期明细")


class SupplierEvaluationResponse(BaseModel):
    """供应商评估响应"""
    supplier_id: str
    supplier_name: str
    total_score: float
    grade: str
    quality_score: float
    price_score: float
    delivery_score: float
    service_score: float
    risk_score: float

class SupplierEvaluator:
    """供应商评估引擎"""

    DEFAULT_WEIGHTS = {
        "quality": 0.30,
        "price": 0.25,
        "delivery": 0.25,
        "service": 0.10,
        "risk": 0.10,
    }

    GRADE_THRESHOLDS = {
        "A": 90, "B": 80, "C": 70, "D": 60,
    }

    def evaluate(self, req: SupplierEvaluationRequest) -> SupplierEvaluationResponse:
        """评估供应商"""
        weights = req.weights or self.DEFAULT_WEIGHTS
        scores = req.scores

        # 加权总分
        total = (
            scores.quality_score * weights.get("quality", 0.30)
            + scores.price_score * weights.get("price", 0.25)
            + scores.delivery_score * weights.get("delivery", 0.25)
            + scores.service_score * weights.get("service", 0.10)
            + scores.risk_score * weights.get("risk", 0.10)
        )

        # 评级
        grade = self._calculate_grade(total)

        # 建议
        recommendations = self._generate_recommendations(scores, total)

        return SupplierEvaluationResponse(
            supplier_id=req.supplier_id,
            supplier_name=req.supplier_name,
            total_score=round(total, 1),
            grade=grade,
            quality_score=scores.quality_score,
            price_score=scores.price_score,
            delivery_score=scores.delivery_score,
            service_score=scores.service_score,
            risk_score=scores.risk_score,
            recommendations=recommendations,
        )

    def _calculate_grade(self, score: float) -> str:
        """计算供应商等级"""
        for grade, threshold in self.GRADE_THRESHOLDS.items():
            if score >= threshold:
                return grade
        return "E"

    def _generate_recommendations(self, scores: SupplierScore, total: float) -> List[str]:
        """生成改进建议"""
        recs = []
        if scores.quality_score < 70:
            recs.append("质量评分偏低，建议加强来料检验并要求供应商提供改进计划")
        if scores.price_score < 70:
            recs.append("价格竞争力不足，建议引入替代供应商竞价或协商降本方案")
        if scores.delivery_score < 70:
            recs.append("交期表现不稳定，建议设定交付SLA并建立预警机制")
        if scores.service_score < 60:
            recs.append("服务水平低于预期，建议评估是否需要更换供应商")
        if scores.risk_score < 60:
            recs.append("风险评分偏低，建议制定备选供应商计划")
        if total >= 90:
            recs.append("综合表现优秀，建议纳入战略合作供应商")
        if not recs:
            recs.append("表现良好，建议持续监控并定期评估")
        return recs

    def compare_suppliers(
        self,
        evaluations: List[SupplierEvaluationRequest],
        weights: Optional[Dict[str, float]] = None,
    ) -> List[Dict]:
        """对比多个供应商"""
        results = []
        for req in evaluations:
            if weights:
                req.weights = weights
            result = self.evaluate(req)
            results.append({
                "supplier_id": result.supplier_id,
                "supplier_name": result.supplier_name,
                "total_score": result.total_score,
                "grade": result.grade,
                "quality": result.quality_score,
                "price": result.price_score,
                "delivery": result.delivery_score,
            })
        return sorted(results, key=lambda x: x["total_score"], reverse=True)

采购优化

经济批量 (EOQ) 在采购中的应用

最优采购批量 Q* = sqrt(2 * D * S / H)

其中:
D = 年需求量
S = 每次采购的固定成本(订单处理、运输等)
H = 单位年持有成本

最优采购次数 N* = D / Q*
最优采购周期 T* = 365 / N*

联合采购

多个SKU从同一供应商采购时，可通过联合订购降低总订货成本。

def joint_replenishment_optimizer(
    items: list,
    ordering_cost_major: float,
    ordering_cost_minor: float,
    holding_cost_rate: float,
) -> dict:
    """
    联合采购优化

    使用共同周期法: 所有商品在共同周期T的整数倍时间订货

    Args:
        items: [{"id": str, "annual_demand": float, "unit_cost": float}, ...]
        ordering_cost_major: 主要订货成本(固定)
        ordering_cost_minor: 每增加一个SKU的边际订货成本
        holding_cost_rate: 年持有成本率

    Returns:
        最优共同周期和各商品的采购计划
    """
    n = len(items)
    # 计算各商品的独立EOQ周期
    for item in items:
        D = item["annual_demand"]
        H = item["unit_cost"] * holding_cost_rate
        S = ordering_cost_major + ordering_cost_minor
        if H > 0 and D > 0:
            item["eoq"] = np.sqrt(2 * D * S / H)
            item["eoq_cycle_days"] = 365 * item["eoq"] / D
        else:
            item["eoq"] = 0
            item["eoq_cycle_days"] = 365

    # 共同周期法求解
    # 总成本 TC(T) = (S_major + n * S_minor) / T + T * Σ(D_i * H_i) / 2
    sum_dh = sum(item["annual_demand"] * item["unit_cost"] * holding_cost_rate for item in items)
    total_S = ordering_cost_major + n * ordering_cost_minor

    if sum_dh > 0:
        optimal_T_days = 365 * np.sqrt(2 * total_S / sum_dh) / 365
        optimal_T_days = np.sqrt(2 * total_S / sum_dh) * 365 / 365
        # 修正: T(年) = sqrt(2 * S / sum(D_i * H_i))
        optimal_T_years = np.sqrt(2 * total_S / sum_dh)
        optimal_T_days = optimal_T_years * 365
    else:
        optimal_T_days = 30

    # 各商品在共同周期内的采购量
    plan = []
    for item in items:
        qty = item["annual_demand"] * optimal_T_years
        plan.append({
            "item_id": item["id"],
            "order_quantity": round(qty, 0),
            "cycle_days": round(optimal_T_days, 1),
        })

    return {
        "common_cycle_days": round(optimal_T_days, 1),
        "total_ordering_cost_per_year": round(total_S / optimal_T_years if optimal_T_years > 0 else 0, 2),
        "total_holding_cost_per_year": round(sum_dh * optimal_T_years / 2, 2),
        "items_plan": plan,
    }

生产排程

Job Shop调度

Job Shop是最一般的生产调度问题，每个工件在各机器上的加工顺序可以不同。

问题定义:
- n个工件(J1, J2, ..., Jn)
- m台机器(M1, M2, ..., Mm)
- 每个工件有指定的加工路径和加工时间
- 目标: 最小化总完工时间(makespan)

这是一个NP-hard问题，常用启发式/元启发式方法求解

Flow Shop调度

Flow Shop中所有工件的加工路线相同(均经过M1→M2→...→Mm)。

NEH启发式算法(经典Flow Shop调度):
1. 按各工件总加工时间降序排列
2. 依次将工件插入到最佳位置
3. 每次插入时评估所有可能位置，选择makespan最小的

排程方法对比

方法类型适用规模求解质量速度
SPT/EDD规则调度规则任意一般极快
NEH启发式构造性100+工件较好快
遗传算法元启发式50-200好中
模拟退火元启发式50-200好中
分支定界精确<20工件最优慢

VRP求解示例

import numpy as np
from typing import List, Tuple, Dict


class CVRPSolver:
    """带容量约束的车辆路径问题求解器"""

    def __init__(
        self,
        depot: Tuple[float, float],
        customers: List[Tuple[float, float]],
        demands: List[float],
        capacity: float,
    ):
        self.depot = depot
        self.customers = customers
        self.demands = demands
        self.capacity = capacity
        self.n = len(customers)
        self.dist_matrix = self._build_distance_matrix()

    def _build_distance_matrix(self) -> np.ndarray:
        """构建距离矩阵"""
        points = [self.depot] + self.customers
        n = len(points)
        dist = np.zeros((n, n))
        for i in range(n):
            for j in range(n):
                dist[i][j] = np.sqrt(
                    (points[i][0] - points[j][0]) ** 2 + (points[i][1] - points[j][1]) ** 2
                )
        return dist

    def solve_savings(self) -> List[List[int]]:
        """
        Clarke-Wright节约算法求解CVRP

        Returns:
            路线列表，每条路线为客户索引列表(0-indexed)
        """
        # 初始解: 每个客户单独一条路线
        routes = [[i] for i in range(self.n)]
        route_loads = [self.demands[i] for i in range(self.n)]

        # 计算所有客户对的节约值
        savings = []
        for i in range(self.n):
            for j in range(i + 1, self.n):
                # 节约值 = d(0,i) + d(0,j) - d(i,j)
                save = self.dist_matrix[0][i + 1] + self.dist_matrix[0][j + 1] - self.dist_matrix[i + 1][j + 1]
                savings.append((save, i, j))

        savings.sort(reverse=True)

        # 合并路线
        route_of = {i: i for i in range(self.n)}

        for save, i, j in savings:
            ri = route_of[i]
            rj = route_of[j]
            if ri == rj:
                continue

            # 检查合并后是否超容量
            if route_loads[ri] + route_loads[rj] > self.capacity:
                continue

            # 检查i和j是否分别在路线的两端
            route_i = routes[ri]
            route_j = routes[rj]
            if not route_i or not route_j:
                continue

            i_at_end = (route_i[-1] == i) or (route_i[0] == i)
            j_at_end = (route_j[-1] == j) or (route_j[0] == j)

            if not (i_at_end and j_at_end):
                continue

            # 合并路线
            if route_i[-1] == i and route_j[0] == j:
                new_route = route_i + route_j
            elif route_i[0] == i and route_j[-1] == j:
                new_route = route_j + route_i
            elif route_i[-1] == i and route_j[-1] == j:
                new_route = route_i + route_j[::-1]
            else:
                new_route = route_i[::-1] + route_j

            # 更新路由归属
            routes[ri] = new_route
            routes[rj] = []
            route_loads[ri] += route_loads[rj]
            route_loads[rj] = 0
            for c in new_route:
                route_of[c] = ri

        # 过滤空路线
        return [r for r in routes if r]

    def calculate_total_distance(self, routes: List[List[int]]) -> float:
        """计算总行驶距离"""
        total = 0
        for route in routes:
            total += self.dist_matrix[0][route[0] + 1]
            for k in range(len(route) - 1):
                total += self.dist_matrix[route[k] + 1][route[k + 1] + 1]
            total += self.dist_matrix[route[-1] + 1][0]
        return total

供应链网络优化

设施选址

设施选址决定仓库/工厂的最优位置，是供应链网络设计的战略决策。

目标: min Σ_j f_j * y_j + Σ_i Σ_j c_ij * x_ij

约束:
1. 需求满足: Σ_j x_ij >= d_i  (每个需求点必须被服务)
2. 设施容量: Σ_i x_ij <= Q_j * y_j  (不超过设施容量)
3. 设施开放: y_j ∈ {0,1}  (设施是否开放)
4. 非负: x_ij >= 0

其中:
f_j = 开放设施j的固定成本
c_ij = 从设施j到需求点i的单位运输成本
d_i = 需求点i的需求量
Q_j = 设施j的容量

流量分配

已确定设施位置后，优化各设施到需求点的运输量分配。

from scipy.optimize import linprog
import numpy as np


def optimize_flow_allocation(
    facilities: list,
    demands: list,
    transport_cost: np.ndarray,
    facility_capacities: list,
) -> dict:
    """
    流量分配优化

    Args:
        facilities: 设施列表 [{"id": str, "capacity": float}, ...]
        demands: 需求点列表 [{"id": str, "demand": float}, ...]
        transport_cost: 运输成本矩阵 (n_facilities x n_demands)
        facility_capacities: 设施容量列表

    Returns:
        最优分配方案
    """
    n_f = len(facilities)
    n_d = len(demands)

    # 目标: 最小化运输总成本
    c = transport_cost.flatten()

    # 约束1: 每个需求点的需求必须满足
    A_eq_demand = np.zeros((n_d, n_f * n_d))
    for j in range(n_d):
        for i in range(n_f):
            A_eq_demand[j, i * n_d + j] = 1
    b_eq_demand = np.array([d["demand"] for d in demands])

    # 约束2: 每个设施的输出不超过容量
    A_ub_capacity = np.zeros((n_f, n_f * n_d))
    for i in range(n_f):
        for j in range(n_d):
            A_ub_capacity[i, i * n_d + j] = 1
    b_ub_capacity = np.array(facility_capacities)

    # 非负约束
    bounds = [(0, None)] * (n_f * n_d)

    result = linprog(
        c, A_ub=A_ub_capacity, b_ub=b_ub_capacity,
        A_eq=A_eq_demand, b_eq=b_eq_demand,
        bounds=bounds, method="highs",
    )

    if result.success:
        allocation = result.x.reshape(n_f, n_d)
        return {
            "status": "optimal",
            "total_cost": round(result.fun, 2),
            "allocation": {
                facilities[i]["id"]: {
                    demands[j]["id"]: round(allocation[i][j], 2)
                    for j in range(n_d) if allocation[i][j] > 0.01
                }
                for i in range(n_f)
            },
        }
    else:
        return {"status": "infeasible", "message": result.message}

from typing import List, Optional, Dict

                eoq = req.annual_demand

            # 年订货成本
            annual_ordering = (req.annual_demand / eoq) * req.ordering_cost

            # 年持有成本
            annual_holding = (eoq / 2) * H

            # 提前期库存成本
            lead_time_stock = req.annual_demand / 365 * lead_time * H

            total_cost = annual_purchase + annual_ordering + annual_holding + lead_time_stock

            # 综合评分(成本越低越好，质量/交期越高越好)
            cost_score = max(0, 100 - (total_cost / (req.annual_demand * req.unit_cost) - 1) * 100)
            overall_score = cost_score * 0.5 + quality_score * 0.3 + delivery_score * 0.2

            supplier_results.append({
                "supplier_id": sup.get("id", f"SUP{idx}"),
                "supplier_name": sup.get("name", f"供应商{idx+1}"),
                "total_cost": round(total_cost, 2),
                "unit_price": price,
                "annual_purchase_cost": round(annual_purchase, 2),
                "annual_ordering_cost": round(annual_ordering, 2),
                "annual_holding_cost": round(annual_holding, 2),
                "score": round(overall_score, 1),
            })

        # 按评分排序
        supplier_results.sort(key=lambda x: x["score"], reverse=True)
        for i, s in enumerate(supplier_results):
            s["rank"] = i + 1

        # 推荐供应商
        best = supplier_results[0] if supplier_results else None

        # 最优订货量(基于推荐供应商价格)
        if best:
            H = best["unit_price"] * req.holding_cost_rate
            eoq = np.sqrt(2 * req.annual_demand * req.ordering_cost / H) if H > 0 else req.annual_demand
        else:
            eoq = np.sqrt(2 * req.annual_demand * req.ordering_cost / (req.unit_cost * req.holding_cost_rate))

        return PurchaseOptimizationResponse(
            sku_id=req.sku_id,
            optimal_order_quantity=round(eoq, 0),
            optimal_order_frequency=round(req.annual_demand / eoq, 1),
            optimal_cycle_days=round(365 * eoq / req.annual_demand, 1),
            recommended_supplier=SupplierRecommendation(**best) if best else None,
            all_suppliers=[SupplierRecommendation(**s) for s in supplier_results],
            total_annual_cost=best["total_cost"] if best else 0,
        )
