智能定价算法

智能定价算法

定价策略

定价是电商运营中影响利润和销量的核心决策。不同的定价策略适用于不同的业务场景和竞争环境。

成本定价 (Cost-based Pricing)

以成本为基准，加上目标利润率确定售价。

售价 = 成本 * (1 + 目标毛利率)

成本 = 采购成本 + 仓储分摊 + 物流分摊 + 退损分摊
  • 优势：计算简单、确保利润
  • 劣势：忽略市场需求和竞争、可能偏离消费者认知价值
  • 适用场景：独家商品、成本结构复杂、新品定价参考

竞争定价 (Competitive Pricing)

以竞争对手价格为锚点，根据自身定位进行定价。

策略价格定位适用场景
平价策略与竞品持平同质化商品、市场份额稳定
低价策略低于竞品价格敏感用户、市场份额扩张
高价策略高于竞品品牌溢价、差异化服务
  • 优势：市场导向、操作简单
  • 劣势：可能导致价格战、忽略自身成本结构
  • 适用场景：同质化标品、竞争激烈品类

价值定价 (Value-based Pricing)

以消费者对商品的价值感知为定价依据。

消费者感知价值 = 功能价值 + 情感价值 + 社交价值 - 获取成本

最优价格 = 消费者愿付价格区间内的利润最大化点
  • 优势：利润空间大、与消费者认知一致
  • 劣势：感知价值难以量化、需大量调研
  • 适用场景：品牌商品、差异化商品、新品类

动态定价 (Dynamic Pricing)

根据实时市场条件(供需、竞争、用户特征)动态调整价格。

  • 核心思想：价格随时间、场景、用户变化
  • 技术基础：实时数据采集、算法模型、自动化决策
  • 典型应用：机票、酒店、网约车、电商大促
  • 关键约束：价格波动频率、消费者感知公平性、合规要求

价格弹性模型

需求价格弹性

需求价格弹性衡量需求量对价格变化的敏感程度，是定价决策的量化基础。

价格弹性 ε = (ΔQ/Q) / (ΔP/P) = (dQ/dP) * (P/Q)

|ε| > 1: 富有弹性，降价可增加总收入
|ε| = 1: 单位弹性，价格变化不影响总收入
|ε| < 1: 缺乏弹性，涨价可增加总收入

弹性计算方法

import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from typing import Tuple, Optional


class PriceElasticityEstimator:
    """价格弹性估计器"""

    def __init__(self, log_log_model: bool = True):
        """
        Args:
            log_log_model: 是否使用对数-对数模型
        """
        self.log_log_model = log_log_model
        self.elasticity: Optional[float] = None
        self.model: Optional[LinearRegression] = None

    def fit(
        self,
        prices: np.ndarray,
        quantities: np.ndarray,
        features: Optional[np.ndarray] = None,
    ) -> float:
        """
        估计价格弹性

        Args:
            prices: 价格序列
            quantities: 销量序列
            features: 其他控制变量

        Returns:
            价格弹性系数
        """
        if self.log_log_model:
            # 对数-对数模型: ln(Q) = α + ε*ln(P) + β*X
            log_q = np.log(np.maximum(quantities, 1))
            log_p = np.log(np.maximum(prices, 0.01))

            if features is not None:
                X = np.column_stack([log_p, features])
            else:
                X = log_p.reshape(-1, 1)

            self.model = LinearRegression()
            self.model.fit(X, log_q)
            self.elasticity = float(self.model.coef_[0])
        else:
            # 线性模型: Q = α + β*P + γ*X
            if features is not None:
                X = np.column_stack([prices, features])
            else:
                X = prices.reshape(-1, 1)

            self.model = LinearRegression()
            self.model.fit(X, quantities)

            # 弹性 = (dQ/dP) * (P_mean/Q_mean)
            mean_p = np.mean(prices)
            mean_q = np.mean(quantities)
            if mean_q == 0:
                self.elasticity = 0
            else:
                self.elasticity = float(self.model.coef_[0] * mean_p / mean_q)

        return self.elasticity

    def optimal_price(
        self,
        cost: float,
        current_price: float,
        current_quantity: float,
    ) -> Tuple[float, float]:
        """
        基于弹性计算利润最大化价格

        Args:
            cost: 单位成本
            current_price: 当前价格
            current_quantity: 当前销量

        Returns:
            (最优价格, 预期利润提升比例)
        """
        if self.elasticity is None:
            raise ValueError("请先调用fit方法估计弹性")

        e = self.elasticity

        # 利润最大化条件: P* = C * ε / (ε + 1)  (当ε < -1)
        if e < -1:
            optimal = cost * e / (e + 1)
        else:
            # 缺乏弹性时，涨价可增利，但需考虑上限
            optimal = current_price * 1.1

        optimal = max(optimal, cost * 1.05)  # 最低5%毛利率

        # 预期销量变化
        price_change = optimal / current_price - 1
        quantity_change = e * price_change
        new_quantity = current_quantity * (1 + quantity_change)

        old_profit = (current_price - cost) * current_quantity
        new_profit = (optimal - cost) * new_quantity
        profit_improvement = (new_profit - old_profit) / max(old_profit, 1)

        return round(optimal, 2), round(profit_improvement, 4)

弹性分类与定价建议

弹性范围类型定价建议
ε < -2高弹性谨慎涨价，降价可显著提升收入
-2 <= ε < -1中弹性适度调价，关注利润最大化点
-1 <= ε < -0.5低弹性可适度涨价提升利润
-0.5 <= ε < 0极低弹性价格不敏感，品牌溢价空间大

对标策略

def competitive_pricing(
    self_price: float,
    competitor_prices: list,
    cost: float,
    strategy: str = "parity",
    min_margin: float = 0.05,
    max_discount: float = 0.15,
) -> float:
    """
    基于竞品价格的定价策略

    Args:
        self_price: 当前自身价格
        competitor_prices: 竞品价格列表
        cost: 成本
        strategy: 定价策略 - parity(平价)/below(低价)/above(高价)
        min_margin: 最低毛利率
        max_discount: 最大折扣率

    Returns:
        建议价格
    """
    min_price = cost * (1 + min_margin)
    avg_comp = sum(competitor_prices) / len(competitor_prices)
    min_comp = min(competitor_prices)

    if strategy == "parity":
        suggested = avg_comp
    elif strategy == "below":
        suggested = min_comp * (1 - max_discount / 2)
    elif strategy == "above":
        suggested = avg_comp * 1.05
    else:
        suggested = self_price

    # 确保不低于最低利润线
    suggested = max(suggested, min_price)
    # 限制价格波动幅度
    lower = self_price * (1 - max_discount)
    upper = self_price * (1 + max_discount)
    suggested = max(min(suggested, upper), lower)

    return round(suggested, 2)

动态定价

多臂老虎机 (MAB)

多臂老虎机(Multi-Armed Bandit)是动态定价的经典框架，在探索(尝试不同价格)和利用(选择最优价格)之间取得平衡。

import numpy as np
from typing import List, Tuple


class DynamicPricingMAB:
    """基于MAB的动态定价引擎"""

    def __init__(
        self,
        price_candidates: List[float],
        cost: float,
        strategy: str = "thompson",
    ):
        """
        Args:
            price_candidates: 候选价格列表
            cost: 单位成本
            strategy: 策略 - thompson/ucb/epsilon_greedy
        """
        self.prices = np.array(price_candidates)
        self.cost = cost
        self.strategy = strategy
        self.n_arms = len(price_candidates)

        # 统计数据
        self.counts = np.zeros(self.n_arms)
        self.total_profits = np.zeros(self.n_arms)
        self.alpha = np.ones(self.n_arms)  # Thompson采样参数
        self.beta = np.ones(self.n_arms)

    def select_price(self, epsilon: float = 0.1) -> Tuple[float, int]:
        """
        选择下一个价格

        Returns:
            (选择的价格, 价格索引)
        """
        if self.strategy == "thompson":
            samples = np.random.beta(self.alpha, self.beta)
            arm = np.argmax(samples)
        elif self.strategy == "ucb":
            if np.any(self.counts == 0):
                arm = np.argmin(self.counts)
            else:
                avg_profit = self.total_profits / np.maximum(self.counts, 1)
                ucb = avg_profit + np.sqrt(2 * np.log(np.sum(self.counts)) / self.counts)
                arm = np.argmax(ucb)
        elif self.strategy == "epsilon_greedy":
            if np.random.random() < epsilon:
                arm = np.random.randint(self.n_arms)
            else:
                avg_profit = self.total_profits / np.maximum(self.counts, 1)
                arm = np.argmax(avg_profit)
        else:
            arm = np.random.randint(self.n_arms)

        return self.prices[arm], int(arm)

    def update(self, arm: int, demand: float) -> None:
        """
        更新观测结果

        Args:
            arm: 价格索引
            demand: 观测到的需求量
        """
        profit = (self.prices[arm] - self.cost) * demand
        self.counts[arm] += 1
        self.total_profits[arm] += profit

        # Thompson采样更新
        if profit > 0:
            self.alpha[arm] += demand
        else:
            self.beta[arm] += 1

    def get_best_price(self) -> Tuple[float, float]:
        """
        获取当前最优价格

        Returns:
            (最优价格, 预期单位利润)
        """
        avg_profit = self.total_profits / np.maximum(self.counts, 1)
        best_arm = np.argmax(avg_profit)
        return self.prices[best_arm], float(avg_profit[best_arm])

    def get_statistics(self) -> dict:
        """获取各价格的统计数据"""
        results = []
        for i in range(self.n_arms):
            avg = self.total_profits[i] / max(self.counts[i], 1)
            results.append({
                "price": float(self.prices[i]),
                "trials": int(self.counts[i]),
                "avg_profit": float(avg),
            })
        return {"strategy": self.strategy, "arms": results}

贝叶斯优化

贝叶斯优化适用于连续价格空间的优化，比网格搜索更高效。

from scipy.stats import norm
from scipy.optimize import minimize
import numpy as np


class BayesianPricingOptimizer:
    """基于贝叶斯优化的定价引擎"""

    def __init__(self, cost: float, price_range: Tuple[float, float]):
        self.cost = cost
        self.price_min, self.price_max = price_range
        self.observations_x = []
        self.observations_y = []

    def _expected_improvement(self, x: float, xi: float = 0.01) -> float:
        """计算期望改进(EI)"""
        if len(self.observations_x) < 2:
            return 0.0

        x_arr = np.array(self.observations_x)
        y_arr = np.array(self.observations_y)

        # 简化的高斯过程预测
        mu = np.interp(x, x_arr, y_arr)
        sigma = np.std(y_arr) / max(len(y_arr), 1) + 1e-6

        y_best = np.max(y_arr)
        z = (mu - y_best - xi) / sigma

        ei = (mu - y_best - xi) * norm.cdf(z) + sigma * norm.pdf(z)
        return ei if sigma > 0 else 0.0

    def suggest_price(self) -> float:
        """建议下一个尝试的价格"""
        if len(self.observations_x) < 3:
            return np.random.uniform(self.price_min, self.price_max)

        # 在价格范围内搜索EI最大的点
        candidates = np.linspace(self.price_min, self.price_max, 100)
        ei_values = [self._expected_improvement(x) for x in candidates]
        best_idx = np.argmax(ei_values)
        return round(float(candidates[best_idx]), 2)

    def observe(self, price: float, demand: float) -> None:
        """记录观测结果"""
        profit = (price - self.cost) * demand
        self.observations_x.append(price)
        self.observations_y.append(profit)

    def get_best_price(self) -> float:
        """获取当前最优价格"""
        if not self.observations_x:
            return (self.price_min + self.price_max) / 2
        best_idx = np.argmax(self.observations_y)
        return self.observations_x[best_idx]

促销定价优化

优惠券面额优化

def optimize_coupon_face_value(
    base_price: float,
    cost: float,
    elasticity: float,
    face_values: list,
    redemption_rates: list,
) -> dict:
    """
    优化优惠券面额

    Args:
        base_price: 商品原价
        cost: 单位成本
        elasticity: 价格弹性
        face_values: 候选面额列表
        redemption_rates: 各面额对应的核销率

    Returns:
        最优面额及预期效果
    """
    best_profit = -float("inf")
    best_face = 0
    results = []

    for face, redempt in zip(face_values, redemption_rates):
        effective_price = base_price - face
        if effective_price <= cost:
            continue

        # 弹性模型预测销量变化
        price_change = effective_price / base_price - 1
        quantity_change = elasticity * price_change

        # 假设基础销量100件
        base_quantity = 100
        new_quantity = base_quantity * (1 + quantity_change) * redempt

        profit = (effective_price - cost) * new_quantity
        results.append({
            "face_value": face,
            "effective_price": round(effective_price, 2),
            "redemption_rate": redempt,
            "expected_quantity": round(new_quantity, 1),
            "expected_profit": round(profit, 2),
        })

        if profit > best_profit:
            best_profit = profit
            best_face = face

    return {"best_face_value": best_face, "best_profit": round(best_profit, 2), "all_results": results}

满减门槛优化

满减优化目标: max Σ (客单价 - 减免金额) * 预计订单量

约束条件:
1. 减免金额 < 毛利空间
2. 门槛金额 > 平均客单价(提客单目的)
3. 层级间梯度合理(不能出现倒挂)

Markdown定价

Markdown定价(降价定价)用于清仓场景，目标是在清仓周期内最小化折损。

Markdown优化模型

def markdown_optimization(
    current_price: float,
    cost: float,
    remaining_stock: int,
    weeks_to_clear: int,
    weekly_base_demand: float,
    elasticity: float,
    min_sell_rate: float = 0.8,
) -> list:
    """
    清仓降价优化

    Args:
        current_price: 当前售价
        cost: 成本
        remaining_stock: 剩余库存
        weeks_to_clear: 清仓周数
        weekly_base_demand: 基础周需求
        elasticity: 价格弹性

    Returns:
        每周建议价格和预期销量
    """
    target_sales = remaining_stock * min_sell_rate
    avg_weekly_target = target_sales / weeks_to_clear

    plan = []
    stock_left = remaining_stock

    for week in range(1, weeks_to_clear + 1):
        # 计算需要的销量提升倍数
        demand_multiplier = avg_weekly_target / weekly_base_demand

        # 根据弹性反推需要的折扣
        # demand_multiplier = (P_new / P_current) ^ elasticity
        if elasticity != 0:
            price_ratio = demand_multiplier ** (1 / elasticity)
        else:
            price_ratio = 1.0

        suggested_price = current_price * price_ratio
        suggested_price = max(suggested_price, cost * 0.5)  # 最低半价
        suggested_price = round(suggested_price, 2)

        expected_demand = weekly_base_demand * demand_multiplier
        actual_sales = min(expected_demand, stock_left)
        stock_left -= actual_sales

        plan.append({
            "week": week,
            "suggested_price": suggested_price,
            "discount_pct": round((1 - suggested_price / current_price) * 100, 1),
            "expected_sales": round(actual_sales, 0),
            "remaining_stock": round(stock_left, 0),
        })

        if stock_left <= 0:
            break

    return plan

完整代码：动态定价引擎

from pydantic import BaseModel, Field
from typing import Optional, List
from enum import Enum
import numpy as np
from datetime import datetime


class PricingStrategy(str, Enum):
    COST_PLUS = "cost_plus"
    COMPETITIVE = "competitive"
    ELASTICITY = "elasticity"
    DYNAMIC = "dynamic"


class PricingRequest(BaseModel):
    sku_id: str = Field(..., description="SKU标识")
    current_price: float = Field(..., gt=0, description="当前价格")
    cost: float = Field(..., gt=0, description="单位成本")
    strategy: PricingStrategy = Field(default=PricingStrategy.ELASTICITY)
    competitor_prices: Optional[List[float]] = Field(default=None, description="竞品价格")
    elasticity: Optional[float] = Field(default=None, description="价格弹性")
    current_demand: Optional[float] = Field(default=None, description="当前需求量")
    target_margin: float = Field(default=0.15, gt=0, lt=1, description="目标毛利率")
    max_price_change: float = Field(default=0.10, gt=0, lt=0.5, description="最大价格变动比例")


class PricingResponse(BaseModel):
    sku_id: str
    suggested_price: float
    current_price: float
    price_change: float
    price_change_pct: float
    expected_margin: float
    expected_demand_change: float
    strategy_used: str
    confidence: float
    reasoning: str


class DynamicPricingEngine:
    """动态定价引擎"""

    def calculate_price(self, request: PricingRequest) -> PricingResponse:
        """计算建议价格"""
        if request.strategy == PricingStrategy.COST_PLUS:
            return self._cost_plus_pricing(request)
        elif request.strategy == PricingStrategy.COMPETITIVE:
            return self._competitive_pricing(request)
        elif request.strategy == PricingStrategy.ELASTICITY:
            return self._elasticity_pricing(request)
        elif request.strategy == PricingStrategy.DYNAMIC:
            return self._dynamic_pricing(request)
        else:
            raise ValueError(f"不支持的策略: {request.strategy}")

    def _cost_plus_pricing(self, req: PricingRequest) -> PricingResponse:
        """成本加成定价"""
        suggested = req.cost / (1 - req.target_margin)
        suggested = self._clamp_price(suggested, req)
        margin = (suggested - req.cost) / suggested

        return PricingResponse(
            sku_id=req.sku_id,
            suggested_price=round(suggested, 2),
            current_price=req.current_price,
            price_change=round(suggested - req.current_price, 2),
            price_change_pct=round((suggested - req.current_price) / req.current_price * 100, 2),
            expected_margin=round(margin, 4),
            expected_demand_change=0.0,
            strategy_used="cost_plus",
            confidence=0.6,
            reasoning=f"基于成本{req.cost}和目标毛利率{req.target_margin:.0%}计算",
        )

    def _competitive_pricing(self, req: PricingRequest) -> PricingResponse:
        """竞争定价"""
        if not req.competitor_prices:
            return self._cost_plus_pricing(req)

        avg_comp = np.mean(req.competitor_prices)
        min_comp = min(req.competitor_prices)
        suggested = avg_comp * 0.98  # 略低于均价
        suggested = self._clamp_price(suggested, req)
        margin = (suggested - req.cost) / suggested

        return PricingResponse(
            sku_id=req.sku_id,
            suggested_price=round(suggested, 2),
            current_price=req.current_price,
            price_change=round(suggested - req.current_price, 2),
            price_change_pct=round((suggested - req.current_price) / req.current_price * 100, 2),
            expected_margin=round(margin, 4),
            expected_demand_change=0.0,
            strategy_used="competitive",
            confidence=0.7,
            reasoning=f"基于{len(req.competitor_prices)}个竞品价格，均价{avg_comp:.2f}，最低{min_comp:.2f}",
        )

    def _elasticity_pricing(self, req: PricingRequest) -> PricingResponse:
        """弹性定价"""
        elasticity = req.elasticity if req.elasticity else -1.5

        if elasticity < -1:
            optimal = req.cost * elasticity / (elasticity + 1)
        else:
            optimal = req.current_price

        suggested = self._clamp_price(optimal, req)
        margin = (suggested - req.cost) / suggested

        demand_change = elasticity * (suggested / req.current_price - 1) if req.current_price > 0 else 0

        return PricingResponse(
            sku_id=req.sku_id,
            suggested_price=round(suggested, 2),
            current_price=req.current_price,
            price_change=round(suggested - req.current_price, 2),
            price_change_pct=round((suggested - req.current_price) / req.current_price * 100, 2),
            expected_margin=round(margin, 4),
            expected_demand_change=round(demand_change, 4),
            strategy_used="elasticity",
            confidence=0.75,
            reasoning=f"基于价格弹性{elasticity:.2f}的利润最大化定价",
        )

    def _dynamic_pricing(self, req: PricingRequest) -> PricingResponse:
        """动态定价(综合策略)"""
        # 综合多种策略
        results = []
        results.append(self._cost_plus_pricing(req))
        if req.competitor_prices:
            results.append(self._competitive_pricing(req))
        if req.elasticity:
            results.append(self._elasticity_pricing(req))

        if not results:
            return self._cost_plus_pricing(req)

        # 加权平均
        weights = [0.2, 0.3, 0.5][:len(results)]
        total_weight = sum(weights)
        suggested = sum(r.suggested_price * w for r, w in zip(results, weights)) / total_weight
        suggested = self._clamp_price(suggested, req)
        margin = (suggested - req.cost) / suggested

        return PricingResponse(
            sku_id=req.sku_id,
            suggested_price=round(suggested, 2),
            current_price=req.current_price,
            price_change=round(suggested - req.current_price, 2),
            price_change_pct=round((suggested - req.current_price) / req.current_price * 100, 2),
            expected_margin=round(margin, 4),
            expected_demand_change=0.0,
            strategy_used="dynamic",
            confidence=0.8,
            reasoning=f"综合{len(results)}种策略加权计算",
        )

    def _clamp_price(self, price: float, req: PricingRequest) -> float:
        """限制价格变动范围"""
        min_price = req.current_price * (1 - req.max_price_change)
        max_price = req.current_price * (1 + req.max_price_change)
        min_price = max(min_price, req.cost * 1.02)  # 最低2%毛利
        return max(min(price, max_price), min_price)
