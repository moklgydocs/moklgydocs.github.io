核心判断

当前水平：L1 满分 + L2 约 40% + L3 约 20%

你的编程基础扎实，项目工程能力不错，但 AI 核心技能（直接使用 LLM、RAG、Agent）的深度不够。目前更像是"AI 基础设施工程师"而非"AI 应用工程师"。

能否胜任初级 AI 工程师？

  • 基础编程能力：达标
  • LLM API 调用：需要补强（从间接代理到直接使用）
  • RAG 全流程：需要补强（从集成到独立实现）
  • Agent 开发：需要补强（从理解架构到独立设计）
  • Prompt 工程：需要从零开始系统学习

结论：以当前水平直接面试 AI 工程师岗位，大概率能通过初级岗的编程基础部分，但在 AI 专业技能环节会被追问到短板。建议按以下优先级集中补强。

补强路线（12 周计划）

第 1-3 周：LLM 直连 + Prompt 工程

目标：从"代理别人的 LLM 服务"变成"自己能用 LLM 做事"

天任务产出
1-2OpenAI / DeepSeek API 直接调用翻译、摘要、对话脚本
3-4流式响应处理（SSE 解析）流式聊天 CLI
5-7Prompt Engineering 体系学习结构化输出、Few-Shot、CoT 实践笔记
8-10JSON Schema 约束输出信息抽取、分类器
11-14多轮对话 + 上下文管理带记忆的聊天机器人
15-21防幻觉 + 可靠性设计RAG 问答基线系统

第 4-7 周：RAG 全流程实战

目标：能独立从零搭建生产级 RAG 系统

天任务产出
22-24文档解析（PDF/Word/HTML）多格式解析器
25-28分块策略（固定/语义/递归）分块效果对比报告
29-31向量化 + 向量数据库实操Milvus/Chroma CRUD
32-35混合检索（向量 + BM25）双路召回实现
36-38重排序（BGE Reranker / Cohere）重排序效果对比

自测清单

完成以下所有条目后，你基本具备了中级 AI 工程师的能力：

L1 编程基础（你应该已达标）

L2 AI 基础（重点补强）

L3 AI 工程（重点补强）

L4 AI 架构（逐步积累）

关键建议

你最大的优势是工程基础扎实，最大的短板是 AI 专业深度不足。不要从头学 Python/后端，而是把精力集中在 L2 和 L3 层 -- 直接 LLM 使用、RAG 全流程、Agent 开发。这三项补齐后，你就是一个有竞争力的中级 AI 工程师。
