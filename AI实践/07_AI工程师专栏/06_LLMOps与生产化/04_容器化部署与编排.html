Docker 最佳实践

AI 服务 Dockerfile

# 多阶段构建：构建阶段
FROM nvidia/cuda:12.4.0-devel-ubuntu22.04 AS builder

WORKDIR /app

# 安装 Python
RUN apt-get update && apt-get install -y python3.10 python3-pip && \
    rm -rf /var/lib/apt/lists/*

# 安装依赖（利用缓存层）
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 运行阶段：更小的基础镜像
FROM nvidia/cuda:12.4.0-runtime-ubuntu22.04

WORKDIR /app

# 只复制必要的运行时文件
COPY --from=builder /usr/local/lib/python3.10 /usr/local/lib/python3.10
COPY --from=builder /usr/local/bin /usr/local/bin
COPY --from=builder /app /app

# 复制应用代码
COPY src/ ./src/

# 非 root 用户运行
RUN useradd -m appuser && chown -R appuser:appuser /app
USER appuser

# 健康检查
HEALTHCHECK --interval=30s --timeout=10s --retries=3 \
    CMD curl -f http://localhost:8000/health || exit 1

EXPOSE 8000

CMD ["python", "-m", "vllm.entrypoints.openai.api_server", \
     "--host", "0.0.0.0", "--port", "8000", \
     "--model", "/models/qwen2.5-7b"]

GPU 资源声明

# llm-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: llm-inference
  namespace: ai-serving
spec:
  replicas: 2
  selector:
    matchLabels:
      app: llm-inference
  template:
    metadata:
      labels:
        app: llm-inference
    spec:
      # 调度到 GPU 节点
      nodeSelector:
        nvidia.com/gpu.present: "true"
      tolerations:
        - key: nvidia.com/gpu
          operator: Exists
          effect: NoSchedule
      containers:
        - name: vllm
          image: registry.example.com/llm-serving:v1.0
          ports:
            - containerPort: 8000
          resources:
            limits:
              nvidia.com/gpu: 1
            requests:
              nvidia.com/gpu: 1
              memory: "16Gi"
              cpu: "4"
          env:
            - name: MODEL_PATH
              value: "/models/qwen2.5-7b"
            - name: MAX_MODEL_LEN
              value: "4096"
          volumeMounts:
            - name: model-storage
              mountPath: /models
          livenessProbe:
            httpGet:
              path: /health
              port: 8000
            initialDelaySeconds: 120
            periodSeconds: 30
          readinessProbe:
            httpGet:
              path: /health
              port: 8000
            initialDelaySeconds: 60
            periodSeconds: 10
      volumes:
        - name: model-storage
          persistentVolumeClaim:
            claimName: model-pvc

HPA 自动伸缩

基于 GPU 利用率的 HPA

# hpa.yaml
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: llm-inference-hpa
  namespace: ai-serving
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: llm-inference
  minReplicas: 1
  maxReplicas: 5
  metrics:
    # 基于 CPU 利用率
    - type: Resource
      resource:
        name: cpu
        target:
          type: Utilization
          averageUtilization: 70
    # 基于 GPU 利用率（需要 DCGM exporter）
    - type: Pods
      pods:
        metric:
          name: gpu_utilization
        target:
          type: AverageValue
          averageValue: "80"
    # 基于并发请求数（自定义指标）
    - type: Pods
      pods:
        metric:
          name: vllm_num_requests_running
        target:
          type: AverageValue
          averageValue: "16"
  behavior:
    scaleUp:
      stabilizationWindowSeconds: 60
      policies:
        - type: Percent
          value: 100
          periodSeconds: 60
    scaleDown:
      stabilizationWindowSeconds: 300
      policies:
        - type: Percent
          value: 10
          periodSeconds: 60

部署前检查

class DeploymentChecklist:
    """生产部署检查清单"""

    checks = [
        # 镜像与模型
        ("镜像已通过安全扫描", "critical"),
        ("模型文件完整性校验（MD5/SHA256）", "critical"),
        ("镜像大小合理（< 20GB）", "warning"),

        # 资源与调度
        ("GPU 资源配额充足", "critical"),
        ("PVC 存储已就绪", "critical"),
        ("节点容忍与亲和性配置正确", "warning"),

        # 网络与安全
        ("Ingress/TLS 证书有效", "critical"),
        ("NetworkPolicy 限制出站流量", "warning"),
        ("ServiceAccount 权限最小化", "warning"),

        # 健康检查
        ("livenessProbe 已配置", "critical"),
        ("readinessProbe 已配置", "critical"),
        ("启动探针 initialDelay 充足", "warning"),

        # 可观测性
        ("Prometheus ServiceMonitor 已配置", "warning"),
        ("日志采集已配置", "warning"),
        ("告警规则已创建", "warning"),

        # 弹性伸缩
        ("HPA 已配置", "warning"),
        ("伸缩阈值合理", "warning"),

        # 灾备
        ("多副本部署", "warning"),
        ("PDB（PodDisruptionBudget）已配置", "warning"),
        ("备份与恢复流程已验证", "warning"),
    ]

    def run(self) -> dict:
        results = {"pass": 0, "fail": 0, "warnings": 0, "details": []}
        # 实际实现中逐项检查
        for check_name, severity in self.checks:
            results["details"].append({
                "check": check_name,
                "severity": severity,
                "status": "pending",  # 需人工确认
            })
        return results

关键配置参数

参数说明推荐值
max-model-len最大序列长度根据业务需求
gpu-memory-utilizationGPU 显存利用率0.85-0.92
max-num-seqs最大并发序列数16-64
enable-prefix-caching前缀缓存开启
enforce-eager禁用 CUDA Graph（调试用）生产关闭

故障排查

现象可能原因排查方法
OOM Killed显存不足降低 gpu-memory-utilization 或 max-model-len
启动超时模型加载慢检查 PVC IOPS，预热模型
请求超时排队过长增加 replicas 或降低 max-num-seqs
GPU 利用率低batch 不足增加 max-num-seqs 或降低 HPA 阈值
响应变慢KV Cache 不足增加显存或减少并发
