# 智能体的共识与拜占庭容错

> 经典分布式系统的 BFT 遇上了随机的 LLM。2025-2026 年冒出三个研究方向：**CP-WBFT**(arXiv:2511.10400）用置信探针给每张票加权；**DecentLLMs**(arXiv:2507.14928）走无领导路线：工人智能体并行提案，用几何中位数聚合；**WBFT**(arXiv:2505.05103）把加权投票和层次结构聚类结合，分出核心节点与边缘节点。《Can AI Agents Agree?》(arXiv:2603.01213）给出的诚实实证结果是：今天连标量共识都很脆弱——一个欺骗性智能体就能攻陷一个 Mixture-of-Agents。BFT 是必要的，但不是充分的。本课构建一个最小 BFT 协议，注入三种智能体特有的攻击（拜占庭谎言、谄媚从众、相关错误的单一文化），测量每种共识变体的应对能力。

**前置要求：** 第 16 阶段 · 07（心智社会与辩论）、第 16 阶段 · 13（共享记忆）

## 问题

你有 N 个 LLM 智能体，各产出一个答案。它们不一致。多数投票选出了错的那个，因为有两个智能体是相关的（同一个基座模型、同样的训练数据、同样的故障模式）。第三个智能体恰好以一种新颖的方式犯错——于是这个多数是假多数。

现在加一个欺骗性智能体：它故意撒谎。或者一个谄媚智能体：谁最后说话它就附和谁。在经典 BFT 里，假设是拜占庭节点占比 `f < n/3`，行为任意。2026 年的现实是：LLM 节点即使诚实也是随机的、跨模型相关的，还会被彼此的输出影响。你不能把它们当作独立的伯努利投票者。

经典 BFT(PBFT,1999）没有错——它是不完整的。它处理任意的比特翻转，但处理不了"三个诚实的智能体因为共享训练数据而共享同一个幻觉"。本课从 PBFT 的地基出发，叠上三种 2025-2026 年的改造。

## 概念

### 经典 BFT 给你什么

实用拜占庭容错（Castro & Liskov,OSDI 1999）容忍 `f < n/3` 个拜占庭节点。协议有三个阶段（pre-prepare、prepare、commit）和两个原语（签名消息、法定人数证书）。在 `n >= 3f + 1` 个或诚实或恶意的节点间对单个值达成一致。

它的担保很强，但假设了：

1. **故障相互独立。** 拜占庭节点互不串通。
2. **诚实节点真的诚实。** 诚实输出的正确性不是问题；协议只对齐分歧。
3. **问题有地面真值答案。** 就错误事实达成的共识，仍然是共识。

LLM 智能体三条全违反。跑同一个基座模型的两个智能体共享故障；"诚实"的 LLM 照样幻觉；在模糊问题上，"真值"就是智能体们决定出来的东西——没有外部神谕。

### 三种 LLM 特有的攻击

**拜占庭谎言。** 一个智能体故意输出错误答案。经典 BFT 在 `f < n/3` 时能处理。

**谄媚从众。** 一个智能体在投票前读了别人的答案，然后附和最后发言的那个。不是恶意，但和最大嗓门相关。经典 BFT 防不住，因为这个智能体通过了所有签名检查。

**相关错误的单一文化。** 三个智能体共享一个基座模型，幻觉出同一个错误答案。多数是错的。经典 BFT 帮不上忙，因为三个都"诚实地"达成一致。

### 2025-2026 年的应对

**CP-WBFT**(arXiv:2511.10400)—— 置信探针加权 BFT。每个投票者给答案附一个置信探针（自报概率，或独立的校准模型预测）。票权重随置信度缩放。报告在完全图上 BFT 提升 85.71%。缓解：谄媚从众（从众的智能体对自己附和来的立场往往置信度低）。

**DecentLLMs**(arXiv:2507.14928)—— 无领导。工人智能体并行提案，评估者智能体给提案打分，最终答案是打分位置的几何中位数。`f < n/2` 时稳健。缓解：拜占庭谎言和相关错误（几何中位数抗离群，拉向密集簇，而不是被模型偏见拉偏的平均值）。

**WBFT**(arXiv:2505.05103)—— 带层次结构聚类的加权 BFT。票权重按响应质量加从历史学到的信任分分配。把智能体聚成核心（Core）和边缘（Edge)；核心先达成共识，边缘跟随。缓解：可扩展性（核心共识又小又快），以及对单一文化的部分缓解（核心可以按多样性挑选）。

### 实证:《Can AI Agents Agree?》(arXiv:2603.01213)

这篇论文在多个前沿模型上测量标量共识（LLM 智能体对单个数值达成一致）。结论让人不安：

- 即使没有对抗者，LLM 智能体在标量问题上的不一致率在许多基准上超过 30%。
- 一个采取欺骗人格的智能体，能把 Mixture-of-Agents 的共识拉偏离诚实基线 40+ 个百分点。
- 不一致率与模型多样性相关——异构集成比同质集成更容易不一致（好事：错误不相关），但收敛也更慢（坏事：达成一致耗时更长）。

要点：BFT 给你对齐输出的机器，但不告诉你对齐后的输出对不对。要和验证（第 16 阶段 · 08 角色专精）、多样性（第 16 阶段 · 15 辩论变体）和评估者智能体（第 16 阶段 · 24 基准）组合使用。

### 剥到最简的核心协议

一个最小的 LLM 智能体 BFT 轮次：

```
1. task arrives; each agent i produces answer a_i
2. each agent attaches confidence probe c_i in [0, 1]
3. aggregator collects (a_i, c_i) from all n agents
4. aggregator groups by semantic cluster (equivalent answers)
5. aggregator computes weight for each cluster C:
     w(C) = sum_{i in C} c_i
6. winner = cluster with max weight, if max > threshold * sum(c_i)
   else: retry or escalate
7. minority clusters logged with provenance for post-hoc audit
```

语义聚类这一步是 LLM 特有的变化。两个答案 "the study reports 4.2%" 和 "4.2% improvement" 属于同一簇。朴素的字符串相等检查会漏掉。生产环境用便宜的嵌入模型或显式的规范化。

### 阈值调节

`threshold` 参数决定何时接受、何时重试。太低：接受弱多数。太高：永远接受不了。经验范围：`n=5-7` 个智能体时 0.5-0.67,`n` 更小时更高。低于阈值，升级给人类或另一组智能体集成。

### 共识帮不上忙的地方

- **模糊问题。** 问题没有地面真值时，共识是一种意见。叫它意见就好。
- **复合问题。** "写代码并解释"——两个答案。各自独立投票。
- **多轮对抗。** 如果智能体能观察之前的轮次并模仿（Du 2023 的辩论），它们会开始互相附和，不管真相。限制轮数（通常 2-3 轮）。

## 动手构建

`code/main.py` 实现了：

- `AgentVoter` —— 带（答案， 置信度）的脚本化策略。
- `MajorityVote` —— 经典的相对多数。
- `CPWBFT` —— 带语义聚类的置信加权投票。
- `DecentLLMs` —— 对打分提案做几何中位数聚合。
- `Scenario` —— 在三种攻击模式下跑每种聚合器。

实现的攻击模式：

1. `byzantine`：一个智能体高置信度撒谎。
2. `sycophancy`：一个智能体复制它看到的第一个答案，置信度照搬。
3. `monoculture`：三个智能体共享一个错误答案（相关错误），置信度中等。

运行：

```
python3 code/main.py
```

预期输出：一张（攻击， 聚合器） -> 最终答案的表，正确答案高亮。相对多数在单一文化案例上失败；CPWBFT 的置信加权缓解谄媚；当单一文化少于人口一半时，DecentLLMs 的几何中位数拉向诚实簇。

## 交付

交付任何共识机制之前：

- **至少用上面三种攻击模式做攻击测试。** 你的协议应该可预期地失败，而不是静默失败。
- **记录每个少数簇**，带出处。少数簇是你发现相关错误的早期预警系统。
- **强制限定轮数。** 不要"一直辩论到达成一致"——那是在奖励谄媚。
- **把达成一致和正确性分开。** 共识输出交给验证者；验证者独立于集成。
- **监控一致率。** 骤升意味着从众偏见；骤降意味着模型漂移。

## 练习

1. 跑 `code/main.py`。确认相对多数在单一文化攻击上失败，而当单一文化的置信度低于 0.7 时 CPWBFT 能部分缓解。
2. 加第四种攻击模式：**静默弃权** —— 一个智能体拒绝回答（"I don't know")。每种聚合器该怎么对待弃权？实现你的选择。
3. 把语义聚类从字符串规范化换成嵌入相似度（用任何开源嵌入模型）。谄媚攻击会发生什么变化？
4. 读 CP-WBFT(arXiv:2511.10400)。实现置信探针校准步骤（一个独立的校准模型检查每个智能体自报的置信度）。测量单一文化场景上的准确率提升。
5. 读《Can AI Agents Agree?》(arXiv:2603.01213)。复现一个简化的标量共识实验：三个智能体、一个标量问题、欺骗人格提示词。CPWBFT 或 DecentLLMs 能抓住它吗？

## 关键术语

| 术语 | 大家嘴里的说法 | 实际含义 |
|------|----------------|------------------------|
| BFT | "拜占庭容错" | Castro-Liskov 1999 的共识协议，容忍 `f < n/3` 任意故障 |
| 拜占庭 | "任何坏行为" | 一个可以撒谎、丢消息、静默失败的节点——除了安全崩溃之外什么都可能 |
| 置信探针 | "你有多确定？" | 附在票上的自报或校准器预测的概率 |
| 语义聚类 | "同一答案，不同说法" | 计票前把等价答案归组 |
| 几何中位数 | "稳健的中心" | 到样本点距离和最小的点。抗离群，不像均值 |
| 单一文化 | "同一个模型，同样的失败" | 智能体共享训练数据或基座模型导致的相关错误 |
| 谄媚从众 | "附和大嗓门" | 智能体的票偏向最先说/最大声的那个 |
| 核心/边缘 | "分层 BFT" | WBFT 的分法：小的核心先共识，边缘跟随。限制延迟 |
