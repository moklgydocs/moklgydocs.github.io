常用插件与配置

常用插件与配置

Jenkins 的灵魂是插件。装对插件，体验翻倍。这篇整理最实用的插件和配置。

Blue Ocean —— 现代化 UI

安装：插件管理 → 搜索 "Blue Ocean" → 安装

效果：
  → 全新的流水线可视化界面
  → 每个 stage 可视化进度
  → 直接在界面里查看日志
  → 好看（这很重要）

入口：Jenkins 首页左侧 → "Open Blue Ocean"
URL: http://jenkins:8080/blue

Docker Pipeline —— Pipeline 里用 Docker

// 用 Docker 镜像作为构建环境
pipeline {
    agent {
        docker {
            image 'mcr.microsoft.com/dotnet/sdk:8.0'
        }
    }
    stages {
        stage('Build') {
            steps {
                sh 'dotnet --version'
                sh 'dotnet publish -c Release -o ./publish'
            }
        }
    }
}
// 在 stage 级别指定不同镜像
pipeline {
    agent none
    stages {
        stage('Build') {
            agent { docker { image 'mcr.microsoft.com/dotnet/sdk:8.0' } }
            steps { sh 'dotnet build' }
        }
        stage('Node Build') {
            agent { docker { image 'node:20' } }
            steps { sh 'npm run build' }
        }
    }
}

Publish Over SSH —— SSH 部署

安装后配置：
系统管理 → 系统配置 → Publish over SSH

SSH Servers:
  Name: prod-server
  Hostname: 192.168.1.100
  Username: deploy
  Remote Directory: /opt/apps
  → 高级 → Use password authentication → 或配置 SSH Key
  → Test Configuration → 成功
// Pipeline 里使用
stage('Deploy') {
    steps {
        sshPublisher(publishers: [
            sshPublisherDesc(
                configName: 'prod-server',
                transfers: [
                    sshTransfer(
                        sourceFiles: '',
                        execCommand: '''
                            cd /opt/apps/erp
                            docker compose pull erp-api
                            docker compose up -d erp-api
                        '''
                    )
                ]
            )
        ])
    }
}

             body: "查看详情: ${BUILD_URL}"

飞书/钉钉通知

def sendFeishu(String msg) {
    withCredentials([string(credentialsId: 'feishu-webhook', variable: 'WEBHOOK')]) {
        sh """
            curl -s -X POST ${WEBHOOK} \
              -H 'Content-Type: application/json' \
              -d '{
                "msg_type": "interactive",
                "card": {
                  "header": {
                    "title": {"content": "${JOB_NAME} #${BUILD_NUMBER}", "tag": "plain_text"}
                  },
                  "elements": [{
                    "tag": "div",
                    "text": {"content": "${msg}", "tag": "plain_text"}
                  }, {
                    "tag": "action",
                    "actions": [{
                      "tag": "button",
                      "text": {"content": "查看详情", "tag": "plain_text"},
                      "url": "${BUILD_URL}",
                      "type": "primary"
                    }]
                  }]
                }
              }'
        """
    }
}

// 使用
post {
    success { script { sendFeishu("✅ 构建成功") } }
    failure { script { sendFeishu("❌ 构建失败") } }
}

构建优化插件

Timestamper —— 日志加时间

安装后，Pipeline 里：
options { timestamps() }

效果：
  [2024-04-14 10:30:15] Building...
  [2024-04-14 10:30:20] Build complete

Build Timeout —— 超时控制

options {
    timeout(time: 30, unit: 'MINUTES')
}

// 或单个 stage
stage('Deploy') {
    options { timeout(time: 5, unit: 'MINUTES') }
    steps { ... }
}

Workspace Cleanup —— 清理空间

post {
    always { cleanWs() }
}

Build Discarder —— 保留策略

options {
    buildDiscarder(logRotator(
        numToKeepStr: '20',        // 保留 20 次构建
        daysToKeepStr: '30',       // 保留 30 天
        artifactNumToKeepStr: '5'  // 产物保留 5 次
    ))
}

Jenkins 日常维护

磁盘清理

# 查看 Jenkins 数据大小
docker exec jenkins du -sh /var/jenkins_home
docker exec jenkins du -sh /var/jenkins_home/workspace
docker exec jenkins du -sh /var/jenkins_home/jobs

# 清理旧构建的工作空间
# Jenkins → 系统管理 → 系统信息 → 查看磁盘使用

更新 Jenkins

# 更新镜像
docker compose pull jenkins
docker compose up -d jenkins

# 更新后检查插件兼容性
# 系统管理 → 插件管理 → Updates

重启

# 安全重启（等当前构建完成）
# 浏览器: http://jenkins:8080/safeRestart

# 或命令行
docker restart jenkins
