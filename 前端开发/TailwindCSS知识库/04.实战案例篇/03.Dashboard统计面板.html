案例 3：Dashboard 统计面板

TL;DR
用 Tailwind Grid 构建一个中后台 Dashboard 统计面板：4 列统计卡片（含趋势指示器）+ 图表区域 + 最近订单列表。掌握 grid-cols-*、col-span-*、tabular-nums、条件样式等核心用法。

统计卡片组件

// src/components/business/stat-card.tsx
import { cn } from "@/lib/utils";

interface StatCardProps {
  title: string;
  value: string;
  change: number;
  changeLabel: string;
  icon: React.ReactNode;
}

function StatCard({ title, value, change, changeLabel, icon }: StatCardProps) {
  const isPositive = change >= 0;

  return (
    <div className="group rounded-xl border bg-card p-6 transition-all duration-200 hover:shadow-md">
      <div className="flex items-center justify-between">
        <span className="text-sm font-medium text-muted-foreground">{title}</span>
        <div className="rounded-lg bg-primary/10 p-2 text-primary transition-colors group-hover:bg-primary group-hover:text-primary-foreground">
          {icon}
        </div>
      </div>

      <div className="mt-3">
        <p className="text-3xl font-bold tabular-nums tracking-tight">{value}</p>
      </div>

      <div className="mt-2 flex items-center gap-2">
        {/* 趋势指示器 */}
        <span
          className={cn(
            "inline-flex items-center gap-0.5 rounded-full px-2 py-0.5 text-xs font-medium",
            isPositive
              ? "bg-green-50 text-green-700 dark:bg-green-500/10 dark:text-green-400"
              : "bg-red-50 text-red-700 dark:bg-red-500/10 dark:text-red-400"
          )}
        >
          <svg
            className={cn("h-3 w-3", !isPositive && "rotate-180")}
            fill="none"
            viewBox="0 0 24 24"
            stroke="currentColor"
            strokeWidth={2}
          >
            <path strokeLinecap="round" strokeLinejoin="round" d="M5 15l7-7 7 7" />
          </svg>
          {Math.abs(change)}%
        </span>
        <span className="text-xs text-muted-foreground">{changeLabel}</span>
      </div>
    </div>
  );
}

export { StatCard };

知识点解析

1. 响应式 Grid 布局策略

// 统计卡片：2 列 → 4 列
"grid grid-cols-2 gap-4 lg:grid-cols-4"

// 下方区域：12 列栅格，图表占 8，列表占 4
"grid grid-cols-1 gap-6 lg:grid-cols-12"
"lg:col-span-7 xl:col-span-8"  // 图表
"lg:col-span-5 xl:col-span-4"  // 列表

在手机上全部堆叠为单列，在桌面上用 12 列栅格精确控制比例。

2. tabular-nums 等宽数字

<p className="text-3xl font-bold tabular-nums">¥1,234K</p>

tabular-nums 让数字字符等宽对齐，数据变化时不会导致布局跳动。在 Dashboard 和表格中特别重要。

3. Group 悬停效果

<div className="group ...">
  <div className="group-hover:bg-primary group-hover:text-primary-foreground">
    {icon}
  </div>
</div>

鼠标悬停在卡片上时，图标容器的背景色和文字色同时变化。

4. 暗色模式适配

// 状态颜色在暗色模式下使用不同的色调
"bg-green-50 text-green-700 dark:bg-green-500/10 dark:text-green-400"

亮色模式用浅底深字（green-50 + green-700），暗色模式用半透明底亮字（green-500/10 + green-400）。

5. divide-y 简化分隔线

<div className="divide-y">
  {orders.map((order) => (
    <div key={order.id} className="py-4">...</div>
  ))}
</div>

divide-y 自动在相邻子元素之间添加水平分隔线，不需要手动在每一项底部加 border-b 再给最后一项加 last:border-b-0。

避坑指南

坑：grid-cols-2 gap-4 在小屏幕上统计卡片太挤

// 修复：超小屏用单列
"grid grid-cols-1 gap-4 xs:grid-cols-2 lg:grid-cols-4"
// 需要在 tailwind.config 中添加 xs: "475px" 断点

坑：数字宽度变化导致卡片高度不一致

// 确保所有 StatCard 都用 items-center 对齐
// 或给数字行固定高度
<p className="h-10 text-3xl font-bold tabular-nums">{value}</p>
