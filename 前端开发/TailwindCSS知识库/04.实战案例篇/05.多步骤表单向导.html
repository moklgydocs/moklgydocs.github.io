案例 5：多步骤表单向导

TL;DR
用 Tailwind 构建一个中后台常见的多步骤表单向导：步骤进度条（已完成/当前/待完成三态）、表单字段分组、校验错误状态样式、步骤切换动画。涵盖 peer、aria-*、条件边框/背景色等进阶技巧。

目标效果

  ①───────②───────③───────④
 基本信息   收货地址   支付方式   确认订单
  (✓)      (当前)    (待完成)   (待完成)

┌──────────────────────────────────┐
│  收货地址                         │
│                                   │
│  收件人 ___________               │
│  手机号 ___________  ← 红框报错    │
│         请输入 11 位手机号          │
│                                   │
│  省/市/区 [___▾] [___▾] [___▾]    │
│  详细地址 ___________________      │
│                                   │
│          [上一步]  [下一步]         │
└──────────────────────────────────┘

步骤指示器

// src/components/business/step-indicator.tsx
import { cn } from "@/lib/utils";

interface Step {
  label: string;
  description?: string;
}

interface StepIndicatorProps {
  steps: Step[];
  currentStep: number;
}

function StepIndicator({ steps, currentStep }: StepIndicatorProps) {
  return (
    <nav className="mx-auto max-w-3xl" aria-label="步骤进度">
      <ol className="flex items-center">
        {steps.map((step, index) => {
          const isCompleted = index < currentStep;
          const isCurrent = index === currentStep;
          const isLast = index === steps.length - 1;

          return (
            <li
              key={step.label}
              className={cn("flex items-center", !isLast && "flex-1")}
            >
              {/* 步骤圆圈 */}
              <div className="flex flex-col items-center">
                <div
                  className={cn(
                    "flex h-10 w-10 items-center justify-center rounded-full border-2 text-sm font-semibold transition-all duration-300",
                    isCompleted &&
                      "border-primary bg-primary text-primary-foreground",
                    isCurrent &&
                      "border-primary bg-primary/10 text-primary ring-4 ring-primary/20",
                    !isCompleted &&
                      !isCurrent &&
                      "border-gray-300 bg-white text-gray-500 dark:border-gray-600 dark:bg-gray-800 dark:text-gray-400"
                  )}
                >
                  {isCompleted ? (
                    <svg
                      className="h-5 w-5"
                      fill="none"
                      viewBox="0 0 24 24"
                      stroke="currentColor"
                      strokeWidth={3}
                    >
                      <path
                        strokeLinecap="round"
                        strokeLinejoin="round"
                        d="M5 13l4 4L19 7"
                      />
                    </svg>
                  ) : (
                    index + 1
                  )}
                </div>

                {/* 步骤标签 */}
                <div className="mt-2 text-center">
                  <p
                    className={cn(
                      "text-xs font-medium",
                      isCurrent
                        ? "text-primary"
                        : isCompleted
                          ? "text-foreground"
                          : "text-muted-foreground"
                    )}
                  >
                    {step.label}
                  </p>
                  {step.description && (
                    <p className="mt-0.5 hidden text-[10px] text-muted-foreground sm:block">
                      {step.description}
                    </p>
                  )}
                </div>
              </div>

              {/* 连接线 */}
              {!isLast && (
                <div className="mx-2 mt-[-1.5rem] h-0.5 flex-1 sm:mx-4">
                  <div
                    className={cn(
                      "h-full rounded-full transition-all duration-500",
                      isCompleted
                        ? "bg-primary"
                        : "bg-gray-200 dark:bg-gray-700"
                    )}
                  />
                </div>
              )}
            </li>
          );
        })}
      </ol>
    </nav>
  );
}

export { StepIndicator };

表单字段组件

// src/components/business/form-field.tsx
import { cn } from "@/lib/utils";
import type { ReactNode } from "react";

interface FormFieldProps {
  label: string;
  htmlFor: string;
  error?: string;
  required?: boolean;
  hint?: string;
  children: ReactNode;
}

function FormField({ label, htmlFor, error, required, hint, children }: FormFieldProps) {
  return (
    <div className="space-y-1.5">
      <label
        htmlFor={htmlFor}
        className="block text-sm font-medium text-foreground"
      >
        {label}
        {required && <span className="ml-0.5 text-red-500">*</span>}
      </label>

      {children}

      {error ? (
        <p className="flex items-center gap-1 text-xs text-red-500" role="alert">
          <svg className="h-3.5 w-3.5" fill="none" viewBox="0 0 24 24" stroke="currentColor" strokeWidth={2}>
            <path strokeLinecap="round" strokeLinejoin="round" d="M12 9v2m0 4h.01m-6.938 4h13.856c1.54 0 2.502-1.667 1.732-2.5L13.732 4c-.77-.833-1.964-.833-2.732 0L4.082 16.5c-.77.833.192 2.5 1.732 2.5z" />
          </svg>
          {error}
        </p>
      ) : hint ? (
        <p className="text-xs text-muted-foreground">{hint}</p>
      ) : null}
    </div>
  );
}

// 文本输入
function TextInput({
  error,
  className,
  ...props
}: React.InputHTMLAttributes<HTMLInputElement> & { error?: boolean }) {
  return (
    <input
      className={cn(
        "flex h-10 w-full rounded-md border bg-background px-3 py-2 text-sm transition-colors",
        "placeholder:text-muted-foreground",
        "focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring",
        "disabled:cursor-not-allowed disabled:opacity-50",
        error
          ? "border-red-500 focus-visible:ring-red-500/30"
          : "border-input",
        className
      )}
      {...props}
    />
  );
}

// 选择框
function SelectInput({
  error,
  options,
  placeholder,
  ...props
}: React.SelectHTMLAttributes<HTMLSelectElement> & {
  error?: boolean;
  options: Array<{ label: string; value: string }>;
  placeholder?: string;
}) {
  return (
    <select
      className={cn(
        "flex h-10 w-full rounded-md border bg-background px-3 py-2 text-sm transition-colors",
        "focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring",
        "disabled:cursor-not-allowed disabled:opacity-50",
        error
          ? "border-red-500 focus-visible:ring-red-500/30"
          : "border-input"
      )}
      {...props}
    >
      {placeholder && (
        <option value="" disabled>
          {placeholder}
        </option>
      )}
      {options.map((opt) => (
        <option key={opt.value} value={opt.value}>
          {opt.label}
        </option>
      ))}
    </select>
  );
}

// 多行文本
function TextareaInput({
  error,
  ...props
}: React.TextareaHTMLAttributes<HTMLTextAreaElement> & { error?: boolean }) {
  return (
    <textarea
      className={cn(
        "flex min-h-[80px] w-full rounded-md border bg-background px-3 py-2 text-sm transition-colors",
        "placeholder:text-muted-foreground",
        "focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring",
        "disabled:cursor-not-allowed disabled:opacity-50 resize-none",
        error
          ? "border-red-500 focus-visible:ring-red-500/30"
          : "border-input"
      )}
      {...props}
    />
  );
}

export { FormField, TextInput, SelectInput, TextareaInput };

多步骤表单向导页面

// src/pages/order-wizard.tsx
import { useState } from "react";
import { cn } from "@/lib/utils";
import { StepIndicator } from "@/components/business/step-indicator";
import { FormField, TextInput, SelectInput, TextareaInput } from "@/components/business/form-field";

const steps = [
  { label: "基本信息", description: "订单信息" },
  { label: "收货地址", description: "配送信息" },
  { label: "支付方式", description: "选择支付" },
  { label: "确认订单", description: "检查并提交" },
];

interface FormErrors {
  [key: string]: string;
}

function OrderWizard() {
  const [currentStep, setCurrentStep] = useState(0);
  const [errors, setErrors] = useState<FormErrors>({});

  function handleNext() {
    const stepErrors = validateStep(currentStep);
    if (Object.keys(stepErrors).length > 0) {
      setErrors(stepErrors);
      return;
    }
    setErrors({});
    setCurrentStep((prev) => Math.min(prev + 1, steps.length - 1));
  }

  function handlePrev() {
    setErrors({});
    setCurrentStep((prev) => Math.max(prev - 1, 0));
  }

  function validateStep(step: number): FormErrors {
    // 简化的校验逻辑示例
    if (step === 1) {
      return { phone: "请输入 11 位手机号" };
    }
    return {};
  }

  return (
    <div className="mx-auto max-w-3xl px-4 py-8">
      {/* 步骤指示器 */}
      <StepIndicator steps={steps} currentStep={currentStep} />

      {/* 表单内容区域 */}
      <div className="mt-10 rounded-xl border bg-card p-6 shadow-sm sm:p-8">
        {/* 步骤标题 */}
        <div className="mb-6 border-b pb-4">
          <h2 className="text-xl font-semibold">{steps[currentStep].label}</h2>
          <p className="mt-1 text-sm text-muted-foreground">
            请填写以下信息以继续
          </p>
        </div>

        {/* 步骤 1: 基本信息 */}
        <div className={cn(currentStep === 0 ? "block" : "hidden")}>
          <div className="grid grid-cols-1 gap-5 sm:grid-cols-2">
            <FormField label="订单类型" htmlFor="orderType" required>
              <SelectInput
                id="orderType"
                placeholder="请选择订单类型"
                options={[
                  { label: "标准订单", value: "standard" },
                  { label: "加急订单", value: "express" },
                  { label: "批量订单", value: "bulk" },
                ]}
              />
            </FormField>

            <FormField label="备注" htmlFor="remark">
              <TextInput id="remark" placeholder="选填" />
            </FormField>

            <div className="sm:col-span-2">
              <FormField label="商品描述" htmlFor="desc">
                <TextareaInput id="desc" placeholder="请描述商品信息..." rows={3} />
              </FormField>
            </div>
          </div>
        </div>

        {/* 步骤 2: 收货地址 */}
        <div className={cn(currentStep === 1 ? "block" : "hidden")}>
          <div className="grid grid-cols-1 gap-5 sm:grid-cols-2">
            <FormField label="收件人" htmlFor="name" required>
              <TextInput id="name" placeholder="请输入收件人姓名" />
            </FormField>

            <FormField
              label="手机号"
              htmlFor="phone"
              required
              error={errors.phone}
            >
              <TextInput
                id="phone"
                type="tel"
                placeholder="请输入 11 位手机号"
                error={!!errors.phone}
              />
            </FormField>

            <FormField label="省份" htmlFor="province" required>
              <SelectInput
                id="province"
                placeholder="请选择"
                options={[
                  { label: "广东省", value: "gd" },
                  { label: "浙江省", value: "zj" },
                  { label: "北京市", value: "bj" },
                ]}
              />
            </FormField>

            <FormField label="城市" htmlFor="city" required>
              <SelectInput
                id="city"
                placeholder="请先选择省份"
                options={[]}
              />
            </FormField>

            <div className="sm:col-span-2">
              <FormField
                label="详细地址"
                htmlFor="address"
                required
                hint="请填写街道、门牌号等详细信息"
              >
                <TextareaInput id="address" placeholder="如：XX路XX号XX大厦XX层" rows={2} />
              </FormField>
            </div>
          </div>
        </div>

        {/* 步骤 3: 支付方式 */}
        <div className={cn(currentStep === 2 ? "block" : "hidden")}>
          <div className="grid grid-cols-1 gap-3 sm:grid-cols-3">
            {[
              { id: "alipay", label: "支付宝", icon: "💳", desc: "推荐" },
              { id: "wechat", label: "微信支付", icon: "📱", desc: "扫码支付" },
              { id: "bank", label: "银行转账", icon: "🏦", desc: "1-3 个工作日" },
            ].map((method) => (
              <label
                key={method.id}
                className={cn(
                  "group relative flex cursor-pointer flex-col items-center rounded-xl border-2 p-6 transition-all duration-200",
                  "hover:border-primary/50 hover:bg-primary/5",
                  "has-[:checked]:border-primary has-[:checked]:bg-primary/5 has-[:checked]:ring-1 has-[:checked]:ring-primary"
                )}
              >
                <input
                  type="radio"
                  name="payment"
                  value={method.id}
                  className="sr-only"
                />
                <span className="text-3xl">{method.icon}</span>
                <span className="mt-2 text-sm font-semibold">{method.label}</span>
                <span className="mt-0.5 text-xs text-muted-foreground">{method.desc}</span>

                {/* 选中指示器 */}
                <div className="absolute right-2 top-2 hidden h-5 w-5 items-center justify-center rounded-full bg-primary text-white group-has-[:checked]:flex">
                  <svg className="h-3 w-3" fill="none" viewBox="0 0 24 24" stroke="currentColor" strokeWidth={3}>
                    <path strokeLinecap="round" strokeLinejoin="round" d="M5 13l4 4L19 7" />
                  </svg>
                </div>
              </label>
            ))}
          </div>
        </div>

        {/* 步骤 4: 确认订单 */}
        <div className={cn(currentStep === 3 ? "block" : "hidden")}>
          <div className="space-y-4 rounded-lg bg-muted/50 p-6">
            <div className="flex justify-between border-b pb-3">
              <span className="text-sm text-muted-foreground">订单类型</span>
              <span className="text-sm font-medium">标准订单</span>
            </div>
            <div className="flex justify-between border-b pb-3">
              <span className="text-sm text-muted-foreground">收件人</span>
              <span className="text-sm font-medium">张三 138****1234</span>
            </div>
            <div className="flex justify-between border-b pb-3">
              <span className="text-sm text-muted-foreground">收货地址</span>
              <span className="text-sm font-medium text-right max-w-[60%]">广东省深圳市南山区XX路XX号</span>
            </div>
            <div className="flex justify-between border-b pb-3">
              <span className="text-sm text-muted-foreground">支付方式</span>
              <span className="text-sm font-medium">支付宝</span>
            </div>
            <div className="flex justify-between pt-2">
              <span className="font-semibold">订单总额</span>
              <span className="text-xl font-bold text-primary tabular-nums">¥2,340.00</span>
            </div>
          </div>
        </div>

        {/* 底部按钮 */}
        <div className="mt-8 flex items-center justify-between border-t pt-6">
          <button
            onClick={handlePrev}
            disabled={currentStep === 0}
            className={cn(
              "rounded-lg border px-6 py-2.5 text-sm font-medium transition-colors",
              currentStep === 0
                ? "cursor-not-allowed opacity-0"
                : "hover:bg-muted"
            )}
          >
            上一步
          </button>

          {currentStep === steps.length - 1 ? (
            <button className="rounded-lg bg-primary px-8 py-2.5 text-sm font-semibold text-primary-foreground shadow-md transition-all hover:bg-primary/90 hover:shadow-lg active:scale-[0.98]">
              提交订单
            </button>
          ) : (
            <button
              onClick={handleNext}
              className="rounded-lg bg-primary px-8 py-2.5 text-sm font-semibold text-primary-foreground shadow-md transition-all hover:bg-primary/90 hover:shadow-lg active:scale-[0.98]"
            >
              下一步
            </button>
          )}
        </div>
      </div>
    </div>
  );
}

export { OrderWizard };

知识点解析

1. 步骤三态样式

// 已完成：实心主色
"border-primary bg-primary text-primary-foreground"

// 当前步骤：浅色背景 + 光圈
"border-primary bg-primary/10 text-primary ring-4 ring-primary/20"

// 待完成：灰色空心
"border-gray-300 bg-white text-gray-500"

2. has-[:checked] 选择器

<label className="has-[:checked]:border-primary has-[:checked]:bg-primary/5">
  <input type="radio" className="sr-only" />
</label>

这是 CSS :has() 选择器的 Tailwind 变体——当 label 内部的 radio 被选中时，label 的样式发生变化。sr-only 让 radio 在视觉上隐藏但对屏幕阅读器可访问。

3. 错误状态样式

// 正常输入框
"border-input focus-visible:ring-ring"

// 错误输入框：红色边框 + 红色焦点环
"border-red-500 focus-visible:ring-red-500/30"

// 错误提示文字
"text-xs text-red-500"

4. 表单两列响应式

// 手机单列，桌面两列
"grid grid-cols-1 gap-5 sm:grid-cols-2"

// 某个字段独占一行
<div className="sm:col-span-2">

5. 步骤切换不用动画

// 用 hidden/block 切换显示，而非条件渲染
// 这样表单状态不会丢失
<div className={cn(currentStep === 0 ? "block" : "hidden")}>

避坑指南

坑：步骤连接线在移动端挤压变形

// 修复：给连接线加最小宽度
<div className="mx-2 min-w-[2rem] flex-1 sm:mx-4">

坑：has-[:checked] 浏览器兼容性

has() 选择器在 Chrome 105+ / Safari 15.4+ / Firefox 121+ 中支持。
如果需要兼容更老浏览器，改用 peer 变体：

<input className="peer sr-only" type="radio" />
<div className="peer-checked:border-primary peer-checked:bg-primary/5">
