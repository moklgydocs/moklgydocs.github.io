案例 4：暗色模式电商商品卡

TL;DR
用 Tailwind 的 dark: 变体构建一个完美适配明暗双模式的电商商品卡：图片悬浮放大效果、促销标签、价格删除线、收藏按钮动画。掌握暗色模式下颜色调配的核心原则。

完整实现

// src/components/business/product-card.tsx
import { useState } from "react";
import { cn } from "@/lib/utils";

interface Product {
  id: string;
  name: string;
  category: string;
  image: string;
  price: number;
  originalPrice?: number;
  rating: number;
  reviewCount: number;
  tags: Array<{ label: string; type: "new" | "hot" | "sale" }>;
  inStock: boolean;
}

const tagStyles = {
  new: "bg-blue-500 text-white",
  hot: "bg-red-500 text-white",
  sale: "bg-amber-500 text-white",
} as const;

function ProductCard({ product }: { product: Product }) {
  const [liked, setLiked] = useState(false);

  const discount = product.originalPrice
    ? Math.round((1 - product.price / product.originalPrice) * 100)
    : 0;

  return (
    <div
      className={cn(
        "group overflow-hidden rounded-2xl border transition-all duration-300",
        // 亮色模式
        "border-gray-200 bg-white shadow-sm hover:shadow-lg",
        // 暗色模式
        "dark:border-gray-800 dark:bg-gray-900 dark:hover:shadow-gray-900/50"
      )}
    >
      {/* 图片区域 */}
      <div className="relative aspect-square overflow-hidden bg-gray-100 dark:bg-gray-800">
        {/* 商品图片：hover 放大效果 */}
        <img
          src={product.image}
          alt={product.name}
          className="h-full w-full object-cover transition-transform duration-500 group-hover:scale-110"
        />

        {/* 促销标签 */}
        <div className="absolute left-3 top-3 flex flex-col gap-1.5">
          {product.tags.map((tag) => (
            <span
              key={tag.label}
              className={cn(
                "rounded-md px-2 py-0.5 text-xs font-bold shadow-sm",
                tagStyles[tag.type]
              )}
            >
              {tag.label}
            </span>
          ))}
        </div>

        {/* 折扣角标 */}
        {discount > 0 && (
          <div className="absolute right-3 top-3 rounded-full bg-red-500 px-2 py-1 text-xs font-bold text-white shadow-sm">
            -{discount}%
          </div>
        )}

        {/* 收藏按钮 */}
        <button
          onClick={() => setLiked(!liked)}
          className={cn(
            "absolute right-3 bottom-3 flex h-9 w-9 items-center justify-center rounded-full shadow-md backdrop-blur-sm transition-all duration-200",
            "bg-white/80 hover:bg-white dark:bg-gray-900/80 dark:hover:bg-gray-900",
            liked && "scale-110"
          )}
        >
          <svg
            className={cn(
              "h-5 w-5 transition-colors",
              liked
                ? "fill-red-500 text-red-500"
                : "fill-none text-gray-500 dark:text-gray-400"
            )}
            viewBox="0 0 24 24"
            stroke="currentColor"
            strokeWidth={2}
          >
            <path
              strokeLinecap="round"
              strokeLinejoin="round"
              d="M4.318 6.318a4.5 4.5 0 000 6.364L12 20.364l7.682-7.682a4.5 4.5 0 00-6.364-6.364L12 7.636l-1.318-1.318a4.5 4.5 0 00-6.364 0z"
            />
          </svg>
        </button>

        {/* 缺货遮罩 */}
        {!product.inStock && (
          <div className="absolute inset-0 flex items-center justify-center bg-black/50 backdrop-blur-sm">
            <span className="rounded-full bg-white/90 px-4 py-2 text-sm font-semibold text-gray-900">
              暂时缺货
            </span>
          </div>
        )}
      </div>

      {/* 信息区域 */}
      <div className="p-4">
        {/* 分类 */}
        <p className="text-xs font-medium uppercase tracking-wider text-muted-foreground">
          {product.category}
        </p>

        {/* 商品名称 */}
        <h3 className="mt-1.5 text-sm font-semibold text-gray-900 dark:text-gray-100 line-clamp-2 group-hover:text-primary transition-colors">
          {product.name}
        </h3>

        {/* 评分 */}
        <div className="mt-2 flex items-center gap-1.5">
          <div className="flex">
            {Array.from({ length: 5 }, (_, i) => (
              <svg
                key={i}
                className={cn(
                  "h-3.5 w-3.5",
                  i < Math.floor(product.rating)
                    ? "text-amber-400"
                    : "text-gray-300 dark:text-gray-600"
                )}
                fill="currentColor"
                viewBox="0 0 20 20"
              >
                <path d="M9.049 2.927c.3-.921 1.603-.921 1.902 0l1.07 3.292a1 1 0 00.95.69h3.462c.969 0 1.371 1.24.588 1.81l-2.8 2.034a1 1 0 00-.364 1.118l1.07 3.292c.3.921-.755 1.688-1.54 1.118l-2.8-2.034a1 1 0 00-1.175 0l-2.8 2.034c-.784.57-1.838-.197-1.539-1.118l1.07-3.292a1 1 0 00-.364-1.118L2.98 8.72c-.783-.57-.38-1.81.588-1.81h3.461a1 1 0 00.951-.69l1.07-3.292z" />
              </svg>
            ))}
          </div>
          <span className="text-xs text-muted-foreground">
            ({product.reviewCount})
          </span>
        </div>

        {/* 价格 */}
        <div className="mt-3 flex items-baseline gap-2">
          <span className="text-lg font-bold text-gray-900 dark:text-white tabular-nums">
            ¥{product.price}
          </span>
          {product.originalPrice && (
            <span className="text-sm text-muted-foreground line-through tabular-nums">
              ¥{product.originalPrice}
            </span>
          )}
        </div>

        {/* 加入购物车按钮 */}
        <button
          disabled={!product.inStock}
          className={cn(
            "mt-4 w-full rounded-lg py-2.5 text-sm font-semibold transition-all duration-200",
            product.inStock
              ? "bg-gray-900 text-white hover:bg-gray-800 active:scale-[0.98] dark:bg-white dark:text-gray-900 dark:hover:bg-gray-100"
              : "cursor-not-allowed bg-gray-100 text-gray-400 dark:bg-gray-800 dark:text-gray-600"
          )}
        >
          {product.inStock ? "加入购物车" : "缺货通知"}
        </button>
      </div>
    </div>
  );
}

export { ProductCard };

知识点解析

1. 暗色模式颜色调配原则

// 原则 1：背景色 — 亮色用 white，暗色用 gray-900
"bg-white dark:bg-gray-900"

// 原则 2：文字色 — 亮色用 gray-900，暗色用 gray-100
"text-gray-900 dark:text-gray-100"

// 原则 3：辅助文字 — 亮色用 gray-500，暗色用 gray-400
"text-gray-500 dark:text-gray-400"

// 原则 4：边框 — 亮色用 gray-200，暗色用 gray-800
"border-gray-200 dark:border-gray-800"

// 原则 5：按钮反转 — 亮色深底浅字，暗色浅底深字
"bg-gray-900 text-white dark:bg-white dark:text-gray-900"

2. 图片悬浮放大

// 关键：overflow-hidden 在父容器上，scale 在图片上
<div className="overflow-hidden">
  <img className="transition-transform duration-500 group-hover:scale-110" />
</div>
  • overflow-hidden 裁剪放大后超出的部分
  • group-hover:scale-110 悬停时放大 10%
  • duration-500 较长的过渡时间让放大更柔和

3. 半透明模糊背景

// 收藏按钮的毛玻璃效果
"bg-white/80 backdrop-blur-sm"

// 缺货遮罩
"bg-black/50 backdrop-blur-sm"

/80 是透明度修饰符（80% 不透明度），配合 backdrop-blur 实现毛玻璃效果。

4. 条件动画

// 点击收藏时弹跳效果
liked && "scale-110"
// 配合 transition-all 产生弹跳的视觉反馈

5. line-clamp-2 多行截断

<h3 className="line-clamp-2">很长很长的商品名称...</h3>

原生 CSS 的 -webkit-line-clamp 在 Tailwind 中一个类名搞定。

避坑指南

坑：dark: 变体太多导致类名爆炸

// Bad: 每个颜色都写 dark: 变体
"bg-white dark:bg-gray-900 text-gray-900 dark:text-gray-100 border-gray-200 dark:border-gray-800"

// Good: 用 CSS 变量方案，只在根节点切换变量
"bg-card text-card-foreground border-border"
// 在 CSS 变量中统一处理暗色模式

坑：backdrop-blur 性能

backdrop-blur 触发合成层 + GPU 绘制。
如果列表中有大量商品卡片同时使用 backdrop-blur，
可能导致移动端卡顿。

解决：只在 hover 时才启用 blur，或用纯色半透明替代。
