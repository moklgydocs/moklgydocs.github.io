内置进阶 Hooks 精讲：被低估的六大官方 Hook

TL;DR
大多数教程只讲 useState/useEffect/useRef，但 React 还提供了六个在中后台场景中极其实用的内置 Hook。useTransition 让搜索筛选不卡顿，useDeferredValue 让实时预览不阻塞，useId 解决表单无障碍，useLayoutEffect 解决弹窗定位闪烁，useImperativeHandle 让组件暴露命令式 API，useSyncExternalStore 桥接浏览器原生状态。

1. useTransition：标记"不那么紧急"的更新

适用场景

搜索输入框 + 大列表筛选——用户打字是紧急的（输入框要立刻响应），列表筛选是非紧急的（可以延迟渲染）。

底层原理

useTransition 将 startTransition 内的 setState 标记为低优先级。React 的并发调度器会优先处理高优先级更新（输入框），然后在空闲时处理低优先级更新（筛选列表）。如果低优先级更新还没完成时又来了新的高优先级更新，React 会中断低优先级的 Render，先处理新的高优先级更新。

import { useState, useTransition } from "react";

function OrderSearch({ orders }: { orders: Order[] }) {
  const [keyword, setKeyword] = useState("");
  const [filteredOrders, setFilteredOrders] = useState(orders);
  const [isPending, startTransition] = useTransition();

  function handleSearch(value: string) {
    // 紧急更新：输入框立刻响应
    setKeyword(value);

    // 非紧急更新：列表筛选可以延迟
    startTransition(() => {
      const filtered = orders.filter(
        (o) =>
          o.orderNo.includes(value) ||
          o.customerName.includes(value)
      );
      setFilteredOrders(filtered);
    });
  }

  return (
    <div>
      <input
        value={keyword}
        onChange={(e) => handleSearch(e.target.value)}
        placeholder="搜索订单号或客户名..."
      />
      {isPending && <span className="text-muted-foreground">搜索中...</span>}
      <OrderTable data={filteredOrders} />
    </div>
  );
}

2. useDeferredValue：延迟更新的"影子值"

适用场景

实时预览场景——用户在编辑器中修改内容，右侧实时预览。预览的渲染成本高（Markdown → HTML、图表重绘），不应该阻塞用户输入。

与 useTransition 的区别

  • useTransition：你控制 setState 的时机，将某个状态更新标记为低优先级
  • useDeferredValue：你控制 值的时机，传入一个值，React 返回它的"延迟版本"
import { useState, useDeferredValue, useMemo } from "react";

function MarkdownEditor() {
  const [content, setContent] = useState("");
  // deferredContent 是 content 的"影子"：content 每次变化，deferredContent 会延迟跟上
  const deferredContent = useDeferredValue(content);

  // 昂贵的预览渲染只在 deferredContent 变化时执行
  const preview = useMemo(
    () => renderMarkdown(deferredContent), // 假设这是一个昂贵的操作
    [deferredContent]
  );

  const isStale = content !== deferredContent;

  return (
    <div className="grid grid-cols-2 gap-4">
      {/* 编辑区：每次按键都立刻响应 */}
      <textarea
        value={content}
        onChange={(e) => setContent(e.target.value)}
        className="h-96 rounded border p-4 font-mono"
      />
      {/* 预览区：延迟更新，不阻塞输入 */}
      <div
        className={cn("h-96 overflow-auto rounded border p-4", isStale && "opacity-70")}
        dangerouslySetInnerHTML={{ __html: preview }}
      />
    </div>
  );
}

3. useId：无障碍表单的好帮手

适用场景

表单的 <label htmlFor> 和 <input id> 需要匹配的唯一 ID。手写 ID 在列表渲染时容易重复，Math.random() 在 SSR 时客户端和服务端不一致。

import { useId } from "react";

interface FormFieldProps {
  label: string;
  type?: string;
  error?: string;
}

function FormField({ label, type = "text", error }: FormFieldProps) {
  const id = useId(); // 生成 SSR 安全的唯一 ID

  return (
    <div>
      <label htmlFor={id} className="block text-sm font-medium">
        {label}
      </label>
      <input
        id={id}
        type={type}
        aria-describedby={error ? `${id}-error` : undefined}
        aria-invalid={!!error}
        className="mt-1 w-full rounded border px-3 py-2"
      />
      {error && (
        <p id={`${id}-error`} className="mt-1 text-sm text-destructive" role="alert">
          {error}
        </p>
      )}
    </div>
  );
}

// 在列表中使用也安全：每个 FormField 实例都有唯一 ID
function DynamicForm() {
  return (
    <>
      <FormField label="商品名称" /> {/* id=":r1:" */}
      <FormField label="数量" type="number" /> {/* id=":r2:" */}
      <FormField label="单价" type="number" /> {/* id=":r3:" */}
    </>
  );
}

4. useLayoutEffect：在浏览器绘制前执行

适用场景

需要同步读取 DOM 尺寸并立刻设置样式——比如 Tooltip 定位、弹窗位置计算。如果用 useEffect，用户会看到元素先出现在错误位置再跳到正确位置（闪烁）。

与 useEffect 的区别

渲染流程：
  组件函数执行 → Virtual DOM → Diff → 更新真实 DOM
  → useLayoutEffect（同步，阻塞绘制）
  → 浏览器绘制像素
  → useEffect（异步，不阻塞）
import { useLayoutEffect, useRef, useState } from "react";

function Tooltip({
  targetRef,
  children,
}: {
  targetRef: React.RefObject<HTMLElement | null>;
  children: React.ReactNode;
}) {
  const tooltipRef = useRef<HTMLDivElement>(null);
  const [position, setPosition] = useState({ top: 0, left: 0 });

  // useLayoutEffect：在浏览器绘制前计算位置，避免闪烁
  useLayoutEffect(() => {
    if (!targetRef.current || !tooltipRef.current) return;

    const targetRect = targetRef.current.getBoundingClientRect();
    const tooltipRect = tooltipRef.current.getBoundingClientRect();

    setPosition({
      top: targetRect.top - tooltipRect.height - 8,
      left: targetRect.left + (targetRect.width - tooltipRect.width) / 2,
    });
  }, [targetRef]);

  return (
    <div
      ref={tooltipRef}
      className="fixed z-50 rounded bg-foreground px-3 py-1.5 text-sm text-background shadow"
      style={{ top: position.top, left: position.left }}
    >
      {children}
    </div>
  );
}

5. useImperativeHandle：暴露命令式 API

适用场景

你封装了一个复杂组件（富文本编辑器、表格、抽屉），父组件需要命令式地调用它的方法（editor.focus()、table.scrollToRow(id)、drawer.open()）。

import { useImperativeHandle, useRef, useState, forwardRef } from "react";

// 定义暴露给父组件的方法接口
interface DrawerHandle {
  open: () => void;
  close: () => void;
  toggle: () => void;
}

const Drawer = forwardRef<DrawerHandle, { title: string; children: React.ReactNode }>(
  function Drawer({ title, children }, ref) {
    const [isOpen, setIsOpen] = useState(false);

    // 只暴露指定方法，不暴露整个 DOM
    useImperativeHandle(ref, () => ({
      open: () => setIsOpen(true),
      close: () => setIsOpen(false),
      toggle: () => setIsOpen((prev) => !prev),
    }));

    if (!isOpen) return null;

    return (
      <div className="fixed inset-y-0 right-0 w-96 border-l bg-card p-6 shadow-xl">
        <div className="flex items-center justify-between">
          <h2 className="text-lg font-bold">{title}</h2>
          <button onClick={() => setIsOpen(false)}>✕</button>
        </div>
        <div className="mt-4">{children}</div>
      </div>
    );
  }
);

// 父组件：命令式控制抽屉
function OrderPage() {
  const drawerRef = useRef<DrawerHandle>(null);

  return (
    <>
      <button onClick={() => drawerRef.current?.open()}>打开订单详情</button>
      <Drawer ref={drawerRef} title="订单详情">
        <p>订单内容...</p>
      </Drawer>
    </>
  );
}

6. useSyncExternalStore：桥接非 React 状态

适用场景

需要在 React 中订阅浏览器原生 API（window.matchMedia、navigator.onLine、document.visibilityState）或第三方非 React 状态库的数据。

import { useSyncExternalStore } from "react";

// 示例：监听网络在线状态
function useOnlineStatus(): boolean {
  return useSyncExternalStore(
    // subscribe: 告诉 React 如何订阅变化
    (callback) => {
      window.addEventListener("online", callback);
      window.addEventListener("offline", callback);
      return () => {
        window.removeEventListener("online", callback);
        window.removeEventListener("offline", callback);
      };
    },
    // getSnapshot: 获取当前值
    () => navigator.onLine,
    // getServerSnapshot: SSR 时的默认值
    () => true
  );
}

// 示例：监听页面可见性（标签页切换）
function usePageVisibility(): boolean {
  return useSyncExternalStore(
    (callback) => {
      document.addEventListener("visibilitychange", callback);
      return () => document.removeEventListener("visibilitychange", callback);
    },
    () => document.visibilityState === "visible",
    () => true
  );
}

// 业务使用：当网络断开时显示提示
function NetworkStatus() {
  const isOnline = useOnlineStatus();
  if (isOnline) return null;
  return (
    <div className="fixed bottom-4 left-1/2 -translate-x-1/2 rounded-lg bg-destructive px-4 py-2 text-destructive-foreground shadow-lg">
      网络已断开，请检查连接
    </div>
  );
}
