React 中后台架构知识库

React 中后台架构知识库

不是另一份 API 速查手册，而是一套从工程地基到性能屋顶、专为中后台 Admin 系统量身定制的架构实战指南。所有代码基于 React 18+ / TypeScript 严格模式 / shadcn/ui，可直接用于生产环境。

这份知识库解决什么问题？

中后台系统是前端工程中复杂度最高、维护周期最长的场景：

  • 动态路由 + 按钮级权限 → 一套 RBAC 拦不住几百个菜单
  • 千行级动态表单 → 用户点一下卡三秒
  • TanStack Table 二十列带筛选排序 → 渲染直接崩盘
  • 多标签页 KeepAlive → React 官方不支持你自己写

这份知识库就是为这些真实痛点而生。
