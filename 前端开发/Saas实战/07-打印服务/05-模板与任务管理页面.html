05 - 模板与任务管理页面

这一步解决什么问题？ 我们要完成打印服务最后两个核心页面 —— 模板管理（功能最丰富的 CRUD+ 发布归档+ 导入导出+ 渲染预览）和任务管理（最轻量的渲染+ 轮询+ 下载）。理解渲染预览中 Blob 错误检测、cancelled 竞态保护、React.memo 防循环闪烁，以及任务轮询中 setInterval 的清理机制，是这一步的重点。

        code: template.code ?? "",
        description: template.description ?? "",
        category: template.category ?? "",
        tags: template.tags ?? "",
        paperSize: template.paperSize ?? "A4",
        orientation: template.orientation ?? "Portrait",

        description: "",
        category: "",
        tags: "",

interface RenderPreviewDialogProps {
  open: boolean
  onOpenChange: (open: boolean) => void
  template: ReportTemplateListDto | null
}

function RenderPreviewDialog({ open, onOpenChange, template }: RenderPreviewDialogProps) {
  const [loading, setLoading] = useState(false)
  const [datasources, setDatasources] = useState<DataSourceConfigDto[]>([])
  const [selectedDsId, setSelectedDsId] = useState<string>("__none__")
  const [format, setFormat] = useState<ExportFormat>(EXPORT_FORMAT.PDF)
  const [directData, setDirectData] = useState("")
  const [xmlData, setXmlData] = useState("")
  const [params, setParams] = useState<Record<string, string>>({})
  const [paramDefs, setParamDefs] = useState<Array<{ name: string; type?: string; required?: boolean; defaultValue?: string }>>([])

  const templateId = open ? template?.id : null
  useEffect(() => {
    if (!templateId || !template) return

    let cancelled = false
    datasourcesApi.list({ isActive: true, maxResultCount: 100 }).then((res) => {
      if (cancelled) return
      const list = res.data?.items ?? []
      setDatasources(list)
      // 自动选中模板的默认数据源
      if (template.defaultDataSourceConfigId) {
        setSelectedDsId(template.defaultDataSourceConfigId)
        const ds = list.find((d) => d.id === template.defaultDataSourceConfigId)
        if (ds?.parameterDefinitions) {
          try {
            const defs = JSON.parse(ds.parameterDefinitions)
            setParamDefs(defs)
            const initial: Record<string, string> = {}
            for (const p of defs) initial[p.name] = p.defaultValue ?? ""
            setParams(initial)
          } catch { setParamDefs([]) }
        }
      }
    }).catch(() => {})

    return () => { cancelled = true }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [templateId])

  const handleDsChange = (dsId: string) => {
    setSelectedDsId(dsId)
    if (dsId === "__none__" || dsId === "__direct__") {
      setParamDefs([])
      setParams({})
      return
    }
    const ds = datasources.find((d) => d.id === dsId)
    if (ds?.parameterDefinitions) {
      try {
        const defs = JSON.parse(ds.parameterDefinitions)
        setParamDefs(defs)
        const initial: Record<string, string> = {}
        for (const p of defs) initial[p.name] = p.defaultValue ?? ""
        setParams(initial)
      } catch { setParamDefs([]); setParams({}) }
    } else {
      setParamDefs([])
      setParams({})
    }
  }

  // Check if the selected datasource is XML type
  const selectedDs = datasources.find((d) => d.id === selectedDsId)
  const isXmlDs = selectedDs?.type === DATA_SOURCE_TYPE.Xml

  const handleRender = async () => {
    if (!template) return
    setLoading(true)
    try {
      const input: Record<string, unknown> = {
        templateId: template.id,
        format,
        async: true,
      }
      if (selectedDsId === "__direct__") {
        if (directData.trim()) {
          try {
            input.directData = JSON.parse(directData)
          } catch {
            toast.error("直传数据 JSON 格式错误")
            setLoading(false)
            return
          }
        }
      } else if (selectedDsId !== "__none__") {
        input.dataSourceConfigId = selectedDsId
        const mergedParams: Record<string, string> = { ...params }
        // For XML data sources, inject __xml_data into parameters
        if (isXmlDs && xmlData.trim()) {
          mergedParams["__xml_data"] = xmlData
        }
        if (Object.keys(mergedParams).length > 0) {
          input.parameters = mergedParams
        }
      }

      const res = await jobsApi.render(input as unknown as import("@/types").RenderReportInput)

      // 异步模式：返回 { jobId, status }，渲染完成后站内通知
      if (input.async) {
        const jobId = (res.data as { jobId?: string })?.jobId
        toast.success(`渲染任务已提交${jobId ? `（${jobId.slice(0, 8)}...）` : ""}，完成后将通知您`)
        onOpenChange?.(false)
        return
      }

      // 同步模式：blob download / preview（backward compat）
      const rawBlob = res.data as BlobPart
      // 如果返回的 Blob 太小或类型为 JSON，可能是后端错误响应
      if (rawBlob instanceof Blob && rawBlob.size < 100 && rawBlob.type?.includes('json')) {
        const text = await rawBlob.text()
        try {
          const json = JSON.parse(text)
          throw new Error(json.message || json.title || '渲染失败')
        } catch (e) {
          if (e instanceof SyntaxError) throw new Error('渲染返回异常数据')
          throw e
        }
      }
      const mimeMap: Record<number, string> = {
        [EXPORT_FORMAT.PDF]: "application/pdf",
        [EXPORT_FORMAT.XLSX]: "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
        [EXPORT_FORMAT.DOCX]: "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
        [EXPORT_FORMAT.HTML]: "text/html",
        [EXPORT_FORMAT.PNG]: "image/png",
        [EXPORT_FORMAT.CSV]: "text/csv",
      }
      const blob = new Blob([res.data as BlobPart], { type: mimeMap[format] ?? "application/octet-stream" })
      const url = URL.createObjectURL(blob)

      if (format === EXPORT_FORMAT.PDF || format === EXPORT_FORMAT.HTML || format === EXPORT_FORMAT.PNG) {
        // Open in new tab for preview
        window.open(url, "_blank")
        // 延迟释放 Object URL，给新标签页足够时间加载
        setTimeout(() => URL.revokeObjectURL(url), 60000)
      } else {
        // Download
        const a = document.createElement("a")
        const extMap: Record<number, string> = {
          [EXPORT_FORMAT.PDF]: "pdf",
          [EXPORT_FORMAT.XLSX]: "xlsx",
          [EXPORT_FORMAT.DOCX]: "docx",
          [EXPORT_FORMAT.HTML]: "html",
          [EXPORT_FORMAT.PNG]: "png",
          [EXPORT_FORMAT.CSV]: "csv",
        }
        const ext = extMap[format] ?? "pdf"
        a.href = url
        a.download = `${template.name}.${ext}`
        a.click()
        URL.revokeObjectURL(url)
      }
      toast.success("渲染完成")
    } catch (err: any) {
      const msg = err?.response?.data?.message || err?.message || "渲染预览失败"
      toast.error(msg)
    } finally {
      setLoading(false)
    }
  }

  return (
    <Dialog key={template?.id ?? 'empty'} open={open} onOpenChange={onOpenChange}>
      <DialogContent className="max-w-lg max-h-[85vh] overflow-y-auto">
        <DialogHeader>
          <DialogTitle>渲染预览 — {template?.name}</DialogTitle>
        </DialogHeader>
        <div className="space-y-4 py-2">
          <div className="space-y-2">
            <Label>数据源</Label>
            <Select value={selectedDsId} onValueChange={handleDsChange}>
              <SelectTrigger>
                <SelectValue placeholder="选择数据源" />
              </SelectTrigger>
              <SelectContent>
                <SelectItem value="__none__">无数据（空渲染）</SelectItem>
                <SelectItem value="__direct__">直传 JSON 数据</SelectItem>
                {datasources.map((ds) => (
                  <SelectItem key={ds.id} value={ds.id}>
                    {ds.name} {ds.code ? `(${ds.code})` : ""}
                  </SelectItem>
                ))}
              </SelectContent>
            </Select>
          </div>

          {selectedDsId === "__direct__" && (
            <div className="space-y-2">
              <Label>JSON 数据</Label>
              <Textarea
                value={directData}
                onChange={(e) => setDirectData(e.target.value)}
                placeholder={'[{"orderId":"PO-001","amount":1000}]'}
                rows={6}
                className="font-mono text-sm"
              />
            </div>
          )}

          {isXmlDs && (
            <div className="space-y-2">
              <Label>XML 数据</Label>
              <Textarea
                value={xmlData}
                onChange={(e) => setXmlData(e.target.value)}
                placeholder={'<Orders>\n  <Order>\n    <Id>PO-001</Id>\n    <Amount>1000</Amount>\n  </Order>\n</Orders>'}
                rows={6}
                className="font-mono text-sm"
              />
              <p className="text-xs text-muted-foreground">XML 数据源需要传入 XML 数据，留空则渲染空报表</p>
            </div>
          )}

          {paramDefs.length > 0 && selectedDsId !== "__none__" && selectedDsId !== "__direct__" && (
            <div className="space-y-3">
              <Label className="text-muted-foreground">运行时参数</Label>
              <div className="grid grid-cols-2 gap-3">
                {paramDefs.map((p) => (
                  <div key={p.name} className="space-y-1">
                    <Label className="text-sm">
                      {p.name}
                      {p.required && <span className="text-destructive"> *</span>}
                    </Label>
                    <Input
                      value={params[p.name] ?? ""}
                      onChange={(e) => setParams((prev) => ({ ...prev, [p.name]: e.target.value }))}
                      placeholder={p.type ?? "string"}
                    />
                  </div>
                ))}
              </div>
            </div>
          )}

          <div className="space-y-2">
            <Label>导出格式</Label>
            <Select value={String(format)} onValueChange={(v) => setFormat(Number(v) as ExportFormat)}>
              <SelectTrigger>
                <SelectValue />
              </SelectTrigger>
              <SelectContent>
                {Object.entries(EXPORT_FORMAT_LABELS).map(([key, label]) => (
                  <SelectItem key={key} value={key}>{label}</SelectItem>
                ))}
              </SelectContent>
            </Select>
          </div>
        </div>
        <DialogFooter>
          <Button variant="outline" onClick={() => onOpenChange(false)} disabled={loading}>
            取消
          </Button>
          <Button onClick={handleRender} disabled={loading}>
            {loading ? "渲染中..." : "渲染预览"}
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}

  const [page, setPage] = useState(1)
  const [pageSize, setPageSize] = useState(20)

  const [deleteConfirm, setDeleteConfirm] = useState<ReportTemplateListDto | null>(null)
  const [publishConfirm, setPublishConfirm] = useState<ReportTemplateListDto | null>(null)

  const fileInputRef = useRef<HTMLInputElement>(null)

  const loadTemplates = useCallback(async () => {
    setLoading(true)
    try {
      const res = await templatesApi.list({
        keyword: keyword || undefined,
        status: statusFilter ? Number(statusFilter) : undefined,
        skipCount: (page - 1) * pageSize,
        maxResultCount: pageSize,
      })
      setTemplates(res.data?.items ?? [])
      setTotal(res.data?.totalCount ?? 0)
    } catch {
      toast.error("加载模板列表失败")
    } finally {
      setLoading(false)
    }
  }, [keyword, statusFilter, page, pageSize])

  useEffect(() => {
    loadTemplates()
  }, [loadTemplates])

  const handleCreate = () => {
    setEditingTemplate(null)
    setFormOpen(true)
  }

  const handleEdit = (template: ReportTemplateListDto) => {
    setEditingTemplate(template)
    setFormOpen(true)
  }

    if (!deleteConfirm) return

      await templatesApi.delete(deleteConfirm.id)
      toast.success("模板已删除")

    } catch {
      toast.error("删除模板失败")

    }

    } catch {
      toast.error("归档模板失败")
    } finally {
      setArchiveConfirm(null)
    }
  }

    const file = e.target.files?.[0]
    if (!file) return
    if (!file.name.endsWith(".frx")) {
      toast.error("请选择 .frx 文件")
      return

/**
 * 渲染报表对话框的 Props 接口
 * @property open - 对话框是否打开
 * @property onOpenChange - 对话框打开状态变更回调

interface RenderDialogProps {
  open: boolean
  onOpenChange: (open: boolean) => void
  onSuccess: () => void
}

/**
 * 渲染报表对话框组件
 * 选择已发布的模板和导出格式进行报表渲染，支持同步和异步两种模式。
 */
function RenderDialog({ open, onOpenChange, onSuccess }: RenderDialogProps) {
  const [loading, setLoading] = useState(false)
  const [templates, setTemplates] = useState<ReportTemplateListDto[]>([])
  const [selectedTemplateId, setSelectedTemplateId] = useState("")
  const [format, setFormat] = useState<ExportFormat>(EXPORT_FORMAT.PDF)
  const [asyncMode, setAsyncMode] = useState(false)

  useEffect(() => {
    if (open) {
      // 加载已发布的模板列表
      templatesApi.list({ status: TEMPLATE_STATUS.Published, maxResultCount: 100 }).then((res) => {
        setTemplates(res.data?.items ?? [])
      }).catch(() => {
        // 静默处理
      })
      setSelectedTemplateId("")
      setFormat(EXPORT_FORMAT.PDF)
      setAsyncMode(false)
    }
  }, [open])

  const handleRender = async () => {
    if (!selectedTemplateId) {
      toast.error("请选择模板")
      return
    }
    setLoading(true)
    try {
      const res = await jobsApi.render({
        templateId: selectedTemplateId,
        format,
        async: asyncMode,
      })
      if (asyncMode) {
        // 异步模式：返回 jobId
        const jobData = (res as unknown as { data: { jobId: string } }).data
        toast.success(`渲染任务已创建，JobId: ${jobData?.jobId?.slice(0, 8)}...`)
      } else {
        // 同步模式：下载文件
        const rawBlob = res.data as BlobPart
        if (rawBlob instanceof Blob && rawBlob.size < 100 && rawBlob.type?.includes('json')) {
          const text = await rawBlob.text()
          try {
            const json = JSON.parse(text)
            throw new Error(json.message || json.title || '渲染失败')
          } catch (e) {
            if (e instanceof SyntaxError) throw new Error('渲染返回异常数据')
            throw e
          }
        }
        const blob = new Blob([rawBlob], {
          type: format === EXPORT_FORMAT.PDF ? "application/pdf"
            : format === EXPORT_FORMAT.XLSX ? "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
            : format === EXPORT_FORMAT.DOCX ? "application/vnd.openxmlformats-officedocument.wordprocessingml.document"
            : format === EXPORT_FORMAT.HTML ? "text/html"
            : format === EXPORT_FORMAT.PNG ? "image/png"
            : "text/csv",
        })
        const url = URL.createObjectURL(blob)
        const a = document.createElement("a")
        const ext = EXPORT_FORMAT_LABELS[format]?.toLowerCase() ?? "pdf"
        a.href = url
        a.download = `report.${ext}`
        a.click()
        URL.revokeObjectURL(url)
        toast.success("渲染完成，文件已下载")
      }
      onSuccess()
      onOpenChange(false)
    } catch (err: any) {
      const msg = err?.response?.data?.message || err?.message || (asyncMode ? "创建渲染任务失败" : "渲染报表失败")
      toast.error(msg)
    } finally {
      setLoading(false)
    }
  }

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="max-w-md">
        <DialogHeader>
          <DialogTitle>渲染报表</DialogTitle>
        </DialogHeader>
        <div className="space-y-4 py-2">
          <div className="space-y-2">
            <Label>选择模板 *</Label>
            <Select value={selectedTemplateId} onValueChange={setSelectedTemplateId}>
              <SelectTrigger>
                <SelectValue placeholder="请选择已发布的模板" />
              </SelectTrigger>
              <SelectContent>
                {templates.map((t) => (
                  <SelectItem key={t.id} value={t.id}>
                    {t.name} {t.code ? `(${t.code})` : ""}
                  </SelectItem>
                ))}
              </SelectContent>
            </Select>
          </div>
          <div className="space-y-2">
            <Label>导出格式</Label>
            <Select value={String(format)} onValueChange={(v) => setFormat(Number(v) as ExportFormat)}>
              <SelectTrigger>
                <SelectValue />
              </SelectTrigger>
              <SelectContent>
                {Object.entries(EXPORT_FORMAT_LABELS).map(([key, label]) => (
                  <SelectItem key={key} value={key}>
                    {label}
                  </SelectItem>
                ))}
              </SelectContent>
            </Select>
          </div>
          <div className="flex items-center gap-2">
            <input
              type="checkbox"
              id="async-mode"
              checked={asyncMode}
              onChange={(e) => setAsyncMode(e.target.checked)}
              className="rounded border-muted-foreground"
            />

渲染预览 —— 同步 vs 异步的前端处理

渲染预览对话框是最核心的交互。它需要处理两种渲染模式的完全不同的响应：

异步模式（async=true）:
  请求 → POST /api/print/jobs/render { async: true }
  响应 → { jobId: "abc123...", status: 1 }
  后续 → 站内通知（SignalR）告知渲染完成

同步模式（async=false/undefined）:
  请求 → POST /api/print/jobs/render { responseType: "blob" }
  响应 → Blob（二进制文件流）
  处理 → PDF/HTML/PNG 在新标签页打开；XLSX/DOCX/CSV 触发下载

【易错点】 Blob 响应的特殊处理：后端可能返回 HTTP 200 但 body 是 JSON 错误（比如渲染失败但没抛异常）。前端必须检测 Blob 类型：

收到 Blob → 检查 size < 100 且 type 包含 "json" → 解析为 JSON → 提取错误信息
         → 否则 → 正常处理文件

这类似 ASP.NET Core 中 HttpClient 调用返回 200 OK 但 body 是错误 JSON 的场景 —— 你不能只看 HTTP 状态码，还要检查 Content-Type。

cancelled 标志防止竞态条件

在 RenderPreviewDialog 中，当用户快速切换不同模板时，前一个模板的数据源请求可能还没返回，后一个请求已经发出。这会导致竞态条件：

时间线:
  t0: 点击模板A → 发起 datasourcesApi.list()
  t1: 点击模板B → 发起 datasourcesApi.list()
  t2: 模板A的请求返回 → setDatasources(A的数据) ← 错误！应该用B的数据
  t3: 模板B的请求返回 → setDatasources(B的数据) ← 覆盖了，但中间态已经错误

解决方案是 cancelled 标志：

useEffect(() => {
  let cancelled = false          // 1. 创建标志
  datasourcesApi.list(...).then((res) => {
    if (cancelled) return        // 2. 检查标志，过时的响应直接丢弃
    setDatasources(...)
  })
  return () => { cancelled = true }  // 3. 清理时置标志
}, [templateId])                 // 4. templateId 变化时重新执行

ASP.NET Core 类比：这类似 CancellationToken 在异步方法中的用法。useEffect 的清理函数相当于 CancellationTokenSource.Cancel()。

🤔 导师提问：cancelled 标志是 React 处理竞态的经典方案。但还有另一种方案：用 AbortController 真正取消网络请求（axios 支持 signal 参数）。cancelled 标志只是"丢弃结果"，请求本身还是发出了；AbortController 则可以从浏览器层面取消请求。在什么场景下，"只丢弃结果"不够用，必须真正取消请求？

React.memo 防止渲染循环

【性能陷阱】 RenderPreviewDialog 用 React.memo 包裹，原因如下：

父组件 TemplatesPage 重渲染（如列表加载完成）
    ↓
所有子组件默认重渲染（包括 RenderPreviewDialog）
    ↓
Dialog 的 onOpenChange 触发 → 又重渲染 → 循环
    ↓
React.memo 打断循环：props 没变就不重渲染

但光用 React.memo 还不够 —— 如果 onOpenChange 每次渲染都是新函数引用，memo 会失效。所以还需要 useCallback：

const handlePreviewOpenChange = useCallback((open: boolean) => {
  if (!open) setPreviewTemplate(null)
}, [])

任务轮询机制

任务管理页面实现了简单的前端轮询来追踪异步任务：

创建异步渲染任务
    ↓
setPollingJobId(jobId)
    ↓
useEffect 启动 setInterval(3s)
    ↓
GET /api/print/jobs/{id} → 检查 status
    ↓
status === Completed → toast.success + 刷新列表
status === Failed → toast.error + 显示 errorMessage
status === Queued/Processing → 继续轮询

ASP.NET Core 类比：这类似 IHostedService 中 while (!token.IsCancellationRequested) { await Task.Delay(3000); ... } 的轮询模式。生产环境中更推荐用 SignalR 推送，但轮询作为兜底方案始终存在。

🤔 导师提问：任务轮询的 setInterval 在 useEffect 中创建，清理函数中 clearInterval。但如果用户在轮询期间切换到其他页面（组件卸载），clearInterval 会在清理函数中执行。这和 ASP.NET Core 中 IHostedService.StopAsync 被调用的场景类似。想想看：如果 clearInterval 没有在清理函数中调用，组件卸载后会发生什么？setJobs() 还能执行吗？

【设计取舍】 3 秒是轮询频率的经验值。太短（<1s）给后端造成压力，太长（>10s）用户体验差。如果后端是 Kubernetes 集群，频繁轮询还可能影响 HPA 的 CPU 阈值判定。

延迟释放 Object URL

【性能陷阱】 PDF 预览时，URL.createObjectURL 创建的 URL 不能立即释放：

window.open(url, "_blank")
// ❌ URL.revokeObjectURL(url)   ← 立即释放，新标签页加载失败！
setTimeout(() => URL.revokeObjectURL(url), 60000)  // ← 延迟 60s 释放

因为 window.open 只是打开新标签页，PDF 加载是异步的。如果立即调用 revokeObjectURL，浏览器还没来得及读取 Blob 数据，URL 就失效了。60 秒是经验值 —— 一般 PDF 加载不会超过 60 秒，加载完成后释放也不影响已加载的内容。

而对于 XLSX/DOCX/CSV 等下载文件，a.click() 是同步触发下载，可以立即释放：

a.click()
URL.revokeObjectURL(url)  // ✅ 下载已触发，可以立即释放

🤔 导师提问：URL.createObjectURL 创建的 Blob URL 占用浏览器内存，直到 revokeObjectURL 才释放。PDF 预览场景延迟 60s 释放是经验值，但如果用户连续预览 10 个 PDF，就会创建 10 个未释放的 Blob URL。在大数据量场景下，你会如何优化这个内存管理策略？（提示：考虑引用计数或全局 Blob URL 管理器）

踩坑提醒

  1. 选择同一文件时 onChange 不会触发：<input type="file"> 的已知行为，导入后必须重置 fileInputRef.current.value = ""，否则再次选择同一个 .frx 文件不会触发 onChange。
  2. cancelled 标志防止竞态条件：快速切换模板时，前一个数据源请求可能后返回。cancelled 标志确保过时的响应不会更新状态，相当于 ASP.NET Core 的 CancellationToken。
  3. Blob 响应可能包含 JSON 错误：后端可能返回 HTTP 200 但 body 是 JSON 错误。必须检测 Blob size < 100 且 type 包含 "json"，解析为 JSON 提取错误信息。
  4. URL.createObjectURL 不能立即释放：PDF 预览用 window.open 打开新标签页，加载是异步的。立即 revokeObjectURL 会导致新标签页加载失败。需延迟 60s 释放。
  5. React.memo 必须配合 useCallback：如果 onOpenChange 每次渲染都是新函数引用，React.memo 的浅比较会判定 props 变化，导致 memo 失效，引发 Dialog 循环闪烁。
  6. setInterval 必须在 useEffect 清理函数中 clearInterval：否则组件卸载后定时器仍在执行，造成内存泄漏和状态更新错误。
