文件分享

|

这一步解决什么问题？ 访问控制解决的是"内部授权"问题——给特定用户赋权。但实际业务中还需要外部分享：给没有账号的人发送文件链接，类似百度网盘的分享功能、Google Drive 的"任何人都可访问"链接。类比后端：如果说 ACL 是 [Authorize(Policy = "FileRead")]（需要登录），那分享链接就是 [AllowAnonymous] + 临时 Token（不需要登录，但有时间和次数限制）。

前置知识

  • 07 篇访问控制：ACL 授权（需要登录）vs 分享链接（允许匿名）的区别
  • 02 篇文件 API 层：shareApi（create、listByFile、revoke）的用法
  • 浏览器 Clipboard API 基础：navigator.clipboard.writeText()

🤔 导师提问：ACL 授权需要用户登录后才能访问，分享链接则允许匿名访问。类比后端，这就像 [Authorize] vs [AllowAnonymous] + Token 校验。分享链接的 Token 和 JWT Token 有什么本质区别？为什么分享链接不适合用 JWT？

分享链接生命周期

创建分享
    │
    ▼
生成 shareUrl + token
    │
    ├── 访问者打开链接 → accessCount++ → 检查 maxAccessCount → 检查 expiresAt
    │
    ├── 过期 / 超过次数 → 链接失效
    │
    └── 创建者主动撤销 → isRevoked = true

完整代码

来源：src/pages/file/share-dialog.tsx

import { useState, useEffect, useCallback, useRef } from "react"
import { toast } from "sonner"
import { Copy, Trash2, Link, Loader2, Plus, Clock, Check, Link2Off } from "lucide-react"
import {
  Dialog, DialogContent, DialogHeader, DialogTitle,
} from "@/components/ui/dialog"
import { Button } from "@/components/ui/button"
import { Label } from "@/components/ui/label"
import { Input } from "@/components/ui/input"
import { Card, CardContent } from "@/components/ui/card"
import { Badge } from "@/components/ui/badge"
import { Tooltip, TooltipContent, TooltipTrigger } from "@/components/ui/tooltip"
import { shareApi } from "@/api/file/share"
import type { ShareLinkDto } from "@/types"

interface ShareDialogProps {
  open: boolean
  onOpenChange: (open: boolean) => void
  fileId: string
  fileName: string
}

/** 有效期选项：小时数，0 表示永久 */
const EXPIRY_OPTIONS = [
  { label: "1天", value: "24" },
  { label: "3天", value: "72" },
  { label: "7天", value: "168" },
  { label: "30天", value: "720" },
  { label: "永久", value: "0" },
]

export default function ShareDialog({ open, onOpenChange, fileId, fileName }: ShareDialogProps) {
  const [links, setLinks] = useState<ShareLinkDto[]>([])
  const [loadingLinks, setLoadingLinks] = useState(false)
  const [creating, setCreating] = useState(false)
  const [revoking, setRevoking] = useState<string | null>(null)
  const [copiedLinkId, setCopiedLinkId] = useState<string | null>(null)
  const copyTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null)

  // 表单状态
  const [expiryHours, setExpiryHours] = useState("24")
  const [maxAccessCount, setMaxAccessCount] = useState("")

  /** 加载已有分享链接 */
  const loadLinks = useCallback(async () => {
    setLoadingLinks(true)
    try {
      const res = await shareApi.listByFile(fileId)
      setLinks(res.data ?? [])
    } catch {
      toast.error("加载分享链接失败")
    } finally {
      setLoadingLinks(false)
    }
  }, [fileId])

  useEffect(() => {
    if (open && fileId) {
      loadLinks()
    }
  }, [open, fileId, loadLinks])

> **🤔 导师提问**：`loadLinks` 在 `open && fileId` 时才触发，这是典型的"惰性加载"模式。类比后端，这就像不在页面初始化时加载所有数据，而是按需查询。如果改成打开页面就预加载所有文件的分享链接，会有什么性能问题？

  /** 创建新分享链接 */
  const handleCreate = async () => {
    setCreating(true)
    try {
      const hours = parseInt(expiryHours)
      const res = await shareApi.create({
        fileId,
        expiryHours: hours > 0 ? hours : undefined,
        maxAccessCount: maxAccessCount ? parseInt(maxAccessCount) : undefined,
      })
      if (res.success) {
        toast.success("分享链接创建成功")
        await loadLinks()
      } else {
        toast.error(res.message || "创建失败")
      }
    } catch {
      toast.error("创建分享链接失败")
    } finally {
      setCreating(false)
    }
  }

  /** 撤销分享链接 */
  const handleRevoke = async (shareId: string) => {
    setRevoking(shareId)
    try {
      const res = await shareApi.revoke(shareId)
      if (res.success) {
        toast.success("分享链接已撤销")
        setLinks((prev) => prev.filter((l) => l.id !== shareId))
      } else {
        toast.error(res.message || "撤销失败")
      }
    } catch {
      toast.error("撤销分享链接失败")
    } finally {
      setRevoking(null)
    }
  }

  /** 复制链接到剪贴板 */
  const copyLink = async (linkId: string, url: string) => {
    try {
      await navigator.clipboard.writeText(url)
      setCopiedLinkId(linkId)
      if (copyTimerRef.current) clearTimeout(copyTimerRef.current)
      copyTimerRef.current = setTimeout(() => setCopiedLinkId(null), 2000)
    } catch {
      toast.error("复制失败，请手动复制")
    }
  }

  const activeLinks = links.filter((l) => !l.isRevoked)
  const revokedLinks = links.filter((l) => l.isRevoked)

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="max-w-lg">
        <DialogHeader>
          <DialogTitle className="flex items-center gap-2">
            <Link className="h-4 w-4" />
            分享文件
          </DialogTitle>
          <p className="text-sm text-muted-foreground truncate">{fileName}</p>
        </DialogHeader>

        {/* 创建新分享 */}
        <Card>
          <CardContent className="space-y-4 pt-4">
            <p className="text-sm font-medium">创建新分享链接</p>

            <div className="space-y-2">
              <Label className="text-sm">有效期</Label>
              <div className="flex gap-1 flex-wrap">
                {EXPIRY_OPTIONS.map((opt) => (
                  <Badge
                    key={opt.value}
                    variant={expiryHours === opt.value ? "default" : "outline"}
                    className="cursor-pointer"
                    onClick={() => setExpiryHours(opt.value)}
                  >
                    {opt.label}
                  </Badge>
                ))}
              </div>
            </div>

            <div className="space-y-2">
              <Label className="text-sm">最大访问次数（留空不限）</Label>
              <Input
                type="number"
                min={1}
                placeholder="不限制"
                value={maxAccessCount}
                onChange={(e) => setMaxAccessCount(e.target.value)}
              />
            </div>

            <Button onClick={handleCreate} disabled={creating} className="w-full">
              {creating ? (
                <Loader2 className="mr-1.5 h-4 w-4 animate-spin" />
              ) : (
                <Plus className="mr-1.5 h-4 w-4" />
              )}
              {creating ? "创建中..." : "创建分享链接"}
            </Button>
          </CardContent>
        </Card>

        {/* 已有分享链接列表 */}
        <div className="space-y-2">
          <p className="text-sm font-medium">
            有效链接
            <span className="ml-1 text-muted-foreground text-xs">({activeLinks.length})</span>
          </p>

          {loadingLinks ? (
            <div className="flex items-center justify-center py-6">
              <Loader2 className="h-5 w-5 animate-spin text-muted-foreground" />
            </div>
          ) : activeLinks.length === 0 ? (
            <div className="flex flex-col items-center justify-center py-8 text-muted-foreground">
              <Link2Off className="h-10 w-10 mb-2" />
              <p className="text-sm">暂无有效分享链接</p>
            </div>
          ) : (
            <div className="max-h-48 overflow-y-auto space-y-2">
              {activeLinks.map((link) => (
                <ShareLinkCard
                  key={link.id}
                  link={link}
                  revoking={revoking === link.id}
                  isCopied={copiedLinkId === link.id}
                  onCopy={() => copyLink(link.id, link.shareUrl)}
                  onRevoke={() => handleRevoke(link.id)}
                />
              ))}
            </div>
          )}

          {revokedLinks.length > 0 && (
            <p className="text-xs text-muted-foreground">
              另有 {revokedLinks.length} 条已撤销链接
            </p>
          )}
        </div>
      </DialogContent>
    </Dialog>
  )
}

/** 计算分享链接剩余时间文本 */
function getRemainingText(expiresAt: string | null): string {
  if (!expiresAt) return "永久有效"
  const diff = new Date(expiresAt).getTime() - Date.now()
  if (diff <= 0) return "已过期"
  const minutes = Math.ceil(diff / (1000 * 60))
  if (minutes < 60) return `剩余 ${minutes} 分钟`
  const hours = Math.ceil(diff / (1000 * 60 * 60))
  if (hours < 24) return `剩余 ${hours} 小时`
  const days = Math.ceil(diff / (1000 * 60 * 60 * 24))
  return `剩余 ${days} 天`
}

/** 单条分享链接卡片 */
function ShareLinkCard({
  link, revoking, isCopied, onCopy, onRevoke,
}: {
  link: ShareLinkDto
  revoking: boolean
  isCopied: boolean
  onCopy: () => void
  onRevoke: () => void
}) {
  const expiresAt = link.expiresAt ? new Date(link.expiresAt).toLocaleString("zh-CN") : "永久"
  const remainingText = getRemainingText(link.expiresAt ?? null)
  const accessInfo =
    link.maxAccessCount != null
      ? `${link.accessCount}/${link.maxAccessCount} 次`
      : `已访问 ${link.accessCount} 次`

  return (
    <Card className="p-3">
      <CardContent className="p-0 space-y-2">
        <div className="flex items-center gap-1.5">
          <Input readOnly value={link.shareUrl} className="h-7 text-xs flex-1 bg-muted" />
          <Tooltip>
            <TooltipTrigger asChild>
              <Button size="icon" variant="outline" className="h-7 w-7 shrink-0" onClick={onCopy}>
                {isCopied ? <Check className="h-3 w-3 text-success" /> : <Copy className="h-3 w-3" />}
              </Button>
            </TooltipTrigger>
            <TooltipContent>{isCopied ? "已复制" : "复制链接"}</TooltipContent>
          </Tooltip>
          <Tooltip>
            <TooltipTrigger asChild>
              <Button
                size="icon" variant="outline"
                className="h-7 w-7 shrink-0 text-destructive hover:text-destructive"
                onClick={onRevoke} disabled={revoking}
              >
                {revoking ? <Loader2 className="h-3 w-3 animate-spin" /> : <Trash2 className="h-3 w-3" />}
              </Button>
            </TooltipTrigger>
            <TooltipContent>撤销分享</TooltipContent>
          </Tooltip>
        </div>
        <div className="space-y-0.5">
          <div className="flex items-center justify-between text-muted-foreground text-xs">
            <span>有效期至：{expiresAt}</span>
            <span>{accessInfo}</span>
          </div>
          <div className="flex items-center gap-1 text-muted-foreground text-xs">
            <Clock className="h-3 w-3" />
            <span>{remainingText}</span>
          </div>
        </div>
      </CardContent>
    </Card>
  )
}

逐行讲解

EXPIRY_OPTIONS — 小时制有效期

const EXPIRY_OPTIONS = [
  { label: "1天", value: "24" },
  { label: "3天", value: "72" },
  { label: "7天", value: "168" },
  { label: "30天", value: "720" },
  { label: "永久", value: "0" },
]
  • 用小时而非天：因为后端接口 CreateShareRequest.expiryHours 接受小时数。1天 = 24小时，7天 = 168小时。【设计取舍】用字符串 "24" 而非数字 24 是因为 Badge 的选中比较用字符串更方便（value 与 state 同类型）。

🤔 导师提问：EXPIRY_OPTIONS 中"永久"对应 value: "0"，传给后端时 expiryHours 为 undefined（因为 hours > 0 ? hours : undefined）。这意味着"永久"不是传 0 小时，而是不传过期时间。类比后端，这就像 DateTime? 为 null 表示永不过期——为什么不用 DateTime.MaxValue 表示"永远"？哪种语义更清晰？

copyLink — 剪贴板复制 + 自动恢复

const copyLink = async (linkId: string, url: string) => {
  try {
    await navigator.clipboard.writeText(url)
    setCopiedLinkId(linkId)
    if (copyTimerRef.current) clearTimeout(copyTimerRef.current)
    copyTimerRef.current = setTimeout(() => setCopiedLinkId(null), 2000)
  } catch {
    toast.error("复制失败，请手动复制")
  }
}
  • navigator.clipboard.writeText：现代浏览器 Clipboard API。【易错点】此 API 仅在 HTTPS 或 localhost 下可用，HTTP 环境会抛异常。
  • 2 秒自动恢复：复制成功后图标从 📋 变为 ✓，2 秒后恢复。用 useRef 存 timer，防止组件重渲染时 timer 丢失。

getRemainingText — 人性化剩余时间

function getRemainingText(expiresAt: string | null): string {
  if (!expiresAt) return "永久有效"
  const diff = new Date(expiresAt).getTime() - Date.now()
  if (diff <= 0) return "已过期"
  const minutes = Math.ceil(diff / (1000 * 60))
  if (minutes < 60) return `剩余 ${minutes} 分钟`
  const hours = Math.ceil(diff / (1000 * 60 * 60))
  if (hours < 24) return `剩余 ${hours} 小时`
  const days = Math.ceil(diff / (1000 * 60 * 60 * 24))
  return `剩余 ${days} 天`
}
  • Math.ceil：向上取整。"剩余 0.5 小时" 对用户不友好，应显示"剩余 1 小时"。【设计取舍】使用 Math.ceil 而非 Math.round，因为"剩余 23 分钟"比"剩余 0 小时"更有紧迫感。

activeLinks / revokedLinks 分离

const activeLinks = links.filter((l) => !l.isRevoked)
const revokedLinks = links.filter((l) => l.isRevoked)
  • 已撤销的链接不显示完整列表，只显示数量。避免界面杂乱。

🤔 导师提问：activeLinks 和 revokedLinks 是每次渲染时从 links 数组 filter 出来的，没有用 useMemo 缓存。类比后端，这就像每次请求都重新计算而非使用缓存。在这个场景下不缓存是可以接受的——为什么？什么情况下必须加 useMemo？

验证步骤

  1. 在文件管理器中选中一个文件，点击"分享"按钮，确认分享对话框打开并显示"暂无有效分享链接"
  2. 选择有效期"7天"，点击"创建分享链接"，确认成功后列表中出现新链接，状态显示"剩余 X 天"
  3. 点击链接旁边的复制按钮，确认图标从 📋 变为 ✓，2 秒后自动恢复为 📋
  4. 在浏览器新标签页（无登录状态）粘贴访问分享链接，确认可以访问文件内容
  5. 点击"撤销分享"，确认链接从"有效链接"列表中消失，再次访问该链接应返回"链接已失效"

踩坑提醒

  1. navigator.clipboard.writeText 仅在 HTTPS 或 localhost 下可用：HTTP 环境下此 API 会抛异常，代码中已用 try/catch 兜底并提示"复制失败，请手动复制"。部署到 HTTP 环境时用户只能手动复制链接。
  2. EXPIRY_OPTIONS 中"永久"的语义："永久"对应 value: "0"，传给后端时 expiryHours 为 undefined（因为 hours > 0 ? hours : undefined）。这意味着"永久"不是传 0 小时，而是不传过期时间。如果后端不理解 undefined（即字段缺失），可能会设置默认过期时间而非永久有效。
  3. copyTimerRef 防止内存泄漏：复制成功后用 useRef 存 timer，2 秒后恢复图标。如果组件在 2 秒内卸载，timer 仍会执行但 setCopiedLinkId(null) 不会报错（React 会忽略对已卸载组件的 setState）。

🤔 思考题

概念级：分享链接的两种限制条件是什么？分别对应 CreateShareRequest 的哪两个字段？

推理级：copyLink 函数中为什么用 copyTimerRef 存储定时器，而不是直接用 setTimeout 的返回值？如果组件在 2 秒内被卸载会怎样？

动手级：当前分享链接创建后需要手动复制。请设计一个"创建后自动复制"的 UX 改进（提示：在 handleCreate 成功后调用 copyLink，但需要拿到新创建链接的 ID）。
