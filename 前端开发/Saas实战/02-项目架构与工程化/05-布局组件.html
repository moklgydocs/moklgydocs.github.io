布局组件

布局组件

这一步解决什么问题？
路由系统搭好了，但页面还没有"骨架"——侧边栏、顶栏、内容区在哪里？本文将实现应用的三大布局组件：AppLayout（主布局框架）、AppSidebar（动态菜单侧边栏）、AppHeader（顶部导航栏），让每个路由页面都有一个统一的"画框"。

对于 ASP.NET Core 开发者来说，AppLayout 就是 _Layout.cshtml，AppSidebar 就是 _NavMenu.cshtml，<Outlet /> 就是 @RenderBody()——理解了这组对应关系，布局组件的逻辑就一目了然。

前置知识

前端布局 vs .NET 布局

前端组件.NET 对应说明
AppLayout_Layout.cshtml侧边栏 + 顶栏 + 内容区的整体框架
AppSidebar_NavMenu.cshtml左侧导航菜单，数据来自 API
AppHeader_LoginPartial.cshtml顶部用户信息、租户切换、面包屑
<Outlet />@RenderBody()子页面的渲染插槽
SidebarProvider_ViewStart.cshtml管理侧边栏的展开/折叠状态

关键区别：.NET 的布局是静态的，React 的布局是动态的

在 .NET 中，_Layout.cshtml 在服务端渲染一次就结束了。在 React 中，布局组件是持续渲染的——侧边栏的展开/折叠、租户的切换、菜单的加载状态都会触发重新渲染。这意味着布局组件需要处理"中间状态"（如加载中、加载失败），而 .NET 布局不需要。

import { Outlet } from "react-router-dom"
import { SidebarProvider, SidebarInset } from "@/components/ui/sidebar"
import { AppSidebar } from "./app-sidebar"
import { AppHeader } from "./app-header"

/**
 * 应用主布局组件
 *
 * 提供侧边栏 + 顶栏 + 内容区域的整体页面结构。
 * SidebarProvider 管理侧边栏的展开/折叠状态，
 * SidebarInset 自动适应侧边栏宽度偏移，
 * Outlet 渲染当前路由匹配的子页面。
 */
export function AppLayout() {
  return (
    <SidebarProvider>
      <AppSidebar />
      <SidebarInset>
        <AppHeader />
        <main className="flex-1 overflow-auto" style={{ scrollbarGutter: "stable" }}>
          <Outlet />
        </main>
      </SidebarInset>
    </SidebarProvider>
  )
}

src/components/layout/app-sidebar.tsx

import { useEffect } from "react"
import { useLocation, useNavigate } from "react-router-dom"
import { motion } from "framer-motion"
import {
  Sidebar,
  SidebarContent,
  SidebarGroup,
  SidebarGroupContent,
  SidebarGroupLabel,
  SidebarHeader,
  SidebarMenu,
  SidebarMenuButton,
  SidebarMenuItem,
  SidebarFooter,
} from "@/components/ui/sidebar"
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/collapsible"
import { ScrollArea } from "@/components/ui/scroll-area"
import { Logo } from "@/components/brand/logo"
import { LayoutDashboard, ChevronRight } from "lucide-react"
import { useMenuStore } from "@/stores/menu-store"
import { DynamicIcon } from "@/components/shared/dynamic-icon"
import { Skeleton } from "@/components/ui/skeleton"
import type { MenuDto } from "@/types"
import { MENU_TYPE } from "@/types"

/**
 * 动态菜单目录（Directory）渲染为可折叠分组
 */
function DynamicMenuGroup({ menu, isActive, navigate }: {
  menu: MenuDto
  isActive: (url: string) => boolean
  navigate: (url: string) => void
}) {
  const children = menu.children.filter(c => c.type !== MENU_TYPE.Button)

  // 权限过滤后可能所有子菜单都被移除，此时不渲染空目录
  if (children.length === 0) return null

  const hasActiveChild = children.some(c => isActive(c.path ?? ""))

  return (
    <Collapsible key={menu.id} defaultOpen={hasActiveChild} className="group/collapsible">
      <SidebarGroup>
        <CollapsibleTrigger asChild>
          <SidebarGroupLabel className="cursor-pointer hover:text-foreground transition-colors">
            {menu.icon && <DynamicIcon name={menu.icon} className="mr-1.5 h-3.5 w-3.5" />}
            {menu.name}
            <ChevronRight className="ml-auto h-3.5 w-3.5 transition-transform group-data-[state=open]/collapsible:rotate-90" />
          </SidebarGroupLabel>
        </CollapsibleTrigger>
        <CollapsibleContent>
          <SidebarGroupContent>
            <SidebarMenu>
              {children.map(child => (
                <SidebarMenuItem key={child.id}>
                  <SidebarMenuButton
                    isActive={isActive(child.path ?? "")}
                    onClick={() => {
                      if (child.type === MENU_TYPE.ExternalLink) {
                        window.open(child.path ?? "", "_blank")
                      } else {
                        navigate(child.path ?? "/")
                      }
                    }}
                    className="relative"
                  >
                    {isActive(child.path ?? "") && (
                      <motion.div
                        layoutId="sidebar-active"
                        className="absolute left-0 top-1/2 -translate-y-1/2 h-5 w-[3px] rounded-full bg-primary"
                        transition={{ type: "spring", stiffness: 350, damping: 30 }}
                      />
                    )}
                    {child.icon && <DynamicIcon name={child.icon} className="h-4 w-4" />}
                    <span>{child.name}</span>
                  </SidebarMenuButton>
                </SidebarMenuItem>
              ))}
            </SidebarMenu>
          </SidebarGroupContent>
        </CollapsibleContent>
      </SidebarGroup>
    </Collapsible>
  )
}

/**
 * 加载骨架屏
 */
function SidebarSkeleton() {
  return (
    <div className="space-y-4 px-3">
      {Array.from({ length: 6 }).map((_, i) => (
        <div key={i} className="space-y-2">
          <Skeleton className="h-4 w-24" />
          <Skeleton className="h-8 w-full" />
          <Skeleton className="h-8 w-full" />
        </div>
      ))}
    </div>
  )
}

/**
 * 应用侧边栏组件
 *
 * 从后端动态加载菜单，按权限过滤。
 * 仪表盘为硬编码入口，其余菜单从数据库读取。
 * 当前激活菜单项会显示带弹簧动画的左侧竖条指示器。
 */
export function AppSidebar() {
  const location = useLocation()
  const navigate = useNavigate()
  const { menus, loading, error, fetchMenus } = useMenuStore()

  useEffect(() => {
    fetchMenus("admin-web")
  }, [fetchMenus])

  const isActive = (url: string) =>
    url === "/" ? location.pathname === "/" : location.pathname.startsWith(url)

  return (
    <Sidebar>
      <SidebarHeader>
        <div className="px-3 py-3">
          <Logo />
        </div>
      </SidebarHeader>

      <SidebarContent>
        <ScrollArea className="flex-1">
          {/* 仪表盘 — 硬编码入口，始终可见 */}
          <SidebarGroup>
            <SidebarGroupContent>
              <SidebarMenu>
                <SidebarMenuItem>
                  <SidebarMenuButton
                    isActive={isActive("/")}
                    onClick={() => navigate("/")}
                    className="relative"
                  >
                    {isActive("/") && (
                      <motion.div
                        layoutId="sidebar-active"
                        className="absolute left-0 top-1/2 -translate-y-1/2 h-5 w-[3px] rounded-full bg-primary"
                        transition={{ type: "spring", stiffness: 350, damping: 30 }}
                      />
                    )}
                    <LayoutDashboard className="h-4 w-4" />
                    <span>仪表盘</span>
                  </SidebarMenuButton>
                </SidebarMenuItem>
              </SidebarMenu>
            </SidebarGroupContent>
          </SidebarGroup>

          {/* 动态菜单分组 */}
          {loading ? (
            <SidebarSkeleton />
          ) : error ? (
            <SidebarGroup>
              <SidebarGroupContent>
                <p className="text-xs text-muted-foreground px-3">菜单加载失败</p>
              </SidebarGroupContent>
            </SidebarGroup>
          ) : (
            menus.map(menu => (
              <DynamicMenuGroup
                key={menu.id}
                menu={menu}
                isActive={isActive}
                navigate={navigate}
              />
            ))
          )}
        </ScrollArea>
      </SidebarContent>

      <SidebarFooter>
        <div className="flex items-center justify-between px-4 py-2">
          <span className="text-[11px] text-muted-foreground/60">沐川科创 v1.0.0</span>
          <div className="flex items-center gap-1.5">
            <div className="h-1.5 w-1.5 rounded-full bg-success animate-pulse" />
            <span className="text-[11px] text-muted-foreground/60">在线</span>
          </div>
        </div>
      </SidebarFooter>
    </Sidebar>
  )
}

src/components/layout/app-header.tsx

import { useState } from "react"
import { useLocation, useNavigate } from "react-router-dom"
import { useAuth } from "@/hooks/use-auth"
import { useAuthStore } from "@/stores/auth-store"
import { authApi } from "@/api/auth/auth"
import { SidebarTrigger } from "@/components/ui/sidebar"
import { Button } from "@/components/ui/button"
import { Avatar, AvatarFallback } from "@/components/ui/avatar"
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu"
import { LogOut, User, Building2, MapPin, BadgeCheck, ChevronRight, Search, Check, ChevronDown, Loader2 } from "lucide-react"
import { Separator } from "@/components/ui/separator"
import { ThemeToggle } from "@/components/shared/theme-toggle"
import { NotificationBell } from "@/components/notification-bell"
import { CommandMenu, useCommandMenu } from "@/components/shared/command-menu"
import { getBreadcrumbs } from "@/lib/breadcrumbs"
import { toast } from "sonner"

/**
 * 应用顶部导航栏组件
 *
 * 包含侧边栏折叠按钮、面包屑导航、全局搜索、租户切换、
 * 通知铃铛、主题切换、用户下拉菜单等功能区域。
 */
export function AppHeader() {
  const { user, logout } = useAuth()
  const location = useLocation()
  const navigate = useNavigate()
  const { open: openCommand } = useCommandMenu()
  const { currentTenantId, currentTenantName, availableTenants, setTokens, setCurrentTenant } = useAuthStore()
  const [switchingTenant, setSwitchingTenant] = useState(false)

  /**
   * 切换租户处理函数
   * 调用后端接口获取新租户的令牌，更新本地状态并刷新页面
   * @param tenant - 目标租户信息
   */
  const handleSwitchTenant = async (tenant: { tenantId: string; tenantName: string }) => {
    if (tenant.tenantId === currentTenantId || switchingTenant) return
    setSwitchingTenant(true)
    try {
      const res = await authApi.switchTenant(tenant.tenantId)
      if (res.access_token) {
        setTokens(res.access_token, res.refresh_token)
        setCurrentTenant(tenant.tenantId, tenant.tenantName)
        toast.success(`已切换到「${tenant.tenantName}」`)
        window.location.reload()
      } else {
        toast.error("切换租户失败")
      }
    } catch {
      toast.error("切换租户失败")
    } finally {
      setSwitchingTenant(false)
    }
  }

  // 取用户名前两个字符作为头像缩写
  const initials = user?.displayName
    ?.split("")
    .slice(0, 2)
    .join("")
    .toUpperCase() ?? "AD"

  // 判断是否存在组织信息（用于展示额外的组织上下文）
  const hasOrgContext = user?.primaryCompanyName || user?.primaryOrgUnitName || user?.primaryPositionName
  const breadcrumbs = getBreadcrumbs(location.pathname)

  return (
    <>
      <header className="sticky top-0 z-30 flex h-14 items-center gap-3 border-b bg-background px-4">
        {/* 侧边栏折叠/展开按钮 */}
        <SidebarTrigger />
        <Separator orientation="vertical" className="h-5" />

        {/* Breadcrumbs */}
        {breadcrumbs.length > 0 && (
          <nav className="hidden md:flex items-center gap-1 text-sm">
            {breadcrumbs.map((crumb, i) => (
              <span key={i} className="flex items-center gap-1">
                {i > 0 && <ChevronRight className="h-3 w-3 text-muted-foreground/50" />}
                {crumb.href ? (
                  <button
                    className="text-muted-foreground hover:text-foreground transition-colors cursor-pointer"
                    onClick={() => navigate(crumb.href!)}
                  >
                    {crumb.label}
                  </button>
                ) : (
                  <span className="text-foreground font-medium">{crumb.label}</span>
                )}
              </span>
            ))}
          </nav>
        )}

        <div className="flex-1" />

        {/* Search trigger - 点击打开全局命令搜索面板 */}
        <button
          onClick={openCommand}
          className="hidden sm:inline-flex items-center gap-2 rounded-md border bg-background px-3 py-1.5 text-sm text-muted-foreground transition-colors hover:bg-accent hover:text-accent-foreground"
        >
          <Search className="h-3.5 w-3.5" />
          <span>搜索...</span>
          <kbd className="pointer-events-none hidden select-none items-center gap-0.5 rounded border bg-muted px-1.5 font-mono text-[10px] font-medium text-muted-foreground lg:inline-flex">
            <span className="text-xs">⌘</span>K
          </kbd>
        </button>

        {/* Tenant switcher - 多租户切换下拉框 */}
        {currentTenantName && (
          availableTenants && availableTenants.length > 1 ? (
            <DropdownMenu>
              <DropdownMenuTrigger asChild>
                <Button variant="outline" size="sm" className="gap-1.5 h-8" disabled={switchingTenant}>
                  {switchingTenant ? (
                    <Loader2 className="h-3.5 w-3.5 animate-spin" />
                  ) : (
                    <Building2 className="h-3.5 w-3.5" />
                  )}
                  <span className="text-sm max-w-[120px] truncate">{currentTenantName}</span>
                  <ChevronDown className="h-3 w-3" />
                </Button>
              </DropdownMenuTrigger>
              <DropdownMenuContent>
                <DropdownMenuLabel>切换租户</DropdownMenuLabel>
                <DropdownMenuSeparator />
                {availableTenants.map((t) => (
                  <DropdownMenuItem key={t.tenantId} onClick={() => handleSwitchTenant(t)}>
                    {t.tenantName}
                    {/* 当前租户显示勾选标记 */}
                    {t.tenantId === currentTenantId && <Check className="ml-auto h-4 w-4" />}
                  </DropdownMenuItem>
                ))}
              </DropdownMenuContent>
            </DropdownMenu>
          ) : (
            // 单租户时仅展示租户名称，不可切换
            <div className="hidden sm:flex items-center gap-1.5 text-sm text-muted-foreground">
              <Building2 className="h-3.5 w-3.5" />
              <span className="max-w-[120px] truncate">{currentTenantName}</span>
            </div>
          )
        )}

        {/* Org context (desktop) - 桌面端显示组织架构信息 */}
        {hasOrgContext && (
          <div className="hidden lg:flex items-center gap-2 text-sm text-muted-foreground">
            {user?.primaryCompanyName && (
              <span className="flex items-center gap-1">
                <Building2 className="h-3.5 w-3.5" />
                {user.primaryCompanyName}
              </span>
            )}
            {user?.primaryOrgUnitName && (
              <>
                <span className="text-muted-foreground/40">/</span>
                <span className="flex items-center gap-1">
                  <MapPin className="h-3.5 w-3.5" />
                  {user.primaryOrgUnitName}
                </span>
              </>
            )}
          </div>
        )}

        <NotificationBell />
        <ThemeToggle />

        {/* User menu - 用户下拉菜单 */}
        <DropdownMenu>
          <DropdownMenuTrigger asChild>
            <Button variant="ghost" className="relative h-8 w-8 rounded-full">
              <Avatar className="h-8 w-8">
                <AvatarFallback className="bg-primary/10 text-primary text-xs font-medium">
                  {initials}
                </AvatarFallback>
              </Avatar>
            </Button>
          </DropdownMenuTrigger>
          <DropdownMenuContent align="end" className="w-56">
            <DropdownMenuLabel>
              <div className="flex flex-col space-y-1">
                <p className="text-sm font-medium">{user?.displayName}</p>
                <p className="text-xs text-muted-foreground">{user?.email}</p>
                {user?.employeeNo && (
                  <p className="text-xs text-muted-foreground">
                    工号: {user.employeeNo}
                  </p>
                )}
              </div>
            </DropdownMenuLabel>

            {/* Org details (mobile: show in dropdown) - 移动端在菜单内展示组织信息 */}
            {hasOrgContext && (
              <>
                <DropdownMenuSeparator />
                <DropdownMenuLabel className="font-normal">
                  <div className="flex flex-col space-y-1 text-xs text-muted-foreground">
                    {user?.primaryCompanyName && (
                      <div className="flex items-center gap-1.5">
                        <Building2 className="h-3 w-3 shrink-0" />
                        <span>{user.primaryCompanyName}</span>
                      </div>
                    )}
                    {user?.primaryOrgUnitName && (
                      <div className="flex items-center gap-1.5">
                        <MapPin className="h-3 w-3 shrink-0" />
                        <span>{user.primaryOrgUnitName}</span>
                      </div>
                    )}
                    {user?.primaryPositionName && (
                      <div className="flex items-center gap-1.5">
                        <BadgeCheck className="h-3 w-3 shrink-0" />
                        <span>{user.primaryPositionName}</span>
                      </div>
                    )}
                  </div>
                </DropdownMenuLabel>
              </>
            )}

            <DropdownMenuSeparator />
            <DropdownMenuItem>
              <User className="mr-2 h-4 w-4" />
              个人设置
            </DropdownMenuItem>
            <DropdownMenuSeparator />
            <DropdownMenuItem onClick={logout} className="text-destructive">
              <LogOut className="mr-2 h-4 w-4" />
              退出登录
            </DropdownMenuItem>
          </DropdownMenuContent>
        </DropdownMenu>
      </header>

      {/* Command menu (Cmd+K) - 全局搜索命令面板 */}
      <CommandMenu />
    </>
  )
}

代码讲解

AppLayout — 三层嵌套结构

SidebarProvider（管理侧边栏状态：展开/折叠/宽度）
  ├── AppSidebar（左侧，宽度由 SidebarProvider 控制）
  └── SidebarInset（右侧，自动偏移以避免侧边栏遮挡）
       ├── AppHeader（固定在顶部，h-14）
       └── <main>（内容区域，flex-1 填满剩余空间）
            └── <Outlet />（子路由渲染在这里）

SidebarProvider 是 shadcn/ui 的上下文组件，它通过 React Context 在所有子组件中共享侧边栏状态。SidebarInset 监听侧边栏宽度变化，自动添加左内边距。

【性能陷阱】 SidebarProvider 使用 React Context 共享侧边栏状态。如果侧边栏状态频繁变化（如拖拽调整宽度时每次鼠标移动都更新宽度），所有消费 Context 的组件都会重渲染。shadcn/ui 的 SidebarProvider 内部做了优化（用 CSS 变量而非 state 控制宽度），但如果你自定义了侧边栏的状态管理，需要注意避免 Context 引起的级联重渲染。

.NET 类比：SidebarProvider = ViewData 字典，在 _Layout.cshtml 中设置，在 _NavMenu.cshtml 中读取。SidebarInset = CSS 的 margin-left: var(--sidebar-width)。

AppSidebar — 动态菜单的三种状态

首次渲染
  │
  ├─ loading=true → 显示 SidebarSkeleton（骨架屏）
  │
  ├─ error!=null → 显示"菜单加载失败"
  │
  └─ loading=false && menus.length>0 → 渲染动态菜单
       │
       ├─ 仪表盘（硬编码，始终可见）
       └─ menus.map(menu => DynamicMenuGroup)
            │
            ├─ 目录类型（Directory）→ 可折叠分组
            ├─ 菜单类型（Menu）→ 可点击的菜单项
            ├─ 按钮类型（Button）→ 过滤掉，不在侧边栏显示
            └─ 外链类型（ExternalLink）→ window.open 新窗口

DynamicMenuGroup — 折叠菜单的实现

<Collapsible defaultOpen={hasActiveChild}>

defaultOpen 控制菜单的初始展开状态。如果当前路由匹配某个子菜单，则自动展开父目录——这样用户刷新页面后侧边栏仍然是展开的。

【易错点】 defaultOpen 是非受控属性——它只在组件首次渲染时生效。如果用户手动折叠了一个目录，然后路由变化使得 hasActiveChild 变为 true，目录不会自动重新展开。如果你需要受控行为（路由变化时自动展开/折叠），应该用 open + onOpenChange 替代 defaultOpen。

.NET 类比：就像 _NavMenu.cshtml 中根据当前 URL 高亮对应的菜单项。但 .NET 是服务端渲染时一次性决定的，React 是客户端路由变化时动态更新的。

激活指示器的弹簧动画

<motion.div
  layoutId="sidebar-active"
  className="absolute left-0 top-1/2 -translate-y-1/2 h-5 w-[3px] rounded-full bg-primary"
  transition={{ type: "spring", stiffness: 350, damping: 30 }}
/>

layoutId="sidebar-active" 是 framer-motion 的共享布局动画。当激活菜单从一个项切换到另一个项时，竖条不会消失再出现，而是平滑滑动到新位置——就像一条竖条在两个位置之间移动。

AppHeader — 租户切换的逻辑

多租户用户（availableTenants.length > 1）
  → 显示下拉框，可以切换租户
  → 切换时：调用 API → 获取新 token → 更新 store → 刷新页面

单租户用户（availableTenants.length === 1）
  → 只显示租户名称，不可切换

无租户信息（currentTenantName 为空）
  → 不显示租户区域

切换租户后调用 window.location.reload() 而不是 React 路由跳转，是因为租户切换会影响所有 API 请求的 X-Tenant-Id 头。刷新页面可以确保所有组件都重新获取数据。

【设计取舍】 租户切换用 window.location.reload() 而不是 React 状态更新，是因为切换租户影响的数据太多了——菜单、权限、所有页面的 API 数据都变了。如果用 React 状态更新，需要手动清除所有 Store 和缓存，比刷新页面更复杂且容易遗漏。但 reload() 会丢失所有未保存的表单数据——这是一个已知的 trade-off。

🤔 导师提问：AppHeader 承担了面包屑、搜索、租户切换、通知、主题、用户菜单等多个职责。有人认为这违反了单一职责原则，应该拆分为更小的组件。但也有人认为 Header 就是一个"编排者"，它本身不应该有复杂逻辑，只是组合各子组件。你怎么看？类比后端，一个 Controller 也可以注入 5 个 Service——这算违反 SRP 吗？

踩坑提醒

  1. useEffect 的依赖项 [fetchMenus]。fetchMenus 来自 Zustand store，如果每次渲染都创建新引用，会导致无限循环。Zustand 保证了 store 方法的引用稳定性，所以不会出问题——但如果你用 useCallback 包裹 fetchMenus，要确保依赖项正确。

  2. motion.div 的 layoutId 在同一时间只能有一个活跃元素。如果同时有多个元素使用相同的 layoutId，动画会混乱。确保路由变化时旧的激活指示器先消失，新的再出现。

  3. handleSwitchTenant 中的 window.location.reload()。这会导致整个应用重新加载，所有状态都会丢失。这是刻意的设计——切换租户后所有数据都应该重新获取。如果不刷新页面，需要手动清除所有 store 和缓存，比刷新页面更复杂。

  4. 骨架屏组件 SidebarSkeleton 是静态的。它不模拟真实菜单结构，只是显示 6 个通用的加载条。这比真实的菜单骨架简单，但足以给用户"正在加载"的反馈。
