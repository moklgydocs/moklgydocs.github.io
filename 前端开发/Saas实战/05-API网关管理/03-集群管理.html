集群管理

|

这一步解决什么问题？ HTTP 客户端搭好了，现在来实现网关管理的第一个核心功能——集群管理。在 YARP 中，Cluster 是一组后端服务实例的集合。当路由匹配到请求后，会根据 Cluster 的负载均衡策略选择一个 Destination 转发。我们要实现集群的完整 CRUD，包括动态目标地址列表、负载均衡策略选择和健康检查配置。

前置知识

  • 01 篇 YARP 网关基础：Cluster 与 Destination 的关系、负载均衡策略（PowerOfTwoChoices / RoundRobin / Random / LeastRequests / FirstAlphabetical）
  • 02 篇网关 HTTP 客户端：gwHttp 实例的创建和使用方式
  • React useState + useEffect + useCallback 的基本用法

集群 API 层完整源码

src/api/gateway/clusters.ts

import { get, post, put, del } from "./http"
import type { ClusterDto, CreateClusterRequest, UpdateClusterRequest } from "@/types"

/** 网关集群管理 API，用于管理 API 网关的后端服务集群 */
export const clustersApi = {
  /** 获取所有集群列表 */
  getAll: () => get<ClusterDto[]>("/api/gateway/clusters"),

  /**
   * 根据 ID 获取集群详情
   * @param id 集群 ID
   */
  getById: (id: string) => get<ClusterDto>(`/api/gateway/clusters/${id}`),

  /**
   * 创建新集群
   * @param data 集群创建请求数据
   */
  create: (data: CreateClusterRequest) => post<ClusterDto>("/api/gateway/clusters", data),

  /**
   * 更新集群信息
   * @param id 集群 ID
   * @param data 集群更新请求数据
   */
  update: (id: string, data: UpdateClusterRequest) => put<ClusterDto>(`/api/gateway/clusters/${id}`, data),

  /**
   * 删除集群
   * @param id 集群 ID
   */
  delete: (id: string) => del<object>(`/api/gateway/clusters/${id}`),
}

逐行讲解

clustersApi 对象结构：

  • 标准五件套：getAll / getById / create / update / delete。
  • 后端类比：前端的 IClusterService，每个方法对应一个 Controller Action。

【易错点】delete 是 JavaScript 保留字，不能直接用作变量名。但作为对象属性名是合法的，所以 delete: (id) => del(...) 没问题。解构时要用 clustersApi.delete(id)，不能 const { delete } = clustersApi。

集群表单对话框完整源码

src/pages/gateway/clusters/cluster-form-dialog.tsx

import { useEffect, useState } from "react"
import type { ClusterDto, CreateClusterRequest, DestinationDto } from "@/types"

/**
 * 集群表单对话框的 Props 接口
 * @property open - 对话框是否打开
 * @property onOpenChange - 对话框打开状态变更回调
 * @property cluster - 正在编辑的集群数据，为 null 时表示新建模式
 * @property onSave - 保存回调，接收集群表单数据
 */
interface Props {
  open: boolean
  onOpenChange: (open: boolean) => void
  cluster: ClusterDto | null
  onSave: (data: CreateClusterRequest) => void
}

> **🤔 导师提问**：为什么 `onSave` 接收的是 `CreateClusterRequest` 而不是 `ClusterDto`？两者有什么区别？为什么不直接传整个表单状态？

/** 空的目标地址模板 */
const emptyDestination: DestinationDto = { destinationId: "default", address: "", health: null, isEnabled: true }

/**
 * 集群表单对话框组件
 * 用于新建或编辑 YARP 代理集群，支持配置集群 ID、负载均衡策略、目标地址和主动健康检查。
 */
export function ClusterFormDialog({ open, onOpenChange, cluster, onSave }: Props) {
  const [clusterId, setClusterId] = useState("")
  const [loadBalancingPolicy, setLoadBalancingPolicy] = useState("")
  const [description, setDescription] = useState("")
  /** 集群下的目标地址列表 */
  const [destinations, setDestinations] = useState<DestinationDto[]>([{ ...emptyDestination }])
  /** 是否启用主动健康检查 */
  const [healthCheckEnabled, setHealthCheckEnabled] = useState(false)
  /** 健康检查探针路径 */
  const [healthCheckPath, setHealthCheckPath] = useState("/health")
  /** 健康检查间隔（秒） */
  const [healthCheckIntervalSeconds, setHealthCheckIntervalSeconds] = useState(30)
  /** 健康检查超时时间（秒） */
  const [healthCheckTimeoutSeconds, setHealthCheckTimeoutSeconds] = useState(10)

  // 对话框打开时，根据是否为编辑模式初始化表单数据
  useEffect(() => {
    if (cluster) {
      // 编辑模式：填充已有集群数据
      setClusterId(cluster.clusterId)
      setLoadBalancingPolicy(cluster.loadBalancingPolicy || "")
      setDescription(cluster.description || "")
      setDestinations(cluster.destinations.length > 0 ? cluster.destinations : [{ ...emptyDestination }])
      setHealthCheckEnabled(cluster.healthCheckEnabled)
      setHealthCheckPath(cluster.healthCheckPath || "/health")
      setHealthCheckIntervalSeconds(cluster.healthCheckIntervalSeconds)
      setHealthCheckTimeoutSeconds(cluster.healthCheckTimeoutSeconds)
    } else {
      // 新建模式：重置为默认值
      setClusterId("")
      setLoadBalancingPolicy("")
      setDescription("")
      setDestinations([{ ...emptyDestination }])
      setHealthCheckEnabled(false)
      setHealthCheckPath("/health")
      setHealthCheckIntervalSeconds(30)
      setHealthCheckTimeoutSeconds(10)
    }
  }, [cluster, open])

  /** 提交表单，将表单数据传递给 onSave 回调 */
  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault()
    onSave({
      clusterId,
      loadBalancingPolicy: loadBalancingPolicy || undefined,
      description: description || undefined,
      destinations: destinations.filter(d => d.address), // 过滤掉地址为空的目标
      healthCheckEnabled,
      healthCheckPath: healthCheckEnabled ? (healthCheckPath || undefined) : undefined, // 未启用时不传健康检查路径
      healthCheckIntervalSeconds,
      healthCheckTimeoutSeconds,
    })
  }

  /** 更新指定索引的目标地址字段 */
  const updateDestination = (index: number, field: keyof DestinationDto, value: string | boolean) => {
    setDestinations(prev => prev.map((d, i) => i === index ? { ...d, [field]: value } : d))
  }

  /** 添加一个新的目标地址行 */
  const addDestination = () => {
    setDestinations(prev => [...prev, { destinationId: `dest-${prev.length}`, address: "", health: null, isEnabled: true }])
  }

  /** 移除指定索引的目标地址 */
  const removeDestination = (index: number) => {
    setDestinations(prev => prev.filter((_, i) => i !== index))
  }

  if (!open) return null

  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center bg-black/50" onClick={() => onOpenChange(false)}>
      <div className="w-full max-w-lg max-h-[90vh] overflow-y-auto rounded-lg bg-background p-6 shadow-lg" onClick={e => e.stopPropagation()}>
        <h2 className="text-lg font-semibold mb-4">{cluster ? "编辑集群" : "新建集群"}</h2>
        <form onSubmit={handleSubmit} className="space-y-4">
          <div>
            <label className="text-sm font-medium">集群 ID</label>
            <input
              value={clusterId}
              onChange={e => setClusterId(e.target.value)}
              required
              placeholder="如：authserver"
              className="mt-1 w-full rounded-md border px-3 py-2 text-sm"
            />
          </div>
          <div>
            <label className="text-sm font-medium">负载均衡策略</label>
            <select value={loadBalancingPolicy} onChange={e => setLoadBalancingPolicy(e.target.value)} className="mt-1 w-full rounded-md border px-3 py-2 text-sm">
              <option value="">默认 (PowerOfTwoChoices)</option>
              <option value="RoundRobin">RoundRobin</option>
              <option value="Random">Random</option>
              <option value="LeastRequests">LeastRequests</option>
              <option value="FirstAlphabetical">FirstAlphabetical</option>
            </select>
          </div>
          <div>
            <label className="text-sm font-medium">描述</label>
            <input
              value={description}
              onChange={e => setDescription(e.target.value)}
              placeholder="可选"
              className="mt-1 w-full rounded-md border px-3 py-2 text-sm"
            />
          </div>

          {/* 目标地址列表，支持动态增删 */}
          <div>
            <div className="flex items-center justify-between mb-2">
              <label className="text-sm font-medium">目标地址</label>
              <button type="button" onClick={addDestination} className="text-xs text-primary hover:underline">+ 添加</button>
            </div>
            <div className="space-y-2">
              {destinations.map((dest, i) => (
                <div key={i} className="flex gap-2 items-center">
                  <input
                    value={dest.destinationId}
                    onChange={e => updateDestination(i, "destinationId", e.target.value)}
                    placeholder="ID"
                    className="w-24 rounded-md border px-2 py-1.5 text-xs"
                  />
                  <input
                    value={dest.address}
                    onChange={e => updateDestination(i, "address", e.target.value)}
                    placeholder="http://moklgy.me:5000"
                    required
                    className="flex-1 rounded-md border px-2 py-1.5 text-xs font-mono"
                  />
                  <label className="flex items-center gap-1 text-xs">
                    <input type="checkbox" checked={dest.isEnabled} onChange={e => updateDestination(i, "isEnabled", e.target.checked)} />
                    启用
                  </label>
                  {/* 至少保留一个目标地址行 */}
                  {destinations.length > 1 && (
                    <button type="button" onClick={() => removeDestination(i)} className="text-xs text-destructive">删除</button>
                  )}
                </div>
              ))}
            </div>
          </div>

          {/* 主动健康检查 */}
          <div className="rounded-md border p-4 space-y-3">
            <label className="flex items-center gap-2 text-sm font-medium cursor-pointer">
              <input
                type="checkbox"
                checked={healthCheckEnabled}
                onChange={e => setHealthCheckEnabled(e.target.checked)}
              />
              启用主动健康检查（YARP Active Health Check）
            </label>
            {healthCheckEnabled && (
              <div className="space-y-3 pl-5">
                <div>
                  <label className="text-xs font-medium text-muted-foreground">探针路径</label>
                  <input
                    value={healthCheckPath}
                    onChange={e => setHealthCheckPath(e.target.value)}
                    placeholder="/health"
                    className="mt-1 w-full rounded-md border px-3 py-1.5 text-sm font-mono"
                  />
                  <p className="mt-0.5 text-xs text-muted-foreground">YARP 定期向此路径发 GET 请求，连续失败 3 次后将目标标记为不健康</p>
                </div>
                <div className="grid grid-cols-2 gap-3">
                  <div>
                    <label className="text-xs font-medium text-muted-foreground">检查间隔（秒）</label>
                    <input
                      type="number"
                      min={5}
                      value={healthCheckIntervalSeconds}
                      onChange={e => setHealthCheckIntervalSeconds(Number(e.target.value))}
                      className="mt-1 w-full rounded-md border px-3 py-1.5 text-sm"
                    />
                  </div>
                  <div>
                    <label className="text-xs font-medium text-muted-foreground">超时时间（秒）</label>
                    <input
                      type="number"
                      min={1}
                      value={healthCheckTimeoutSeconds}
                      onChange={e => setHealthCheckTimeoutSeconds(Number(e.target.value))}
                      className="mt-1 w-full rounded-md border px-3 py-1.5 text-sm"
                    />
                  </div>
                </div>
              </div>
            )}
          </div>

          <div className="flex justify-end gap-2 pt-4">
            <button type="button" onClick={() => onOpenChange(false)} className="rounded-md border px-4 py-2 text-sm">取消</button>
            <button type="submit" className="rounded-md bg-primary px-4 py-2 text-sm text-primary-foreground hover:bg-primary/90">保存</button>
          </div>
        </form>
      </div>
    </div>
  )
}

动态目标地址列表

const updateDestination = (index: number, field: keyof DestinationDto, value: string | boolean) => {
  setDestinations(prev => prev.map((d, i) => i === index ? { ...d, [field]: value } : d))
}

const addDestination = () => {
  setDestinations(prev => [...prev, { destinationId: `dest-${prev.length}`, address: "", health: null, isEnabled: true }])
}

const removeDestination = (index: number) => {
  setDestinations(prev => prev.filter((_, i) => i !== index))
}
  • updateDestination：map + 不可变更新 + 计算属性名 [field]: value。【易错点】不能直接修改 prev[index][field] = value，这会变异原数组，React 检测不到变化。
  • addDestination：追加新行，dest-${prev.length} 自动递增。
  • removeDestination：filter 移除指定索引，不可变方式。
  • 后端类比：BindingList<Destination> 的 Add / RemoveAt，用不可变方式实现。

【性能陷阱】updateDestination 每次调用都创建新数组。对于目标地址列表（通常 2~5 个），这个开销完全可以忽略。如果列表项超过 100 个，才需要考虑用 useReducer 优化。

负载均衡策略

<select value={loadBalancingPolicy} onChange={e => setLoadBalancingPolicy(e.target.value)}>
  <option value="">默认 (PowerOfTwoChoices)</option>
  <option value="RoundRobin">RoundRobin</option>
  <option value="Random">Random</option>
  <option value="LeastRequests">LeastRequests</option>
  <option value="FirstAlphabetical">FirstAlphabetical</option>
</select>
策略原理优点缺点适用场景
PowerOfTwoChoices（默认）随机选2个，挑请求少的无需全局状态，效率高不保证绝对均衡通用场景（推荐）
RoundRobin依次轮询均匀分配需要计数器状态请求处理时间均匀的服务
Random纯随机选择无状态，实现简单长期才趋于均衡无状态短请求
LeastRequests选当前连接数最少的最优利用需要跟踪连接数请求处理时间差异大
FirstAlphabetical按字母序选第一个简单可预测永远选同一个测试/调试环境

【设计取舍】默认策略选择 PowerOfTwoChoices 而非 RoundRobin，是因为前者在分布式环境中无需协调状态（不需要全局轮询计数器），且在实际场景中表现接近最优。

🤔 导师提问：AdminWeb 默认用 PowerOfTwoChoices 而不是简单的 RoundRobin，为什么它更适合真实流量？提示：想想负载均衡理论中的"二次随机选择"算法。

健康检查配置

  • {healthCheckEnabled && (...)} 条件渲染：只在启用时显示配置项。
  • 配置包括：探针路径（默认 /health）、检查间隔（默认 30s）、超时时间（默认 10s）。
  • 后端类比：YARP Active Health Check ≈ services.AddHealthChecks() + UseHealthChecks("/health")。

YARP 主动健康检查的工作机制：

  1. 网关按 healthCheckIntervalSeconds 间隔，向每个 Destination 的 healthCheckPath 发 GET 请求
  2. 如果 healthCheckTimeoutSeconds 内未响应，记为一次失败
  3. 连续失败 3 次后，将该 Destination 标记为 unhealthy
  4. 负载均衡器不再选择 unhealthy 的 Destination
  5. 一旦探针恢复，自动标记为 healthy 并重新加入负载均衡

列设计逐个讲解

目标地址列：多个 Destination 用 map 渲染，启用→绿色，禁用→删除线。这个列用 flex: 1 自适应宽度，因为地址文本长度不一。

健康检查列：启用→绿色徽章+探针路径+间隔；未启用→灰色徽章。类比 Kubernetes 的 readinessProbe 配置面板。

【易错点】健康检查列的 cellRenderer 参数名是 { data: record }，而不是 { data }。这是因为外层作用域已经有 data 变量，用 record 避免命名冲突。

操作列：pinned: "right" 固定在右侧，不会因为水平滚动而消失。

 * 展示网关代理集群列表，支持新建、编辑和删除集群。
 * 集群是 YARP 反向代理的核心概念，包含一组目标地址和负载均衡策略。
 */
export default function ClustersPage() {
  /** 集群列表数据 */
  const [clusters, setClusters] = useState<ClusterDto[]>([])
  /** 表格加载状态 */
  const [loading, setLoading] = useState(false)
  /** 新建/编辑对话框是否打开 */
  const [dialogOpen, setDialogOpen] = useState(false)
  /** 当前正在编辑的集群，为 null 时表示新建模式 */
  const [editingCluster, setEditingCluster] = useState<ClusterDto | null>(null)
  /** 待删除的集群，非 null 时显示删除确认框 */
  const [deleteTarget, setDeleteTarget] = useState<ClusterDto | null>(null)
  /** 删除操作进行中 */
  const [deleting, setDeleting] = useState(false)

  /** 获取集群列表 */
  const fetchClusters = useCallback(async () => {
    setLoading(true)
    try {
      const res = await clustersApi.getAll()
      if (res.success) setClusters(res.data ?? [])
    } catch {
      toast.error("获取集群列表失败")
    } finally {
      setLoading(false)
    }
  }, [])

  useEffect(() => { fetchClusters() }, [fetchClusters])

  /** 打开新建集群对话框 */
  const handleCreate = () => {
    setEditingCluster(null)
    setDialogOpen(true)
  }

  /** 打开编辑集群对话框 */
  const handleEdit = (cluster: ClusterDto) => {
    setEditingCluster(cluster)
    setDialogOpen(true)
  }

  /** 确认删除集群 */
  const handleDeleteConfirm = async () => {
    if (!deleteTarget) return
    setDeleting(true)
    try {
      const res = await clustersApi.delete(deleteTarget.id)
      if (res.success) {
        toast.success("删除成功")
        setDeleteTarget(null)
        await fetchClusters() // 删除成功后刷新列表
      } else {
        toast.error(res.message)
      }
    } catch {
      toast.error("删除失败")
    } finally {
      setDeleting(false)
    }
  }

  /** 保存集群（新建或更新） */
  const handleSave = async (data: CreateClusterRequest) => {
    try {
      if (editingCluster) {
        // 更新已有集群
        const res = await clustersApi.update(editingCluster.id, data)
        if (res.success) {
          toast.success("更新成功")
          setDialogOpen(false)
          await fetchClusters()
        } else {
          toast.error(res.message)
        }
      } else {
        // 创建新集群
        const res = await clustersApi.create(data)
        if (res.success) {
          toast.success("创建成功")
          setDialogOpen(false)
          await fetchClusters()
        } else {
          toast.error(res.message)
        }
      }
    } catch {
      toast.error("保存失败")
    }
  }

  // ... columns 定义（见上文） ...

  return (
    <div className="flex flex-col h-full">
      <PageToolbar
        title="集群管理"
        actions={
          <>
            <ToolbarButton icon={Plus} variant="primary" onClick={handleCreate}>
              新建集群
            </ToolbarButton>
            <ToolbarButton icon={RefreshCw} onClick={fetchClusters}>
              刷新
            </ToolbarButton>
          </>
        }
      />

      <AgTable
        columns={columns}
        data={clusters}
        total={clusters.length}
        loading={loading}
        rowKey="id"
      />

      {/* 集群新建/编辑表单对话框 */}
      <ClusterFormDialog
        open={dialogOpen}
        onOpenChange={setDialogOpen}
        cluster={editingCluster}
        onSave={handleSave}
      />

      {/* 删除确认对话框 */}
      <ConfirmDialog
        open={!!deleteTarget}
        onOpenChange={(open) => { if (!open) setDeleteTarget(null) }}
        title="删除集群"
        description={`确定删除集群 "${deleteTarget?.clusterId}" 吗？`}
        onConfirm={handleDeleteConfirm}
        loading={deleting}
        variant="destructive"
        type="danger"
        confirmLabel="删除"
      />
    </div>
  )
}

页面组件结构讲解

状态设计（6 个 useState）：

  • clusters + loading：列表数据 + 加载状态
  • dialogOpen + editingCluster：对话框开关 + 编辑目标（null = 新建模式）
  • deleteTarget + deleting：删除确认框 + 删除中状态

后端类比：这和 MVC 的 Controller 完全对应——fetchClusters = Index()，handleSave = Create()/Update()，handleDeleteConfirm = Delete()。区别是 MVC 返回 View，而 React 通过 setState 触发重新渲染。

CRUD 处理器模式：

  1. handleSave：判断 editingCluster 是否为 null → 决定调用 create 还是 update API → 成功后关闭对话框 + 刷新列表
  2. handleDeleteConfirm：调用 delete API → 成功后清除 deleteTarget + 刷新列表
  3. 所有处理器都遵循：try → 成功 → toast + 状态清理 → catch → toast 错误

ConfirmDialog 组件：variant="destructive" + type="danger" 表示危险操作，按钮用红色高亮。onOpenChange 回调中判断 !open 清除 deleteTarget，这是关闭确认框时重置状态的标准模式。

踩坑提醒

  1. useEffect 依赖数组必须包含 open：如果只依赖 cluster，关闭对话框后再打开同一个集群，useEffect 不会重新执行（因为 cluster 引用没变），表单数据可能是旧的。
  2. updateDestination 不能直接修改 prev[index][field]：这会变异原数组，React 检测不到变化，UI 不会更新。必须用 map + 不可变更新 + 计算属性名 [field]: value。
  3. delete 是 JavaScript 保留字：作为对象属性名合法，但解构时不能用 const { delete } = clustersApi，只能用 clustersApi.delete(id)。

  2. 点击"新建集群"，填写集群 ID（如 test-cluster）、一个目标地址（如 http://localhost:5000），点击保存
