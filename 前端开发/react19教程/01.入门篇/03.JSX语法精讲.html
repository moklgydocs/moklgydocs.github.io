JSX 语法精讲

JSX 语法精讲

学习目标

  • 理解 JSX 的本质（它不是 HTML！）
  • 掌握 JSX 的所有常用语法
  • 知道 JSX 编译后变成了什么

JSX 的本质：JavaScript 的语法扩展

很多初学者以为 JSX 就是「在 JS 里写 HTML」，这个理解是错的。

JSX 是 JavaScript 的语法扩展，它会被 Babel 编译成 React.createElement() 调用：

// 你写的 JSX
const element = <h1 className="title">Hello, React!</h1>;

// 编译后的 JavaScript（React 17+ 用 jsx 运行时）
const element = _jsx('h1', { className: 'title', children: 'Hello, React!' });

🔬 原理：JSX → 编译 → createElement() → 虚拟 DOM 对象 → 真实 DOM

所以 JSX 本质上就是在创建「描述 UI 的 JavaScript 对象」。理解这一点非常重要，后面学虚拟 DOM 时你会发现一切都串起来了。

基础语法

1. 表达式插值：{}

在 JSX 中，用花括号 {} 来嵌入 JavaScript 表达式：

const name = '张三';
const age = 25;

function Greeting() {
  return (
    <div>
      {/* 变量 */}
      <h1>你好，{name}!</h1>
      
      {/* 表达式 */}
      <p>明年你就 {age + 1} 岁了</p>
      
      {/* 函数调用 */}
      <p>当前时间: {new Date().toLocaleTimeString()}</p>
      
      {/* 三元表达式 */}
      <p>{age >= 18 ? '成年人' : '未成年人'}</p>
    </div>
  );
}

⚠️ 注意：{} 里只能放表达式（有返回值），不能放语句（if/for/switch）。

// ❌ 错误：if 是语句
<p>{if (true) { 'hello' }}</p>

// ✅ 正确：三元表达式
<p>{true ? 'hello' : 'bye'}</p>

2. 属性语法

JSX 中的属性名用 camelCase 而不是 HTML 的小写：

// HTML 属性 → JSX 属性
// class     → className  （因为 class 是 JS 关键字）
// for       → htmlFor    （因为 for 是 JS 关键字）
// tabindex  → tabIndex
// onclick   → onClick
// style     → style（但值必须是对象）

function StyledComponent() {
  return (
    <div>
      <label htmlFor="username">用户名</label>
      <input 
        id="username"
        className="input-field"
        tabIndex={1}
        style={{ color: 'red', fontSize: '16px' }}  // 注意：双花括号
        autoFocus  // 布尔属性：写了就是 true
      />
    </div>
  );
}

💡 为什么 style 要用对象？
因为 JSX 是 JavaScript，所以 style 值是一个 JS 对象。属性名用 camelCase（fontSize 而不是 font-size），值是字符串。

第一层 {} 表示「这是一个表达式」，第二层 {} 是 JS 对象字面量。

3. JSX 必须有一个根元素

// ❌ 错误：多个根元素
function App() {
  return (
    <h1>标题</h1>
    <p>内容</p>
  );
}

// ✅ 方案一：用 div 包裹
function App() {
  return (
    <div>
      <h1>标题</h1>
      <p>内容</p>
    </div>
  );
}

// ✅ 方案二：Fragment（不会生成多余 DOM）
function App() {
  return (
    <>
      <h1>标题</h1>
      <p>内容</p>
    </>
  );
}

💡 为什么必须有一个根元素？
因为 JSX 编译后是一个函数调用，函数只能返回一个值。<>...</> 是 <React.Fragment> 的语法糖，它让你可以返回多个元素而不创建额外的 DOM 节点。

4. JSX 注释

function App() {
  return (
    <div>
      {/* 这是 JSX 中的注释 */}
      <h1>Hello</h1>
      {/* 
        多行注释
        也是这样写 
      */}
    </div>
  );
}

进阶语法

5. 条件渲染

在 JSX 中实现条件渲染有三种常用方式：

function UserGreeting({ isLoggedIn, role, notifications }) {
  return (
    <div>
      {/* 方式一：三元表达式（二选一时用） */}
      {isLoggedIn ? <p>欢迎回来！</p> : <p>请登录</p>}
      
      {/* 方式二：&& 短路（显示/隐藏时用） */}
      {notifications > 0 && <span className="badge">{notifications}</span>}
      
      {/* 方式三：提取到变量中（逻辑复杂时用） */}
      {(() => {
        if (role === 'admin') return <AdminPanel />;
        if (role === 'editor') return <EditorPanel />;
        return <UserPanel />;
      })()}
    </div>
  );
}

⚠️ 踩坑警告：&& 短路有一个经典陷阱！

// ❌ 当 count 为 0 时，会渲染数字 "0"
{count && <p>{count} 条消息</p>}

// ✅ 显式转为布尔值
{count > 0 && <p>{count} 条消息</p>}
{!!count && <p>{count} 条消息</p>}

这是因为 JavaScript 中 0 && anything 的结果是 0，而 React 会把数字 0 渲染出来。这个坑我在生产环境中遇到过，页面突然出现一个孤零零的 "0"。

6. 列表渲染

用 map() 把数据数组转换为 JSX 数组：

function TodoList() {
  const todos = [
    { id: 1, text: '学习 React', done: true },
    { id: 2, text: '写一个项目', done: false },
    { id: 3, text: '部署上线', done: false },
  ];

  return (
    <ul>
      {todos.map(todo => (
        <li 
          key={todo.id}  // ⭐ key 是必须的！
          style={{ textDecoration: todo.done ? 'line-through' : 'none' }}
        >
          {todo.text}
        </li>
      ))}
    </ul>
  );
}

🔬 key 的原理：
React 用 key 来标识列表中的每个元素。当列表变化时，React 用 key 来判断哪些元素是新增的、删除的、还是移动的。

key 的规则：

  • ✅ 使用数据库 ID、UUID 等唯一且稳定的值
  • ❌ 不要用数组索引（index）作为 key（除非列表不会变化）
  • ❌ 不要用 Math.random()（每次渲染都变，key 就失去意义了）
// ❌ 用 index 做 key，当列表项重新排序或删除时会出 Bug
{todos.map((todo, index) => <li key={index}>{todo.text}</li>)}

7. 事件处理

function EventDemo() {
  // 事件处理函数
  const handleClick = (event) => {
    console.log('按钮被点击了', event);
  };

  const handleInputChange = (event) => {
    console.log('输入值:', event.target.value);
  };

  return (
    <div>
      {/* 基本事件绑定 */}
      <button onClick={handleClick}>点我</button>
      
      {/* 传参的方式 */}
      <button onClick={() => handleClick('参数')}>带参数</button>
      
      {/* 输入事件 */}
      <input onChange={handleInputChange} />
      
      {/* ⚠️ 常见错误 */}
      {/* ❌ 这样写会直接执行函数！ */}
      {/* <button onClick={handleClick()}>错误示范</button> */}
      
      {/* ✅ 传的是函数引用 */}
      <button onClick={handleClick}>正确</button>
    </div>
  );
}

🔬 事件系统原理：React 的事件不是直接绑定在 DOM 上的，而是通过事件委托统一绑定在根节点上。React 19 中事件委托绑定在 root 容器上。这样做的好处是减少了事件监听器的数量，提升了性能。

8. 动态 className

function DynamicClass({ isActive, isDisabled }) {
  // 方式一：模板字符串
  return <div className={`card ${isActive ? 'active' : ''}`}>...</div>;
  
  // 方式二：数组 join（多个条件时）
  const classes = [
    'card',
    isActive && 'active',
    isDisabled && 'disabled',
  ].filter(Boolean).join(' ');
  return <div className={classes}>...</div>;
  
  // 方式三：使用 clsx 库（推荐）
  // pnpm add clsx
  // import clsx from 'clsx';
  // return <div className={clsx('card', { active: isActive, disabled: isDisabled })}>...</div>;
}

实战案例：用户卡片组件

综合运用以上知识，写一个完整的用户卡片：

function UserCard({ user }) {
  const { name, avatar, role, isOnline, skills } = user;
  
  return (
    <div className={`user-card ${isOnline ? 'online' : 'offline'}`}>
      {/* 头像 */}
      <img 
        src={avatar} 
        alt={`${name} 的头像`}
        style={{ width: '80px', borderRadius: '50%' }}
      />
      
      {/* 基本信息 */}
      <h3>{name}</h3>
      <p className="role">{role}</p>
      
      {/* 在线状态 */}
      {isOnline && <span className="status-badge">🟢 在线</span>}
      
      {/* 技能列表 */}
      {skills.length > 0 && (
        <ul className="skills">
          {skills.map(skill => (
            <li key={skill}>{skill}</li>
          ))}
        </ul>
      )}
    </div>
  );
}

// 使用
function App() {
  const user = {
    name: '张三',
    avatar: '/avatar.png',
    role: '前端工程师',
    isOnline: true,
    skills: ['React', 'TypeScript', 'Node.js'],
  };
  
  return <UserCard user={user} />;
}
