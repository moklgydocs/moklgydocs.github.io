外部状态库对比

外部状态库对比

什么时候需要外部状态库？

信号说明
Context 层级太多Provider 嵌套超过 5 层
需要跨路由共享状态页面切换后状态要保持
复杂的异步数据管理缓存、轮询、乐观更新
需要 DevTools时间旅行调试、状态快照
高频更新导致性能问题Context 的不精确更新导致卡顿

主流方案对比

1. Zustand（推荐入门）

轻量、简单、不需要 Provider：

import { create } from 'zustand';

const useStore = create((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  reset: () => set({ count: 0 }),
}));

function Counter() {
  const { count, increment } = useStore();
  return <button onClick={increment}>{count}</button>;
}

2. Redux Toolkit（企业级标准）

功能完善，生态最大，适合大型团队：

import { createSlice, configureStore } from '@reduxjs/toolkit';
import { Provider, useSelector, useDispatch } from 'react-redux';

const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: (state) => { state.value += 1; }, // Immer 允许直接修改！
    decrement: (state) => { state.value -= 1; },
  },
});

const store = configureStore({ reducer: { counter: counterSlice.reducer } });

function Counter() {
  const count = useSelector((state) => state.counter.value);
  const dispatch = useDispatch();
  return <button onClick={() => dispatch(counterSlice.actions.increment())}>{count}</button>;
}

3. Jotai（原子化状态）

import { atom, useAtom } from 'jotai';

const countAtom = atom(0);
const doubleAtom = atom((get) => get(countAtom) * 2); // 派生原子

function Counter() {
  const [count, setCount] = useAtom(countAtom);
  const [double] = useAtom(doubleAtom);
  return <div>{count} × 2 = {double}</div>;
}

4. TanStack Query（服务端状态）

专门管理服务器数据的缓存、同步、更新：

import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';

function TodoList() {
  const { data: todos, isLoading } = useQuery({
    queryKey: ['todos'],
    queryFn: () => fetch('/api/todos').then(r => r.json()),
  });

  if (isLoading) return <p>加载中...</p>;
  return <ul>{todos.map(t => <li key={t.id}>{t.title}</li>)}</ul>;
}

选择指南

规模推荐原因
小型项目useState + Context够用就不引入依赖
中型项目Zustand简单、轻量、灵活
大型项目Redux Toolkit生态完善、DevTools 强大
服务端数据管理TanStack Query专业的缓存和同步方案
细粒度更新Jotai / Valtio原子化，精确更新

⚠️ 教训：不要在小项目中使用 Redux。我见过只有 3 个页面的应用用了 Redux，光是样板代码就比业务代码还多。选择最简单的够用方案。
