实战：表单

TailwindCSS 实战组件：表单 — 输入框 / 选择器 / 校验 / 多列布局

TL;DR
表单是中后台的核心交互载体。本文覆盖输入框、选择器、复选框、单选、文件上传、校验反馈等全部表单元素的 Tailwind 实现，以及多列响应式表单布局。

💻 1. 基础表单元素

输入框

<!-- 标准输入框 -->
<div class="space-y-2">
  <label class="text-sm font-medium leading-none" for="username">
    用户名 <span class="text-destructive">*</span>
  </label>
  <input
    id="username"
    type="text"
    class="flex h-10 w-full rounded-md border border-input bg-background px-3 py-2 text-sm
           ring-offset-background 
           placeholder:text-muted-foreground 
           focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2
           disabled:cursor-not-allowed disabled:opacity-50"
    placeholder="请输入用户名"
  />
  <p class="text-xs text-muted-foreground">用户名将用于登录系统</p>
</div>

<!-- 带图标的输入框 -->
<div class="relative">
  <svg class="absolute left-3 top-1/2 size-4 -translate-y-1/2 text-muted-foreground" fill="none" stroke="currentColor" viewBox="0 0 24 24">
    <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M3 8l7.89 5.26a2 2 0 002.22 0L21 8M5 19h14a2 2 0 002-2V7a2 2 0 00-2-2H5a2 2 0 00-2 2v10a2 2 0 002 2z"/>
  </svg>
  <input class="h-10 w-full rounded-md border px-3 pl-9 text-sm placeholder:text-muted-foreground focus:outline-none focus:ring-2 focus:ring-ring" 
         placeholder="you@example.com" />
</div>

<!-- 错误状态 -->
<div class="space-y-2">
  <label class="text-sm font-medium text-destructive">邮箱</label>
  <input class="h-10 w-full rounded-md border border-destructive px-3 text-sm
                focus:outline-none focus:ring-2 focus:ring-destructive/20"
         value="invalid-email" />
  <p class="text-xs text-destructive">请输入有效的邮箱地址</p>
</div>

Textarea

📐 2. 多列表单布局

<form class="space-y-6">
  <!-- 标题区 -->
  <div>
    <h2 class="text-lg font-semibold">创建用户</h2>
    <p class="mt-1 text-sm text-muted-foreground">填写以下信息创建新用户账户</p>
  </div>
  
  <div class="h-px bg-border"></div>

  <!-- 两列布局 -->
  <div class="grid grid-cols-1 gap-4 sm:grid-cols-2 sm:gap-6">
    <div class="space-y-2">
      <label class="text-sm font-medium">姓名 <span class="text-destructive">*</span></label>
      <input class="h-10 w-full rounded-md border px-3 text-sm focus:outline-none focus:ring-2 focus:ring-ring" />
    </div>
    <div class="space-y-2">
      <label class="text-sm font-medium">邮箱 <span class="text-destructive">*</span></label>
      <input type="email" class="h-10 w-full rounded-md border px-3 text-sm focus:outline-none focus:ring-2 focus:ring-ring" />
    </div>
    <div class="space-y-2">
      <label class="text-sm font-medium">手机号</label>
      <input type="tel" class="h-10 w-full rounded-md border px-3 text-sm focus:outline-none focus:ring-2 focus:ring-ring" />
    </div>
    <div class="space-y-2">
      <label class="text-sm font-medium">部门</label>
      <select class="h-10 w-full rounded-md border px-3 text-sm focus:outline-none focus:ring-2 focus:ring-ring">
        <option>请选择</option>
        <option>研发部</option>
        <option>产品部</option>
      </select>
    </div>
    <!-- 全宽字段 -->
    <div class="space-y-2 sm:col-span-2">
      <label class="text-sm font-medium">备注</label>
      <textarea class="min-h-[80px] w-full rounded-md border px-3 py-2 text-sm resize-none focus:outline-none focus:ring-2 focus:ring-ring" rows="3"></textarea>
    </div>
  </div>

  <div class="h-px bg-border"></div>

  <!-- 操作按钮 -->
  <div class="flex justify-end gap-3">
    <button type="button" class="h-10 rounded-md border px-4 text-sm font-medium hover:bg-accent transition-colors">
      取消
    </button>
    <button type="submit" class="h-10 rounded-md bg-primary px-4 text-sm font-medium text-primary-foreground hover:bg-primary/90 transition-colors">
      创建用户
    </button>
  </div>
</form>

💣 3. 避坑指南

坑: 表单元素默认样式不一致

<!-- ✅ 使用 @tailwindcss/forms 插件统一默认样式 -->
<!-- npm install @tailwindcss/forms -->
<!-- plugins: [require('@tailwindcss/forms')] -->

<!-- 或手动重置基础样式 -->
<input class="h-10 w-full rounded-md border border-input bg-background px-3 text-sm
              focus:outline-none focus:ring-2 focus:ring-ring" />

🧠 4. 向 AI 提问的 Prompt 模板

请用 TailwindCSS 实现一个完整的用户编辑表单页面，包含：
1. 基本信息区：姓名/邮箱/手机（两列布局）
2. 角色权限区：角色选择 + 权限复选框组
3. 头像上传区：拖拽上传 + 预览
4. 表单校验：实时校验 + 错误提示 + 成功状态
5. 底部操作栏：取消/保存草稿/提交（Sticky）

响应式布局：移动端单列，桌面端两列。包含暗色模式适配。
