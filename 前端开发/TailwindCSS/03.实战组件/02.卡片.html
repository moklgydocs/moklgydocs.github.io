🧠 6. 向 AI 提问的 Prompt 模板

请用 TailwindCSS 实现以下 Admin 卡片组件：
1. Dashboard 统计卡片（4列，带趋势箭头和进度条）
2. 带图片的内容卡片（hover 图片放大 + 标题变色）
3. 设置项卡片（包含 Toggle 开关和保存按钮）
4. 空状态卡片（图标 + 描述 + CTA 按钮）

所有组件需要：暗色模式适配、响应式布局、hover 过渡动画。
输出可直接复制使用的 HTML 代码。
