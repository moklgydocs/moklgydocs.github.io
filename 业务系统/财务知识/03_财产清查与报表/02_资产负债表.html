资产负债表

资产负债表

资产负债表是企业的"快照"——它定格在某一个时点，告诉你：企业拥有什么、欠了多少、剩下的归谁。就像在柠檬水站收摊那一刻拍张照片，清点柠檬、现金、欠条，一览无余。

一、资产负债表的概念与作用

1.1 什么是资产负债表？

资产负债表是反映企业在某一特定日期财务状况的报表，其核心等式：

资产=负债+所有者权益资产 = 负债 + 所有者权益 资产=负债+所有者权益

1.2 资产负债表的作用

作用说明
反映资产规模与结构企业拥有多少资源，如何分布
反映负债水平企业承担多少债务，偿债压力大不大
反映所有者权益资产扣除负债后归投资者多少
分析偿债能力流动比率、速动比率、资产负债率
分析财务弹性资产变现能力、再融资空间

二、资产负债表的结构与格式

2.1 账户式结构

我国资产负债表采用账户式（左右式）结构：

排列规则：

项目排列顺序
资产流动性由强到弱（货币资金→固定资产）
负债到期日由近到远（短期借款→长期借款）
所有者权益永久性由强到弱（实收资本→未分配利润）

三、资产项目的填列方法

3.1 两种填列方法

填列方法说明举例
直接填列根据总账科目余额直接填列短期借款、实收资本
分析计算填列根据多个科目余额分析计算货币资金、存货、应收账款

3.2 重点项目填列方法

（1）货币资金

货币资金=库存现金+银行存款+其他货币资金货币资金 = 库存现金 + 银行存款 + 其他货币资金 货币资金=库存现金+银行存款+其他货币资金

（2）应收票据及应收账款

应收票据及应收账款=应收票据借方余额+应收账款借方余额+预收账款借方余额−坏账准备（应收部分）应收票据及应收账款 = 应收票据借方余额 + 应收账款借方余额 + 预收账款借方余额 - 坏账准备（应收部分） 应收票据及应收账款=应收票据借方余额+应收账款借方余额+预收账款借方余额−坏账准备（应收部分）

应收账款的"双重来源"

应收账款明细账中可能出现贷方余额（实为预收账款），应并入预收款项列示；同理，预收账款的借方余额应并入应收账款。这就是"重分类"——不要把债权当债务，也不要把债务当债权。

（3）存货

存货=原材料+在途物资+委托加工物资+生产成本+库存商品+发出商品+周转材料−存货跌价准备存货 = 原材料 + 在途物资 + 委托加工物资 + 生产成本 + 库存商品 + 发出商品 + 周转材料 - 存货跌价准备 存货=原材料+在途物资+委托加工物资+生产成本+库存商品+发出商品+周转材料−存货跌价准备

（4）固定资产

固定资产=固定资产原价−累计折旧−固定资产减值准备固定资产 = 固定资产原价 - 累计折旧 - 固定资产减值准备 固定资产=固定资产原价−累计折旧−固定资产减值准备

（5）短期借款

直接根据"短期借款"总账科目期末贷方余额填列。

（6）应付账款

应付账款=应付账款贷方余额+预付账款贷方余额应付账款 = 应付账款贷方余额 + 预付账款贷方余额 应付账款=应付账款贷方余额+预付账款贷方余额

（7）一年内到期的非流动负债

从长期借款、应付债券等非流动负债中，将一年内到期的部分分离出来填列。

五、练习题

练习1：货币资金与存货填列

某企业期末科目余额：库存现金 ¥2,000，银行存款 ¥198,000，其他货币资金 ¥30,000，原材料 ¥150,000，生产成本 ¥45,000，库存商品 ¥200,000，材料成本差异（借方）¥5,000，存货跌价准备 ¥12,000。

要求：计算资产负债表中"货币资金"和"存货"项目的金额。

参考答案
  • 货币资金 = 2,000＋198,000＋30,000 = ¥230,000
  • 存货 = 150,000＋45,000＋200,000＋5,000−12,000 = ¥388,000

练习2：重分类计算

某企业应收账款明细账：甲公司借余 ¥80,000，乙公司贷余 ¥15,000；预收账款明细账：丙公司贷余 ¥50,000，丁公司借余 ¥10,000。坏账准备（应收部分）¥5,000。

要求：计算资产负债表中"应收票据及应收账款"和"预收款项"的金额。

参考答案
  • 应收票据及应收账款 = 甲公司借余 80,000＋丁公司借余 10,000−坏账准备 5,000 = ¥85,000
  • 预收款项 = 丙公司贷余 50,000＋乙公司贷余 15,000 = ¥65,000

练习3：固定资产填列

某企业固定资产原价 ¥2,000,000，累计折旧 ¥600,000，固定资产减值准备 ¥80,000。另外在建工程 ¥300,000。

要求：计算资产负债表中"固定资产"和"在建工程"的金额。

参考答案
  • 固定资产 = 2,000,000−600,000−80,000 = ¥1,320,000
  • 在建工程 = ¥300,000（直接填列）

面试速查

  1. 核心等式：资产 = 负债 + 所有者权益（永远成立）
  2. 账户式：左资产、右负债+权益，流动性从强到弱排列
  3. 货币资金 = 库存现金 + 银行存款 + 其他货币资金
  4. 应收账款需重分类：应收借余 + 预收借余 − 坏账准备
  5. 存货 = 各存货科目借余之和 − 存货跌价准备
  6. 固定资产 = 原价 − 累计折旧 − 减值准备
  7. 一年内到期的非流动负债要从长期负债中分离出来
  8. 编完务必验证：资产总计 = 负债和所有者权益总计
