车间执行与报工

车间执行与报工

概述

车间执行是生产工单从下达到完工的具体操作环节，包括领料出库、工序生产、报工记录和完工入库。报工是车间工人记录每道工序的产出数量和工时的过程，是人工成本归集和生产进度跟踪的数据来源。

一、车间执行流程

工单下达
    │
    ▼
① 领料出库
   按工单物料清单到仓库领取原材料
   超领/补领需审批
    │
    ▼
② 工序执行
   按工艺路线依次执行各工序
   记录每道工序的开始/结束时间
    │
    ▼
③ 工序报工
   记录产出数量、合格数、报废数
   记录实际工时（准备时间+加工时间）
    │
    ▼
④ 工序流转
   当前工序完成 → 流转到下一工序
   最后工序完成 → 完工
    │
    ▼
⑤ 完工质检（可选）
    │
    ▼
⑥ 完工入库
   产成品入库，更新库存
   触发成本结转

二、核心实体

2.1 领料单

MaterialIssue (领料单)
├── Id: Guid
├── TenantId: Guid
├── IssueNo: string(30)               # 领料单号 MI-{YYYYMMDD}-{SEQ}
├── WorkOrderId: Guid                  # 关联工单
├── WorkOrderNo: string(30)
├── IssueType: IssueType              # 领料类型
├── IssueDate: DateTime                # 领料日期
├── WarehouseId: Guid                  # 领料仓库
├── RequesterId: Guid                  # 申请人
├── Status: IssueStatus
├── ApprovalStatus: ApprovalStatus?    # 超领需审批
├── VoucherId: Guid?
├── Remark: string(500)
└── Lines: List<MaterialIssueLine>

MaterialIssueLine (领料行)
├── Id: Guid
├── IssueId: Guid
├── WOMaterialId: Guid                 # 关联工单物料行
├── ItemId: Guid
├── ItemCode: string(50)
├── ItemName: string(200)
├── UnitOfMeasure: string(20)
├── RequiredQuantity: decimal(18,4)   # 需求数量
├── IssueQuantity: decimal(18,4)      # 本次领用数量
├── UnitCost: decimal(18,6)           # 出库单价
├── CostAmount: decimal(18,2)         # 出库成本
├── LocationId: Guid?                  # 库位
├── BatchNo: string(50)?              # 批次号
└── Remark: string(200)

枚举:
  IssueType: Normal=1(正常领料), Additional=2(补领), Return=3(退料)
  IssueStatus: Draft=0, Confirmed=1, Cancelled=-1

2.2 报工记录

WorkReport (报工记录)
├── Id: Guid
├── TenantId: Guid
├── ReportNo: string(30)               # 报工单号 WR-{YYYYMMDD}-{SEQ}
├── WorkOrderId: Guid
├── WorkOrderNo: string(30)
├── WOOperationId: Guid                # 关联工单工序
├── OperationNo: int                   # 工序号
├── OperationName: string(100)
├── WorkCenterId: Guid                 # 工作中心
│
├── ReportDate: DateTime               # 报工日期
├── WorkerId: Guid                     # 操作工/报工人
├── WorkerName: string(50)
├── ShiftCode: string(10)?             # 班次
│
├── SetupTime: decimal(18,2)          # 准备时间 (分钟)
├── RunTime: decimal(18,2)            # 加工时间 (分钟)
├── TotalTime: decimal(18,2)          # 总工时 (分钟)
├── MachineTime: decimal(18,2)?       # 机器工时 (分钟)
│
├── InputQuantity: decimal(18,4)      # 投入数量
├── OutputQuantity: decimal(18,4)     # 产出数量（合格）
├── ScrapQuantity: decimal(18,4)      # 报废数量
├── ReworkQuantity: decimal(18,4)     # 返工数量
│
├── LaborCostRate: decimal(18,2)      # 人工费率 (元/小时)
├── LaborCost: decimal(18,2)          # 人工成本
├── MachineCostRate: decimal(18,2)?   # 机器费率
├── MachineCost: decimal(18,2)?       # 机器成本
│
├── QualityIssue: string(500)?        # 质量问题描述
├── DowntimeMinutes: decimal(18,2)?   # 停机时间
├── DowntimeReason: string(200)?      # 停机原因
│
├── Status: ReportStatus
└── Remark: string(500)

枚举:
  ReportStatus: Draft=0, Confirmed=1, Cancelled=-1

三、在制品管理

3.1 在制品（WIP）计算

工单在制品价值 = 已投入材料成本 + 已投入人工成本 + 已分配制造费用 - 已完工入库成本

按工序统计:
  工序10: 材料投入 30,000 + 人工 5,000 = 35,000
  工序20: 人工追加 8,000 = 8,000
  已完工转出: -38,000
  在制品余额: 35,000 + 8,000 - 38,000 = 5,000

六、业务规则

规则描述
工单已下达只有 Released 及之后状态才能领料和报工
领料按BOM领料物料必须在工单物料清单中
超领审批超出需求量的领料需要审批
报工按工序必须按工序顺序报工（上一工序完成后才能报下一工序）
报废记录报废数量必须记录原因
完工不超计划完工入库累计不超过计划数量的 105%
完工成本完工入库时自动计算单位成本
退料冲减退料自动冲减已领料数量和成本
