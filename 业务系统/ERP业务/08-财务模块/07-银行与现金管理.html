银行与现金管理

银行与现金管理

概述

银行与现金管理子系统负责企业银行账户的统一管理、收付款业务处理、银行对账以及现金流监控。它是资金流的枢纽，连接应收（AR）的回款入账和应付（AP）的付款出账，确保账实相符和资金安全。

一、核心业务流程

1.1 收付款全流程

收款流程:
  客户回款 → 银行入账 → 系统登记 → 匹配应收 → 核销清账 → 生成凭证

付款流程:
  付款申请 → 审批通过 → 银行转账 → 系统登记 → 匹配应付 → 核销清账 → 生成凭证

现金管理:
  现金收入/支出 → 登记现金日记账 → 日终盘点 → 核对余额

1.2 银行对账流程

① 获取银行对账单
   ├── 手工导入 (Excel/CSV)
   └── 银企直连 (API 自动获取)
              │
              ▼
② 系统自动匹配
   ├── 金额+日期精确匹配
   ├── 金额匹配+日期模糊匹配（±3天）
   └── 摘要关键字匹配
              │
              ▼
③ 处理未匹配项
   ├── 企业已记银行未记 → 银行在途
   ├── 银行已记企业未记 → 补录交易
   └── 金额不一致 → 差异调查
              │
              ▼
④ 编制银行余额调节表
   企业账面余额 + 银行已记企业未记 - 企业已记银行未记 = 银行余额
              │
              ▼
⑤ 确认对账结果

二、核心实体

2.1 银行账户

BankAccount (银行账户)
├── Id: Guid
├── TenantId: Guid
├── AccountNo: string(30)              # 银行账号
├── AccountName: string(200)           # 账户名称
├── BankName: string(100)              # 开户银行
├── BranchName: string(100)            # 支行名称
├── BankCode: string(20)               # 银行编码（联行号）
├── AccountType: BankAccountType       # 账户类型
├── CurrencyCode: string(3)            # 币种
├── GLAccountId: Guid                  # 对应总账科目 (1002.xx)
├── CurrentBalance: decimal(18,2)      # 当前余额
├── IsDefault: bool                    # 是否默认账户
├── IsActive: bool                     # 是否启用
├── OpenDate: DateTime                 # 开户日期
├── ContactPerson: string(50)          # 联系人
├── ContactPhone: string(20)           # 联系电话
└── Remark: string(500)

枚举:
  BankAccountType: Basic=1(基本户), General=2(一般户), Temporary=3(临时户),
                   Special=4(专用户), Cash=5(现金账户)

2.2 银行交易

BankTransaction (银行交易)
├── Id: Guid
├── TenantId: Guid
├── TransactionNo: string(30)          # 交易编号
├── BankAccountId: Guid                # 银行账户ID
├── TransactionDate: DateTime          # 交易日期
├── ValueDate: DateTime                # 起息日
├── TransactionType: TransactionType   # 交易类型
├── Direction: TransactionDirection     # 收/付
├── Amount: decimal(18,2)             # 交易金额
├── BalanceAfter: decimal(18,2)       # 交易后余额
├── CounterpartyName: string(200)      # 对方名称
├── CounterpartyAccount: string(30)    # 对方账号
├── CounterpartyBank: string(100)      # 对方开户行
├── Reference: string(100)             # 银行参考号
├── Summary: string(200)               # 摘要
├── SourceType: TransactionSource      # 来源
├── SourceDocumentId: Guid?            # 来源单据ID
├── SourceDocumentNo: string(50)?
├── ReconcileStatus: ReconcileStatus   # 对账状态
├── ReconcileId: Guid?                 # 对账批次ID
├── VoucherId: Guid?                   # 关联凭证
└── Remark: string(500)

枚举:
  TransactionType: Transfer=1(转账), Cash=2(现金), Check=3(支票),
                   BankCharge=4(手续费), Interest=5(利息), Other=9
  TransactionDirection: In=1(收入), Out=2(支出)
  TransactionSource: Manual=0, ARReceipt=1, APPayment=2, BankStatement=3
  ReconcileStatus: Unreconciled=0, Reconciled=1, InDispute=2

2.3 银行对账

BankReconciliation (银行对账)
├── Id: Guid
├── TenantId: Guid
├── ReconcileNo: string(30)            # 对账编号
├── BankAccountId: Guid                # 银行账户
├── ReconcileDate: DateTime            # 对账日期
├── PeriodStart: DateTime              # 对账期间起
├── PeriodEnd: DateTime                # 对账期间止
├── BankStatementBalance: decimal(18,2) # 银行对账单余额
├── BookBalance: decimal(18,2)         # 企业账面余额
├── AdjustedBankBalance: decimal(18,2) # 调整后银行余额
├── AdjustedBookBalance: decimal(18,2) # 调整后账面余额
├── IsBalanced: bool                   # 是否平衡
├── Status: ReconcileStatus
├── ReconcileBy: Guid                  # 对账人
└── Items: List<ReconcileItem>

ReconcileItem (对账明细)
├── Id: Guid
├── ReconciliationId: Guid
├── BookTransactionId: Guid?           # 账面交易ID
├── StatementTransactionId: Guid?      # 银行流水ID
├── MatchType: MatchType               # 匹配类型
├── BookAmount: decimal(18,2)?        # 账面金额
├── StatementAmount: decimal(18,2)?   # 银行金额
├── Difference: decimal(18,2)         # 差异
├── Status: ItemStatus                 # 状态
└── Note: string(200)

枚举:
  MatchType: Matched=1(已匹配), BookOnly=2(仅账面有), StatementOnly=3(仅银行有)
  ItemStatus: Matched=1, PendingBookEntry=2, PendingInvestigation=3

2.4 银行对账单导入

BankStatement (银行对账单)
├── Id: Guid
├── TenantId: Guid
├── BankAccountId: Guid
├── ImportDate: DateTime                # 导入日期

├── TotalInAmount: decimal(18,2)       # 收入总额

├── TotalOutAmount: decimal(18,2)      # 支出总额
├── OpeningBalance: decimal(18,2)      # 期初余额
├── ClosingBalance: decimal(18,2)      # 期末余额
└── Lines: List<BankStatementLine>

BankStatementLine (对账单明细)
├── Id: Guid
├── StatementId: Guid
├── TransactionDate: DateTime
├── ValueDate: DateTime
├── Direction: TransactionDirection
├── Amount: decimal(18,2)
├── BalanceAfter: decimal(18,2)
├── CounterpartyName: string(200)
├── CounterpartyAccount: string(30)
├── Reference: string(100)             # 银行流水号
├── Summary: string(200)
├── IsMatched: bool                    # 是否已匹配
└── MatchedTransactionId: Guid?        # 匹配的账面交易ID

│                                │                                │

✅ 两边调整后余额必须相等，否则有差错需要排查

3.2 未达账项处理

类型说明处理方式
企业已记银行未记企业已入账但银行尚未处理等待银行处理，下期自动对冲
银行已记企业未记银行已入账但企业尚未登记根据银行通知补录交易

4.2 现金盘点

月末/日终现金盘点:
  系统账面余额 vs 实际清点金额
  差异 → 查明原因 → 调整:
    盘盈: 借 库存现金, 贷 营业外收入
    盘亏: 借 管理费用/其他应收款, 贷 库存现金

八、业务规则与约束

规则描述
银行账号唯一同一租户内银行账号不可重复
余额实时更新每笔交易后实时更新账户余额
收付分离收款和付款分别登记，不可合并
对账期间连续必须按月顺序对账，不可跳月
未达账项追踪上期未达账项本期自动带入
余额调节平衡调整后企业余额必须等于调整后银行余额
大额付款审批超过限额的付款必须经过审批
现金余额限额现金余额不得超过规定限额（如5万元）
对账后不可改已完成对账的交易不可修改
交易留痕所有交易操作全程审计追踪
