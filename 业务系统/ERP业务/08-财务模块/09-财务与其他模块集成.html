财务与其他模块集成

财务与其他模块集成

概述

财务模块作为 ERP 系统的核心中枢，与采购、销售、生产、MRP 四大业务模块深度集成。业务模块的单据在特定节点自动触发财务凭证的生成，实现"业财一体化"——业务操作即完成会计核算，无需手工重复录入。

二、采购模块 → 财务

2.1 集成触发点

采购事件触发时机财务操作目标子系统
收货入库GRN 确认暂估入账GL (存货科目)
采购发票发票登记生成应付、冲暂估AP + GL
三单匹配匹配完成更新应付金额AP
付款付款执行银行出账、核销应付AP + BANK
预付款预付确认预付账款入账GL + BANK
采购退货退货确认红冲入库凭证GL + AP

三、销售模块 → 财务

3.1 集成触发点

销售事件触发时机财务操作目标子系统
发货出库出库确认结转销售成本GL (存货→成本)
销售发票开票确认确认收入、生成应收AR + GL
客户回款回款确认银行入账、核销应收AR + BANK
预收款收款确认预收账款入账GL + BANK
销售退货退货确认红冲收入和成本AR + GL
折扣/折让审批通过调整收入AR + GL

销售产品A-销项税2221.02 销项税额13,000.00

摘要科目借方贷方辅助
结转销售成本5401 主营业务成本70,000.00产品:A
出库产品A1405 库存商品70,000.00

客户回款:

摘要科目借方贷方辅助
收XYZ公司货款1002 银行存款113,000.00银行:工商银行
收XYZ公司货款1122 应收账款113,000.00客户:XYZ

3.3 收入确认原则

条件说明
商品已交付风险报酬已转移（通常以发货或签收为准）
收入可计量金额已确定（发票开具）
成本可计量相关成本能够可靠计量
经济利益很可能流入客户信用良好，预计能收到款项

四、生产模块 → 财务

4.1 集成触发点

生产事件触发时机财务操作目标子系统
领料出库出库确认材料转入生产成本GL + COST
报工报工确认人工成本归集COST
制造费用发生费用入账制造费用归集GL + COST
制造费用分配月末分配费用分配至工单COST + GL
完工入库入库确认在制品→产成品GL + COST
废品/报废确认非正常损失GL

五、MRP/库存模块 → 财务

5.1 集成触发点

库存事件触发时机财务操作目标子系统
采购入库入库确认存货增加GL
销售出库出库确认存货减少GL
生产领料出库确认原材料→在制品GL
完工入库入库确认在制品→产成品GL
其他入库确认存货增加GL
其他出库确认存货减少GL
库存盘盈审批通过存货增加GL
库存盘亏审批通过存货减少GL
库存调拨确认仓库间转移GL（仓库辅助核算变更）

5.2 存货计价方法

方法说明凭证影响
加权平均法每次入库重新计算加权平均单价出库成本按平均单价
移动加权平均每次入库即时更新单价实时反映最新成本
先进先出 (FIFO)先入库的先出库出库成本按批次
个别计价法按具体批次/序列号出库成本按实际

6.2 凭证模板配置

VoucherTemplate (凭证模板)
├── Id: Guid
├── TenantId: Guid
├── Code: string(20)                   # 模板编码
├── Name: string(100)                  # 模板名称
├── SourceModule: string(20)           # 来源模块 (Purchase/Sales/Production/Inventory)
├── SourceEvent: string(50)            # 来源事件 (GoodsReceipt/SalesInvoice/...)
├── VoucherType: VoucherType           # 凭证类型
├── AutoPost: bool                     # 是否自动过账
├── IsActive: bool
└── Lines: List<VoucherTemplateLine>

VoucherTemplateLine (模板行)
├── Id: Guid
├── TemplateId: Guid
├── LineNo: int
├── SummaryTemplate: string(200)       # 摘要模板 (支持变量: {SupplierName}, {ProductName})
├── AccountMapping: string(50)         # 科目映射规则
├── Direction: string(1)               # D=借方, C=贷方
├── AmountExpression: string(200)      # 金额表达式 (Amount, TaxAmount, TotalAmount)
├── AuxCustomer: bool                  # 需要客户辅助
├── AuxSupplier: bool                  # 需要供应商辅助
├── AuxDepartment: bool                # 需要部门辅助
└── AuxProject: bool                   # 需要项目辅助

示例模板 — 采购入库:
  Line 1: D 1403(原材料)     Amount        "采购入库-{ProductName}"
  Line 2: D 2221.01(进项税)  TaxAmount     "进项税额"
  Line 3: C 2202(应付账款)   TotalAmount   "应付-{SupplierName}"  [辅助:供应商]

七、月结协同流程

7.1 跨模块月结步骤

月末关账流程 (必须按顺序执行):

Day 1-3: 业务截止
  ① 采购模块: 截止收货、发票登记
  ② 销售模块: 截止发货、开票
  ③ 生产模块: 截止报工、完工入库
  ④ 库存模块: 截止出入库、执行库存盘点

Day 3-5: 财务处理
  ⑤ 暂估入账核查: 未到票采购暂估是否准确
  ⑥ 计提折旧: FA 模块执行月度折旧
  ⑦ 计提坏账: AR 模块执行坏账计提
  ⑧ 制造费用分配: COST 模块分配制造费用
  ⑨ 完工成本结转: COST 模块结转完工产品成本
  ⑩ 销售成本结转: COST 模块结转销售成本

Day 5-7: 期末结转
  ⑪ 汇兑损益: 外币科目期末调汇
  ⑫ 损益结转: 损益类科目结转至本年利润
  ⑬ 试算平衡: 检查借贷是否平衡
  ⑭ 生成报表: 资产负债表、利润表、现金流量表

Day 7: 关闭期间
  ⑮ 关闭当月会计期间
  ⑯ 打开下月会计期间

7.2 月结检查清单

检查项模块验证内容
凭证全部过账GL无 Submitted/Approved 状态凭证
试算平衡GL借方总额 = 贷方总额
银行已对账BANK余额调节表已平衡
应收已核对AR应收余额与客户确认一致
应付已核对AP应付余额与供应商确认一致
暂估已处理AP上月暂估已冲回或正式入账
折旧已计提FA本月折旧凭证已生成
成本已归集COST制造费用已分配，完工成本已结转
损益已结转GL损益类科目余额已清零
存货已盘点MRP账实差异已处理

九、业务规则与约束

规则描述
业务凭证可追溯自动生成的凭证必须关联来源单据（SourceDocumentId）
凭证不可手工删除业务单据生成的凭证只能通过红冲处理
单据取消联动业务单据取消时自动红冲对应凭证
模板匹配唯一同一事件类型只能匹配到一个有效模板
金额一致性凭证金额必须与来源单据金额一致
期间一致性凭证期间必须与业务单据日期所在期间一致
月结顺序性月结步骤必须按规定顺序执行
跨模块数据一致AR应收余额 = GL应收科目余额
失败重试凭证生成失败时记录日志，支持手工重试
模板版本控制模板修改后旧凭证不受影响
