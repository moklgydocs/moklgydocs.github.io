科目体系与总账GL

科目体系与总账 GL (General Ledger)

概述

总账（General Ledger）是财务模块的核心，是所有财务数据的最终归集点。它管理会计科目体系、凭证的完整生命周期（录入→审核→过账→结转），以及辅助核算维度，为财务报表提供数据基础。

一、会计科目体系

1.1 科目分类

按照中国企业会计准则（CAS），科目分为六大类：

类别编码类别名称编码范围余额方向说明
1资产类1001-1999借方货币资金、应收、存货、固定资产等
2负债类2001-2999贷方应付、预收、借款、应交税费等
3所有者权益类3001-3999贷方实收资本、资本公积、盈余公积、未分配利润
4成本类4001-4999借方生产成本、制造费用
5损益类（收入）5001-5499贷方主营业务收入、其他业务收入
6损益类（费用）5501-5999借方主营业务成本、管理费用、销售费用等

1.2 科目编码规则

采用4-2-2-2分级编码体系：

一级科目:    1001              (4位，对应国标科目)
二级科目:    1001.01           (2位，企业自定义)
三级科目:    1001.01.01        (2位，明细)
四级科目:    1001.01.01.01     (2位，最细粒度)

示例:
1001          库存现金
1002          银行存款
1002.01         工商银行基本户
1002.02         建设银行一般户
1122          应收账款
1122.01         内销应收
1122.02         外销应收

1.4 科目实体模型

Account (会计科目)
├── Id: Guid                           # 主键
├── TenantId: Guid                     # 租户ID
├── Code: string(20)                   # 科目编码
├── Name: string(100)                  # 科目名称
├── ParentId: Guid?                    # 上级科目ID
├── Level: int                         # 科目级次 (1-4)
├── Category: AccountCategory          # 科目类别 (Asset/Liability/Equity/Cost/Revenue/Expense)
├── BalanceDirection: BalanceDirection  # 余额方向 (Debit/Credit)
├── IsLeaf: bool                       # 是否末级科目（只有末级可做凭证）
├── IsActive: bool                     # 是否启用
├── IsCashFlowRelevant: bool           # 是否涉及现金流
├── CurrencyCode: string(3)            # 核算币种 (CNY/USD/EUR)
├── AuxiliaryTypes: AuxFlag[]          # 辅助核算类型 (Customer/Supplier/Department/Employee/Project)
├── OpeningBalanceDebit: decimal(18,2) # 期初借方余额
├── OpeningBalanceCredit: decimal(18,2)# 期初贷方余额
└── Remark: string(500)               # 备注

枚举:
  AccountCategory: Asset=1, Liability=2, Equity=3, Cost=4, Revenue=5, Expense=6
  BalanceDirection: Debit=1, Credit=2
  AuxFlag: Customer=1, Supplier=2, Department=4, Employee=8, Project=16, BankAccount=32

二、辅助核算

2.1 辅助核算类型

辅助核算为科目提供多维度分析能力，不需要创建大量明细科目：

辅助类型说明典型科目数据来源
客户按客户核算应收账款、预收账款销售模块 Customer
供应商按供应商核算应付账款、预付账款采购模块 Supplier
部门按部门核算管理费用、销售费用组织架构
员工按员工核算其他应收款人事数据
项目按项目核算工程施工、研发支出项目管理
银行账户按银行账户核算银行存款银行模块 BankAccount

2.2 辅助核算余额表

AuxiliaryBalance (辅助核算余额)
├── Id: Guid
├── TenantId: Guid
├── AccountId: Guid                 # 科目ID
├── AuxType: AuxFlag                # 辅助类型
├── AuxId: Guid                     # 辅助对象ID (客户ID/供应商ID/...)
├── FiscalPeriodId: Guid            # 会计期间
├── OpeningDebit: decimal(18,2)     # 期初借方
├── OpeningCredit: decimal(18,2)    # 期初贷方
├── PeriodDebit: decimal(18,2)      # 本期借方发生
├── PeriodCredit: decimal(18,2)     # 本期贷方发生
├── ClosingDebit: decimal(18,2)     # 期末借方
└── ClosingCredit: decimal(18,2)    # 期末贷方

三、凭证管理

3.1 凭证生命周期

┌────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ Draft   │───▶│ Submitted │───▶│ Approved  │───▶│ Posted   │
│ 草稿    │    │ 已提交    │    │ 已审核    │    │ 已过账    │
└────────┘    └──────────┘    └──────────┘    └──────────┘
    ▲              │                                 │
    │              ▼                                 ▼
    │         ┌──────────┐                    ┌──────────┐
    └─────────│ Rejected  │                    │ Reversed  │
              │ 已驳回    │                    │ 已红冲    │
              └──────────┘                    └──────────┘

状态流转规则:
  Draft     → Submitted  : 制单人提交
  Submitted → Approved   : 审核人审核通过
  Submitted → Rejected   : 审核人驳回 → 退回草稿修改
  Rejected  → Draft      : 自动回到草稿，允许修改后重新提交
  Approved  → Posted     : 过账（不可逆，更新科目余额）
  Posted    → Reversed   : 红冲（生成反向凭证）

3.2 凭证实体模型

Voucher (会计凭证)
├── Id: Guid
├── TenantId: Guid
├── VoucherNo: string(30)             # 凭证编号 (PZ-2024-01-0001)
├── VoucherType: VoucherType          # 凭证类型 (收/付/转/记)
├── VoucherDate: DateTime             # 凭证日期
├── FiscalPeriodId: Guid              # 所属会计期间
├── AttachmentCount: int              # 附件张数
├── TotalDebit: decimal(18,2)         # 借方合计
├── TotalCredit: decimal(18,2)        # 贷方合计
├── Status: VoucherStatus             # 凭证状态
├── Source: VoucherSource             # 来源 (Manual/Auto_Purchase/Auto_Sales/Auto_Production...)
├── SourceDocumentId: Guid?           # 来源单据ID
├── SourceDocumentNo: string(50)?     # 来源单据号
├── Memo: string(500)                 # 摘要/备注
├── CreatorId: Guid                   # 制单人
├── AuditorId: Guid?                  # 审核人
├── AuditTime: DateTime?              # 审核时间
├── PosterId: Guid?                   # 过账人
├── PostTime: DateTime?               # 过账时间
├── ReversedVoucherId: Guid?          # 被红冲凭证ID（如果是红冲凭证）
├── ReversingVoucherId: Guid?         # 红冲凭证ID（如果被红冲了）
└── Lines: List<VoucherLine>          # 凭证明细

VoucherLine (凭证明细行)
├── Id: Guid
├── VoucherId: Guid                   # 所属凭证
├── LineNo: int                       # 行号
├── AccountId: Guid                   # 科目ID
├── AccountCode: string(20)           # 科目编码（冗余）
├── AccountName: string(100)          # 科目名称（冗余）
├── Summary: string(200)              # 摘要
├── DebitAmount: decimal(18,2)        # 借方金额
├── CreditAmount: decimal(18,2)       # 贷方金额
├── CurrencyCode: string(3)           # 币种
├── ExchangeRate: decimal(18,6)       # 汇率
├── OriginalAmount: decimal(18,2)     # 原币金额
├── AuxCustomerId: Guid?              # 辅助核算-客户
├── AuxSupplierId: Guid?              # 辅助核算-供应商
├── AuxDepartmentId: Guid?            # 辅助核算-部门
├── AuxEmployeeId: Guid?              # 辅助核算-员工
├── AuxProjectId: Guid?               # 辅助核算-项目
├── AuxBankAccountId: Guid?           # 辅助核算-银行账户
├── Quantity: decimal(18,4)?          # 数量（数量金额式）
├── UnitPrice: decimal(18,6)?         # 单价（数量金额式）
└── CashFlowItemId: Guid?            # 现金流量项目

枚举:
  VoucherType: Receipt=1(收), Payment=2(付), Transfer=3(转), General=4(记)
  VoucherStatus: Draft=0, Submitted=10, Approved=20, Posted=30, Reversed=40, Rejected=-1
  VoucherSource: Manual=0, Auto_Purchase=1, Auto_Sales=2, Auto_Production=3,
                 Auto_Depreciation=4, Auto_BankReconcile=5, Auto_PeriodClose=6

3.3 凭证校验规则

规则说明时机
借贷平衡TotalDebit == TotalCredit保存时
金额非零每行至少有借方或贷方金额 > 0保存时
借贷互斥同一行不可同时填借方和贷方保存时
末级科目只能使用 IsLeaf = true 的科目保存时
辅助核算完整科目要求的辅助核算必须填写保存时
期间匹配凭证日期必须在所选期间内保存时
期间未关闭凭证所在期间不能已关闭保存时
制单与审核分离制单人 ≠ 审核人审核时
已过账不可修改Posted 状态只能红冲，不能编辑删除编辑/删除时

4.2 期间操作规则

操作条件效果
打开期间上一期间已关闭或为第一期允许录入凭证
关闭期间所有凭证已过账、月末结转完成禁止录入/修改凭证
重新打开后续期间未关闭允许调整
关闭年度12个期间均已关闭、年终结转完成冻结该年度所有数据

五、科目余额

5.1 余额表实体

AccountBalance (科目余额)
├── Id: Guid
├── TenantId: Guid
├── AccountId: Guid                   # 科目ID
├── FiscalPeriodId: Guid              # 会计期间
├── OpeningDebit: decimal(18,2)       # 期初借方余额
├── OpeningCredit: decimal(18,2)      # 期初贷方余额
├── PeriodDebit: decimal(18,2)        # 本期借方发生额
├── PeriodCredit: decimal(18,2)       # 本期贷方发生额
├── YearDebit: decimal(18,2)          # 本年累计借方
├── YearCredit: decimal(18,2)         # 本年累计贷方
├── ClosingDebit: decimal(18,2)       # 期末借方余额
└── ClosingCredit: decimal(18,2)      # 期末贷方余额

5.2 余额计算公式

期末余额 = 期初余额 + 本期发生额

对于借方余额科目（资产/成本/费用）:
  期末借方余额 = 期初借方余额 + 本期借方发生额 - 本期贷方发生额

对于贷方余额科目（负债/权益/收入）:
  期末贷方余额 = 期初贷方余额 + 本期贷方发生额 - 本期借方发生额

下一期间期初余额 = 上一期间期末余额
新年度期初余额 = 上年度最后期间期末余额（资产负债类）
新年度期初余额 = 0（损益类科目，年末已结转至利润分配）

六、期末结转

6.1 月末结转流程

① 确认所有业务凭证已录入并过账
          │
          ▼
② 执行自动计提
   ├── 计提折旧 (FA → GL)
   ├── 计提坏账 (AR → GL)
   ├── 摊销待摊费用
   └── 计提工资/社保
          │
          ▼
③ 成本归集与结转
   ├── 制造费用分配至生产成本
   ├── 完工产品成本结转
   └── 销售成本结转 (COGS)
          │
          ▼
④ 汇兑损益处理（如有外币）
          │
          ▼
⑤ 损益类科目结转至"本年利润"
   ├── 收入类科目余额 → 贷方转入本年利润
   └── 费用类科目余额 → 借方转入本年利润
          │
          ▼
⑥ 生成试算平衡表，检查借贷平衡
          │
          ▼
⑦ 关闭当月会计期间

6.2 年末结转

完成12月月末结转后:
          │
          ▼
① "本年利润"余额结转至"利润分配-未分配利润"
   借: 本年利润 (3104.01)
   贷: 利润分配-未分配利润 (3104.04)
   （如果本年利润在借方，即亏损，则借贷反向）
          │
          ▼
② 计提盈余公积（税后利润的10%，累计达50%可不再计提）
   借: 利润分配-提取盈余公积
   贷: 盈余公积
          │
          ▼
③ 结转利润分配各明细至"未分配利润"
          │
          ▼
④ 关闭会计年度，生成年报
          │
          ▼
⑤ 自动创建下一年度期间，结转期初余额

十、业务规则与约束

规则描述
科目编码唯一同一租户内科目编码不可重复
上级科目不可记账有子科目的科目不可出现在凭证中
科目删除前检查有发生额或余额的科目不可删除
凭证必须平衡借方合计 = 贷方合计
过账不可撤销已过账凭证只能通过红冲处理
期间连续关闭必须按顺序关闭期间，不可跳期
年度关闭不可逆关闭年度后不可重新打开
审核权限分离制单人不可审核自己的凭证
损益科目不跨年损益类科目年末必须结转清零
辅助核算必填科目启用辅助核算后，凭证行必须填写对应辅助信息
