JavaScript 核心面试题

前端面试必考 JS 基础，不管你用 React 还是 Vue，JS 底子一定要扎实。

Q1: var、let、const 的区别？

难度：⭐ | 频率：🔥🔥🔥🔥🔥

💡 回答：

特性varletconst
作用域函数作用域块级作用域块级作用域
变量提升✅（值为 undefined）❌ 暂时性死区（TDZ）❌ TDZ
重复声明✅❌❌
重新赋值✅✅❌
// 经典面试题
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// 输出：3, 3, 3（var 是函数作用域，循环结束 i=3）

for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// 输出：0, 1, 2（let 是块级作用域，每次循环都是新的 i）

⚠️ const 对象的属性可以修改：const obj = {}; obj.a = 1; // ✅。const 只保证引用不变。

Q2: 闭包是什么？有什么实际用途？

难度：⭐⭐ | 频率：🔥🔥🔥🔥🔥

💡 回答：

闭包是函数能访问其词法作用域中变量的能力，即使函数在作用域外被调用。

function createCounter() {
  let count = 0; // 被闭包捕获
  return {
    increment: () => ++count,
    getCount: () => count,
  };
}
const counter = createCounter();
counter.increment(); // 1
counter.increment(); // 2
counter.getCount();  // 2
// count 变量对外不可直接访问，但通过闭包仍然存活

实际用途：

  1. 数据封装：模拟私有变量
  2. 函数工厂：createLogger('prefix')
  3. 防抖/节流：保存 timer 变量
  4. React Hooks：每个 Hook 都利用了闭包

⚠️ 内存泄漏注意：闭包会让变量无法被 GC 回收。在事件监听中用闭包要记得取消监听。

Q3: 原型链是什么？如何实现继承？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥

💡 回答：

每个对象都有一个 __proto__ 属性指向它的原型对象。当访问一个属性时，JS 会沿着原型链向上查找。

实例 → Constructor.prototype → Object.prototype → null
function Animal(name) { this.name = name; }
Animal.prototype.speak = function() { return `${this.name} makes a sound`; };

const dog = new Animal('Dog');
dog.speak();        // "Dog makes a sound"
dog.toString();     // 沿原型链找到 Object.prototype.toString

ES6 class 继承（推荐）：

class Animal {
  constructor(name) { this.name = name; }
  speak() { return `${this.name} makes a sound`; }
}

class Dog extends Animal {
  bark() { return `${this.name} barks`; }
}

Q4: Promise 的原理和用法？async/await 的本质？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥🔥

💡 回答：

Promise 有三种状态：pending → fulfilled / rejected，状态一旦改变不可逆。

const p = new Promise((resolve, reject) => {
  setTimeout(() => resolve('done'), 1000);
});
p.then(value => console.log(value)); // 1秒后 "done"

async/await 是 Promise 的语法糖：

// 等价写法
async function fetchUser() {
  const res = await fetch('/api/user'); // 等价于 fetch().then(...)
  const data = await res.json();
  return data;
}

常见方法：

Promise.all([p1, p2, p3]);     // 全部成功才成功，一个失败就失败
Promise.allSettled([p1, p2]);   // 等所有都结束，不管成功失败
Promise.race([p1, p2]);        // 第一个完成的结果
Promise.any([p1, p2]);         // 第一个成功的结果

Q5: 事件循环（Event Loop）是什么？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥🔥

💡 回答：

JS 是单线程的，通过事件循环处理异步：

执行栈 → 清空后 → 执行所有微任务 → 取一个宏任务 → 再清微任务 → ...

微任务（优先）：Promise.then、MutationObserver、queueMicrotask
宏任务：setTimeout、setInterval、DOM 事件、网络请求回调

console.log('1');
setTimeout(() => console.log('2'), 0);
Promise.resolve().then(() => console.log('3'));
console.log('4');
// 输出：1, 4, 3, 2

Q6: this 指向问题

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥

💡 回答：

调用方式this 指向
普通函数调用window / undefined（严格模式）
对象方法调用该方法的对象
new 构造函数新创建的实例
call/apply/bind指定的对象
箭头函数定义时的外层 this（不会改变）
const obj = {
  name: 'obj',
  getName: function() { return this.name; },
  getNameArrow: () => { return this.name; }, // 箭头函数的 this 是外层
};
obj.getName();      // 'obj'
obj.getNameArrow(); // undefined（this 是外层，不是 obj）

const fn = obj.getName;
fn();               // undefined（普通调用，this 不是 obj）

Q7: 深拷贝和浅拷贝的区别？如何实现深拷贝？

难度：⭐⭐ | 频率：🔥🔥🔥🔥

💡 回答：

浅拷贝只复制第一层，深拷贝递归复制所有层。

// 浅拷贝
const shallow = { ...obj };
const shallow2 = Object.assign({}, obj);

// 深拷贝方案
// 1. structuredClone（现代浏览器原生支持，推荐）
const deep = structuredClone(obj);

// 2. JSON（有局限：不支持函数、undefined、循环引用）
const deep2 = JSON.parse(JSON.stringify(obj));

// 3. 手写递归
function deepClone(obj, cache = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj;
  if (cache.has(obj)) return cache.get(obj); // 处理循环引用
  const clone = Array.isArray(obj) ? [] : {};
  cache.set(obj, clone);
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      clone[key] = deepClone(obj[key], cache);
    }
  }
  return clone;
}

Q9: 防抖和节流的区别？手写实现？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥🔥

💡 回答：

  • 防抖（Debounce）：事件停止触发后才执行。如搜索框输入。
  • 节流（Throttle）：固定间隔执行一次。如滚动事件。
// 防抖
function debounce(fn, delay) {
  let timer;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}

// 节流
function throttle(fn, interval) {
  let lastTime = 0;
  return function(...args) {
    const now = Date.now();
    if (now - lastTime >= interval) {
      lastTime = now;
      fn.apply(this, args);
    }
  };
}

Q10: 数组常用方法有哪些？map、forEach、filter、reduce 的区别？

难度：⭐ | 频率：🔥🔥🔥🔥

💡 回答：

方法返回值是否改变原数组用途
map新数组❌转换每个元素
forEachundefined❌遍历执行副作用
filter新数组❌过滤符合条件的
reduce累积值❌归纳为单个值
find单个元素❌找第一个匹配的
someboolean❌是否有符合条件的
everyboolean❌是否全部符合
// reduce 实现求和
[1, 2, 3].reduce((sum, n) => sum + n, 0); // 6

// reduce 实现分组
users.reduce((groups, user) => {
  const key = user.role;
  groups[key] = groups[key] || [];
  groups[key].push(user);
  return groups;
}, {});
