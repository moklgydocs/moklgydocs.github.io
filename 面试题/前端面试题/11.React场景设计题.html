Q1: 如何实现一个无限滚动列表？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥

💡 回答思路：

function InfiniteList() {
  const [items, setItems] = useState([]);
  const [page, setPage] = useState(1);
  const [loading, setLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);
  const observerRef = useRef(null);
  const lastItemRef = useRef(null);

  // 用 IntersectionObserver 检测最后一项是否进入视口
  useEffect(() => {
    if (loading || !hasMore) return;

    observerRef.current = new IntersectionObserver(([entry]) => {
      if (entry.isIntersecting) {
        setPage(p => p + 1);
      }
    });

    if (lastItemRef.current) {
      observerRef.current.observe(lastItemRef.current);
    }

    return () => observerRef.current?.disconnect();
  }, [loading, hasMore, items]);

  // 加载数据
  useEffect(() => {
    setLoading(true);
    fetchItems(page).then(newItems => {
      setItems(prev => [...prev, ...newItems]);
      setHasMore(newItems.length > 0);
      setLoading(false);
    });
  }, [page]);

  return (
    <ul>
      {items.map((item, i) => (
        <li key={item.id} ref={i === items.length - 1 ? lastItemRef : null}>
          {item.name}
        </li>
      ))}
      {loading && <li>加载中...</li>}
    </ul>
  );
}

关键点：IntersectionObserver、分页、loading 状态、去重。

Q2: 如何设计一个弹窗（Modal）组件？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥

💡 回答思路：

function Modal({ open, onClose, title, children }) {
  // ESC 关闭
  useEffect(() => {
    const handleEsc = (e) => { if (e.key === 'Escape') onClose(); };
    if (open) document.addEventListener('keydown', handleEsc);
    return () => document.removeEventListener('keydown', handleEsc);
  }, [open, onClose]);

  // 阻止滚动
  useEffect(() => {
    if (open) document.body.style.overflow = 'hidden';
    return () => { document.body.style.overflow = ''; };
  }, [open]);

  if (!open) return null;

  return createPortal(
    <div className="modal-overlay" onClick={onClose}>
      <div className="modal-content" onClick={e => e.stopPropagation()}>
        <h2>{title}</h2>
        {children}
        <button onClick={onClose}>关闭</button>
      </div>
    </div>,
    document.body
  );
}

关键点：createPortal 挂到 body、点遮罩关闭、ESC 关闭、阻止背景滚动、无障碍。

Q3: 如何实现表单验证？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥

💡 回答思路：

function useForm(initialValues, validate) {
  const [values, setValues] = useState(initialValues);
  const [errors, setErrors] = useState({});
  const [touched, setTouched] = useState({});

  const handleChange = (name) => (e) => {
    const value = e.target.value;
    setValues(prev => ({ ...prev, [name]: value }));
    // 实时验证
    const fieldErrors = validate({ ...values, [name]: value });
    setErrors(prev => ({ ...prev, [name]: fieldErrors[name] }));
  };

  const handleBlur = (name) => () => {
    setTouched(prev => ({ ...prev, [name]: true }));
  };

  const handleSubmit = (onSubmit) => (e) => {
    e.preventDefault();
    const allErrors = validate(values);
    setErrors(allErrors);
    setTouched(Object.keys(values).reduce((acc, k) => ({ ...acc, [k]: true }), {}));
    if (Object.keys(allErrors).length === 0) onSubmit(values);
  };

  return { values, errors, touched, handleChange, handleBlur, handleSubmit };
}

// 使用
const { values, errors, touched, handleChange, handleBlur, handleSubmit } = useForm(
  { email: '', password: '' },
  (values) => {
    const errors = {};
    if (!values.email) errors.email = '邮箱必填';
    if (values.password.length < 6) errors.password = '密码至少6位';
    return errors;
  }
);

💡 实际项目推荐：用 react-hook-form + zod，性能好且类型安全。

Q4: 如何实现一个主题切换（暗色/亮色）？

难度：⭐⭐ | 频率：🔥🔥🔥

💡 回答思路：

const ThemeContext = createContext({ theme: 'light', toggle: () => {} });

function ThemeProvider({ children }) {
  const [theme, setTheme] = useState(() =>
    localStorage.getItem('theme') || 'light'
  );

  const toggle = () => {
    const next = theme === 'light' ? 'dark' : 'light';
    setTheme(next);
    localStorage.setItem('theme', next);
    document.documentElement.setAttribute('data-theme', next);
  };

  useEffect(() => {
    document.documentElement.setAttribute('data-theme', theme);
  }, []);

  return (
    <ThemeContext.Provider value={{ theme, toggle }}>
      {children}
    </ThemeContext.Provider>
  );
}

// CSS 变量方案
// [data-theme="light"] { --bg: #fff; --text: #333; }
// [data-theme="dark"]  { --bg: #1a1a1a; --text: #eee; }

// 路由级权限
function ProtectedRoute({ children, requiredRole }) {
  const { user } = useAuth();
  if (!user) return <Navigate to="/login" />;
  if (requiredRole && user.role !== requiredRole) return <Navigate to="/403" />;
  return children;
}

// 按钮级权限
function AuthButton({ permission, children, ...props }) {
  const { permissions } = useAuth();
  if (!permissions.includes(permission)) return null;
  return <button {...props}>{children}</button>;
}

// 使用
<Route path="/admin" element={
  <ProtectedRoute requiredRole="admin">
    <AdminPage />

Q6: 如何实现一个虚拟列表？

难度：⭐⭐⭐⭐ | 频率：🔥🔥🔥

💡 回答思路：

核心原理：只渲染可视区域内的元素，用一个大容器撑开滚动区域。

function VirtualList({ items, itemHeight, containerHeight }) {
  const [scrollTop, setScrollTop] = useState(0);

  const startIndex = Math.floor(scrollTop / itemHeight);
  const endIndex = Math.min(startIndex + Math.ceil(containerHeight / itemHeight) + 1, items.length);
  const visibleItems = items.slice(startIndex, endIndex);
  const totalHeight = items.length * itemHeight;

  return (
    <div
      style={{ height: containerHeight, overflow: 'auto' }}
      onScroll={(e) => setScrollTop(e.currentTarget.scrollTop)}
    >
      <div style={{ height: totalHeight, position: 'relative' }}>
        {visibleItems.map((item, i) => (
          <div
            key={startIndex + i}
            style={{
              position: 'absolute',
              top: (startIndex + i) * itemHeight,
              height: itemHeight,
              width: '100%',
            }}
          >
            {item.name}
          </div>
        ))}
      </div>
    </div>
  );
}

💡 实际项目用 react-window 或 @tanstack/react-virtual。

Q7: 如何封装一个通用的 useFetch Hook？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥

💡 回答思路：

function useFetch<T>(url: string) {
  const [data, setData] = useState<T | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    const controller = new AbortController();

    setLoading(true);
    setError(null);

    fetch(url, { signal: controller.signal })
      .then(res => {
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        return res.json();
      })
      .then(setData)
      .catch(err => {
        if (err.name !== 'AbortError') setError(err.message);
      })
      .finally(() => setLoading(false));

    return () => controller.abort(); // 组件卸载时取消请求
  }, [url]);

  return { data, loading, error };
}

关键点：loading/error 状态、AbortController 取消、泛型类型。

Q8: 如何做国际化（i18n）？

难度：⭐⭐⭐ | 频率：🔥🔥

💡 回答思路：

方案选择：react-i18next（最流行）或 react-intl

核心思路：

  1. 定义语言包（JSON 文件）
  2. Context 存储当前语言
  3. 翻译函数 t('key') 根据语言返回对应文本
  4. 切换语言时更新 Context
// 简化实现
const translations = {
  zh: { greeting: '你好', submit: '提交' },
  en: { greeting: 'Hello', submit: 'Submit' },
};

function useTranslation() {
  const { locale } = useContext(LocaleContext);
  const t = (key) => translations[locale]?.[key] || key;
  return { t };
}

// 使用
function Header() {
  const { t } = useTranslation();
  return <h1>{t('greeting')}</h1>;
}

Q9: 如何处理大文件上传？

难度：⭐⭐⭐⭐ | 频率：🔥🔥🔥

💡 回答思路：

分片上传：

  1. 前端将文件切片（如 5MB 一片）
  2. 并发上传各分片
  3. 服务端合并
  4. 支持断点续传（记录已传分片）
async function uploadFile(file) {
  const CHUNK_SIZE = 5 * 1024 * 1024;
  const chunks = Math.ceil(file.size / CHUNK_SIZE);
  const fileHash = await calculateHash(file); // MD5

  for (let i = 0; i < chunks; i++) {
    const chunk = file.slice(i * CHUNK_SIZE, (i + 1) * CHUNK_SIZE);
    const formData = new FormData();
    formData.append('chunk', chunk);
    formData.append('hash', fileHash);
    formData.append('index', i);

    await fetch('/api/upload/chunk', { method: 'POST', body: formData });
    setProgress(((i + 1) / chunks) * 100);
  }

  await fetch('/api/upload/merge', {
    method: 'POST',
    body: JSON.stringify({ hash: fileHash, chunks }),
  });
}

Q10: 微前端方案怎么选？

难度：⭐⭐⭐⭐ | 频率：🔥🔥

💡 回答思路：

方案特点适用场景
iframe最简单，天然隔离对隔离性要求高
qiankun基于 single-spa，JS 沙箱渐进式迁移
Module FederationWebpack 5 原生支持同构技术栈
Web Components标准化，框架无关跨框架组件

选择建议：

  • 新项目 → 尽量Monorepo + 统一框架
  • 老项目渐进迁移 → qiankun
  • 简单嵌入 → iframe
