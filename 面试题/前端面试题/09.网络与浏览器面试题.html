网络与浏览器面试题

前端离不开网络知识，HTTP、缓存、跨域、安全都是高频考点。

Q1: HTTP 和 HTTPS 的区别？

难度：⭐⭐ | 频率：🔥🔥🔥🔥

💡 回答：

方面HTTPHTTPS
端口80443
加密❌ 明文✅ TLS/SSL
证书不需要需要 CA 证书
性能快稍慢（TLS 握手）

HTTPS = HTTP + TLS。TLS 握手过程：客户端发送支持的加密方式 → 服务端返回证书 → 客户端验证证书 → 协商对称密钥 → 加密通信。

Q2: HTTP 状态码分别是什么意思？

难度：⭐ | 频率：🔥🔥🔥🔥🔥

💡 回答：

状态码含义常见
2xx成功200 成功、201 已创建、204 无内容
3xx重定向301 永久、302 临时、304 未修改(缓存)
4xx客户端错误400 请求错误、401 未认证、403 禁止、404 未找到
5xx服务器错误500 服务器错误、502 网关错误、503 服务不可用

面试高频：301 vs 302 的区别？304 是什么机制触发的？

Q3: 浏览器缓存机制？强缓存和协商缓存的区别？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥🔥

💡 回答：

强缓存（不请求服务器）：

  • Cache-Control: max-age=3600（优先级高）
  • Expires: Wed, 09 Jun 2025 10:18:14 GMT

协商缓存（请求服务器验证，返回 304 或新内容）：

  • Last-Modified / If-Modified-Since（精度秒级）
  • ETag / If-None-Match（精度更高，推荐）

流程：

请求 → 有强缓存且未过期？→ ✅ 直接用本地缓存（200 from cache）
                         → ❌ 发请求带 If-None-Match
                              → 服务器验证 ETag → 没变 304 → 用缓存
                                                → 变了 200 → 新内容

Q4: 跨域问题是什么？怎么解决？

难度：⭐⭐ | 频率：🔥🔥🔥🔥🔥

💡 回答：

同源策略：协议 + 域名 + 端口 都相同才是同源。不同源的请求会被浏览器拦截。

解决方案：

  1. CORS（最推荐）：服务端设置 Access-Control-Allow-Origin
  2. 代理：开发时 Vite/Webpack 配置 proxy，生产时 Nginx 反向代理
  3. JSONP：只支持 GET，利用 <script> 标签不受同源限制
// Vite 开发代理
export default {
  server: {
    proxy: {
      '/api': {
        target: 'http://backend:3000',
        changeOrigin: true,
      }
    }
  }
}

Q5: 输入 URL 到页面显示的全过程？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥🔥

💡 回答：

  1. DNS 解析：域名 → IP 地址（递归查询：浏览器缓存 → 系统缓存 → 路由缓存 → DNS 服务器）
  2. TCP 连接：三次握手建立连接
  3. HTTPS 握手：TLS 协商加密
  4. 发送 HTTP 请求
  5. 服务器处理并返回响应
  6. 浏览器解析 HTML：构建 DOM 树
  7. 解析 CSS：构建 CSSOM 树
  8. 合并：DOM + CSSOM → Render Tree
  9. 布局（Layout）：计算每个节点的位置和大小
  10. 绘制（Paint）：将节点绘制到屏幕
  11. 合成（Composite）：GPU 合成图层

Q6: XSS 和 CSRF 攻击是什么？如何防御？

难度：⭐⭐⭐ | 频率：🔥🔥🔥🔥

💡 回答：

XSS（跨站脚本）：攻击者注入恶意脚本到页面。

防御：

  • 输出转义（React 默认转义 JSX 中的值）
  • CSP（Content Security Policy）
  • 避免使用 dangerouslySetInnerHTML

CSRF（跨站请求伪造）：利用用户已登录状态发送恶意请求。

防御：

  • CSRF Token
  • SameSite Cookie 属性
  • 验证 Referer / Origin 头

Q9: 什么是回流（Reflow）和重绘（Repaint）？

难度：⭐⭐ | 频率：🔥🔥🔥

💡 回答：

  • 回流：元素的尺寸、位置变化，需要重新计算布局（开销大）
  • 重绘：外观变化（颜色、背景等），不影响布局（开销小）

回流一定触发重绘，重绘不一定触发回流。

优化：

  • 使用 transform 替代 top/left（不触发回流）
  • 批量修改 DOM（DocumentFragment）
  • 使用 CSS 动画代替 JS 动画
  • 避免频繁读取布局属性（offsetWidth 等）

Q10: WebSocket 是什么？和 HTTP 有什么区别？

难度：⭐⭐ | 频率：🔥🔥🔥

💡 回答：

WebSocket 是全双工通信协议，建立连接后客户端和服务端可以随时互发消息。

方面HTTPWebSocket
通信方式请求-响应（半双工）全双工
连接短连接（每次请求新建）长连接
协议http://ws:// / wss://
适用场景REST API实时聊天、推送、协作编辑
