名词分类与数词表达

名词分类与数词表达

日语名词没有性别、格的变化，但数量表达体系独特而复杂——不同类别的物品使用不同的量词（助数词），这是学习难点。

学习导航

  • 级别定位：（助数词的音变规律是 N5 听力与阅读的高频考点）
  • 深入讲解：名词的状态表达（だ/じゃない/だった）见系统讲解篇 ；数量词在句中的位置与计数表达见

名词的特征

1. 无性别、无单复数

日语名词不区分阴阳性，也不通过词形变化表示单复数：

中文日语
一本书本
三本书本（三冊）
男人/女人男 / 女

表示复数可用复数后缀：

后缀用途示例
たち人（通用）私たち（我们）、子供たち（孩子们）
がた人（敬语）先生方（老师们）、あなたがた（您们）
ら人（随意）彼ら（他们）、僕ら（我们）
達（たち）人/动物鳥たち（鸟儿们）

2. 无冠词

日语没有相当于「a/the」的冠词，通过上下文或指示词区分：

指示词读音指代
これこれ这个（近）
それそれ那个（中）
あれあれ那个（远）
どれどれ哪个

3. 指示代词体系

日语指示代词按「こそあど」四段体系组织：

距离こ（近）そ（中）あ（远）ど（疑问）
事物これそれあれどれ
场所ここそこあそこどこ
方向こちらそちらあちらどちら
修饰このそのあのどの
方式こうそうああどう
程度こんなそんなあんなどんな

こそあど 记忆

  • こ系：说话人身边（这）
  • そ系：听话人身边（那）
  • あ系：远离双方（那）
  • ど系：疑问（哪）

名词的分类

按来源分类

类别特征示例
和语词日本固有词山、川、木、水
汉语词中文借词学校、先生、電話
外来语西方借词（片假名）パン、テレビ、コンピュータ
混种词混合来源夕方（和+汉）、鉛筆（汉）

按性质分类

类别说明示例
普通名词同类事物通称本、人、学校
专有名词特定事物名称東京、田中、日本
代名词替代名词私、これ、それ
形式名词只起语法作用の、こと、もの、ところ

形式名词详解

形式名词本身意义虚化，需接修饰语：

形式名词用法示例
の名词化、所属食べるのが好き（喜欢吃）
こと抽象事态日本へ行ったことがある（去过日本）
もの具体事物/人高いものだ（真贵啊）
ところ时间/场所今勉強しているところです（正在学）
つもり打算行くつもりだ（打算去）
はず应该もう着いているはずだ（应该到了）

数词

基数词

日语数字有两套读法——音读（汉语音）和训读（日本固有读法）：

数字音读训读
1いちひと（つ）
2にふた（つ）
3さんみっ（つ）
4し / よんよっ（つ）
5ごいつ（つ）
6ろくむっ（つ）
7しち / なななな（つ）
8はちやっ（つ）
9きゅう / くここの（つ）
10じゅうとお

4 和 7 的两种读法

  • 4：し（音读，但避讳死）/ よん（更常用）
  • 7：しち（音读）/ なな（更常用）

实际使用中よん和なな更普遍。

序数词

表达示例
第 + 数字第一（だいいち）、第二（だいに）
数字 + 番目一番目（いちばんめ）、二番目（にばんめ）
数字 + 号1号（いちごう）、3号線

大数字

单位读法数值
百ひゃく100
千せん1,000
万まん10,000
億おく100,000,000
兆ちょう1,000,000,000,000

百/千的特殊读音

  • 300：さんびゃく（不是 さんひゃく）
  • 600：ろっぴゃく（不是 ろくひゃく）
  • 800：はっぴゃく（不是 はちひゃく）
  • 3000：さんぜん（不是 さんせん）
  • 8000：はっせん（不是 はちせん）

助数词的读音变化

助数词前的数字会发生音变（促音化/浊音化）：

本（ほん）的音变

数字 + 本读音变化
1本いっぽん促音 + 半浊音
2本にほん无变化
3本さんぼん浊音化
4本よんほん无变化
5本ごほん无变化
6本ろっぽん促音 + 半浊音
7本ななほん无变化
8本はっぽん促音 + 半浊音
9本きゅうほん无变化
10本じゅっぽん促音 + 半浊音

匹（ひき）的音变

数字 + 匹读音
1匹いっぴき
2匹にひき
3匹さんびき
6匹ろっぴき
8匹はっぴき
10匹じゅっぴき

階（かい）的音变

数字 + 階读音
1階いっかい
3階さんがい
6階ろっかい
8階はっかい
10階じゅっかい

音变规律

  • 1、6、8、10 后常促音化（っ）
  • 3 后常浊音化（は→ば、は→ぱ）
  • 用「よん」「なな」代替「し」「しち」避免歧义

つ 系列通用量词

1-9 可用「つ」通用计数，10 用「とお」：

数量读音数量读音
1つひとつ6つむっつ
2つふたつ7つななつ
3つみっつ8つやっつ
4つよっつ9つここのつ
5ついつつ10とお

つ 的限制

  • 只能用于 1-9，10 用とお
  • 不用于人、动物、机械
  • 常用于抽象事物（年齢、顺序）

数量表达句型

1. 名词 + 数量 + 助词

数量词放在名词后、动词前：

  • りんごを3個食べた（吃了3个苹果）
  • 学生が5人来た（来了5个学生）
  • 本を2冊買った（买了2本书）

2. 数量词 + も（强调多/少）

  • りんごを3個も食べた（竟然吃了3个苹果 —— 强调多）
  • 1人も来なかった（一个人都没来 —— 强调少）

3. 数量词 + で（合计）

  • りんごを3個で300円です（3个苹果共300日元）
  • 全部で5冊あります（总共有5本）

4. 疑问数量

  • りんごをいくつ買いましたか（买了几个苹果？）
  • 学生が何人来ましたか（来了几个学生？）
  • これはいくらですか（这个多少钱？）

时刻 vs 时长

  • 3時（さんじ）：3点（时刻）
  • 3時間（さんじかん）：3小时（时长）
  • 3日（みっか）：3号（日期）
  • 3日間（みっかかん）：3天（时长）

20岁读「はたち」，不用「にじゅっさい」。这是法定成年年龄，有特殊读法。

小结

要点说明
名词特征无性别、无单复数、无冠词
こそあど近/中/远/疑四段体系
数词读法音读 + 训读两套
助数词按物品类别选量词（30+种）
音变1/6/8/10促音化，3浊音化
时刻 vs 时长3時（点）/ 3時間（小时）
日期 vs 时长3日（号）/ 3日間（天）

掌握数词表达是日语日常交流的基础，建议结合和反复练习。
