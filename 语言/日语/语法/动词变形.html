动词变形总览

动词变形总览

日语动词变形是语法的核心。所有动词变形都从辞书形（原形）派生而来。

学习导航

  • 级别定位： ます形・て形・ない形・た形　｜　 可能・受身・使役・仮定・意志・命令
  • 术语对照：本篇的「一类（五段）/二类（一段）/三类（不规则）」＝系统讲解篇的「う动词/る动词/不规则动词」——完全等价，只是命名流派不同，看到两种叫法别慌
  • 深入讲解：动词分类的原理与例外清单见 ；て形、可能形、条件形的语境用法见

动词分类

日语动词分三类：

类别特征示例
一类动词（五段）词尾在 う段，且多为「～る」前是 い/え 段假名書く、飲む、買う、待つ
二类动词（一段）词尾「～る」，る 前是 い/え 段假名食べる、見る、起きる
三类动词（不规则）する（做）、来る（来）勉強する、来る

辨别技巧

  • 二类动词的「る」前一定是 い段（上一段）或 え段（下一段）
  • 但一类动词也有「～る」结尾的（如 帰る、知る），需单独记忆
  • する、来る 永远是三类

变形总览表

以常见动词为例：

变形一类（書く）二类（食べる）三类（する/来る）用途
辞书形書く食べるする / 来る原形
ます形書きます食べますします / 来ます郑重肯定
ない形書かない食べないしない / 来ない否定
て形書いて食べてして / 来て连接、请求
た形書いた食べたした / 来た过去
可能形書ける食べられるできる / 来られる能、会
受身形書かれる食べられるされる / 来られる被动
使役形書かせる食べさせるさせる / 来させる让、使
命令形書け食べろしろ / 来い命令
仮定形書けば食べればすれば / 来れば如果
意志形書こう食べようしよう / 来よう打算、邀请

一类动词（五段）变形规律

一类动词变形最复杂，词尾う段假名会移到同一行的其他段。

ます形（う段 → い段 + ます）

辞书形词尾变化ます形
書くく → き書きます
飲むむ → み飲みます
買うう → い買います
待つつ → ち待ちます
話すす → し話します
死ぬぬ → に死にます
飛ぶぶ → び飛びます
帰るる → り帰ります

ない形（う段 → あ段 + ない）

辞书形词尾变化ない形
書くく → か書かない
飲むむ → ま飲まない
買うう → わ買わない（注意：不是 あ）
待つつ → た待たない
話すす → さ話さない

特殊：ある

「ある」（有）的否定是「ない」，不是「あらない」。

て形 / た形（最重要的变形）

一类动词的て形/た形词尾变化规律：

辞书形词尾て形/た形示例
くいて/いた書く → 書いて/書いた
ぐいで/いだ泳ぐ → 泳いで/泳いだ
う、つ、るって/った買う → 買って/買った
ぬ、ぶ、むんで/んだ飲む → 飲んで/飲んだ
すして/した話す → 話して/話した

记忆口诀

「きいて、いで、って、んで、して」——按词尾分组记忆最有效。

可能形（う段 → え段 + る）

辞书形可能形示例句
書く書ける日本語が書けます
飲む飲めるお酒が飲めます
買う買えるこれが買えます

仮定形（う段 → え段 + ば）

辞书形仮定形示例句
書く書けば書けば、分かります
飲む飲めば薬を飲めば、治ります

意志形（う段 → お段 + う）

辞书形意志形示例句
書く書こう一緒に書こう
飲む飲もうお酒を飲もう

命令形（う段 → え段）

辞书形命令形示例句
書く書け早く書け！
飲む飲めこれを飲め！

二类动词（一段）变形规律

二类动词变形最简单：去掉「る」+ 对应词尾。

变形规律食べる見る
ます形去 る + ます食べます見ます
ない形去 る + ない食べない見ない
て形去 る + て食べて見て
た形去 る + た食べた見た
可能形去 る + られる食べられる見られる
受身形去 る + られる食べられる見られる
使役形去 る + させる食べさせる見させる
命令形去 る + ろ食べろ見ろ
仮定形去 る + れば食べれば見れば
意志形去 る + よう食べよう見よう

三类动词（不规则）变形

变形する来る（くる）
ます形します来ます（きます）
ない形しない来ない（こない）
て形して来て（きて）
た形した来た（きた）
可能形できる来られる（こられる）
受身形される来られる（こられる）
使役形させる来させる（こさせる）
命令形しろ来い（こい）
仮定形すれば来れば（くれば）
意志形しよう来よう（こよう）

来る 的读音

「来る」所有变形都从「こ」行变化：きます、こない、きて、きた、こられる...

实用变形组合

ている（正在进行 / 状态）

  • 食べている（正在吃）
  • 結婚している（已婚 —— 表示状态）

たい（想做）

  • 食べたい（想吃）
  • 行きたい（想去）

ましょう（邀请）

  • 食べましょう（一起吃吧）
  • 行きましょう（一起去吧）

なければならない（必须）

  • 食べなければならない（必须吃）
  • 行かなければならない（必须去）

学习建议

  1. 先掌握ます形 —— 最常用的礼貌体
  2. 死磕て形 —— て形使用频率最高，连接各种表达
  3. 分类记忆 —— 一类动词按词尾分组记规律
  4. 多造句练习 —— 每个变形至少造 3 个句子
  5. 参考 —— 理解句型后再学变形
