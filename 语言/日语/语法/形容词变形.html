形容词变形与活用

形容词变形与活用

日语形容词分两大类，各自有完整的活用（变形）体系。掌握形容词变形，才能表达否定、过去、连接、推测等各种语气。

学习导航

  • 级别定位：（形容词活用是 N5 必考基础）
  • 深入讲解：い/な 形容词的区分诀窍（看「い」是否属于汉字的一部分）与"为什么不能接だ"的原理，见系统讲解篇

形容词分类

类别特征词尾示例
い形容词（形容词）以「い」结尾～い高い、新しい、面白い
な形容词（形容动词）词干 + な + 名词～な静か、元気、便利

容易混淆的词

有些词以「い」结尾但不是い形容词：

  • きれい（漂亮）—— な形容词（来源「綺麗」，汉语词）
  • 嫌い（讨厌）—— な形容词
  • ゆうめい（有名）—— な形容词

判断技巧：汉字词 + い 多为な形容词；和语词 + い 多为い形容词。

い形容词活用

以「高い」（高的）为例：

活用形形态示例中文
辞书形高い高いです高
郑重肯定高いです高いです高
郑重否定高くないです / 高くありません高くないです不高
普通否定高くない高くない不高
过去肯定高かった高かったです曾经高
过去否定高くなかった高くなかったです曾经不高
て形高くて高くて、新しい高而且新
副词形高く高くする提高
条件形高ければ高ければ買わない如果贵就不买
推量形高かろう / 高いだろう高かろう大概贵吧

变形规律

高い（辞书形）
  ├─ 肯定：高いです
  ├─ 否定：高く + ないです / ありません
  ├─ 过去：高かっ + たです
  ├─ 过去否定：高く + なかったです
  ├─ て形：高く + て
  ├─ 副词：高く
  ├─ 条件：高けれ + ば
  └─ 推量：高かろ + う

否定的敬体

い形容词否定有两种敬体：

  • 高くないです（较常用）
  • 高くありません（更正式）

常用い形容词活用示例

辞书形否定过去て形
高い（高）高くない高かった高くて
新しい（新）新しくない新しかった新しくて
面白い（有趣）面白くない面白かった面白くて
寒い（冷）寒くない寒かった寒くて
暑い（热）暑くない暑かった暑くて
大きい（大）大きくない大きかった大きくて
小さい（小）小さくない小さかった小さくて
良い（好）良くない良かった良くて

いい 的特殊变形

「いい」（好）的变形基于「よい」：

  • 辞书形：いい / よい
  • 否定：よくない（不是 いくない）
  • 过去：よかった（不是 いかった）
  • て形：よくて

な形容词活用

な形容词的活用本质上是词干 + 助动词（だ/です/な）的组合。

以「静か」（安静的）为例：

活用形形态示例中文
辞书形静かだ静かだ安静
郑重肯定静かです静かです安静
郑重否定静かじゃないです / 静かではありません静かじゃないです不安静
普通否定静かじゃない / 静かではない静かじゃない不安静
过去肯定静かだった静かでした曾经安静
过去否定静かじゃなかった / 静かではなかった静かじゃなかった曾经不安静
て形静かで静かで、きれいだ安静而且漂亮
连体形静かな静かな部屋安静的房间
副词形静かに静かに話す安静地说话
条件形静かなら（ば）静かなら、ここで勉強する如果安静就在这学
推量形静かだろう / 静かでしょう静かだろう大概安静吧

变形规律

静か（词干）
  ├─ 肯定：静か + です / だ
  ├─ 否定：静か + じゃない / ではない
  ├─ 过去：静か + だった / でした
  ├─ 过去否定：静か + じゃなかった / ではなかった
  ├─ て形：静か + で
  ├─ 修饰名词：静か + な + 名词
  ├─ 副词：静か + に
  ├─ 条件：静か + なら（ば）
  └─ 推量：静か + だろう / でしょう

常用な形容词活用示例

辞书形否定过去て形连体形
静か（安静）静かじゃない静かだった静かで静かな
元気（健康）元気じゃない元気だった元気で元気な
便利（方便）便利じゃない便利だった便利で便利な
きれい（漂亮）きれいじゃないきれいだったきれいできれいな
暇（空闲）暇じゃない暇だった暇で暇な
好き（喜欢）好きじゃない好きだった好きで好きな
嫌い（讨厌）嫌いじゃない嫌いだった嫌いで嫌いな
有名（有名）有名じゃない有名だった有名で有名な

两类形容词对照表

活用い形容词（高い）な形容词（静か）
肯定高いです静かです
否定高くないです静かじゃないです
过去高かったです静かでした
过去否定高くなかったです静かじゃなかったです
て形高くて静かで
修饰名词高い本静かな部屋
副词高く静かに
条件高ければ静かなら
推量高かろう静かだろう

形容词修饰名词

い形容词 + 名词

直接连接，不变形：

  • 高い山（高山）
  • 新しい本（新书）
  • 面白い映画（有趣的电影）
  • 美しい花（美丽的花）

な形容词 + 名词

词干 + な + 名词：

  • 静かな町（安静的小镇）
  • 元気な子供（健康的孩子）
  • 便利な場所（方便的地方）
  • きれいな空（美丽的天空）

形容词副词化

形容词变为副词，修饰动词：

い形容词：く + 动词

形容词副词示例
高い高く価段が高くなる（变贵）
速い速く速く走る（快跑）
大きい大きく声が大きくする（放大声音）
新しく新しく部屋を新しくする（翻新房间）

な形容词：に + 动词

形容词副词示例
静か静かに静かに話す（安静地说）
元気元気に元気に育つ（健康地成长）
きれいきれいに部屋をきれいにする（打扫干净）
簡単簡単に簡単に解ける（简单解决）

形容词て形连接

て形用于连接多个形容词或句子，表示并列、原因等。

い形容词て形：～くて

  • このりんごは赤くて、甘い（这个苹果红而且甜）
  • 日本語は面白くて、難しい（日语有趣但难）
  • 田中さんは若くて、元気だ（田中年轻又有精神）

な形容词て形：～で

  • この町は静かで、きれいだ（这个小镇安静而且漂亮）
  • 田中さんは元気で、親切だ（田中健康而且亲切）
  • この部屋は広くて、便利だ（混合使用：い形容词て形 + な形容词）

混合连接

い形容词和な形容词可以混合连接：

  • この部屋は広くて、静かだ（这房间宽敞且安静）
  • 彼は若くて、元気だ（他年轻且有精神）

条件形用法

い形容词：～ければ

  • 高ければ、買わない（如果贵就不买）
  • 面白ければ、見に行こう（如果有趣就去看）

な形容词：～なら（ば）

  • 静かなら、ここで勉強しよう（如果安静就在这学）
  • 便利なら、そこに住みたい（如果方便就住那里）

推量形

表达推测「大概...吧」：

い形容词

  • 高いだろう / 高いでしょう（大概贵吧）
  • 高かろう（古风/书面）

な形容词

  • 静かだろう / 静かでしょう（大概安静吧）

特殊形容词

いい / よい（好）

活用形态
辞书形いい / よい
否定よくない
过去よかった
て形よくて
条件よければ

注意

「いい」只能用于辞书形和连体形，变形时必须用「よい」。

多い / 少ない（多/少）

这两个词不能直接修饰名词：

  • ✗ 多い人
  • ✓ 多くの人（很多人）
  • ✗ 少ない本
  • ✓ 少ない数の本 / あまり多くない本

实用表达

比较句

句型示例
A は B より...日本は中国より小さい（日本比中国小）
A と B とどちらが...日本語と英語とどちらが難しいですか
A の方が...日本語の方が難しいです（日语更难）
一番...三人の中で田中さんが一番高い（三人中田中最高）

好恶表达

好恶用な形容词「好き/嫌い」：

  • 私はりんごが好きです（我喜欢苹果）
  • 私は肉が嫌いじゃない（我不讨厌肉）
  • どんな音楽が好きですか（喜欢什么音乐？）

好恶的对象用が

表示好恶、能力时，对象用「が」而非「を」：

  • 私は日本語が好きだ（不是 日本語を好きだ）
  • 私はスポーツが得意だ（不是 スポーツを得意だ）

变化表达

句型示例
〜くなる（い形容词）価段が高くなった（变贵了）
〜になる（な形容词）部屋がきれいになった（房间变干净了）
〜くする（い形容词）価段を安くする（降价）
〜にする（な形容词）部屋をきれいにする（打扫房间）

小结

要点说明
分类い形容词（～い）/ な形容词（～な + 名词）
い否定～くないです / ～くありません
な否定～じゃないです / ～ではありません
い过去～かったです
な过去～でした / ～だった
いて形～くて
なて形～で
修饰名词い直接 / な + な
副词化い→～く / な→～に
条件い→～ければ / な→～なら

掌握形容词活用后，配合和，就能表达丰富的日语句子了。
