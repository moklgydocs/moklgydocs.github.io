高级话题——正式表达、迹象、倾向、即时事件

高级话题——正式表达、迹象、倾向、即时事件

本章节参考 Tae Kim《A Guide to Japanese Grammar》（CC BY-NC-SA 3.0）编译整合。

这一章覆盖高级语法：正式书面表达、理应如此、最低期望、迹象与氛围、不可行性、倾向、即时事件、被某物覆盖、其他杂项。这些语法大多用于书面，口语里很少听到。 学这些主要是为了读小说、新闻、公文，以及应付 JLPT N1。

一、正式表达（である）

我们学过口语的「だ」、礼貌的「です」、尊敬的「でございます」。还有一种正式陈述事实的状态表达：「である」。主要用于演讲、报告、纪录片、学术文章。

  • 吾輩は猫である。　——我是猫。（夏目漱石小说名）
  • 混合物とは、2種類以上の純物質が混じりあっている物質である。　——混合物是两种以上纯物质混合而成的物质。（维基百科）

对比同一个句子的不同语气：

  1. 混合物は何？　混合物は、…物質だ。　——口语
  2. 混合物は何ですか？　混合物は、…物質です。　——礼貌
  3. 混合物は何でしょうか。　混合物は、…物質でございます。　——尊敬
  4. 混合物とは？　混合物は、…物質である。　——正式

否定形： 因为「ある」的否定是「ない」，你以为是「でない」，实际是「ではない」（中间要插主题助词「は」）。

  • それは不公平ではないでしょうか。　——那不算不公平吧？
  • 言語は簡単にマスターできることではない。　——语言不是能轻易掌握的东西。

活用表：

肯定否定
非过去学生である学生ではない
过去学生であった学生ではなかった

正式文章里的连用形

复合句里我们学过用て形连接动作。但正式文章、新闻报道为了简洁，用动词词干代替て形连接顺序动作。

  • 花火は、火薬と金属の粉末を混ぜたものに火を付け、燃焼時の火花を楽しむためのもの。　——烟花是把火药和金属粉末混合物点燃、享受燃烧时火花的玩意。（维基百科）
  • 企業内の顧客データを利用し、彼の行方を調べることが出来た。　——利用公司内部客户数据，查清了他的下落。

「～ている」在正式文章里变「～てい」，但放在句中不合适，所以用「いる」的谦让形「おる」的连用形「おり」：

  • 封筒には写真が数枚入っており、手紙が添えられていた。　——信封里有几张照片，附了一封信。
  • このファイルにはパスワードが設定されており、開く際にはそれを入力する必要がある。　——这个文件设了密码，打开时要输入。

二、理应如此（はず、べき）

「はず」：预期

表示"应该、本来应该"。像普通名词一样用。注意：要表达"不该发生"的预期，必须用「ない」说"这种预期不存在"：「～はずがない」「～はずはない」。「はずじゃない」只用于反问确认：「～はずじゃないか？」

  • 彼は漫画マニアだから、これらをもう全部読んだはずだよ。　——他是漫画狂，应该已经全看过了。
  • この料理はおいしいはずだったが、焦げちゃって、まずくなった。　——这菜本应该好吃的，烧糊了变难吃了。
  • 色々予定してあるから、今年は楽しいクリスマスのはず。　——各种安排都做好了，今年应该是个快乐的圣诞。
  • そう簡単に直せるはずがないよ。　——不可能那么容易修好。
  • 打合せは毎週２時から始まるはずじゃないですか？　——会议不是应该每周两点开始吗？

「べき」：应该做

强语气的"应该"。不能用来提建议（提建议用「方がいい」），它是"你应该/理应做"的断言，听起来像说教。多用于对自己或中性语境。

像普通名词一样用。「するべき」可缩成「すべき」（仅限「する」一个动词）。

  • 何かを買う前に本当に必要かどうかをよく考えるべきだ。　——买东西前应该好好想想是否真需要。
  • 例え国のためであっても、国民を騙すべきではないと思う。　——就算为了国家，也不应该欺骗国民。
  • 金融庁は被害者の救済を優先させて、金融機関に犯罪防止対策の強化を促すべきだと判断。　——金融厅判断应优先救济受害者，督促金融机构加强防罪对策。（朝日新闻）

「べく」：为了做

「べき」的连用形（古旧表达，少用），表示"为了做到某事"。

  • 試験に合格すべく、皆一生懸命に勉強している。　——为了通过考试，大家都在拼命学。
  • 今後もお客様との対話の窓口として、より充実していくべく努力してまいります。　——今后也会为了提供更充实的客户互动窗口而努力。

「べからず」：不可做

「べき」的反义，"不可做"。多用于规章制度。

  • ゴミ捨てるべからず。　——禁止扔垃圾。
  • 安全措置を忘れるべからず。　——不可忘记安全措施。

三、最低期望（さえ、すら、おろか）

「（で）さえ」：连……都

表示最低要求都没达到，或"只要有……就够了"。

名词：直接加「さえ」或「でさえ」。

  • 宿題が多すぎて、トイレに行く時間さえなかった。　——作业太多，连上厕所的时间都没有。
  • お金さえあれば、何でも出来るよ。　——只要有钱什么都能做。
  • 私でさえ出来れば、あんたには楽ちんでしょう。　——连我都会，对你肯定小菜一碟。

动词：词干 + さえ + する。或て形 + さえ。

  • ビタミンを食べさえすれば、健康が保証されますよ。　——只要吃维生素，健康有保证。
  • 自分の過ちを認めさえしなければ、問題は解決しないよ。　——只要不承认自己的错，问题就解决不了。
  • 教科書をもっとちゃんと読んでさえいれば、合格できたのに。　——要是好好读课本就能及格了。
  • 一言言ってさえくれればこんなことにならなかった。　——你要是说一句话就不会变成这样。

「（で）すら」：「さえ」的老版本

基本互换，但只用于名词，更书面。

  • この天才の私ですらわからなかった。　——连我这样的天才都不会。
  • 私は緊張しすぎて、ちらっと見ることすら出来ませんでした。　——我紧张得连瞥一眼都做不到。
  • 「人」の漢字すら知らない生徒は、いないでしょ！　——连"人"字都不认识的学生没有吧！

「おろか」：别提了

表示"某事荒谬到不值得考虑"。英语 "much less" 的感觉。

  • 漢字はおろか、ひらがなさえ読めないよ！　——汉字别提了，连平假名都不会读！
  • 結婚はおろか、2ヶ月付き合って、結局別れてしまった。　——结婚别提了，交往两个月就分了。
  • 大学はおろか、高校すら卒業しなかった。　——大学别提了，连高中都没毕业。

更常见的同义表达是「どころか」（直接接名词/形容词/动词）：

  • 漢字どころか、ひらがなさえ読めないよ！　——汉字别提了，连平假名都不会读！

四、迹象与氛围（がる、ばかり、めく）

「～がる」：观察到他人的情绪

用于观察别人的情绪（不能用于自己，因为不用猜自己的情绪）。只能接形容词。变成う动词。

  • い形容词：去「い」加「がる」。怖い → 怖がる
  • な形容词：直接加「がる」。嫌 → 嫌がる
肯定否定
非过去怖がる怖がらない
过去怖がった怖がらなかった
  • 早くきてよ！何を恥ずかしがっているの？　——快点过来！你害羞个什么劲？
  • 彼女は朝早く起こされるのを嫌がるタイプです。　——她是那种讨厌被早起叫醒的类型。
  • うちの子供はプールに入るのを理由もなく怖がる。　——我家孩子莫名其妙地怕进泳池。

也能用「欲しい」「～たい」观察别人想要什么（多用于叙事，口语常用「でしょう」代替）：

  • 家に帰ったら、すぐパソコンを使いたがる。　——他一回家就想用电脑。
  • みんなイタリアに行きたがってるんだけど、私の予算で行けるかどうかはとても怪しい。　——大家都表现得想去意大利，但我这预算能不能去很可疑。
  • 妻はルイヴィトンのバッグを欲しがっているんだけど、そんなもん、買えるわけないでしょう！　——老婆想要路易威登的包，那种东西怎么可能买得起！

加「屋」表示"容易……的人"：恥ずかしがり屋（容易害羞的人）、寒がり屋（容易冷的人）、暑がり屋（容易热的人）。

  • 私は寒がり屋だから、ミネソタで暮らすのは辛かった。　——我是怕冷体质，在明尼苏达生活很痛苦。

「ばかり」：装作要做某事

动词的「ん」否定形 +「ばかり」，表示"装作要……的样子"。和表示数量或刚做完的「ばかり」完全不同。多用于小说，口语几乎不用。

  • 非过去肯定：言う → 言わない → 言わん → 言わんばかり
  • 其他形：直接加「ばかり」。言わなかった → 言わなかったばかり
肯定否定
非过去言わんばかり言わないばかり
过去言ったばかり言わなかったばかり
  • ボールは爆発せんばかりに、膨らんでいた。　——球膨胀得像要爆炸。
  • 「あんたとは関係ない」と言わんばかりに彼女は彼を無視していた。　——她无视他，像在说"跟你没关系"。
  • 昨日の喧嘩で何も言わなかったばかりに、平気な顔をしている。　——昨天吵架时什么都没说，一脸没事的样子。

「めく」：……的氛围

接名词或な形容词，表示"散发出……的氛围"。变成う动词。最常用的是过去形「～めいた」。

  • 謎 → 謎めく
  • 紅葉が始まり、すっかり秋めいた空気になってきた。　——红叶开始变红，空气完全有了秋意。
  • そんな謎めいた顔をされても、うまく説明できないよ。　——你摆出那种谜一样的表情，我也解释不好。
  • いつも皮肉めいた言い方をしたら、みんなを嫌がらせるよ。　——老用那种讽刺的口吻说话，会让大家都讨厌你。

五、不可行性（ざるを得ない、やむを得ない、かねる）

「～ざるを得ない」：不得不

双重否定表示"不得不做"。带"本来不想做，但没办法"的语气。使用古旧的「～ざる」否定形（把「ない」换成「ざる」）。

  • 食べる → 食べない → 食べざる → 食べざるを得ない

  • 行く → 行かない → 行かざる → 行かざるを得ない

  • 例外：する → せざる；くる → こざる

  • このテレビがこれ以上壊れたら、新しいのを買わざるを得ないな。　——这电视再坏下去，只能买新的了。

  • ずっと我慢してきたが、この状態だと歯医者さんに行かざるを得ない。　——忍了很久，这情况只能去看牙医了。

  • 上司の話を聞くと、どうしても海外に出張をせざるを得ないようです。　——听老板的意思，无论如何都得去海外出差。

「やむを得ない」：无可奈何

固定短语，描述"身不由己的情况"。和「仕方がない」「しょうがない」意思接近，但更正式，用于描述客观情况而不是被迫做某事。

  • やむを得ない事由により手続が遅れた場合、必ずご連絡下さい。　——因不可抗力导致手续延误时，请务必联系。
  • この仕事は厳しいかもしれませんが、最近の不景気では新しい仕事が見つからないのでやむを得ない状態です。　——这工作可能辛苦，但最近不景气找不到新工作，是无可奈何的状况。

「～かねる」：难以做

る动词，接动词词干，表示"难以/不便/拒绝做"。常用于正式礼貌的拒绝。否定形「～かねない」表示"有可能发生（不好的事）"。

  • 決める → 決めかねる

  • する → しかねる

  • なる → なりかねる → なりかねない

  • この場ではちょっと決めかねますので、また別途会議を設けましょう。　——这里不太好决定，再另开个会吧。

  • このままでは、個人情報が漏洩しかねないので、速やかに対応をお願い致します。　——这样下去可能有个人信息泄露的风险，请尽快处理。

六、倾向（がち、つつ、きらいがある）

「～がち」：容易……

接动词词干或名词，表示"容易发生（多为不好的）"。像な形容词一样用。这是本章唯一可能在口语里听到的语法。

  • 动词：词干 + がち。見る → 見がち；なる → なりがち

  • 名词：直接加。病気 → 病気がち

  • 確定申告は忘れがちな手続のひとつだ。　——报税是容易忘的手续之一。

  • 留守がちなご家庭には、犬よりも、猫の方がおすすめです。　——经常不在家的家庭，推荐养猫而非狗。

  • 父親は病気がちで、みんなが心配している。　——父亲容易生病，大家都很担心。

「～つつ」：一边……一边……（书面）

接动词词干，类似「ながら」但更书面、更文学，两动作权重相等。口语几乎不用。

  • 見る → 見つつ

  • 思う → 思いつつ

  • 二日酔いで痛む頭を押さえつつ、トイレに入った。　——一边按着宿醉头痛的头一边进了厕所。

  • 体によくないと思いつつ、最近は全然運動してない。　——一边觉得对身体不好，最近完全没运动。

加「ある」变「～つつある」表示"正在……中"，常用于报道趋势：

  • 電気製品の発展につれて、ハードディスクの容量はますます大きくなりつつある。　——随着电子产品发展，硬盘容量越来越大。
  • 今の日本では、終身雇用や年功序列という雇用慣行が崩れつつある。　——当今日本，终身雇佣和年功序列的雇佣惯例正在瓦解。

「きらいがある」：有……的坏倾向

固定表达，「きらい」在这里是名词（和な形容词「嫌い」不同）。表示"有……的不良习惯"。

  • 多くの大学生は、締切日ぎりぎりまで、宿題をやらないきらいがある。　——很多大学生有把作业拖到截止日的坏习惯。
  • コーディングが好きな開発者は、ちゃんとしたドキュメント作成と十分なテストを怠るきらいがある。　——喜欢编程的开发者有忽视文档和测试的坏倾向。

七、即时事件（が早いか、や否や、そばから）

这三个都表示"一……就……"，但侧重点不同。都用于书面，口语几乎不用。

「が早いか」：一……瞬间就……

强调两件事几乎同时发生，像同步一样。第一个动词用词典形或过去形。

  • 彼女は、教授の姿を見るが早いか、教室から逃げ出した。　——她一看到教授的身影，就逃出了教室。
  • 「食べてみよう」と言うが早いか、口の中に放り込んだ。　——一说"尝尝看"，就塞进了嘴里。

「や／や否や」：一……马上就……

「否」读「いな」，字面"是否做了"，意思是"还没来得及判断第一件事是否发生，第二件事就来了"。第一个动词用词典形。

  • 私の顔を見るや、何か言おうとした。　——一看到我的脸，就想说什么。
  • 搭乗のアナウンスが聞こえるや否や、みんながゲートの方へ走り出した。　——一听到登机广播，大家就朝登机口跑去。

「そばから」：一……就……（反复）

和前两个不同，这个暗示反复发生。比如"刚打扫完又脏了"。第一个动词用词典形，第二个动词通常用词典形（因为是反复事件）。

  • 子供が掃除するそばから散らかすから、もうあきらめたくなった。　——孩子我一打扫就弄乱，我都想放弃了。
  • 教科書を読んだそばから忘れてしまうので勉強ができない。　——课本读了就忘，没法学习。

八、被某物覆盖（だらけ、まみれ、ずくめ）

「だらけ」：满是……

接名词，表示"满是……（通常是负面的）"。像名词一样用。

  • 間違い → 間違いだらけ（满是错误）

  • 埃 → 埃だらけ（满是灰尘）

  • このドキュメントは間違いだらけで、全然役に立たない。　——这文档满是错误，完全没用。

  • 携帯を２年間使ってたら、傷だらけになった。　——手机用了两年，全是划痕。

  • この埃だらけのテレビをちゃんと拭いてくれない？　——能把这台满是灰的电视擦干净吗？

「まみれ」：沾满……

和「だらけ」相似，但只能用于物理上真正覆盖物体的东西（液体、粉尘）。不能用于抽象的"错误"或"垃圾"这种不真正"覆盖"的东西。

  • 血 → 血まみれ（沾满血）

  • 油 → 油まみれ（沾满油）

  • 彼は油まみれになりながら、車の修理に頑張りました。　——他满身油污地努力修车。

  • たった１キロを走っただけで、汗まみれになるのは情けない。　——只跑了一公里就满身大汗，真没出息。

（不能说「間違いまみれ」「ゴミまみれ」，要用「だらけ」。）

「ずくめ」：全是……

表示"全都是……（从 head to toe）"。很少用，常配合颜色描述"全身穿某色"。

  • 白 → 白ずくめ

  • いいこと → いいことずくめ

  • 白ずくめ団体は去年ニュースになっていた。　——那个全穿白色的团体去年上了新闻。

  • このシェークは、おいしいし、栄養たっぷりで体にいいですから、いいことずくめですよ。　——这奶昔又好喝又营养对身体好，全是好事。

九、其他杂项

「思いきや」：本以为……却……

表示"本以为 X，结果却大不相同"。用「と」接想法，把「思う」换成「思いきや」。没有时态（结果已经发生，想法隐含过去）。

  • 昼間だから絶対込んでいると思いきや、一人もいなかった。　——本来以为白天肯定很挤，结果一个人都没有。
  • このレストランは安いと思いきや、会計は5千円以上だった！　——以为这餐厅便宜，账单居然超过 5 千日元！

「～がてら」：顺便……

表示做主要动作时顺便做另一件事。比「ながら」正式，少用。可接名词（推断「する」）或动词词干。

  • 散歩 → 散歩がてら

  • 作る → 作りがてら

  • 散歩がてら、タバコを買いに行きました。　——散步顺便去买烟。

  • 博物館を見がてらに、お土産を買うつもりです。　——看博物馆顺便买纪念品。

「～あげく」：……到最后

表示"经过漫长的……，最后（通常是坏结果）"。接动词过去形或「の」+名词。

  • けんか → けんかのあげく

  • 考えた → 考えたあげく

  • 事情を2時間かけて説明したあげく、納得してもらえなかった。　——花了两个小时解释情况，最后还是没被理解。

  • 先生と相談のあげく、退学をしないことにした。　——和老师商量后，最后决定不退学。

「あげくの果て」是更强版本。
