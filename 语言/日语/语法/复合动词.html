复合动词与补助动词

复合动词与补助动词

日语动词可以通过组合表达更丰富的含义。复合动词和补助动词是中级语法的重点，掌握它们能让表达更地道。

复合动词

复合动词 = 动词1（ます形词干）+ 动词2，两个动词组合产生新含义。

常见复合动词

复合动词构成含义示例
〜始めるVます + 始める开始做...食べ始める（开始吃）
〜出すVます + 出す开始/涌出泣き出す（哭起来）
〜続けるVます + 続ける持续做...走り続ける（持续走）
〜終わるVます + 終わる做完...読み終わる（读完）
〜過ぎるVます + 過ぎる过度...食べ過ぎる（吃太多）
〜直すVます + 直す重新做...書き直す（重写）
〜返すVます + 返す反复/回思い返す（回想）
〜込むVます + 込む进入/深入入り込む（进入深处）
〜上げるVます + 上げる向上/完成作り上げる（制作完成）
〜上げるVます + 上げる彻底完成書き上げる（写完）
〜下げるVます + 下げる向下見下げる（俯视）
〜付くVます + 付く附带言い付く（嘱咐）
〜切るVます + 切る彻底/切断読み切る（读完）、分かり切る（完全明白）
〜切れないVます + 切れない无法穷尽数え切れない（数不清）
〜抜くVます + 抜く贯穿/坚持到底やり抜く（坚持做完）
〜通すVます + 通す贯穿到底言い通す（坚持说）
〜合うVます + 合う互相...話し合う（互相讨论）
〜かけるVます + かける开始/未完成食べかける（开始吃/没吃完）
〜慣れるVます + 慣れる习惯于...使い慣れる（用习惯）
〜忘れるVます + 忘れる忘记做...書き忘れる（忘记写）
〜得るVます + 得る能够...あり得る（可能有）

按功能分类

1. 表示开始/结束

复合动词含义示例
〜始める开始雨が降り始めた（开始下雨了）
〜出す突然开始突然泣き出した（突然哭起来）
〜終わる结束宿題をやり終わった（写完作业了）
〜上がる完成踊りが終わり上がった（舞蹈结束了）

始める vs 出す

  • 始める：平稳开始（雨が降り始める）
  • 出す：突然、意外地开始（突然降り出した）

2. 表示持续/反复

复合动词含义示例
〜続ける持续3時間歩き続けた（持续走了3小时）
〜通す贯穿到底一晩中話し通した（聊了一整夜）
〜抜く坚持到底最後までやり抜いた（坚持到最后）

3. 表示程度

复合动词含义示例
〜過ぎる过度食べ過ぎて腹が痛い（吃太多肚子疼）
〜切る彻底信じ切る（深信不疑）
〜切れない无法穷尽数え切れない星（数不清的星星）

4. 表示互相

复合动词含义示例
〜合う互相助け合う（互相帮助）
話し合う（讨论）
愛し合う（相爱）

5. 表示重新/修正

复合动词含义示例
〜直す重做書き直す（重写）
考え直す（重新考虑）
やり直す（重做）

6. 表示未完成

复合动词含义示例
〜かける没做完食べかけのパン（吃了一半的面包）
読みかけたが、やめた（读了开头但放弃了）

复合动词的注意事项

不是所有动词都能复合

  • ✗ 食べ始める ✓（他动词 + 始める）
  • ✗ 降り始める ✓（自动词 + 始める）
  • 但部分动词组合不自然，需查词典确认

〜切る vs 〜抜く

  • 読み切る：读完（强调完成）
  • 読み抜く：坚持读完（强调克服困难）

补助动词

补助动词：失去独立意义，附在て形/ます形后增添语法功能的动词。

て形 + 补助动词

这是最重要的补助动词用法。

1. 〜ている（正在进行/状态）

用法示例翻译
动作进行食べている正在吃
结果状态死んでいる死了（状态）
习惯毎日走っている每天跑步
经验結婚している已婚

ている 的口语缩略

口语中常省略「い」：

  • 食べてる（食べている）
  • 読んでる（読んでいる）

2. 〜てある（结果状态）

他动词 + てある：表示某人做了某事后留下的状态。

  • 窓が開けてある（窗户开着 —— 有人开的）
  • 字が書いてある（写着字）
  • 部屋が片付けてある（房间收拾好了）

ている vs てある

  • 窓が開いている：窗户开着（客观状态，可能是风吹的）
  • 窓が開けてある：窗户开着（有人故意开的）

3. 〜ておく（预先/放任）

用法示例翻译
预先做電話しておく提前打电话
放任不管そのままにしておく就那样放着
事后处理メモしておく记下来（备用）

口语缩略：ておく → とく

  • 電話しとく（電話しておく）
  • 見とく（見ておく）

4. 〜てみる（尝试）

  • 食べてみる（尝尝看）
  • やってみる（试试做）
  • 読んでみてください（请读读看）

5. 〜てしまう（完成/遗憾）

用法示例翻译
彻底完成宿題をやってしまった作业做完了
遗憾/不小心落としてしまった不小心掉了
无可挽回遅刻してしまった迟到了（遗憾）

口语缩略：てしまう → ちゃう / てしまう → ちまう

  • 食べちゃう（食べてしまう）
  • 忘れちゃった（忘れてしまった）

6. 〜てくる / 〜ていく（趋势/方向）

形式含义示例
〜てくる向说话人方向/到现在为止走ってきた（跑过来了）
状态变化出现寒くなってきた（变冷了）
持续到现在ずっと勉強してきた（一直学到现-在）
〜ていく离开说话人/今后继续走っていった（跑过去了）
状态变化持续これも寒くなっていく（今后会继续变冷）
持续到未来これも勉強していく（今后继续学）

てくる vs ていく

  • てくる：变化发生到现在（到现在为止）
  • ていく：变化从现在持续到未来（今后）
  • 寒くなってきた（已经变冷了）
  • これから寒くなっていく（今后会变冷）

7. 〜てくれる / 〜てもらう / 〜てあげる（授受）

形式谁做谁受益示例
〜てあげる我/己方对方本を貸してあげる（我借书给你）
〜てくれる对方我田中さんが教えてくれる（田中教我）
〜てもらう对方我（主动请求）田中さんに教えてもらう（请田中教我）

敬体：

  • 〜てさしあげる（谦让：给对方）
  • 〜てくださる（尊敬：对方给我）
  • 〜ていただく（谦让：我接受对方）

てあげる 的注意

对长辈或上级用「てあげる」显得不礼貌（有施恩意味），应改用：

  • お/ご + ます形 + する（谦让语）
  • 或避免直接表达「我为你做」

8. 〜てほしい（希望对方做）

  • 来てほしい（希望你来）
  • 手伝ってほしい（希望你帮忙）
  • 早く来てほしい（希望你早点来）

9. 〜ても（让步）

  • 食べてもいい（可以吃）
  • 行かなくてもいい（不去也行）
  • いくら読んでも分からない（怎么读都不懂）

10. 〜て済む / 〜て済ませる（解决）

  • 謝って済む問題だ（道个歉就能解决的问题）
  • 金で済ませる（用钱解决）

ます形 + 补助动词

形式含义示例
Vます + たい想做食べたい
Vます + たがる想做（第三人称）田中さんは食べたがる
Vます + そうだ（样态）看起来要...雨が降りそうだ
Vます + ながら一边...一边食べながら話す
Vます + つもり打算行くつもりだ
Vます + 予定预定3時に着く予定だ
Vます + ことができる能够食べることができる

小结

要点说明
复合动词Vます + V2，产生新含义
补助动词て形/ます形 + 辅助动词，增添语法功能
ている进行/状态/习惯/经验
てある他动词结果的存续
ておく预先/放任
てしまう完成/遗憾
てくる/ていく时间方向趋势
てあげる/くれる/もらう授受关系

掌握复合动词和补助动词是日语从初级迈向中级的关键，建议结合反复练习。
