敬语体系

敬语体系

敬语（けいご）是日语的重要特征，用于表达对他人或第三者的尊敬。日语敬语体系庞大但规则清晰，主要分三大类。

敬语三大类

类别作用对象核心
尊敬语（そんけいご）抬高对方动作对方/第三者（上位）动词特殊变形
谦让语（けんじょうご）贬低自己动作自己/己方（下位）动词特殊变形
郑重语（ていねいご）礼貌表达听者です/ます

核心原则

  • 对对方的动作用尊敬语（抬高对方）
  • 对自己的动作用谦让语（贬低自己）
  • 对所有表达加郑重语（礼貌语气）

郑重语（ていねいご）

最基础的敬语，表示对听者的礼貌。

规则

词类普通体郑重语
名词学生だ学生です
い形容词高い高いです
な形容词静かだ静かです
动词書く書きます
否定書かない書きません
过去書いた書きました

更郑重的表达

在です/ます基础上，用「ござる」「存じる」等更郑重的词：

普通郑重更郑重
ですですでございます
あるありますございます
ないありませんございません
だですでございます

示例：

  • これは本です → これは本でございます
  • 申し訳ありません → 申し訳ございません

尊敬语（そんけいご）

用于对方或上位者的动作，表示尊敬。

构成方式

方式规则示例
特殊动词用专门的尊敬动词いる→いらっしゃる
お/ご + 动词ます形 + になる规则变形書く→お書きになる
お/ご + 动词ます形 + です规则变形書く→お書きです
れる/られる受身形作尊敬書く→書かれる

常用尊敬动词

普通尊敬语中文
いるいらっしゃる在
行くいらっしゃる / おいでになる去
来るいらっしゃる / おいでになる / 見える来
するなさる做
言うおっしゃる说
食べる / 飲む召し上がる吃/喝
見るご覧になる看
聞くお聞きになる听/问
思う思し召す想
知っているご存知です知道
着るお召しになる穿

なさる 的变形

なさる、いらっしゃる、おっしゃる、くださる、ござる 这五个动词的ます形特殊：

  • なさる → なさいます（不是 なさります）
  • いらっしゃる → いらっしゃいます
  • おっしゃる → おっしゃいます
  • くださる → くださいます
  • ござる → ございます

规则变形示例

普通お～になるお～ですれる/られる
書くお書きになるお書きです書かれる
読むお読みになるお読みです読まれる
待つお待ちになるお待ちです待たれる
話すお話しになるお話しです話される

尊敬语使用示例

  • 先生がいらっしゃいます（老师在）
  • 社長がおっしゃいました（社长说了）
  • 田中先生はお茶を召し上がります（田中先生喝茶）
  • 先生はこの本をご覧になりました（老师看了这本书）
  • 社長は明日東京へいらっしゃいます（社长明天去东京）

谦让语（けんじょうご）

用于自己或己方人员的动作，通过贬低自己来抬高对方。

构成方式

方式规则示例
特殊动词用专门的谦让动词言う→申し上げる
お/ご + 动词ます形 + する规则变形書く→お書きする
お/ご + 动词ます形 + 申し上げる更谦让書く→お書き申し上げる

常用谦让动词

普通谦让语中文
行く参る（まいる）去
来る参る来
する致す（いたす）做
言う申し上げる / 申す说
食べる / 飲む頂く（いただく）吃/喝
見る拝見する（はいけんする）看
聞く伺う（うかがう） / 拝聴する听/问
思う存じる（ぞんじる）想
知っている存じ上げている知道
会うお目にかかる见面
借りる拝借する（はいしゃくする）借
もらう頂く（いただく） / 賜る得到
あげる差し上げる（さしあげる）给

规则变形示例

普通お～するお～申し上げる
書くお書きするお書き申し上げる
読むお読みするお読み申し上げる
持つお持ちするお持ち申し上げる
送るお送りするお送り申し上げる

谦让语使用示例

  • 私が参ります（我去）
  • 私は明日東京に参ります（我明天去东京）
  • 先生にお目にかかりました（见到了老师）
  • これからご説明いたします（接下来我来解释）
  • お手紙を拝見しました（我看了您的信）
  • ごちそうをいただきました（我吃了美食）

来るいらっしゃる / 見える参る

美化语（びかご）

美化语不是严格意义的敬语，而是让词语显得文雅：

普通美化语
酒お酒
茶お茶
飯ご飯
金お金
肉お肉
水お水

お vs ご

  • お + 和语词（日本固有词）：お茶、お水、お花
  • ご + 汉语词（中文借词）：ご飯、ご挨拶、ご連絡

场景表达

敬语使用要点

1. 区分内外关系

内外关系

对公司外部提到自己公司的人时，即使对方是社长也不用尊敬语：

  • ✗ 社長がいらっしゃいます（对外部说自家社长）
  • ✓ 社長がおります（对外部说自家社长，用谦让语）

2. 避免双重敬语

  • ✗ お召し上がりになる（双重）
  • ✓ 召し上がる / お食べになる

3. 尊敬语 vs 谦让语选择

场景选择
对方/上位者的动作尊敬语
自己/己方的动作谦让语
无关第三者（一般）郑重语即可

4. 身份关系

对象敬语等级
家人（对外）不用敬语
朋友普通体或郑重语
同事郑重语
上司/客户尊敬语 + 谦让语
初次见面郑重语起

小结

要点说明
三大类尊敬语（抬高对方）/ 谦让语（贬低自己）/ 郑重语（礼貌语气）
尊敬语对方动作用，特殊动词或 お～になる
谦让语自己动作用，特殊动词或 お～する
郑重语です/ます，最基础礼貌
内外关系对外提自己人不用尊敬语
避免双重一个动词只用一种敬语形式

敬语是日语高级阶段的内容，建议先扎实掌握和后再深入学习。
