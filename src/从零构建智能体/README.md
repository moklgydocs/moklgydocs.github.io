如果说 2024 年是"百模大战"的元年,2025 年则开启了"Agent 元年"。本教程穿透框架表象,从智能体核心原理出发,深入经典范式,最终亲手构建属于自己的多智能体应用——从一名大语言模型的"使用者",蜕变为智能体系统的"构建者"。

## 阅读路线

- **第一部分 · 智能体与语言模型基础**(第 1~3 章):智能体定义、发展史、大语言模型基础。
- **第二部分 · 构建你的大语言模型智能体**(第 4~7 章):ReAct 等经典范式、低代码平台、AutoGen/LangGraph 等主流框架、自研 Agent 框架。
- **第三部分 · 高级知识扩展**(第 8~12 章):记忆与检索、上下文工程、智能体通信协议(MCP/A2A/ANP)、Agentic-RL、性能评估。
- **第四部分 · 综合案例进阶**(第 13~15 章):智能旅行助手、自动化深度研究智能体、赛博小镇。
- **第五部分 · 毕业设计**(第 16 章):构建完整的多智能体应用。
- **番外篇**:面试题、Dify 保姆级教程、GUI/Web Agent 实战、Skill 写作、踩坑经验等社区精选。

原书配套代码在仓库 [code/ 目录](https://github.com/datawhalechina/hello-agents/tree/main/code)下。
