> 本专栏转载自 李博杰[《深入理解 AI Agent:设计原理与工程实践》](https://bojieli.github.io/ai-agent-book/)(项目地址:[bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book))。著作权归原作者所有,采用 [Apache License 2.0](https://github.com/bojieli/ai-agent-book/blob/main/LICENSE) 许可,本站仅供个人学习使用。

**Agent = LLM + 上下文 + 工具**——本书围绕这个核心公式,用 10 章把 AI Agent 从原理讲到工程实战:

1. **AI Agent 入门**:核心组成与经典架构;
2. **上下文工程**:Agent 的"眼睛";
3. **用户记忆和知识库**:让 Agent 记住用户;
4. **工具**:Agent 的"手脚";
5. **Coding Agent 与通用 Agent**:Cursor、Deep Research 等产品形态解析;
6. **交互:观察与动作空间的扩展**:异步交互与多模态;
7. **Agent 的评估**: benchmark 与工程评测;
8. **模型后训练**:SFT 与强化学习;
9. **Agent 的持续进化**:自我改进机制;
10. **多 Agent 协作**:协作模式与通信协议。

全书另有 **103 个配套实验**,在原仓库各 `chapterN/` 目录下,建议结合正文动手跑一遍。每章末尾思考题汇总于[思考题参考答案](./12-思考题参考答案.md)。
