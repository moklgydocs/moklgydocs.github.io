# AI 工程实战(从零到生产)

一套从开发环境到生产部署的完整 AI 工程课程,503 课、20 个阶段,覆盖数学基础、机器学习、深度学习、计算机视觉、NLP、语音、Transformer、生成式 AI、强化学习、从零构建 LLM、LLM 工程、多模态、工具与协议、智能体工程、自治系统、多智能体、基础设施与生产、伦理安全对齐,最后是 87 个结课项目。

::: info 关于本专栏
本专栏为 [ai-engineering-from-scratch](https://github.com/devpanna/ai-engineering-from-scratch) 课程的中文全译本,代码、图表、数据与原文保持一致。每课含:元信息(类型/编程语言/前置要求/预计耗时)、正文、关键术语表、练习与延伸阅读。
:::

## 使用建议

- **零基础**:从第 0 阶段顺序读起,每课动手做练习。
- **有 ML 基础**:可从第 7 阶段(Transformer)切入,再按兴趣分流到生成式、智能体或基建。
- **工程师转行**:第 11、13、14、17 阶段是工程密度最高的部分,优先精读。
