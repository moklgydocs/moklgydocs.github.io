# 心智社会与多智能体辩论

> Minsky 1986 年的前提——智能是一个专家组成的社会——每十年被重新发现一次。2023 年,Du 等人把它变成了一个具体算法:多个 LLM 实例各自提出答案、互读彼此的答案、批评、更新。经过 N 轮,它们收敛到一个共识,在六个推理与事实性任务上胜过零样本 CoT 和反思。两个发现要紧:**多个智能体**和**多个轮次**各自独立地有贡献。社会胜过单智能体独白;多轮交换胜过一次性投票。

**类型:** 学习 + 动手构建
**编程语言:** Python(标准库)
**前置要求:** 第 16 阶段 · 04(原语模型)
**预计耗时:** 约 60 分钟

## 问题

自一致性(self-consistency)——同一个模型采样多次,取多数答案——是你能外挂的最便宜的推理改进。它有效,但饱和得很快。采样数翻倍,也看不到再一次有意义的提升。

辩论打破了饱和。不再是从一个模型取 N 个独立样本,而是 N 个智能体互读彼此的推理并修正。样本之间的相关性下降(它们不再是独立同分布的),而收敛点往往在独立投票自信地答错的地方,反而是对的。

## 概念

### Du 等人 2023 年的算法

出自 arXiv:2305.14325(ICML 2024):

1. N 个智能体各自对问题给出初始答案。
2. 第 r = 2..R 轮:每个智能体看到其他智能体第 r-1 轮的答案,被要求"考虑这些,给出你更新后的答案"。
3. R 轮之后,对最终答案做多数投票。

论文在 MMLU、GSM8K、传记、MATH 和事实性基准上测试。辩论稳定胜过 CoT 和自我反思。

### 两个独立的旋钮

同一篇论文的消融:

- **只加智能体数**(1 轮,N 个多数投票)在多数任务上胜过单智能体,但很快到平台期。
- **只加轮数**(1 个智能体看自己先前的推理)几乎没帮助——反思的已知弱点。
- **两个一起**才产生大跳跃。多智能体之间的多轮交换,才是收益的来源。

### 为什么有效

两个机制:

1. **暴露于分歧。** 当一个智能体看到另一个智能体结论不同的推理链时,它必须要么自证、要么更新。无论哪种,第 r+1 轮的上下文都比第 r 轮更丰富。
2. **相关误差减少。** 自一致性里,所有样本来自同一个模型,误差相关——你平均出一个自信的错误答案。不同模型或不同种子可以去相关,而不同*经过辩论的观点*去相关得更彻底。

### 异质辩论

A-HMAD 及相关后续工作,给不同智能体用*不同的基座模型*。Llama + Claude + GPT 辩论能减少单一文化崩塌(第 26 课),因为一个模型家族的相关误差,其他家族并不共享。

缺点:辩论中混入一个弱模型,可能把共识拖向它的错误答案(见 "Should we be going MAD?",arXiv:2311.17371)。

### NLSOM —— 129 智能体扩展

Zhuge 等人("Mindstorms in Natural Language-Based Societies of Mind",arXiv:2305.17066)把这个想法扩到 129 个成员的社会。结果是:专门化与自组织随规模涌现,系统在视觉问答这类任务上胜过单智能体。

### 失败模式

- **谄媚级联(Sycophancy cascade)。** 所有智能体都倒向听起来最自信的那个。辩论塌缩成最大嗓门。用对抗角色提示("必须有一个智能体持反方")有帮助。
- **主题漂移。** 多轮辩论会漂离原问题。缓解:每轮重新注入问题。
- **算力爆炸。** N 个智能体 × R 轮 = N·R 次 LLM 调用,每次上下文还在涨。5 智能体、5 轮的辩论是 25 次调用,上下文递增。每题成本可能超过单次 CoT 调用的 10 倍。

## 动手构建

`code/main.py` 在一道数学题上跑 3 智能体 × 3 轮辩论,每个智能体以不同的(可能错误的)答案开局。智能体是脚本化的——每个的"更新"方式是按脚本置信度加权平均邻居的答案。收敛过程在逐轮日志里可见。

演示展示两个关键效果:

- 仅仅一轮交换,就让智能体更靠近正确答案。
- 第 2 轮之后再加轮,收益递减(与 Du 等人的平台期吻合)。

运行:

```
python3 code/main.py
```

## 投入使用

`outputs/skill-debate-configurator.md` 为新任务配置一场辩论:智能体数、轮数、异质性(同模型 vs 混合)、角色分配(对称 vs 一个对抗)。它还会在你开跑前估算 token 成本。

## 交付

要交付辩论系统:

- **轮数上限 3。** Du 等人证明 3 轮拿到大部分收益。更多是成本,不是质量。
- **智能体上限 5。** 超过 5 个,上下文膨胀和成本主导一切。
- **默认异质。** 池中至少两个不同的基座模型。
- **对抗席位。** 一个智能体被提示无论如何都要唱反调。打破谄媚。
- **每轮都记日志。** 隐藏中间轮次的辩论系统无法调试、无法审计。

## 练习

1. 运行 `code/main.py`,然后把轮数设为 5,观察收益递减。到哪一轮时,继续收敛就停了?
2. 加第四个对抗角色的智能体:永远与当前多数唱反调。这会破坏还是改善收敛?
3. 画出(打印)每轮的同意度分数(多数答案上的智能体比例)。它何时达到 1.0?那等价于"正确"吗?
4. 读 Du 等人第 4 节的消融。用这份代码复现"只加智能体" vs "只加轮数" vs "两个都加"的结果。
5. 读 "Should we be going MAD?"(arXiv:2311.17371),列出轮流发言之外的两种辩论变体——如裁判主导、链式辩论、对抗式。

## 关键术语

| 术语 | 大家口头的说法 | 实际含义 |
|------|----------------|------------------------|
| 心智社会(Society of Mind) | "Minsky 的想法" | 智能是互动的专家群体;1986 年的框架,如今经 LLM 辩论落地。 |
| 多智能体辩论 | "智能体吵架" | N 个智能体提议、互评、经 R 轮修正,多数投票。 |
| 共识 | "它们同意了" | 不是认识论上的真——只是多数答案上的比例。可以自信地错。 |
| 轮次 | "交换步数" | 一轮 = 每个智能体读其他人并更新一次。 |
| 异质辩论 | "混模型家族" | 用不同基座模型给误差去相关。 |
| 谄媚级联 | "都听嗓门大的" | 一种辩论失败:智能体不顾对错,倒向最自信的那个。 |
| NLSOM | "129 智能体社会" | 自然语言心智社会;Zhuge 等人的规模化版本。 |
| 相关误差 | "同一个模型,同一个 bug" | 自一致性饱和的原因;跨不同观点的辩论去相关。 |
