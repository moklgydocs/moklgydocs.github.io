# 智能体经济、Token 激励与声誉

> 长时程自主智能体(METR 的 1 小时到 8 小时工作曲线)需要经济能动性。正在成形的**五层栈**是:**DePIN**(物理算力)→ **身份**(W3C DID + 声誉资本)→ **认知**(RAG + MCP)→ **结算**(账户抽象)→ **治理**(Agentic DAO)。生产级的智能体激励网络包括 **Bittensor**(TAO 子网奖励任务专用模型)、**Fetch.ai / ASI Alliance**(ASI-1 Mini LLM + FET token)和 **Gonka**(基于 Transformer 的 PoW,把算力重新分配给有产出的 AI 任务)。学术工作方面:AAMAS 2025 的去中心化 LaMAS 用 **Shapley 值信用归因**公平奖励有贡献的智能体;Google Research 的"Mechanism design for large language models"提出在单调聚合下的**二价 token 拍卖**。本课构建一个最小的智能体市场,把 Shapley 值信用归因应用到一条多智能体流水线上,再跑一场二价 token 拍卖,让博弈论机器具体落地。

## 问题

当智能体共同创造价值却需要各自获得奖励时,多智能体系统就变得复杂。经典机制——平均分配、最后贡献者通吃——要么不公平,要么容易被钻空子。基于联盟的 Shapley 值奖励在构造上就是公平的,但计算代价高。2025-2026 年的文献给出了实用的近似:Shapley 采样、单调聚合拍卖,以及从已确认贡献中累积的链上声誉。

信用归因之外,这个领域已经转向真正的经济智能体:Bittensor TAO 奖励用于微调子网专用模型的挖矿算力;Fetch.ai/ASI 用 FET token 奖励 ASI-1 Mini LLM 的使用;Gonka 把 Transformer 工作量证明重新导向有产出的 AI 任务。能自主交易的智能体今天已经存在;问题是如何对齐激励。

本课把智能体经济当作一个具体的问题族——信用归因、机制设计、声誉——并用最少的数学把每一个都搭出来,让想法真正扎根。

## 概念

### 智能体经济的五层栈

1. **DePIN(物理算力)。** 出租 GPU、存储、带宽的去中心化基础设施。Bittensor 子网、Render Network、Akash。不是智能体专用,但智能体在用。
2. **身份。** W3C 去中心化标识符(DID)给每个智能体一个独立于任何平台的持久 ID。声誉累积到 DID 上。Agent Network Protocol(ANP)把 DID 用作发现层。
3. **认知。** 智能体的推理循环:LLM + RAG + MCP。这是其他阶段构建的东西。
4. **结算。** 账户抽象(ERC-4337)让智能体从自己的余额付 gas,无需持有 ETH。智能体可以为服务、为彼此、为算力付费。
5. **治理。** Agentic DAO:人类*和*智能体共同对协议变更投票的治理结构,投票权与声誉挂钩。

不是每个生产系统都用全五层。Bittensor 用了 1、2,部分 3,部分 4,不用 5。OpenAI 的智能体除了 3 什么都不用。这个栈是一张参考地图,不是必选清单。

### Bittensor、Fetch.ai、Gonka —— 跑在生产上的

**Bittensor(TAO)。** 子网是专项任务(语言建模、图像生成、预测)。矿工提交模型输出;验证者排名;按权益加权的评分分配 TAO 奖励。每个子网有自己的评估。经济学要点:为任务专用的输出质量付费,而不是为消耗的算力付费。

**Fetch.ai / ASI Alliance。** ASI-1 Mini LLM 跑在 Fetch.ai 网络上;用户为推理付 FET token。这里"智能体即对等方"的叙事更强:Fetch 上的一个智能体可以调用另一个智能体做任务,并用 FET 支付。

**Gonka。** Transformer 工作量证明:这里的"工作量"是 Transformer 的前向传播。矿工通过运行有已知正确输出(来自训练数据)的推理任务来赚钱。有资源产出的 PoW,而不是哈希 PoW。

截至 2026 年 4 月,三者都是生产级。收益分配各不相同:Bittensor 奖励相对子网验证者的质量;Fetch 按付费用户衡量的效用给奖励;Gonka 奖励可验证的推理工作量。

### Shapley 值信用归因

三个智能体协作完成一个任务,输出得分 0.8。谁贡献了哪部分?

Shapley 值:满足四条公理(有效性、对称性、线性、零贡献者)的唯一信用分配。对智能体 `i`:

```
shapley(i) = (1/N!) * sum over all orderings O of (v(S_i_O ∪ {i}) - v(S_i_O))
```

其中 `S_i_O` 是排列 `O` 中排在 `i` 之前的智能体集合。实践中:枚举所有排列,记录每个智能体在每种排列下的边际贡献,取平均。

N=3 时有 6 种排列;N=10 时有 360 万种——所以实践中是采样排列而不是枚举。

### 用于聚合的二价拍卖

Google Research("Mechanism design for large language models")提出用二价 token 拍卖来聚合 LLM 输出。设定:N 个智能体各自提出一个补全;每个智能体对"被选中"有一个私人估值。拍卖方选出价值最高的提案,支付*第二高*的价值。在单调聚合下(价值取决于选中了哪个提案,而不是有多少人出价),这是说真话机制——智能体会报出自己的真实估值。

这对 LLM 系统为什么重要:你可以把补全任务外包给定价不同的多个智能体;拍卖选出最好的并公平付款,而智能体没有动机虚报。

### 声誉资本

绑定在 DID 上的声誉分数从已确认的贡献中累积。一条简单的更新规则:

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

衰减因子 `alpha` 接近 1。声誉:

- 读取便宜,可用于路由决策("把难任务发给高声誉智能体")。
- 伪造昂贵(随时间累积,绑定在 DID 上)。
- 可以被罚没:验证不通过的贡献会扣分。

### AAMAS 2025 的去中心化 LaMAS

LaMAS 提案(AAMAS 2025)组合了:DID 身份、Shapley 值信用归因和一套简单的拍卖机制。关键主张:把信用归因这一步去中心化,可以让系统可审计,并免疫单点操纵。

### 经济学在哪里会崩

- **价格预言机操纵。** 如果信用函数能被钻空子,智能体就会去钻。每个机制都需要对抗性测试。
- **女巫攻击。** 一个运营者起 N 个假智能体来刷高自己的贡献。DID 能减缓但不能阻止;缓解手段是声誉的伪造代价。
- **验证成本。** 信用归因的公平程度取决于验证者。验证便宜(小 LLM)就能被钻空子;验证昂贵(人工评审团)系统就无法扩展。
- **监管悬顶。** 智能体经济与金融监管相交。截至 2026 年,Bittensor、Fetch、Gonka 在某些法域都处于法律灰色地带。

### 智能体经济什么时候说得通

- **运营者异构的开放网络。** 没有单一团队控制所有智能体。
- **可验证的输出。** 没有验证,信用归因就是猜。
- **长时程工作流。** 一次性任务享受不到声誉累积的好处。
- **Token 化支付在你的法域合法可行。**

在封闭的公司系统里,经济学让位于更简单的分配方式(经理派活,指标内部消化)。这套经济学文献主要适用于开放网络。

## 交付

2026 年运营一个智能体经济:

- **先做声誉,别急着发币。** 声誉实现便宜,单独就很有价值;token 会增加法律和经济复杂度。
- **先验证,再发奖。** 绝不在没有独立验证步骤的情况下分配信用。自报质量会滋生女巫游戏。
- **Shapley 采样,而非 Shapley 精确。** 采样 100-1000 种排列;精确枚举不可扩展。
- **给衰减因子设上限、给声誉设下限。** 无界衰减会误伤合法贡献者;衰减太慢又会奖励吃老本的高声誉智能体。
- **对机制做对抗性审计。** 开放网络之前先跑红队场景。每个机制都有自己的博弈论;漏洞应该由你来发现,而不是攻击者。

## 关键术语

| 术语 | 大家嘴里的说法 | 实际含义 |
|------|----------------|----------|
| DePIN | "去中心化物理基础设施" | 用 token 激励的算力/存储/带宽。Bittensor、Akash、Render。 |
| DID | "去中心化标识符" | W3C 的可移植 ID 规范。智能体声誉绑定在 DID 上,而不是平台上。 |
| ERC-4337 | "账户抽象" | 可以代付 gas 的合约账户,使智能体支付成为可能。 |
| Shapley 值 | "公平的信用归因" | 满足有效性、对称性、线性、零贡献者公理的唯一分配。 |
| 二价拍卖 | "Vickrey 拍卖" | 说真话机制:赢家付第二高出价。兼容单调聚合。 |
| 声誉资本 | "累积的质量分" | 从已确认贡献累积的 DID 绑定分数;随时间衰减。 |
| Agentic DAO | "智能体 + 人类共同治理" | 智能体作为一等投票者的 DAO,投票权与声誉挂钩。 |
| TAO / FET / GPU 积分 | "各种 token 面额" | Bittensor TAO、Fetch.ai FET、各种 DePIN token。 |
