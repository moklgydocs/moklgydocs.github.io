# 思维树与 LATS:审慎搜索

> 单条思维链轨迹没有回头的余地。ToT(Yao 等,2023)把推理变成一棵树,每个节点带自评估;LATS(Zhou 等,2024)把 ToT、ReAct、Reflexion 统一到蒙特卡洛树搜索之下。24 点游戏从 4%(CoT)到 74%(ToT);LATS 在 HumanEval 上拿到 92.7% 的 pass@1。

**类型:** 动手构建
**编程语言:** Python(标准库)
**前置要求:** 第 14 阶段 · 01(智能体循环)、第 14 阶段 · 03(Reflexion)
**预计耗时:** 约 75 分钟

## 学习目标

- 把推理框架化为搜索:节点是"思维",边是"扩展",价值是"有多有前途"。
- 用纯标准库实现带自评估打分的 ToT 式 BFS 树搜索。
- 扩展成玩具 LATS MCTS 循环:select / expand / simulate / backpropagate。
- 判断何时值得为搜索付 token 倍率(24 点、代码生成),何时单条轨迹就够(简单问答)。

## 问题

思维链是一条直线走到底。第一步错了,后面每一步都建立在坏前提上。在 24 点游戏(用四个数字和 + − × ÷ 凑出 24)上,GPT-4 的 CoT 只有 4% 准确率——模型早期选错子表达式,就无法挽回。

推理需要的,是提出多个候选、评估它们、挑有前途的、遇到死胡同时回溯的能力。这就是搜索。思维树和 LATS 是两个经典形式化。

## 概念

### 思维树(Yao 等,NeurIPS 2023)

每个节点是一个连贯的中间步骤("一个思维")。每个节点可以扩展出 K 个子思维。LLM 用打分提示词自评估每个节点。搜索遍历这棵树——BFS、DFS 或 beam。

```
                     (root: "find 24 from 4 6 4 1")
                    /               |            \
           ("6 - 4 = 2")    ("4 + 1 = 5")    ("4 * 6 = 24")  <- Score: HIGH
              /   \              |                  |
          ...    ...          ...                finish
```

自评估是承重件。论文给出三种变体:`sure / likely / impossible` 分类、`1..10` 数值打分、候选间投票。三者都在 24 点上大幅超过 CoT(GPT-4 从 4% 到 74%)。

### LATS(Zhou 等,ICML 2024)

LATS 把 ToT、ReAct、Reflexion 统一到 MCTS 下。LLM 扮演三个角色:

- **策略:** 提出候选下一动作(ReAct 式)。
- **价值函数:** 给部分轨迹打分(ToT 式自评)。
- **自我反思器:** 失败时写一段自然语言反思(Reflexion 式),用它重新播种未来的展开。

环境反馈(观测)混入价值函数,所以搜索依据的是真实工具结果,不只是模型观点。论文时的成绩:GPT-4 在 HumanEval 上 pass@1 达 92.7%(SOTA);GPT-3.5 在 WebShop 上平均 75.9(逼近梯度微调)。

### 最小化的 MCTS

每轮迭代四个阶段:

1. **Select** —— 用 UCT(树的上置信界)从根走到叶子。
2. **Expand** —— 用策略生成 K 个子节点。
3. **Simulate** —— 从子节点用策略展开,用价值函数(或环境奖励)给叶子打分。
4. **Backpropagate** —— 沿路径向上更新访问次数和价值估计。

UCT 公式:`Q(s, a) + c * sqrt(ln N(s) / N(s, a))`。第一项是利用,第二项是探索。`c` 按任务调。

### 成本的现实

搜索让 token 爆炸。ToT 在 24 点上用的 token 是 CoT 的 100–1000 倍,LATS 类似。这不是免费的;搜索留给这些场景:

- 单条轨迹明显不够用的任务(24 点、复杂代码)。
- 正确性比墙钟时间更要紧的任务。
- 有便宜可靠价值函数的任务(代码有单元测试,数学有明确目标)。

如果你的任务只有一个正确答案而评估器有噪声,搜索常常帮倒忙——它会找到一个"得分很高"的错误答案。

### 2026 年的位置

大多数生产智能体不跑 LATS,跑的是 ReAct + 工具落地验证(CRITIC,第 05 课)。搜索出现在专门的生态位:

- 把测试当价值函数的编程智能体(HumanEval 式)。
- 探索多条查询路径的深度研究智能体。
- LangGraph 子图里的重规划工作流。

AlphaEvolve(第 11 课)是 2025 年的极端:对代码做进化搜索,适应度机器可验证,前沿级成果(56 年来首次改进 4x4 矩阵乘法)。

## 动手构建

`code/main.py` 实现:

- 在一个风格化"选算术运算"任务上的迷你 ToT BFS。
- 同一任务上的玩具 LATS MCTS 循环(Select / Expand / Simulate / Backpropagate),用 UCT 选择。
- 一个组合符号分数与自评分数的价值函数。

运行:

```
python3 code/main.py
```

轨迹展示 ToT 以 BFS 每节点扩展三个候选,对比 LATS 通过 MCTS 收敛到最优展开。两者的 token 数都会打印。

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|------|----------------|------------------------|
| 思维树 | "分支 CoT" | Yao 等 —— 思维节点组成的树,带自评估 |
| LATS | "LLM 的 MCTS" | Zhou 等 —— 在 MCTS 下统一 ToT + ReAct + Reflexion |
| UCT | "上置信界" | 平衡利用(Q)与探索(ln N / n)的选择公式 |
| 价值函数 | "这个状态有多好" | 提示出的 LLM 分数或环境奖励;喂给回传 |
| 策略 | "动作提议器" | ReAct 式生成器;产出候选下一思维/动作 |
| 展开(rollout) | "模拟轨迹" | 用策略从节点走到叶子,用价值打分 |
| 回传 | "更新祖先" | 把叶子奖励沿路径上推,更新访问次数和 Q |
| 搜索成本 | "token 爆炸" | 24 点上是 CoT 的 100–1000 倍;采用前先算预算 |
