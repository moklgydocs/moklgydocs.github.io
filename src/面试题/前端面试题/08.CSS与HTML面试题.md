# CSS 与 HTML 面试题

> 别小看 CSS 面试题，很多人在这里翻车。

## Q1: CSS 盒模型是什么？`box-sizing` 有什么用？

**难度**：⭐ | **频率**：🔥🔥🔥🔥🔥

💡 **回答**：

盒模型 = content + padding + border + margin

- **标准盒模型**（`content-box`）：width = content
- **IE 盒模型**（`border-box`）：width = content + padding + border

```css
/* 推荐全局设置 */
*, *::before, *::after {
  box-sizing: border-box;
}
```

## Q2: Flex 布局常用属性？如何实现垂直水平居中？

**难度**：⭐⭐ | **频率**：🔥🔥🔥🔥🔥

💡 **回答**：

```css
/* 垂直水平居中 */
.container {
  display: flex;
  justify-content: center; /* 主轴居中 */
  align-items: center;     /* 交叉轴居中 */
}

/* 其他常用 */
flex-direction: row | column;
flex-wrap: wrap;
gap: 16px;
flex: 1;  /* flex-grow: 1, flex-shrink: 1, flex-basis: 0% */
```

其他居中方式：
```css
/* Grid */
display: grid; place-items: center;

/* 绝对定位 */
position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%);
```

## Q3: position 的几个值分别是什么？

**难度**：⭐ | **频率**：🔥🔥🔥🔥

💡 **回答**：

| 值 | 含义 | 脱离文档流 | 参照物 |
|----|------|-----------|--------|
| `static` | 默认 | ❌ | - |
| `relative` | 相对自身偏移 | ❌ | 自身原位置 |
| `absolute` | 绝对定位 | ✅ | 最近非 static 祖先 |
| `fixed` | 固定定位 | ✅ | 视口 |
| `sticky` | 粘性定位 | 滚动后脱离 | 滚动容器 |

## Q4: BFC 是什么？如何触发？

**难度**：⭐⭐⭐ | **频率**：🔥🔥🔥

💡 **回答**：

BFC（Block Formatting Context，块级格式化上下文）是一个独立的渲染区域，内部布局不影响外部。

触发条件：
- `overflow: hidden / auto / scroll`
- `display: flex / grid / inline-block / flow-root`
- `position: absolute / fixed`
- `float: left / right`

作用：
1. 清除浮动
2. 防止 margin 合并
3. 阻止元素被浮动元素覆盖

## Q5: CSS 选择器优先级怎么计算？

**难度**：⭐⭐ | **频率**：🔥🔥🔥

💡 **回答**：

```
!important > 内联 > #id > .class / [属性] / :伪类 > 标签 > * > 继承
```

权重计算（a, b, c, d）：
- 内联样式：1,0,0,0
- #id：0,1,0,0
- .class、[attr]、:hover：0,0,1,0
- 标签、::before：0,0,0,1

## Q6: CSS 实现响应式布局的方式？

**难度**：⭐⭐ | **频率**：🔥🔥🔥

💡 **回答**：

1. **媒体查询**：`@media (max-width: 768px) { ... }`
2. **Flex/Grid 弹性布局**：自适应排列
3. **相对单位**：`rem`、`em`、`vw`、`vh`、`%`
4. **Container Queries**：基于容器大小（新特性）
5. **clamp()**：`font-size: clamp(14px, 2vw, 18px);`

## Q7: HTML5 语义化标签有哪些？为什么要语义化？

**难度**：⭐ | **频率**：🔥🔥🔥

💡 **回答**：

标签：`header`、`nav`、`main`、`section`、`article`、`aside`、`footer`、`figure`

好处：
1. **无障碍**：屏幕阅读器能理解结构
2. **SEO**：搜索引擎更好地理解页面
3. **可维护**：代码意图更清晰

## Q8: `display: none`、`visibility: hidden`、`opacity: 0` 的区别？

**难度**：⭐⭐ | **频率**：🔥🔥🔥

💡 **回答**：

| 属性 | 占据空间 | 触发事件 | 触发回流 | 子元素可见 |
|------|---------|---------|---------|-----------|
| `display: none` | ❌ | ❌ | ✅ | ❌ |
| `visibility: hidden` | ✅ | ❌ | ❌ | 子元素可设 visible |
| `opacity: 0` | ✅ | ✅ | ❌ | ❌ |

## Q9: CSS 预处理器（Sass/Less）vs CSS Modules vs CSS-in-JS vs Tailwind，怎么选？

**难度**：⭐⭐ | **频率**：🔥🔥🔥

💡 **回答**：

| 方案 | 优点 | 缺点 | 适合 |
|------|------|------|------|
| Sass/Less | 功能强大 | 全局污染 | 传统项目 |
| CSS Modules | 局部作用域 | 动态样式麻烦 | React 项目 |
| CSS-in-JS (styled-components) | 动态样式强 | 运行时开销 | 组件库 |
| Tailwind CSS | 快速开发 | 类名多 | 快速迭代 |
