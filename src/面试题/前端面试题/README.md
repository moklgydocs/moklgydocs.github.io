## 🎯 面试准备建议

1. **先过一遍基础题**：确保这些题你能流利回答
2. **重点准备原理题**：这是拉开差距的关键
3. **准备 2-3 个项目故事**：每个故事要有「挑战 → 方案 → 结果」
4. **模拟面试**：找人对练，适应被追问的节奏
5. **保持诚实**：不会就说不会，乱答比不答更扣分
