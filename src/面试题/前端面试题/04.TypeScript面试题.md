# TypeScript 面试题

> TypeScript 已经是前端标配，从初级到高级都会考。

## Q1: TypeScript 和 JavaScript 的区别？为什么要用 TS？

**难度**：⭐ | **频率**：🔥🔥🔥🔥🔥

💡 **回答要点**：

TypeScript 是 JavaScript 的**超集**，添加了**静态类型系统**。

核心价值：
1. **编译时检查错误**：传错参数、拼写错误都能在写代码时发现
2. **IDE 智能提示**：自动补全、跳转定义、重构支持
3. **代码即文档**：类型定义就是最好的接口文档
4. **重构安全**：改了接口定义，所有用到的地方都会报错

> ⚠️ **常见误区**：TS 不会让代码运行更快——它在编译后变成普通 JS。TS 的价值在开发阶段。

## Q2: interface 和 type 有什么区别？

**难度**：⭐⭐ | **频率**：🔥🔥🔥🔥🔥

💡 **回答要点**：

| 能力 | interface | type |
|------|-----------|------|
| 对象类型 | ✅ | ✅ |
| 联合类型 | ❌ | ✅ `type A = B \| C` |
| 交叉类型 | ❌ | ✅ `type A = B & C` |
| 继承扩展 | ✅ `extends` | ✅ `&` |
| 声明合并 | ✅ 同名自动合并 | ❌ 报错 |
| 基础类型别名 | ❌ | ✅ `type ID = string` |

**实际建议**：
- 定义对象形状 → `interface`（可扩展）
- 联合类型、工具类型 → `type`
- 团队统一即可

```tsx
// interface：适合对象、可扩展
interface User {
  name: string;
  age: number;
}
interface Admin extends User {
  role: 'admin';
}

// type：适合组合
type Status = 'loading' | 'success' | 'error';
type Response<T> = { data: T; status: Status };
```

## Q3: 什么是泛型？在 React 中怎么使用泛型？

**难度**：⭐⭐⭐ | **频率**：🔥🔥🔥🔥🔥

💡 **回答要点**：

泛型是**类型的参数**，让代码在不同类型下都能工作。

```tsx
// 泛型函数
function getFirst<T>(arr: T[]): T | undefined {
  return arr[0];
}
getFirst<number>([1, 2, 3]); // 返回 number
getFirst<string>(['a', 'b']); // 返回 string

// React 中：useState 泛型
const [user, setUser] = useState<User | null>(null);

// React 中：泛型组件
interface ListProps<T> {
  items: T[];
  renderItem: (item: T) => React.ReactNode;
}

function List<T>({ items, renderItem }: ListProps<T>) {
  return <ul>{items.map(renderItem)}</ul>;
}

// 使用
<List<User> items={users} renderItem={u => <li>{u.name}</li>} />
```

## Q4: 说说 TS 的工具类型（Utility Types）

**难度**：⭐⭐⭐ | **频率**：🔥🔥🔥🔥

💡 **回答要点**：

```tsx
interface User {
  id: number;
  name: string;
  email: string;
  age: number;
}

// Partial：所有属性可选
type UpdateUser = Partial<User>; // { id?: number; name?: string; ... }

// Required：所有属性必填
type FullUser = Required<User>;

// Pick：选取部分属性
type UserPreview = Pick<User, 'id' | 'name'>; // { id: number; name: string }

// Omit：排除部分属性
type UserWithoutEmail = Omit<User, 'email'>; // { id, name, age }

// Record：键值对映射
type RolePermissions = Record<'admin' | 'user', string[]>;

// ReturnType：获取函数返回类型
type Result = ReturnType<typeof fetchUser>; // Promise<User>

// Parameters：获取函数参数类型
type Params = Parameters<typeof fetchUser>; // [id: number]
```

🔗 **追问**：能手写一个 Partial 的实现吗？

```tsx
type MyPartial<T> = {
  [K in keyof T]?: T[K];
};
```

## Q5: any、unknown、never 的区别？

**难度**：⭐⭐ | **频率**：🔥🔥🔥🔥

💡 **回答要点**：

| 类型 | 含义 | 安全性 | 使用场景 |
|------|------|--------|---------|
| `any` | 任意类型，关闭类型检查 | ❌ 不安全 | 过渡期、第三方库 |
| `unknown` | 未知类型，使用前必须收窄 | ✅ 安全 | 替代 any |
| `never` | 不可能的类型 | - | 穷尽检查、不返回的函数 |

```tsx
// unknown：必须类型收窄才能使用
function process(input: unknown) {
  if (typeof input === 'string') {
    console.log(input.toUpperCase()); // ✅ 收窄为 string
  }
}

// never：穷尽性检查
type Shape = 'circle' | 'square';
function getArea(shape: Shape) {
  switch (shape) {
    case 'circle': return Math.PI;
    case 'square': return 1;
    default:
      const _exhaustive: never = shape; // 如果漏了某个 case，这里会报错
      return _exhaustive;
  }
}
```

## Q6: TypeScript 中如何给 React 组件写类型？

**难度**：⭐⭐ | **频率**：🔥🔥🔥🔥🔥

💡 **回答要点**：

```tsx
// Props 类型
interface ButtonProps {
  children: React.ReactNode;
  variant?: 'primary' | 'secondary';
  disabled?: boolean;
  onClick?: (e: React.MouseEvent<HTMLButtonElement>) => void;
}

// 函数组件（推荐直接声明 props 类型）
function Button({ children, variant = 'primary', onClick }: ButtonProps) {
  return <button className={variant} onClick={onClick}>{children}</button>;
}

// 不推荐 React.FC（有隐式 children 等问题）
// const Button: React.FC<ButtonProps> = (props) => { ... }

// 事件类型
const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {};
const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {};

// Ref 类型
const inputRef = useRef<HTMLInputElement>(null);

// 获取原生元素的所有 Props
type NativeButtonProps = React.ComponentProps<'button'>;
```

## Q7: 如何在 TS 中处理 API 响应类型？

**难度**：⭐⭐⭐ | **频率**：🔥🔥🔥

💡 **回答要点**：

```tsx
// 定义 API 响应的通用结构
interface ApiResponse<T> {
  code: number;
  message: string;
  data: T;
}

// 定义具体的数据类型
interface User {
  id: number;
  name: string;
  email: string;
}

// 封装请求函数
async function request<T>(url: string): Promise<ApiResponse<T>> {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}

// 使用：自动推断 data 类型
const { data: user } = await request<User>('/api/user/1');
console.log(user.name); // ✅ 有类型提示

// 列表
const { data: users } = await request<User[]>('/api/users');
users.forEach(u => console.log(u.email)); // ✅
```

## Q8: 什么是类型收窄（Type Narrowing）？

**难度**：⭐⭐⭐ | **频率**：🔥🔥🔥

💡 **回答要点**：

类型收窄是通过条件判断让 TS 在特定代码块中推断出更精确的类型。

```tsx
// typeof 收窄
function padLeft(value: string | number) {
  if (typeof value === 'number') {
    return value.toFixed(2);  // number
  }
  return value.trim();        // string
}

// 可辨识联合（Discriminated Union）
type Shape =
  | { kind: 'circle'; radius: number }
  | { kind: 'square'; side: number };

function area(shape: Shape) {
  switch (shape.kind) {
    case 'circle': return Math.PI * shape.radius ** 2;
    case 'square': return shape.side ** 2;
  }
}

// in 收窄
function isAdmin(user: User | Admin) {
  if ('role' in user) {
    return user.role === 'admin'; // Admin 类型
  }
  return false;
}
```
