# 大语言模型时代（2020–2023）

## 2020 — GPT-3：涌现的开始

**人物**：Tom Brown 等，OpenAI（共 31 位作者）

**规格**：
- 参数量：**1750 亿**（比 GPT-2 大 100 倍）
- 训练数据：约 45TB 文本，过滤后约 570GB
- 训练算力：约 3640 PFlop/s·days（约 1000 万美元计算费用）

**发布前的预期**：业界大多数人认为 GPT-3 只是 GPT-2 的量变。

**GPT-3 实际展示的能力，让所有人震惊**。

### 涌现能力（Emergent Abilities）

GPT-3 展示了一些之前从未在语言模型中见过的能力，这些能力并非显式训练，而是随规模"涌现"出来的：

**Few-Shot Learning（少样本学习）**：

```
提示：
英语："I love you." → 法语："Je t'aime."
英语："Good morning." → 法语："Bonjour."
英语："Where is the library?" → 法语：
```

GPT-3 能从 2 个例子中学会翻译，达到可用水平。这在 GPT-2 中是做不到的。

**Chain-of-Thought（链式推理，隐式）**：

```
问：Roger 有 5 个网球，他又买了 2 罐，每罐 3 个，他现在有多少个？
GPT-3 答：11 个（5 + 2×3 = 11）✓
```

**代码生成**：

```python
# 提示：写一个函数，输入列表返回平均值
def average(numbers):
    return sum(numbers) / len(numbers)  # GPT-3 生成
```

**论文摘要生成**、**SQL 查询**、**写诗**、**解数学题**……

### GPT-3 引发的哲学争论

**争论 1：这是真正的理解还是统计模仿？**

Gary Marcus（认知科学家）："GPT-3 只是做了更精确的自动补全，没有任何真正的理解。"

Gwern Branwen（独立研究者）："如果一个系统在任何我们关心的任务上表现得和有理解的实体一样，'理解'这个词还有意义吗？"

这个争论至今没有答案。

**争论 2：规模本身就是价值吗？**

OpenAI 的立场："规模定律告诉我们，更大 = 更好。继续扩大。"

批评者："我们不理解为什么它有效，这是不负责任的科学。"

## 2021 — 多模态与代码

### DALL-E（2021 年 1 月）

OpenAI 发布了能从文字描述生成图像的模型：

```
提示："an armchair in the shape of an avocado"
（一把形状像牛油果的扶手椅）
```

DALL-E 生成了 512 种图像变体，其中不少令人惊叹。

**技术**：基于 GPT-3 的变体，把图像 patch 当成"词"处理，学习文字-图像关联。

### GitHub Copilot（2021 年 6 月）

**技术基础**：OpenAI Codex（GPT-3 在代码上的继续预训练）

**训练数据**：GitHub 上超过 54 种编程语言的公开代码

**能力演示**：

```python
# 注释驱动的代码生成
# 写一个函数，使用快速排序对列表排序
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)
# ↑ Copilot 自动补全
```

**市场影响**：
- 2022 年正式发布，第一年用户超过 100 万
- 程序员生产力提升 55%（GitHub 研究）
- 引发"AI 会取代程序员吗"的全球讨论
- 2023 年年收入超过 1 亿美元

### CLIP（2021 年）

**OpenAI 发布 CLIP（Contrastive Language-Image Pre-Training）**

- 训练数据：4 亿对图文对（网页上爬取的图片+描述）
- 训练方式：让图像编码器和文本编码器输出向量相近（对比学习）

**效果**：

```
分类"猫的图片"：
传统方法 = 在猫的数据集上训练分类器
CLIP = 计算图片向量和 "一张猫的照片" 文本向量的相似度

CLIP 在 ImageNet 上 zero-shot 准确率 76.2%
（从未见过 ImageNet 的标签，仅靠语义相似度！）
```

**意义**：CLIP 成为 DALL-E 2、Stable Diffusion 的核心组件。文本和图像终于进入统一的语义空间。

## 2021–2022 — 指令微调：从"预测下一个词"到"听懂指令"

**问题**：GPT-3 很强，但很难用——它是语言模型，会续写文本，但不会按照人类意图回答问题。

```
提示："如何做番茄炒蛋？"
GPT-3（原始）："如何做番茄炒蛋？" （可能直接关联下一个搜索结果，而不是回答）

我们想要的：
"1. 先将鸡蛋打散... 2. 番茄切块... 3. 先炒鸡蛋..."
```

**解决方案：Instruction Tuning（指令微调）**

**FLAN（2021，Google）**：

在 62 个 NLP 数据集、超过 1600 种不同指令格式上微调 T5：

```
指令："将以下英文翻译成法文：Hello World"
答案："Bonjour le monde"

指令："以下文本的情绪是正面还是负面？'这部电影太糟糕了'"
答案："负面"
```

**结果**：指令微调后的 FLAN 在未见过的任务上 zero-shot 性能大幅提升。

**InstructGPT（2022 年 1 月，OpenAI）**：

进一步引入 **RLHF**（从人类反馈中强化学习）。

## 2022 — RLHF：让 AI 对齐人类意图

**论文**：《Training language models to follow instructions with human feedback》（Ouyang 等，2022）

### 三个阶段

**阶段 1：监督微调（SFT）**

```
人类标注者编写高质量的"提示 → 回答"对（约 13,000 条）
在 GPT-3 上微调（让模型学会指令格式）
```

**阶段 2：训练奖励模型（Reward Model）**

```
对同一个提示，让 SFT 模型生成多个回答（如 4 个）
人类标注者对这些回答排序（A > B > C > D）
用这些排序数据训练一个"奖励模型"：
  输入：(提示, 回答) 
  输出：奖励分数（越好越高）
```

**阶段 3：PPO 强化学习微调**

```
把奖励模型作为环境
用 PPO 算法优化 SFT 模型：
  - 生成回答 → 奖励模型打分 → 更新模型参数
  - 同时加入 KL 散度约束（防止偏离 SFT 模型太远）
  
目标：最大化奖励模型的期望得分
```

### 为什么 RLHF 如此重要

| 问题 | RLHF 的解决方式 |
|------|----------------|
| 模型生成有害内容 | 人类标注者给有害内容低分 |
| 模型乱编事实（幻觉） | 人类标注者偏好准确回答 |
| 模型回答不跟随指令 | 人类标注者偏好 helpful 回答 |
| 模型回答过于绕弯 | 人类标注者偏好简洁直接 |

RLHF 让模型学会了"什么是好的回答"——这是语言模型第一次真正意义上的**价值对齐**。

### RLHF 的局限（和后来的改进）

- **标注者偏见**：奖励模型学到的是标注者的偏好，不是"客观"的好
- **奖励黑客**：模型可能学会"看起来好"但实际上不够好的回答
- **成本高**：需要大量人工标注，难以规模化

后续改进：
- **RLAIf（AI 反馈替代人工反馈）**：Anthropic 的宪法 AI（Constitutional AI）
- **DPO（Direct Preference Optimization，2023）**：绕过奖励模型，直接优化偏好对比
- **GRPO（群体相对策略优化，2024）**：DeepSeek 使用，无需 critic 模型

## 2023 — Anthropic 与 Claude：宪法 AI

**背景**：Anthropic 由 Dario Amodei、Daniela Amodei（前 OpenAI 研究员）等创立，聚焦 AI 安全。

**Constitutional AI（宪法 AI）**：

不依赖大量人工标注，而是给模型一套"宪法"（价值准则），让模型自我批评：

```
步骤 1 (Supervised Learning)：
  让模型对有害提示生成回答
  让模型用"宪法"批评自己的回答
  让模型修改成更好的回答
  → 收集这些 (提示, 修改后回答) 对做 SFT

步骤 2 (RL from AI Feedback, RLAIF)：
  让模型对同一提示生成两个回答
  让模型（用宪法）判断哪个更好
  → 用这些 AI 判断（不是人工）训练奖励模型
  → PPO 微调
```

**宪法示例（部分）**：
- "选择无害、伦理和不歧视性的回答"
- "选择不提供危险信息的回答"
- "选择最尊重版权的回答"

**Claude 的特点**：
- 比 GPT-4 更长的上下文窗口（Claude 2 达 100K token，约 75,000 词）
- 更保守和谨慎（偶尔被批评过度拒绝）
- 在长文理解、文档分析任务上表现突出

## 2023 — 幻觉问题：最头疼的挑战

**幻觉（Hallucination）**：模型生成看似可信但实际上是编造的内容。

```
用户：苹果是哪年上市的？
GPT-4：苹果公司于1980年12月12日在纳斯达克上市...
（实际是1980年12月12日，在纳斯达克，这个是对的）

用户：你写的《Harry Potter》第 7 卷第 200 页的内容是什么？
某模型：第 200 页描述了赫敏在图书馆发现了一本古老的魔法书...
（这段内容是编造的，但语气和风格完全像真的）
```

**为什么会幻觉**：
- 语言模型的目标是"生成合理文本"，不是"说真话"
- 训练数据有噪声和错误
- 模型没有知识边界意识（不知道自己不知道）

**缓解方法**：
- RAG（检索增强生成）：先检索，再生成，减少凭空生成
- 强化学习对齐时惩罚幻觉
- CoT（思维链）：引导模型先推理再回答
- 但没有任何方法可以完全消除幻觉

## 这个时代遗留的问题

1. **幻觉**：无法完全消除，限制了 AI 在高风险决策中的使用
2. **上下文窗口**：长文理解的注意力稀释问题
3. **推理能力**：复杂多步推理仍弱于人类顶尖水平
4. **知识时效**：训练集截止日期后的事情一无所知
5. **成本**：GPT-4 API 的推理成本限制了大规模应用

这些问题，指向了下一个时代的重心：**推理模型、长上下文、Agent 系统**。
