# 机器学习兴起（1986–2010）

## 范式转变：从"写规则"到"学规律"

符号主义的核心假设是：人类专家知道规则，AI 只需要被告知规则。

机器学习的反叛：**与其告诉机器规则，不如给它数据，让它自己找规律。**

这个转变听起来简单，但它需要：
1. 足够多的数据
2. 足够强的计算力  
3. 聪明的数学工具

这三样东西在 1990 年代前后刚好开始同时具备。

---

## 1986 — 反向传播：沉睡 17 年的答案

**人物**：David Rumelhart、Geoffrey Hinton、Ronald Williams

**问题**：多层神经网络能解决 XOR 这类非线性问题，但怎么训练？误差怎么从输出层"传回"来调整前面几层的权重？

**反向传播（Backpropagation）**：

核心思路是链式求导（微积分里的链式法则）：

```
损失函数 L 相对于某个权重 w 的梯度
= ∂L/∂w
= 用链式法则逐层分解
= 上一层梯度 × 本层激活函数导数 × 本层输入
```

**直觉理解**：
- 向前传播：输入 → 层层计算 → 输出预测
- 计算误差：预测 vs 真实答案，差多少？
- 向后传播：误差从输出层开始，逐层"追责"，每个权重分摊多少责任？
- 更新权重：每个权重按责任大小调整

**为什么它重要**：
- 这不是新数学，链式法则是 18 世纪莱布尼茨时代就有的
- 但没人把它和多层神经网络训练联系起来
- Rumelhart 等人的贡献是证明：**反向传播能在实际网络上高效工作**

**发表情况**：1986 年发表在 Nature 上的论文《Learning representations by back-propagating errors》，引用超过 20,000 次。

**历史注脚**：反向传播算法其实早在 1970 年就由 Seppo Linnainmaa 在硕士论文里发明了（名为"自动微分"），1974 年 Paul Werbos 也独立发现。但都没引起注意，直到 Rumelhart/Hinton 的版本公开才引发轰动。

## 1989–1998 — LeCun 与卷积网络的萌芽

**人物**：Yann LeCun（今 Meta AI 负责人）

**背景**：LeCun 刚从法国来到 Bell Labs（贝尔实验室），他盯上了手写数字识别这个问题——美国每天有数亿张支票要手工处理。

### 卷积神经网络（CNN）的核心思想

普通神经网络处理图片的问题：一张 28×28 的图片有 784 个像素，如果全连接，参数量爆炸。而且位移一下，"1"变成了完全不同的输入模式。

**LeCun 的洞见**：图片有局部相关性，用一个小滤波器（kernel）在图片上滑动检测特征，而不是每个像素连接每个神经元。

```
卷积层：用滤波器检测边缘、角点等局部特征
池化层：对特征降采样，增加平移不变性
全连接层：综合所有特征做最终分类
```

**LeNet-5（1998）**：
- 架构：卷积→池化→卷积→池化→全连接→输出
- 应用：识别手写数字，错误率 0.7%
- 实际部署：AT&T/NCR 银行系统，每天处理数以百万计的支票

**为什么还没爆发**：LeNet-5 很厉害，但 1998 年的计算能力限制了它。训练一个稍大的网络要几周。SVM 等方法在多数任务上更快更强。LeCun 研究的种子在埋着，等待 2012 年的爆发。

## 1990 年代 — 统计学习的黄金时代

当神经网络因为计算力不足而受限时，统计学习方法蓬勃发展。

### 贝叶斯方法的回归

**贝叶斯定理** 提供了一个优雅的框架：

$$P(假设|数据) = \frac{P(数据|假设) \cdot P(假设)}{P(数据)}$$

**应用**：
- **朴素贝叶斯分类器**（1960s 发明，1990s 大规模使用）：垃圾邮件过滤的基础。Google Gmail 早期垃圾邮件过滤就是贝叶斯方法。
- **贝叶斯网络**（Judea Pearl，1988）：因果推理的形式化框架，Pearl 因此获得 2011 年图灵奖。

### 决策树与集成方法

**决策树**：像 20 道 Yes/No 问题游戏一样，逐步缩小范围到分类结果。

```
               ○ 年收入 > 5万？
              /  \
           是/    \否
            ○      ○ 有房产？
  征信评分>700？   /  \
    /   \       是/    \否
   是   否    批贷款   拒绝
  批贷  拒绝
```

**随机森林（Random Forest，2001）**：Leo Breiman 发明。

关键洞见：一棵决策树容易过拟合，但如果训练 1000 棵树，每棵用不同的随机子集，然后投票——结果会稳定且准确得多。

这叫"集成学习"（Ensemble Learning）。

### SVM：最优分类超平面

**人物**：Vladimir Vapnik（苏联数学家），核心理论在苏联发展，1992 年在 Bell Labs 与 Cortes 合作完善。

**支持向量机（SVM）的核心思想**：

两类点可以被很多条线分开，哪条线最好？

**SVM 的答案**：找到使两类之间"间隔"最大的那条线（超平面）。

```
类1：●●●       间隔越大
      ↑支持向量  分类越稳健
‒‒‒‒‒‒‒‒‒‒‒‒ ← 最优超平面
      ↓支持向量
类2：○○○
```

**核技巧（Kernel Trick）**：对于非线性可分的数据，把它映射到高维空间（甚至无穷维），在高维里用线性分类。神奇的是，这个计算可以用"核函数"隐式完成，不需要真的做高维计算。

**SVM 为何重要**：
- 有严格的数学理论保证（VC 维、统计学习理论）
- 在高维稀疏数据上（文本分类）效果极好
- 2000 年代初是图像分类的最强方法，直到被 AlexNet 击败

## 1997 — Deep Blue 击败人类国际象棋冠军

**背景**：国际象棋长期被视为人类智识最高峰。1996 年 IBM 的 Deep Blue 挑战卡斯帕罗夫，以 2-4 告负。

**1997 年重赛**：IBM 重新设计了 Deep Blue，专家系统 + 遍历式搜索 + 残局数据库。

**每秒计算 2 亿步棋**。

**结果**：Deep Blue 3.5 - 2.5 击败卡斯帕罗夫，全球震惊。

**争议**：卡斯帕罗夫声称 IBM 在第二局结束后提供了人工干预的证据，要求复盘被拒绝。IBM 随即拆解了机器，拒绝了续赛请求。

**意义**：AI 在人类定义的智力游戏里赢了"神"级人类。但批评者说：这只是蛮力搜索，不是真正的智能。这个争论延续至今。

## 1998–2006 — 黄金时代的顶点与暗流

### 互联网带来了数据

1990 年代互联网的爆炸带来了前所未有的数据：
- 网页文本：数十亿词
- 用户行为：点击、购买、评分
- 图片：Flickr（2004）、YouTube（2005）

机器学习的饥渴终于有了食物。

### Google 的崛起（1998）

Larry Page 和 Sergey Brin 的 PageRank 算法本质上是一个概率马尔可夫链，用链接关系计算网页权威度。

**PageRank 核心**：如果很多重要的网页都链接到你，你就重要。重要性是递归定义的，用特征向量求解。

这是机器学习思想在实际产品中的大规模落地。

### 推荐系统的兴起

**Netflix Prize（2006）**：Netflix 悬赏 100 万美元，给能把推荐准确率提升 10% 的团队。

这个比赛极大地推动了协同过滤、矩阵分解等推荐算法的发展。2009 年获奖的 BellKor's Pragmatic Chaos 团队用了集成学习：100+ 个模型融合，提升了 10.06%。

### 语音识别：隐马尔可夫模型

1990–2010 年的语音识别靠的是**隐马尔可夫模型（HMM）**+ **高斯混合模型（GMM）**：

- 把语音当成状态序列（音素）的概率生成过程
- 维特比算法找最可能的状态路径
- Dragon Naturally Speaking（1997）实现了实用水平的连续语音识别

这是 Siri（2011）出现之前行业维持了近 20 年的主流方案。

## 2001–2010 — 机器学习工程化

这个时期，机器学习从研究走向了工程实践。

### 工具链成熟

- **Scikit-learn（2007）**：Python 机器学习库，让没有博士学位的工程师也能用 SVM/随机森林
- **R 语言统计生态**：统计学家的标准工具
- **Hadoop（2006）**：分布式处理海量数据，机器学习数据规模大幅提升

### 广告点击率预测

Google、百度、阿里的广告系统开始大规模使用机器学习：

- 逻辑回归 + 海量特征工程
- 每天训练，每小时更新
- 点击率提升 1% = 数亿美元利润

这是机器学习第一次被数十亿人间接使用。

## 2006 — Hinton 的深度信念网络：深度学习的黎明

**人物**：Geoffrey Hinton，时年 58 岁，坚持研究神经网络 20 年

**背景**：整个 AI 领域都在用 SVM。深度神经网络被认为训练太难（梯度消失问题）、效果不如 SVM。

**Hinton 的突破**：

论文《A fast learning algorithm for deep belief nets》（2006，Science）：

1. 用无监督预训练（RBM 逐层贪心训练）初始化深度网络的权重
2. 再用有监督的反向传播微调
3. 结果：深度网络在 MNIST 上打败了 SVM

**梯度消失问题**（为什么深层网络难训练）：
- 反向传播时，梯度通过每层都要乘以激活函数的导数
- Sigmoid 函数的导数最大只有 0.25
- 5 层 × 0.25^5 = 梯度缩小到 0.001，几乎为零
- 越深的层，梯度越小，几乎学不到东西

Hinton 的预训练方法绕开了这个问题。不过这个方案不是最终答案——2 年后，He 等人的残差连接（ResNet）才是真正的解法。

**意义**：这篇论文重新点燃了深度学习的希望，让 Hinton 在 2012 年的爆发有了充分的理论积累。

## 这个时代的遗产

| 技术 | 今天还在用 |
|------|---------|
| 反向传播 | 所有深度学习的训练核心 |
| CNN 基本结构 | ResNet、VGG、EfficientNet |
| 随机森林 | 结构化数据的首选基线 |
| Gradient Boosting | XGBoost、LightGBM（竞赛神器）|
| SVM | 小数据集、高维稀疏数据 |
| 推荐系统协同过滤 | Netflix、Spotify 基础层 |

机器学习时代把 AI 从"写规则"变成了"学规律"，奠定了工程化 AI 的基础。但它仍然依赖大量的**特征工程**——人类专家手工设计特征告诉模型该看什么。

打破这个限制，需要深度学习的到来。
