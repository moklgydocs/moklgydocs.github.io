# AI 演进史

从 1943 年数学家在纸上画出第一个"神经元"，到 2024 年 AI 模型能写代码、画画、推理物理问题——这 80 年是人类最壮阔的智识冒险之一。

这里不只是年表，而是试图回答：**每一次突破，背后的关键洞见是什么？为什么它在那个时代出现？它又如何塑造了今天我们用的工具？**

## 时间轴总览

```
1943 ─── 神经元数学模型  
1950 ─── 图灵测试  
1956 ─┬─ 达特茅斯会议：AI 正式命名  
      └─ 感知机  
1969 ─── 感知机局限性证明 → 第一次寒冬  
1986 ─── 反向传播复兴  
1997 ─── Deep Blue 击败卡斯帕罗夫  
2006 ─── 深度信念网络：深度学习前夜  
2012 ─── AlexNet：深度学习元年  
2014 ─── GAN 诞生  
2016 ─── AlphaGo 击败李世石  
2017 ─── Transformer："Attention is All You Need"  
2018 ─── BERT / GPT-1  
2020 ─── GPT-3（1750 亿参数）  
2022 ─── ChatGPT：AI 大众化元年  
2023 ─── GPT-4 / LLaMA 2 / Claude 2 / Gemini  
2024 ─┬─ o1 推理模型 / 多模态全面爆发（GPT-4o / Gemini 1.5）  
      └─ MCP 协议 / Sora 发布 / DeepSeek-V2  
2025 ─┬─ DeepSeek R1（557 万美元训练成本对标 o1，全球震动）  
      ├─ OpenAI Operator（官方 Agent，自主操作浏览器）  
      ├─ o3 / o4-mini（图像进入思维链，视觉推理质变）  
      ├─ Llama 4（Scout/Maverick/Behemoth，1000 万 token 上下文）  
      ├─ GPT-5（8 月发布，多模态 + 推理一体化）  
      ├─ Gemini 3 Pro（11 月，ARC-AGI-2 领先）  
      └─ Sora 2（9 月，"世界模拟器"）  
2026 ─┬─ Claude 4 / Opus 4.6（SWE-bench 80.9%，百万 token 上下文）  
      ├─ Gemini 2.5 Pro（Deep Think 模式）  
      └─ GPT-5.4（256K 上下文，经济价值测试 83%）  
```

## 两次寒冬，三次浪潮

AI 历史上曾两度陷入"寒冬"，资金断绝，研究者转行。理解寒冬的原因，才能理解后来每次复兴需要什么：

```
第一次寒冬（1974–1980）
  原因：感知机被证明有根本局限；计算力不足；承诺过度、落地不足
  打破：专家系统的商业成功让资金回流

第二次寒冬（1987–1993）  
  原因：专家系统维护成本暴增；Lisp 机被通用 PC 击败；日本第五代计算机计划失败
  打破：反向传播 + 统计学习 + 互联网数据爆发
```

每一次寒冬的结束，都不是靠修补旧范式，而是靠一个完全不同的突破点。
