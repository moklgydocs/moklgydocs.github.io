# Agent 与未来（2023–）

## 从"聊天"到"行动"

2022 年的 ChatGPT 是一个聊天机器人——它能说，但不能做。

2023 年开始，研究的重心转向了一个更宏大的问题：**如何让 AI 自主完成复杂任务，而不只是回答问题？**

这就是 Agent 时代的主题。而 2025–2026 年，这个问题有了令人震惊的进展。

---

## 2023 — 早期 Agent 的爆红与局限

### Auto-GPT（2023 年 3 月）

**作者**：Toran Bruce Richards，一名游戏开发者，在 GitHub 上发布

**核心思路**：让 GPT-4 循环调用自己，自主分解任务、使用工具、直到完成目标。

```python
# Auto-GPT 的伪代码逻辑
goal = "研究特斯拉最新财报并写一份摘要"

while not done:
    action = gpt4(f"当前目标：{goal}\n当前进度：{memory}\n下一步应该做什么？")
    
    if action == "搜索网页":
        result = search_web(query)
    elif action == "保存文件":
        result = save_file(content)
    elif action == "写代码":
        result = execute_code(code)
    elif action == "完成":
        done = True
    
    memory.update(result)
```

**GitHub 在发布一周内获得 5 万 Star**——创下当时开源项目最快增长记录。

**实际使用中的问题**：
- 容易陷入无限循环（"我需要搜索 X" → 搜索 X → "我需要搜索更多 X" → ...）
- 幻觉问题被放大：每步幻觉，后续步骤基于错误前提继续幻觉
- 成本高昂：一个简单任务可能调用数十次 GPT-4 API

**意义**：第一个让公众看到"自主 AI"可能性的产品，尽管还不成熟。

### Function Calling 正式化（2023 年 6 月）

OpenAI 在 API 中发布结构化工具调用，比 Auto-GPT 靠谱得多：

```json
{
  "name": "get_weather",
  "description": "获取指定城市的天气",
  "parameters": {
    "city": {"type": "string"},
    "unit": {"type": "string", "enum": ["celsius", "fahrenheit"]}
  }
}
```

**ReAct 框架**（Reasoning + Acting）让 Agent 推理过程透明可调试：

```
Thought: 我需要知道今天的股价
Action: search_web("AAPL 股价 今天")
Observation: 苹果股价 $187.5，涨幅 +1.2%
Thought: 现在我知道了，可以回答
Answer: 苹果今日股价 $187.5，涨幅 1.2%
```

## 2023 — 多模态与长上下文爆发

### GPT-4V / GPT-4o

- **GPT-4V**（2023 年 9 月）：GPT-4 加入视觉理解，能看图说话、理解截图、分析图表
- **GPT-4o**（2024 年 5 月）：原生多模态，文字/音频/图像统一处理  
  - 实时语音对话，延迟 <300ms，能感知语气和情绪
  - 不需要先把语音转文字，模型直接处理音频信号

### Claude 2 的长上下文

Anthropic 将 Claude 推进到 **100K token 上下文**（约 75,000 词）：
- 可以一次性分析整本书
- 代码库级别的理解和修改
- 长文档问答不丢失早期信息

### Gemini 1.5 Pro（2024 年 2 月）

**100 万 token 上下文**（实验版达到 200 万 token）：
- 上传完整电影，问关于场景的问题
- 上传整个代码库，问架构问题
- 上传 1 小时录音，找特定内容片段

## 2024 — o1：推理时计算的革命

**OpenAI 发布 o1**（2024 年 9 月），这是一个范式级别的突破。

**核心区别**：

| | 标准 LLM | o1 推理模型 |
|--|---------|-----------|
| 响应方式 | 立即生成回答 | 先"思考"再回答 |
| 思考时间 | 几乎无 | 几秒到几分钟 |
| 擅长任务 | 通用对话、写作 | 数学、编程、逻辑推理 |
| 比喻 | 直觉反应 | 深思熟虑 |

**o1 的成绩**：

| 测试 | GPT-4o | o1 |
|------|--------|-----|
| AIME 数学竞赛 | 12% | 74% |
| Codeforces 竞赛编程 | 11th %ile | 89th %ile |
| PhD 级科学题（GPQA）| 47% | 77% |

**"推理时计算规模定律"**：在推理时花更多算力（让模型思考更久），效果和"在训练时花更多算力"类似——不需要更大的模型，只需要让模型想得更久。

## 2025 年 1 月 20 日 — DeepSeek R1：最大的行业震动

**深度求索（DeepSeek）发布 R1 推理模型**

**关键数据**：
- 训练成本：**约 557 万美元**（o1 训练成本估计超过 1 亿美元）
- 性能：在数学、代码、推理 Benchmark 上**对标甚至超越 OpenAI o1**
- 开源：完整模型权重公开，任何人可下载运行

**2025 年 1 月 27 日（DeepSeek 发布后一周）**：NVIDIA 单日市值蒸发超过 **5000 亿美元**——市场意识到高效训练可能削减对顶级 GPU 的需求。

### DeepSeek R1 的核心技术创新

**1. GRPO（群体相对策略优化）**：

传统 RLHF 需要一个独立的 critic 模型打分，GRPO 用组内对比代替：

```python
# 对同一个问题生成 G 个回答
outputs = [model.generate(question) for _ in range(G)]

# 计算每个回答的奖励（基于规则：数学题的答案对不对）
rewards = [compute_reward(output, answer) for output in outputs]

# 组内归一化（高于平均得正奖励，低于平均得负奖励）
baseline = mean(rewards)
advantages = [r - baseline for r in rewards]

# 用组内相对优势更新策略，不需要 critic 网络
loss = -mean([adv * log_prob for adv, log_prob in zip(advantages, log_probs)])
```

**优势**：节省 critic 模型的内存和计算，同时训练更稳定。

**2. 纯 RL 涌现推理**：

DeepSeek 发现，不需要人工标注思维链数据，只需要用 RL 对正确答案给奖励，模型**自发学会了用思维链来推理**——这被称为"顿悟时刻（Aha Moment）"。

```
早期训练（RL 初期）：
  问题：1+1=?
  模型回答：2  （直接）

足够多的 RL 训练后：
  问题：一个复杂数学题
  模型自发输出：<think>
    让我先分解这道题...
    步骤 1：...
    步骤 2：...
    检查一下：...
  </think>
  答案：...
```

**3. MoE 架构（DeepSeek-V3）**：
- 总参数：6710 亿
- 每次激活：约 370 亿（稀疏激活，计算量大幅减少）
- MLA（Multi-Head Latent Attention）：大幅降低 KV Cache 内存占用

## 2025 年 1 月 23 日 — OpenAI Operator：官方 Agent 登场

**OpenAI 发布 Operator**，第一个官方商业化 AI Agent。

**能力**：自主操控浏览器，像人类一样点击、输入、导航，完成端到端任务。

```
用户：帮我在 OpenTable 订一个今晚 7 点、曼哈顿的两人意大利餐厅
Operator：
  1. 打开 OpenTable 网站
  2. 搜索"意大利餐厅"，位置"曼哈顿"，时间"今晚 19:00"，人数"2"
  3. 筛选评分 4.5+，价格中等
  4. 选择 Via Carota（评分 4.7，有空位）
  5. 填写订位信息（姓名、电话）
  6. 确认预订
  → 预订已完成，确认邮件已发送
```

**意义**：AI 从"回答问题"正式进入"完成任务"阶段，计算机成为 AI 的操控对象而非人类的工具。

## 2025 年 4 月 — OpenAI o3 / o4-mini：图像进入思维链

**核心突破**：o3 / o4-mini 首次实现**把图像融入思维链推理**。

之前的推理模型只能在文字上推理。o3/o4-mini 可以：

```
问题：[上传一张几何图形] 求这个不规则四边形的面积

o3 思维链（可见部分）：
<parameter name="content">
我先识别图中的顶点坐标...
A(0,0), B(4,0), C(5,3), D(1,4)
用 Shoelace 公式：
Area = ½|x_A(y_B-y_D) + x_B(y_C-y_A) + x_C(y_D-y_B) + x_D(y_A-y_C)|
     = ½|0(0-4) + 4(3-0) + 5(4-0) + 1(0-3)|
     = ½|0 + 12 + 20 - 3| = ½ × 29 = 14.5
```

答案：面积为 14.5 平方单位

**视觉推理的质变**：不再是"看图说话"，而是把图像当作推理的中间变量。

## 2025 年 4 月 — Llama 4：Meta 的开源反击

**Meta 发布 Llama 4**，包含三个模型：

| 型号 | 参数 | 特点 |
|------|------|------|
| **Scout** | 17B 激活（109B 总参数，16 专家）| 上下文 **1000 万 token**（史上最长）|
| **Maverick** | 17B 激活（400B 总参数，128 专家）| 多模态，超越 GPT-4o 和 Gemini 2.0 Flash |
| **Behemoth** | ~2000B 总参数（训练中）| 目标超越 GPT-5 |

**Llama 4 Scout 的 1000 万 token 上下文**意味着：
- 可以装入整个 Linux 内核代码库（约 2800 万行）
- 可以装入一个人一生的阅读量（约 10 万本书）
- 实时处理小时级视频

**Maverick 的技术亮点**：
- Mixture of Experts：128 个专家网络，每次只激活部分
- 原生多模态：图文语音视频统一训练
- 在多模态 Benchmark 上超越同量级闭源模型

**开源策略**：部分 Llama 4 模型权重完全开放，延续了 Meta 的开源路线，与 OpenAI/Anthropic 的闭源形成对抗。

## 2025 年 8 月 7 日 — GPT-5：一体化的诞生

**OpenAI 正式发布 GPT-5**，集成在 ChatGPT 中。

**核心变化**：在 GPT-4 时代，OpenAI 有两套产品——"标准模型"（快速回答）和"推理模型"（o1 慢思考）。GPT-5 将两者合并：

```
用户问简单问题 → GPT-5 快速回答（像 GPT-4o）
用户问复杂问题 → GPT-5 自动切换到深度推理（像 o1）
用户上传图片 + 提问 → GPT-5 原生多模态处理
```

**能力提升**：
- 科学问题解决能力大幅提升（GPQA PhD 级别测试）
- 更长的上下文（提升至更大窗口）
- 更低的幻觉率
- Agent 能力增强（工具调用更可靠）

**Sora 2（2025 年 9 月）**：从视频生成器进化为"世界模拟器"：
- 不只生成视频，而是维护物理世界的内部状态
- 物体的运动、遮挡、反射更加一致
- 可以交互式地修改生成中的场景

## 2025–2026 的范式转变总结

### 从"模型竞赛"到"系统竞赛"

2023 年的竞争核心是"谁的基础模型更强"。2025–2026 年，竞争变成了更复杂的系统问题：

```
基础模型能力    ←→    推理时间分配
       ↕                    ↕
  上下文长度    ←→    Agent 可靠性
       ↕                    ↕
  工具生态      ←→    安全与对齐
```

单一指标不再能描述一个模型的竞争力。

### "效率革命"改变了格局

DeepSeek 的出现打破了"更多算力 = 更强模型"的线性假设：

| 时代 | 逻辑 |
|------|------|
| 2020–2023 | 花更多钱训练更大模型 → 能力提升 |
| 2024–2025 | 花相同的钱，更聪明的架构（MoE + GRPO + FP8）→ 能力提升 |
| 2025–2026 | 花更多推理时间（测试时计算）→ 特定任务能力提升 |

三条路径并行，意味着资本壁垒不再是唯一护城河。

### "Vibe Coding"：AI 改变编程文化

2025 年初，Andrej Karpathy（前 OpenAI、前 Tesla AI 总监）创造了这个词：

> "我越来越多地只是用英语描述我想要什么，然后 AI 写代码，我只管看它能不能跑。"

**现实情况**（2025–2026）：
- GitHub Copilot：超过 77% 的 GitHub 用户至少每周使用一次
- Cursor IDE：以 AI 为核心的编程环境，月活超过 400 万开发者
- Claude Code（Anthropic 命令行工具）：直接在终端做代码 Agent

**争议**：
- 支持者：大幅提升生产力，让程序员聚焦高层设计
- 反对者：初级工程师正在失去学习底层的机会

## 未解决的核心问题（2026）

**1. 幻觉（仍存在）**：即使 GPT-5.4 和 Claude Opus 4.6，在需要精确事实的场景下仍会编造答案。RAG 是当前主流缓解方案，但不能完全解决。

**2. 可靠 Agent**：即使 SWE-bench 达到 80%，在真实生产环境中，Agent 还是会在意想不到的边缘情况失败，需要人工监督。

**3. ARC-AGI 的"最后 20%"**：人类平均 85%，最好的模型约 77%。这 8% 的差距背后，是什么样的能力缺失？

**4. 长期记忆**：即使有 100 万 token 上下文，模型在"会话结束后记住这个人"这件事上仍然是空白的（依赖外部数据库 + 召回）。

**5. 自主学习**：模型在推理时能"想"，但不能"学"——每次对话结束，经验不会更新到权重里（微调除外）。

## 未来路径（2026 年展望）

### 路径一：推理时计算的极限

```
当前：让模型思考几分钟解一道数学题
下一步：让 AI 对一个科学问题思考几天、探索数千条假设路径
终点：AI Scientist，自主设计实验、分析数据、发表论文
```

**已有迹象**：AlphaFold 3（蛋白质折叠）、GNoME（新材料发现，Google 2023）已在科学发现上有实质贡献。

### 路径二：Agent 走向成熟的临界点

```
2023 Auto-GPT：概念验证，不可靠
2024 工具调用 API：结构化，但步骤有限
2025 Operator / Claude Code：特定领域可用
2026 ?：多步骤、长时间、高可靠的通用 Agent？
```

Anthropic 研究表明：Agent 成功率随任务步骤数指数衰减。30 步任务，每步 95% 成功率 → 总成功率 21%。提升单步可靠性是关键。

DeepSeek 式效率革命的下一步：
- 高端模型能力 → 下沉到手机端运行

```
2023：文字 + 图片
2024：+ 语音（实时）
```

## AI 演进史的主线叙事

回溯 80 年的历程，有一条清晰的主线：

```
1950s：智能 = 规则
  → 失败：规则无法覆盖世界复杂性

1990s：智能 = 统计模式
  → 进步：SVM、随机森林，但需要大量特征工程

2010s：智能 = 表示 + 端到端学习
  → 突破：深度学习，从原始数据自动学习特征

2017+：智能 = 注意力 + 规模
  → 涌现：GPT-3、ChatGPT，语言理解达到惊人水平

2024+：智能 = 推理时间 + 工具使用
  → 进行中：o1/o3、Claude 4，AI 开始"做事"而不只是"说话"

2026+：智能 = 自主行动 + 持续学习？
  → 未知...
```

每一次转变，都不是前一个范式的小改进，而是根本性的思维方式转变。

而下一次转变——无论它是什么——很可能已经在某个实验室里悄悄发生。
