# 技能差距诊断：你的水平在哪个段位

## 当前项目能力评估

以你的 ZuruAI 项目（AI 知识库与智能客服）为基准，对照五层技能栈进行评估：

### 已具备的能力

| 技能 | 项目体现 | 段位 |
|------|----------|------|
| FastAPI 异步开发 | 网关服务完整实现，SSE 流式透传 | L1 达标 |
| API 设计与认证 | JWT + API Key 双模式，RESTful 路由 | L1 达标 |
| 多租户架构 | Redis 驱动的租户管理、功能开关 | L1 超标 |
| LLM API 集成 | 通过网关代理 LLM 服务调用 | L2 基础 |
| RAG 系统集成 | L4/L5 级别的 RAG 服务集成 | L2 基础 |
| Agent 架构理解 | L6-L9 Agent 服务集成，MCP Server | L3 基础 |
| SSE 流式输出 | 正确的流式响应透传 | L2 达标 |
| Docker Compose | 9 服务编排，健康检查 | L4 基础 |
| 钉钉集成 | Webhook + 签名验证 + 防重放 | L2 达标 |
| 代码质量 | 结构清晰、异步模式正确、测试覆盖 | L1 达标 |

### 关键差距

| 差距 | 现状 | 目标（中级 AI 工程师） | 优先级 |
|------|------|----------------------|--------|
| **直接 LLM 调用** | 网关代理，无直接调用代码 | 能独立写 Prompt + 调用 + 解析 | 紧急 |
| **Prompt 工程** | 无直接实践 | 结构化输出、Few-Shot、CoT | 紧急 |
| **RAG 全流程** | 集成已有服务，未独立实现 | 文档解析→分块→向量化→检索→重排→生成 | 紧急 |
| **向量数据库** | 配置级使用 | 编程级使用（增删改查、混合检索） | 紧急 |
| **Agent 开发** | 集成已有 Agent，未独立设计 | 独立设计带记忆、工具的 Agent | 高 |
| **微调实操** | 无 | 能跑通 LoRA 微调并评估 | 中 |
| **推理优化** | 无 | 理解 vLLM/量化原理，能部署 | 中 |
| **可观测性** | 基础 Prometheus 抓取 | OpenTelemetry + 分布式追踪 | 中 |
| **数据持久化** | 纯 Redis，无数据库 | PostgreSQL + 迁移 | 低 |
| **CI/CD** | 无 | GitHub Actions 自动化 | 低 |

### 核心判断

**当前水平：L1 满分 + L2 约 40% + L3 约 20%**

你的编程基础扎实，项目工程能力不错，但 AI 核心技能（直接使用 LLM、RAG、Agent）的深度不够。目前更像是"AI 基础设施工程师"而非"AI 应用工程师"。

**能否胜任初级 AI 工程师？**

- 基础编程能力：达标
- LLM API 调用：需要补强（从间接代理到直接使用）
- RAG 全流程：需要补强（从集成到独立实现）
- Agent 开发：需要补强（从理解架构到独立设计）
- Prompt 工程：需要从零开始系统学习

**结论**：以当前水平直接面试 AI 工程师岗位，大概率能通过初级岗的编程基础部分，但在 AI 专业技能环节会被追问到短板。建议按以下优先级集中补强。
