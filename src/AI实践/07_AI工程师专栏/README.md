# AI 工程师专栏：从转型到胜任

基于 BOSS 直聘真实岗位要求，系统化构建 AI 工程师能力体系。不是泛泛而谈的"AI 入门"，而是一份**岗位对标、能力可量化、项目可落地**的转型路线图。

## 专栏定位

本专栏回答三个核心问题：

1. **AI 工程师到底要会什么？** -- 基于真实 JD 的岗位画像与能力模型
2. **我现在的水平够不够？** -- 技能差距分析与优先级排序
3. **怎么学到能上岗？** -- 从理论到实战的完整学习路径
