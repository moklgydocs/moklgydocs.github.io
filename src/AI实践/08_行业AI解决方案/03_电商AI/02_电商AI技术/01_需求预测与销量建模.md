# 需求预测与销量建模

## 需求预测分类

需求预测是电商供应链智能化的核心能力，准确的预测直接驱动库存优化、采购计划和定价策略。

### 按时间维度分类

| 预测类型 | 时间范围 | 主要用途 | 可预测性 | 核心方法 |
|---------|---------|---------|---------|---------|
| 短期预测 | 日/周 | 日常补货、排班 | 较高 | 时序模型、近期趋势 |
| 中期预测 | 月/季度 | 采购计划、库存规划 | 中等 | 机器学习、季节分解 |
| 长期预测 | 季/年 | 产能规划、战略决策 | 较低 | 趋势外推、情景分析 |

### 按颗粒度分类

| 颗粒度 | 预测对象 | SKU数量 | 难度 | 应用场景 |
|--------|---------|---------|------|---------|
| 全局级 | 全平台/全品类总量 | 1 | 低 | 宏观规划、资源分配 |
| 品类级 | 按品类聚合 | 10-100 | 中 | 品类运营、仓网规划 |
| SKU级 | 单个SKU | 1万-100万+ | 高 | 精细化补货、定价 |

预测颗粒度越细，噪声越大，预测难度指数级上升。实际应用中常采用"自上而下"或"自下而上"的层次预测策略。

## 时间序列方法

### ARIMA

ARIMA(AutoRegressive Integrated Moving Average)是经典的时间序列预测方法，适合处理具有趋势和季节性的数据。

**模型构成**：ARIMA(p, d, q)

- **AR(p)**：自回归项，用历史值的线性组合预测
- **I(d)**：差分项，使非平稳序列变为平稳
- **MA(q)**：移动平均项，用历史误差的线性组合修正

```
ARIMA(1,1,1)模型:
(1 - φ₁B)(1 - B)yₜ = (1 + θ₁B)εₜ

展开:
yₜ = yₜ₋₁ + φ₁(yₜ₋₁ - yₜ₋₂) + εₜ + θ₁εₜ₋₁
```

**优势**：理论基础扎实、适合短期预测、参数可解释
**劣势**：难以捕捉非线性关系、需要手动调参、对异常值敏感

### Prophet

Prophet是Meta开源的时间序列预测工具，特别适合具有强季节性和多周期模式的业务数据。

**模型构成**：

```
加法模式（适合季节性波动幅度稳定）：
y(t) = g(t) + s(t) + h(t) + ε(t)

乘法模式（适合季节性波动幅度随趋势增长）：
y(t) = g(t) × s(t) × h(t) × ε(t)

g(t): 趋势项 - 分段线性或逻辑增长
s(t): 季节项 - Fourier级数拟合多周期季节性
h(t): 节假日项 - 用户自定义节假日效应
ε(t): 误差项

电商销量通常随促销大幅波动，宜用乘法模式。
```

**优势**：
- 自动处理缺失值和异常值
- 季节性多周期(年+周+日)自动拟合
- 节假日效应内置支持
- 无需大量调参即可获得合理结果
- 支持趋势变点自动检测

### LSTM

LSTM(Long Short-Term Memory)是深度学习时间序列预测的代表性方法，通过门控机制捕捉长程依赖。

**模型结构**：

```
输入门:  iₜ = σ(Wᵢxₜ + Uᵢhₜ₋₁ + bᵢ)
遗忘门:  fₜ = σ(Wf xₜ + Uf hₜ₋₁ + bf)
输出门:  oₜ = σ(Wₒxₜ + Uₒhₜ₋₁ + bₒ)
候选记忆: c̃ₜ = tanh(Wc xₜ + Uc hₜ₋₁ + bc)
记忆更新: cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ c̃ₜ
隐藏状态: hₜ = oₜ ⊙ tanh(cₜ)
```

**优势**：捕捉非线性模式、长程依赖建模、可融入多维特征
**劣势**：训练数据量大、训练时间长、可解释性差、容易过拟合

## 机器学习方法

### XGBoost/LightGBM特征工程

基于梯度提升树的方法将时间序列问题转化为监督学习问题，通过特征工程捕捉时间模式。

**核心思路**：将时间序列的每个时间点构造为一条样本，用历史窗口的特征预测未来值。

### 特征设计

**日历特征**：

```python
def create_calendar_features(df, date_col="date"):
    """创建日历相关特征"""
    df = df.copy()
    df["year"] = df[date_col].dt.year
    df["month"] = df[date_col].dt.month
    df["day"] = df[date_col].dt.day
    df["dayofweek"] = df[date_col].dt.dayofweek
    df["dayofyear"] = df[date_col].dt.dayofyear
    df["weekofyear"] = df[date_col].dt.isocalendar().week.astype(int)
    df["is_weekend"] = (df[date_col].dt.dayofweek >= 5).astype(int)
    df["is_month_start"] = df[date_col].dt.is_month_start.astype(int)
    df["is_month_end"] = df[date_col].dt.is_month_end.astype(int)
    df["quarter"] = df[date_col].dt.quarter
    return df
```

**促销特征**：

```python
def create_promotion_features(df, date_col="date"):
    """创建促销相关特征"""
    df = df.copy()
    # 大促标记
    big_promos = {
        "618": [(6, 1), (6, 18)],
        "double11": [(11, 1), (11, 11)],
        "double12": [(12, 1), (12, 12)],
    }
    # 构建促销日期列表
    promos = []
    for promo_name, (start, end) in big_promos.items():
        for year in df[date_col].dt.year.unique():
            promos.append({
                'name': promo_name,
                'start': pd.Timestamp(year=year, month=start[0], day=start[1]),
                'end': pd.Timestamp(year=year, month=end[0], day=end[1]),
            })

    df["is_promo"] = 0
    df["days_to_promo"] = 999
    for idx, row in df.iterrows():
        current_date = row[date_col]
        # 检查当前日期是否在促销期内
        for p in promos:
            if p['start'] <= current_date <= p['end']:
                df.at[idx, "is_promo"] = 1
                break
        # 计算距下次促销的天数
        future_promos = [p for p in promos if p['start'] > current_date]
        if future_promos:
            days_to_promo = (future_promos[0]['start'] - current_date).days
            df.at[idx, "days_to_promo"] = days_to_promo
    return df
```

```python
def create_historical_features(df, target_col="sales", date_col="date"):
    """创建历史统计特征"""
    df = df.copy()
    df['lag_7'] = df.groupby('sku_id')[target_col].shift(7)
    df['lag_14'] = df.groupby('sku_id')[target_col].shift(14)
    df['lag_28'] = df.groupby('sku_id')[target_col].shift(28)
    df['rolling_7_mean'] = df.groupby('sku_id')[target_col].rolling(7, min_periods=1).mean().reset_index(level=0, drop=True)
    df['rolling_7_std'] = df.groupby('sku_id')[target_col].rolling(7, min_periods=1).std().reset_index(level=0, drop=True)
    df['rolling_28_mean'] = df.groupby('sku_id')[target_col].rolling(28, min_periods=1).mean().reset_index(level=0, drop=True)
    for window in [14, 28]:
        df[f'rolling_mean_{window}'] = df.groupby('sku_id')[target_col].rolling(window, min_periods=1).mean().reset_index(level=0, drop=True)
        df[f'rolling_std_{window}'] = df.groupby('sku_id')[target_col].rolling(window, min_periods=1).std().reset_index(level=0, drop=True)
        df[f'rolling_min_{window}'] = df.groupby('sku_id')[target_col].rolling(window, min_periods=1).min().reset_index(level=0, drop=True)
        df[f'rolling_max_{window}'] = df.groupby('sku_id')[target_col].rolling(window, min_periods=1).max().reset_index(level=0, drop=True)
    # 同比
    df[f"yoy_ratio"] = df[target_col] / df.groupby('sku_id')[target_col].shift(364) - 1
    # 环比
    df[f"wow_ratio"] = df[target_col] / df.groupby('sku_id')[target_col].shift(7) - 1
    return df
```

## Prophet预测代码示例

```python
import pandas as pd
import numpy as np
from prophet import Prophet
from prophet.make_holidays import make_holidays_df
from datetime import datetime, timedelta
from typing import Optional, Dict, List, Tuple


class SalesForecaster:
    """基于Prophet的销量预测引擎"""

    def __init__(
        self,
        growth: str = "linear",
        seasonality_mode: str = "multiplicative",
        yearly_seasonality: int = 10,
        weekly_seasonality: int = 3,
        daily_seasonality: bool = False,
        changepoint_prior_scale: float = 0.05,
        seasonality_prior_scale: float = 10.0,
        holidays_prior_scale: float = 10.0,
    ):
        self.growth = growth
        self.seasonality_mode = seasonality_mode
        self.yearly_seasonality = yearly_seasonality
        self.weekly_seasonality = weekly_seasonality
        self.daily_seasonality = daily_seasonality
        self.changepoint_prior_scale = changepoint_prior_scale
        self.seasonality_prior_scale = seasonality_prior_scale
        self.holidays_prior_scale = holidays_prior_scale
        self.model: Optional[Prophet] = None
        self.train_df: Optional[pd.DataFrame] = None

    @staticmethod
    def _build_holidays(years: List[int]) -> pd.DataFrame:
        """构建中国节假日DataFrame"""
        holidays = []
        for year in years:
            # 春节
            holidays.extend([
                {"holiday": "spring_festival", "ds": f"{year}-01-01", "lower_window": -7, "upper_window": 7},
            ])
            # 618
            holidays.extend([
                {"holiday": "promo_618", "ds": f"{year}-06-18", "lower_window": -17, "upper_window": 0},
            ])
            # 双11
            holidays.extend([
                {"holiday": "promo_double11", "ds": f"{year}-11-11", "lower_window": -10, "upper_window": 0},
            ])
            # 双12
            holidays.extend([
                {"holiday": "promo_double12", "ds": f"{year}-12-12", "lower_window": -5, "upper_window": 0},
            ])
            # 国庆
            holidays.extend([
                {"holiday": "national_day", "ds": f"{year}-10-01", "lower_window": 0, "upper_window": 6},
            ])
        return pd.DataFrame(holidays)

    def train(
        self,
        df: pd.DataFrame,
        date_col: str = "ds",
        target_col: str = "y",
        promo_df: Optional[pd.DataFrame] = None,
    ) -> Dict:
        """
        训练预测模型

        Args:
            df: 训练数据，包含日期列和目标列
            date_col: 日期列名
            target_col: 目标列名
            promo_df: 促销事件DataFrame

        Returns:
            训练结果摘要
        """
        train_df = df[[date_col, target_col]].rename(columns={date_col: "ds", target_col: "y"})
        train_df["ds"] = pd.to_datetime(train_df["ds"])
        self.train_df = train_df.copy()

        # 构建节假日
        years = train_df["ds"].dt.year.unique().tolist()
        holidays = self._build_holidays(years)
        if promo_df is not None:
            holidays = pd.concat([holidays, promo_df], ignore_index=True)

        # 初始化模型
        self.model = Prophet(
            growth=self.growth,
            seasonality_mode=self.seasonality_mode,
            yearly_seasonality=self.yearly_seasonality,
            weekly_seasonality=self.weekly_seasonality,
            daily_seasonality=self.daily_seasonality,
            changepoint_prior_scale=self.changepoint_prior_scale,
            seasonality_prior_scale=self.seasonality_prior_scale,
            holidays_prior_scale=self.holidays_prior_scale,
            holidays=holidays if not holidays.empty else None,
        )

        # 添加自定义季节性
        self.model.add_seasonality(name="monthly", period=30.5, fourier_order=5)

        # 训练
        self.model.fit(train_df)

        # 训练集拟合评估
        forecast_train = self.model.predict(train_df)
        y_true = train_df["y"].values
        y_pred = forecast_train["yhat"].values
        mape = self._calculate_mape(y_true, y_pred)
        rmse = self._calculate_rmse(y_true, y_pred)

        return {
            "train_samples": len(train_df),
            "train_mape": mape,
            "train_rmse": rmse,
            "model_params": {
                "growth": self.growth,
                "seasonality_mode": self.seasonality_mode,
                "changepoint_prior_scale": self.changepoint_prior_scale,
            },
        }

    def predict(
        self,
        periods: int = 30,
        freq: str = "D",
        include_history: bool = False,
    ) -> pd.DataFrame:
        """
        生成未来预测

        Args:
            periods: 预测天数
            freq: 时间频率
            include_history: 是否包含历史预测

        Returns:
            预测结果DataFrame
        """
        if self.model is None:
            raise ValueError("模型尚未训练，请先调用train方法")

        future = self.model.make_future_dataframe(periods=periods, freq=freq, include_history=include_history)
        forecast = self.model.predict(future)

        result = forecast[["ds", "yhat", "yhat_lower", "yhat_upper"]].copy()
        result.columns = ["date", "predicted", "predicted_lower", "predicted_upper"]

        # 预测值不能为负
        result["predicted"] = result["predicted"].clip(lower=0)
        result["predicted_lower"] = result["predicted_lower"].clip(lower=0)

        return result

    def evaluate(
        self,
        test_df: pd.DataFrame,
        date_col: str = "ds",
        target_col: str = "y",
    ) -> Dict:
        """
        评估预测准确率

        Args:
            test_df: 测试数据
            date_col: 日期列名
            target_col: 目标列名

        Returns:
            评估指标
        """
        if self.model is None:
            raise ValueError("模型尚未训练")

        test_data = test_df[[date_col, target_col]].rename(columns={date_col: "ds", target_col: "y"})
        test_data["ds"] = pd.to_datetime(test_data["ds"])

        forecast = self.model.predict(test_data[["ds"]])

        y_true = test_data["y"].values
        y_pred = forecast["yhat"].values

        return {
            "mape": self._calculate_mape(y_true, y_pred),
            "rmse": self._calculate_rmse(y_true, y_pred),
            "wmape": self._calculate_wmape(y_true, y_pred),
            "mae": self._calculate_mae(y_true, y_pred),
            "test_samples": len(test_data),
        }

    @staticmethod
    def _calculate_mape(y_true: np.ndarray, y_pred: np.ndarray) -> float:
        """计算MAPE"""
        mask = y_true != 0
        if not mask.any():
            return float("inf")
        return float(np.mean(np.abs((y_true[mask] - y_pred[mask]) / y_true[mask])) * 100)

    @staticmethod
    def _calculate_rmse(y_true: np.ndarray, y_pred: np.ndarray) -> float:
        """计算RMSE"""
        return float(np.sqrt(np.mean((y_true - y_pred) ** 2)))

    @staticmethod
    def _calculate_wmape(y_true: np.ndarray, y_pred: np.ndarray) -> float:
        """计算WMAPE"""
        total = np.sum(np.abs(y_true))
        if total == 0:
            return float("inf")
        return float(np.sum(np.abs(y_true - y_pred)) / total * 100)

    @staticmethod
    def _calculate_mae(y_true: np.ndarray, y_pred: np.ndarray) -> float:
        """计算MAE"""
        return float(np.mean(np.abs(y_true - y_pred)))


def generate_sample_data(
    start_date: str = "2022-01-01",
    end_date: str = "2024-12-31",
    base_sales: float = 1000,
    trend: float = 0.5,
    weekly_seasonality: float = 0.15,
    yearly_seasonality: float = 0.3,
    noise_std: float = 50,
    seed: int = 42,
) -> pd.DataFrame:
    """生成模拟销量数据"""
    np.random.seed(seed)
    dates = pd.date_range(start=start_date, end=end_date, freq="D")
    n = len(dates)

    # 趋势
    trend_values = np.arange(n) * trend
    # 周季节性
    day_of_week = dates.dayofweek
    week_pattern = np.array([0.9, 1.0, 1.05, 1.0, 1.1, 1.3, 1.2])
    weekly = week_pattern[day_of_week]
    # 年季节性
    day_of_year = dates.dayofyear
    yearly = 1 + yearly_seasonality * np.sin(2 * np.pi * (day_of_year - 80) / 365)
    # 大促脉冲
    promo_boost = np.zeros(n)
    for i, d in enumerate(dates):
        if d.month == 6 and d.day in range(1, 19):
            promo_boost[i] = 2.0
        elif d.month == 11 and d.day in range(1, 12):
            promo_boost[i] = 3.0
    # 噪声
    noise = np.random.normal(0, noise_std, n)
    # 合成
    sales = base_sales * weekly * yearly + trend_values + promo_boost * base_sales + noise
    sales = np.maximum(sales, 0)

    return pd.DataFrame({"ds": dates, "y": sales})


if __name__ == "__main__":
    # 生成模拟数据
    df = generate_sample_data()

    # 划分训练集和测试集
    split_date = "2024-10-01"
    train_df = df[df["ds"] < split_date]
    test_df = df[df["ds"] >= split_date]

    # 训练模型
    forecaster = SalesForecaster(
        seasonality_mode="multiplicative",
        changepoint_prior_scale=0.05,
    )
    train_result = forecaster.train(train_df)
    print(f"训练完成: {train_result}")

    # 评估
    eval_result = forecaster.evaluate(test_df)
    print(f"测试集评估: {eval_result}")

    # 预测未来30天
    forecast = forecaster.predict(periods=30)
    print(f"\n未来30天预测:")
    print(forecast.tail(10).to_string(index=False))
```

## 多层次预测

### 层次预测策略

电商预测面临SKU数量庞大的挑战，需要采用层次化的预测策略。

| 策略 | 方法 | 优势 | 劣势 |
|------|------|------|------|
| 自下而上 | SKU级预测后聚合 | 细节丰富、可操作 | 噪声大、聚合后偏差 |
| 自上而下 | 总量预测后按比例分配 | 总量准确 | 分配比例难确定 |
| 中间向外 | 品类级预测后双向扩展 | 平衡精度和细节 | 层级选择困难 |
| 最优组合 | 统计最优组合各层预测 | 理论最优 | 计算复杂度高 |

### 实践建议

```
1. A类商品(高价值): SKU级独立预测，Prophet/XGBoost精细调参
2. B类商品(中等): 品类级预测 + SKU比例分配
3. C类商品(长尾): 品类级预测 + 均匀分配或历史比例
4. 新品: 相似品迁移 + 小样本快速更新
```

## 预测评估

### 评估指标

| 指标 | 公式 | 特点 | 适用场景 |
|------|------|------|---------|
| MAPE | mean(\|y-ŷ\|/\|y\|) * 100 | 百分比误差，直观 | 销量>0的场景 |
| WMAPE | sum(\|y-ŷ\|) / sum(\|y\|) * 100 | 按量加权，不受小值影响 | 含零值或小值的场景 |
| RMSE | sqrt(mean((y-ŷ)^2)) | 惩罚大误差 | 关注极端偏差 |
| MAE | mean(\|y-ŷ\|) | 绝对误差平均 | 线性惩罚 |
| Bias | mean(ŷ-y) | 预测偏度 | 检测系统性偏差 |

### 准确率基准

| 商品类型 | MAPE基准 | 说明 |
|---------|---------|------|
| 稳定标品 | 10-15% | 需求波动小，预测较准 |
| 季节性商品 | 15-25% | 季节模式明显 |
| 时尚/潮流 | 25-40% | 趋势变化快 |
| 长尾商品 | 30-50% | 数据稀疏，噪声大 |
| 新品 | 40-60% | 历史数据缺失 |

## 冷启动问题

新品预测是电商需求预测的难点，缺乏历史数据导致传统时序方法失效。

### 新品预测策略

| 策略 | 方法 | 适用条件 | 预期准确率 |
|------|------|---------|-----------|

### 相似品迁移代码示例

```python
from sklearn.metrics.pairwise import cosine_similarity
import numpy as np


def find_similar_products(
    new_product_features: np.ndarray,
    existing_products_features: np.ndarray,
    existing_products_ids: list,
    top_k: int = 5,
) -> list:
    """
    基于特征相似度找到最相似的商品

    Args:
        new_product_features: 新品特征向量 (1, n_features)
        existing_products_features: 已有商品特征矩阵 (n_products, n_features)
        existing_products_ids: 已有商品ID列表
        top_k: 返回最相似的K个商品

    Returns:
        相似商品ID及其相似度得分列表
    """
    similarities = cosine_similarity(new_product_features, existing_products_features)[0]
    top_indices = np.argsort(similarities)[::-1][:top_k]
    return [(existing_products_ids[i], float(similarities[i])) for i in top_indices]


def transfer_forecast(
    similar_sales_data: list,
    weights: list,
) -> np.ndarray:
    """
    基于相似品销量数据进行迁移预测

    Args:
        similar_sales_data: 相似品的销量序列列表
        weights: 各相似品的权重(相似度)

    Returns:
        加权合成的预测序列
    """
    weights = np.array(weights)
    weights = weights / weights.sum()

    max_len = max(len(s) for s in similar_sales_data)
    padded = np.zeros((len(similar_sales_data), max_len))
    for i, sales in enumerate(similar_sales_data):
        padded[i, :len(sales)] = sales

    return np.average(padded, axis=0, weights=weights)
```
