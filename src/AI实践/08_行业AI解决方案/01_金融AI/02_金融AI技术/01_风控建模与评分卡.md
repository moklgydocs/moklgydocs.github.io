# 风控建模与评分卡

## 信用评分卡体系

信用评分卡是银行和金融机构进行信用风险评估的核心工具，通过量化借款人的信用状况，辅助信贷审批决策。根据应用场景的不同，评分卡体系分为三大类：

| 评分卡类型 | 英文 | 应用阶段 | 目的 |
|-----------|------|----------|------|
| A卡(Application) | Application Scorecard | 贷前审批 | 评估申请人信用等级 |
| B卡(Behavior) | Behavior Scorecard | 贷中管理 | 监控客户行为变化 |
| C卡(Collection) | Collection Scorecard | 贷后催收 | 评估催收效果和策略 |

### 评分卡开发方法论

评分卡开发遵循标准化的流程，确保模型的稳定性和可解释性：


## 特征工程

### WOE编码

WOE(Weight of Evidence)编码是评分卡特征处理的核心方法，将连续变量或分类变量转换为与目标变量相关的数值：

$$WOE_i = \ln\left(\frac{Good_i / Good_{total}}{Bad_i / Bad_{total}}\right)$$

WOE编码的优势：

- 统一量纲，便于特征比较
- 处理缺失值和异常值
- 与逻辑回归天然匹配
- 提升模型可解释性

### IV值筛选

IV(Information Value)衡量特征对目标变量的预测能力：

$$IV = \sum_{i=1}^{n} (Good_i/Good_{total} - Bad_i/Bad_{total}) \times WOE_i$$

| IV值范围 | 预测能力 | 建议 |
|----------|----------|------|
| < 0.02 | 无预测力 | 剔除 |
| 0.02 - 0.1 | 弱预测力 | 谨慎使用 |
| 0.1 - 0.3 | 中等预测力 | 可用 |
| 0.3 - 0.5 | 强预测力 | 优选 |
| > 0.5 | 过强，需警惕 | 检查数据泄露 |

### PSI稳定性

PSI(Population Stability Index)衡量特征分布在时间上的稳定性：

$$PSI = \sum_{i=1}^{n} (Actual_i - Expected_i) \times \ln\frac{Actual_i}{Expected_i}$$

| PSI值 | 稳定性 | 建议 |
|-------|--------|------|
| < 0.1 | 稳定 | 无需调整 |
| 0.1 - 0.25 | 轻微偏移 | 关注并排查 |
| > 0.25 | 显著偏移 | 需要重新建模 |

## 逻辑回归评分卡开发全流程

以下代码展示完整的评分卡开发流程：

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score, roc_curve
import warnings
warnings.filterwarnings('ignore')


class WOEEncoder:
    """WOE编码器"""

    def __init__(self, n_bins=10, min_samples=0.05):
        self.n_bins = n_bins
        self.min_samples = min_samples
        self.bin_dict = {}
        self.woe_dict = {}
        self.iv_dict = {}

    def fit(self, df, features, target):
        """对特征进行WOE编码"""
        for feat in features:
            if df[feat].dtype in ['object', 'category']:
                self._fit_categorical(df, feat, target)
            else:
                self._fit_numerical(df, feat, target)
        return self

    def _fit_numerical(self, df, feat, target):
        """数值型特征WOE编码"""
        total_good = (df[target] == 0).sum()
        total_bad = (df[target] == 1).sum()

        # 等频分箱
        df_temp = df[[feat, target]].copy()
        df_temp['bin'] = pd.qcut(
            df_temp[feat], q=self.n_bins, duplicates='drop'
        )

        bin_stats = df_temp.groupby('bin', observed=True)[target].agg(
            ['count', 'sum']
        )
        bin_stats.columns = ['total', 'bad']
        bin_stats['good'] = bin_stats['total'] - bin_stats['bad']

        # 平滑处理，避免除零
        bin_stats['good_rate'] = (bin_stats['good'] + 0.5) / (total_good + 0.5)
        bin_stats['bad_rate'] = (bin_stats['bad'] + 0.5) / (total_bad + 0.5)
        bin_stats['woe'] = np.log(bin_stats['good_rate'] / bin_stats['bad_rate'])
        bin_stats['iv'] = (
            (bin_stats['good_rate'] - bin_stats['bad_rate']) * bin_stats['woe']
        )

        self.bin_dict[feat] = bin_stats.index.tolist()
        self.woe_dict[feat] = bin_stats['woe'].to_dict()
        self.iv_dict[feat] = bin_stats['iv'].sum()

    def _fit_categorical(self, df, feat, target):
        """类别型特征WOE编码"""
        total_good = (df[target] == 0).sum()
        total_bad = (df[target] == 1).sum()

        bin_stats = df.groupby(feat)[target].agg(['count', 'sum'])
        bin_stats.columns = ['total', 'bad']
        bin_stats['good'] = bin_stats['total'] - bin_stats['bad']

        bin_stats['good_rate'] = (bin_stats['good'] + 0.5) / (total_good + 0.5)
        bin_stats['bad_rate'] = (bin_stats['bad'] + 0.5) / (total_bad + 0.5)
        bin_stats['woe'] = np.log(bin_stats['good_rate'] / bin_stats['bad_rate'])
        bin_stats['iv'] = (
            (bin_stats['good_rate'] - bin_stats['bad_rate']) * bin_stats['woe']
        )

        self.bin_dict[feat] = bin_stats.index.tolist()
        self.woe_dict[feat] = bin_stats['woe'].to_dict()
        self.iv_dict[feat] = bin_stats['iv'].sum()

    def transform(self, df, features):
        """将特征转换为WOE值"""
        df_woe = pd.DataFrame(index=df.index)
        for feat in features:
            if feat not in self.woe_dict:
                continue
            if df[feat].dtype in ['object', 'category']:
                df_woe[f'{feat}_woe'] = df[feat].map(self.woe_dict[feat])
            else:
                df_temp = df[[feat]].copy()
                bin_edges = self.bin_dict[feat]
                df_woe[f'{feat}_woe'] = pd.cut(
                    df_temp[feat],
                    bins=[b.left for b in bin_edges] + [bin_edges[-1].right],
                    labels=[self.woe_dict[feat][b] for b in bin_edges],
                ).astype(float)
        return df_woe

    def get_iv_summary(self):
        """获取IV值汇总"""
        iv_df = pd.DataFrame({
            'feature': list(self.iv_dict.keys()),
            'iv_value': list(self.iv_dict.values()),
        }).sort_values('iv_value', ascending=False)
        iv_df['predictive_power'] = iv_df['iv_value'].apply(
            lambda x: '强' if x > 0.3 else '中' if x > 0.1 else '弱' if x > 0.02 else '无'
        )
        return iv_df


class ScorecardModel:
    """信用评分卡模型"""

    def __init__(self, base_score=600, base_odds=20, pdo=20):
        """
        参数:
            base_score: 基准分数
            base_odds: 基准好坏比(好:坏)
            pdo: 每翻一倍好坏比增加的分数(points to double odds)
        """
        self.base_score = base_score
        self.base_odds = base_odds
        self.pdo = pdo
        self.factor = pdo / np.log(2)
        self.offset = base_score - self.factor * np.log(base_odds)
        self.model = None
        self.woe_encoder = None
        self.feature_scores = None

    def fit(self, df, features, target):
        """训练评分卡模型"""
        # WOE编码
        self.woe_encoder = WOEEncoder()
        self.woe_encoder.fit(df, features, target)

        # 查看IV值筛选特征
        iv_summary = self.woe_encoder.get_iv_summary()
        print("IV值汇总:")
        print(iv_summary.to_string(index=False))

        # 筛选IV值大于0.02的特征
        selected_features = iv_summary[iv_summary['iv_value'] > 0.02]['feature'].tolist()
        print(f"\n筛选后特征数: {len(selected_features)}")

        # WOE转换
        df_woe = self.woe_encoder.transform(df, selected_features)
        woe_features = [f'{f}_woe' for f in selected_features]

        # 训练逻辑回归
        X = df_woe[woe_features].fillna(0)
        y = df[target]

        self.model = LogisticRegression(
            penalty='l2', C=1.0, solver='lbfgs', max_iter=1000, random_state=42
        )
        self.model.fit(X, y)

        # 计算特征评分
        self._calculate_feature_scores(selected_features)

        return self

    def _calculate_feature_scores(self, features):
        """计算每个特征分箱对应的评分"""
        woe_features = [f'{f}_woe' for f in features]
        coefs = self.model.coef_[0]
        intercept = self.model.intercept_[0]

        self.feature_scores = {}
        for i, feat in enumerate(features):
            woe_feat = woe_features[i]
            coef = coefs[i]
            feat_scores = {}
            for bin_key, woe_val in self.woe_encoder.woe_dict[feat].items():
                score = -(coef * woe_val + intercept / len(features)) * self.factor
                feat_scores[str(bin_key)] = round(score, 2)
            self.feature_scores[feat] = feat_scores

    def predict_score(self, df):
        """预测信用评分"""
        features = list(self.feature_scores.keys())
        df_woe = self.woe_encoder.transform(df, features)
        woe_features = [f'{f}_woe' for f in features]
        X = df_woe[woe_features].fillna(0)

        # 使用逻辑回归预测概率
        prob = self.model.predict_proba(X)[:, 1]

        # 转换为评分
        scores = self.offset - self.factor * np.log(prob / (1 - prob))
        return scores.astype(int)

    def evaluate(self, df, target):
        """评估模型性能"""
        features = list(self.feature_scores.keys())
        df_woe = self.woe_encoder.transform(df, features)
        woe_features = [f'{f}_woe' for f in features]
        X = df_woe[woe_features].fillna(0)
        y = df[target]

        y_pred_proba = self.model.predict_proba(X)[:, 1]

        # AUC
        auc = roc_auc_score(y, y_pred_proba)

        # KS值
        fpr, tpr, thresholds = roc_curve(y, y_pred_proba)
        ks = max(tpr - fpr)

        # Gini系数
        gini = 2 * auc - 1

        print(f"AUC: {auc:.4f}")
        print(f"KS: {ks:.4f}")
        print(f"Gini: {gini:.4f}")

        return {'auc': auc, 'ks': ks, 'gini': gini}

    def get_scorecard(self):
        """输出评分卡"""
        print("\n===== 信用评分卡 =====")
        for feat, bins in self.feature_scores.items():
            print(f"\n特征: {feat}")
            for bin_key, score in sorted(bins.items(), key=lambda x: x[1], reverse=True):
                print(f"  {bin_key}: {score}分")
```

### 使用示例

```python
# 生成模拟信贷数据
np.random.seed(42)
n_samples = 10000

data = pd.DataFrame({
    'age': np.random.randint(22, 65, n_samples),
    'income': np.random.lognormal(10, 0.5, n_samples).astype(int),
    'loan_amount': np.random.lognormal(11, 0.6, n_samples).astype(int),
    'employment_years': np.random.randint(0, 30, n_samples),
    'num_credit_cards': np.random.randint(0, 8, n_samples),
    'debt_ratio': np.random.beta(2, 5, n_samples),
    'delinquency_count': np.random.poisson(0.3, n_samples),
    'credit_history_months': np.random.randint(6, 240, n_samples),
})

# 生成目标变量（违约概率）
risk_score = (
    -0.02 * data['age']
    + 0.00001 * data['loan_amount']
    - 0.0001 * data['income']
    + 0.5 * data['debt_ratio']
    + 0.8 * data['delinquency_count']
    - 0.005 * data['credit_history_months']
)
prob = 1 / (1 + np.exp(-risk_score + 5))
data['default'] = (np.random.random(n_samples) < prob).astype(int)

# 训练评分卡
features = [
    'age', 'income', 'loan_amount', 'employment_years',
    'num_credit_cards', 'debt_ratio', 'delinquency_count',
    'credit_history_months'
]

train_df, test_df = train_test_split(data, test_size=0.3, random_state=42)

scorecard = ScorecardModel(base_score=600, base_odds=20, pdo=20)
scorecard.fit(train_df, features, 'default')

# 评估
print("\n===== 训练集表现 =====")
scorecard.evaluate(train_df, 'default')
print("\n===== 测试集表现 =====")
scorecard.evaluate(test_df, 'default')

# 预测评分
test_scores = scorecard.predict_score(test_df)
print(f"\n评分分布: 均值={test_scores.mean()}, 中位数={np.median(test_scores)}")
print(f"评分范围: [{test_scores.min()}, {test_scores.max()}]")
```

## XGBoost/LightGBM风控模型

树模型在风控场景中广泛使用，相比逻辑回归具有更强的非线性拟合能力：

```python
import xgboost as xgb
import lightgbm as lgb
from sklearn.model_selection import StratifiedKFold
from sklearn.metrics import roc_auc_score


def train_xgboost_model(X_train, y_train, X_val, y_val):
    """训练XGBoost风控模型"""
    params = {
        'objective': 'binary:logistic',
        'eval_metric': 'auc',
        'max_depth': 6,
        'learning_rate': 0.05,
        'subsample': 0.8,
        'colsample_bytree': 0.8,
        'min_child_weight': 50,
        'scale_pos_weight': (y_train == 0).sum() / (y_train == 1).sum(),
        'reg_alpha': 0.1,
        'reg_lambda': 1.0,
        'random_state': 42,
    }

    dtrain = xgb.DMatrix(X_train, label=y_train)
    dval = xgb.DMatrix(X_val, label=y_val)

    model = xgb.train(
        params,
        dtrain,
        num_boost_round=500,
        evals=[(dtrain, 'train'), (dval, 'val')],
        early_stopping_rounds=50,
        verbose_eval=50,
    )

    return model


def train_lightgbm_model(X_train, y_train, X_val, y_val, categorical_features=None):
    """训练LightGBM风控模型"""
    params = {
        'objective': 'binary',
        'metric': 'auc',
        'max_depth': 6,
        'learning_rate': 0.05,
        'num_leaves': 31,
        'subsample': 0.8,
        'colsample_bytree': 0.8,
        'min_child_samples': 50,
        'scale_pos_weight': (y_train == 0).sum() / (y_train == 1).sum(),
        'reg_alpha': 0.1,
        'reg_lambda': 1.0,
        'random_state': 42,
        'verbose': -1,
    }

    train_data = lgb.Dataset(
        X_train, label=y_train,
        categorical_feature=categorical_features or 'auto'
    )
    val_data = lgb.Dataset(X_val, label=y_val, reference=train_data)

    model = lgb.train(
        params,
        train_data,
        num_boost_round=500,
        valid_sets=[train_data, val_data],
        callbacks=[
            lgb.early_stopping(50),
            lgb.log_evaluation(50),
        ],
    )

    return model


def cross_validate_model(X, y, n_splits=5, model_type='xgboost'):
    """交叉验证评估模型稳定性"""
    skf = StratifiedKFold(n_splits=n_splits, shuffle=True, random_state=42)
    auc_scores = []

    for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
        X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
        y_train, y_val = y.iloc[train_idx], y.iloc[val_idx]

        if model_type == 'xgboost':
            model = train_xgboost_model(X_train, y_train, X_val, y_val)
            dval = xgb.DMatrix(X_val)
            y_pred = model.predict(dval)
        else:
            model = train_lightgbm_model(X_train, y_train, X_val, y_val)
            y_pred = model.predict(X_val)

        auc = roc_auc_score(y_val, y_pred)
        auc_scores.append(auc)
        print(f"Fold {fold + 1}: AUC = {auc:.4f}")

    print(f"\n平均AUC: {np.mean(auc_scores):.4f} +/- {np.std(auc_scores):.4f}")
    return auc_scores
```

## 模型评估

### KS值(Kolmogorov-Smirnov)

KS值衡量好坏客户评分分布的最大差异，是风控模型最重要的评估指标：

```python
def calculate_ks(y_true, y_pred_proba):
    """计算KS值"""
    fpr, tpr, thresholds = roc_curve(y_true, y_pred_proba)
    ks = max(tpr - fpr)
    ks_threshold = thresholds[np.argmax(tpr - fpr)]
    return ks, ks_threshold


def plot_ks_curve(y_true, y_pred_proba):
    """绘制KS曲线"""
    import matplotlib.pyplot as plt

    fpr, tpr, thresholds = roc_curve(y_true, y_pred_proba)
    ks_values = tpr - fpr
    ks_max = max(ks_values)
    ks_idx = np.argmax(ks_values)

    fig, ax = plt.subplots(figsize=(10, 6))
    ax.plot(thresholds, tpr, label='TPR (好客户累积分布)')
    ax.plot(thresholds, fpr, label='FPR (坏客户累积分布)')
    ax.plot(thresholds, ks_values, label=f'KS (max={ks_max:.4f})', linestyle='--')
    ax.axvline(x=thresholds[ks_idx], color='red', linestyle=':', alpha=0.5)
    ax.set_xlabel('评分阈值')
    ax.set_ylabel('累积比例')
    ax.set_title('KS曲线')
    ax.legend()
    ax.invert_xaxis()
    plt.tight_layout()
    plt.savefig('ks_curve.png', dpi=150)
    plt.close()
```

### AUC与Gini系数

| 指标 | 计算方式 | 含义 | 参考标准 |
|------|----------|------|----------|
| AUC | ROC曲线下面积 | 模型区分好坏客户的能力 | > 0.7可用, > 0.75良好 |
| Gini | 2*AUC - 1 | AUC的线性变换，更直观 | > 0.4可用, > 0.5良好 |
| KS | TPR-FPR最大值 | 好坏分布最大分离度 | > 0.3可用, > 0.4良好 |

## 模型监控

模型上线后需要持续监控其表现，及时发现性能退化：

### PSI(Population Stability Index)

监控评分分布的稳定性：

```python
def calculate_psi(expected, actual, n_bins=10):
    """计算PSI值"""
    breakpoints = np.linspace(0, 100, n_bins + 1)

    expected_pct = np.percentile(expected, breakpoints) / 100
    actual_pct = np.percentile(actual, breakpoints) / 100

    expected_bins = np.histogram(expected, bins=expected_pct)[0] / len(expected)
    actual_bins = np.histogram(actual, bins=expected_pct)[0] / len(actual)

    # 避免零值
    expected_bins = np.clip(expected_bins, 0.0001, None)
    actual_bins = np.clip(actual_bins, 0.0001, None)

    psi = np.sum((actual_bins - expected_bins) * np.log(actual_bins / expected_bins))
    return psi


def calculate_csi(expected, actual, feature, n_bins=10):
    """计算CSI(Characteristic Stability Index)"""
    breakpoints = np.percentile(expected, np.linspace(0, 100, n_bins + 1))

    expected_bins = np.histogram(expected, bins=breakpoints)[0] / len(expected)
    actual_bins = np.histogram(actual, bins=breakpoints)[0] / len(actual)

    expected_bins = np.clip(expected_bins, 0.0001, None)
    actual_bins = np.clip(actual_bins, 0.0001, None)

    csi = np.sum((actual_bins - expected_bins) * np.log(actual_bins / expected_bins))
    return csi
```

### 评分分布偏移监控

```python
class ModelMonitor:
    """模型监控器"""

    def __init__(self, reference_scores, reference_features_df):
        """
        参数:
            reference_scores: 基准期评分
            reference_features_df: 基准期特征数据
        """
        self.reference_scores = reference_scores
        self.reference_features = reference_features_df
        self.monitor_results = []

    def check(self, current_scores, current_features_df):
        """执行模型监控检查"""
        results = {}

        # 1. PSI检查
        psi = calculate_psi(self.reference_scores, current_scores)
        results['psi'] = psi
        results['psi_status'] = (
            '稳定' if psi < 0.1 else '关注' if psi < 0.25 else '预警'
        )

        # 2. CSI检查
        csi_results = {}
        for col in current_features_df.columns:
            if col in self.reference_features.columns:
                csi = calculate_csi(
                    self.reference_features[col].values,
                    current_features_df[col].values,
                )
                csi_results[col] = csi
        results['csi'] = csi_results
        results['csi_alert_features'] = [
            k for k, v in csi_results.items() if v > 0.1
        ]

        # 3. 评分分布统计
        results['score_stats'] = {
            'reference_mean': np.mean(self.reference_scores),
            'current_mean': np.mean(current_scores),
            'mean_shift': np.mean(current_scores) - np.mean(self.reference_scores),
            'reference_std': np.std(self.reference_scores),
            'current_std': np.std(current_scores),
        }

        self.monitor_results.append(results)
        return results

    def generate_report(self):
        """生成监控报告"""
        if not self.monitor_results:
            print("暂无监控数据")
            return

        latest = self.monitor_results[-1]
        print("===== 模型监控报告 =====")
        print(f"PSI: {latest['psi']:.4f} ({latest['psi_status']})")
        print(f"评分均值偏移: {latest['score_stats']['mean_shift']:.2f}")

        if latest['csi_alert_features']:
            print(f"CSI预警特征: {latest['csi_alert_features']}")
        else:
            print("所有特征CSI正常")

        print("\n特征CSI详情:")
        for feat, csi_val in latest['csi'].items():
            status = '预警' if csi_val > 0.1 else '关注' if csi_val > 0.05 else '正常'
            print(f"  {feat}: {csi_val:.4f} ({status})")
```

### 监控指标阈值

| 指标 | 绿灯 | 黄灯 | 红灯 |
|------|------|------|------|
| PSI | < 0.1 | 0.1 - 0.25 | > 0.25 |
| CSI | < 0.05 | 0.05 - 0.1 | > 0.1 |
| AUC下降 | < 2% | 2% - 5% | > 5% |
| KS下降 | < 2% | 2% - 5% | > 5% |
| 评分均值偏移 | < 10分 | 10 - 20分 | > 20分 |

## 评分卡与树模型的融合策略

在实际风控中，通常将评分卡与树模型融合使用：

| 策略 | 说明 | 优势 |
|------|------|------|
| 评分卡前置筛选 | 评分卡过滤低风险客户，树模型评估剩余 | 降低计算成本 |
| 并行决策 | 两模型独立评分，取较严结果 | 提升召回率 |
| 模型融合 | 加权平均或Stacking | 提升AUC |
| 分层应用 | A卡用评分卡，B/C卡用树模型 | 各取所长 |

## 小结

风控建模是金融AI最核心的应用场景之一。评分卡以逻辑回归为基础，通过WOE编码和IV值筛选构建可解释的信用评分体系。XGBoost和LightGBM等树模型提供更强的非线性拟合能力。KS值、AUC、Gini系数是模型评估的核心指标，PSI和CSI是模型监控的关键工具。在实际应用中，评分卡和树模型的融合策略可以兼顾可解释性和预测性能。
