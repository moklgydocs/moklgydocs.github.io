# 行业 AI 解决方案

从行业知识到AI技术，再到完整可运行系统，覆盖金融、医疗、电商三大核心领域。

## 内容结构

每个行业包含三个层次：

| 层次 | 内容 | 目标 |
|------|------|------|
| 行业知识 | 业务体系、核心流程、术语体系、合规框架 | 理解行业本质 |
| AI 技术 | 领域算法、模型方法、技术选型 | 掌握技术手段 |
| 项目实战 | 完整可运行系统（FastAPI + React + Docker） | 落地生产能力 |

## 三大行业

### 金融 AI — 反欺诈与合规系统

覆盖金融体系全景、银行业务、证券投资、保险、监管合规等行业知识，风控建模、反欺诈检测、反洗钱监测、RegTech等AI技术，最终实现包含实时交易监控、AI欺诈评分引擎、KYC/AML合规审查的完整系统。

### 医疗 AI — 智慧诊疗系统

覆盖医疗体系、临床诊疗流程、医学影像与检验、药品处方、信息化合规等行业知识，医学影像AI、临床决策支持、NLP与电子病历、智能问诊与知识图谱等AI技术，最终实现包含电子病历、AI辅助诊断、知识图谱问诊、合理用药审查的完整系统。

### 电商 AI — 智能供应链系统

覆盖电商生态、供应链仓储、商品库存、物流配送、数据运营等行业知识，需求预测、智能定价、库存优化、供应链协同等AI技术，最终实现包含销量预测、动态定价、库存优化、采购协同的完整系统。
