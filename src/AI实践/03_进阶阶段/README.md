# 第三阶段：进阶

**目标**：掌握多智能体系统、模型微调与生产运维，能为 Agent 系统保驾护航。

**预计周期**：4-6 周

## 目录

- [多智能体系统设计](01.多智能体系统设计.md) —— Supervisor、Swarm、任务分解与协作
- [Fine-tuning 微调实战](02.Fine-tuning微调实战.md) —— 数据准备、LoRA 微调、效果评估
- [生产可观测性建设](03.生产可观测性.md) —— 链路追踪、指标监控、成本告警

## 阶段验收标准

完成以下项目认为本阶段达标：
- [ ] 能设计一个 3 个 Agent 协作完成复杂任务的多智能体系统
- [ ] 能在本地用 LoRA 微调一个小模型，并评估微调效果
- [ ] 能为生产 RAG 系统配置完整的可观测性（日志 + 指标 + 成本追踪）
