# Fine-tuning 微调实战

微调让通用模型适应特定领域和风格。本文覆盖 OpenAI API 微调（最简单）和本地 LoRA 微调（成本最低），以及何时选择微调而非 RAG。

## 1. 何时选择微调（而非 RAG）

```
微调适合：
✅ 需要特定的输出格式或风格（如企业口吻、代码注释规范）
✅ 领域术语识别（医学、法律、金融专有名词）
✅ 特定任务的准确率要求极高（如合同信息提取）
✅ 不适合放入上下文的隐式知识（如"我们的 API 叫什么名字"）

RAG 更合适：
✅ 知识会频繁更新（产品文档、新闻）
✅ 知识量大（几千篇文档）
✅ 需要给出具体信息来源
✅ 成本限制（微调有训练费用）
```

## 2. OpenAI Fine-tuning（最简路径）

### 准备训练数据

数据格式为 JSONL，每行一条对话：

```python

training_data = [

        ]
    },
    {
        "messages": [
            {"role": "system", "content": "你是企业客服助手小智，专业友好，回复简洁"},
            {"role": "user", "content": "产品有质量问题怎么办？"},
            {"role": "assistant", "content": "非常抱歉给您带来不便 🙏 如遇质量问题，请在收货后 7 天内联系我们，提供订单号和问题照片，我们将为您安排退换货。请问您方便提供相关信息吗？"},

# 保存为 JSONL
with open("training_data.jsonl", "w", encoding="utf-8") as f:
    for item in training_data:
        f.write(json.dumps(item, ensure_ascii=False) + "\n")
```

### 上传并启动微调

```python
from openai import OpenAI
import time

client = OpenAI()

# 1. 上传文件
with open("training_data.jsonl", "rb") as f:
    upload_response = client.files.create(file=f, purpose="fine-tune")

file_id = upload_response.id
print(f"文件 ID: {file_id}")

# 2. 创建微调任务
ft_job = client.fine_tuning.jobs.create(
    training_file=file_id,
    model="gpt-4o-mini-2024-07-18",  # 比 gpt-4o 便宜得多
    hyperparameters={
        "n_epochs": 3,           # 训练轮数
        "batch_size": "auto",    # 批大小
        "learning_rate_multiplier": "auto",
    },
)

print(f"微调任务 ID: {ft_job.id}")

# 3. 等待完成
while True:
    job = client.fine_tuning.jobs.retrieve(ft_job.id)
    print(f"状态: {job.status}")
    
    if job.status in ("succeeded", "failed"):
        break
    
    time.sleep(30)

if job.status == "succeeded":
    model_id = job.fine_tuned_model  # 微调后的模型 ID
    print(f"微调完成！模型 ID: {model_id}")
```

## 3. 本地 LoRA 微调（低成本）

LoRA（Low-Rank Adaptation）只训练少量参数，显存占用 1/10，效果接近全量微调。

```bash
pip install transformers peft datasets accelerate bitsandbytes
```

### 数据准备

```python
from datasets import Dataset

# 格式化为 instruction-tuning 格式
def format_data(examples):
    texts = []
    for instruction, input_text, output in zip(
        examples["instruction"],
        examples.get("input", [""] * len(examples["instruction"])),
        examples["output"]
    ):
        if input_text:
            text = f"### 指令:\n{instruction}\n\n### 输入:\n{input_text}\n\n### 回答:\n{output}"
        else:
            text = f"### 指令:\n{instruction}\n\n### 回答:\n{output}"
        texts.append(text)
    return {"text": texts}

# 加载数据
raw_data = [
    {"instruction": "将以下句子翻译成英文", "input": "我喜欢学习 AI", "output": "I enjoy learning AI"},
    # ... 更多数据
]

dataset = Dataset.from_list(raw_data).map(format_data, batched=True)
```

### LoRA 微调核心代码

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig, get_peft_model, TaskType
from trl import SFTTrainer

# 加载基础模型（用 4-bit 量化减少显存）
model_name = "Qwen/Qwen2.5-1.5B-Instruct"  # 1.5B 参数，消费级显卡可跑

tokenizer = AutoTokenizer.from_pretrained(model_name)

model = AutoModelForCausalLM.from_pretrained(
    model_name,
    load_in_4bit=True,      # 4-bit 量化，显存减少 4 倍
    device_map="auto",      # 自动分配 GPU/CPU
    torch_dtype=torch.float16,
)

# LoRA 配置
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=16,               # LoRA 秩，越大参数越多精度越高
    lora_alpha=32,      # 缩放系数，通常是 r 的 2 倍
    lora_dropout=0.05,
    target_modules=[
        "q_proj", "v_proj",  # 对 attention 层应用 LoRA
        "k_proj", "o_proj",
        "gate_proj", "up_proj", "down_proj",
    ],
)

model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
# 可训练参数：约 1%（远少于全量微调）

# 训练配置
training_args = TrainingArguments(
    output_dir="./lora_model",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,   # 等效批大小 = 4*4 = 16
    learning_rate=2e-4,
    fp16=True,
    logging_steps=10,
    save_strategy="epoch",
    warmup_ratio=0.05,
)

# 开始训练
trainer = SFTTrainer(
    model=model,
    tokenizer=tokenizer,
    train_dataset=dataset,
    dataset_text_field="text",
    max_seq_length=2048,
    args=training_args,
)

trainer.train()
trainer.save_model("./lora_output")
```

### 合并 LoRA 权重并推理

```python
from peft import PeftModel

# 加载基础模型 + LoRA 权重
base_model = AutoModelForCausalLM.from_pretrained(model_name, torch_dtype=torch.float16)
model = PeftModel.from_pretrained(base_model, "./lora_output")

# 合并权重（可选，合并后能加速推理）
model = model.merge_and_unload()
model.save_pretrained("./merged_model")

# 推理
inputs = tokenizer("### 指令:\n将以下句子翻译成英文\n\n### 输入:\n今天天气真好\n\n### 回答:\n", 
                   return_tensors="pt")
outputs = model.generate(**inputs, max_new_tokens=100)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

## 5. 成本估算

| 方式 | 训练成本 | 推理成本 | 适用数据量 |
|------|---------|---------|----------|
| OpenAI Fine-tuning | $0.025/1K tokens | 约 2x 原价 | 数百条起 |
| 本地 LoRA (7B) | 显卡耗电约 2-5 小时 | 近乎零 | 数千条 |
| 本地 LoRA (1.5B) | 显卡耗电约 30 分钟 | 近乎零 | 数百条 |
| 第三方云微调 | $10-100 | 按 token 计 | 数千条 |
