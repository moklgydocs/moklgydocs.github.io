# 第五阶段：业务落地

**目标**：把前四阶段的技术能力，落到公司真实业务中，交付有实际价值的 AI 产品。

## 本阶段逻辑

前四阶段解决的是"能不能做到"，本阶段解决的是"在真实工作环境里怎么做到"：

- RAG 做到 90% 准确率 → 如何把企业 Confluence 文档变成可问答的知识库？
- LangGraph 实现 Agent → 如何做成一个 24 小时在线的客服机器人？
- Text2SQL 跑通 → 如何让业务同学直接问数据，不再等数据团队拉表？

## 业务场景选型决策

```
用户有具体问题要问？
  ↓
来自知识文档？ → 是 → 企业知识库
来自数据库？   → 是 → 数据分析助手
来自外部用户？ → 是 → 智能客服系统

用户要生成内容/代码？
  ↓
面向研发团队？ → 研发辅助工具

需要接入现有 IM 工具（钉钉/企微）？
  → 系统集成最佳实践
```
