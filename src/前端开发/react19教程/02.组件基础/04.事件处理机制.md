# 事件处理机制

## 学习目标

- 掌握 React 事件绑定的正确方式
- 理解合成事件系统的原理
- 学会处理表单事件
- 避开事件处理中的常见陷阱

## 基本事件绑定

### React 事件 vs DOM 事件

```jsx
// HTML 原生事件
<button onclick="handleClick()">点击</button>

// React 事件
<button onClick={handleClick}>点击</button>
```

区别：
- 命名：`onclick` → `onClick`（camelCase）
- 值：字符串 → 函数引用
- 行为：React 事件是**合成事件**（SyntheticEvent），不是原生 DOM 事件

### 常用事件

```jsx
function EventShowcase() {
  return (
    <div>
      {/* 鼠标事件 */}
      <button onClick={handleClick}>点击</button>
      <div onMouseEnter={handleEnter} onMouseLeave={handleLeave}>悬浮区域</div>
      
      {/* 键盘事件 */}
      <input onKeyDown={handleKeyDown} onKeyUp={handleKeyUp} />
      
      {/* 表单事件 */}
      <input onChange={handleChange} onFocus={handleFocus} onBlur={handleBlur} />
      <form onSubmit={handleSubmit}>...</form>
      
      {/* 滚动事件 */}
      <div onScroll={handleScroll}>长内容...</div>
      
      {/* 剪贴板事件 */}
      <input onCopy={handleCopy} onPaste={handlePaste} />
    </div>
  );
}
```

## 事件处理函数的写法

### 方式一：直接定义函数

```jsx
function App() {
  const handleClick = () => {
    console.log('按钮被点击');
  };
  
  return <button onClick={handleClick}>点击</button>;
}
```

### 方式二：内联箭头函数（需要传参时）

```jsx
function App() {
  const handleDelete = (id) => {
    console.log('删除', id);
  };
  
  return (
    <div>
      {/* ✅ 内联箭头函数包裹，传递参数 */}
      <button onClick={() => handleDelete(1)}>删除 1</button>
      <button onClick={() => handleDelete(2)}>删除 2</button>
    </div>
  );
}
```

### 常见错误

```jsx
// ❌ 错误：直接调用函数，会在渲染时立即执行！
<button onClick={handleClick()}>点击</button>

// ✅ 正确：传递函数引用
<button onClick={handleClick}>点击</button>

// ✅ 正确：用箭头函数包裹
<button onClick={() => handleClick()}>点击</button>
```

> 🔬 **原理**：`handleClick()` 加了括号就是**调用**函数，它会在 JSX 渲染时执行，返回值（通常是 `undefined`）被赋给 onClick。而 `handleClick` 不加括号是**引用**，React 会在点击时调用它。

## 事件对象（Event）

```jsx
function Form() {
  const handleChange = (event) => {
    // event 是 React 的合成事件对象
    console.log(event.target.value);  // 输入框的当前值
    console.log(event.target.name);   // 输入框的 name 属性
    console.log(event.type);          // 事件类型，如 "change"
  };

  const handleSubmit = (event) => {
    event.preventDefault();  // 阻止表单默认提交行为
    console.log('表单提交');
  };

  const handleLinkClick = (event) => {
    event.stopPropagation();  // 阻止事件冒泡
    console.log('链接被点击');
  };

  return (
    <form onSubmit={handleSubmit}>
      <input name="username" onChange={handleChange} />
      <a href="/page" onClick={handleLinkClick}>链接</a>
      <button type="submit">提交</button>
    </form>
  );
}
```

### 同时传参和 event

```jsx
function TodoList({ todos }) {
  const handleToggle = (id, event) => {
    console.log('切换', id, event);
  };

  return (
    <ul>
      {todos.map(todo => (
        <li key={todo.id}>
          {/* event 会作为最后一个参数自动传入 */}
          <input
            type="checkbox"
            onChange={(e) => handleToggle(todo.id, e)}
          />
          {todo.text}
        </li>
      ))}
    </ul>
  );
}
```

## 表单处理

### 受控组件（Controlled Component）

输入框的值完全由 React 状态控制：

```jsx
function LoginForm() {
  const [formData, setFormData] = useState({
    username: '',
    password: '',
  });

  const handleChange = (e) => {
    const { name, value } = e.target;
    setFormData(prev => ({
      ...prev,      // 保留其他字段
      [name]: value // 更新当前字段
    }));
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log('提交数据:', formData);
    // 调用登录 API...
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        name="username"
        value={formData.username}
        onChange={handleChange}
        placeholder="用户名"
      />
      <input
        name="password"
        type="password"
        value={formData.password}
        onChange={handleChange}
        placeholder="密码"
      />
      <button type="submit">登录</button>
    </form>
  );
}
```

> 💡 **重点**：`value` + `onChange` 的组合就是受控组件的标志。React 状态是「唯一数据源」（Single Source of Truth），输入框只是状态的「映射」。

### 非受控组件（Uncontrolled Component）

用 `ref` 直接读取 DOM 值：

```jsx
import { useRef } from 'react';

function SimpleForm() {
  const inputRef = useRef(null);

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log('输入值:', inputRef.current.value);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input ref={inputRef} defaultValue="默认值" />
      <button type="submit">提交</button>
    </form>
  );
}
```

### 受控 vs 非受控

| 特性 | 受控组件 | 非受控组件 |
|------|----------|------------|
| 数据源 | React state | DOM 自身 |
| 实时访问值 | ✅ 随时可用 | ❌ 需要通过 ref 获取 |
| 实时验证 | ✅ 输入时即可验证 | ❌ 提交时才能获取值 |
| 动态控制 | ✅ 可以程序化控制输入 | ❌ 难以控制 |
| 代码量 | 较多 | 较少 |
| 适用场景 | 需要实时验证、联动 | 简单表单、文件上传 |

> 💡 **实战建议**：90% 的情况用受控组件。只有简单的、不需要实时交互的表单才考虑非受控组件。React 19 的新 API 会进一步简化表单处理，我们会在 [React 19 新特性](../04.React19新特性/02.useActionState与表单.md) 中讲到。

## 合成事件系统

> 🔬 **原理解析**

React 并不直接在每个 DOM 元素上绑定事件监听器。而是使用**事件委托**：

```
所有事件 → 统一绑定在 root 容器上 → React 根据 event.target 分发到对应组件
```

这样做的好处：
1. **性能**：减少事件监听器数量
2. **一致性**：屏蔽浏览器差异
3. **控制力**：React 可以控制事件的触发时机（如批量更新）

合成事件（SyntheticEvent）的特点：
- 跨浏览器兼容
- 接口与原生事件一致
- 通过 `event.nativeEvent` 可获取原生事件对象

## 实战案例：搜索组件

```jsx
import { useState, useCallback } from 'react';

function SearchBox({ onSearch }) {
  const [query, setQuery] = useState('');

  const handleChange = (e) => {
    setQuery(e.target.value);
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    if (query.trim()) {
      onSearch(query.trim());
    }
  };

  const handleKeyDown = (e) => {
    if (e.key === 'Escape') {
      setQuery('');
    }
  };

  const handleClear = () => {
    setQuery('');
  };

  return (
    <form onSubmit={handleSubmit} style={{ display: 'flex', gap: '8px' }}>
      <div style={{ position: 'relative', flex: 1 }}>
        <input
          value={query}
          onChange={handleChange}
          onKeyDown={handleKeyDown}
          placeholder="搜索..."
          style={{ width: '100%', padding: '8px 32px 8px 8px' }}
        />
        {query && (
          <button
            type="button"
            onClick={handleClear}
            style={{
              position: 'absolute', right: '8px', top: '50%',
              transform: 'translateY(-50%)', border: 'none',
              cursor: 'pointer', background: 'none'
            }}
          >
            ✕
          </button>
        )}
      </div>
      <button type="submit">🔍 搜索</button>
    </form>
  );
}
```
