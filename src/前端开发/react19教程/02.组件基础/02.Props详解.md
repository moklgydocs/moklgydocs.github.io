# Props 详解：组件之间的数据传递

## 学习目标

- 理解 Props 是什么，为什么需要 Props
- 掌握 Props 的各种传递方式
- 理解 Props 的只读性和单向数据流
- 学会用 children 实现内容插槽

## Props 是什么？

Props（Properties 的缩写）是父组件传递给子组件的数据。你可以把它想象成**函数的参数**——事实上它就是函数的参数。

```jsx
// 组件就是函数，Props 就是参数
function Greeting(props) {
  return <h1>你好，{props.name}！</h1>;
}

// 使用组件时传入 Props
<Greeting name="张三" />
```

### 解构写法（推荐）

直接解构 props 参数，代码更简洁：

```jsx
function Greeting({ name, age }) {
  return (
    <div>
      <h1>你好，{name}！</h1>
      <p>你今年 {age} 岁</p>
    </div>
  );
}

<Greeting name="张三" age={25} />
```

## Props 的各种类型

```jsx
function Demo({
  // 字符串
  title,           // <Demo title="hello" />
  
  // 数字
  count,           // <Demo count={42} />
  
  // 布尔值
  isActive,        // <Demo isActive={true} /> 或 <Demo isActive />
  
  // 数组
  items,           // <Demo items={[1, 2, 3]} />
  
  // 对象
  user,            // <Demo user={{ name: '张三', age: 25 }} />
  
  // 函数
  onClick,         // <Demo onClick={() => console.log('clicked')} />
  
  // JSX / 组件
  icon,            // <Demo icon={<StarIcon />} />
}) {
  return <div>...</div>;
}
```

> 💡 **注意**：字符串可以直接用引号，其他所有类型都要用 `{}` 包裹。

## 默认值

```jsx
// 方式一：解构时设置默认值（推荐）
function Button({ text = '按钮', size = 'medium', variant = 'primary' }) {
  return <button className={`btn btn-${size} btn-${variant}`}>{text}</button>;
}

// 这些用法都合法
<Button />                          // 全用默认值
<Button text="提交" />              // 只覆盖 text
<Button text="取消" variant="secondary" />  // 覆盖部分
```

## Props 是只读的！

这是 React 的铁律：**子组件不能修改 Props**。

```jsx
function BadComponent({ count }) {
  // ❌ 永远不要这样做！
  count = count + 1;  // 直接修改 props
  
  return <p>{count}</p>;
}

function GoodComponent({ count, onIncrement }) {
  // ✅ 通过回调函数通知父组件修改
  return (
    <div>
      <p>{count}</p>
      <button onClick={onIncrement}>+1</button>
    </div>
  );
}
```

> 🔬 **原理**：Props 的只读性保证了**单向数据流**。数据只能从上往下流，如果子组件需要「改变」数据，它要通过**回调函数**告诉父组件去改。这样数据的变化就是可追踪、可预测的。

### 回调函数：子传父的桥梁

```jsx
// 父组件
function Parent() {
  const [count, setCount] = useState(0);
  
  return (
    <div>
      <p>父组件的 count: {count}</p>
      {/* 把修改函数传给子组件 */}
      <Child count={count} onIncrement={() => setCount(count + 1)} />
    </div>
  );
}

// 子组件
function Child({ count, onIncrement }) {
  return (
    <div>
      <p>子组件收到的 count: {count}</p>
      <button onClick={onIncrement}>让父组件 +1</button>
    </div>
  );
}
```

数据流动方向：

```
Father ──(count)──→ Child     （数据向下）
Father ←──(onIncrement)── Child（事件向上）
```

> ⚠️ **教训**：有些新手会想通过 `props.xxx = newValue` 来「更新」父组件的数据。这不会工作，还会导致难以追踪的 Bug。**永远通过回调函数来沟通**。

## children：特殊的 Props

`children` 是一个特殊的 prop，它代表组件**标签之间**的内容：

```jsx
function Card({ children, title }) {
  return (
    <div className="card">
      <div className="card-header">{title}</div>
      <div className="card-body">
        {children}  {/* 这里会渲染标签之间的内容 */}
      </div>
    </div>
  );
}

// 使用
<Card title="用户信息">
  <p>姓名：张三</p>
  <p>年龄：25</p>
  <img src="/avatar.png" />
</Card>

<Card title="操作面板">
  <button>编辑</button>
  <button>删除</button>
</Card>
```

> 💡 **children 的妙用**：children 让组件变成了一个「容器」，类似于 Vue 中的 `<slot>`。这是 React 中实现**组合**（Composition）的核心方式。

### children 的类型

children 可以是任何东西：

```jsx
// 文本
<Wrapper>Hello</Wrapper>

// JSX 元素
<Wrapper><p>段落</p></Wrapper>

// 多个元素
<Wrapper>
  <Header />
  <Content />
  <Footer />
</Wrapper>

// 甚至是函数（Render Props 模式）
<DataProvider>
  {(data) => <div>{data.name}</div>}
</DataProvider>
```

## 展开运算符传递 Props

当你有一个对象，想把它的所有属性作为 Props 传递时：

```jsx
const buttonProps = {
  type: 'submit',
  disabled: false,
  className: 'btn-primary',
  onClick: handleClick,
};

// 等价于 <Button type="submit" disabled={false} className="btn-primary" onClick={handleClick} />
<Button {...buttonProps} />
```

> ⚠️ **注意**：展开传递虽然方便，但要小心不要传入多余的属性。如果不确定对象里有什么，可能会产生预料之外的行为。

## 实战案例：可配置的按钮组件

```jsx
function Button({ 
  children, 
  variant = 'primary',    // primary | secondary | danger
  size = 'medium',        // small | medium | large
  disabled = false,
  loading = false,
  icon = null,
  onClick,
}) {
  const sizeMap = { small: '12px', medium: '14px', large: '16px' };
  const colorMap = {
    primary: { bg: '#1890ff', text: '#fff' },
    secondary: { bg: '#f0f0f0', text: '#333' },
    danger: { bg: '#ff4d4f', text: '#fff' },
  };

  const colors = colorMap[variant];

  return (
    <button
      onClick={onClick}
      disabled={disabled || loading}
      style={{
        backgroundColor: disabled ? '#d9d9d9' : colors.bg,
        color: disabled ? '#999' : colors.text,
        fontSize: sizeMap[size],
        padding: size === 'small' ? '4px 8px' : size === 'large' ? '12px 24px' : '8px 16px',
        border: 'none',
        borderRadius: '6px',
        cursor: disabled ? 'not-allowed' : 'pointer',
        display: 'inline-flex',
        alignItems: 'center',
        gap: '6px',
      }}
    >
      {loading ? '⏳' : icon}
      {children}
    </button>
  );
}

// 各种用法
<Button>默认按钮</Button>
<Button variant="danger" icon="🗑️">删除</Button>
<Button size="large" loading>提交中...</Button>
<Button variant="secondary" disabled>不可用</Button>
```

## Props 设计原则

| 原则 | 说明 |
|------|------|
| **简洁** | Props 数量不要太多，超过 5 个考虑用对象合并 |
| **语义化** | 命名要表达意图：`onSubmit` 而不是 `fn` |
| **合理默认值** | 让组件在最少配置下就能工作 |
| **单一职责** | 一个 prop 只做一件事 |
| **一致性** | 类似的 prop 在不同组件中保持相同的命名和行为 |
