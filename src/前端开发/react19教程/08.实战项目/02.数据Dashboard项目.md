# 数据 Dashboard 项目

## 项目概述

构建一个数据看板应用，综合运用进阶技能：

- 异步数据获取（自定义 Hook）
- 多组件状态共享（Context）
- 性能优化（React.memo、useMemo）
- 错误处理（Error Boundary）
- React 19 新特性（Suspense、use）

## 架构设计

```
Dashboard
├── Header            → 用户信息 + 日期选择
├── StatCards         → 关键指标卡片（4个）
│   └── StatCard      → 单个指标卡片
├── ChartSection      → 图表区域
│   ├── LineChart     → 趋势图
│   └── PieChart      → 占比图
├── DataTable         → 数据表格
│   ├── TableHeader
│   ├── TableRow
│   └── Pagination
└── ErrorBoundary     → 容错边界
```

## 核心实现思路

### 数据层：自定义 Hook

```tsx
// useApiData.ts
function useApiData<T>(url: string) {
  const [data, setData] = useState<T | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  const fetchData = useCallback(async () => {
    setLoading(true);
    setError(null);
    try {
      const res = await fetch(url);
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      const json = await res.json();
      setData(json);
    } catch (err) {
      setError(err instanceof Error ? err.message : '未知错误');
    } finally {
      setLoading(false);
    }
  }, [url]);

  useEffect(() => { fetchData(); }, [fetchData]);

  return { data, loading, error, refetch: fetchData };
}
```

### 组件层：StatCard 带骨架屏

```tsx
function StatCard({ title, value, loading, trend }) {
  if (loading) {
    return (
      <div className="stat-card skeleton">
        <div className="skeleton-line" style={{ width: '60%' }} />
        <div className="skeleton-line" style={{ width: '40%', height: '32px' }} />
      </div>
    );
  }

  return (
    <div className="stat-card">
      <h3>{title}</h3>
      <p className="value">{value}</p>
      <span className={`trend ${trend > 0 ? 'up' : 'down'}`}>
        {trend > 0 ? '📈' : '📉'} {Math.abs(trend)}%
      </span>
    </div>
  );
}
```

### 容错层：局部错误边界

```tsx
function Dashboard() {
  return (
    <div className="dashboard">
      <Header />
      <ErrorBoundary fallback={<p>指标数据加载失败</p>}>
        <StatCards />
      </ErrorBoundary>
      <ErrorBoundary fallback={<p>图表加载失败</p>}>
        <Suspense fallback={<ChartSkeleton />}>
          <ChartSection />
        </Suspense>
      </ErrorBoundary>
      <ErrorBoundary fallback={<p>表格加载失败</p>}>
        <DataTable />
      </ErrorBoundary>
    </div>
  );
}
```
