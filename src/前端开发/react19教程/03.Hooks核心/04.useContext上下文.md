# useContext 上下文

## 学习目标

- 理解 Context 解决了什么问题
- 掌握 Context 的创建和使用
- 知道 Context 的性能问题及解决方案
- 理解 React 19 中 Context 的变化

## Context 解决什么问题？

**Props Drilling（属性透传）**——当深层组件需要数据时，只能一层一层传递 Props：

```jsx
// ❌ Props Drilling：theme 要经过 3 层才能到达 Button
function App() {
  const [theme, setTheme] = useState('dark');
  return <Layout theme={theme}><Page theme={theme}><Button theme={theme} /></Page></Layout>;
}
```

Context 让你**跨越组件层级直接传递数据**。

## 三步使用 Context

### 第一步：创建 Context

```jsx
// ThemeContext.js
import { createContext } from 'react';

export const ThemeContext = createContext('light'); // 默认值
```

### 第二步：在顶层提供 Context

```jsx
import { ThemeContext } from './ThemeContext';

function App() {
  const [theme, setTheme] = useState('dark');

  return (
    // 用 Provider 包裹，value 就是要共享的值
    <ThemeContext.Provider value={theme}>
      <Layout />  {/* 不需要传 theme prop 了！*/}
    </ThemeContext.Provider>
  );
}
```

### 第三步：在任意深层组件中消费

```jsx
import { useContext } from 'react';
import { ThemeContext } from './ThemeContext';

function Button() {
  const theme = useContext(ThemeContext); // 直接获取！
  
  return (
    <button className={`btn-${theme}`}>
      当前主题: {theme}
    </button>
  );
}
```

## 实战案例：主题切换系统

```jsx
// ThemeContext.jsx
import { createContext, useContext, useState } from 'react';

const ThemeContext = createContext(null);

// 自定义 Provider 组件
export function ThemeProvider({ children }) {
  const [theme, setTheme] = useState('light');
  
  const toggleTheme = () => {
    setTheme(prev => prev === 'light' ? 'dark' : 'light');
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

// 自定义 Hook（推荐做法）
export function useTheme() {
  const context = useContext(ThemeContext);
  if (!context) {
    throw new Error('useTheme 必须在 ThemeProvider 内使用');
  }
  return context;
}
```

```jsx
// App.jsx
import { ThemeProvider } from './ThemeContext';

function App() {
  return (
    <ThemeProvider>
      <Header />
      <MainContent />
    </ThemeProvider>
  );
}

// 任何深层组件
function ThemeToggle() {
  const { theme, toggleTheme } = useTheme();
  return (
    <button onClick={toggleTheme}>
      {theme === 'light' ? '🌙 切换暗色' : '☀️ 切换亮色'}
    </button>
  );
}
```

> 💡 **最佳实践**：
> 1. 把 Context、Provider 和自定义 Hook 放在同一个文件中
> 2. 导出自定义 Hook 而不是 Context 对象
> 3. 在 Hook 中加入错误检查

## Context 适合放什么？

| ✅ 适合 | ❌ 不适合 |
|---------|----------|
| 主题（theme） | 频繁变化的数据（如输入框值） |
| 当前用户信息 | 大量数据（如商品列表） |
| 语言/国际化 | 局部状态（只在几个组件间共享） |
| 权限配置 | 需要高性能更新的数据 |

## Context 的性能问题

> ⚠️ **重要**：Context 值变化时，**所有使用该 Context 的组件都会重渲染**，不管它们是否用到了变化的那部分数据。

```jsx
// ❌ 性能问题：theme 或 user 任一变化，所有消费者都重渲染
<AppContext.Provider value={{ theme, user, settings }}>
  <App />
</AppContext.Provider>

// ✅ 拆分成独立的 Context
<ThemeContext.Provider value={theme}>
  <UserContext.Provider value={user}>
    <SettingsContext.Provider value={settings}>
      <App />
    </SettingsContext.Provider>
  </UserContext.Provider>
</ThemeContext.Provider>
```

## React 19 中的 Context 变化

React 19 中 `use()` 函数可以替代 `useContext()`：

```jsx
import { use } from 'react';

function Button() {
  // React 19 新方式
  const theme = use(ThemeContext);
  
  // 等价于
  // const theme = useContext(ThemeContext);
  
  return <button className={`btn-${theme}`}>按钮</button>;
}
```

`use()` 的优势是它可以在条件语句中使用（useContext 不行），我们会在 [React 19 新特性](../04.React19新特性/03.use函数与Promise.md) 中详细讲解。
