# useRef 引用操作

## 学习目标

- 理解 useRef 的两大用途：DOM 引用和持久化值
- 知道 useRef 和 useState 的本质区别
- 掌握 React 19 中 ref 的新用法

## useRef 是什么？

`useRef` 返回一个**可变的引用对象**，这个对象有一个 `.current` 属性：

```jsx
const ref = useRef(initialValue);
// ref = { current: initialValue }

// 修改值
ref.current = newValue;
// 读取值
console.log(ref.current);
```

**关键特性**：修改 `ref.current` **不会触发重新渲染**。

## 用途一：引用 DOM 元素

```jsx
function TextInput() {
  const inputRef = useRef(null);

  const handleFocus = () => {
    inputRef.current.focus(); // 直接操作 DOM
  };

  const handleSelect = () => {
    inputRef.current.select(); // 选中文本
  };

  return (
    <div>
      <input ref={inputRef} defaultValue="Hello" />
      <button onClick={handleFocus}>聚焦</button>
      <button onClick={handleSelect}>全选</button>
    </div>
  );
}
```

### 常见 DOM 操作场景

```jsx
function VideoPlayer() {
  const videoRef = useRef(null);

  return (
    <div>
      <video ref={videoRef} src="/video.mp4" />
      <button onClick={() => videoRef.current.play()}>播放</button>
      <button onClick={() => videoRef.current.pause()}>暂停</button>
    </div>
  );
}

function ScrollToTop() {
  const topRef = useRef(null);
  
  const scrollToTop = () => {
    topRef.current.scrollIntoView({ behavior: 'smooth' });
  };
  
  return (
    <div>
      <div ref={topRef} /> {/* 锚点 */}
      {/* 长内容... */}
      <button onClick={scrollToTop}>回到顶部</button>
    </div>
  );
}

function AutoResizeTextarea() {
  const textareaRef = useRef(null);
  
  const handleInput = () => {
    const el = textareaRef.current;
    el.style.height = 'auto';
    el.style.height = el.scrollHeight + 'px';
  };

  return (
    <textarea 
      ref={textareaRef}
      onInput={handleInput}
      placeholder="自动调整高度..."
    />
  );
}
```

## 用途二：保存不需要触发渲染的值

当你需要在多次渲染之间保存某个值，但又不想因为修改它而导致重渲染：

```jsx
function StopWatch() {
  const [time, setTime] = useState(0);
  const [isRunning, setIsRunning] = useState(false);
  const timerRef = useRef(null); // 存储定时器 ID

  const start = () => {
    setIsRunning(true);
    timerRef.current = setInterval(() => {
      setTime(t => t + 10);
    }, 10);
  };

  const stop = () => {
    setIsRunning(false);
    clearInterval(timerRef.current); // 用 ref 取到定时器 ID
  };

  const reset = () => {
    stop();
    setTime(0);
  };

  return (
    <div>
      <p>{(time / 1000).toFixed(2)} 秒</p>
      {isRunning ? (
        <button onClick={stop}>停止</button>
      ) : (
        <button onClick={start}>开始</button>
      )}
      <button onClick={reset}>重置</button>
    </div>
  );
}
```

### 为什么定时器 ID 用 useRef 而不是 useState？

因为定时器 ID 是一个「后台标识符」，我们只需要在清除定时器时用到它，不需要显示在 UI 上。如果用 useState，每次设置都会触发不必要的重渲染。

## useRef vs useState

| 特性 | useRef | useState |
|------|--------|----------|
| 修改是否触发渲染 | ❌ 不会 | ✅ 会 |
| 值在渲染间保持 | ✅ | ✅ |
| 修改时机 | 随时可改 | 需要通过 setter |
| 当前值访问 | 同步（`.current` 永远是最新值） | 异步快照（可能是旧值） |
| 适用场景 | DOM 引用、定时器 ID、上一次的值 | 需要驱动 UI 的数据 |

## 经典用法：保存上一次的值

```jsx
function usePrevious(value) {
  const ref = useRef();
  
  useEffect(() => {
    ref.current = value;
  }, [value]);
  
  return ref.current; // 返回更新前的值
}

// 使用
function Counter() {
  const [count, setCount] = useState(0);
  const prevCount = usePrevious(count);

  return (
    <div>
      <p>当前值: {count}</p>
      <p>上一次: {prevCount}</p>
      <button onClick={() => setCount(c => c + 1)}>+1</button>
    </div>
  );
}
```

## React 19：ref 作为 prop

在 React 19 之前，如果要把 ref 传给子组件，需要用 `forwardRef`：

```jsx
// React 18 及之前：必须用 forwardRef
const FancyInput = forwardRef((props, ref) => {
  return <input ref={ref} className="fancy" {...props} />;
});

// React 19：ref 可以直接作为 prop
function FancyInput({ ref, ...props }) {
  return <input ref={ref} className="fancy" {...props} />;
}

// 使用方式不变
function Parent() {
  const inputRef = useRef(null);
  return <FancyInput ref={inputRef} placeholder="新方式" />;
}
```

> 💡 **React 19 的改进**：`forwardRef` 不再是必需的了！ref 现在可以像普通 prop 一样传递。这大大简化了组件封装。

## ⚠️ 注意事项

```jsx
// ❌ 不要在渲染期间读写 ref
function Bad() {
  const ref = useRef(0);
  ref.current += 1; // 在渲染时修改 ref
  return <p>{ref.current}</p>; // 在渲染时读取 ref
}

// ✅ 在事件处理或 useEffect 中操作 ref
function Good() {
  const ref = useRef(0);
  
  const handleClick = () => {
    ref.current += 1;
    console.log(ref.current);
  };
  
  return <button onClick={handleClick}>点击</button>;
}
```
