# useOptimistic：让 UI 快如闪电

## 学习目标

- 理解什么是乐观更新及其应用场景
- 掌握 useOptimistic 的用法
- 知道乐观更新的回滚机制

## 什么是乐观更新？

**乐观更新**是一种 UI 模式：在异步操作完成之前，先假设操作会成功，立即更新 UI。如果失败，再回滚。

最典型的例子：点赞。

```
传统方式（悲观）：
点击 → 等待请求完成（1秒）→ UI 更新
❌ 用户体验差：感觉卡顿

乐观更新：
点击 → UI 立即更新 → 请求在后台执行
✅ 用户体验好：感觉瞬间完成
```

## useOptimistic 基本用法

```jsx
import { useOptimistic } from 'react';

function LikeButton({ initialCount, postId }) {
  const [count, setCount] = useState(initialCount);
  const [optimisticCount, setOptimisticCount] = useOptimistic(count);

  const handleLike = async () => {
    setOptimisticCount(prev => prev + 1); // 立即更新 UI
    
    try {
      const newCount = await likePost(postId); // 发请求
      setCount(newCount); // 用真实数据更新
    } catch (error) {
      // 失败时自动回滚到 count 的值
      alert('点赞失败，请重试');
    }
  };

  return (
    <button onClick={handleLike}>
      ❤️ {optimisticCount}
    </button>
  );
}
```

## 配合 Actions 使用

```jsx
function TodoItem({ todo, updateTodo }) {
  const [optimisticTodo, setOptimisticTodo] = useOptimistic(todo);

  const toggleDone = async (formData) => {
    const newTodo = { ...todo, done: !todo.done };
    setOptimisticTodo(newTodo); // 乐观更新
    await updateTodo(newTodo);  // 实际请求
  };

  return (
    <form action={toggleDone}>
      <label style={{ 
        textDecoration: optimisticTodo.done ? 'line-through' : 'none',
        opacity: optimisticTodo !== todo ? 0.7 : 1 // 乐观状态用半透明提示
      }}>
        <input type="checkbox" checked={optimisticTodo.done} readOnly />
        {optimisticTodo.text}
        {optimisticTodo !== todo && ' (保存中...)'}
      </label>
      <button type="submit">切换</button>
    </form>
  );
}
```

## 实战场景：聊天消息发送

```jsx
function Chat() {
  const [messages, setMessages] = useState([]);
  const [optimisticMessages, addOptimisticMessage] = useOptimistic(
    messages,
    (currentMessages, newMessage) => [
      ...currentMessages,
      { ...newMessage, sending: true } // 标记为发送中
    ]
  );

  const sendMessage = async (formData) => {
    const text = formData.get('message');
    const tempMessage = { id: Date.now(), text, sending: true };
    
    addOptimisticMessage(tempMessage);
    
    const savedMessage = await sendToServer(text);
    setMessages(prev => [...prev, savedMessage]);
  };

  return (
    <div>
      <div className="messages">
        {optimisticMessages.map(msg => (
          <div key={msg.id} style={{ opacity: msg.sending ? 0.6 : 1 }}>
            {msg.text}
            {msg.sending && <span> ⏳</span>}
          </div>
        ))}
      </div>
      <form action={sendMessage}>
        <input name="message" placeholder="输入消息..." />
        <button type="submit">发送</button>
      </form>
    </div>
  );
}
```

## 乐观更新的注意事项

| 适合乐观更新 | 不适合乐观更新 |
|-------------|--------------|
| 点赞/收藏 | 支付/转账 |
| 切换完成状态 | 删除重要数据 |
| 发送消息 | 修改权限 |
| 表单保存 | 不可逆操作 |

> ⚠️ **教训**：不要对不可逆操作做乐观更新！我曾在项目中对「删除」操作做了乐观更新，结果服务器偶尔失败，用户看到项目消失又出现，体验非常糟糕。
