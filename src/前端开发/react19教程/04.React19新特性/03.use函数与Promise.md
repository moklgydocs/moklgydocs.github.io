# use() 函数：全新的数据读取方式

## 学习目标

- 理解 `use()` 函数的作用和限制
- 掌握用 `use()` 读取 Promise 和 Context
- 理解与 Suspense 组件的配合

## use() 是什么？

`use()` 是 React 19 引入的新 API，可以在组件中**直接读取 Promise 的值**：

```jsx
import { use, Suspense } from 'react';

function UserProfile({ userPromise }) {
  // use() 会「暂停」组件渲染，等 Promise 完成后继续
  const user = use(userPromise);
  
  return <div>{user.name}</div>;
}

// 配合 Suspense 使用
function App() {
  const userPromise = fetchUser(1); // 返回 Promise
  
  return (
    <Suspense fallback={<p>加载中...</p>}>
      <UserProfile userPromise={userPromise} />
    </Suspense>
  );
}
```

## use() 读取 Context

`use()` 还可以替代 `useContext()`，且有一个重要优势——**可以在条件语句中调用**：

```jsx
import { use } from 'react';

function StatusMessage({ isLoggedIn }) {
  // ✅ use() 可以在条件语句中使用！
  if (isLoggedIn) {
    const user = use(UserContext);
    return <p>欢迎回来，{user.name}！</p>;
  }
  return <p>请登录</p>;
}

// 对比：useContext 不能在条件中使用
function BadExample({ isLoggedIn }) {
  // ❌ 这违反了 Hook 规则
  if (isLoggedIn) {
    const user = useContext(UserContext); // 不能在条件中！
  }
}
```

## use() 与 Suspense 配合

`use()` 读取 Promise 时需要配合 `<Suspense>` 来显示加载状态：

```jsx
// 数据获取函数（注意：Promise 应该在组件外部创建或缓存）
async function fetchTodos() {
  const res = await fetch('/api/todos');
  return res.json();
}

// 在组件外创建 Promise（或在 Action/Event 中创建）
const todosPromise = fetchTodos();

function TodoList() {
  const todos = use(todosPromise); // 读取 Promise
  
  return (
    <ul>
      {todos.map(todo => (
        <li key={todo.id}>{todo.title}</li>
      ))}
    </ul>
  );
}

function App() {
  return (
    <Suspense fallback={<div>📋 加载待办事项...</div>}>
      <TodoList />
    </Suspense>
  );
}
```

> ⚠️ **重要**：不要在组件内部创建 Promise 传给 `use()`，否则每次渲染都会创建新的 Promise：
> ```jsx
> // ❌ 错误：每次渲染都创建新 Promise
> function Bad() {
>   const data = use(fetch('/api/data').then(r => r.json()));
> }
> 
> // ✅ 正确：在组件外部或 useMemo 中创建
> const dataPromise = fetchData();
> function Good() {
>   const data = use(dataPromise);
> }
> ```

## Error Boundary 处理错误

当 `use()` 读取的 Promise 被 reject 时，需要用 Error Boundary 捕获：

```jsx
import { Component } from 'react';

class ErrorBoundary extends Component {
  state = { error: null };
  
  static getDerivedStateFromError(error) {
    return { error };
  }
  
  render() {
    if (this.state.error) {
      return (
        <div className="error">
          <p>出错了：{this.state.error.message}</p>
          <button onClick={() => this.setState({ error: null })}>重试</button>
        </div>
      );
    }
    return this.props.children;
  }
}

// 使用
<ErrorBoundary>
  <Suspense fallback={<Loading />}>
    <DataComponent />
  </Suspense>
</ErrorBoundary>
```

## use() vs useEffect 数据获取

| 特性 | use() + Suspense | useEffect + useState |
|------|-----------------|---------------------|
| 代码量 | 少 | 多（需要管理 loading/error） |
| 加载状态 | Suspense 自动处理 | 手动管理 |
| 渲染时机 | 数据就绪后才渲染 | 先渲染空状态，再更新 |
| SSR 友好 | ✅ | ❌ |
| 适用场景 | 数据加载是必要条件 | 非关键数据、可选加载 |
