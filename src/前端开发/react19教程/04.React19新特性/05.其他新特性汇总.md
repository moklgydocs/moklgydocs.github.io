# React 19 其他新特性汇总

## ref 回调清理函数

React 19 中 ref 回调支持返回清理函数：

```jsx
function MeasuredComponent() {
  return (
    <div ref={(node) => {
      if (node) {
        // 设置：element 挂载时
        const observer = new ResizeObserver(entries => {
          console.log('尺寸变化:', entries[0].contentRect);
        });
        observer.observe(node);
        
        // 清理：element 卸载时自动调用
        return () => observer.disconnect();
      }
    }}>
      内容
    </div>
  );
}
```

## Context 直接作为 Provider

```jsx
// React 18
const ThemeContext = createContext('light');
<ThemeContext.Provider value="dark">...</ThemeContext.Provider>

// React 19：直接用 Context 作为 Provider
<ThemeContext value="dark">...</ThemeContext>
```

## 样式表优先级控制

```jsx
function Component() {
  return (
    <>
      {/* precedence 控制样式表的加载优先级 */}
      <link rel="stylesheet" href="/base.css" precedence="default" />
      <link rel="stylesheet" href="/theme.css" precedence="high" />
      <div>内容</div>
    </>
  );
}
```

## 资源预加载 API

```jsx
import { prefetchDNS, preconnect, preload, preinit } from 'react-dom';

function App() {
  // DNS 预解析
  prefetchDNS('https://api.example.com');
  
  // 预连接
  preconnect('https://cdn.example.com');
  
  // 预加载资源
  preload('/heavy-script.js', { as: 'script' });
  preload('/hero-image.jpg', { as: 'image' });
  
  // 预初始化（加载并执行）
  preinit('/critical.js', { as: 'script' });
  
  return <div>App</div>;
}
```

## 更好的水合错误报告

React 19 改进了 SSR 水合（hydration）不匹配时的错误信息，现在会显示具体差异的 diff 而不是模糊的警告。

## React Compiler（实验性）

React Compiler 是一个编译器插件，可以自动优化你的 React 代码：

- 自动添加 `useMemo` / `useCallback`
- 自动添加 `React.memo`
- 减少不必要的重渲染

```bash
# 安装（实验性）
pnpm add -D babel-plugin-react-compiler
```

> 💡 **趋势**：React 团队的长期目标是让开发者不需要手动进行性能优化。Compiler 会分析你的代码，自动在需要的地方插入缓存逻辑。

## 废弃和移除的 API

| API | 状态 | 替代方案 |
|-----|------|---------|
| `forwardRef` | 不再需要 | ref 作为 prop |
| `React.createFactory` | 已移除 | JSX |
| `react-test-renderer` | 已废弃 | `@testing-library/react` |
| `defaultProps`（函数组件） | 已废弃 | ES6 默认参数 |
| 字符串 ref | 已移除 | `useRef` / 回调 ref |
