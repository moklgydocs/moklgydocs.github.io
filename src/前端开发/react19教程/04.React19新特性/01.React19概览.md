# React 19 新特性概览

## 学习目标

- 了解 React 19 的重大变化
- 理解每个新特性解决了什么问题
- 为后续深入学习各特性打好基础

## React 19 全景图

React 19 是自 Hooks 以来最大的一次更新。它的核心主题是：**让开发者写更少的代码，处理更少的边界情况**。

### 新增 API 一览

| 特性 | 解决的问题 | 替代了什么 |
|------|-----------|-----------|
| **Actions** | 异步操作 + pending/error 状态 | 手动 setState + try/catch |
| **`useActionState`** | 表单提交状态管理 | 手写表单状态逻辑 |
| **`use()`** | 在组件中读取 Promise/Context | useEffect + useState 请求模式 |
| **`useOptimistic`** | 乐观 UI 更新 | 手动管理临时状态 |
| **ref 作为 prop** | 简化 ref 传递 | `forwardRef` |
| **`<title>`/`<meta>`** | 文档元数据管理 | react-helmet 等三方库 |
| **React Compiler** | 自动性能优化 | useMemo/useCallback |

## Actions：革命性的异步处理

在 React 19 之前，处理异步操作需要手动管理大量状态：

```jsx
// ❌ React 18：手动管理
function OldWay() {
  const [isPending, setIsPending] = useState(false);
  const [error, setError] = useState(null);

  const handleSubmit = async () => {
    setIsPending(true);
    setError(null);
    try {
      await submitData();
    } catch (e) {
      setError(e.message);
    } finally {
      setIsPending(false);
    }
  };
}
```

```jsx
// ✅ React 19：Actions 自动处理
function NewWay() {
  const [error, submitAction, isPending] = useActionState(
    async (previousState, formData) => {
      const error = await submitData(formData);
      if (error) return error;
      redirect('/success');
      return null;
    },
    null
  );
}
```

## ref 不再需要 forwardRef

```jsx
// React 18：繁琐的 forwardRef
const Input = forwardRef((props, ref) => (
  <input ref={ref} {...props} />
));

// React 19：ref 就是普通 prop
function Input({ ref, ...props }) {
  return <input ref={ref} {...props} />;
}
```

## 文档元数据原生支持

```jsx
// React 18：需要 react-helmet
import { Helmet } from 'react-helmet';
function Page() {
  return (
    <>
      <Helmet><title>我的页面</title></Helmet>
      <div>内容</div>
    </>
  );
}

// React 19：原生支持
function Page() {
  return (
    <>
      <title>我的页面</title>
      <meta name="description" content="页面描述" />
      <link rel="stylesheet" href="/styles.css" />
      <div>内容</div>
    </>
  );
}
```

## 升级建议

1. **新项目**：直接使用 React 19
2. **老项目**：可以渐进升级，大部分 React 18 代码兼容
3. **注意移除**：`forwardRef`（可选）、一些废弃 API
4. **测试工具**：React 官方提供了 codemod 工具辅助迁移

```bash
# 使用官方迁移工具
npx @react-codemod/cli react-19
```
