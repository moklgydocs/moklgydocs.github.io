# 第一个 React 应用：计数器到记事本

## 学习目标

- 从零开始写一个完整的 React 应用
- 理解「状态驱动 UI」的开发模式
- 体会从需求分析到实现的完整过程

## 热身：从计数器开始

在正式做项目之前，让我们先写一个最简单的计数器，感受 React 的开发流程。

### 需求分析

- 显示当前数字
- 点击「+」按钮数字加 1
- 点击「-」按钮数字减 1
- 点击「重置」回到 0

### 实现思路

在 React 中开发，你需要转变思维方式：

1. **先想清楚「状态」是什么**：这里状态就是 `count`（一个数字）
2. **再想「UI 如何根据状态渲染」**：显示 count 的值
3. **最后想「什么事件改变状态」**：点击按钮改变 count

```jsx
import { useState } from 'react';

function Counter() {
  // 第 1 步：声明状态
  const [count, setCount] = useState(0);

  // 第 3 步：定义事件处理
  const increment = () => setCount(count + 1);
  const decrement = () => setCount(count - 1);
  const reset = () => setCount(0);

  // 第 2 步：根据状态渲染 UI
  return (
    <div style={{ textAlign: 'center', padding: '20px' }}>
      <h1>计数器</h1>
      <p style={{ fontSize: '48px', margin: '20px 0' }}>{count}</p>
      <button onClick={decrement}>➖</button>
      <button onClick={reset} style={{ margin: '0 10px' }}>🔄 重置</button>
      <button onClick={increment}>➕</button>
    </div>
  );
}

export default Counter;
```

> 🧠 **思维转变**：注意这里的开发顺序——**先状态，后 UI，最后事件**。这是 React 的核心思维模式：**所有的 UI 变化都是状态变化的结果**。

## 实战项目：迷你记事本

现在让我们做一个更有意义的应用——一个迷你记事本。

### 需求分析

1. 用户可以输入笔记内容并添加
2. 显示所有笔记列表
3. 每条笔记可以删除
4. 显示笔记总数
5. 支持按关键词搜索

### 步骤一：确定状态

> 💡 **经验法则**：在写任何代码之前，先问自己——「这个应用有哪些会变化的数据？」

对于记事本应用：
- `notes`：笔记数组（核心数据）
- `inputValue`：输入框的当前值（UI 状态）
- `searchTerm`：搜索关键词（过滤条件）

```jsx
const [notes, setNotes] = useState([]);
const [inputValue, setInputValue] = useState('');
const [searchTerm, setSearchTerm] = useState('');
```

### 步骤二：渲染 UI 骨架

先把 UI 结构搭出来，不关心样式：

```jsx
function NoteApp() {
  const [notes, setNotes] = useState([]);
  const [inputValue, setInputValue] = useState('');
  const [searchTerm, setSearchTerm] = useState('');

  return (
    <div>
      <h1>📝 迷你记事本</h1>
      
      {/* 输入区域 */}
      <div>
        <input 
          value={inputValue}
          onChange={(e) => setInputValue(e.target.value)}
          placeholder="写点什么..."
        />
        <button>添加</button>
      </div>

      {/* 搜索区域 */}
      <div>
        <input 
          value={searchTerm}
          onChange={(e) => setSearchTerm(e.target.value)}
          placeholder="搜索笔记..."
        />
      </div>

      {/* 统计 */}
      <p>共 {notes.length} 条笔记</p>

      {/* 笔记列表 */}
      <ul>
        {notes.map(note => (
          <li key={note.id}>
            {note.text}
            <button>删除</button>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

### 步骤三：实现添加功能

```jsx
const addNote = () => {
  // 防止添加空笔记
  if (inputValue.trim() === '') return;
  
  const newNote = {
    id: Date.now(),  // 用时间戳作为简单 ID
    text: inputValue.trim(),
    createdAt: new Date().toLocaleString(),
  };
  
  setNotes([newNote, ...notes]);  // 新笔记放在最前面
  setInputValue('');  // 清空输入框
};
```

> 🤔 **思考**：为什么用 `[newNote, ...notes]` 而不是 `notes.push(newNote)`？
> 
> 因为 React 要求**不可变更新**（Immutable Update）。`push` 会直接修改原数组，React 检测不到变化就不会重新渲染。`[newNote, ...notes]` 创建了一个新数组，React 就知道状态变了。
> 
> 这是 React 的一个核心原则，后面我们会在 [useState 状态管理](../03.Hooks核心/01.useState状态管理.md) 中深入讲解。

### 步骤四：实现删除功能

```jsx
const deleteNote = (id) => {
  setNotes(notes.filter(note => note.id !== id));
};
```

### 步骤五：实现搜索过滤

```jsx
// 派生状态：根据搜索词过滤笔记
const filteredNotes = notes.filter(note => 
  note.text.toLowerCase().includes(searchTerm.toLowerCase())
);
```

> 💡 **重要概念：派生状态**
> 
> `filteredNotes` 不需要用 `useState`，因为它可以从 `notes` 和 `searchTerm` 计算出来。**能计算出来的值，就不要存成状态**——这是 React 的重要设计原则。

### 步骤六：支持回车添加

```jsx
const handleKeyDown = (e) => {
  if (e.key === 'Enter') {
    addNote();
  }
};

// 在 input 上添加
<input 
  value={inputValue}
  onChange={(e) => setInputValue(e.target.value)}
  onKeyDown={handleKeyDown}
  placeholder="写点什么...按回车添加"
/>
```

### 完整代码

```jsx
import { useState } from 'react';

function NoteApp() {
  const [notes, setNotes] = useState([]);
  const [inputValue, setInputValue] = useState('');
  const [searchTerm, setSearchTerm] = useState('');

  // 添加笔记
  const addNote = () => {
    if (inputValue.trim() === '') return;
    const newNote = {
      id: Date.now(),
      text: inputValue.trim(),
      createdAt: new Date().toLocaleString(),
    };
    setNotes([newNote, ...notes]);
    setInputValue('');
  };

  // 删除笔记
  const deleteNote = (id) => {
    setNotes(notes.filter(note => note.id !== id));
  };

  // 回车添加
  const handleKeyDown = (e) => {
    if (e.key === 'Enter') addNote();
  };

  // 派生状态：过滤后的笔记
  const filteredNotes = notes.filter(note =>
    note.text.toLowerCase().includes(searchTerm.toLowerCase())
  );

  return (
    <div style={{ maxWidth: '600px', margin: '0 auto', padding: '20px' }}>
      <h1>📝 迷你记事本</h1>

      {/* 输入区域 */}
      <div style={{ display: 'flex', gap: '8px', marginBottom: '16px' }}>
        <input
          value={inputValue}
          onChange={(e) => setInputValue(e.target.value)}
          onKeyDown={handleKeyDown}
          placeholder="写点什么...按回车添加"
          style={{ flex: 1, padding: '8px' }}
        />
        <button onClick={addNote} style={{ padding: '8px 16px' }}>
          添加
        </button>
      </div>

      {/* 搜索区域 */}
      <input
        value={searchTerm}
        onChange={(e) => setSearchTerm(e.target.value)}
        placeholder="🔍 搜索笔记..."
        style={{ width: '100%', padding: '8px', marginBottom: '16px' }}
      />

      {/* 统计信息 */}
      <p style={{ color: '#666' }}>
        共 {notes.length} 条笔记
        {searchTerm && `，搜索到 ${filteredNotes.length} 条`}
      </p>

      {/* 笔记列表 */}
      {filteredNotes.length === 0 ? (
        <p style={{ textAlign: 'center', color: '#999' }}>
          {notes.length === 0 ? '还没有笔记，快写一条吧！' : '没有匹配的笔记'}
        </p>
      ) : (
        <ul style={{ listStyle: 'none', padding: 0 }}>
          {filteredNotes.map(note => (
            <li
              key={note.id}
              style={{
                display: 'flex',
                justifyContent: 'space-between',
                alignItems: 'center',
                padding: '12px',
                marginBottom: '8px',
                backgroundColor: '#f5f5f5',
                borderRadius: '8px',
              }}
            >
              <div>
                <p style={{ margin: 0 }}>{note.text}</p>
                <small style={{ color: '#999' }}>{note.createdAt}</small>
              </div>
              <button
                onClick={() => deleteNote(note.id)}
                style={{ color: 'red', border: 'none', cursor: 'pointer' }}
              >
                🗑️
              </button>
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}

export default NoteApp;
```

## 代码复盘：我们学到了什么？

### 开发流程

```
需求分析 → 确定状态 → 搭建 UI → 实现交互 → 优化体验
```

### 核心概念实践

| 概念 | 在项目中的体现 |
|------|---------------|
| 状态管理 | `notes`、`inputValue`、`searchTerm` 三个状态 |
| 声明式 UI | UI 完全由状态决定，修改状态就修改了 UI |
| 不可变更新 | 用展开运算符和 `filter` 创建新数组 |
| 派生状态 | `filteredNotes` 不是状态，是计算值 |
| 列表渲染 | `map` + `key` |
| 条件渲染 | 三元表达式、`&&` 短路 |

### 可以继续优化的点

这个应用还有很多可以优化的地方，随着后续章节的学习你可以回来改进：

- [ ] 数据持久化（localStorage） → 学完 useEffect
- [ ] 编辑笔记功能 → 更复杂的状态管理
- [ ] 拆分子组件 → 学完组件基础
- [ ] 添加动画效果 → 学完 React 动画
- [ ] 用 useReducer 重构 → 学完状态管理进阶
