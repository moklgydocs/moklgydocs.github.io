# 错误边界与容错

## 错误边界（Error Boundary）

Error Boundary 是 React 的容错机制，能捕获子组件**渲染期间**的 JavaScript 错误，防止整个应用崩溃：

```jsx
class ErrorBoundary extends React.Component {
  state = { hasError: false, error: null };

  static getDerivedStateFromError(error) {
    return { hasError: true, error };
  }

  componentDidCatch(error, errorInfo) {
    // 上报错误到监控系统
    logErrorToService(error, errorInfo.componentStack);
  }

  render() {
    if (this.state.hasError) {
      return (
        <div className="error-fallback">
          <h2>😥 哎呀，出了点问题</h2>
          <p>{this.state.error?.message}</p>
          <button onClick={() => this.setState({ hasError: false, error: null })}>
            重试
          </button>
        </div>
      );
    }
    return this.props.children;
  }
}

// 使用
<ErrorBoundary>
  <UserProfile />
</ErrorBoundary>
```

> ⚠️ **注意**：Error Boundary **无法捕获**事件处理、异步代码、服务端渲染中的错误。这些需要用 try/catch。

## 容错策略

### 局部容错

```jsx
function Dashboard() {
  return (
    <div>
      <ErrorBoundary fallback={<p>用户信息加载失败</p>}>
        <UserInfo />
      </ErrorBoundary>
      <ErrorBoundary fallback={<p>图表加载失败</p>}>
        <Charts />
      </ErrorBoundary>
      {/* 一个模块出错不影响其他模块 */}
    </div>
  );
}
```

### 错误恢复

```jsx
function RetryableWidget({ children }) {
  const [key, setKey] = useState(0);
  
  return (
    <ErrorBoundary 
      key={key}
      onReset={() => setKey(k => k + 1)}
      fallback={({ resetErrorBoundary }) => (
        <button onClick={resetErrorBoundary}>重试</button>
      )}
    >
      {children}
    </ErrorBoundary>
  );
}
```

> 💡 **实战建议**：推荐使用 `react-error-boundary` 库，它提供了更好的 API，包括 `useErrorBoundary` Hook 和 `ErrorBoundary` 组件。
