# TypeScript 与 React

## 为什么 React 项目要用 TypeScript？

- **编译时发现错误**：Props 传错类型？编译就报错
- **智能提示**：IDE 自动补全 Props、State
- **重构安全**：改了接口定义，所有用到的地方都会有提示
- **文档即代码**：类型定义就是最好的文档

## 组件类型定义

```tsx
// 基本的函数组件
interface UserCardProps {
  name: string;
  age: number;
  avatar?: string;        // 可选属性
  role: 'admin' | 'user'; // 联合类型
  onClick: (id: string) => void;
  children?: React.ReactNode;
}

function UserCard({ name, age, avatar, role, onClick, children }: UserCardProps) {
  return (
    <div onClick={() => onClick(name)}>
      <h3>{name}</h3>
      <p>{age} 岁 - {role}</p>
      {avatar && <img src={avatar} alt={name} />}
      {children}
    </div>
  );
}
```

## Hooks 类型

```tsx
// useState
const [count, setCount] = useState<number>(0);
const [user, setUser] = useState<User | null>(null);

// useRef
const inputRef = useRef<HTMLInputElement>(null);
const timerRef = useRef<number | null>(null);

// useReducer
type Action = 
  | { type: 'INCREMENT' }
  | { type: 'SET'; payload: number };

function reducer(state: number, action: Action): number {
  switch (action.type) {
    case 'INCREMENT': return state + 1;
    case 'SET': return action.payload;
  }
}

// useContext
interface ThemeContextType {
  theme: 'light' | 'dark';
  toggleTheme: () => void;
}
const ThemeContext = createContext<ThemeContextType | null>(null);
```

## 事件类型

```tsx
function Form() {
  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    console.log(e.target.value);
  };

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
  };

  const handleClick = (e: React.MouseEvent<HTMLButtonElement>) => {
    console.log(e.clientX, e.clientY);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input onChange={handleChange} />
      <button onClick={handleClick}>提交</button>
    </form>
  );
}
```

## 常用类型速查

| 类型 | 用途 |
|------|------|
| `React.ReactNode` | 任何可渲染的内容 |
| `React.ReactElement` | JSX 元素 |
| `React.FC<Props>` | 函数组件类型（不推荐了） |
| `React.ChangeEvent<HTMLInputElement>` | input change 事件 |
| `React.MouseEvent<HTMLElement>` | 鼠标事件 |
| `React.CSSProperties` | style 对象类型 |
| `React.ComponentProps<'button'>` | 获取原生元素的 props 类型 |

> 💡 **建议**：不推荐使用 `React.FC`，直接给 props 加类型即可。`React.FC` 有一些历史遗留问题（比如隐式 children）。
