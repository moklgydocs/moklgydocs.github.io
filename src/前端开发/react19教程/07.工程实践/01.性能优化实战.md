# 性能优化实战

## 优化原则：先测量，再优化

> ⚠️ **核心原则**：永远不要凭直觉优化！先用 Profiler 找到真正的瓶颈。

### React DevTools Profiler 使用步骤

1. 打开 DevTools → Profiler Tab
2. 点击录制 → 操作页面 → 停止录制
3. 查看火焰图，找到耗时最长的组件

## 常见性能问题及解决方案

### 1. 不必要的重渲染

```jsx
// 问题：父组件更新 → 所有子组件重渲染
// 解决：React.memo + useCallback

const ExpensiveChild = React.memo(({ onClick, data }) => {
  console.log('ExpensiveChild 渲染');
  return <div onClick={onClick}>{data.name}</div>;
});

function Parent() {
  const [count, setCount] = useState(0);
  const [data] = useState({ name: 'test' });
  
  const handleClick = useCallback(() => {
    console.log('clicked');
  }, []);
  
  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>{count}</button>
      <ExpensiveChild onClick={handleClick} data={data} />
    </div>
  );
}
```

### 2. 大列表渲染

```jsx
// 问题：渲染 10000 条数据
// 解决：虚拟列表（只渲染可视区域）

import { FixedSizeList } from 'react-window';

function VirtualList({ items }) {
  const Row = ({ index, style }) => (
    <div style={style}>{items[index].name}</div>
  );

  return (
    <FixedSizeList
      height={400}
      itemCount={items.length}
      itemSize={50}
      width="100%"
    >
      {Row}
    </FixedSizeList>
  );
}
```

### 3. 昂贵的计算

```jsx
// 问题：每次渲染都重新排序/过滤
// 解决：useMemo

function ProductList({ products, sortBy, filterBy }) {
  const processedProducts = useMemo(() => {
    console.log('重新计算...');
    return products
      .filter(p => p.category === filterBy)
      .sort((a, b) => a[sortBy] - b[sortBy]);
  }, [products, sortBy, filterBy]);

  return processedProducts.map(p => <ProductCard key={p.id} product={p} />);
}
```

### 4. 懒加载组件

```jsx
import { lazy, Suspense } from 'react';

// 只有用到时才加载组件代码
const HeavyChart = lazy(() => import('./HeavyChart'));
const AdminPanel = lazy(() => import('./AdminPanel'));

function App() {
  return (
    <Suspense fallback={<Loading />}>
      {showChart && <HeavyChart />}
      {isAdmin && <AdminPanel />}
    </Suspense>
  );
}
```

### 5. 防抖与节流

```jsx
function SearchInput({ onSearch }) {
  const [query, setQuery] = useState('');
  const debouncedQuery = useDebounce(query, 300);

  useEffect(() => {
    if (debouncedQuery) onSearch(debouncedQuery);
  }, [debouncedQuery, onSearch]);

  return <input value={query} onChange={e => setQuery(e.target.value)} />;
}
```

## 性能优化清单

| 级别 | 优化手段 | 适用场景 |
|------|---------|---------|
| 基础 | 避免在 JSX 中内联对象/函数 | 所有项目 |
| 基础 | 正确使用 key | 列表渲染 |
| 中级 | React.memo + useCallback | 频繁重渲染的子组件 |
| 中级 | useMemo 缓存计算 | 昂贵的数据处理 |
| 中级 | lazy + Suspense | 大型组件按需加载 |
| 高级 | 虚拟列表 | 超长列表 |
| 高级 | startTransition | 输入框 + 重渲染 |
| 高级 | Web Worker | CPU 密集型计算 |
