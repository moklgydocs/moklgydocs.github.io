# 并发模式与调度

## 什么是并发模式？

并发模式让 React 可以**同时准备多个版本的 UI**，根据优先级决定先展示哪个。

类比：你在写邮件时接到电话。
- **同步模式**：必须写完邮件才能接电话
- **并发模式**：暂停写邮件 → 接电话 → 继续写邮件

## startTransition

把非紧急更新标记为「可中断的过渡」：

```jsx
import { useState, useTransition } from 'react';

function SearchPage() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);
  const [isPending, startTransition] = useTransition();

  const handleSearch = (e) => {
    setQuery(e.target.value);          // 紧急：立即更新输入框
    
    startTransition(() => {
      setResults(heavySearch(e.target.value)); // 非紧急：可以稍后
    });
  };

  return (
    <div>
      <input value={query} onChange={handleSearch} />
      {isPending && <p>搜索中...</p>}
      <SearchResults results={results} />
    </div>
  );
}
```

## useDeferredValue

延迟某个值的更新：

```jsx
import { useDeferredValue } from 'react';

function SearchResults({ query }) {
  const deferredQuery = useDeferredValue(query);
  const isStale = query !== deferredQuery; // 是否过期
  
  const results = useMemo(() => search(deferredQuery), [deferredQuery]);

  return (
    <div style={{ opacity: isStale ? 0.5 : 1 }}>
      {results.map(r => <div key={r.id}>{r.title}</div>)}
    </div>
  );
}
```

## Suspense 与并发

```jsx
<Suspense fallback={<Skeleton />}>
  <UserProfile />     {/* 需要等待数据 */}
  <UserPosts />        {/* 需要等待数据 */}
</Suspense>

// Suspense 让 React 可以：
// 1. 在数据准备好之前显示 fallback
// 2. 当数据逐步到达时，逐步展示内容
// 3. 如果有新的更高优先级更新，可以中断当前渲染
```

## 调度器（Scheduler）

React 内部有一个调度器，使用 `MessageChannel` 实现时间切片：

```
浏览器一帧的工作：
|-- 用户事件 --|-- JS执行 --|-- 样式计算 --|-- 布局 --|-- 绘制 --|-- 空闲 --|

React 利用空闲时间执行渲染工作：
|-- 浏览器工作 --|-- React工作（5ms上限）--|-- 浏览器工作 --|-- React工作 --|
```

每 5ms React 会交还控制权给浏览器，确保页面保持流畅。

## 实际应用场景

| 场景 | API | 效果 |
|------|-----|------|
| 搜索输入 + 结果列表 | `useTransition` | 输入流畅，结果延迟更新 |
| 大列表筛选 | `useDeferredValue` | 筛选框流畅，列表延迟 |
| 路由切换 | `startTransition` | 旧页面保持展示，新页面后台加载 |
| 数据加载 | `Suspense` | 优雅的加载状态控制 |

> 💡 **实战经验**：大部分场景你不需要手动使用并发特性。React 19 默认就启用了自动批量更新。只有当你发现某个交互明显卡顿时，才需要用 `startTransition` 或 `useDeferredValue` 来优化。
