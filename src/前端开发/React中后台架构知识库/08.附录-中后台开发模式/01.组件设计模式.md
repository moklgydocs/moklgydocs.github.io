# 组件设计模式：复合组件、Provider、受控与非受控

> **TL;DR**
> 中后台系统的组件不是简单的"接收 Props → 渲染 UI"——你需要复合组件模式构建灵活的 UI 组合，Provider 模式管理跨层级配置，以及清晰的受控/非受控边界。这些模式决定了你的组件库是"能用"还是"好用"。

## 1. 复合组件模式（Compound Components）

### 什么是复合组件？

复合组件是一组**语义关联、协同工作**的子组件，它们通过共享的 Context 进行隐式通信，使用者通过组合子组件来声明 UI 结构。

HTML 的 `<select>` + `<option>` 就是天然的复合组件——`<option>` 离开 `<select>` 没有意义，但组合在一起就能表达"下拉选择"。

### 实战：构建 Tabs 复合组件

```tsx
// src/components/business/tabs.tsx
import {
  createContext,
  useContext,
  useState,
  type ReactNode,
  useCallback,
} from "react";
import { cn } from "@/lib/utils";

// 1. 共享 Context
interface TabsContextValue {
  activeKey: string;
  setActiveKey: (key: string) => void;
}

const TabsContext = createContext<TabsContextValue | null>(null);

function useTabsContext() {
  const ctx = useContext(TabsContext);
  if (!ctx) throw new Error("Tabs 子组件必须在 <Tabs> 内使用");
  return ctx;
}

// 2. 根组件：管理状态，提供 Context
interface TabsProps {
  defaultActiveKey: string;
  onChange?: (key: string) => void;
  children: ReactNode;
  className?: string;
}

function Tabs({ defaultActiveKey, onChange, children, className }: TabsProps) {
  const [activeKey, setActiveKeyState] = useState(defaultActiveKey);

  const setActiveKey = useCallback(
    (key: string) => {
      setActiveKeyState(key);
      onChange?.(key);
    },
    [onChange]
  );

  return (
    <TabsContext.Provider value={{ activeKey, setActiveKey }}>
      <div className={className}>{children}</div>
    </TabsContext.Provider>
  );
}

// 3. Tab 列表容器
function TabList({ children, className }: { children: ReactNode; className?: string }) {
  return (
    <div className={cn("flex gap-1 border-b", className)} role="tablist">
      {children}
    </div>
  );
}

// 4. 单个 Tab 触发器
function TabTrigger({
  tabKey,
  children,
}: {
  tabKey: string;
  children: ReactNode;
}) {
  const { activeKey, setActiveKey } = useTabsContext();
  const isActive = activeKey === tabKey;

  return (
    <button
      role="tab"
      aria-selected={isActive}
      onClick={() => setActiveKey(tabKey)}
      className={cn(
        "px-4 py-2 text-sm font-medium transition-colors",
        isActive
          ? "border-b-2 border-primary text-primary"
          : "text-muted-foreground hover:text-foreground"
      )}
    >
      {children}
    </button>
  );
}

// 5. Tab 内容面板
function TabPanel({
  tabKey,
  children,
}: {
  tabKey: string;
  children: ReactNode;
}) {
  const { activeKey } = useTabsContext();
  if (activeKey !== tabKey) return null;
  return (
    <div role="tabpanel" className="py-4">
      {children}
    </div>
  );
}

// 6. 组合导出
Tabs.List = TabList;
Tabs.Trigger = TabTrigger;
Tabs.Panel = TabPanel;

export { Tabs };
```

```tsx
// 使用：声明式组合，灵活且语义清晰
function OrderPage() {
  return (
    <Tabs defaultActiveKey="all" onChange={(key) => console.log("切换到", key)}>
      <Tabs.List>
        <Tabs.Trigger tabKey="all">全部订单</Tabs.Trigger>
        <Tabs.Trigger tabKey="pending">待处理</Tabs.Trigger>
        <Tabs.Trigger tabKey="shipped">已发货</Tabs.Trigger>
      </Tabs.List>

      <Tabs.Panel tabKey="all">
        <OrderTable filter="all" />
      </Tabs.Panel>
      <Tabs.Panel tabKey="pending">
        <OrderTable filter="pending" />
      </Tabs.Panel>
      <Tabs.Panel tabKey="shipped">
        <OrderTable filter="shipped" />
      </Tabs.Panel>
    </Tabs>
  );
}
```

## 2. Provider 模式：跨层级配置注入

### 适用场景
当多个不相邻的组件需要共享配置（主题、国际化、权限、Toast 管理器）时，用 Provider 模式在组件树顶层注入，子组件通过 Hook 消费。

```tsx
// src/providers/app-provider.tsx — 统一包裹所有 Provider
import { QueryClientProvider } from "@tanstack/react-query";
import { queryClient } from "@/lib/query-client";
import { ToastProvider } from "@/components/ui/toast";
import type { ReactNode } from "react";

function AppProvider({ children }: { children: ReactNode }) {
  return (
    <QueryClientProvider client={queryClient}>
      <ToastProvider>
        {children}
      </ToastProvider>
    </QueryClientProvider>
  );
}

export { AppProvider };
```

### Toast 通知的 Provider 实现

```tsx
// src/components/ui/toast-provider.tsx
import { createContext, useContext, useState, useCallback, type ReactNode } from "react";

interface Toast {
  id: string;
  message: string;
  type: "success" | "error" | "warning" | "info";
}

interface ToastContextValue {
  toasts: Toast[];
  addToast: (message: string, type?: Toast["type"]) => void;
  removeToast: (id: string) => void;
}

const ToastContext = createContext<ToastContextValue | null>(null);

function useToast() {
  const ctx = useContext(ToastContext);
  if (!ctx) throw new Error("useToast 必须在 <ToastProvider> 内使用");
  return ctx;
}

function ToastProvider({ children }: { children: ReactNode }) {
  const [toasts, setToasts] = useState<Toast[]>([]);

  const addToast = useCallback(
    (message: string, type: Toast["type"] = "info") => {
      const id = Math.random().toString(36).slice(2);
      setToasts((prev) => [...prev, { id, message, type }]);

      // 3 秒后自动关闭
      setTimeout(() => {
        setToasts((prev) => prev.filter((t) => t.id !== id));
      }, 3000);
    },
    []
  );

  const removeToast = useCallback((id: string) => {
    setToasts((prev) => prev.filter((t) => t.id !== id));
  }, []);

  return (
    <ToastContext.Provider value={{ toasts, addToast, removeToast }}>
      {children}
      {/* Toast 渲染区域 */}
      <div className="fixed bottom-4 right-4 z-50 flex flex-col gap-2">
        {toasts.map((toast) => (
          <div
            key={toast.id}
            className={`animate-fade-in rounded-lg px-4 py-3 text-sm text-white shadow-lg ${
              toast.type === "success" ? "bg-green-600" :
              toast.type === "error" ? "bg-red-600" :
              toast.type === "warning" ? "bg-yellow-600" :
              "bg-blue-600"
            }`}
          >
            {toast.message}
          </div>
        ))}
      </div>
    </ToastContext.Provider>
  );
}

export { ToastProvider, useToast };

// 使用（在任何子组件中）：
// const { addToast } = useToast();
// addToast("订单创建成功", "success");
// addToast("操作失败，请重试", "error");
```

## 3. 受控 vs 非受控组件设计

### 设计原则
当你封装一个组件时，同时支持**受控模式**（外部控制 value）和**非受控模式**（内部管理 state），给使用者最大的灵活性。

```tsx
// src/components/business/searchable-select.tsx — 同时支持受控和非受控
import { useState, useMemo } from "react";
import { useDebounce } from "@/hooks/use-debounce";

interface Option {
  label: string;
  value: string;
}

interface SearchableSelectProps {
  options: Option[];
  placeholder?: string;
  // 受控模式 Props（如果传了 value + onChange，就是受控）
  value?: string;
  onChange?: (value: string) => void;
  // 非受控模式 Props
  defaultValue?: string;
}

function SearchableSelect({
  options,
  placeholder = "请选择",
  value: controlledValue,
  onChange,
  defaultValue = "",
}: SearchableSelectProps) {
  // 判断是否是受控模式
  const isControlled = controlledValue !== undefined;

  const [internalValue, setInternalValue] = useState(defaultValue);
  const [search, setSearch] = useState("");
  const [open, setOpen] = useState(false);

  // 统一读取当前值
  const currentValue = isControlled ? controlledValue : internalValue;

  // 统一设置值
  function handleSelect(newValue: string) {
    if (!isControlled) {
      setInternalValue(newValue);
    }
    onChange?.(newValue);
    setOpen(false);
    setSearch("");
  }

  const debouncedSearch = useDebounce(search, 200);
  const filteredOptions = useMemo(
    () =>
      options.filter((opt) =>
        opt.label.toLowerCase().includes(debouncedSearch.toLowerCase())
      ),
    [options, debouncedSearch]
  );

  const selectedLabel = options.find((o) => o.value === currentValue)?.label;

  return (
    <div className="relative">
      <button
        onClick={() => setOpen(!open)}
        className="flex w-full items-center justify-between rounded-md border px-3 py-2 text-sm"
      >
        <span className={selectedLabel ? "text-foreground" : "text-muted-foreground"}>
          {selectedLabel || placeholder}
        </span>
        <span>{open ? "▲" : "▼"}</span>
      </button>

      {open && (
        <div className="absolute z-10 mt-1 w-full rounded-md border bg-card shadow-lg">
          <input
            value={search}
            onChange={(e) => setSearch(e.target.value)}
            placeholder="搜索..."
            className="w-full border-b px-3 py-2 text-sm"
            autoFocus
          />
          <div className="max-h-60 overflow-auto">
            {filteredOptions.map((opt) => (
              <button
                key={opt.value}
                onClick={() => handleSelect(opt.value)}
                className={`w-full px-3 py-2 text-left text-sm hover:bg-muted ${
                  opt.value === currentValue ? "bg-primary/10 text-primary" : ""
                }`}
              >
                {opt.label}
              </button>
            ))}
            {filteredOptions.length === 0 && (
              <p className="px-3 py-4 text-center text-sm text-muted-foreground">
                无匹配结果
              </p>
            )}
          </div>
        </div>
      )}
    </div>
  );
}

export { SearchableSelect };
```

```tsx
// 受控使用（筛选联动场景）
const [country, setCountry] = useState("");
<SearchableSelect value={country} onChange={setCountry} options={countries} />

// 非受控使用（简单表单场景）
<SearchableSelect defaultValue="CN" options={countries} />
```

## 4. Render Props 模式（现代版）

当 Hook 无法满足需求（比如需要根据状态切换**渲染内容**的布局结构），Render Props 依然有用武之地。

```tsx
// src/components/business/async-boundary.tsx — 异步数据加载边界
import type { ReactNode } from "react";

interface AsyncBoundaryProps<TData> {
  data: TData | undefined;
  isLoading: boolean;
  error: Error | null;
  loadingFallback?: ReactNode;
  errorFallback?: (error: Error, retry: () => void) => ReactNode;
  emptyFallback?: ReactNode;
  isEmpty?: (data: TData) => boolean;
  children: (data: TData) => ReactNode; // Render Prop
  onRetry?: () => void;
}

function AsyncBoundary<TData>({
  data,
  isLoading,
  error,
  loadingFallback,
  errorFallback,
  emptyFallback,
  isEmpty,
  children,
  onRetry,
}: AsyncBoundaryProps<TData>) {
  if (isLoading) {
    return <>{loadingFallback ?? <div className="animate-pulse p-8 text-center">加载中...</div>}</>;
  }

  if (error) {
    return (
      <>
        {errorFallback?.(error, onRetry ?? (() => {})) ?? (
          <div className="p-8 text-center text-destructive">
            <p>加载失败：{error.message}</p>
            {onRetry && (
              <button onClick={onRetry} className="mt-2 text-primary underline">
                点击重试
              </button>
            )}
          </div>
        )}
      </>
    );
  }

  if (!data || (isEmpty && isEmpty(data))) {
    return <>{emptyFallback ?? <div className="p-8 text-center text-muted-foreground">暂无数据</div>}</>;
  }

  return <>{children(data)}</>;
}

export { AsyncBoundary };
```

```tsx
// 使用：
const { data, isLoading, error, refetch } = useOrderList(params);

<AsyncBoundary
  data={data}
  isLoading={isLoading}
  error={error}
  onRetry={refetch}
  isEmpty={(d) => d.list.length === 0}
>
  {(orderData) => (
    <DataTable
      columns={columns}
      data={orderData.list}
      total={orderData.total}
    />
  )}
</AsyncBoundary>
```

## 5. 模式选择指南

| 模式 | 适用场景 | 复杂度 |
|------|---------|:------:|
| **复合组件** | 一组语义关联的 UI 部件（Tabs、Accordion、Dropdown） | 中 |
| **Provider** | 全局/跨层级的配置注入（主题、Toast、权限） | 低 |
| **受控/非受控** | 表单类组件需要同时支持两种使用方式 | 中 |
| **Render Props** | 根据异步状态切换不同的渲染布局 | 低 |
| **HOC** | 遗留模式，现代项目优先用 Hook 替代 | 高 |
