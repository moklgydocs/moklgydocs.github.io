# 租户管理

租户管理聚焦于租户生命周期：开通（Provision）、激活（Activate）、暂停（Suspend）、终止（Terminate）。本节实现租户查询页面、开通对话框和版本变更对话框。

> **🤔 导师提问**：租户的四个生命周期操作（Provision/Activate/Suspend/Terminate）构成了一个状态机。在后端，你通常用枚举 + 状态转换验证来保证操作合法性（比如不能从 Terminated 激活）。前端是否也需要维护同样的状态机逻辑？还是说前端只负责发请求、后端负责校验？如果后端返回"非法状态转换"的错误，前端应该如何展示？

## 租户查询页面

```tsx
// src/pages/ops/tenants/index.tsx
import { useState, useCallback } from "react"
import { AnimatedPage } from "@/components/shared/animated-page"
import { PageHeader } from "@/components/shared/page-header"
import { ConfirmDialog } from "@/components/shared/confirm-dialog"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
import { Badge } from "@/components/ui/badge"
import { StatCard } from "@/components/shared/stat-card"
import { tenantsApi } from "@/api/ops/tenants"
import { toast } from "sonner"
import { Search, RefreshCw, Plus, Pause, Play, XCircle, ArrowRightLeft, Loader2 } from "lucide-react"
import { useNavigate } from "react-router-dom"
import type { TenantDashboardDto } from "@/types"
import {
  TENANT_STATUS,
  TENANT_STATUS_LABELS,
  TENANT_EDITION_STATUS,
  BILLING_CYCLE_LABELS,
  HEALTH_STATUS_LABELS,
} from "@/types"
import { ProvisionDialog } from "./provision-dialog"
import { SubscribeEditionDialog } from "./subscribe-edition-dialog"

/**
 * 租户管理页面
 * 聚焦于租户生命周期管理：开通、暂停、激活、终止。
 * 通过输入租户 ID 查找并管理租户。
 */
export default function OpsTenantsPage() {
  const [tenantId, setTenantId] = useState("")
  const [dashboard, setDashboard] = useState<TenantDashboardDto | null>(null)
  const [loading, setLoading] = useState(false)
  const [provisionOpen, setProvisionOpen] = useState(false)
  const [subscribeOpen, setSubscribeOpen] = useState(false)
  const [confirmOpen, setConfirmOpen] = useState(false)
  const [confirmAction, setConfirmAction] = useState<{ type: string; reason?: string } | null>(null)
  const [actionLoading, setActionLoading] = useState(false)

  const navigate = useNavigate()

  const fetchDashboard = useCallback(async () => {
    if (!tenantId.trim()) return
    setLoading(true)
    try {
      const res = await tenantsApi.getDashboard(tenantId.trim())
      setDashboard(res.data ?? null)
    } catch {
      toast.error("获取租户信息失败")
      setDashboard(null)
    } finally {
      setLoading(false)
    }
  }, [tenantId])

  const handleSuspend = async () => {
    if (!dashboard) return
    setActionLoading(true)
    try {
      await tenantsApi.suspend(dashboard.tenantId, confirmAction?.reason)
      toast.success("租户已暂停")
      setConfirmOpen(false)
      setConfirmAction(null)
      await fetchDashboard()
    } catch {
      toast.error("暂停操作失败")
    } finally {
      setActionLoading(false)
    }
  }

  const handleActivate = async () => {
    if (!dashboard) return
    setActionLoading(true)
    try {
      await tenantsApi.activate(dashboard.tenantId)
      toast.success("租户已激活")
      await fetchDashboard()
    } catch {
      toast.error("激活操作失败")
    } finally {
      setActionLoading(false)
    }
  }

  const handleTerminate = async () => {
    if (!dashboard) return
    setActionLoading(true)
    try {
      await tenantsApi.terminate(dashboard.tenantId, confirmAction?.reason)
      toast.success("租户已终止")
      setConfirmOpen(false)
      setConfirmAction(null)
      await fetchDashboard()
    } catch {
      toast.error("终止操作失败")
    } finally {
      setActionLoading(false)
    }
  }

  const handleConfirmAction = () => {
    if (!confirmAction) return
    if (confirmAction.type === "suspend") handleSuspend()
    else if (confirmAction.type === "terminate") handleTerminate()
  }

  /** 租户状态对应的 Badge 变体 */
  const statusBadgeVariant = (status: number) => {
    if (status === TENANT_STATUS.Active) return "default"
    if (status === TENANT_STATUS.Suspended) return "destructive"
    if (status === TENANT_STATUS.Terminated) return "destructive"
    return "secondary"
  }

  /** 版本状态对应的 Badge 变体 */
  const editionStatusVariant = (status: number) => {
    if (status === TENANT_EDITION_STATUS.Active) return "default"
    if (status === TENANT_EDITION_STATUS.Trial) return "secondary"
    return "destructive"
  }

  return (
    <AnimatedPage>
      <div className="space-y-6">
        <PageHeader
          title="租户管理"
          description="租户生命周期管理：开通、暂停、激活、终止"
          action={
            <Button onClick={() => setProvisionOpen(true)}>
              <Plus className="h-4 w-4 mr-1" />
              开通租户
            </Button>
          }
        />

        {/* 搜索区 */}
        <div className="flex items-end gap-3">
          <div className="w-80 space-y-1.5">
            <Label>租户 ID</Label>
            <div className="flex gap-2">
              <Input
                value={tenantId}
                onChange={(e) => setTenantId(e.target.value)}
                placeholder="输入租户 ID"
                onKeyDown={(e) => { if (e.key === "Enter") fetchDashboard() }}
              />
              <Button onClick={fetchDashboard} disabled={loading || !tenantId.trim()}>
                {loading ? <Loader2 className="h-4 w-4 animate-spin" /> : <Search className="h-4 w-4" />}
                查询
              </Button>
              <Button variant="outline" onClick={fetchDashboard} disabled={loading || !tenantId.trim()}>
                <RefreshCw className="h-4 w-4" />
              </Button>
            </div>
          </div>
        </div>

        {/* 租户仪表盘 */}
        {dashboard && (
          <div className="space-y-4">
            {/* 基本信息 */}
            <div className="rounded-lg border p-5 space-y-4">
              <div className="flex items-center justify-between">
                <div className="flex items-center gap-3">
                  <h3 className="text-lg font-semibold">{dashboard.tenantName}</h3>
                  <Badge variant={statusBadgeVariant(dashboard.health?.overallStatus ?? 0)}>
                    {TENANT_STATUS_LABELS[dashboard.health?.overallStatus as keyof typeof TENANT_STATUS_LABELS] ?? "未知"}
                  </Badge>
                </div>
                <Button variant="outline" size="sm" onClick={() => navigate(`/ops/tenants/${dashboard.tenantId}`)}>
                  查看详情
                </Button>
              </div>

              <div className="grid grid-cols-2 md:grid-cols-4 gap-4 text-sm">
                <div>
                  <span className="text-muted-foreground">标识符</span>
                  <p className="font-mono">{dashboard.tenantIdentifier}</p>
                </div>
                <div>
                  <span className="text-muted-foreground">版本</span>
                  <p>{dashboard.edition?.editionDisplayName ?? "无"}</p>
                </div>
                <div>
                  <span className="text-muted-foreground">计费周期</span>
                  <p>{dashboard.edition ? BILLING_CYCLE_LABELS[dashboard.edition.cycle] : "-"}</p>
                </div>
                <div>
                  <span className="text-muted-foreground">健康状态</span>
                  <p>{dashboard.health ? HEALTH_STATUS_LABELS[dashboard.health.overallStatus] : "-"}</p>
                </div>
              </div>

              {dashboard.edition && (
                <div className="flex items-center gap-2 text-sm">
                  <span className="text-muted-foreground">版本状态：</span>
                  <Badge variant={editionStatusVariant(dashboard.edition.status)}>
                    {dashboard.edition.autoRenew ? "自动续费" : "手动续费"}
                  </Badge>
                  <span className="text-muted-foreground">到期：{new Date(dashboard.edition.expiresAt).toLocaleDateString("zh-CN")}</span>
                </div>
              )}
            </div>

            {/* 统计卡片 */}
            <div className="grid grid-cols-2 md:grid-cols-4 gap-4">
              <StatCard label="配额项" value={dashboard.quotas.length} color="primary" />
              <StatCard
                label="已启用模块"
                value={dashboard.modules.filter((m) => m.isEnabled).length}
                sub={`共 ${dashboard.modules.length} 个`}
                color="success"
              />
              <StatCard
                label="健康状态"
                value={dashboard.health ? HEALTH_STATUS_LABELS[dashboard.health.overallStatus] : "-"}
                color={dashboard.health?.overallStatus === 0 ? "success" : dashboard.health?.overallStatus === 1 ? "warning" : "destructive"}
              />
              <StatCard label="活跃用户" value={dashboard.health?.activeUsersCount ?? "-"} color="info" />
            </div>

            {/* 生命周期操作按钮 */}
            <div className="flex items-center gap-3">
              <Button variant="outline" onClick={handleActivate} disabled={actionLoading}>
                <Play className="h-4 w-4 mr-1" />激活
              </Button>
              <Button variant="outline" onClick={() => { setConfirmAction({ type: "suspend" }); setConfirmOpen(true) }} disabled={actionLoading}>
                <Pause className="h-4 w-4 mr-1" />暂停
              </Button>
              <Button variant="destructive" onClick={() => { setConfirmAction({ type: "terminate" }); setConfirmOpen(true) }} disabled={actionLoading}>
                <XCircle className="h-4 w-4 mr-1" />终止
              </Button>
              <Button variant="outline" onClick={() => setSubscribeOpen(true)}>
                <ArrowRightLeft className="h-4 w-4 mr-1" />变更版本
              </Button>
            </div>
          </div>
        )}

        {/* 无数据提示 */}
        {!dashboard && !loading && tenantId && (
          <p className="text-muted-foreground text-sm">未找到该租户信息</p>
        )}

        {/* 开通租户对话框 */}
        <ProvisionDialog
          open={provisionOpen}
          onOpenChange={setProvisionOpen}
          onSuccess={() => {
            setProvisionOpen(false)
            if (tenantId.trim()) fetchDashboard()
          }}
        />

        {/* 变更版本对话框 */}
        {dashboard && (
          <SubscribeEditionDialog
            open={subscribeOpen}
            onOpenChange={setSubscribeOpen}
            tenantId={dashboard.tenantId}
            onSuccess={() => {
              setSubscribeOpen(false)
              fetchDashboard()
            }}
          />
        )}

        {/* 确认对话框 */}
        <ConfirmDialog
          open={confirmOpen}
          onOpenChange={(open) => {
            if (!open) { setConfirmOpen(false); setConfirmAction(null) }
          }}
          title={confirmAction?.type === "suspend" ? "暂停租户" : "终止租户"}
          description={
            confirmAction?.type === "suspend"
              ? `确定暂停租户 "${dashboard?.tenantName}" 吗？暂停后租户将无法访问系统。`
              : `确定终止租户 "${dashboard?.tenantName}" 吗？此操作不可逆！`
          }
          onConfirm={handleConfirmAction}
          loading={actionLoading}
          variant="destructive"
          type="danger"
          confirmLabel={confirmAction?.type === "suspend" ? "暂停" : "终止"}
        />
      </div>
    </AnimatedPage>
  )
}
```

## 生命周期操作的模式

暂停和终止都需要确认，激活不需要：

```typescript
// 激活：直接执行
const handleActivate = async () => {
  await tenantsApi.activate(dashboard.tenantId)
  toast.success("租户已激活")
  await fetchDashboard()  // 刷新数据
}

// 暂停/终止：先设置确认动作，弹出确认框
<Button onClick={() => { setConfirmAction({ type: "suspend" }); setConfirmOpen(true) }}>暂停</Button>
<Button onClick={() => { setConfirmAction({ type: "terminate" }); setConfirmOpen(true) }}>终止</Button>

// 确认后分发到具体操作
const handleConfirmAction = () => {
  if (confirmAction.type === "suspend") handleSuspend()
  else if (confirmAction.type === "terminate") handleTerminate()
}
```

> **后端类比**：确认对话框就像 `Are you sure?` 的 CLI 提示——危险操作需要二次确认。`confirmAction` 的 `type` 字段就像 `Command` 模式中的命令类型，`handleConfirmAction` 就是 `CommandDispatcher`。

> **🤔 导师提问**：暂停和终止都需要 `reason` 参数（审计日志），激活不需要。这和后端的审计日志设计一致——破坏性操作需要记录原因。但前端的 `ConfirmDialog` 目前没有 `reason` 输入框，`confirmAction.reason` 从何而来？如果需要添加 reason 输入，`ConfirmDialog` 应该如何改造？

## 开通租户对话框

```tsx
// src/pages/ops/tenants/provision-dialog.tsx
import { useState, useEffect } from "react"
import {
  Dialog, DialogContent, DialogHeader, DialogTitle, DialogFooter,
} from "@/components/ui/dialog"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
import { Switch } from "@/components/ui/switch"
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from "@/components/ui/select"
import { ScrollArea } from "@/components/ui/scroll-area"
import { Loader2 } from "lucide-react"
import { tenantsApi } from "@/api/ops/tenants"
import { editionsApi } from "@/api/ops/editions"
import { toast } from "sonner"
import type { EditionDto, ProvisionTenantRequest, BillingCycle } from "@/types"
import { BILLING_CYCLE as BC } from "@/types"

const cycleOptions = [
  { value: String(BC.Monthly), label: "月付" },
  { value: String(BC.Yearly), label: "年付" },
]

interface ProvisionDialogProps {
  open: boolean
  onOpenChange: (open: boolean) => void
  onSuccess: () => void
}

export function ProvisionDialog({ open, onOpenChange, onSuccess }: ProvisionDialogProps) {
  const [loading, setLoading] = useState(false)
  const [editions, setEditions] = useState<EditionDto[]>([])

  const [form, setForm] = useState({
    tenantName: "",
    tenantIdentifier: "",
    editionId: "",
    cycle: String(BC.Monthly),
    autoRenew: true,
    trialDays: 0,
    contactName: "",
    contactPhone: "",
    contactEmail: "",
  })

  // 加载版本列表
  useEffect(() => {
    if (!open) return
    editionsApi.getList().then((res) => { setEditions(res.data ?? []) })
      .catch(() => { toast.error("获取版本列表失败") })
  }, [open])

  // 打开时重置表单
  useEffect(() => {
    if (!open) return
    setForm({
      tenantName: "", tenantIdentifier: "", editionId: "",
      cycle: String(BC.Monthly), autoRenew: true, trialDays: 0,
      contactName: "", contactPhone: "", contactEmail: "",
    })
  }, [open])

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault()
    setLoading(true)
    try {
      const payload: ProvisionTenantRequest = {
        tenantName: form.tenantName,
        tenantIdentifier: form.tenantIdentifier,
        editionId: form.editionId,
        cycle: Number(form.cycle) as BillingCycle,
        autoRenew: form.autoRenew,
        trialDays: form.trialDays || undefined,
        contactName: form.contactName || undefined,
        contactPhone: form.contactPhone || undefined,
        contactEmail: form.contactEmail || undefined,
      }
      const res = await tenantsApi.provision(payload)
      if (res.success) {
        toast.success("租户开通成功")
        onOpenChange(false)
        onSuccess()
      } else {
        toast.error(res.message)
      }
    } catch {
      toast.error("开通租户失败")
    } finally {
      setLoading(false)
    }
  }

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="sm:max-w-xl max-h-[90vh]">
        <DialogHeader><DialogTitle>开通租户</DialogTitle></DialogHeader>
        <ScrollArea className="max-h-[65vh] pr-4">
          <form id="provision-form" onSubmit={handleSubmit} className="space-y-4">
            {/* 租户名称与标识符 */}
            <div className="grid grid-cols-2 gap-4">
              <div className="space-y-2">
                <Label>租户名称</Label>
                <Input value={form.tenantName}
                  onChange={(e) => setForm((p) => ({ ...p, tenantName: e.target.value }))}
                  placeholder="公司名称" required />
              </div>
              <div className="space-y-2">
                <Label>租户标识符</Label>
                <Input value={form.tenantIdentifier}
                  onChange={(e) => setForm((p) => ({ ...p, tenantIdentifier: e.target.value }))}
                  placeholder="唯一标识，如 company-code" required />
              </div>
            </div>

            {/* 版本选择 */}
            <div className="space-y-2">
              <Label>版本</Label>
              <Select value={form.editionId}
                onValueChange={(v) => setForm((p) => ({ ...p, editionId: v }))}>
                <SelectTrigger className="w-full"><SelectValue placeholder="选择版本" /></SelectTrigger>
                <SelectContent>
                  {editions.map((ed) => (
                    <SelectItem key={ed.id} value={ed.id}>
                      {ed.displayName} (月付 ¥{ed.monthlyPrice} / 年付 ¥{ed.yearlyPrice})
                    </SelectItem>
                  ))}
                </SelectContent>
              </Select>
            </div>

            {/* 计费周期与试用天数 */}
            <div className="grid grid-cols-2 gap-4">
              <div className="space-y-2">
                <Label>计费周期</Label>
                <Select value={form.cycle} onValueChange={(v) => setForm((p) => ({ ...p, cycle: v }))}>
                  <SelectTrigger className="w-full"><SelectValue /></SelectTrigger>
                  <SelectContent>
                    {cycleOptions.map((opt) => (
                      <SelectItem key={opt.value} value={opt.value}>{opt.label}</SelectItem>
                    ))}
                  </SelectContent>
                </Select>
              </div>
              <div className="space-y-2">
                <Label>试用天数</Label>
                <Input type="number" min={0} value={form.trialDays}
                  onChange={(e) => setForm((p) => ({ ...p, trialDays: Number(e.target.value) }))}
                  placeholder="0 表示无试用" />
              </div>
            </div>

            <div className="flex items-center gap-3">
              <Switch checked={form.autoRenew}
                onCheckedChange={(checked) => setForm((p) => ({ ...p, autoRenew: checked }))} />
              <Label>自动续费</Label>
            </div>

            {/* 联系人信息 */}
            <div className="grid grid-cols-3 gap-4">
              <div className="space-y-2">
                <Label>联系人</Label>
                <Input value={form.contactName}
                  onChange={(e) => setForm((p) => ({ ...p, contactName: e.target.value }))}
                  placeholder="姓名" />
              </div>
              <div className="space-y-2">
                <Label>联系电话</Label>
                <Input value={form.contactPhone}
                  onChange={(e) => setForm((p) => ({ ...p, contactPhone: e.target.value }))}
                  placeholder="手机号" />
              </div>
              <div className="space-y-2">
                <Label>联系邮箱</Label>
                <Input type="email" value={form.contactEmail}
                  onChange={(e) => setForm((p) => ({ ...p, contactEmail: e.target.value }))}
                  placeholder="邮箱" />
              </div>
            </div>
          </form>
        </ScrollArea>
        <DialogFooter>
          <Button type="button" variant="outline" onClick={() => onOpenChange(false)}>取消</Button>
          <Button type="submit" form="provision-form" disabled={loading}>
            {loading && <Loader2 className="mr-2 h-4 w-4 animate-spin" />}
            开通
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}
```

## 版本变更对话框

```tsx
// src/pages/ops/tenants/subscribe-edition-dialog.tsx
import { useState, useEffect } from "react"
import {
  Dialog, DialogContent, DialogHeader, DialogTitle, DialogFooter,
} from "@/components/ui/dialog"
import { Button } from "@/components/ui/button"
import { Label } from "@/components/ui/label"
import { Switch } from "@/components/ui/switch"
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from "@/components/ui/select"
import { Loader2 } from "lucide-react"
import { tenantsApi } from "@/api/ops/tenants"
import { editionsApi } from "@/api/ops/editions"
import { toast } from "sonner"
import type { EditionDto, BillingCycle } from "@/types"
import { BILLING_CYCLE as BC } from "@/types"

const cycleOptions = [
  { value: String(BC.Monthly), label: "月付" },
  { value: String(BC.Yearly), label: "年付" },
]

interface SubscribeEditionDialogProps {
  open: boolean
  onOpenChange: (open: boolean) => void
  tenantId: string
  onSuccess: () => void
}

export function SubscribeEditionDialog({ open, onOpenChange, tenantId, onSuccess }: SubscribeEditionDialogProps) {
  const [loading, setLoading] = useState(false)
  const [editions, setEditions] = useState<EditionDto[]>([])
  const [form, setForm] = useState({
    editionId: "",
    cycle: String(BC.Monthly),
    autoRenew: true,
  })

  // 加载版本列表
  useEffect(() => {
    if (!open) return
    editionsApi.getList().then((res) => { setEditions(res.data ?? []) })
      .catch(() => { toast.error("获取版本列表失败") })
  }, [open])

  // 打开时重置表单
  useEffect(() => {
    if (!open) return
    setForm({ editionId: "", cycle: String(BC.Monthly), autoRenew: true })
  }, [open])

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault()
    setLoading(true)
    try {
      await tenantsApi.subscribeEdition(tenantId, {
        editionId: form.editionId,
        cycle: Number(form.cycle) as BillingCycle,
        autoRenew: form.autoRenew,
      })
      toast.success("版本变更成功")
      onOpenChange(false)
      onSuccess()
    } catch {
      toast.error("版本变更失败")
    } finally {
      setLoading(false)
    }
  }

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="sm:max-w-md">
        <DialogHeader><DialogTitle>变更版本</DialogTitle></DialogHeader>
        <form id="subscribe-form" onSubmit={handleSubmit} className="space-y-4">
          <div className="space-y-2">
            <Label>目标版本</Label>
            <Select value={form.editionId} onValueChange={(v) => setForm((p) => ({ ...p, editionId: v }))}>
              <SelectTrigger className="w-full"><SelectValue placeholder="选择版本" /></SelectTrigger>
              <SelectContent>
                {editions.map((ed) => (
                  <SelectItem key={ed.id} value={ed.id}>
                    {ed.displayName} (月付 ¥{ed.monthlyPrice} / 年付 ¥{ed.yearlyPrice})
                  </SelectItem>
                ))}
              </SelectContent>
            </Select>
          </div>
          <div className="space-y-2">
            <Label>计费周期</Label>
            <Select value={form.cycle} onValueChange={(v) => setForm((p) => ({ ...p, cycle: v }))}>
              <SelectTrigger className="w-full"><SelectValue /></SelectTrigger>
              <SelectContent>
                {cycleOptions.map((opt) => (
                  <SelectItem key={opt.value} value={opt.value}>{opt.label}</SelectItem>
                ))}
              </SelectContent>
            </Select>
          </div>
          <div className="flex items-center gap-3">
            <Switch checked={form.autoRenew}
              onCheckedChange={(checked) => setForm((p) => ({ ...p, autoRenew: checked }))} />
            <Label>自动续费</Label>
          </div>
        </form>
        <DialogFooter>
          <Button type="button" variant="outline" onClick={() => onOpenChange(false)}>取消</Button>
          <Button type="submit" form="subscribe-form" disabled={loading}>
            {loading && <Loader2 className="mr-2 h-4 w-4 animate-spin" />}
            确认变更
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}
```

## 对话框的 form 提交模式

开通和版本变更对话框都使用 `form id` + `Button form` 模式：

```tsx
<form id="provision-form" onSubmit={handleSubmit}>...</form>
<DialogFooter>
  <Button type="submit" form="provision-form">开通</Button>
</DialogFooter>
```

`Button` 不在 `<form>` 内部，但通过 `form="provision-form"` 关联到表单。这样 DialogFooter 可以独立于表单内容布局。

> **后端类比**：`form id` 关联就像 ASP.NET Core 的 `asp-handler`——按钮的 `form` 属性指定提交到哪个表单，相当于指定 `asp-handler="Create"` 或 `asp-handler="Edit"`。

## 枚举作为下拉选项

计费周期使用枚举值作为 Select 的 value：

```typescript
const cycleOptions = [
  { value: String(BC.Monthly), label: "月付" },   // value: "1"
  { value: String(BC.Yearly), label: "年付" },   // value: "2"
]

// 提交时转换回数字枚举
cycle: Number(form.cycle) as BillingCycle
```

为什么不用字符串 `"Monthly"` / `"Yearly"`？因为后端的枚举是 `int` 类型，API 期望接收数字。Select 组件的 value 必须是 string，所以用 `String()` 转换，提交时再 `Number()` 转回。

> **后端类比**：这就像 ASP.NET Core 的 `JsonConverter<StringEnumConverter>`——默认枚举序列化为 int，但前端下拉框需要字符串。`String(BC.Monthly)` 就是 `"1"`，提交时 `Number("1")` 转回 `1`。

> **🤔 导师提问**：计费周期用数字枚举（0/1/2）而非字符串（"Monthly"/"Yearly"），前端需要 `String()` → `Number()` 双向转换。在后端，你更倾向于用 `enum BillingCycle { Monthly = 1, Yearly = 2 }` 还是用字符串常量？两种方案在 API 版本兼容性上各有什么优劣？

## 版本变更对现有租户的影响

推荐"不影响"策略：变更只对新租户生效，现有租户保持原配额。如需批量更新，提供明确的"同步到现有租户"按钮。

三种级联方案：

| 方案 | 行为 | 优缺点 |
|------|------|--------|
| **A（级联更新）** | 所有该版本租户配额自动变更 | 风险：商业合同冲突 |
| **B（快照模式）** | 租户创建时拷贝配额，后续不受影响 | 安全但升级需手动 |
| **C（默认+覆盖）** | 无覆盖时跟随版本变更，有覆盖则保留 | 灵活但复杂 |

当前项目采用**方案 C**，在租户详情页的配额管理 Tab 中体现。

> **🤔 导师提问**：版本变更的三种级联方案（级联更新/快照模式/默认+覆盖）中，当前项目选择了方案 C。这三种方案本质上对应了配置继承的三种策略——覆盖（Override）、隔离（Isolate）、继承（Inherit）。在后端，你设计过类似的默认配置 + 租户级覆盖模型吗？EF Core 的 TPH/TPT 继承策略和这里的方案 C 有什么思想上的共通之处？
