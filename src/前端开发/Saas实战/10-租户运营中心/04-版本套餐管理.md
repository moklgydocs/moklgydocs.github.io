# 版本套餐管理

版本（Edition）定义了 SaaS 产品的定价、可用模块和配额策略。本节实现版本列表页、版本表单对话框（含动态模块行和配额行），以及删除确认。

---

## 版本列表页

```tsx
// src/pages/ops/editions/index.tsx
import { useEffect, useState, useCallback } from "react"
import { Button } from "@/components/ui/button"
import { Badge } from "@/components/ui/badge"
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu"
import { PageToolbar, ToolbarButton } from "@/components/shared/page-toolbar"
import { AgTable, type AgColumn } from "@/components/shared/ag-table"
import { ConfirmDialog } from "@/components/shared/confirm-dialog"
import { EditionFormDialog } from "./edition-form-dialog"
import { editionsApi } from "@/api/ops/editions"
import { toast } from "sonner"
import { Plus, RefreshCw, MoreHorizontal, Pencil, Trash } from "lucide-react"
import type { EditionDto } from "@/types"

/**
 * 版本管理页面
 * 展示租户运营中心的版本列表，支持创建、编辑和删除版本。
 * 每个版本定义了不同的定价、模块和配额策略。
 */
export default function EditionsPage() {
  const [data, setData] = useState<EditionDto[]>([])
  const [loading, setLoading] = useState(false)
  // 表单对话框与删除确认对话框状态
  const [formOpen, setFormOpen] = useState(false)
  const [editingItem, setEditingItem] = useState<EditionDto | null>(null)
  const [deleteOpen, setDeleteOpen] = useState(false)
  const [deleteTarget, setDeleteTarget] = useState<EditionDto | null>(null)
  const [deleteLoading, setDeleteLoading] = useState(false)

  /** 获取版本列表 */
  const fetchData = useCallback(async () => {
    setLoading(true)
    try {
      const res = await editionsApi.getList()
      setData(res.data ?? [])
    } catch {
      toast.error("获取版本列表失败")
    } finally {
      setLoading(false)
    }
  }, [])

  useEffect(() => { fetchData() }, [fetchData])

  /** 删除选中的版本 */
  const handleDelete = async () => {
    if (!deleteTarget) return
    setDeleteLoading(true)
    try {
      await editionsApi.delete(deleteTarget.id)
      toast.success("版本已删除")
      setDeleteOpen(false)
      fetchData()
    } catch {
      toast.error("删除失败")
    } finally {
      setDeleteLoading(false)
    }
  }

  /** 表格列定义 */
  const columns: AgColumn<EditionDto>[] = [
    {
      field: "code",
      headerName: "版本代码",
      minWidth: 120,
      flex: 1,
      cellRenderer: ({ data }) => <span className="font-mono text-sm font-medium">{data.code}</span>,
    },
    {
      field: "displayName",
      headerName: "显示名称",
      minWidth: 120,
      flex: 1,
    },
    {
      field: "monthlyPrice",
      headerName: "月度价格",
      minWidth: 100,
      width: 120,
      cellRenderer: ({ data }) => <span>¥{data.monthlyPrice.toLocaleString()}</span>,
    },
    {
      field: "yearlyPrice",
      headerName: "年度价格",
      minWidth: 100,
      width: 120,
      cellRenderer: ({ data }) => <span>¥{data.yearlyPrice.toLocaleString()}</span>,
    },
    {
      field: "isActive",
      headerName: "状态",
      width: 80,
      cellRenderer: ({ data }) => (
        <Badge variant={data.isActive ? "default" : "destructive"}>
          {data.isActive ? "启用" : "禁用"}
        </Badge>
      ),
    },
    {
      field: "sortOrder",
      headerName: "排序",
      width: 80,
    },
    {
      field: "__actions__",
      headerName: "操作",
      width: 80,
      pinned: "right",
      cellRenderer: ({ data: r }) => (
        <DropdownMenu>
          <DropdownMenuTrigger asChild>
            <Button variant="ghost" size="icon" className="h-8 w-8">
              <MoreHorizontal className="h-4 w-4" />
            </Button>
          </DropdownMenuTrigger>
          <DropdownMenuContent align="end">
            <DropdownMenuItem onClick={() => { setEditingItem(r); setFormOpen(true) }}>
              <Pencil className="mr-2 h-4 w-4" />编辑
            </DropdownMenuItem>
            <DropdownMenuItem
              className="text-destructive"
              onClick={() => { setDeleteTarget(r); setDeleteOpen(true) }}
            >
              <Trash className="mr-2 h-4 w-4" />删除
            </DropdownMenuItem>
          </DropdownMenuContent>
        </DropdownMenu>
      ),
    },
  ]

  return (
    <div className="flex flex-col h-full">
      {/* 页面工具栏：标题、新建和刷新按钮 */}
      <PageToolbar
        title="版本管理"
        actions={
          <>
            <ToolbarButton icon={Plus} variant="primary" onClick={() => { setEditingItem(null); setFormOpen(true) }}>
              新建版本
            </ToolbarButton>
            <ToolbarButton icon={RefreshCw} onClick={fetchData}>
              刷新
            </ToolbarButton>
          </>
        }
      />

      {/* 版本数据表格 */}
      <AgTable
        columns={columns}
        data={data}
        total={data.length}
        loading={loading}
        rowKey="id"
      />

> **🤔 导师提问**：版本列表页用了 `useState<EditionDto[]>` 管理数据，并通过 `fetchData()` 拉取。这和后端你在 Controller 中调用 `Mediator.Send()` 获取数据再返回给 View 的模式非常相似。但后端的数据生命周期由 DI 容器管理，前端的数据生命周期由 React 组件控制——`useEffect` 的依赖数组 `[fetchData]` 保证了什么？如果依赖数组为空 `[]`，会发生什么？

      {/* 版本创建/编辑对话框 */}
      <EditionFormDialog open={formOpen} onOpenChange={setFormOpen} item={editingItem} onSuccess={fetchData} />

      {/* 删除确认对话框 */}
      <ConfirmDialog
        open={deleteOpen}
        onOpenChange={setDeleteOpen}
        title="删除版本"
        description={`确定要删除版本「${deleteTarget?.displayName}」吗？关联的模块和配额配置也会一并删除。`}
        onConfirm={handleDelete}
        loading={deleteLoading}
      />
    </div>
  )
}
```

## 版本表单对话框

版本表单的核心难点是**动态行**——模块列表和配额列表都是可增删的动态行：

```tsx
// src/pages/ops/editions/edition-form-dialog.tsx
import { useEffect, useState } from "react"
import {
  Dialog,
  DialogContent,
  DialogHeader,
  DialogTitle,
  DialogFooter,
} from "@/components/ui/dialog"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
import { Switch } from "@/components/ui/switch"
import { Checkbox } from "@/components/ui/checkbox"
import { editionsApi } from "@/api/ops/editions"
import { toast } from "sonner"
import { Loader2, Plus, X } from "lucide-react"
import type { EditionDto, CreateEditionModuleRequest, CreateEditionQuotaRequest } from "@/types"

interface EditionFormDialogProps {
  open: boolean
  onOpenChange: (open: boolean) => void
  item: EditionDto | null
  onSuccess: () => void
}

/** 模块行表单状态 */
interface ModuleRow {
  moduleCode: string
  moduleDisplayName: string
  isIncluded: boolean
  isDefault: boolean
}

/** 配额行表单状态 */
interface QuotaRow {
  resourceType: string
  resourceName: string
  defaultValue: number
  unit: string
  isAdjustable: boolean
  sortOrder: number
}

export function EditionFormDialog({ open, onOpenChange, item, onSuccess }: EditionFormDialogProps) {
  const isEdit = !!item
  const [loading, setLoading] = useState(false)
  const [form, setForm] = useState({
    code: "",
    displayName: "",
    description: "",
    monthlyPrice: 0,
    yearlyPrice: 0,
    isActive: true,
    sortOrder: 0,
    featuresJson: "",
  })
  const [modules, setModules] = useState<ModuleRow[]>([])
  const [quotas, setQuotas] = useState<QuotaRow[]>([])

  // 对话框打开时初始化表单数据
  useEffect(() => {
    if (open) {
      setForm({
        code: item?.code ?? "",
        displayName: item?.displayName ?? "",
        description: item?.description ?? "",
        monthlyPrice: item?.monthlyPrice ?? 0,
        yearlyPrice: item?.yearlyPrice ?? 0,
        isActive: item?.isActive ?? true,
        sortOrder: item?.sortOrder ?? 0,
        featuresJson: item?.featuresJson ?? "",
      })
      setModules(
        item?.modules?.map((m) => ({
          moduleCode: m.moduleCode,
          moduleDisplayName: m.moduleDisplayName ?? "",
          isIncluded: m.isIncluded,
          isDefault: m.isDefault,
        })) ?? []
      )
      setQuotas(
        item?.quotaDefaults?.map((q) => ({
          resourceType: q.resourceType,
          resourceName: q.resourceName,
          defaultValue: q.defaultValue,
          unit: q.unit ?? "",
          isAdjustable: q.isAdjustable,
          sortOrder: q.sortOrder,
        })) ?? []
      )
    }
  }, [open, item])

  /** 添加模块行 */
  const addModule = () => {
    setModules([...modules, { moduleCode: "", moduleDisplayName: "", isIncluded: true, isDefault: false }])
  }

  /** 移除模块行 */
  const removeModule = (index: number) => {
    setModules(modules.filter((_, i) => i !== index))
  }

  /** 更新模块行字段 */
  const updateModule = (index: number, field: keyof ModuleRow, value: string | boolean) => {
    const updated = [...modules]
    updated[index] = { ...updated[index], [field]: value }
    setModules(updated)
  }

  /** 添加配额行 */
  const addQuota = () => {
    setQuotas([...quotas, { resourceType: "", resourceName: "", defaultValue: 0, unit: "", isAdjustable: true, sortOrder: 0 }])
  }

  /** 移除配额行 */
  const removeQuota = (index: number) => {
    setQuotas(quotas.filter((_, i) => i !== index))
  }

  /** 更新配额行字段 */
  const updateQuota = (index: number, field: keyof QuotaRow, value: string | number | boolean) => {
    const updated = [...quotas]
    updated[index] = { ...updated[index], [field]: value }
    setQuotas(updated)
  }

  /** 提交表单，创建或更新版本 */
  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault()
    if (!form.code || !form.displayName) {
      toast.error("版本代码和显示名称不能为空")
      return
    }

    const modulePayload: CreateEditionModuleRequest[] = modules
      .filter((m) => m.moduleCode)
      .map((m) => ({
        moduleCode: m.moduleCode,
        moduleDisplayName: m.moduleDisplayName || undefined,
        isIncluded: m.isIncluded,
        isDefault: m.isDefault,
      }))

    const quotaPayload: CreateEditionQuotaRequest[] = quotas
      .filter((q) => q.resourceType && q.resourceName)
      .map((q) => ({
        resourceType: q.resourceType,
        resourceName: q.resourceName,
        defaultValue: q.defaultValue,
        unit: q.unit || undefined,
        isAdjustable: q.isAdjustable,
        sortOrder: q.sortOrder,
      }))

    setLoading(true)
    try {
      if (isEdit) {
        await editionsApi.update(item.id, {
          displayName: form.displayName,
          description: form.description || undefined,
          monthlyPrice: form.monthlyPrice,
          yearlyPrice: form.yearlyPrice,
          isActive: form.isActive,
          sortOrder: form.sortOrder,
          featuresJson: form.featuresJson || undefined,
          modules: modulePayload,
          quotaDefaults: quotaPayload,
        })
        toast.success("版本已更新")
      } else {
        await editionsApi.create({
          code: form.code,
          displayName: form.displayName,
          description: form.description || undefined,
          monthlyPrice: form.monthlyPrice,
          yearlyPrice: form.yearlyPrice,
          sortOrder: form.sortOrder,
          featuresJson: form.featuresJson || undefined,
          modules: modulePayload,
          quotaDefaults: quotaPayload,
        })
        toast.success("版本已创建")
      }
      onSuccess()
      onOpenChange(false)
    } catch {
      toast.error(isEdit ? "更新失败" : "创建失败")
    } finally {
      setLoading(false)
    }
  }

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="sm:max-w-xl max-h-[85vh] overflow-y-auto">
        <DialogHeader>
          <DialogTitle>{isEdit ? "编辑版本" : "新建版本"}</DialogTitle>
        </DialogHeader>
        <form onSubmit={handleSubmit} className="space-y-4 py-2">
          {/* 版本代码：创建时必填，编辑时不可修改 */}
          <div className="space-y-2">
            <Label htmlFor="code">版本代码 *</Label>
            <Input
              id="code"
              placeholder="如: standard"
              value={form.code}
              onChange={(e) => setForm({ ...form, code: e.target.value })}
              disabled={isEdit}
            />
          </div>
          {/* 显示名称 */}
          <div className="space-y-2">
            <Label htmlFor="displayName">显示名称 *</Label>
            <Input
              id="displayName"
              placeholder="如: 标准版"
              value={form.displayName}
              onChange={(e) => setForm({ ...form, displayName: e.target.value })}
            />
          </div>
          {/* 描述 */}
          <div className="space-y-2">
            <Label htmlFor="description">描述</Label>
            <textarea
              id="description"
              className="flex min-h-[80px] w-full rounded-md border border-input bg-background px-3 py-2 text-sm ring-offset-background placeholder:text-muted-foreground focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:cursor-not-allowed disabled:opacity-50"
              placeholder="可选"
              value={form.description}
              onChange={(e) => setForm({ ...form, description: e.target.value })}
            />
          </div>
          {/* 月度价格 & 年度价格 */}
          <div className="grid grid-cols-2 gap-4">
            <div className="space-y-2">
              <Label htmlFor="monthlyPrice">月度价格 (¥)</Label>
              <Input
                id="monthlyPrice"
                type="number"
                min={0}
                value={form.monthlyPrice}
                onChange={(e) => setForm({ ...form, monthlyPrice: parseFloat(e.target.value) || 0 })}
              />
            </div>
            <div className="space-y-2">
              <Label htmlFor="yearlyPrice">年度价格 (¥)</Label>
              <Input
                id="yearlyPrice"
                type="number"
                min={0}
                value={form.yearlyPrice}
                onChange={(e) => setForm({ ...form, yearlyPrice: parseFloat(e.target.value) || 0 })}
              />
            </div>
          </div>
          {/* 启用开关 & 排序 */}
          <div className="grid grid-cols-2 gap-4">
            <div className="flex items-center gap-3">
              <Switch
                id="isActive"
                checked={form.isActive}
                onCheckedChange={(v: boolean) => setForm({ ...form, isActive: v })}
              />
              <Label htmlFor="isActive">启用</Label>
            </div>
            <div className="space-y-2">
              <Label htmlFor="sortOrder">排序</Label>
              <Input
                id="sortOrder"
                type="number"
                value={form.sortOrder}
                onChange={(e) => setForm({ ...form, sortOrder: parseInt(e.target.value) || 0 })}
              />
            </div>
          </div>
          {/* Features JSON */}
          <div className="space-y-2">
            <Label htmlFor="featuresJson">Features JSON</Label>
            <textarea
              id="featuresJson"
              className="flex min-h-[60px] w-full rounded-md border border-input bg-background px-3 py-2 text-sm font-mono ring-offset-background placeholder:text-muted-foreground focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:cursor-not-allowed disabled:opacity-50"
              placeholder='{"maxUsers": 100}'
              value={form.featuresJson}
              onChange={(e) => setForm({ ...form, featuresJson: e.target.value })}
            />
          </div>

          {/* ── 模块列表 ── */}
          <div className="space-y-3">
            <div className="flex items-center justify-between">
              <Label>模块列表</Label>
              <Button type="button" variant="outline" size="sm" onClick={addModule}>
                <Plus className="mr-1 h-3.5 w-3.5" />添加模块
              </Button>
            </div>
            {modules.map((mod, i) => (
              <div key={i} className="flex items-start gap-2 p-3 border rounded-md">
                <div className="flex-1 grid grid-cols-2 gap-2">
                  <Input
                    placeholder="模块代码"
                    value={mod.moduleCode}
                    onChange={(e) => updateModule(i, "moduleCode", e.target.value)}
                  />
                  <Input
                    placeholder="模块名称"
                    value={mod.moduleDisplayName}
                    onChange={(e) => updateModule(i, "moduleDisplayName", e.target.value)}
                  />
                  <div className="flex items-center gap-4 col-span-2">
                    <div className="flex items-center gap-2">
                      <Checkbox
                        checked={mod.isIncluded}
                        onCheckedChange={(v) => updateModule(i, "isIncluded", !!v)}
                      />
                      <Label className="text-xs">包含</Label>
                    </div>
                    <div className="flex items-center gap-2">
                      <Checkbox
                        checked={mod.isDefault}
                        onCheckedChange={(v) => updateModule(i, "isDefault", !!v)}
                      />
                      <Label className="text-xs">默认</Label>
                    </div>
                  </div>
                </div>
                <Button type="button" variant="ghost" size="icon" className="h-8 w-8 shrink-0" onClick={() => removeModule(i)}>
                  <X className="h-4 w-4" />
                </Button>
              </div>
            ))}
          </div>

          {/* ── 配额默认值列表 ── */}
          <div className="space-y-3">
            <div className="flex items-center justify-between">
              <Label>配额默认值</Label>
              <Button type="button" variant="outline" size="sm" onClick={addQuota}>
                <Plus className="mr-1 h-3.5 w-3.5" />添加配额
              </Button>
            </div>
            {quotas.map((q, i) => (
              <div key={i} className="flex items-start gap-2 p-3 border rounded-md">
                <div className="flex-1 grid grid-cols-2 gap-2">
                  <Input
                    placeholder="资源类型"
                    value={q.resourceType}
                    onChange={(e) => updateQuota(i, "resourceType", e.target.value)}
                  />
                  <Input
                    placeholder="资源名称"
                    value={q.resourceName}
                    onChange={(e) => updateQuota(i, "resourceName", e.target.value)}
                  />
                  <Input
                    placeholder="默认值"
                    type="number"
                    value={q.defaultValue}
                    onChange={(e) => updateQuota(i, "defaultValue", parseFloat(e.target.value) || 0)}
                  />
                  <Input
                    placeholder="单位"
                    value={q.unit}
                    onChange={(e) => updateQuota(i, "unit", e.target.value)}
                  />
                  <div className="flex items-center gap-4 col-span-2">
                    <div className="flex items-center gap-2">
                      <Checkbox
                        checked={q.isAdjustable}
                        onCheckedChange={(v) => updateQuota(i, "isAdjustable", !!v)}
                      />
                      <Label className="text-xs">可调整</Label>
                    </div>
                    <div className="flex items-center gap-2">
                      <Label className="text-xs">排序</Label>
                      <Input
                        type="number"
                        className="w-20 h-7 text-xs"
                        value={q.sortOrder}
                        onChange={(e) => updateQuota(i, "sortOrder", parseInt(e.target.value) || 0)}
                      />
                    </div>
                  </div>
                </div>
                <Button type="button" variant="ghost" size="icon" className="h-8 w-8 shrink-0" onClick={() => removeQuota(i)}>
                  <X className="h-4 w-4" />
                </Button>
              </div>
            ))}
          </div>

          <DialogFooter>
            <Button type="button" variant="outline" onClick={() => onOpenChange(false)} disabled={loading}>
              取消
            </Button>
            <Button type="submit" disabled={loading}>
              {loading && <Loader2 className="mr-2 h-4 w-4 animate-spin" />}
              {isEdit ? "保存" : "创建"}
            </Button>
          </DialogFooter>
        </form>
      </DialogContent>
    </Dialog>
  )
}
```

## 动态行的增删改模式

模块和配额都使用**数组 + 展开更新**模式：

```typescript
// 添加：展开原数组，追加新行
const addModule = () => {
  setModules([...modules, { moduleCode: "", moduleDisplayName: "", isIncluded: true, isDefault: false }])
}

// 删除：filter 过滤掉目标索引
const removeModule = (index: number) => {
  setModules(modules.filter((_, i) => i !== index))
}

// 更新：展开目标索引行，覆盖单个字段
const updateModule = (index: number, field: keyof ModuleRow, value: string | boolean) => {
  const updated = [...modules]
  updated[index] = { ...updated[index], [field]: value }
  setModules(updated)
}
```

> **后端类比**：动态行操作就像 EF Core 的集合导航属性——`addModule` 对应 `Edition.Modules.Add()`，`removeModule` 对应 `Edition.Modules.Remove()`，`updateModule` 对应修改导航属性中某个实体的字段。展开运算符 `[...modules]` 就是 `AsNoTracking()` 的深拷贝。

> **🤔 导师提问**：动态行的"展开更新"模式 `const updated = [...modules]; updated[i] = { ...updated[i], [field]: value }` 保证了不可变性（immutable update）。在后端 EF Core 中，你修改导航属性直接赋值即可，ChangeTracker 会自动追踪。为什么前端必须用不可变更新？如果直接 `modules[i].moduleCode = "new"`，React 会感知到变化吗？

## 版本代码的创建/编辑差异

```typescript
// 创建时：code 可编辑
<Input value={form.code} onChange={...} disabled={isEdit} />

// 提交时：编辑模式不发送 code
if (isEdit) {
  await editionsApi.update(item.id, {
    displayName: form.displayName,  // 不含 code
    ...
  })
} else {
  await editionsApi.create({
    code: form.code,  // 含 code
    ...
  })
}
```

版本代码创建后不可修改，这是业务规则——代码作为系统内部标识，修改会影响 API 路由和权限映射。

> **🤔 导师提问**：版本代码（code）创建后不可修改，Input 设置了 `disabled={isEdit}`。提交时编辑模式不发送 code。在后端，你通常用 `[ReadOnlyAfterCreate]` 之类的自定义验证或在 UpdateDTO 中排除 code 来实现。前端的 `disabled` 只是 UI 层面的约束——如果有人绕过前端直接调 API 修改 code 呢？前后端各应承担什么层级的防护？

> **后端类比**：这就像主键不可修改——`code` 是版本的自然键，对应数据库的 `UNIQUE` 约束。`CreateEditionRequest` 包含 `code`，`UpdateEditionRequest` 不包含 `code`。

## 提交前的数据清理

```typescript
// 过滤掉空行，空字段设为 undefined（不发送给后端）
const modulePayload: CreateEditionModuleRequest[] = modules
  .filter((m) => m.moduleCode)  // 过滤空行
  .map((m) => ({
    moduleCode: m.moduleCode,
    moduleDisplayName: m.moduleDisplayName || undefined,  // 空字符串 → 不发送
    isIncluded: m.isIncluded,
    isDefault: m.isDefault,
  }))
```

> **后端类比**：`filter` 空行就像后端的 `ModelState` 验证——`[Required]` 字段为空时跳过。`|| undefined` 就像 `[JsonProperty(NullValueHandling = NullValueHandling.Ignore)]`——空值不序列化。

> **🤔 导师提问**：提交前用 `.filter(m => m.moduleCode)` 过滤空行，用 `|| undefined` 将空字符串转为 undefined。后端的 `[Required]` 验证会在 Model Binding 阶段拒绝空值，而前端是主动过滤掉。这两种策略在用户体验上有什么差异？如果后端的 `moduleCode` 标记了 `[Required]`，前端不过滤空行直接提交，会发生什么？

## 小结

| 要点 | 说明 |
|------|------|
| 列表页 | `AgTable` + `PageToolbar` + `DropdownMenu` 操作列 |
| 表单对话框 | `EditionFormDialog` 含动态模块行和配额行 |
| 动态行模式 | 数组 + 展开更新（add/remove/update） |
| 版本代码 | 创建时必填，编辑时不可修改 |
| 数据清理 | 提交前 filter 空行，空字符串 → undefined |
| 删除确认 | `ConfirmDialog` + loading 状态 |

> **🤔 导师提问**：删除确认用 `ConfirmDialog`，但版本编辑却直接在表单对话框中完成，没有额外的确认步骤。暂停/终止租户（下一篇）也有确认对话框。什么类型的操作需要确认，什么不需要？这和后端写操作需要审计日志的思路有什么对应关系？

> **🔍 验证步骤**
>
> 1. 在运营中心页面点击新建版本，填写版本代码（如 `test-edition`）、显示名称、价格，点击创建——观察 Network 面板是否发送 `POST /ops-api/api/tenant-ops/editions`，返回值是否为新建版本的 ID（string）
> 2. 在新建版本对话框中添加 2 个模块行和 1 个配额行，提交后刷新页面——确认版本列表中新版本的模块数和配额数正确
> 3. 点击版本操作菜单的编辑，确认版本代码字段为灰色不可编辑，而显示名称可以修改
> 4. 点击删除版本，确认弹出 ConfirmDialog，输入原因后提交——观察 Network 请求为 `DELETE /ops-api/api/tenant-ops/editions/{id}`
> 5. 故意在模块行中留一行空的 moduleCode，提交后确认该空行被过滤掉、不会发送给后端
