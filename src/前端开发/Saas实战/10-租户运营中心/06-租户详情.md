# 租户详情

租户详情页是运营中心信息密度最高的页面——6 个 Tab 覆盖概览、配额、模块、功能开关、健康检查和操作日志。核心难点是配额内联编辑的脏数据追踪。

> **🤔 导师提问**：6 个 Tab 的数据源各不相同（Dashboard/Quotas/Modules/Features/Health/Logs），页面初始化时用 `Promise.all` 并行加载。在后端，你习惯用 MediatR 发送多个 Query，但通常是串行的。前端为什么选择并行加载？如果其中一个请求失败，`Promise.all` 会怎样？应该用 `Promise.allSettled` 吗？

## 完整实现

```tsx
// src/pages/ops/tenants/detail/index.tsx
import { useEffect, useState } from "react"
import { useParams, useNavigate } from "react-router-dom"
import { ArrowLeft, Save } from "lucide-react"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card"
import { Switch } from "@/components/ui/switch"
import { Badge } from "@/components/ui/badge"
import { Progress } from "@/components/ui/progress"
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs"
import {
  Table, TableBody, TableCell, TableHead, TableHeader, TableRow,
} from "@/components/ui/table"
import { toast } from "sonner"
import {
  getTenantDashboard, getTenantQuotas, updateTenantQuota,
  getTenantModules, toggleTenantModule, getTenantFeatures, setTenantFeature,
  getTenantHealth, getTenantOperations,
  TENANT_STATUS, HEALTH_STATUS,
  type TenantDashboardDto, type TenantQuotaDto,
  type TenantModuleAccessDto, type TenantFeatureFlagDto,
  type TenantHealthCheckDto, type TenantOperationLogDto,
} from "@/api/ops/tenants"

function HealthBadge({ status }: { status: HEALTH_STATUS }) {
  const cfg = {
    [HEALTH_STATUS.Healthy]: { label: "健康", variant: "default" as const },
    [HEALTH_STATUS.Degraded]: { label: "降级", variant: "secondary" as const },
    [HEALTH_STATUS.Unhealthy]: { label: "异常", variant: "destructive" as const },
  }
  const c = cfg[status]
  return <Badge variant={c.variant}>{c.label}</Badge>
}

export default function OpsTenantDetailPage() {
  const { id } = useParams<{ id: string }>()
  const navigate = useNavigate()

  const [dashboard, setDashboard] = useState<TenantDashboardDto | null>(null)
  const [quotas, setQuotas] = useState<TenantQuotaDto[]>([])
  const [modules, setModules] = useState<TenantModuleAccessDto[]>([])
  const [features, setFeatures] = useState<TenantFeatureFlagDto[]>([])
  const [health, setHealth] = useState<TenantHealthCheckDto | null>(null)
  const [logs, setLogs] = useState<TenantOperationLogDto[]>([])
  const [loading, setLoading] = useState(true)

  // 配额编辑状态：quotaId → 新的 quotaLimit
  const [editedQuotas, setEditedQuotas] = useState<Record<string, number>>({})

  const fetchAll = async () => {
    if (!id) return
    setLoading(true)
    try {
      const [dash, q, m, f, h, l] = await Promise.all([
        getTenantDashboard(id), getTenantQuotas(id), getTenantModules(id),
        getTenantFeatures(id), getTenantHealth(id), getTenantOperations(id),
      ])
      setDashboard(dash); setQuotas(q); setModules(m)
      setFeatures(f); setHealth(h); setLogs(l)
    } catch { toast.error("加载租户详情失败") }
    finally { setLoading(false) }
  }

  useEffect(() => { fetchAll() }, [id])

  const handleSaveQuota = async (quotaId: string) => {
    if (!id || editedQuotas[quotaId] === undefined) return
    try {
      await updateTenantQuota(id, quotaId, editedQuotas[quotaId])
      toast.success("配额已更新")
      const q = await getTenantQuotas(id)
      setQuotas(q)
      setEditedQuotas((prev) => { const next = { ...prev }; delete next[quotaId]; return next })
    } catch { toast.error("更新配额失败") }
  }

  const handleToggleModule = async (moduleCode: string, isEnabled: boolean) => {
    if (!id) return
    try {
      await toggleTenantModule(id, moduleCode, !isEnabled)
      toast.success(`模块已${isEnabled ? "禁用" : "启用"}`)
      setModules(await getTenantModules(id))
    } catch { toast.error("操作失败") }
  }

  const handleToggleFeature = async (featureKey: string, currentEnabled: boolean) => {
    if (!id) return
    try {
      await setTenantFeature(id, featureKey, !currentEnabled)
      toast.success(`功能已${currentEnabled ? "关闭" : "开启"}`)
      setFeatures(await getTenantFeatures(id))
    } catch { toast.error("操作失败") }
  }

  if (loading) return <div className="p-6 text-muted-foreground">加载中...</div>
  if (!dashboard) return <div className="p-6 text-destructive">租户不存在</div>

  return (
    <div className="p-6 space-y-6">
      <div className="flex items-center gap-3">
        <Button variant="ghost" size="icon" onClick={() => navigate("/ops/tenants")}>
          <ArrowLeft className="h-5 w-5" />
        </Button>
        <h1 className="text-2xl font-bold">{dashboard.tenantName}</h1>
        <Badge variant="outline" className="font-mono">{dashboard.tenantIdentifier}</Badge>
      </div>

      <Tabs defaultValue="overview">
        <TabsList>
          <TabsTrigger value="overview">概览</TabsTrigger>
          <TabsTrigger value="quotas">配额</TabsTrigger>
          <TabsTrigger value="modules">模块</TabsTrigger>
          <TabsTrigger value="features">功能开关</TabsTrigger>
          <TabsTrigger value="health">健康</TabsTrigger>
          <TabsTrigger value="logs">操作日志</TabsTrigger>
        </TabsList>

        {/* Tab 1: 概览 */}
        <TabsContent value="overview">
          <div className="grid grid-cols-2 lg:grid-cols-4 gap-4 mt-4">
            <Card><CardHeader className="pb-2"><CardTitle className="text-sm text-muted-foreground">租户名称</CardTitle></CardHeader>
              <CardContent><div className="text-lg font-bold">{dashboard.tenantName}</div></CardContent></Card>
            <Card><CardHeader className="pb-2"><CardTitle className="text-sm text-muted-foreground">租户标识</CardTitle></CardHeader>
              <CardContent><div className="font-mono">{dashboard.tenantIdentifier}</div></CardContent></Card>
            <Card><CardHeader className="pb-2"><CardTitle className="text-sm text-muted-foreground">当前版本</CardTitle></CardHeader>
              <CardContent><div className="font-medium">{dashboard.edition}</div></CardContent></Card>
            <Card><CardHeader className="pb-2"><CardTitle className="text-sm text-muted-foreground">租户 ID</CardTitle></CardHeader>
              <CardContent><div className="font-mono text-sm">{dashboard.tenantId}</div></CardContent></Card>
          </div>
        </TabsContent>

        {/* Tab 2: 配额（内联编辑 + 进度条） */}
        <TabsContent value="quotas">
          <Card className="mt-4"><CardContent className="p-0">
            <Table>
              <TableHeader><TableRow>
                <TableHead>资源名称</TableHead><TableHead>当前使用</TableHead>
                <TableHead>配额上限</TableHead><TableHead>使用率</TableHead>
                <TableHead>单位</TableHead><TableHead>硬限制</TableHead>
                <TableHead className="text-right">操作</TableHead>
              </TableRow></TableHeader>
              <TableBody>
                {quotas.map((q) => (
                  <TableRow key={q.id}>
                    <TableCell className="font-medium">{q.resourceName}</TableCell>
                    <TableCell>{q.currentUsage.toLocaleString()}</TableCell>
                    <TableCell>
                      <Input type="number" className="w-24"
                        value={editedQuotas[q.id] ?? q.quotaLimit}
                        onChange={(e) => setEditedQuotas((prev) => ({ ...prev, [q.id]: Number(e.target.value) }))} />
                    </TableCell>
                    <TableCell className="w-40">
                      <div className="flex items-center gap-2">
                        <Progress value={Math.min(q.usagePercentage, 100)}
                          className={`h-2 ${q.usagePercentage > 90 ? "[&>div]:bg-red-500" : q.usagePercentage > 70 ? "[&>div]:bg-yellow-500" : ""}`} />
                        <span className="text-xs w-10 text-right">{q.usagePercentage.toFixed(0)}%</span>
                      </div>
                    </TableCell>
                    <TableCell>{q.unit}</TableCell>
                    <TableCell>
                      <Badge variant={q.isHardLimit ? "destructive" : "secondary"}>
                        {q.isHardLimit ? "是" : "否"}</Badge>
                    </TableCell>
                    <TableCell className="text-right">
                      {editedQuotas[q.id] !== undefined && editedQuotas[q.id] !== q.quotaLimit && (
                        <Button size="sm" onClick={() => handleSaveQuota(q.id)}>
                          <Save className="mr-1 h-3 w-3" /> 保存</Button>
                      )}
                    </TableCell>
                  </TableRow>
                ))}
              </TableBody>
            </Table>
          </CardContent></Card>
        </TabsContent>

        {/* Tab 3: 模块 */}
        <TabsContent value="modules">
          <Card className="mt-4"><CardContent className="p-0">
            <Table><TableHeader><TableRow>
              <TableHead>模块代码</TableHead><TableHead>模块名称</TableHead><TableHead>状态</TableHead>
            </TableRow></TableHeader>
            <TableBody>
              {modules.map((m) => (
                <TableRow key={m.moduleCode}>
                  <TableCell className="font-mono">{m.moduleCode}</TableCell>
                  <TableCell className="font-medium">{m.moduleDisplayName}</TableCell>
                  <TableCell>
                    <div className="flex items-center gap-2">
                      <Switch checked={m.isEnabled} onCheckedChange={() => handleToggleModule(m.moduleCode, m.isEnabled)} />
                      <span className="text-sm">{m.isEnabled ? "已启用" : "已禁用"}</span>
                    </div>
                  </TableCell>
                </TableRow>
              ))}
            </TableBody></Table>
          </CardContent></Card>
        </TabsContent>

        {/* Tab 4: 功能开关 */}
        <TabsContent value="features">
          <Card className="mt-4"><CardContent className="p-0">
            <Table><TableHeader><TableRow>
              <TableHead>功能键</TableHead><TableHead>显示名称</TableHead>
              <TableHead>描述</TableHead><TableHead>值</TableHead><TableHead>状态</TableHead>
            </TableRow></TableHeader>
            <TableBody>
              {features.map((f) => (
                <TableRow key={f.featureKey}>
                  <TableCell className="font-mono">{f.featureKey}</TableCell>
                  <TableCell className="font-medium">{f.displayName}</TableCell>
                  <TableCell className="text-muted-foreground text-sm">{f.description}</TableCell>
                  <TableCell className="font-mono text-xs">{f.valueJson}</TableCell>
                  <TableCell>
                    <div className="flex items-center gap-2">
                      <Switch checked={f.isEnabled} onCheckedChange={() => handleToggleFeature(f.featureKey, f.isEnabled)} />
                      <span className="text-sm">{f.isEnabled ? "开启" : "关闭"}</span>
                    </div>
                  </TableCell>
                </TableRow>
              ))}
            </TableBody></Table>
          </CardContent></Card>
        </TabsContent>

        {/* Tab 5: 健康 */}
        <TabsContent value="health">
          {health && (
            <div className="grid grid-cols-2 lg:grid-cols-4 gap-4 mt-4">
              <Card><CardHeader className="pb-2"><CardTitle className="text-sm text-muted-foreground">总体状态</CardTitle></CardHeader>
                <CardContent><HealthBadge status={health.overallStatus} /></CardContent></Card>
              <Card><CardHeader className="pb-2"><CardTitle className="text-sm text-muted-foreground">活跃用户</CardTitle></CardHeader>
                <CardContent><div className="text-2xl font-bold">{health.activeUsersCount.toLocaleString()}</div></CardContent></Card>
              <Card><CardHeader className="pb-2"><CardTitle className="text-sm text-muted-foreground">存储用量</CardTitle></CardHeader>
                <CardContent><div className="text-lg font-bold">{(health.storageUsedBytes / 1024 / 1024).toFixed(1)} MB</div></CardContent></Card>
              <Card><CardHeader className="pb-2"><CardTitle className="text-sm text-muted-foreground">今日 API 请求数</CardTitle></CardHeader>
                <CardContent><div className="text-2xl font-bold">{health.apiRequestsToday.toLocaleString()}</div></CardContent></Card>
            </div>
          )}
        </TabsContent>

        {/* Tab 6: 操作日志 */}
        <TabsContent value="logs">
          <Card className="mt-4"><CardContent className="p-0">
            <Table><TableHeader><TableRow>
              <TableHead>操作类型</TableHead><TableHead>详情</TableHead>
              <TableHead>操作人</TableHead><TableHead>IP 地址</TableHead><TableHead>时间</TableHead>
            </TableRow></TableHeader>
            <TableBody>
              {logs.map((log, i) => (
                <TableRow key={i}>
                  <TableCell><Badge variant="outline">{log.operationType}</Badge></TableCell>
                  <TableCell className="max-w-xs truncate">{log.detail}</TableCell>
                  <TableCell>{log.operatorName}</TableCell>
                  <TableCell className="font-mono text-xs">{log.clientIpAddress}</TableCell>
                  <TableCell className="text-sm">{new Date(log.creationTime).toLocaleString()}</TableCell>
                </TableRow>
              ))}
            </TableBody></Table>
          </CardContent></Card>
        </TabsContent>
      </Tabs>
    </div>
  )
}
```

## 配额内联编辑的脏数据追踪

租户详情页的配额 Tab 支持**内联编辑**——直接在表格行内修改配额值。核心难点是追踪"哪些行被修改了"：

```typescript
// 使用 Record<quotaId, newValue> 追踪修改
const [editedQuotas, setEditedQuotas] = useState<Record<string, number>>({})

// 判断某行是否有未保存的修改
const isDirty = (quota: TenantQuotaDto) =>
  editedQuotas[quota.id] !== undefined && editedQuotas[quota.id] !== quota.quotaLimit

// 保存后清除脏标记
const handleSave = async (quotaId: string) => {
  await updateTenantQuota(tenantId, quotaId, editedQuotas[quotaId])
  setEditedQuotas(prev => {
    const next = { ...prev }
    delete next[quotaId]
    return next
  })
}
```

这比"全量保存"更高效——只提交修改过的行，减少网络请求和后端校验压力。

> **后端类比**：脏数据追踪就像 EF Core 的 `ChangeTracker`——只提交 `EntityState.Modified` 的实体。前端用 `Record<string, number>` 代替 `ChangeTracker`，效果相同。

> **🤔 导师提问**：`editedQuotas` 是一个 `Record<string, number>`，只存储修改过的配额 ID 和新值。这和 EF Core ChangeTracker 的"快照式对比"有何异同？ChangeTracker 在首次追踪时保存原始值快照，而 `editedQuotas` 是通过比较 `editedQuotas[id] !== quota.quotaLimit` 来判断脏状态。哪种方式更可靠？

### 使用率可视化

配额使用率通过 Progress 进度条 + 颜色分级展示：

- **正常**：默认蓝色
- **>70%**：黄色 `[&>div]:bg-yellow-500`
- **>90%**：红色 `[&>div]:bg-red-500`

> **🤔 导师提问**：配额使用率用颜色分级（蓝/黄/红）提供视觉反馈。在后端，你可能用 Health Check 的 `HealthStatus`（Healthy/Degraded/Unhealthy）枚举来表达类似的概念。前端的颜色分级是硬编码的阈值（70%/90%），如果这些阈值需要按租户配置，前端应该如何改造？提示：考虑 CSS 变量或 Theme Token。

## 6 个 Tab 的职责

| Tab | 数据源 | 交互方式 |
|-----|-------|---------|
| 概览 | `getTenantDashboard` | 只读展示 |
| 配额 | `getTenantQuotas` | 内联编辑 + 逐行保存 |
| 模块 | `getTenantModules` | Switch 切换 |
| 功能开关 | `getTenantFeatures` | Switch 切换 |
| 健康 | `getTenantHealth` | 只读展示 + 状态徽章 |
| 操作日志 | `getTenantOperations` | 只读列表 |

---

> **🤔 导师提问**：租户详情页有 6 个 Tab，但用户可能只想看其中一个。`Tabs` 组件默认加载第一个 Tab，其他 Tab 的内容也会渲染（只是 CSS 隐藏）。如果某个 Tab 的数据加载很重（比如操作日志有分页），应该用什么策略优化？提示：考虑 React.lazy 或条件渲染。

> **🔍 验证步骤**
>
> 1. 从租户管理页面点击"查看详情"，确认跳转到 `/ops/tenants/{id}` 页面，6 个 Tab 正常显示
> 2. 切换到"配额" Tab，修改某个配额上限值——确认"保存"按钮只在值被修改时出现
> 3. 点击"保存"，观察 Network 面板发送 `PUT /ops-api/api/tenant-ops/tenants/{id}/quotas`，保存后保存按钮消失
> 4. 切换到"模块" Tab，点击某个模块的 Switch——确认状态切换后列表自动刷新
> 5. 切换到"健康" Tab，确认展示总体状态、活跃用户数、存储用量和 API 请求数

## 小结

| 要点 | 说明 |
|------|------|
| 6 个 Tab | 概览/配额/模块/功能开关/健康/日志 |
| 配额内联编辑 | `editedQuotas` 脏数据追踪 + 逐行保存 |
| 使用率可视化 | Progress + 颜色分级（蓝/黄/红） |
| 模块/功能开关 | Switch 逐行切换 + 刷新列表 |

> **🤔 导师提问**：模块和功能开关都使用 Switch 切换，但它们调用的 API 不同——`toggleModule` vs `setFeature`。观察 `handleToggleModule` 和 `handleToggleFeature` 的实现，它们都遵循"切换 → 调 API → 刷新列表"的模式。在后端，这就像 Command → Handler → 返回结果。如果切换失败，Switch 应该回滚到原始状态——当前代码是怎么处理的？
| 健康检查 | HealthBadge + 关键指标卡片 |
