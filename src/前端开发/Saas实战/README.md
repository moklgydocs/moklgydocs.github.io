# SaaS 实战开发

> 面向后端开发者的 React 企业级实战教程，从零搭建完整 SaaS 管理平台。
> 参考项目：[AdminWeb](../..) — 已上线可用的真实项目。

## 两个目录的关系

| 目录 | 用途 | 路径 |
|------|------|------|
| 文档 | 知识讲解 + 代码讲解 + 自测题 | `E:\博客\moklgydocs.github.io\src\前端开发\Saas实战\` |
| 代码 | 可运行的完整项目 | `E:\项目\asp.net core\Saas\CommonSaas\Web\SaasWeb\` |

**学习方式**：先读文档理解原理，再在代码目录中动手实现，每一步都可运行验证。

## 每个步骤文档的结构

```
## 本步目标
  — 这一步要完成什么，完成后能看到什么效果

## 前置知识
  — 需要理解的概念（配后端类比，如"Zustand 就像 C# 的 Scoped Service"）

## 代码实现
  — 完整可运行的代码，与 AdminWeb 保持一致
  — 每段代码后紧跟逐行讲解

## 代码讲解
  — 关键设计决策的 Why
  — 与后端/其他语言的对比
  — 【易错点】【性能陷阱】【设计取舍】标记

## 踩坑提醒
  — 这一步最容易犯的错

## 自测题
  — 概念级 / 推理级 / 动手级 三级递进

## 输出检查清单
  — 本步完成后你应该掌握的知识点
```
