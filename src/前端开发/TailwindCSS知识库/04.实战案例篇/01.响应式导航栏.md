# 案例 1：响应式导航栏

> **TL;DR**
> 用纯 Tailwind 实现一个生产级响应式导航栏：移动端汉堡菜单 + 桌面端水平导航 + 滚动吸顶 + 活跃状态高亮。涵盖 `md:hidden`、`group`、`transition` 等核心用法。

## 目标效果

```
桌面端 (≥768px):
┌────────────────────────────────────────────────┐
│ 🏪 GlobalMart   首页  订单  商品  用户   [头像] │
└────────────────────────────────────────────────┘

移动端 (<768px):
┌──────────────────────┐
│ 🏪 GlobalMart    ☰   │
├──────────────────────┤
│ 首页                  │ ← 点击 ☰ 展开
│ 订单                  │
│ 商品                  │
│ 用户                  │
└──────────────────────┘
```

## 完整实现

```tsx
// src/components/layout/navbar.tsx
import { useState, useEffect } from "react";
import { cn } from "@/lib/utils";

interface NavItem {
  label: string;
  href: string;
}

const navItems: NavItem[] = [
  { label: "首页", href: "/" },
  { label: "订单管理", href: "/orders" },
  { label: "商品中心", href: "/products" },
  { label: "用户管理", href: "/users" },
];

function Navbar() {
  const [mobileMenuOpen, setMobileMenuOpen] = useState(false);
  const [scrolled, setScrolled] = useState(false);
  const [activeItem, setActiveItem] = useState("/");

  // 监听滚动，实现吸顶阴影效果
  useEffect(() => {
    function handleScroll() {
      setScrolled(window.scrollY > 10);
    }
    window.addEventListener("scroll", handleScroll, { passive: true });
    return () => window.removeEventListener("scroll", handleScroll);
  }, []);

  // 窗口变大时自动关闭移动菜单
  useEffect(() => {
    function handleResize() {
      if (window.innerWidth >= 768) setMobileMenuOpen(false);
    }
    window.addEventListener("resize", handleResize);
    return () => window.removeEventListener("resize", handleResize);
  }, []);

  return (
    <header
      className={cn(
        "fixed top-0 left-0 right-0 z-50 border-b bg-background/95 backdrop-blur transition-shadow duration-300",
        scrolled && "shadow-md"
      )}
    >
      <div className="mx-auto flex h-16 max-w-7xl items-center justify-between px-4 md:px-8">
        {/* Logo */}
        <a href="/" className="flex items-center gap-2 text-lg font-bold">
          <span className="text-2xl">🏪</span>
          <span className="bg-gradient-to-r from-blue-600 to-purple-600 bg-clip-text text-transparent">
            GlobalMart
          </span>
        </a>

        {/* 桌面端导航（md 以上显示） */}
        <nav className="hidden items-center gap-1 md:flex">
          {navItems.map((item) => (
            <a
              key={item.href}
              href={item.href}
              onClick={(e) => {
                e.preventDefault();
                setActiveItem(item.href);
              }}
              className={cn(
                "rounded-md px-3 py-2 text-sm font-medium transition-colors",
                activeItem === item.href
                  ? "bg-primary/10 text-primary"
                  : "text-muted-foreground hover:bg-muted hover:text-foreground"
              )}
            >
              {item.label}
            </a>
          ))}
        </nav>

        {/* 桌面端右侧操作区 */}
        <div className="hidden items-center gap-4 md:flex">
          <button className="relative rounded-md p-2 hover:bg-muted">
            <svg
              xmlns="http://www.w3.org/2000/svg"
              className="h-5 w-5"
              fill="none"
              viewBox="0 0 24 24"
              stroke="currentColor"
            >
              <path
                strokeLinecap="round"
                strokeLinejoin="round"
                strokeWidth={2}
                d="M15 17h5l-1.405-1.405A2.032 2.032 0 0118 14.158V11a6.002 6.002 0 00-4-5.659V5a2 2 0 10-4 0v.341C7.67 6.165 6 8.388 6 11v3.159c0 .538-.214 1.055-.595 1.436L4 17h5m6 0v1a3 3 0 11-6 0v-1m6 0H9"
              />
            </svg>
            {/* 通知徽标 */}
            <span className="absolute -right-0.5 -top-0.5 flex h-4 w-4 items-center justify-center rounded-full bg-red-500 text-[10px] font-bold text-white">
              3
            </span>
          </button>

          <div className="h-8 w-8 overflow-hidden rounded-full bg-gradient-to-br from-blue-400 to-purple-500">
            <img
              src="https://api.dicebear.com/7.x/avataaars/svg?seed=admin"
              alt="头像"
              className="h-full w-full object-cover"
            />
          </div>
        </div>

        {/* 移动端汉堡按钮（md 以下显示） */}
        <button
          onClick={() => setMobileMenuOpen(!mobileMenuOpen)}
          className="rounded-md p-2 hover:bg-muted md:hidden"
          aria-label="切换菜单"
        >
          <div className="flex h-5 w-5 flex-col items-center justify-center gap-1">
            <span
              className={cn(
                "block h-0.5 w-5 bg-foreground transition-all duration-300",
                mobileMenuOpen && "translate-y-[6px] rotate-45"
              )}
            />
            <span
              className={cn(
                "block h-0.5 w-5 bg-foreground transition-all duration-300",
                mobileMenuOpen && "opacity-0"
              )}
            />
            <span
              className={cn(
                "block h-0.5 w-5 bg-foreground transition-all duration-300",
                mobileMenuOpen && "-translate-y-[6px] -rotate-45"
              )}
            />
          </div>
        </button>
      </div>

      {/* 移动端下拉菜单 */}
      <div
        className={cn(
          "overflow-hidden border-t transition-all duration-300 md:hidden",
          mobileMenuOpen ? "max-h-80 opacity-100" : "max-h-0 opacity-0 border-t-0"
        )}
      >
        <nav className="flex flex-col gap-1 px-4 py-3">
          {navItems.map((item) => (
            <a
              key={item.href}
              href={item.href}
              onClick={(e) => {
                e.preventDefault();
                setActiveItem(item.href);
                setMobileMenuOpen(false);
              }}
              className={cn(
                "rounded-md px-3 py-2.5 text-sm font-medium transition-colors",
                activeItem === item.href
                  ? "bg-primary/10 text-primary"
                  : "text-muted-foreground hover:bg-muted hover:text-foreground"
              )}
            >
              {item.label}
            </a>
          ))}
        </nav>
      </div>
    </header>
  );
}

export { Navbar };
```

## 知识点解析

### 1. 响应式切换核心

```tsx
// 桌面导航：移动端隐藏
<nav className="hidden md:flex">

// 汉堡按钮：桌面端隐藏
<button className="md:hidden">

// 移动菜单：桌面端隐藏
<div className="md:hidden">
```

核心就是 `hidden` + `md:flex/block` 的搭配——**移动优先**，默认隐藏，到 `md` 断点才显示。

### 2. 汉堡按钮动画

```tsx
// 三条线变 X 的技巧：
// 第一条线：下移 + 旋转 45°
"translate-y-[6px] rotate-45"
// 中间线：透明消失
"opacity-0"
// 第三条线：上移 + 反向旋转 45°
"-translate-y-[6px] -rotate-45"
```

### 3. 展开/收起动画

```tsx
// 用 max-height 实现展开收起
mobileMenuOpen ? "max-h-80 opacity-100" : "max-h-0 opacity-0"
// 配合 overflow-hidden + transition-all 实现平滑过渡
```

### 4. 滚动吸顶

```tsx
// 固定定位 + 背景模糊 + 条件阴影
"fixed top-0 left-0 right-0 z-50 bg-background/95 backdrop-blur"
scrolled && "shadow-md"
```

## 避坑指南

**坑：移动菜单展开时，页面仍可滚动**

```tsx
// 修复：展开时锁定 body 滚动
useEffect(() => {
  if (mobileMenuOpen) {
    document.body.style.overflow = "hidden";
  } else {
    document.body.style.overflow = "";
  }
  return () => { document.body.style.overflow = ""; };
}, [mobileMenuOpen]);
```

**坑：`backdrop-blur` 在某些安卓浏览器不生效**

```css
/* 降级方案：不支持 backdrop-blur 时用纯色背景 */
@supports not (backdrop-filter: blur(8px)) {
  header { @apply bg-background; }
}
```
