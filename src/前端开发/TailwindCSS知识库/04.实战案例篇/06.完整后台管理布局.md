# 案例 6：完整后台管理布局

> **TL;DR**
> 用纯 Tailwind 构建一个生产级的后台管理系统布局：可折叠侧边栏（展开/收起动画）、固定顶栏、面包屑导航、内容区滚动隔离、移动端抽屉菜单。这是所有中后台项目的布局骨架。

import { cn } from "@/lib/utils";

interface MenuItem {
  icon: React.ReactNode;
  label: string;
  href: string;
  children?: Array<{ label: string; href: string }>;
}

const menuItems: MenuItem[] = [
  {
    icon: <BarChartIcon />,
    label: "运营大盘",
    href: "/dashboard",
  },
  {
    icon: <PackageIcon />,

      { label: "订单列表", href: "/orders/list" },
      { label: "订单统计", href: "/orders/stats" },

    label: "商品中心",
    href: "/products",

      { label: "商品列表", href: "/products/list" },

    ],

    icon: <UsersIcon />,

    href: "/users",

];

interface SidebarProps {
  collapsed: boolean;
  onToggle: () => void;
}

function Sidebar({ collapsed, onToggle }: SidebarProps) {
  const [expandedMenus, setExpandedMenus] = useState<string[]>(["/orders"]);
  const [activeItem, setActiveItem] = useState("/dashboard");

  function toggleMenu(href: string) {
    setExpandedMenus((prev) =>
      prev.includes(href)
        ? prev.filter((h) => h !== href)
        : [...prev, href]
    );
  }

  return (
    <aside
      className={cn(
        "flex h-full flex-col border-r bg-card transition-all duration-300",
        collapsed ? "w-[68px]" : "w-64"
      )}
    >
      {/* Logo 区域 */}
      <div className="flex h-16 items-center border-b px-4">
        <span className="text-xl">🏪</span>
        <span
          className={cn(
            "ml-2 whitespace-nowrap text-lg font-bold bg-gradient-to-r from-blue-600 to-purple-600 bg-clip-text text-transparent transition-all duration-300",
            collapsed ? "w-0 opacity-0" : "w-auto opacity-100"
          )}
        >
          GlobalMart
        </span>
      </div>

      {/* 菜单列表 */}
      <nav className="flex-1 overflow-y-auto px-3 py-4">
        <ul className="space-y-1">
          {menuItems.map((item) => {
            const isActive = activeItem === item.href || activeItem.startsWith(item.href + "/");
            const isExpanded = expandedMenus.includes(item.href);
            const hasChildren = item.children && item.children.length > 0;

            return (
              <li key={item.href}>
                <button
                  onClick={() => {
                    if (hasChildren) {
                      toggleMenu(item.href);
                    } else {
                      setActiveItem(item.href);
                    }
                  }}
                  title={collapsed ? item.label : undefined}
                  className={cn(
                    "group flex w-full items-center gap-3 rounded-lg px-3 py-2.5 text-sm font-medium transition-all duration-200",
                    isActive
                      ? "bg-primary/10 text-primary"
                      : "text-muted-foreground hover:bg-muted hover:text-foreground"
                  )}
                >
                  <span className="h-5 w-5 flex-none">{item.icon}</span>

                  <span
                    className={cn(
                      "flex-1 text-left whitespace-nowrap transition-all duration-300",
                      collapsed ? "w-0 opacity-0 overflow-hidden" : "w-auto opacity-100"
                    )}
                  >
                    {item.label}
                  </span>

                  {/* 展开箭头 */}
                  {hasChildren && !collapsed && (
                    <svg
                      className={cn(
                        "h-4 w-4 transition-transform duration-200",
                        isExpanded && "rotate-90"
                      )}
                      fill="none"
                      viewBox="0 0 24 24"
                      stroke="currentColor"
                      strokeWidth={2}
                    >
                      <path strokeLinecap="round" strokeLinejoin="round" d="M9 5l7 7-7 7" />
                    </svg>
                  )}
                </button>

                {/* 子菜单 */}
                {hasChildren && !collapsed && (
                  <div
                    className={cn(
                      "overflow-hidden transition-all duration-200",
                      isExpanded ? "max-h-40 opacity-100" : "max-h-0 opacity-0"
                    )}
                  >
                    <ul className="ml-5 mt-1 space-y-0.5 border-l pl-4">
                      {item.children!.map((child) => (
                        <li key={child.href}>
                          <button
                            onClick={() => setActiveItem(child.href)}
                            className={cn(
                              "w-full rounded-md px-3 py-2 text-left text-sm transition-colors",
                              activeItem === child.href
                                ? "font-medium text-primary"
                                : "text-muted-foreground hover:text-foreground"
                            )}
                          >
                            {child.label}
                          </button>
                        </li>
                      ))}
                    </ul>
                  </div>
                )}
              </li>
            );
          })}
        </ul>
      </nav>

      {/* 折叠按钮 */}
      <div className="border-t p-3">
        <button
          onClick={onToggle}
          className="flex w-full items-center justify-center gap-2 rounded-lg px-3 py-2 text-sm text-muted-foreground transition-colors hover:bg-muted hover:text-foreground"
        >
          <svg
            className={cn(
              "h-4 w-4 transition-transform duration-300",
              collapsed && "rotate-180"
            )}
            fill="none"
            viewBox="0 0 24 24"
            stroke="currentColor"
            strokeWidth={2}
          >
            <path strokeLinecap="round" strokeLinejoin="round" d="M11 19l-7-7 7-7m8 14l-7-7 7-7" />
          </svg>
          {!collapsed && <span>收起菜单</span>}
        </button>
      </div>
    </aside>
  );
}

### 主布局组装

```tsx
// src/components/layout/admin-layout.tsx
import { useState, useEffect } from "react";
import { cn } from "@/lib/utils";
import { Sidebar } from "./sidebar";
import { Header } from "./header";

function AdminLayout({ children }: { children: React.ReactNode }) {
  const [sidebarCollapsed, setSidebarCollapsed] = useState(false);
  const [mobileMenuOpen, setMobileMenuOpen] = useState(false);

  // 监听窗口大小，大屏自动关闭移动菜单
  useEffect(() => {
    function handleResize() {
      if (window.innerWidth >= 1024) setMobileMenuOpen(false);
    }
    window.addEventListener("resize", handleResize);
    return () => window.removeEventListener("resize", handleResize);
  }, []);

  return (
    <div className="flex h-screen overflow-hidden bg-background">
      {/* 桌面端侧边栏（lg 以上显示） */}
      <div className="hidden lg:block">
        <Sidebar
          collapsed={sidebarCollapsed}
          onToggle={() => setSidebarCollapsed(!sidebarCollapsed)}
        />
      </div>

      {/* 移动端侧边栏（抽屉模式） */}
      {/* 遮罩层 */}
      <div
        className={cn(
          "fixed inset-0 z-40 bg-black/50 backdrop-blur-sm transition-opacity lg:hidden",
          mobileMenuOpen ? "opacity-100" : "pointer-events-none opacity-0"
        )}
        onClick={() => setMobileMenuOpen(false)}
      />
      {/* 抽屉 */}
      <div
        className={cn(
          "fixed inset-y-0 left-0 z-50 w-72 transform transition-transform duration-300 lg:hidden",
          mobileMenuOpen ? "translate-x-0" : "-translate-x-full"
        )}
      >
        <Sidebar collapsed={false} onToggle={() => setMobileMenuOpen(false)} />
      </div>

      {/* 右侧主区域 */}
      <div className="flex flex-1 flex-col overflow-hidden">
        {/* 顶栏 */}
        <Header
          onMobileMenuToggle={() => setMobileMenuOpen(true)}
          breadcrumbs={[
            { label: "首页", href: "/" },
            { label: "订单管理", href: "/orders" },
            { label: "订单列表" },
          ]}
        />

        {/* 内容区域（独立滚动） */}
        <main className="flex-1 overflow-y-auto bg-muted/30 p-4 md:p-6">
          {children}
        </main>
      </div>
    </div>
  );
}

export { AdminLayout };
```

## 知识点解析

### 1. 布局骨架的核心 CSS 结构

```tsx
// 最外层：flex + h-screen + overflow-hidden
<div className="flex h-screen overflow-hidden">
  {/* 侧边栏：固定宽度 */}
  <aside className="w-64 flex-none" />
  {/* 右侧：flex-1 + flex-col */}
  <div className="flex flex-1 flex-col overflow-hidden">
    {/* 顶栏：固定高度 */}
    <header className="h-16 flex-none" />
    {/* 内容区：flex-1 + overflow-y-auto（独立滚动） */}
    <main className="flex-1 overflow-y-auto" />
  </div>
</div>
```

**关键**：`h-screen` 占满视口 → `overflow-hidden` 阻止外层滚动 → 内容区 `overflow-y-auto` 实现独立滚动。侧边栏和顶栏永远固定。

### 2. 侧边栏折叠动画

```tsx
// 侧边栏宽度过渡
"transition-all duration-300"
collapsed ? "w-[68px]" : "w-64"

// 文字消失动画
collapsed ? "w-0 opacity-0 overflow-hidden" : "w-auto opacity-100"
```

不需要 JS 动画库，`transition-all` + 宽度/透明度变化就能实现丝滑的折叠效果。

### 3. 移动端抽屉菜单

```tsx
// 遮罩：fixed + inset-0 + 过渡透明度
"fixed inset-0 z-40 bg-black/50 transition-opacity"
mobileMenuOpen ? "opacity-100" : "pointer-events-none opacity-0"

// 抽屉：fixed + left-0 + 平移动画
"fixed inset-y-0 left-0 z-50 w-72 transform transition-transform"
mobileMenuOpen ? "translate-x-0" : "-translate-x-full"
```

- 打开时：遮罩变不透明，抽屉从左侧滑入
- 关闭时：遮罩变透明 + `pointer-events-none`（穿透点击），抽屉滑出

### 4. 子菜单展开/收起

```tsx
// max-height 实现平滑展开
isExpanded ? "max-h-40 opacity-100" : "max-h-0 opacity-0"
// 配合 overflow-hidden + transition-all
```

### 5. 键盘快捷键提示

```tsx
<kbd className="rounded border bg-muted px-1.5 py-0.5 text-[10px] text-muted-foreground">
  ⌘K
</kbd>
```

用 `<kbd>` 标签 + 微小的边框和背景，展示快捷键提示。

## 避坑指南

**坑：`overflow-hidden` 导致 Dropdown/Tooltip 被裁剪**

```tsx
// 问题：侧边栏 overflow-hidden/auto 会裁剪溢出的 Popover
// 解决方案 1：Popover 用 Portal 渲染到 body
// 解决方案 2：侧边栏用 overflow-x-hidden overflow-y-auto（只裁剪水平方向）
<aside className="overflow-x-hidden overflow-y-auto">
```

**坑：移动端遮罩没有阻止滚动穿透**

```tsx
// 修复：打开抽屉时锁定 body
useEffect(() => {
  if (mobileMenuOpen) {
    document.body.style.overflow = "hidden";
  } else {
    document.body.style.overflow = "";
  }
}, [mobileMenuOpen]);
```

**坑：侧边栏折叠时 Tooltip 不显示**

```tsx
// 折叠状态下，鼠标悬停在图标上应显示菜单名 Tooltip
// 简易方案：用 title 属性
<button title={collapsed ? item.label : undefined}>
// 更好的方案：用 Radix Tooltip 组件
```
