# 案例 2：定价卡片组件

> **TL;DR**
> 用 Tailwind 实现一个 SaaS 风格的定价卡片组：三列响应式布局、推荐套餐高亮放大、hover 上浮动画、功能列表对勾/叉号。涵盖 `ring`、`scale`、`group-hover`、渐变等进阶用法。

## 目标效果

```
┌──────────┐  ┌────────────────┐  ┌──────────┐
│  基础版   │  │  ⭐ 专业版 推荐  │  │  企业版   │
│  ¥49/月  │  │   ¥99/月       │  │  ¥299/月  │
│           │  │  （放大 + 边框） │  │           │
│  ✓ 功能1  │  │  ✓ 功能1       │  │  ✓ 功能1  │
│  ✓ 功能2  │  │  ✓ 功能2       │  │  ✓ 功能2  │
│  ✗ 功能3  │  │  ✓ 功能3       │  │  ✓ 功能3  │
│           │  │  ✓ 功能4       │  │  ✓ 功能4  │
│ [选择方案] │  │ [立即开始]      │  │  ✓ 功能5  │
└──────────┘  └────────────────┘  │ [联系销售] │
                                   └──────────┘
```

## 知识点解析

### 1. 推荐套餐突出显示

```tsx
// 组合 scale + border-primary + ring + shadow
plan.popular
  ? "scale-105 border-primary shadow-lg shadow-primary/10 ring-1 ring-primary"
  : "border-border"
```

- `scale-105`：放大 5%，让推荐卡片视觉更突出
- `ring-1 ring-primary`：外轮廓光圈效果
- `shadow-primary/10`：带主色调的阴影，更精致

### 2. 悬浮上浮效果

```tsx
"hover:-translate-y-2 hover:shadow-xl transition-all duration-300"
```

三个属性配合：上移 8px + 增强阴影 + 300ms 过渡动画。

### 3. 绝对定位标签

```tsx
// 标签相对于卡片定位
<div className="relative"> {/* 卡片作为定位参考 */}
  <div className="absolute -top-4 left-1/2 -translate-x-1/2">
    {/* -top-4：向上偏移，超出卡片边界 */}
    {/* left-1/2 + -translate-x-1/2：水平居中 */}
  </div>
</div>
```

### 4. 响应式布局

```tsx
"grid grid-cols-1 md:grid-cols-3 items-center"
```

- 手机：单列堆叠
- 平板/桌面：三列并排
- `items-center`：让三张卡片（推荐卡片因 `scale-105` 而更高）在交叉轴上居中对齐

### 5. `flex-1` 让功能列表撑满剩余空间

```tsx
<ul className="flex-1 space-y-3">
```

确保不管功能数量差异多大，CTA 按钮始终对齐到卡片底部。

## 变体扩展

### 年付/月付切换

```tsx
function PricingToggle({ isAnnual, onToggle }: { isAnnual: boolean; onToggle: () => void }) {
  return (
    <div className="mt-8 flex items-center justify-center gap-3">
      <span className={cn("text-sm", !isAnnual && "font-semibold text-foreground")}>
        月付
      </span>
      <button
        onClick={onToggle}
        className={cn(
          "relative h-6 w-11 rounded-full transition-colors",
          isAnnual ? "bg-primary" : "bg-muted"
        )}
      >
        <span
          className={cn(
            "absolute left-0.5 top-0.5 h-5 w-5 rounded-full bg-white shadow transition-transform",
            isAnnual && "translate-x-5"
          )}
        />
      </button>
      <span className={cn("text-sm", isAnnual && "font-semibold text-foreground")}>
        年付
        <span className="ml-1 text-xs text-green-600">省 20%</span>
      </span>
    </div>
  );
}
```
