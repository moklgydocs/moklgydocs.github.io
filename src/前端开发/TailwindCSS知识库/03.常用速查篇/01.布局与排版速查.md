# 布局与排版速查：覆盖日常 90% 场景的速查卡

> **TL;DR**
> 这不是官方文档的翻译，而是按照中后台开发的**实际使用频率**整理的速查卡。Flexbox/Grid 布局、间距系统、排版系统、颜色体系、边框阴影圆角、动画过渡——每个分类都附带最常用的组合模式。

## 1. Flexbox 布局

### 核心类名

| 类名 | CSS | 用途 |
|------|-----|------|
| `flex` | `display: flex` | 启用 Flex 布局 |
| `inline-flex` | `display: inline-flex` | 行内 Flex |
| `flex-row` | `flex-direction: row` | 水平排列（默认） |
| `flex-col` | `flex-direction: column` | 垂直排列 |
| `flex-wrap` | `flex-wrap: wrap` | 允许换行 |
| `items-center` | `align-items: center` | 交叉轴居中 |
| `items-start` | `align-items: flex-start` | 交叉轴顶部 |
| `items-end` | `align-items: flex-end` | 交叉轴底部 |
| `items-stretch` | `align-items: stretch` | 交叉轴拉伸（默认） |
| `justify-center` | `justify-content: center` | 主轴居中 |
| `justify-between` | `justify-content: space-between` | 两端对齐 |
| `justify-end` | `justify-content: flex-end` | 主轴尾部 |
| `gap-4` | `gap: 1rem` | 子元素间距 |
| `flex-1` | `flex: 1 1 0%` | 占满剩余空间 |
| `flex-none` | `flex: none` | 不伸缩 |
| `flex-shrink-0` | `flex-shrink: 0` | 不压缩 |

### 高频组合模式

```tsx
// 模式 1：水平居中
<div className="flex items-center justify-center">
  居中内容
</div>

// 模式 2：两端对齐（顶栏常见）
<header className="flex items-center justify-between px-6 py-4">
  <Logo />
  <UserMenu />
</header>

// 模式 3：左侧固定 + 右侧自适应（侧边栏布局）
<div className="flex">
  <aside className="w-64 flex-none">侧边栏</aside>
  <main className="flex-1 overflow-auto">内容区</main>
</div>

// 模式 4：垂直列表 + 间距
<nav className="flex flex-col gap-1">
  <NavItem />
  <NavItem />
  <NavItem />
</nav>

// 模式 5：图标 + 文字对齐
<span className="inline-flex items-center gap-2">
  <Icon className="h-4 w-4" />
  <span>设置</span>
</span>

// 模式 6：底部固定（对话框按钮）
<div className="flex flex-col h-full">
  <div className="flex-1 overflow-auto">滚动内容</div>
  <div className="flex justify-end gap-2 border-t p-4">
    <Button variant="outline">取消</Button>
    <Button>确认</Button>
  </div>
</div>
```

## 2. Grid 布局

### 核心类名

| 类名 | CSS | 用途 |
|------|-----|------|
| `grid` | `display: grid` | 启用 Grid 布局 |
| `grid-cols-3` | `grid-template-columns: repeat(3, 1fr)` | 3 等分列 |
| `grid-cols-12` | `grid-template-columns: repeat(12, 1fr)` | 12 列栅格 |
| `grid-rows-2` | `grid-template-rows: repeat(2, 1fr)` | 2 等分行 |
| `col-span-2` | `grid-column: span 2 / span 2` | 跨 2 列 |
| `col-span-full` | `grid-column: 1 / -1` | 跨满所有列 |
| `row-span-2` | `grid-row: span 2 / span 2` | 跨 2 行 |
| `gap-4` | `gap: 1rem` | 行列间距 |
| `gap-x-4` | `column-gap: 1rem` | 仅列间距 |
| `gap-y-2` | `row-gap: 0.5rem` | 仅行间距 |

### 高频组合模式

```tsx
// 模式 1：响应式卡片网格
<div className="grid grid-cols-1 gap-6 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4">
  {cards.map((card) => <Card key={card.id} {...card} />)}
</div>

// 模式 2：Dashboard 统计卡片（4 列等分）
<div className="grid grid-cols-2 gap-4 lg:grid-cols-4">
  <StatCard title="总订单" value="12,345" />
  <StatCard title="今日营收" value="¥89,012" />
  <StatCard title="活跃用户" value="3,456" />
  <StatCard title="转化率" value="4.2%" />
</div>

// 模式 3：表单两列布局
<form className="grid grid-cols-1 gap-4 md:grid-cols-2">
  <div>用户名输入</div>
  <div>邮箱输入</div>
  <div className="md:col-span-2">地址输入（独占一行）</div>
</form>

// 模式 4：12 列栅格（精确控制比例）
<div className="grid grid-cols-12 gap-6">
  <div className="col-span-12 lg:col-span-8">主内容</div>
  <div className="col-span-12 lg:col-span-4">侧边栏</div>
</div>

// 模式 5：自定义列宽
<div className="grid grid-cols-[250px_1fr] gap-4">
  <aside>固定 250px 侧边栏</aside>
  <main>自适应内容区</main>
</div>
```

## 3. 尺寸与定位

### 宽度

| 类名 | CSS | 常用场景 |
|------|-----|---------|
| `w-full` | `width: 100%` | 撑满容器 |
| `w-screen` | `width: 100vw` | 撑满视口 |
| `w-auto` | `width: auto` | 自动宽度 |
| `w-64` | `width: 16rem` | 侧边栏宽度 |
| `max-w-sm` | `max-width: 24rem` | 窄容器 |
| `max-w-md` | `max-width: 28rem` | 中窄容器 |
| `max-w-lg` | `max-width: 32rem` | 中容器 |
| `max-w-xl` | `max-width: 36rem` | 中宽容器 |
| `max-w-2xl` | `max-width: 42rem` | 宽容器 |
| `max-w-7xl` | `max-width: 80rem` | 页面最大宽度 |
| `min-w-0` | `min-width: 0` | 防 Flex 子项溢出 |

### 高度

| 类名 | CSS | 常用场景 |
|------|-----|---------|
| `h-full` | `height: 100%` | 撑满父容器 |
| `h-screen` | `height: 100vh` | 撑满视口 |
| `h-10` | `height: 2.5rem` | 按钮/输入框高度 |
| `min-h-screen` | `min-height: 100vh` | 至少撑满一屏 |

### 定位

```tsx
// 固定定位（顶栏）
<header className="fixed top-0 left-0 right-0 z-50 h-16 border-b bg-background/95 backdrop-blur">

// 粘性定位（表格表头）
<thead className="sticky top-0 z-10 bg-background">

// 绝对定位（徽标）
<div className="relative">
  <Bell className="h-5 w-5" />
  <span className="absolute -right-1 -top-1 flex h-4 w-4 items-center justify-center rounded-full bg-red-500 text-[10px] text-white">
    3
  </span>
</div>

// 居中定位（加载遮罩）
<div className="absolute inset-0 flex items-center justify-center bg-background/80">
  <Spinner />
</div>
```

## 4. 排版系统

### 字号

| 类名 | 字号 / 行高 | 用途 |
|------|------------|------|
| `text-xs` | 12px / 16px | 辅助文字、标签 |
| `text-sm` | 14px / 20px | 正文（中后台推荐） |
| `text-base` | 16px / 24px | 默认正文 |
| `text-lg` | 18px / 28px | 小标题 |
| `text-xl` | 20px / 28px | 标题 |
| `text-2xl` | 24px / 32px | 页面标题 |
| `text-3xl` | 30px / 36px | 大标题 |

### 字重

| 类名 | CSS | 常用 |
|------|-----|------|
| `font-normal` | `font-weight: 400` | 正文 |
| `font-medium` | `font-weight: 500` | 标签、按钮 |
| `font-semibold` | `font-weight: 600` | 标题 |
| `font-bold` | `font-weight: 700` | 大标题 |

### 文本处理

```tsx
// 单行截断
<p className="truncate">很长很长的文字会被截断显示省略号...</p>

// 多行截断（2 行）
<p className="line-clamp-2">多行文字截断到两行，超出部分显示省略号...</p>

// 文字颜色层级（从强到弱）
<h1 className="text-foreground">主标题</h1>           {/* 最强 */}
<p className="text-muted-foreground">辅助说明文字</p>  {/* 中等 */}
<span className="text-muted-foreground/60">提示</span>  {/* 最弱 */}

// 对齐
<p className="text-left">左对齐</p>
<p className="text-center">居中</p>
<p className="text-right">右对齐（数字常用）</p>

// 其他
<span className="uppercase tracking-wider">STATUS</span>  {/* 大写 + 字距 */}
<span className="tabular-nums">1,234,567</span>           {/* 等宽数字 */}
<del className="line-through">¥199</del>                   {/* 删除线 */}
<a className="underline underline-offset-4">链接</a>       {/* 下划线偏移 */}
```

## 5. 颜色体系

### 颜色使用方式

```tsx
// 预设颜色（含 50-950 色阶）
<div className="bg-blue-500 text-white">

// 自定义语义颜色（推荐）
<div className="bg-primary text-primary-foreground">
<div className="bg-destructive text-destructive-foreground">

// 透明度修饰符
<div className="bg-primary/10">10% 透明度的主色背景</div>
<div className="bg-black/50">半透明黑色遮罩</div>
<div className="text-foreground/70">70% 透明度文字</div>

// 渐变
<div className="bg-gradient-to-r from-blue-500 to-purple-600">
<div className="bg-gradient-to-br from-primary/20 via-transparent to-secondary/20">
```

### 中后台常用颜色语义

```tsx
// 状态颜色
<span className="text-green-600">成功 / 已完成</span>
<span className="text-red-600">错误 / 已取消</span>
<span className="text-yellow-600">警告 / 待处理</span>
<span className="text-blue-600">信息 / 进行中</span>

// 背景状态色（浅色版）
<div className="rounded-md bg-green-50 px-3 py-1 text-green-700">
  成功
</div>
```

## 6. 边框、圆角与阴影

### 边框

```tsx
// 边框宽度
<div className="border">1px 全边框</div>
<div className="border-2">2px 边框</div>
<div className="border-t">仅顶部边框</div>
<div className="border-b">仅底部边框</div>
<div className="border-l-4 border-primary">左侧 4px 装饰边框</div>

// 边框颜色
<div className="border border-border">默认边框色</div>
<div className="border border-red-500">红色边框</div>

// 分隔线
<div className="divide-y">
  <div className="py-4">每个子元素之间</div>
  <div className="py-4">自动添加水平分隔线</div>
  <div className="py-4">无需手动加 border-b</div>
</div>
```

### 圆角

| 类名 | CSS | 用途 |
|------|-----|------|
| `rounded-none` | 0 | 无圆角 |
| `rounded-sm` | 0.125rem | 微圆角 |
| `rounded` | 0.25rem | 小圆角 |
| `rounded-md` | 0.375rem | 中圆角（输入框） |
| `rounded-lg` | 0.5rem | 大圆角（卡片、按钮） |
| `rounded-xl` | 0.75rem | 更大圆角 |
| `rounded-2xl` | 1rem | 卡片装饰 |
| `rounded-full` | 9999px | 圆形（头像、胶囊） |

### 阴影

| 类名 | 用途 |
|------|------|
| `shadow-sm` | 微阴影（卡片基础） |
| `shadow` | 标准阴影 |
| `shadow-md` | 中等阴影（悬浮卡片） |
| `shadow-lg` | 大阴影（下拉菜单、弹窗） |
| `shadow-xl` | 强阴影（模态框） |
| `shadow-none` | 无阴影 |

## 7. 动画与过渡

### 过渡

```tsx
// 通用过渡（推荐）
<button className="transition-colors duration-200 hover:bg-primary">
<div className="transition-all duration-300 hover:shadow-lg hover:-translate-y-1">

// 过渡属性
// transition-none / transition-all / transition / transition-colors
// transition-opacity / transition-shadow / transition-transform

// 过渡时长
// duration-75 / duration-100 / duration-150 / duration-200 / duration-300 / duration-500

// 缓动函数
// ease-linear / ease-in / ease-out / ease-in-out
```

### 变换

```tsx
// 缩放（按钮点击效果）
<button className="active:scale-95 transition-transform">

// 位移（悬浮上移效果）
<div className="hover:-translate-y-1 transition-transform">

// 旋转（图标动画）
<svg className="hover:rotate-180 transition-transform duration-500">
```

### 内置动画

```tsx
// 旋转加载（Loading Spinner）
<svg className="animate-spin h-5 w-5">

// 脉冲（Skeleton 占位）
<div className="animate-pulse rounded-md bg-muted h-4 w-full">

// 弹跳（通知提醒）
<span className="animate-bounce">↓</span>

// 渐入（配合 tailwindcss-animate 插件）
<div className="animate-fade-in">
<div className="animate-slide-in-from-bottom">
```

## 8. 高频组合模式速查

### 卡片

```tsx
<div className="rounded-lg border bg-card p-6 shadow-sm">
  <h3 className="text-lg font-semibold">卡片标题</h3>
  <p className="mt-2 text-sm text-muted-foreground">卡片描述</p>
</div>
```

### 徽标 / Badge

```tsx
<span className="inline-flex items-center rounded-full bg-green-50 px-2.5 py-0.5 text-xs font-medium text-green-700">
  已完成
</span>
```

### 头像

```tsx
<div className="h-10 w-10 overflow-hidden rounded-full bg-muted">
  <img src={avatar} alt="" className="h-full w-full object-cover" />
</div>
```

### 输入框

```tsx
<input
  className="flex h-10 w-full rounded-md border border-input bg-background px-3 py-2 text-sm placeholder:text-muted-foreground focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring disabled:cursor-not-allowed disabled:opacity-50"
  placeholder="请输入..."
/>
```

### 遮罩层

```tsx
<div className="fixed inset-0 z-50 bg-black/50 backdrop-blur-sm" />
```

### 滚动容器

```tsx
<div className="h-[400px] overflow-y-auto scrollbar-thin">
  {/* 长内容 */}
</div>
```

### 响应式隐藏

```tsx
<div className="hidden md:block">仅桌面可见</div>
<div className="md:hidden">仅移动端可见</div>
```

```tsx

```
