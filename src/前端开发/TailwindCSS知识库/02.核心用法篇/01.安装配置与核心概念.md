# 安装配置与核心概念：从零搭建 Tailwind 工程环境

> **TL;DR**
> 掌握 Tailwind 的安装集成（Vite/PostCSS）、响应式断点系统、状态变体（hover/focus/group）、暗色模式、`tailwind.config` 深度定制，以及 `@layer` 指令的正确使用方式。这一篇覆盖你日常开发 90% 的配置需求。

## 1. 安装与 Vite 集成

### 标准安装流程

```bash
# 创建 Vite + React + TypeScript 项目
npm create vite@latest my-app -- --template react-ts
cd my-app

# 安装 Tailwind CSS 及其依赖
npm install -D tailwindcss postcss autoprefixer

# 生成配置文件
npx tailwindcss init -p
# 会生成 tailwind.config.js 和 postcss.config.js
```

### 配置文件详解

```ts
// tailwind.config.ts（推荐使用 TypeScript 配置）
import type { Config } from "tailwindcss";

const config: Config = {
  // 1. content：告诉 JIT 扫描哪些文件
  content: [
    "./index.html",
    "./src/**/*.{ts,tsx,js,jsx}",
  ],

  // 2. theme：定制设计系统
  theme: {
    extend: {
      // 扩展（而非覆盖）默认主题
      colors: {
        brand: {
          50: "#eff6ff",
          500: "#3b82f6",
          900: "#1e3a5f",
        },
      },
      fontFamily: {
        sans: ['"Inter"', "system-ui", "sans-serif"],
      },
      spacing: {
        18: "4.5rem", // 自定义间距值
      },
    },
  },

  // 3. plugins：扩展功能
  plugins: [
    require("tailwindcss-animate"), // 动画插件
  ],

  // 4. darkMode：暗色模式策略
  darkMode: "class", // 通过 class="dark" 切换
};

export default config;
```

### 入口 CSS 文件

```css
/* src/index.css */

/* 这三行指令引入 Tailwind 的三个层 */
@tailwind base;       /* 重置样式 + 基础变量 */
@tailwind components; /* 组件层（用于 @apply 抽象） */
@tailwind utilities;  /* 工具类层（所有原子类） */

/* 自定义全局样式放在 @layer 中 */
@layer base {
  :root {
    --background: 0 0% 100%;
    --foreground: 222.2 84% 4.9%;
    --primary: 221.2 83.2% 53.3%;
    --primary-foreground: 210 40% 98%;
    --muted: 210 40% 96.1%;
    --muted-foreground: 215.4 16.3% 46.9%;
    --border: 214.3 31.8% 91.4%;
    --radius: 0.5rem;
  }

  .dark {
    --background: 222.2 84% 4.9%;
    --foreground: 210 40% 98%;
    --primary: 217.2 91.2% 59.8%;
    --primary-foreground: 222.2 47.4% 11.2%;
    --muted: 217.2 32.6% 17.5%;
    --muted-foreground: 215 20.2% 65.1%;
    --border: 217.2 32.6% 17.5%;
  }

  body {
    @apply bg-background text-foreground antialiased;
  }
}
```

## 2. 响应式设计：移动优先断点系统

### 断点定义

Tailwind 采用**移动优先（Mobile First）**策略——默认样式作用于所有屏幕，断点前缀表示"从该宽度**开始**生效"：

| 前缀 | 最小宽度 | 典型设备 | CSS 等价 |
|------|---------|---------|---------|
| （无前缀） | 0px | 所有设备 | 直接写 |
| `sm:` | 640px | 大手机横屏 | `@media (min-width: 640px)` |
| `md:` | 768px | 平板 | `@media (min-width: 768px)` |
| `lg:` | 1024px | 笔记本 | `@media (min-width: 1024px)` |
| `xl:` | 1280px | 桌面显示器 | `@media (min-width: 1280px)` |
| `2xl:` | 1536px | 大屏显示器 | `@media (min-width: 1536px)` |

### 实战示例

```tsx
// 响应式网格：手机 1 列 → 平板 2 列 → 桌面 3 列 → 大屏 4 列
<div className="grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4">
  {cards.map((card) => (
    <Card key={card.id} {...card} />
  ))}
</div>

// 响应式内边距：手机小间距，桌面大间距
<main className="px-4 py-6 md:px-8 md:py-10 lg:px-16">
  {children}
</main>

// 响应式显示/隐藏
<nav className="hidden md:flex">桌面导航</nav>      {/* 手机隐藏，md 以上显示 */}
<button className="md:hidden">☰</button>             {/* 手机显示，md 以上隐藏 */}

// 响应式文字大小
<h1 className="text-2xl font-bold md:text-3xl lg:text-4xl">
  标题
</h1>
```

### 自定义断点

```ts
// tailwind.config.ts
export default {
  theme: {
    screens: {
      xs: "475px",  // 新增超小屏断点
      sm: "640px",
      md: "768px",
      lg: "1024px",
      xl: "1280px",
      "2xl": "1536px",
      "3xl": "1920px", // 新增超大屏断点
    },
  },
};
```

## 3. 状态变体：交互样式的声明式表达

### 伪类变体

```tsx
<button
  className={[
    // 基础样式
    "rounded-lg bg-primary px-4 py-2 text-sm font-medium text-white",
    // 悬停
    "hover:bg-primary/90",
    // 聚焦（键盘导航可见的焦点环）
    "focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary",
    // 激活（按下瞬间）
    "active:scale-95",
    // 禁用
    "disabled:pointer-events-none disabled:opacity-50",
    // 过渡动画
    "transition-all duration-200",
  ].join(" ")}
>
  提交订单
</button>
```

### Group 变体：父元素状态影响子元素

```tsx
// 鼠标悬停卡片时，标题变色 + 箭头位移
<div className="group cursor-pointer rounded-lg border p-6 transition-shadow hover:shadow-lg">
  <h3 className="text-lg font-semibold group-hover:text-primary">
    订单管理
  </h3>
  <p className="mt-2 text-sm text-muted-foreground">
    查看和处理所有订单
  </p>
  <span className="mt-4 inline-flex items-center text-sm text-primary">
    查看详情
    <svg className="ml-1 h-4 w-4 transition-transform group-hover:translate-x-1">
      {/* 箭头图标 */}
    </svg>
  </span>
</div>
```

### Peer 变体：兄弟元素状态影响

```tsx
// 输入框获得焦点时，标签高亮
<div className="relative">
  <input
    type="email"
    className="peer w-full rounded-md border px-3 py-2 placeholder-transparent focus:border-primary focus:outline-none"
    placeholder="邮箱"
    id="email"
  />
  <label
    htmlFor="email"
    className="absolute -top-2.5 left-2 bg-background px-1 text-xs text-muted-foreground transition-all peer-placeholder-shown:top-2.5 peer-placeholder-shown:text-sm peer-focus:-top-2.5 peer-focus:text-xs peer-focus:text-primary"
  >
    邮箱地址
  </label>
</div>
```

### 常用变体速查

| 变体 | 作用 | 示例 |
|------|------|------|
| `hover:` | 鼠标悬停 | `hover:bg-blue-600` |
| `focus:` | 获得焦点 | `focus:ring-2` |
| `focus-visible:` | 键盘焦点（推荐） | `focus-visible:ring-2` |
| `active:` | 按下状态 | `active:scale-95` |
| `disabled:` | 禁用状态 | `disabled:opacity-50` |
| `group-hover:` | 父 `.group` 悬停 | `group-hover:text-primary` |
| `peer-focus:` | 兄弟 `.peer` 聚焦 | `peer-focus:text-primary` |
| `first:` | 第一个子元素 | `first:mt-0` |
| `last:` | 最后一个子元素 | `last:border-b-0` |
| `odd:` | 奇数行 | `odd:bg-muted/50` |
| `placeholder:` | 占位文本 | `placeholder:text-muted-foreground` |

## 4. 暗色模式

### 配置策略

```ts
// tailwind.config.ts
export default {
  darkMode: "class", // 推荐：通过 <html class="dark"> 切换
  // darkMode: "media", // 备选：跟随系统偏好（无手动切换）
};
```

### 使用暗色变体

```tsx
<div className="bg-white text-gray-900 dark:bg-gray-900 dark:text-gray-100">
  <h2 className="border-b border-gray-200 dark:border-gray-700">
    订单详情
  </h2>
  <p className="text-gray-600 dark:text-gray-400">
    订单号：GM-20240101-001
  </p>
</div>
```

### 主题切换实现

```tsx
// src/hooks/use-theme.ts
import { useState, useEffect } from "react";

type Theme = "light" | "dark" | "system";

function useTheme() {
  const [theme, setTheme] = useState<Theme>(() => {
    if (typeof window === "undefined") return "system";
    return (localStorage.getItem("theme") as Theme) || "system";
  });

  useEffect(() => {
    const root = document.documentElement;
    const systemDark = window.matchMedia("(prefers-color-scheme: dark)");

    function applyTheme(t: Theme) {
      const isDark = t === "dark" || (t === "system" && systemDark.matches);
      root.classList.toggle("dark", isDark);
    }

    applyTheme(theme);
    localStorage.setItem("theme", theme);

    // 监听系统主题变化
    const handler = () => { if (theme === "system") applyTheme("system"); };
    systemDark.addEventListener("change", handler);
    return () => systemDark.removeEventListener("change", handler);
  }, [theme]);

  return { theme, setTheme };
}

export { useTheme };
```

```tsx
// 切换按钮
function ThemeToggle() {
  const { theme, setTheme } = useTheme();

  return (
    <button
      onClick={() =>
        setTheme(theme === "light" ? "dark" : theme === "dark" ? "system" : "light")
      }
      className="rounded-md p-2 hover:bg-muted"
    >
      {theme === "light" ? "☀️" : theme === "dark" ? "🌙" : "💻"}
    </button>
  );
}
```

### CSS 变量 + 暗色模式（推荐方案）

使用 CSS 变量而非直接用 `dark:` 写两套颜色，可以极大减少类名数量：

```css
/* 定义变量 */
@layer base {
  :root {
    --card: 0 0% 100%;
    --card-foreground: 222.2 84% 4.9%;
  }
  .dark {
    --card: 222.2 84% 4.9%;
    --card-foreground: 210 40% 98%;
  }
}
```

```ts
// tailwind.config.ts
export default {
  theme: {
    extend: {
      colors: {
        card: "hsl(var(--card))",
        "card-foreground": "hsl(var(--card-foreground))",
      },
    },
  },
};
```

```tsx
// 使用时只需一个类名，自动适配暗色模式
<div className="bg-card text-card-foreground">
  {/* 不需要写 dark:bg-xxx dark:text-xxx */}
</div>
```

## 5. 间距与尺寸系统

### 间距比例尺

Tailwind 的间距基于 `4px` 基准（`1 单位 = 0.25rem = 4px`）：

| 类名 | 值 | 像素 |
|------|------|------|
| `p-0` | 0 | 0px |
| `p-px` | 1px | 1px |
| `p-0.5` | 0.125rem | 2px |
| `p-1` | 0.25rem | 4px |
| `p-2` | 0.5rem | 8px |
| `p-3` | 0.75rem | 12px |
| `p-4` | 1rem | 16px |
| `p-6` | 1.5rem | 24px |
| `p-8` | 2rem | 32px |
| `p-12` | 3rem | 48px |
| `p-16` | 4rem | 64px |

### 方向缩写

| 前缀 | 含义 | 示例 |
|------|------|------|
| `p-` / `m-` | 四个方向 | `p-4` → `padding: 1rem` |
| `px-` / `mx-` | 水平（左右） | `px-4` → `padding-left: 1rem; padding-right: 1rem` |
| `py-` / `my-` | 垂直（上下） | `py-2` → `padding-top: 0.5rem; padding-bottom: 0.5rem` |
| `pt-` / `mt-` | 上 | `mt-4` → `margin-top: 1rem` |
| `pr-` / `mr-` | 右 | `pr-2` → `padding-right: 0.5rem` |
| `pb-` / `mb-` | 下 | `mb-6` → `margin-bottom: 1.5rem` |
| `pl-` / `ml-` | 左 | `ml-auto` → `margin-left: auto` |

### 任意值（Arbitrary Values）

当预设值无法满足需求时，用方括号写任意值：

```tsx
// 任意间距
<div className="p-[13px] mt-[2.5rem]">

// 任意颜色
<div className="bg-[#1a1a2e] text-[rgb(230,230,250)]">

// 任意宽度
<div className="w-[calc(100%-2rem)] max-w-[680px]">

// 任意网格
<div className="grid grid-cols-[200px_1fr_200px]">
```

## 6. tailwind.config 深度定制

### 扩展 vs 覆盖

```ts
export default {
  theme: {
    // ⚠️ 直接写在 theme 下：覆盖默认值
    colors: {
      // 只有这些颜色可用，Tailwind 默认的 red/blue/green 全部消失！
      primary: "#3b82f6",
      secondary: "#64748b",
    },

    // ✅ 写在 extend 下：在默认值基础上扩展
    extend: {
      colors: {
        // 默认颜色保留，同时新增 brand 颜色
        brand: {
          light: "#e0f2fe",
          DEFAULT: "#0ea5e9",
          dark: "#0369a1",
        },
      },
      animation: {
        "fade-in": "fadeIn 0.3s ease-out",
        "slide-up": "slideUp 0.3s ease-out",
      },
      keyframes: {
        fadeIn: {
          from: { opacity: "0" },
          to: { opacity: "1" },
        },
        slideUp: {
          from: { opacity: "0", transform: "translateY(10px)" },
          to: { opacity: "1", transform: "translateY(0)" },
        },
      },
    },
  },
};
```

### 插件系统

```ts
import plugin from "tailwindcss/plugin";

export default {
  plugins: [
    // 自定义工具类插件
    plugin(function ({ addUtilities, addComponents, theme }) {
      // 添加工具类
      addUtilities({
        ".text-balance": { "text-wrap": "balance" },
        ".scrollbar-hide": {
          "-ms-overflow-style": "none",
          "scrollbar-width": "none",
          "&::-webkit-scrollbar": { display: "none" },
        },
      });

      // 添加组件类
      addComponents({
        ".btn": {
          padding: `${theme("spacing.2")} ${theme("spacing.4")}`,
          borderRadius: theme("borderRadius.lg"),
          fontWeight: theme("fontWeight.medium"),
          fontSize: theme("fontSize.sm"),
          transition: "all 200ms",
        },
      });
    }),
  ],
};
```

## 7. 实用工具链

### cn() 工具函数

中后台项目必备的类名合并工具，解决 Tailwind 类名冲突问题：

```bash
npm install clsx tailwind-merge
```

```ts
// src/lib/utils.ts
import { type ClassValue, clsx } from "clsx";
import { twMerge } from "tailwind-merge";

function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}

export { cn };
```

```tsx
// 使用场景：组件的 className 合并
interface CardProps {
  className?: string;
  children: React.ReactNode;
}

function Card({ className, children }: CardProps) {
  return (
    <div className={cn("rounded-lg border bg-card p-6 shadow-sm", className)}>
      {children}
    </div>
  );
}

// 使用：传入的 p-4 会覆盖默认的 p-6，而不是两者同时存在
<Card className="p-4">紧凑卡片</Card>
// 最终类名: "rounded-lg border bg-card p-4 shadow-sm"
```

### class-variance-authority (cva)

为组件创建类型安全的变体系统：

```bash
npm install class-variance-authority
```

```tsx
// src/components/ui/button.tsx
import { cva, type VariantProps } from "class-variance-authority";
import { cn } from "@/lib/utils";

const buttonVariants = cva(
  // 基础样式
  "inline-flex items-center justify-center rounded-md text-sm font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 disabled:pointer-events-none disabled:opacity-50",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground hover:bg-primary/90",
        destructive: "bg-destructive text-destructive-foreground hover:bg-destructive/90",
        outline: "border border-input bg-background hover:bg-accent hover:text-accent-foreground",
        ghost: "hover:bg-accent hover:text-accent-foreground",
      },
      size: {
        sm: "h-8 px-3 text-xs",
        default: "h-10 px-4 py-2",
        lg: "h-12 px-6 text-base",
        icon: "h-10 w-10",
      },
    },
    defaultVariants: {
      variant: "default",
      size: "default",
    },
  }
);

interface ButtonProps
  extends React.ButtonHTMLAttributes<HTMLButtonElement>,
    VariantProps<typeof buttonVariants> {}

function Button({ className, variant, size, ...props }: ButtonProps) {
  return (
    <button
      className={cn(buttonVariants({ variant, size }), className)}
      {...props}
    />
  );
}

export { Button, buttonVariants };
```

```tsx
// 类型安全的使用
<Button variant="destructive" size="lg">删除订单</Button>
<Button variant="outline">取消</Button>
<Button variant="ghost" size="icon"><SearchIcon /></Button>
```

## 8. 避坑指南

### 坑一：`extend` 和直接覆盖搞混

```ts
// Bad: 覆盖了整个 colors，所有默认颜色消失
theme: {
  colors: { primary: "#3b82f6" }
}

// Good: 在 extend 中添加，保留默认
theme: {
  extend: {
    colors: { primary: "#3b82f6" }
  }
}
```

### 坑二：忘记处理 CSS 变量的色彩空间

```ts
// Bad: CSS 变量中存的是完整 hsl() 值
:root { --primary: hsl(221, 83%, 53%); }
// Tailwind 无法用 bg-primary/50 做透明度变化

// Good: 只存 h s l 值，不带 hsl() 包裹
:root { --primary: 221.2 83.2% 53.3%; }
// 配置中用 hsl() 包裹
colors: { primary: "hsl(var(--primary))" }
// 现在 bg-primary/50 → hsl(221.2 83.2% 53.3% / 0.5) ✅
```

### 坑三：生产环境 CSS 为空

```ts
// 常见原因：content 路径没有匹配到任何文件
content: [
  "./src/**/*.{ts,tsx}", // ✅ 确保后缀覆盖全
  "./index.html",         // ✅ 别忘了入口 HTML
  // 如果用了 UI 库的组件，也要包含其路径
  "./node_modules/@shadcn/ui/**/*.{js,ts,jsx,tsx}",
]
```
