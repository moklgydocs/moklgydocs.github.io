# 资产负债表

> 资产负债表是企业的"快照"——它定格在某一个时点，告诉你：企业拥有什么、欠了多少、剩下的归谁。就像在柠檬水站收摊那一刻拍张照片，清点柠檬、现金、欠条，一览无余。

---

## 一、资产负债表的概念与作用

### 1.1 什么是资产负债表？

资产负债表是反映企业在**某一特定日期**财务状况的报表，其核心等式：

$$
资产 = 负债 + 所有者权益
$$

### 1.2 资产负债表的作用

| 作用 | 说明 |
|------|------|
| 反映资产规模与结构 | 企业拥有多少资源，如何分布 |
| 反映负债水平 | 企业承担多少债务，偿债压力大不大 |
| 反映所有者权益 | 资产扣除负债后归投资者多少 |
| 分析偿债能力 | 流动比率、速动比率、资产负债率 |
| 分析财务弹性 | 资产变现能力、再融资空间 |

## 二、资产负债表的结构与格式

### 2.1 账户式结构

我国资产负债表采用**账户式**（左右式）结构：

```mermaid

    subgraph 左侧——资产
        A1["💰 流动资产"]
        A2["🏢 非流动资产"]
    end
    subgraph 右侧——负债与权益
        L1["💳 流动负债"]
        L2["🏦 非流动负债"]
        E1["👑 所有者权益"]
    end

    A1 --- L1
    A2 --- L2
    A2 --- E1

    style A1 fill:#e3f2fd,stroke:#1565c0,color:#000
    style A2 fill:#bbdefb,stroke:#1565c0,color:#000
    style L1 fill:#ffcdd2,stroke:#c62828,color:#000
    style L2 fill:#ef9a9a,stroke:#c62828,color:#000
    style E1 fill:#c8e6c9,stroke:#2e7d32,color:#000
```

**排列规则：**

| 项目 | 排列顺序 |
|------|---------|
| 资产 | 流动性由强到弱（货币资金→固定资产） |
| 负债 | 到期日由近到远（短期借款→长期借款） |
| 所有者权益 | 永久性由强到弱（实收资本→未分配利润） |

### 2.2 资产负债表基本框架

| 左侧：资产 | 右侧：负债和所有者权益 |
|-----------|---------------------|
| **流动资产** | **流动负债** |
| 货币资金 | 短期借款 |
| 应收票据及应收账款 | 应付票据及应付账款 |
| 预付款项 | 合同负债 |
| 存货 | 应付职工薪酬 |
| 其他流动资产 | 应交税费 |
| **非流动资产** | 一年内到期的非流动负债 |
| 长期股权投资 | 其他流动负债 |
| 固定资产 | **非流动负债** |
| 在建工程 | 长期借款 |
| 无形资产 | 应付债券 |
| 长期待摊费用 | 租赁负债 |
| | **所有者权益** |
| | 实收资本 |
| | 资本公积 |
| | 盈余公积 |
| | 未分配利润 |
| **资产总计** | **负债和所有者权益总计** |

## 三、资产项目的填列方法

### 3.1 两种填列方法

| 填列方法 | 说明 | 举例 |
|---------|------|------|
| **直接填列** | 根据总账科目余额直接填列 | 短期借款、实收资本 |
| **分析计算填列** | 根据多个科目余额分析计算 | 货币资金、存货、应收账款 |

### 3.2 重点项目填列方法

#### （1）货币资金

$$
货币资金 = 库存现金 + 银行存款 + 其他货币资金
$$

#### （2）应收票据及应收账款

$$
应收票据及应收账款 = 应收票据借方余额 + 应收账款借方余额 + 预收账款借方余额 - 坏账准备（应收部分）
$$

::: important 应收账款的"双重来源"
应收账款明细账中可能出现**贷方余额**（实为预收账款），应并入预收款项列示；同理，预收账款的借方余额应并入应收账款。这就是"**重分类**"——不要把债权当债务，也不要把债务当债权。
:::

#### （3）存货

$$
存货 = 原材料 + 在途物资 + 委托加工物资 + 生产成本 + 库存商品 + 发出商品 + 周转材料 - 存货跌价准备
$$

#### （4）固定资产

$$
固定资产 = 固定资产原价 - 累计折旧 - 固定资产减值准备
$$

#### （5）短期借款

直接根据"短期借款"总账科目期末贷方余额填列。

#### （6）应付账款

$$
应付账款 = 应付账款贷方余额 + 预付账款贷方余额
$$

#### （7）一年内到期的非流动负债

从长期借款、应付债券等非流动负债中，将**一年内到期**的部分分离出来填列。

### 3.3 重点科目填列汇总表

| 报表项目 | 填列方法 |
|---------|---------|
| 货币资金 | 库存现金＋银行存款＋其他货币资金 |
| 应收票据及应收账款 | 应收票据＋应收账款（借余）＋预收账款（借余）−坏账准备 |
| 预付款项 | 预付账款（借余）＋应付账款（借余）−坏账准备 |
| 存货 | 原材料＋生产成本＋库存商品＋周转材料＋...−存货跌价准备 |
| 固定资产 | 固定资产−累计折旧−固定资产减值准备 |
| 无形资产 | 无形资产−累计摊销−无形资产减值准备 |
| 应付票据及应付账款 | 应付票据＋应付账款（贷余）＋预付账款（贷余） |
| 预收款项 | 预收账款（贷余）＋应收账款（贷余） |
| 未分配利润 | 利润分配−未分配利润（贷余为正，借余为负） |

## 四、资产负债表编制实例

### 4.1 已知科目余额

某公司 2025 年 12 月 31 日部分科目余额如下：

| 科目 | 借方余额 | 贷方余额 |
|------|---------|---------|
| 库存现金 | 5,000 | |
| 银行存款 | 245,000 | |
| 其他货币资金 | 50,000 | |
| 应收账款——甲公司 | 120,000 | |
| 应收账款——乙公司 | | 20,000 |
| 坏账准备（应收账款） | | 10,000 |
| 预付账款——A公司 | 30,000 | |
| 预付账款——B公司 | | 5,000 |
| 原材料 | 180,000 | |
| 生产成本 | 60,000 | |
| 库存商品 | 200,000 | |
| 存货跌价准备 | | 15,000 |
| 固定资产 | 1,500,000 | |
| 累计折旧 | | 400,000 |
| 固定资产减值准备 | | 50,000 |
| 无形资产 | 300,000 | |
| 累计摊销 | | 60,000 |
| 短期借款 | | 200,000 |
| 应付账款——丙公司 | | 80,000 |
| 应付账款——丁公司 | 10,000 | |
| 预收账款——C公司 | | 40,000 |
| 预收账款——D公司 | 8,000 | |
| 应交税费 | | 35,000 |
| 长期借款（其中一年内到期100,000） | | 500,000 |
| 实收资本 | | 1,000,000 |
| 资本公积 | | 100,000 |
| 盈余公积 | | 80,000 |
| 利润分配——未分配利润 | | 113,000 |

### 4.2 分析计算

| 报表项目 | 计算过程 | 金额 |
|---------|---------|------|
| 货币资金 | 5,000＋245,000＋50,000 | **300,000** |
| 应收票据及应收账款 | 120,000＋8,000−10,000 | **118,000** |
| 预付款项 | 30,000＋10,000 | **40,000** |
| 存货 | 180,000＋60,000＋200,000−15,000 | **425,000** |
| 固定资产 | 1,500,000−400,000−50,000 | **1,050,000** |
| 无形资产 | 300,000−60,000 | **240,000** |
| 应付票据及应付账款 | 80,000＋5,000 | **85,000** |
| 预收款项 | 40,000＋20,000 | **60,000** |
| 一年内到期的非流动负债 | 长期借款中一年内到期部分 | **100,000** |
| 长期借款 | 500,000−100,000 | **400,000** |

::: tip 重分类要点
- 应收账款——乙公司贷余 ¥20,000 → 并入预收款项
- 预付账款——B公司贷余 ¥5,000 → 并入应付账款
- 应付账款——丁公司借余 ¥10,000 → 并入预付款项
- 预收账款——D公司借余 ¥8,000 → 并入应收账款
:::

### 4.3 完整资产负债表

**资产负债表**

编制单位：某公司　　2025年12月31日　　单位：元

| 资产 | 期末余额 | 负债和所有者权益 | 期末余额 |
|------|---------|----------------|---------|
| **流动资产：** | | **流动负债：** | |
| 货币资金 | 300,000 | 短期借款 | 200,000 |
| 应收票据及应收账款 | 118,000 | 应付票据及应付账款 | 85,000 |
| 预付款项 | 40,000 | 合同负债（预收款项） | 60,000 |
| 存货 | 425,000 | 应交税费 | 35,000 |
| | | 一年内到期的非流动负债 | 100,000 |
| **流动资产合计** | **883,000** | **流动负债合计** | **480,000** |
| **非流动资产：** | | **非流动负债：** | |
| 固定资产 | 1,050,000 | 长期借款 | 400,000 |
| 无形资产 | 240,000 | **非流动负债合计** | **400,000** |
| **非流动资产合计** | **1,290,000** | **负债合计** | **880,000** |
| | | **所有者权益：** | |
| | | 实收资本 | 1,000,000 |
| | | 资本公积 | 100,000 |
| | | 盈余公积 | 80,000 |
| | | 未分配利润 | 113,000 |
| | | **所有者权益合计** | **1,293,000** |
| **资产总计** | **2,173,000** | **负债和所有者权益总计** | **2,173,000** |

::: tip 验证平衡
资产总计 = 负债和所有者权益总计 = ¥2,173,000，资产负债表平衡。

核心验算：流动资产 883,000 + 非流动资产 1,290,000 = 2,173,000；流动负债 480,000 + 非流动负债 400,000 + 所有者权益 1,293,000 = 2,173,000。
:::

## 五、练习题

### 练习1：货币资金与存货填列

某企业期末科目余额：库存现金 ¥2,000，银行存款 ¥198,000，其他货币资金 ¥30,000，原材料 ¥150,000，生产成本 ¥45,000，库存商品 ¥200,000，材料成本差异（借方）¥5,000，存货跌价准备 ¥12,000。

要求：计算资产负债表中"货币资金"和"存货"项目的金额。

::: details 参考答案
- **货币资金** = 2,000＋198,000＋30,000 = **¥230,000**
- **存货** = 150,000＋45,000＋200,000＋5,000−12,000 = **¥388,000**
:::

### 练习2：重分类计算

某企业应收账款明细账：甲公司借余 ¥80,000，乙公司贷余 ¥15,000；预收账款明细账：丙公司贷余 ¥50,000，丁公司借余 ¥10,000。坏账准备（应收部分）¥5,000。

要求：计算资产负债表中"应收票据及应收账款"和"预收款项"的金额。

::: details 参考答案
- **应收票据及应收账款** = 甲公司借余 80,000＋丁公司借余 10,000−坏账准备 5,000 = **¥85,000**
- **预收款项** = 丙公司贷余 50,000＋乙公司贷余 15,000 = **¥65,000**
:::

### 练习3：固定资产填列

某企业固定资产原价 ¥2,000,000，累计折旧 ¥600,000，固定资产减值准备 ¥80,000。另外在建工程 ¥300,000。

要求：计算资产负债表中"固定资产"和"在建工程"的金额。

::: details 参考答案
- **固定资产** = 2,000,000−600,000−80,000 = **¥1,320,000**
- **在建工程** = **¥300,000**（直接填列）
:::

---

::: tip 面试速查
1. **核心等式**：资产 = 负债 + 所有者权益（永远成立）
2. **账户式**：左资产、右负债+权益，流动性从强到弱排列
3. **货币资金** = 库存现金 + 银行存款 + 其他货币资金
4. **应收账款**需重分类：应收借余 + 预收借余 − 坏账准备
5. **存货** = 各存货科目借余之和 − 存货跌价准备
6. **固定资产** = 原价 − 累计折旧 − 减值准备
7. **一年内到期的非流动负债**要从长期负债中分离出来
8. 编完务必验证：资产总计 = 负债和所有者权益总计
:::
