# MES制造执行系统

MES（Manufacturing Execution System，制造执行系统）是连接企业管理层与车间控制层的关键信息系统，承担着生产计划分解、生产执行管控、质量追溯、设备监控等核心职责。本课程体系从MES基础概念出发，逐步深入生产计划排产、执行报工、质量管理、设备物料、系统集成等核心模块，并结合开源项目进行实战解析。
