# 入库管理

> 入库是仓储作业的起点——货物从"门外来"变成"库里存"，每一步都需要精确管控。

## 本章导读

| 维度 | 核心问题 | 对应文章 |
|------|---------|---------|
| **流程** | 入库有哪些环节？异常怎么处理？ | [入库流程全解析](01_入库流程全解析.md) |
| **策略** | 货物上架放到哪个库位？ | [智能上架策略](02_智能上架策略.md) |

## 学习目标

- 掌握从到货登记到上架确认的完整入库流程
- 理解采购入库、退货入库、生产入库的区别
- 学会处理超收、短收、质检不合格等异常场景
- 了解智能上架策略的设计思路与储位推荐算法
