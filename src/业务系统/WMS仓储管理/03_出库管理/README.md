## 学习目标

- 掌握从订单接收到发货确认的完整出库流程
- 理解销售出库、生产领料出库、调拨出库的区别
- 学会处理缺货、拣错、包装破损等出库异常
- 理解波次策略的设计逻辑与订单拆合规则
