# 业务与系统断层

> 系统竖井和数据孤岛，是企业数字化转型的头号痛点。系统越来越多，但业务却越来越割裂——审批在OA、执行在ERP、数据在Excel，三者永远对不上。

## 本章导读

企业上了OA、上了ERP、上了MES，以为"数字化"就完成了。现实却是：系统之间各自为政，业务数据在系统之间断流，流程在系统边界处断裂。本章聚焦业务与系统之间的断层问题，分析成因、量化成本、给出解决方案。
