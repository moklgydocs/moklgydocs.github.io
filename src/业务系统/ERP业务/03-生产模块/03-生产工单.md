# 生产工单

## 概述

生产工单（Work Order）是车间执行生产任务的核心指令。它定义了生产什么产品、数量多少、使用什么 BOM 和工艺路线、计划开始和完工日期。工单从创建到完工关闭形成完整的生命周期。

## 一、工单生命周期

```
┌────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ Draft   │───▶│ Confirmed│───▶│ Released │───▶│InProgress│
│ 草稿    │    │ 已确认    │    │ 已下达    │    │ 执行中    │
└────────┘    └──────────┘    └──────────┘    └─────┬────┘
                   │                                 │
                   ▼                      ┌──────────┼──────────┐
              ┌──────────┐               ▼          ▼          ▼
              │ Cancelled│         ┌──────────┐ ┌────────┐ ┌────────┐
              │ 已取消    │         │PartDone  │ │ Done   │ │OnHold  │
              └──────────┘         │ 部分完工  │ │ 已完工  │ │ 暂停   │
                                   └──────────┘ └────┬───┘ └────────┘
                                                     │
                                                     ▼
                                                ┌────────┐
                                                │ Closed │
                                                │ 已关闭  │
                                                └────────┘

关键状态说明:
  Draft     → 草稿，可编辑
  Confirmed → 已确认BOM/路线/物料可用性，等待下达
  Released  → 已下达车间，可开始领料和生产
  InProgress→ 已开始生产（有领料或报工记录）
  PartDone  → 部分完工入库
  Done      → 全部完工入库
  Closed    → 成本归集完成，工单关闭
  OnHold    → 暂停（缺料、设备故障等）
  Cancelled → 取消（未开始的工单）
```

## 二、核心实体

### 2.1 生产工单

```
WorkOrder (生产工单)
├── Id: Guid
├── TenantId: Guid
├── OrderNo: string(30)                # 工单号 WO-{YYYYMMDD}-{SEQ}
├── ProductId: Guid                    # 产品ID
├── ProductCode: string(50)
├── ProductName: string(200)
├── BOMId: Guid                        # 使用的 BOM
├── BOMVersion: int
├── RoutingId: Guid                    # 使用的工艺路线
├── RoutingVersion: int
│
├── PlannedQuantity: decimal(18,4)    # 计划数量
├── CompletedQuantity: decimal(18,4)  # 已完工数量
├── ScrapQuantity: decimal(18,4)      # 报废数量
├── UnitOfMeasure: string(20)
│
├── PlannedStartDate: DateTime         # 计划开始日期
├── PlannedEndDate: DateTime           # 计划完工日期
├── ActualStartDate: DateTime?         # 实际开始日期
├── ActualEndDate: DateTime?           # 实际完工日期
│
├── Priority: int                      # 优先级 (1最高)
├── WarehouseId: Guid                  # 完工入库仓库
├── WorkCenterId: Guid?                # 主工作中心
│
├── Source: WOSource                   # 来源
├── SourceDocumentId: Guid?            # 来源单据ID
├── SourceDocumentNo: string(50)?
│
├── Status: WOStatus
├── ApprovalStatus: ApprovalStatus
├── HoldReason: string(200)?           # 暂停原因
├── CancelReason: string(200)?
├── Remark: string(500)
│
├── PlannedMaterialCost: decimal(18,2)  # 计划材料成本
├── PlannedLaborCost: decimal(18,2)     # 计划人工成本
├── PlannedOverheadCost: decimal(18,2)  # 计划制造费用
├── ActualMaterialCost: decimal(18,2)   # 实际材料成本
├── ActualLaborCost: decimal(18,2)      # 实际人工成本
├── ActualOverheadCost: decimal(18,2)   # 实际制造费用
│
├── Materials: List<WOMaterial>        # 物料需求清单
└── Operations: List<WOOperation>      # 工序计划

WOMaterial (工单物料)
├── Id: Guid
├── WorkOrderId: Guid
├── LineNo: int
├── ItemId: Guid
├── ItemCode: string(50)
├── ItemName: string(200)
├── UnitOfMeasure: string(20)
├── RequiredQuantity: decimal(18,4)   # 需求数量 (来自BOM展开)
├── IssuedQuantity: decimal(18,4)     # 已领料数量
├── ReturnedQuantity: decimal(18,4)   # 已退料数量
├── ScrapQuantity: decimal(18,4)      # 报废数量
├── WarehouseId: Guid                  # 领料仓库
├── OperationNo: int?                  # 投料工序
└── Remark: string(200)

WOOperation (工单工序)
├── Id: Guid
├── WorkOrderId: Guid
├── OperationNo: int                   # 工序号
├── OperationName: string(100)
├── WorkCenterId: Guid
├── PlannedSetupTime: decimal(18,2)   # 计划准备时间
├── PlannedRunTime: decimal(18,2)     # 计划加工时间
├── ActualSetupTime: decimal(18,2)    # 实际准备时间
├── ActualRunTime: decimal(18,2)      # 实际加工时间
├── PlannedQuantity: decimal(18,4)    # 计划产出
├── CompletedQuantity: decimal(18,4)  # 已完成产出
├── ScrapQuantity: decimal(18,4)      # 报废数量
├── Status: OperationStatus
└── Remark: string(200)

枚举:
  WOSource: Manual=1, MRP=2, SalesOrder=3(MTO按单生产), Reorder=4(再订货点)
  WOStatus: Draft=0, Confirmed=1, Released=2, InProgress=3, PartDone=4,
            Done=5, Closed=6, OnHold=7, Cancelled=-1
  OperationStatus: Pending=0, InProgress=1, Completed=2
```

## 三、排产规则

### 3.1 排产方式

| 方式 | 说明 | 适用 |
|------|------|------|
| **正排** (Forward) | 从开始日期向后排 | 已知开始日期 |
| **倒排** (Backward) | 从交付日期向前排 | 已知交付期限 |
| **有限产能排产** | 考虑工作中心产能约束 | 精确排产 |
| **无限产能排产** | 不考虑产能约束 | 粗略计划 |

### 3.2 排产示例（倒排）

```
交付日期: 1月20日
工序30(组装): 需2天 → 1月18-19日
工序20(加工): 需3天 → 1月15-17日
工序10(下料): 需1天 → 1月14日
领料: 1月13日
→ 最晚开始日期: 1月13日
```

## 六、业务规则

| 规则 | 描述 |
|------|------|
| BOM 必须有效 | 工单创建时 BOM 必须为 Active 状态 |
| 物料可用性检查 | 确认工单时检查库存+在途是否满足需求 |
| 下达后不可改 | Released 及以后状态不可修改基础信息 |
| 领料不超需求 | 累计领料不得超过需求量的 110%（可配置） |
| 取消条件 | 已领料或已报工的工单不可直接取消 |
| 关闭条件 | 完工入库完成且成本归集完成后才能关闭 |
| 优先级排产 | 优先级高的工单优先分配产能 |
| 暂停记录 | 暂停必须记录原因，支持后续分析 |
