# 生产成本归集

## 概述

生产成本归集将料（直接材料）、工（直接人工）、费（制造费用）三大要素归集到具体的生产工单/产品，最终形成产品的实际成本。完工入库时将在制品成本转为产成品成本。

## 一、成本归集流程

```
┌──────────────────────────────────────────────────────────────┐
│                    生产成本归集流程                             │
│                                                              │
│  领料出库 ──────▶ 直接材料成本 ────┐                          │
│  (MaterialIssue)   按领料单实际金额  │                          │
│                                    │                          │
│  报工工时 ──────▶ 直接人工成本 ────┼──▶ 工单成本 ──完工──▶ 产成品│
│  (WorkReport)     工时×人工费率     │      (WIP)         (FG)  │
│                                    │                          │
│  制造费用 ──────▶ 月末分配    ──────┘                          │
│  (折旧/水电/间接)  按分配标准                                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、三大成本要素

### 2.1 直接材料

```
来源: 领料单 (MaterialIssue)
归集方式: 实时归集，领料确认时即计入工单

工单直接材料成本 = Σ(各领料行出库金额) - Σ(退料金额)

出库成本取决于存货计价方法:
  加权平均法: 出库单价 = 库存总金额 / 库存总数量
  先进先出: 按入库批次的先后顺序
```

### 2.2 直接人工

```
来源: 报工记录 (WorkReport)
归集方式: 实时归集，报工确认时即计入工单

工单直接人工成本 = Σ(各报工记录工时 × 人工费率)

人工费率来源:
  ① 工作中心费率 (LaborCostRate)
  ② 工人个人费率 (如有)
  ③ 标准费率 (配置)
```

### 2.3 制造费用

```
来源: 制造费用科目 (4101)
归集方式: 月末批量分配

本月制造费用包括:
  ├── 间接材料 (车间耗材)
  ├── 间接人工 (车间管理人员工资)
  ├── 折旧费 (生产设备折旧)
  ├── 水电费 (车间水电)
  ├── 维修费 (设备维修)
  └── 其他

分配方式: 详见财务模块 06-成本核算
```

## 三、完工入库成本计算

### 3.1 全部完工

```
当工单全部完工时:
  产成品单位成本 = (材料成本 + 人工成本 + 制造费用) / 完工数量

示例:
  直接材料: 30,000
  直接人工: 15,000
  制造费用: 10,000 (分配)
  完工数量: 100件
  单位成本: 55,000 / 100 = 550 元/件
```

### 3.2 部分完工（约当产量法）

```
当工单部分完工时:
  约当产量 = 完工数量 + 在制数量 × 完工百分比
  单位成本 = 总成本 / 约当产量
  完工成本 = 单位成本 × 完工数量
  在制成本 = 单位成本 × (在制数量 × 完工百分比)

示例:
  完工: 80件, 在制: 20件(完工度50%)
  约当产量 = 80 + 20×50% = 90
  总成本 = 45,000
  单位成本 = 45,000 / 90 = 500
  完工成本 = 500 × 80 = 40,000
  在制品 = 500 × 10 = 5,000
```

## 五、成本差异

```
标准成本 vs 实际成本:

  标准材料成本: 100件 × 280元 = 28,000
  实际材料成本: 30,000
  材料差异: +2,000 (不利)

  标准人工成本: 100件 × 130元 = 13,000
  实际人工成本: 15,000
  人工差异: +2,000 (不利)

  标准制造费用: 100件 × 90元 = 9,000
  实际制造费用: 10,000
  制造费用差异: +1,000 (不利)

详细差异分析见: 财务模块/06-成本核算
```

## 七、业务规则

| 规则 | 描述 |
|------|------|
| 成本实时归集 | 材料和人工在领料/报工时实时计入工单 |
| 制造费用月末 | 制造费用在月末统一分配 |
| 完工前必须归集 | 完工入库前所有成本要素必须归集完毕 |
| 工单关闭条件 | 成本归集、差异分析完成后才能关闭 |
| 成本不可为负 | 产品单位成本不可为负 |
| 退料冲减 | 退料自动减少工单材料成本 |
| 报废损失 | 报废品的成本计入工单总成本（非正常损失除外） |
| 跨月工单 | 跨月工单按月归集，月末计算在制品 |
