# 采购模块

采购模块管理企业从供应商获取物资和服务的完整流程，涵盖供应商管理、采购申请、采购订单、收货入库、质检和采购发票对账。它是企业供应链的起点，与 MRP（物料需求）、财务（应付账款）、库存（入库）模块紧密集成。
