# 供应商管理

## 概述

供应商管理是采购模块的基础，负责供应商的全生命周期管理：从准入审批、主数据维护、绩效评估到淘汰退出。良好的供应商管理直接影响采购质量、成本和交期。

## 一、核心实体

### 1.1 供应商主数据

```
Supplier (供应商)
├── Id: Guid
├── TenantId: Guid
├── Code: string(30)                   # 供应商编码 SUP-{YYYYMM}-{SEQ}
├── Name: string(200)                  # 供应商名称
├── ShortName: string(50)              # 简称
├── Category: SupplierCategory         # 分类
├── Level: SupplierLevel               # 等级
├── TaxId: string(30)                  # 统一社会信用代码/税号
├── LegalRepresentative: string(50)    # 法人代表
├── RegisteredCapital: decimal(18,2)?  # 注册资本
├── BusinessScope: string(500)         # 经营范围
├── Address: string(300)               # 地址
├── City: string(50)
├── Province: string(50)
├── PostalCode: string(10)
├── Country: string(50)
│
├── ContactName: string(50)            # 联系人
├── ContactPhone: string(20)           # 联系电话
├── ContactEmail: string(100)          # 联系邮箱
├── Fax: string(20)
├── Website: string(200)
│
├── BankName: string(100)              # 开户银行
├── BankAccountNo: string(30)          # 银行账号
├── BankAccountName: string(200)       # 账户名称
│
├── PaymentTermDays: int               # 账期天数
├── CurrencyCode: string(3)            # 默认交易币种
├── TaxRate: decimal(5,2)              # 默认税率
│
├── Status: SupplierStatus             # 状态
├── ApprovalStatus: ApprovalStatus     # 审批状态
├── ApprovedBy: Guid?
├── ApprovedAt: DateTime?
├── BlacklistReason: string(500)?      # 黑名单原因
├── Remark: string(500)
└── Contacts: List<SupplierContact>    # 多联系人

SupplierContact (供应商联系人)
├── Id: Guid
├── SupplierId: Guid
├── Name: string(50)
├── Position: string(50)               # 职务
├── Phone: string(20)
├── Email: string(100)
├── IsPrimary: bool                    # 是否主联系人
└── Remark: string(200)

枚举:
  SupplierCategory: RawMaterial=1(原材料), Component=2(零部件), Equipment=3(设备),
                    Service=4(服务), MRO=5(间接物料), Other=9
  SupplierLevel: Strategic=1(战略), Preferred=2(优选), Qualified=3(合格), 
                 Probation=4(试用), Blacklisted=5(黑名单)
  SupplierStatus: Active=1, Inactive=2, Blocked=3
```

### 1.2 供应商评估

```
SupplierEvaluation (供应商评估)
├── Id: Guid
├── TenantId: Guid
├── SupplierId: Guid
├── EvaluationPeriod: string(10)       # 评估期间 (2024-Q1)
├── EvaluationDate: DateTime
├── QualityScore: decimal(5,2)         # 质量评分 (0-100)
├── DeliveryScore: decimal(5,2)        # 交期评分 (0-100)
├── PriceScore: decimal(5,2)           # 价格评分 (0-100)
├── ServiceScore: decimal(5,2)         # 服务评分 (0-100)
├── TotalScore: decimal(5,2)           # 综合评分
├── Rating: SupplierRating             # 评级结果
├── EvaluatedBy: Guid
├── Recommendation: string(500)        # 改进建议
└── Remark: string(500)

枚举:
  SupplierRating: A=1(优秀,90+), B=2(良好,80-89), C=3(一般,60-79), D=4(不合格,<60)
```

### 1.3 评分权重

| 维度 | 权重 | 评分依据 |
|------|------|---------|
| 质量 | 40% | 来料合格率、退货率、质量事故 |
| 交期 | 30% | 准时交货率、交期偏差天数 |
| 价格 | 20% | 价格竞争力、价格稳定性 |
| 服务 | 10% | 响应速度、配合度、售后支持 |

## 二、供应商生命周期

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 潜在供应商 │───▶│ 准入审批   │───▶│ 试用期    │───▶│ 合格供应商 │
│ Potential │    │ Approval │    │ Probation│    │ Qualified│
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                     │                               │
                     │ 拒绝                    定期评估│
                     ▼                               ▼
                ┌──────────┐                   ┌──────────┐
                │ 淘汰      │◀──评估不合格────── │ 降级/淘汰 │
                │ Eliminated│                   └──────────┘
                └──────────┘
```

## 三、API 接口设计

## 五、业务规则

| 规则 | 描述 |
|------|------|
| 编码唯一 | 供应商编码全局唯一 |
| 税号唯一 | 同一租户内税号不可重复（防止重复建档） |
| 准入审批 | 新供应商必须经过准入审批才能下单 |
| 黑名单限制 | 黑名单供应商不可创建采购订单 |
| 试用期限制 | 试用期供应商单次采购金额不超限额 |
| 定期评估 | 合格供应商至少每季度评估一次 |
| 评估降级 | 连续两次评估为 D 级自动进入淘汰流程 |
| 银行信息必填 | 付款前银行信息必须完整 |
