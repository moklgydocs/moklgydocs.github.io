# 采购收货与质检

## 概述

收货是采购订单执行的关键环节，确认供应商交付的物资数量和质量。收货确认后更新库存并触发财务暂估入账。质检流程确保来料符合质量标准，不合格品通过退货流程处理。

## 一、收货流程

### 1.1 收货全流程

```
供应商发货 → 到货通知 → 核对PO → 验收/清点 → 质检（可选）
                                                  │
                              ┌───────────────────┤
                              ▼                   ▼
                         质检合格              质检不合格
                              │                   │
                              ▼                   ▼
                         入库确认              退货/让步接收
                              │                   │
                              ▼                   ▼
                    更新PO收货数量           创建退货单(PRN)
                    更新库存数量
                    财务暂估入账
```

### 1.2 收货单状态机

```
┌────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ Draft   │───▶│ Inspecting│───▶│ Accepted │───▶│ Stocked  │
│ 草稿    │    │ 质检中    │    │ 已验收    │    │ 已入库    │
└────────┘    └──────────┘    └──────────┘    └──────────┘
                   │
                   ▼
              ┌──────────┐
              │ Rejected  │
              │ 已拒收    │
              └──────────┘
```

## 二、核心实体

### 2.1 收货单

```
GoodsReceipt (收货单)
├── Id: Guid
├── TenantId: Guid
├── ReceiptNo: string(30)              # 收货单号 GRN-{YYYYMMDD}-{SEQ}
├── PurchaseOrderId: Guid              # 关联 PO
├── PurchaseOrderNo: string(30)
├── SupplierId: Guid
├── SupplierName: string(200)
├── WarehouseId: Guid                  # 收货仓库
├── ReceiptDate: DateTime              # 收货日期
├── DeliveryNoteNo: string(50)?        # 供应商送货单号
├── Carrier: string(100)?              # 承运商
├── TrackingNo: string(50)?            # 运单号
├── Status: GRNStatus
├── InspectionRequired: bool           # 是否需要质检
├── VoucherId: Guid?                   # 暂估入账凭证
├── Remark: string(500)
└── Lines: List<GRNLine>

GRNLine (收货单行)
├── Id: Guid
├── ReceiptId: Guid
├── LineNo: int
├── POLineId: Guid                     # 关联 PO 行
├── ItemId: Guid
├── ItemCode: string(50)
├── ItemName: string(200)
├── UnitOfMeasure: string(20)
├── OrderedQuantity: decimal(18,4)    # 订购数量
├── DeliveredQuantity: decimal(18,4)  # 送货数量
├── AcceptedQuantity: decimal(18,4)   # 验收合格数量
├── RejectedQuantity: decimal(18,4)   # 拒收数量
├── UnitPrice: decimal(18,6)          # 单价（来自 PO）
├── Amount: decimal(18,2)             # 入库金额
├── WarehouseId: Guid                  # 行级入库仓库
├── LocationId: Guid?                  # 库位
├── BatchNo: string(50)?              # 批次号
├── InspectionResult: InspectionResult? # 质检结果
└── Remark: string(200)

枚举:
  GRNStatus: Draft=0, Inspecting=1, Accepted=2, Stocked=3, Rejected=-1
  InspectionResult: Pending=0, Passed=1, Failed=2, ConditionalAccept=3
```

### 2.2 质检单

```
IncomingInspection (来料检验)
├── Id: Guid
├── TenantId: Guid
├── InspectionNo: string(30)           # 检验单号 QC-{YYYYMMDD}-{SEQ}
├── GoodsReceiptId: Guid               # 关联收货单
├── GRNLineId: Guid                    # 关联收货行
├── ItemId: Guid
├── ItemCode: string(50)
├── ItemName: string(200)
├── SupplierId: Guid
├── InspectionDate: DateTime
├── InspectorId: Guid                  # 检验员
├── SampleSize: int                    # 抽样数量
├── InspectedQuantity: decimal(18,4)  # 检验数量
├── PassedQuantity: decimal(18,4)     # 合格数量
├── FailedQuantity: decimal(18,4)     # 不合格数量
├── PassRate: decimal(5,2)            # 合格率
├── Result: InspectionResult           # 检验结果
├── DefectType: string(200)?           # 缺陷类型
├── DefectDescription: string(500)?    # 缺陷描述
├── Disposition: InspectionDisposition? # 处理方式
└── Remark: string(500)

枚举:
  InspectionDisposition: Accept=1(接收), Reject=2(退货), Rework=3(返工),
                         ConditionalAccept=4(让步接收), Sort=5(挑选使用)
```

### 2.3 退货单

```
PurchaseReturn (采购退货)
├── Id: Guid
├── TenantId: Guid
├── ReturnNo: string(30)               # 退货单号 PRN-{YYYYMMDD}-{SEQ}
├── GoodsReceiptId: Guid               # 关联收货单
├── PurchaseOrderId: Guid              # 关联 PO
├── SupplierId: Guid
├── SupplierName: string(200)
├── ReturnDate: DateTime
├── ReturnReason: ReturnReason         # 退货原因
├── ReasonDetail: string(500)          # 原因详情
├── Status: ReturnStatus
├── ApprovalStatus: ApprovalStatus
├── VoucherId: Guid?                   # 红冲凭证
├── Remark: string(500)
└── Lines: List<ReturnLine>

ReturnLine (退货行)
├── Id: Guid
├── ReturnId: Guid
├── GRNLineId: Guid
├── ItemId: Guid
├── ItemCode: string(50)
├── ItemName: string(200)
├── ReturnQuantity: decimal(18,4)     # 退货数量
├── UnitPrice: decimal(18,6)
├── Amount: decimal(18,2)
└── Remark: string(200)

枚举:
  ReturnReason: QualityDefect=1(质量不合格), WrongItem=2(发错货),
                OverDelivery=3(多发), Damaged=4(运输损坏), Other=9
  ReturnStatus: Draft=0, Submitted=1, Approved=2, Shipped=3, Completed=4, Cancelled=-1
```

## 三、API 接口设计

### 3.1 收货管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/purchase/goods-receipts` | 收货单列表 |
| GET | `/api/purchase/goods-receipts/{id}` | 收货单详情 |
| POST | `/api/purchase/goods-receipts` | 创建收货单（关联 PO） |
| PUT | `/api/purchase/goods-receipts/{id}` | 修改收货单 |
| POST | `/api/purchase/goods-receipts/{id}/inspect` | 提交质检 |
| POST | `/api/purchase/goods-receipts/{id}/accept` | 验收确认 |
| POST | `/api/purchase/goods-receipts/{id}/stock-in` | 入库确认 |

### 3.2 质检管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/purchase/inspections` | 检验单列表 |
| POST | `/api/purchase/inspections` | 创建检验单 |
| PUT | `/api/purchase/inspections/{id}` | 录入检验结果 |
| POST | `/api/purchase/inspections/{id}/complete` | 完成检验 |

### 3.3 退货管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/purchase/returns` | 退货单列表 |
| POST | `/api/purchase/returns` | 创建退货单 |
| POST | `/api/purchase/returns/{id}/submit` | 提交审批 |
| POST | `/api/purchase/returns/{id}/approve` | 审批通过 |
| POST | `/api/purchase/returns/{id}/ship` | 退货发运 |
| POST | `/api/purchase/returns/{id}/complete` | 退货完成 |

## 五、业务规则

| 规则 | 描述 |
|------|------|
| 必须关联 PO | 收货必须关联已审批的采购订单 |
| 超收限制 | 收货数量不得超过 PO 行剩余数量的 105% |
| 质检免检 | 战略/优选供应商且物料为非关键件可免检 |
| 批次追溯 | 关键物料必须记录批次号 |
| 入库触发暂估 | 入库确认自动生成暂估入账凭证 |
| 退货冲库存 | 退货确认后自动扣减库存 |
| 退货冲凭证 | 退货生成红冲凭证 |
| 不合格率追踪 | 质检结果纳入供应商评估体系 |
