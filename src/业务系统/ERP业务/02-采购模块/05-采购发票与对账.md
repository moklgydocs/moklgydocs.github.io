# 采购发票与对账

## 概述

采购发票管理是采购到付款（P2P）流程的最后环节。供应商开具发票后，系统执行**三单匹配**（PO-GRN-Invoice），确保发票金额与订单和收货一致，匹配通过后生成正式应付账款，进入付款流程。

## 一、发票处理流程

```
收到供应商发票 → 录入发票信息 → 三单匹配 → 匹配结果
                                              │
                          ┌───────────────────┼───────────────────┐
                          ▼                   ▼                   ▼
                     完全匹配            容差内匹配            匹配失败
                          │                   │                   │
                          ▼                   ▼                   ▼
                    自动审批通过          人工确认            差异调查
                          │                   │                   │
                          ▼                   ▼                   ▼
                     生成应付单 AP     生成应付单 AP        退回/调整
                     冲回暂估入账      冲回暂估入账
                          │                   │
                          ▼                   ▼
                     进入 AP 付款流程
```

## 三、三单匹配详解

### 3.1 匹配规则

| 匹配项 | 匹配内容 | 容差 | 说明 |
|--------|---------|------|------|
| 数量匹配 | 发票数量 vs GRN 验收数量 | ±5% | 可配置 |
| 价格匹配 | 发票单价 vs PO 单价 | ±2% | 可配置 |
| 金额匹配 | 发票金额 vs PO 金额 | ±100元 | 可配置 |

### 3.2 匹配结果处理

| 结果 | 条件 | 处理 |
|------|------|------|
| **完全匹配** | 所有项在容差内，差异=0 | 自动审批，生成 AP |
| **容差内匹配** | 差异在容差范围内 | 需人工确认，差异计入成本或价差 |
| **匹配失败** | 差异超出容差 | 退回供应商修正或内部调查 |

### 3.3 差异处理

**价格差异（发票价格 > PO 价格）:**

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 采购价格差异 | 采购价差科目 | 差异金额 | |
| 调整应付 | 2202 应付账款 | | 差异金额 |

**数量差异（发票数量 > GRN 数量）:**
- 退回供应商修正发票，或
- 补做收货后重新匹配

## 四、暂估入账与冲回

### 4.1 暂估流程

```
① 收货时 (GRN 确认):
   按 PO 价格暂估入账
   借: 原材料 (按PO价)
   贷: 应付账款-暂估

② 收到发票时:
   a. 冲回暂估
      借: 应付账款-暂估
      贷: 原材料

   b. 正式入账 (按发票价)
      借: 原材料 (按发票价)
      借: 进项税额
      贷: 应付账款

③ 月末未到票:
   暂估金额保留，在资产负债表中列示
   下月初自动冲回 (可选策略)
```

### 4.2 暂估处理策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 月末不冲回 | 暂估保留直到发票到达才冲 | 一般企业 |
| 月末冲回月初回冲 | 月末自动红冲，次月初恢复 | 大型企业 |

## 七、业务规则

| 规则 | 描述 |
|------|------|
| 发票号唯一 | 同一供应商的发票号不可重复 |
| 必须关联 PO/GRN | 采购发票必须关联 PO 和 GRN |
| 匹配后才能过账 | 发票必须通过三单匹配后才能生成应付 |
| 进项税验证 | 增值税专票的税额需与发票一致 |
| 暂估跟踪 | 系统追踪所有未到票的暂估，提醒催票 |
| 发票时效 | 增值税专票认证期限内必须入账 |
| 重复检查 | 系统检查是否有重复发票录入 |
| 过账不可逆 | 已过账发票不可修改，需红冲处理 |
