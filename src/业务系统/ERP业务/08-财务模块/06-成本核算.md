# 成本核算

## 概述

成本核算子系统负责企业产品成本的计算与控制，涵盖标准成本的制定、实际成本的归集与分配、成本差异的分析。它与生产模块紧密集成，将料、工、费三大要素归集到产品，为定价决策和经营分析提供数据支撑。

## 一、成本核算体系

### 1.1 成本构成

```
产品成本
├── 直接材料 (Direct Material)
│   ├── 主要材料
│   └── 辅助材料
│
├── 直接人工 (Direct Labor)
│   ├── 生产工资
│   └── 加班工资
│
└── 制造费用 (Manufacturing Overhead)
    ├── 间接材料
    ├── 间接人工 (车间管理人员工资)
    ├── 折旧费
    ├── 水电费
    ├── 维修费
    └── 其他制造费用
```

### 1.2 成本核算方法

| 方法 | 说明 | 适用场景 |
|------|------|---------|
| **标准成本法** | 预设标准成本，实际与标准的差异单独核算 | 大批量标准化生产 |
| **实际成本法** | 按实际发生的料工费归集 | 小批量、定制化生产 |
| **品种法** | 按产品品种归集成本 | 大量大批单步骤生产 |
| **分批法** | 按生产批次（工单）归集成本 | 小批量多品种 |
| **分步法** | 按生产步骤逐步结转 | 多步骤连续生产 |

### 1.3 成本核算流程

```
① 期初: 建立/更新标准成本
              │
              ▼
② 日常: 归集实际成本
   ├── 领料出库 → 直接材料
   ├── 报工工时 → 直接人工
   └── 费用分摊 → 制造费用
              │
              ▼
③ 月末: 制造费用分配
   制造费用 → 按分配标准 → 分配至各工单/产品
              │
              ▼
④ 月末: 完工产品成本结转
   在制品 → 产成品（按约当产量法或其他方法）
              │
              ▼
⑤ 月末: 销售成本结转
   产成品 → 主营业务成本（按加权平均/先进先出）
              │
              ▼
⑥ 差异分析: 标准成本 vs 实际成本
```

## 三、成本差异分析

### 3.1 材料差异

```
材料价格差异 = (实际单价 - 标准单价) × 实际用量
材料用量差异 = (实际用量 - 标准用量) × 标准单价

示例:
  标准: 10kg × 50元/kg = 500元
  实际: 11kg × 48元/kg = 528元

  价格差异 = (48 - 50) × 11 = -22元 (有利 ✅)
  用量差异 = (11 - 10) × 50 = +50元 (不利 ❌)
  总差异 = -22 + 50 = +28元 (不利)
```

### 3.2 人工差异

```
人工费率差异 = (实际费率 - 标准费率) × 实际工时
人工效率差异 = (实际工时 - 标准工时) × 标准费率

示例:
  标准: 5小时 × 30元/时 = 150元
  实际: 6小时 × 28元/时 = 168元

  费率差异 = (28 - 30) × 6 = -12元 (有利 ✅)
  效率差异 = (6 - 5) × 30 = +30元 (不利 ❌)
  总差异 = -12 + 30 = +18元 (不利)
```

### 3.3 制造费用差异

```
三因素分析法:

开支差异 = 实际制造费用 - 预算制造费用
效率差异 = (实际工时 - 标准工时) × 标准分配率
产量差异 = (预算产量 - 实际产量) × 标准单位制造费用
```

### 3.4 差异处理会计分录

## 四、完工产品成本结转

### 4.1 约当产量法

```
约当产量 = 完工数量 + 在制品数量 × 完工百分比

示例:
  完工产品: 100件
  在制品: 20件，完工度 50%
  约当产量 = 100 + 20 × 50% = 110件

  本期总成本: 55,000元
  单位成本 = 55,000 / 110 = 500元/件

  完工产品成本 = 100 × 500 = 50,000元
  在制品成本 = 10 × 500 = 5,000元
```

## 五、制造费用分配

### 5.1 分配标准

| 分配标准 | 计算方式 | 适用场景 |
|---------|---------|---------|
| 直接人工工时 | 制造费用 × (工单工时/总工时) | 人工密集型 |
| 机器工时 | 制造费用 × (工单机器工时/总机器工时) | 设备密集型 |
| 直接材料成本 | 制造费用 × (工单材料成本/总材料成本) | 材料密集型 |
| 产量比例 | 制造费用 × (工单产量/总产量) | 单一产品 |

### 5.2 分配示例

```
本月制造费用总计: 100,000元
分配标准: 直接人工工时

工单A: 500小时 (50%)  → 分配 50,000元
工单B: 300小时 (30%)  → 分配 30,000元
工单C: 200小时 (20%)  → 分配 20,000元
合计:  1,000小时       合计 100,000元
```

**分配凭证:**

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 分配制造费用-工单A | 4001 生产成本-工单A | 50,000.00 | |
| 分配制造费用-工单B | 4001 生产成本-工单B | 30,000.00 | |
| 分配制造费用-工单C | 4001 生产成本-工单C | 20,000.00 | |
| 结转制造费用 | 4101 制造费用 | | 100,000.00 |

## 八、业务规则与约束

| 规则 | 描述 |
|------|------|
| 标准成本版本控制 | 同一产品同一时间只有一个有效标准成本 |
| 成本归集完整性 | 工单成本必须包含料、工、费三要素 |
| 制造费用必须分配 | 月末制造费用必须全部分配完毕 |
| 分配基数非零 | 分配标准的基数合计不能为零 |
| 差异及时分析 | 差异率超过阈值（如10%）需说明原因 |
| 完工前不可结转 | 未完工的工单不能结转产成品成本 |
| 成本不可为负 | 产品单位成本不可为负数 |
| 期间一致性 | 成本归集必须在正确的会计期间 |
| 在制品月末盘点 | 月末须确认在制品的完工程度 |
| 成本冻结 | 期间关闭后成本数据不可修改 |
