# 固定资产 FA (Fixed Assets)

## 概述

固定资产（FA）子系统管理企业的长期有形资产（设备、房屋、车辆等），覆盖资产的完整生命周期：从购入登记、折旧计提、资产变动到最终处置报废。它自动生成折旧凭证并更新总账，确保资产价值的准确反映。

## 一、核心业务流程

### 1.1 资产生命周期

```
资产采购/在建转固
      │
      ▼
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 资产登记   │───▶│ 正常使用   │───▶│ 资产变动   │───▶│ 资产处置   │
│ (建卡)    │    │ (计提折旧) │    │ (调拨/改良)│    │ (报废/出售)│
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                     │
                     ▼
               月末自动计提折旧
               生成折旧凭证
```

│ InUse    │───▶│ Idle     │───▶│ InUse    │  (闲置后重新启用)

## 三、折旧计算

### 3.1 折旧方法

**1. 直线法（年限平均法）— 最常用**

```
年折旧额 = (原值 - 残值) / 使用年限
月折旧额 = 年折旧额 / 12

示例: 设备原值 120,000，残值率 5%，使用年限 10年
  残值 = 120,000 × 5% = 6,000
  年折旧额 = (120,000 - 6,000) / 10 = 11,400
  月折旧额 = 11,400 / 12 = 950
```

**2. 双倍余额递减法**

```
年折旧率 = 2 / 使用年限 × 100%
年折旧额 = 期初净值 × 年折旧率
最后两年改为直线法: (期初净值 - 残值) / 2

示例: 设备原值 120,000，残值率 5%，使用年限 5年
  年折旧率 = 2/5 = 40%
  第1年: 120,000 × 40% = 48,000
  第2年: 72,000 × 40% = 28,800
  第3年: 43,200 × 40% = 17,280
  第4年: (25,920 - 6,000) / 2 = 9,960
  第5年: (25,920 - 6,000) / 2 = 9,960
```

**3. 年数总和法**

```
年折旧率 = 剩余使用年数 / 年数总和
年折旧额 = (原值 - 残值) × 年折旧率

示例: 使用年限 5年
  年数总和 = 5+4+3+2+1 = 15
  第1年: (120,000-6,000) × 5/15 = 38,000
  第2年: (120,000-6,000) × 4/15 = 30,400
  第3年: (120,000-6,000) × 3/15 = 22,800
  第4年: (120,000-6,000) × 2/15 = 15,200
  第5年: (120,000-6,000) × 1/15 = 7,600
```

**4. 工作量法**

```
单位工作量折旧额 = (原值 - 残值) / 预计总工作量
月折旧额 = 单位折旧额 × 本月实际工作量

示例: 运输车辆，预计总里程 500,000公里
  单位折旧额 = (120,000 - 6,000) / 500,000 = 0.228/公里
  本月行驶 3,000公里: 月折旧 = 0.228 × 3,000 = 684
```

## 四、资产处置会计处理

### 4.1 出售设备

```
假设: 设备原值 100,000，累计折旧 60,000，出售价 50,000（含税 44,248 + 增值税 5,752）

步骤1: 转入清理
  借: 固定资产清理    40,000    (净值)
  借: 累计折旧        60,000
  贷: 固定资产        100,000

步骤2: 确认收入
  借: 银行存款        50,000
  贷: 固定资产清理    44,248
  贷: 应交税费-销项税  5,752

步骤3: 结转损益
  借: 固定资产清理    4,248     (清理收益 = 44,248 - 40,000)
  贷: 营业外收入      4,248

(如果是亏损: 借 营业外支出, 贷 固定资产清理)
```

### 4.2 报废设备

```
假设: 设备原值 80,000，累计折旧 76,000，残料收入 1,000，清理费 500

步骤1: 转入清理
  借: 固定资产清理    4,000
  借: 累计折旧        76,000
  贷: 固定资产        80,000

步骤2: 残料收入
  借: 原材料/银行存款  1,000
  贷: 固定资产清理    1,000

步骤3: 清理费用
  借: 固定资产清理    500
  贷: 银行存款        500

步骤4: 结转净损失
  借: 营业外支出      3,500    (4,000 - 1,000 + 500)
  贷: 固定资产清理    3,500
```

## 五、资产盘点

### 5.1 盘点流程

```
① 生成盘点计划（按部门/类别/地点）
          │
          ▼
② 打印盘点表 / 移动端扫码盘点
          │
          ▼
③ 录入实盘结果
          │
          ▼
④ 系统自动对比，生成差异报告
   ├── 账实一致  → ✅
   ├── 盘盈      → 增加资产登记
   └── 盘亏      → 资产处置（盘亏）
          │
          ▼
⑤ 审批差异处理
          │
          ▼
⑥ 生成调整凭证
```

## 八、业务规则与约束

| 规则 | 描述 |
|------|------|
| 资产编码唯一 | 同一租户内资产编码不可重复 |
| 残值率范围 | 0-100%，一般不超过 5% |
| 使用年限下限 | 不同类别有最低使用年限（税法规定） |
| 已折旧完不再折旧 | 累计折旧 = 原值 - 残值后停止 |
| 折旧按月 | 当月增加次月开始折旧，当月减少当月仍计提 |
| 处置需审批 | 资产处置必须经过审批流程 |
| 处置前停止折旧 | 资产进入处置状态后不再计提折旧 |
| 净值不可为负 | 累计折旧不可超过（原值-残值） |
| 改良增加原值 | 资本化改良支出增加资产原值，重新计算折旧 |
| 调拨不影响价值 | 部门调拨只变更管理归属，不影响资产价值 |
