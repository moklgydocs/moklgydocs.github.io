# 财务与其他模块集成

## 概述

财务模块作为 ERP 系统的核心中枢，与采购、销售、生产、MRP 四大业务模块深度集成。业务模块的单据在特定节点自动触发财务凭证的生成，实现"业财一体化"——业务操作即完成会计核算，无需手工重复录入。

## 二、采购模块 → 财务

### 2.1 集成触发点

| 采购事件 | 触发时机 | 财务操作 | 目标子系统 |
|---------|---------|---------|-----------|
| 收货入库 | GRN 确认 | 暂估入账 | GL (存货科目) |
| 采购发票 | 发票登记 | 生成应付、冲暂估 | AP + GL |
| 三单匹配 | 匹配完成 | 更新应付金额 | AP |
| 付款 | 付款执行 | 银行出账、核销应付 | AP + BANK |
| 预付款 | 预付确认 | 预付账款入账 | GL + BANK |
| 采购退货 | 退货确认 | 红冲入库凭证 | GL + AP |

## 三、销售模块 → 财务

### 3.1 集成触发点

| 销售事件 | 触发时机 | 财务操作 | 目标子系统 |
|---------|---------|---------|-----------|

| 客户回款 | 回款确认 | 银行入账、核销应收 | AR + BANK |

### 3.3 收入确认原则

| 条件 | 说明 |
|------|------|
| 商品已交付 | 风险报酬已转移（通常以发货或签收为准） |
| 收入可计量 | 金额已确定（发票开具） |
| 成本可计量 | 相关成本能够可靠计量 |
| 经济利益很可能流入 | 客户信用良好，预计能收到款项 |

## 五、MRP/库存模块 → 财务

### 5.1 集成触发点

| 库存事件 | 触发时机 | 财务操作 | 目标子系统 |
|---------|---------|---------|-----------|
| 采购入库 | 入库确认 | 存货增加 | GL |
| 销售出库 | 出库确认 | 存货减少 | GL |
| 生产领料 | 出库确认 | 原材料→在制品 | GL |
| 完工入库 | 入库确认 | 在制品→产成品 | GL |
| 其他入库 | 确认 | 存货增加 | GL |
| 其他出库 | 确认 | 存货减少 | GL |
| 库存盘盈 | 审批通过 | 存货增加 | GL |
| 库存盘亏 | 审批通过 | 存货减少 | GL |
| 库存调拨 | 确认 | 仓库间转移 | GL（仓库辅助核算变更） |

### 5.2 存货计价方法

| 方法 | 说明 | 凭证影响 |
|------|------|---------|
| 加权平均法 | 每次入库重新计算加权平均单价 | 出库成本按平均单价 |
| 移动加权平均 | 每次入库即时更新单价 | 实时反映最新成本 |
| 先进先出 (FIFO) | 先入库的先出库 | 出库成本按批次 |
| 个别计价法 | 按具体批次/序列号 | 出库成本按实际 |

## 六、凭证生成引擎

### 6.1 引擎架构

```
业务单据事件
      │
      ▼
┌──────────────────┐
│  事件订阅器       │  监听业务模块的领域事件
│  Event Subscriber │  (DomainEvent / IntegrationEvent)
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  凭证模板匹配     │  根据单据类型 + 业务场景匹配模板
│  Template Matcher │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  科目映射器       │  根据模板规则映射会计科目
│  Account Mapper   │  支持按类别/仓库/部门等条件映射
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  金额计算器       │  按业务规则计算借贷金额
│  Amount Calculator│  支持含税/不含税/外币
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  凭证生成器       │  组装凭证头和明细行
│  Voucher Builder  │  校验借贷平衡
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  凭证存储         │  保存凭证，状态为 Draft/Submitted
│  Voucher Store    │  可配置自动审核+过账
└──────────────────┘
```

### 6.2 凭证模板配置

```
VoucherTemplate (凭证模板)
├── Id: Guid
├── TenantId: Guid
├── Code: string(20)                   # 模板编码
├── Name: string(100)                  # 模板名称
├── SourceModule: string(20)           # 来源模块 (Purchase/Sales/Production/Inventory)
├── SourceEvent: string(50)            # 来源事件 (GoodsReceipt/SalesInvoice/...)
├── VoucherType: VoucherType           # 凭证类型
├── AutoPost: bool                     # 是否自动过账
├── IsActive: bool
└── Lines: List<VoucherTemplateLine>

VoucherTemplateLine (模板行)
├── Id: Guid
├── TemplateId: Guid
├── LineNo: int
├── SummaryTemplate: string(200)       # 摘要模板 (支持变量: {SupplierName}, {ProductName})
├── AccountMapping: string(50)         # 科目映射规则
├── Direction: string(1)               # D=借方, C=贷方
├── AmountExpression: string(200)      # 金额表达式 (Amount, TaxAmount, TotalAmount)
├── AuxCustomer: bool                  # 需要客户辅助
├── AuxSupplier: bool                  # 需要供应商辅助
├── AuxDepartment: bool                # 需要部门辅助
└── AuxProject: bool                   # 需要项目辅助

示例模板 — 采购入库:
  Line 1: D 1403(原材料)     Amount        "采购入库-{ProductName}"
  Line 2: D 2221.01(进项税)  TaxAmount     "进项税额"
  Line 3: C 2202(应付账款)   TotalAmount   "应付-{SupplierName}"  [辅助:供应商]
```

## 七、月结协同流程

### 7.1 跨模块月结步骤

```
月末关账流程 (必须按顺序执行):

Day 1-3: 业务截止
  ① 采购模块: 截止收货、发票登记
  ② 销售模块: 截止发货、开票
  ③ 生产模块: 截止报工、完工入库
  ④ 库存模块: 截止出入库、执行库存盘点

Day 3-5: 财务处理
  ⑤ 暂估入账核查: 未到票采购暂估是否准确
  ⑥ 计提折旧: FA 模块执行月度折旧
  ⑦ 计提坏账: AR 模块执行坏账计提
  ⑧ 制造费用分配: COST 模块分配制造费用
  ⑨ 完工成本结转: COST 模块结转完工产品成本
  ⑩ 销售成本结转: COST 模块结转销售成本

Day 5-7: 期末结转
  ⑪ 汇兑损益: 外币科目期末调汇
  ⑫ 损益结转: 损益类科目结转至本年利润
  ⑬ 试算平衡: 检查借贷是否平衡
  ⑭ 生成报表: 资产负债表、利润表、现金流量表

Day 7: 关闭期间
  ⑮ 关闭当月会计期间
  ⑯ 打开下月会计期间
```

### 7.2 月结检查清单

| 检查项 | 模块 | 验证内容 |
|--------|------|---------|
| 凭证全部过账 | GL | 无 Submitted/Approved 状态凭证 |
| 试算平衡 | GL | 借方总额 = 贷方总额 |
| 银行已对账 | BANK | 余额调节表已平衡 |
| 应收已核对 | AR | 应收余额与客户确认一致 |
| 应付已核对 | AP | 应付余额与供应商确认一致 |
| 暂估已处理 | AP | 上月暂估已冲回或正式入账 |
| 折旧已计提 | FA | 本月折旧凭证已生成 |
| 成本已归集 | COST | 制造费用已分配，完工成本已结转 |
| 损益已结转 | GL | 损益类科目余额已清零 |
| 存货已盘点 | MRP | 账实差异已处理 |

## 九、业务规则与约束

| 规则 | 描述 |
|------|------|
| 业务凭证可追溯 | 自动生成的凭证必须关联来源单据（SourceDocumentId） |
| 凭证不可手工删除 | 业务单据生成的凭证只能通过红冲处理 |
| 单据取消联动 | 业务单据取消时自动红冲对应凭证 |
| 模板匹配唯一 | 同一事件类型只能匹配到一个有效模板 |

| 跨模块数据一致 | AR应收余额 = GL应收科目余额 |
