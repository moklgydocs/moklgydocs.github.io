# 财务报表

## 概述

财务报表子系统负责生成企业法定财务报表（资产负债表、利润表、现金流量表）和内部管理报表。它从总账科目余额中提取数据，按报表模板计算填列，支持多维度分析和自定义报表，为经营决策提供数据支撑。

## 一、报表体系

### 1.1 报表分类

```
财务报表体系
├── 法定报表 (对外)
│   ├── 资产负债表 (Balance Sheet)
│   ├── 利润表 (Income Statement)
│   ├── 现金流量表 (Cash Flow Statement)
│   └── 所有者权益变动表 (Statement of Changes in Equity)
│
├── 管理报表 (对内)
│   ├── 部门费用报表
│   ├── 项目损益报表
│   ├── 产品毛利分析
│   ├── 预算执行报表
│   └── 自定义报表
│
└── 辅助报表
    ├── 试算平衡表
    ├── 科目余额表
    ├── 明细账
    ├── 总账
    └── 日记账
```

### 1.2 报表生成流程

```
① 确认期间数据完整
   ├── 所有凭证已过账
   ├── 期末结转已完成
   └── 试算平衡通过
              │
              ▼
② 选择报表模板
              │
              ▼
③ 系统自动取数
   ├── 从科目余额表取数
   ├── 按公式计算
   └── 辅助核算维度筛选
              │
              ▼
④ 生成报表草稿
              │
              ▼
⑤ 人工复核调整
              │
              ▼
⑥ 确认发布 → 导出 (PDF/Excel)
```

### 4.2 现金流量编制方法

| 方法 | 说明 | 适用 |
|------|------|------|
| **直接法** | 从凭证中按现金流量项目直接归集 | 主表（经营活动部分） |
| **间接法** | 从净利润出发，调整非现金项目 | 补充资料 |

**直接法**: 凭证录入时指定现金流量项目，或期末手工指定。
**间接法公式**:

```
经营活动现金流量 = 净利润
  + 折旧摊销
  + 资产减值准备
  + 固定资产报废损失
  + 财务费用
  - 投资收益
  + 存货的减少(增加取负)
  + 经营性应收项目的减少(增加取负)
  + 经营性应付项目的增加(减少取负)
  + ...
```

### 5.3 关键财务指标

| 类别 | 指标 | 公式 |
|------|------|------|
| **盈利能力** | 毛利率 | (营业收入-营业成本)/营业收入 × 100% |
| | 净利润率 | 净利润/营业收入 × 100% |
| | ROE(净资产收益率) | 净利润/所有者权益 × 100% |
| | ROA(总资产收益率) | 净利润/总资产 × 100% |
| **偿债能力** | 流动比率 | 流动资产/流动负债 |
| | 速动比率 | (流动资产-存货)/流动负债 |
| | 资产负债率 | 负债总额/资产总额 × 100% |
| **运营效率** | 应收账款周转天数 | 365/(营业收入/平均应收账款) |
| | 存货周转天数 | 365/(营业成本/平均存货) |
| | 总资产周转率 | 营业收入/平均总资产 |
| **成长能力** | 营收增长率 | (本期收入-上期收入)/上期收入 × 100% |
| | 净利润增长率 | (本期净利-上期净利)/上期净利 × 100% |


### 6.2 取数公式语法

```
科目余额:  BAL(1001)          → 1001科目期末余额
           BAL(1001,D)        → 1001科目期末借方余额
           BAL(1001,C)        → 1001科目期末贷方余额
           BAL(1001,Y)        → 1001科目年初余额

期间发生:  PER(5001,C)        → 5001科目本期贷方发生额
           PER(5001,D)        → 5001科目本期借方发生额

表内引用:  ROW(5) + ROW(6)    → 第5行 + 第6行

科目范围:  BAL(1001:1002)     → 1001至1002科目余额之和

辅助核算:  BAL(1122,D,CUS=xxx) → 按客户筛选

示例:
  货币资金 = BAL(1001) + BAL(1002) + BAL(1012)
  应收账款(净) = BAL(1122,D) - BAL(1231,C)
  固定资产(净) = BAL(1601) - BAL(1602)
  营业利润 = ROW(1) - ROW(2) - ROW(3) - ROW(4) - ROW(5) - ROW(6) - ROW(7)
```

## 八、多维度分析

### 8.1 分析维度

| 维度 | 说明 | 应用场景 |
|------|------|---------|
| 时间 | 年/季/月/日 | 趋势分析、同比环比 |
| 部门 | 组织架构 | 部门绩效、费用对比 |
| 产品 | 产品线/品类 | 毛利分析、产品贡献 |
| 客户 | 客户分组 | 客户价值、应收分析 |
| 供应商 | 供应商分组 | 采购成本、应付分析 |
| 项目 | 项目编码 | 项目损益、ROI分析 |
| 区域 | 地理区域 | 区域销售、费用对比 |
| 成本中心 | 成本归属 | 成本控制、预算对比 |

### 8.2 同比与环比

```
同比 = (本期数 - 上年同期数) / |上年同期数| × 100%
环比 = (本期数 - 上期数) / |上期数| × 100%

示例:
  2024年1月收入 100万, 2023年1月收入 80万, 2023年12月收入 90万
  同比增长 = (100-80)/80 = 25%
  环比增长 = (100-90)/90 = 11.1%
```

## 九、业务规则与约束

| 规则 | 描述 |
|------|------|
| 数据完整性 | 生成报表前必须确认期间数据完整，凭证全部过账 |
| 试算平衡 | 资产负债表必须平衡（资产=负债+权益） |
| 现金流验证 | 现金净增加额 = 期末现金余额 - 期初现金余额 |
| 期间一致性 | 利润表为期间数据，资产负债表为时点数据 |
| 版本控制 | 已发布报表不可修改，只能重新生成 |
| 调整留痕 | 手工调整必须记录原因和操作人 |
| 复核分离 | 生成人和复核人必须不同 |
| 模板保护 | 系统预设模板不可删除，只可复制修改 |
| 勾稽关系 | 资产负债表与利润表的勾稽关系必须成立 |
| 四舍五入 | 报表金额四舍五入到分（0.01） |
