# 财务模块总览

## 模块定位

财务模块是 ERP 系统的**核心中枢**，所有业务模块的资金流最终汇聚于此。它承担企业会计核算、资金管理、成本控制和财务报告的全部职能，是企业经营决策的数据基础。

## 子系统职责

| 子系统 | 缩写 | 核心职责 | 关键实体 |
|--------|------|---------|---------|
| **总账** | GL | 科目管理、凭证录入/审核/过账、期末结转 | Account, Voucher, VoucherLine, FiscalPeriod |
| **应收账款** | AR | 客户应收、开票、回款、账龄分析、坏账计提 | Receivable, Receipt, AgingReport |
| **应付账款** | AP | 供应商应付、三单匹配、付款计划、付款执行 | Payable, Payment, ThreeWayMatch |
| **固定资产** | FA | 资产登记、折旧计提、资产变动、处置清理 | FixedAsset, DepreciationRecord, AssetDisposal |
| **成本核算** | COST | 标准成本维护、实际成本归集、差异分析 | CostCenter, CostItem, CostVariance |
| **银行与现金** | BANK | 银行账户管理、收付款、银行对账 | BankAccount, BankTransaction, BankReconciliation |
| **财务报表** | RPT | 三大报表生成、管理报表、多维分析 | ReportTemplate, ReportData, AnalysisDimension |

## 会计准则支持

系统支持中国会计准则（CAS）为主，同时预留 IFRS 国际准则扩展能力：

| 准则 | 覆盖范围 | 说明 |
|------|---------|------|
| CAS（企业会计准则） | 科目编码、报表格式、折旧方法 | 默认标准 |
| 小企业会计准则 | 简化科目、简化报表 | 可配置 |
| IFRS | 科目映射、双套报表 | 预留扩展 |

## 财务处理时序

```
日常处理:
  业务单据 → 自动生成凭证 → 凭证审核 → 凭证过账 → 更新科目余额

月末处理:
  ① 业务单据截止 → ② 计提折旧 → ③ 成本归集与分配
  → ④ 汇兑损益 → ⑤ 计提坏账 → ⑥ 损益结转
  → ⑦ 生成报表 → ⑧ 关闭期间

年末处理:
  月末处理 + 年度损益结转 → 利润分配 → 生成年报 → 关闭会计年度
```

## 凭证编号规则

| 凭证类型 | 字号 | 编号格式 | 示例 |
|---------|------|---------|------|
| 收款凭证 | 收 | SK-{YYYY}-{MM}-{SEQ} | SK-2024-01-0001 |
| 付款凭证 | 付 | FK-{YYYY}-{MM}-{SEQ} | FK-2024-01-0001 |
| 转账凭证 | 转 | ZZ-{YYYY}-{MM}-{SEQ} | ZZ-2024-01-0001 |
| 通用记账 | 记 | PZ-{YYYY}-{MM}-{SEQ} | PZ-2024-01-0001 |

## API 设计概览

| 子系统 | 路由前缀 | 说明 |
|--------|---------|------|
| 总账 | `/api/finance/gl` | 科目、凭证、期间 |
| 应收 | `/api/finance/ar` | 应收单、回款、账龄 |
| 应付 | `/api/finance/ap` | 应付单、付款、三单匹配 |

| 报表 | `/api/finance/report` | 报表生成、查询 |
