# MRP 模块总览

## 模块定位

MRP（Material Requirements Planning，物料需求计划）模块是 ERP 系统的计划引擎，通过 MPS（主生产计划）确定生产什么、MRP 运算确定需要什么物料和何时需要、CRP（产能需求计划）验证产能是否可行。同时，它管理企业的库存，确保物料供应与需求的平衡。

## 核心实体总览

| 实体 | 说明 |
|------|------|
| DemandForecast | 需求预测 |
| MPS | 主生产计划 |
| MRPRun | MRP 运算批次 |
| MRPResult | MRP 运算结果（计划订单） |
| Warehouse / Location | 仓库 / 库位 |
| InventoryItem | 库存物料 |
| InventoryTransaction | 库存事务 |
| CapacityPlan | 产能计划 |

## 核心流程概览

```
需求预测 + 销售订单 + 安全库存
              │
              ▼
         MPS (主生产计划)
         "何时生产什么成品，多少"
              │
              ▼
         MRP 运算
         "需要什么物料，多少，何时"
              │
              ▼
         CRP (产能需求计划)
         "产能是否足够"
              │
         ┌────┴────┐
         ▼         ▼
    产能充足    产能不足
         │         │
         ▼         ▼
    确认计划    调整MPS/加班/外协
         │
    ┌────┴────┐
    ▼         ▼
采购申请(PR)  生产工单(WO)
```

## 与其他模块的集成

| 集成模块 | 数据流向 | 说明 |
|---------|---------|------|
| 销售 → MRP | 销售订单/预测 → 独立需求 | 销售需求作为 MRP 输入 |
| MRP → 采购 | 计划采购订单 → PR | 外购件转采购申请 |
| MRP → 生产 | 计划生产订单 → WO | 自制件转生产工单 |
| 生产 → MRP | BOM → 物料需求 | BOM 展开生成相关需求 |
| MRP ↔ 库存 | 库存数据 | MRP 读取库存计算净需求 |
| 库存 → 财务 | 库存变动 → 存货科目 | 出入库生成凭证 |
