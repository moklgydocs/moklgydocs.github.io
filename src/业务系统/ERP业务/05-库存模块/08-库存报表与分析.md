# 库存报表与分析

## 概述

库存报表与分析为库存管理决策提供数据支撑。系统提供操作级、分析级和管理级三类报表，覆盖库存余额、收发存、库龄分析、周转分析、呆滞物料、仓库利用率等维度，配合 KPI 仪表板实现库存绩效的实时监控。

## 一、报表体系

```
库存报表
├── 操作报表 (日常)
│   ├── 库存余额表          # 当前库存快照
│   ├── 库存收发存报表       # 期间出入库汇总
│   ├── 待入库明细           # 已到货未完成入库
│   ├── 待出库明细           # 已下单未完成出库
│   └── 在途库存             # 调拨在途物料
│
├── 分析报表 (定期)
│   ├── 库龄分析报表         # 库存停留时间分布
│   ├── 库存周转分析         # 周转率、周转天数
│   ├── 呆滞物料报表         # 慢动/死库存
│   ├── ABC分类报表          # 帕累托分析
│   └── 安全库存预警         # 低于安全库存的物料
│
└── 管理报表 (战略)
    ├── 仓库利用率报表       # 空间/容量使用情况
    ├── 供需差距分析         # 库存 vs 需求
    ├── 库存成本分析         # 持有成本、资金占用
    └── KPI 仪表板          # 关键绩效指标汇总
```

## 五、库存周转分析

### 5.1 周转指标

```
库存周转率 = 销售成本 (COGS) / 平均库存金额

库存周转天数 = 365 / 库存周转率
             = 平均库存金额 × 365 / 销售成本

示例:
  年销售成本: ¥5,000,000
  期初库存:   ¥800,000
  期末库存:   ¥1,200,000
  平均库存 = (800,000 + 1,200,000) / 2 = ¥1,000,000

  周转率 = 5,000,000 / 1,000,000 = 5.0 次/年
  周转天数 = 365 / 5.0 = 73 天
```

| 分类 | 条件 | 风险等级 | 建议处置 |

## 九、KPI 仪表板

### 9.1 核心指标

| KPI | 公式 | 目标 | 数据来源 |
|-----|------|------|---------|
| 库存准确率 | 无差异项 / 总盘点项 × 100% | ≥ 97% | 盘点结果 |
| 订单满足率 | 按时足量发货订单 / 总订单 × 100% | ≥ 95% | 出库记录 |
| 库存天数 | 平均库存 × 365 / 年消耗 | 30-60天 | 估值/消耗 |
| 库存周转率 | COGS / 平均库存 | ≥ 6次/年 | 财务/估值 |
| 缺货率 | 缺货次数 / 总需求次数 × 100% | ≤ 2% | 出库/需求 |
| 持有成本率 | 年持有成本 / 平均库存 × 100% | ≤ 25% | 财务/估值 |
| 上架周期 | 平均上架完成时间 | ≤ 4小时 | 上架任务 |
| 拣货准确率 | 正确拣货次数 / 总拣货次数 × 100% | ≥ 99.5% | 拣货任务 |
| 收货准时率 | 按时完成收货 / 总收货 × 100% | ≥ 95% | 入库记录 |
| 呆滞库存比 | 呆滞库存金额 / 总库存金额 × 100% | ≤ 5% | 库龄分析 |

## 十二、业务规则

| 规则 | 描述 |
|------|------|
| 期间数据完整 | 报表生成前对应期间的数据必须完整（无未确认事务） |
| 库龄按入库日 | 库龄从原始入库日期计算，调拨不重置库龄 |
| 周转排除寄售 | 周转率计算排除寄售库存 |
| ABC 季度重算 | ABC 分类至少每季度重新计算 |
| KPI 实时刷新 | KPI 仪表板数据支持实时刷新 |
| 预警阈值可配 | 安全库存预警、库龄预警等阈值可按租户配置 |
| 报表权限 | 不同角色可查看不同级别的报表 |
| 导出格式 | 支持 PDF 和 Excel 两种导出格式 |
| 历史保留 | 报表实例保留至少12个月供查阅 |
| 数据一致性 | 收发存报表的期初+入库-出库必须等于期末 |
