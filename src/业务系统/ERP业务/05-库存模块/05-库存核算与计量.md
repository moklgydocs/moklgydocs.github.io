# 库存核算与计量

## 概述

库存核算与计量是库存管理与财务管理的桥梁，负责存货的计价、成本计算、到岸成本分摊、计量单位换算以及物料分类等。系统支持五种主流存货计价方法，提供成本层管理、到岸成本分摊和库存重估功能，确保库存价值的准确核算。

## 一、存货计价方法

### 1.1 方法对比

| 计价方法 | 英文 | 计算原理 | 适用场景 | 优缺点 |
|---------|------|---------|---------|--------|
| 加权平均 | Weighted Average | 期末统一计算平均成本 | 品种少、波动小 | 简单但月中无法准确计成本 |
| 移动加权平均 | Moving Average | 每次入库重新计算 | 实时性要求高 | 精确但计算频繁 |
| 先进先出 | FIFO | 按入库顺序消耗成本 | 有保质期、标准选择 | 符合实物流，计算复杂 |
| 个别计价 | Specific Identification | 按具体批次/序列号计价 | 高价值、可识别物料 | 最精确但管理成本高 |
| 标准成本 | Standard Cost | 按预设标准成本出入库 | 制造业、成本控制 | 利于分析但需维护标准 |

### 1.2 加权平均法

```
月末加权平均单位成本 = (期初库存金额 + 本期入库总金额) / (期初库存数量 + 本期入库总数量)

示例:
  期初: 100件 × ¥10.00 = ¥1,000.00
  1/5  入库: 200件 × ¥11.00 = ¥2,200.00
  1/15 入库: 150件 × ¥10.50 = ¥1,575.00
  
  加权平均单价 = (1,000 + 2,200 + 1,575) / (100 + 200 + 150) = ¥10.61
  
  本月出库 300件:
  出库成本 = 300 × ¥10.61 = ¥3,183.33
  期末库存 = 150件 × ¥10.61 = ¥1,591.67
```

### 1.3 移动加权平均法

```
每次入库后重新计算单价:

期初: 100件 × ¥10.00 = ¥1,000.00                单价 = ¥10.00

1/5 入库 200件 × ¥11.00:
  新单价 = (1,000 + 2,200) / (100 + 200) = ¥10.67

1/10 出库 150件:
  出库成本 = 150 × ¥10.67 = ¥1,600.00
  剩余: 150件 × ¥10.67 = ¥1,600.00

1/15 入库 150件 × ¥10.50:
  新单价 = (1,600 + 1,575) / (150 + 150) = ¥10.58
  
期末: 300件 × ¥10.58 = ¥3,175.00
```

### 1.4 先进先出法 (FIFO)

```
成本层按入库顺序排列，出库时从最早的成本层开始消耗:

成本层:
  层1: 1/1  入库 100件 × ¥10.00 = ¥1,000
  层2: 1/5  入库 200件 × ¥11.00 = ¥2,200
  层3: 1/15 入库 150件 × ¥10.50 = ¥1,575

1/10 出库 250件:
  消耗层1: 100件 × ¥10.00 = ¥1,000 (层1耗尽)
  消耗层2: 150件 × ¥11.00 = ¥1,650 (层2剩余50件)
  出库成本合计 = ¥2,650

剩余成本层:
  层2: 50件 × ¥11.00 = ¥550
  层3: 150件 × ¥10.50 = ¥1,575
  期末库存 = ¥2,125
```

### 1.5 标准成本法

```
标准成本入库/出库:
  入库: 按标准成本入账，差异计入采购价格差异
  出库: 按标准成本出账

示例: 物料A 标准成本 ¥10.00
  
  采购入库 100件 × 实际 ¥10.50:
    借: 原材料           1,000  (100 × ¥10.00 标准)
    借: 采购价格差异        50  (100 × ¥0.50 差异)
      贷: 应付账款         1,050
  
  生产领料 80件:
    借: 生产成本           800  (80 × ¥10.00 标准)
      贷: 原材料            800
```

```

### 3.2 多 UOM 场景

```
物料: 钢管 (基本单位: 根)

采购单位: 吨    1吨 = 200根
库存单位: 根    (基本单位)
销售单位: 米    1根 = 6米

采购入库:
  PO: 2吨 → 库存: 400根 (× 换算系数 200)

销售出库:
  SO: 1200米 → 库存: 200根 (÷ 换算系数 6)

UOM 组配置:
  ┌────────┬────────┬───────────┐
  │ FromUOM│ ToUOM  │ Factor    │
  ├────────┼────────┼───────────┤
  │ 吨     │ 根     │ 200.000   │
  │ 根     │ 米     │ 6.000     │
  │ 吨     │ 米     │ 1200.000  │
  └────────┴────────┴───────────┘
```

```

## 五、到岸成本分摊

```
到岸成本分摊流程:

① 入库单 RO-001 包含3种物料:
   物料A: 100件, 单价¥10, 金额¥1,000, 重量500kg
   物料B: 200件, 单价¥5,  金额¥1,000, 重量200kg
   物料C: 50件,  单价¥20, 金额¥1,000, 重量300kg

② 发生附加费用:
   运费: ¥600 (按重量分摊)
   关税: ¥300 (按金额分摊)

③ 运费分摊 (按重量):
   物料A: 600 × 500/1000 = ¥300
   物料B: 600 × 200/1000 = ¥120
   物料C: 600 × 300/1000 = ¥180

④ 关税分摊 (按金额):
   物料A: 300 × 1000/3000 = ¥100
   物料B: 300 × 1000/3000 = ¥100
   物料C: 300 × 1000/3000 = ¥100

⑤ 最终到岸成本:
   物料A: ¥1,000 + ¥300 + ¥100 = ¥1,400  单价: ¥14.00/件
   物料B: ¥1,000 + ¥120 + ¥100 = ¥1,220  单价: ¥6.10/件
   物料C: ¥1,000 + ¥180 + ¥100 = ¥1,280  单价: ¥25.60/件

⑥ 会计分录:
   借: 原材料-物料A    400  (到岸成本调增)
   借: 原材料-物料B    220
   借: 原材料-物料C    280
     贷: 应付账款-运费   600
     贷: 应交税费-关税   300
```

## 八、业务规则

| 规则 | 描述 |
|------|------|
| 计价方法不可中途变更 | 会计期间内同一物料不可变更计价方法 |
| 成本层 FIFO 消耗 | FIFO 方法下成本层必须按入库日期顺序消耗 |
| 成本层不可为负 | 成本层剩余数量不可为负 |
| 到岸成本时效 | 到岸成本只能分摊到未出库的入库批次 |
| 到岸成本审批 | 分摊金额超过阈值需要审批 |
| 重估审批 | 库存重估必须经过审批才能过账 |
| 重估生成凭证 | 重估过账自动生成差异调整凭证 |
| UOM 换算一致性 | A→B 和 B→A 的换算系数必须互为倒数 |
| 基准单位唯一 | 每个物料只能有一个基准计量单位 |
| ABC 定期重算 | ABC 分类至少每季度重新计算一次 |
| 期末估值完整 | 月末结账前所有物料必须完成估值计算 |
| 标准成本维护 | 标准成本更新需记录变更历史和原因 |
