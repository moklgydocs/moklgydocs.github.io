# 出库管理

## 概述

出库管理处理所有减少库存的业务操作，包括销售出库、生产领料、采购退货、仓库调拨、报废处理等。系统通过出库单统一管理各类出库事务，支持多种拣货策略、装箱管理和发运确认，确保物料准确、高效地从库存发出。

## 一、出库类型总览

| 出库类型 | 触发来源 | 来源单据 | 需预留 | 财务影响 |
|---------|---------|---------|-------|---------|
| 销售出库 | SO 发货确认 | 销售订单/发货单 | 是 | 库存商品减少，成本结转 |
| 生产领料 | WO 领料申请 | 生产工单 | 可选 | 原材料→生产成本 |
| 采购退货 | 退货审批 | 采购退货单 | 否 | 原材料减少，应付冲回 |
| 调拨出库 | 调拨单审批 | 调拨单 | 是 | 仓库间转移 |
| 报废出库 | 报废审批 | 报废单 | 否 | 库存减少，损失计入费用 |
| 其他出库 | 手工创建 | - | 否 | 库存减少 |

## 四、出库状态机

```
                                    (销售出库路径)
Draft → Allocated → PickingInProgress → Picked → Packing → Packed → Dispatched → Completed
                                          │
                                          │ (领料等无装箱)
                                          └──────────────────────────────────────▶ Completed

任意状态 ──▶ Cancelled (草稿/已分配状态可取消)

```

## 五、拣货策略

### 5.1 策略对比

| 策略 | 英文 | 原理 | 适用场景 |
|------|------|------|---------|
| FIFO拣货 | First In First Out | 优先拣取最早入库批次 | 通用，防止积压 |
| FEFO拣货 | First Expired First Out | 优先拣取最早过期批次 | 食品、药品、化学品 |
| 波次拣货 | Wave Picking | 合并多个出库单生成波次 | 订单量大，提高效率 |
| 分区拣货 | Zone Picking | 拣货员负责固定区域 | 大型仓库，减少行走 |
| 批量拣货 | Batch Picking | 同物料跨订单合并拣取 | 相同SKU多订单 |

### 5.2 FIFO/FEFO 拣货逻辑

```
FIFO 拣货示例:
  物料A 需拣 80件

  可用批次 (按入库日期排序):
    批次 BAT-001: 入库 1/5,  库存 30件  → 拣 30件
    批次 BAT-002: 入库 1/12, 库存 50件  → 拣 50件
    合计: 80件 ✅

FEFO 拣货示例:
  物料A 需拣 80件

  可用批次 (按到期日期排序):
    批次 BAT-003: 到期 3/15, 库存 20件  → 拣 20件
    批次 BAT-001: 到期 4/01, 库存 30件  → 拣 30件
    批次 BAT-002: 到期 5/20, 库存 50件  → 拣 30件
    合计: 80件 ✅
```

## 六、出库成本计算

### 6.1 各计价方法出库成本

```
移动加权平均法:
  出库成本 = 出库数量 × 当前加权平均单位成本
  
  示例:
    期初: 100件 × ¥10 = ¥1,000
    入库: 50件 × ¥12 = ¥600
    加权平均单价 = (1,000 + 600) / (100 + 50) = ¥10.67
    出库 80件: 成本 = 80 × ¥10.67 = ¥853.33

先进先出法:
  出库成本 = 按入库时间顺序逐笔消耗成本层
  
  示例:
    成本层1: 100件 × ¥10
    成本层2: 50件 × ¥12
    出库 120件: = 100×¥10 + 20×¥12 = ¥1,240

标准成本法:
  出库成本 = 出库数量 × 标准单位成本
  差异 = (标准成本 - 实际成本) × 数量 → 计入差异科目
```

## 九、业务规则

| 规则 | 描述 |
|------|------|
| 库存不可为负 | 出库数量不得超过可用库存 (除非仓库允许负库存) |
| 预留优先 | 已预留库存只能被预留订单使用 |
| FIFO/FEFO强制 | 配置FIFO/FEFO的物料必须按策略出库 |
| 批次一致 | 同一出库行的拣货批次必须一致 (或按批次拆行) |
| 拣货确认 | 拣货数量与任务数量不一致时触发短拣流程 |
| 装箱校验 | 装箱总数量必须等于出库单数量 |
| 箱重限制 | 单箱重量不得超过配置的最大重量 |
| 调拨两端同步 | 调拨发出和接收必须有对应的出入库记录 |
| 在途跟踪 | 调拨发出后物料进入在途状态，接收后解除 |
| 领料不超 | 生产领料不得超过工单 BOM 用量 (可配置超领比例) |
| 确认不可逆 | 已确认的出库单不可修改，只能通过入库冲销 |
| 事务原子性 | 出库确认、库存更新、成本计算、财务凭证在同一事务内完成 |
| 序列号追踪 | 序列号管理物料出库时必须记录每件序列号 |
| 取消回退 | 取消出库单自动释放已分配/预留的库存 |
