# 盘点与库存调整

## 概述

盘点与库存调整确保系统库存数据与实物库存一致。系统支持全面盘点、循环盘点和抽盘三种模式，结合盲盘/明盘方式、多轮复盘机制和分级审批工作流，实现库存准确率的持续提升。库存调整涵盖盘点差异处理、损坏核销、报废处理等场景。

## 一、盘点类型

| 盘点类型 | 英文 | 频率 | 范围 | 适用场景 |
|---------|------|------|------|---------|
| 全面盘点 | Full Count | 年度/半年 | 全部库存 | 年终结算、审计要求 |
| 循环盘点 | Cycle Count | 持续滚动 | 部分物料 | 日常管理，不停工 |
| 抽盘 | Spot Count | 随时 | 随机物料 | 差异验证、审计抽查 |

### 盘点方式

| 方式 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| 盲盘 | 不显示账面数量 | 避免主观偏差 | 高差异率需复盘 |
| 明盘 | 显示账面数量 | 效率高 | 可能忽略差异 |

## 三、核心实体

### 3.1 盘点计划

```
StockCountPlan (盘点计划)
├── Id: Guid
├── TenantId: Guid
├── PlanNo: string(30)
├── PlanName: string(100)
├── PlanType: CountPlanType            # 计划类型
├── WarehouseId: Guid                  # 目标仓库
├── ZoneId: Guid?                      # 目标库区 (空=全仓)
│
├── ScheduleType: ScheduleType         # 排程类型
├── CycleFrequency: string(20)?       # 循环频率 (Weekly/Monthly/Quarterly)
├── ABCFrequencyA: string(20)?        # A类频率
├── ABCFrequencyB: string(20)?        # B类频率
├── ABCFrequencyC: string(20)?        # C类频率
│
├── NextCountDate: DateTime?           # 下次盘点日
├── LastCountDate: DateTime?           # 上次盘点日
├── ItemFilter: string?                # 物料筛选条件 (JSON)
│
├── Status: CountPlanStatus
├── CreatedBy: Guid
├── IsActive: bool
└── Remark: string(200)

枚举:
  CountPlanType:
    FullCount=1(全面盘点), CycleCount=2(循环盘点), SpotCount=3(抽盘)
  ScheduleType:
    OneTime=1(一次性), Weekly=2(每周), Monthly=3(每月),
    Quarterly=4(每季), ABCBased=5(ABC频率驱动)
  CountPlanStatus:
    Active=1(生效), Paused=2(暂停), Completed=3(已完成)
```

## 四、循环盘点排程

### 4.1 ABC 频率驱动

```
循环盘点排程 (ABC驱动):

  A类物料 (高价值, ~20%): 每月盘点
  B类物料 (中价值, ~30%): 每季度盘点
  C类物料 (低价值, ~50%): 每半年盘点

  日历示例 (2024年Q1):
  ┌────────┬──────────────────────────────────────┐
  │  月份   │  盘点内容                              │
  ├────────┼──────────────────────────────────────┤
  │ 1月    │ A类全部 + B类(1/3) + C类(1/6)         │
  │ 2月    │ A类全部                                │
  │ 3月    │ A类全部 + B类(1/3)                     │
  └────────┴──────────────────────────────────────┘

  年覆盖率:
    A类: 12次/年 (月度)
    B类: 4次/年 (季度)
    C类: 2次/年 (半年度)
```

### 4.2 盘点覆盖率目标

```
盘点准确率 = 无差异项数 / 总盘点项数 × 100%

行业目标:
  A类物料: 准确率 ≥ 99%
  B类物料: 准确率 ≥ 97%
  C类物料: 准确率 ≥ 95%
  综合准确率: ≥ 97%
```

## 五、库存冻结机制

### 5.1 冻结范围

| 冻结范围 | 影响 | 使用场景 |
|---------|------|---------|
| 仓库级 | 整个仓库暂停出入库 | 全面盘点 |
| 库区级 | 该库区暂停出入库 | 区域盘点 |
| 库位级 | 该库位暂停出入库 | 抽盘 |
| 物料级 | 该物料在指定仓库暂停 | 精确控制 |

### 5.2 冻结规则

```
冻结期间允许的操作:
  ✅ 查询库存
  ✅ 盘点录入
  ✅ 查看报表

冻结期间禁止的操作:
  ❌ 入库确认
  ❌ 出库确认
  ❌ 调拨操作
  ❌ 库存调整 (非盘点)
  ❌ 库位变更

紧急放行:
  特殊情况下管理层可强制解冻部分物料
  需记录解冻原因和审批人
```

## 六、调整审批工作流

### 6.1 分级审批规则

```
审批层级 (按差异金额):

  Level 1: 差异金额 ≤ ¥500
    → 仓库主管审批 → 自动过账

  Level 2: ¥500 < 差异金额 ≤ ¥5,000
    → 仓库主管审批 → 仓储经理审批 → 过账

  Level 3: ¥5,000 < 差异金额 ≤ ¥50,000
    → 仓库主管 → 仓储经理 → 财务经理审批 → 过账

  Level 4: 差异金额 > ¥50,000
    → 仓库主管 → 仓储经理 → 财务经理 → 总经理审批 → 过账
```

## 十、业务规则

| 规则 | 描述 |
|------|------|
| 冻结期禁操作 | 冻结库存期间禁止该范围内的出入库操作 |
| 盲盘不显账面 | 盲盘模式下不向盘点人员显示账面数量 |
| 差异超限复盘 | 差异率超过阈值 (如5%) 必须进行复盘 |
| 复盘换人 | 第二轮复盘必须由不同人员执行 |
| 三轮封顶 | 最多三轮盘点，第三轮结果为最终结果 |
| A类月盘 | A类高价值物料至少每月循环盘点一次 |
| 分级审批 | 调整金额超过阈值需要更高级别审批 |
| 调整生成凭证 | 所有已审批调整必须生成财务凭证 |
| 报废必审批 | 报废处理无论金额大小都需要审批 |
| 盘点前截止 | 全面盘点前必须完成所有在途事务 |
| 过账不可逆 | 已过账的调整不可撤销，只能反向调整 |
| 准确率追踪 | 每次盘点必须计算并记录盘点准确率 |
| 差异追因 | 差异金额超过阈值的项目必须记录差异原因 |
