# 库存模块

库存模块是 ERP 系统的物流中枢，管理企业所有物料的存储、流转、追溯和计量。它连接采购（入库）、销售（出库）、生产（领料/完工）三大业务流，为 MRP 提供实时可用量数据，为财务提供存货变动和计价依据。
