# 入库管理

## 概述

入库管理处理所有增加库存的业务操作，包括采购入库、生产完工入库、销售退货入库、仓库调拨接收等。系统通过入库单统一管理各类入库事务，支持质量检验、上架推荐、条码扫描等功能，确保物料准确、高效地进入库存。

## 一、入库类型总览

| 入库类型 | 触发来源 | 来源单据 | 是否质检 | 财务影响 |
|---------|---------|---------|---------|---------|
| 采购入库 | PO 收货确认 | 采购订单/收货单 | 可配置 | 原材料增加，暂估/确认入账 |
| 完工入库 | WO 完工报告 | 生产工单 | 可配置 | 产成品增加，生产成本结转 |
| 销售退货入库 | 退货收货 | 销售退货单 | 必须 | 库存商品增加，收入冲回 |
| 调拨接收入库 | 调拨单发出 | 调拨单 | 否 | 仓库间转移 |
| 其他入库 | 手工创建 | - | 否 | 库存增加 |
| 期初入库 | 系统初始化 | - | 否 | 期初余额 |

## 三、核心实体

### 3.1 入库单

```
ReceiptOrder (入库单)
├── Id: Guid
├── TenantId: Guid
├── ReceiptNo: string(30)              # 编号 RO-{YYYYMMDD}-{SEQ}
├── ReceiptType: ReceiptType           # 入库类型
├── ReceiptDate: DateTime              # 入库日期
│
├── SourceDocumentType: string(20)     # 来源类型 (PO/WO/SalesReturn/TO)
├── SourceDocumentId: Guid?
├── SourceDocumentNo: string(50)?
│
├── WarehouseId: Guid                  # 目标仓库
├── SupplierId: Guid?                  # 供应商 (采购入库)
├── WorkOrderId: Guid?                 # 工单 (完工入库)
├── TransferOrderId: Guid?             # 调拨单 (调拨入库)
│
├── ExpectedDate: DateTime?            # 预计到货日
├── ActualDate: DateTime?              # 实际到货日
├── InspectionRequired: bool           # 是否需要质检
│
├── Status: ReceiptStatus
├── OperatorId: Guid                   # 收货员
├── ConfirmedBy: Guid?                 # 确认人
├── ConfirmedAt: DateTime?
├── VoucherId: Guid?                   # 关联财务凭证
├── Remark: string(500)
└── Lines: List<ReceiptOrderLine>

枚举:
  ReceiptType:
    PurchaseReceipt=1(采购入库), ProductionReceipt=2(完工入库),
    SalesReturnReceipt=3(销售退货入库), TransferReceipt=4(调拨入库),
    OtherReceipt=5(其他入库), InitialStock=6(期初入库)
  ReceiptStatus:
    Draft=0(草稿), Receiving=1(收货中), PendingInspection=2(待质检),
    Inspecting=3(质检中), PendingPutaway=4(待上架),
    PutawayInProgress=5(上架中), Completed=6(已完成),
    PartialCompleted=7(部分完成), Cancelled=8(已取消)
```

## 五、质检工作流

### 5.1 质检触发规则

| 条件 | 质检类型 | 说明 |
|------|---------|------|
| 新供应商首次到货 | 全检 | 首批必检 |
| 合格供应商常规到货 | 抽检 | 按 AQL 标准抽检 |
| 免检供应商 | 免检 | 历史合格率 > 99% |
| 关键物料 | 全检 | 无论供应商等级 |
| 退货入库 | 全检 | 确认退货品质 |
| 完工入库 | 可配置 | 按工艺要求 |

### 5.2 质检处置流程

```
质检结论
    │
    ├── 合格 (PassRate ≥ 合格线)
    │   └── Accept → 进入上架流程
    │
    ├── 条件接受 (有轻微缺陷但可接受)
    │   └── ConditionalAccept → 降级处理 → 进入上架流程
    │
    ├── 需挑选 (批次内有不合格品)
    │   └── Sort → 分离合格/不合格 → 合格品上架，不合格品处置
    │
    ├── 需返工
    │   └── Rework → 退回产线/供应商返工 → 重新质检
    │
    └── 不合格
        ├── Reject → 退回供应商 (采购入库)
        └── Scrap → 报废处理 → 生成报废凭证
```

## 六、入库成本计算

### 6.1 各类入库成本来源

| 入库类型 | 单位成本来源 | 说明 |
|---------|-------------|------|
| 采购入库 | PO 单价 (暂估) 或 发票单价 (确认) | 暂估入账后发票到账调整 |
| 完工入库 | 生产成本归集 ÷ 完工数量 | 料+工+费 |
| 销售退货 | 原出库成本 | 按原出库单价回冲 |
| 调拨入库 | 出库方成本 | 成本随物料转移 |
| 其他入库 | 手工输入 | 需审批确认 |
| 期初入库 | 手工输入 | 初始化成本 |

### 6.2 暂估入账

```
采购入库暂估流程:

① PO收货 → 按PO单价暂估入库
   借: 原材料          10,000
     贷: 应付账款-暂估    10,000

② 发票到达 → 实际金额 10,500
   冲回暂估:
   借: 应付账款-暂估    10,000
     贷: 原材料          10,000
   
   按发票金额入账:
   借: 原材料          10,500
     借: 应交税费-进项税  1,365
       贷: 应付账款        11,865
```

## 九、业务规则

| 规则 | 描述 |
|------|------|
| 实收不超预期 | 实收数量不得超过预期数量的 110% (可配置容差) |
| 质检必达 | 配置为必检的物料，未质检不可上架 |
| 批次强制 | 启用批次管理的物料必须录入批次号 |
| 序列号唯一 | 序列号管理物料每件必须有唯一序列号 |
| 保质期校验 | 入库时剩余保质期不得低于配置的最低百分比 |
| 存储类别匹配 | 上架库位的存储类别必须兼容物料要求 |
| 库位容量校验 | 上架不可超过库位的重量/体积限制 |
| 来源单据关联 | 采购/完工/退货入库必须关联来源单据 |
| 重复入库防止 | 同一来源单据行不可重复创建入库单行 |
| 确认不可逆 | 已确认的入库单不可修改，只能通过出库冲销 |
| 暂估自动化 | 采购入库无发票时自动按PO价暂估入账 |
| 事务原子性 | 入库确认、库存更新、财务凭证在同一事务内完成 |
