# 委外加工模块总览

## 模块定位

委外加工模块管理企业将部分生产工序外包给外部加工商的完整流程，涵盖委外工单管理、委外发料、委外验收、委外结算等环节。它作为生产模块的延伸，处理企业产能不足或特殊工艺需求时的外包业务，确保委外加工过程的可控性和成本透明度。

## 核心实体总览

| 实体 | 编码规则 | 说明 |
|------|---------|------|
| Subcontractor | SUB-{YYYYMM}-{SEQ} | 加工商主数据 |
| SubcontractOrder | SCO-{YYYYMMDD}-{SEQ} | 委外工单 |
| SubcontractIssue | SCI-{YYYYMMDD}-{SEQ} | 委外发料单 |
| SubcontractReceipt | SCR-{YYYYMMDD}-{SEQ} | 委外收货单 |
| SubcontractInvoice | SINV-{YYYYMMDD}-{SEQ} | 委外发票 |
| SubcontractQuality | SCQ-{YYYYMMDD}-{SEQ} | 委外质检单 |

## 业务流程概览

```
委外加工流程:

生产计划 → 委外工单创建 → 工单审批 → 委外发料 → 加工商生产 → 完工通知 → 委外验收 → 委外入库 → 委外结算

不合格处理流程:

验收不合格 → 返工通知 → 加工商返工 → 重新验收 → 合格入库
                             │
                             └→ 报废处理 → 物料报废 → 成本处理
```

## 与其他模块的集成

| 集成模块 | 数据流向 | 说明 |
|---------|---------|------|
| 生产 → 委外加工 | 生产工单 → 委外工单 | 生产计划转委外加工 |
| 委外加工 → 库存 | 委外发料 → 出库 | 发料时扣减库存 |
| 委外加工 → 库存 | 委外入库 → 入库 | 完工时增加库存 |
| 委外加工 → 财务 | 委外发票 → 应付账款 | 加工费生成应付 |
| 委外加工 → 质量 | 委外验收 → 质检 | 验收时触发质检流程 |
| 采购 → 委外加工 | 供应商 → 加工商 | 供应商可作为加工商 |
