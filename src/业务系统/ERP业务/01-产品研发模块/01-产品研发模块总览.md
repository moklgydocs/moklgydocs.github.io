# 产品研发模块总览

## 模块定位

产品研发模块管理企业从产品概念到量产的完整研发流程，涵盖产品管理、物料管理、BOM（物料清单）管理、ECN（工程变更通知）管理。它是企业创新和产品竞争力的核心，为生产、采购、销售模块提供基础数据支撑。

## 核心实体总览

| 实体 | 编码规则 | 说明 |
|------|---------|------|
| Product | PROD-{Category}-{SEQ} | 产品主数据 |
| Item | ITEM-{Category}-{SEQ} | 物料主数据 |
| BOM | BOM-{ProductCode}-V{N} | 物料清单 |
| ECN | ECN-{YYYYMMDD}-{SEQ} | 工程变更通知 |
| Document | DOC-{Type}-{SEQ} | 技术文档 |
| Project | PRJ-{YYYYMMDD}-{SEQ} | 研发项目 |
| Formula | FORM-{ProductCode}-V{N} | 产品配方 |

## 业务流程概览

```
产品研发流程:

市场调研 → 产品概念 → 产品设计 → BOM设计 → 工艺设计 → 样品试制 → 产品验证 → 量产准备

工程变更流程:

变更需求 → 变更申请(ECN) → 影响分析 → 变更评审 → 变更批准 → 变更执行 → 变更验证
```

## 与其他模块的集成

| 集成模块 | 数据流向 | 说明 |
|---------|---------|------|
| 产品研发 → 生产 | BOM/工艺路线 → 工单 | 提供生产所需的基础数据 |
| 产品研发 → 采购 | 物料/BOM → 采购需求 | 新物料和BOM变更触发采购需求 |
| 产品研发 → 销售 | 产品规格 → 销售报价 | 提供产品技术参数用于报价 |
| 产品研发 → 库存 | 物料主数据 → 库存管理 | 新物料需要在库存中建立档案 |
| 财务 → 产品研发 | 研发费用 → 品本归集 | 研发项目费用归集到产品成本 |
