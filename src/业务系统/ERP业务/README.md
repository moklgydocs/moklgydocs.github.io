# ERP业务系统

ERP（Enterprise Resource Planning，企业资源计划）系统是企业核心业务的数字化中枢，整合产品研发、采购、生产、委外加工、库存、销售、MRP、财务八大核心模块，实现业务流、物流、资金流的三流合一。
