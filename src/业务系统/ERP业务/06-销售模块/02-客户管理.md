# 客户管理

## 概述

客户管理是销售模块的基础，负责客户主数据的维护、客户分类分级、信用额度管理。准确的客户数据和有效的信用控制是销售业务顺畅运行的前提。

## 二、信用管理

### 2.1 信用额度

```
可用信用额度 = 信用额度 - 已用额度
已用额度 = 未清应收余额 + 已确认未发货订单金额 + 已发货未开票金额
```

### 2.2 信用检查时机

| 检查点 | 条件 | 动作 |
|--------|------|------|
| 创建销售订单 | 可用额度 < 订单金额 | 阻止创建/提交审批 |
| 订单审批 | 可用额度 < 订单金额 | 需信用经理审批 |
| 发货前 | 可用额度 < 0 | 阻止发货 |
| 逾期应收 | 逾期金额 > 阈值 | 自动冻结客户 |

### 2.3 信用等级调整规则

| 条件 | 动作 |
|------|------|
| 连续 6 个月无逾期 | 提升一级 |
| 单笔逾期超过 60 天 | 降低一级 |
| 单笔逾期超过 90 天 | 降至 D 级，冻结下单 |
| 发生坏账核销 | 降至 E 级（黑名单） |

## 三、客户分类与价格

| 客户等级 | 默认折扣 | 账期 | 信用额度上限 |
|---------|---------|------|------------|
| VIP | 5%-15% | 60天 | 500万 |
| 重要客户 | 3%-10% | 45天 | 200万 |
| 普通客户 | 0%-5% | 30天 | 50万 |
| 小型客户 | 0% | 预付/15天 | 10万 |

## 六、业务规则

| 规则 | 描述 |
|------|------|
| 编码唯一 | 客户编码全局唯一 |
| 税号唯一 | 同一租户内税号不可重复 |
| 冻结限制 | 冻结客户不可创建新订单和发货 |
| 信用实时 | 信用额度在订单和发货时实时计算 |
| 必填收货地址 | 创建订单前至少有一个收货地址 |
| 销售负责人 | 每个客户必须分配销售负责人 |
| 合并限制 | 客户有未清订单/应收时不可停用 |
