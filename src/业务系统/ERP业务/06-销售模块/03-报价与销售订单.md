# 报价与销售订单

## 概述

报价是销售流程的起点，销售订单是客户正式下单的凭证。报价单经客户确认后转化为销售订单，订单经审批和信用检查后进入执行阶段（备货→发货→开票）。

## 一、业务流程

### 1.1 报价到订单流程

```
客户询价 → 创建报价单(QT) → 报价审批 → 发送客户 → 客户反馈
                                                        │
                              ┌─────────────────────────┤
                              ▼                         ▼
                         客户接受                    协商修改
                              │                         │
                              ▼                         ▼
                         转为 SO                    修改报价重新发送
                              │
                              ▼
                    SO 审批 → 信用检查 → 执行
```

### 1.2 销售订单状态机

```
┌────────┐    ┌──────────┐    ┌──────────┐    ┌───────────┐
│ Draft   │───▶│ Submitted │───▶│ Approved  │───▶│ Processing│
│ 草稿    │    │ 已提交    │    │ 已审批    │    │ 执行中     │
└────────┘    └──────────┘    └──────────┘    └─────┬─────┘
    ▲              │                                 │
    │              ▼                      ┌──────────┼──────────┐
    │         ┌──────────┐               ▼          ▼          ▼
    └─────────│ Rejected  │        ┌──────────┐ ┌────────┐ ┌────────┐
              │ 已驳回    │        │PartShipped│ │ Shipped│ │Cancelled│
              └──────────┘        │ 部分发货  │ │ 已发货  │ │ 已取消  │
                                  └──────────┘ └────┬───┘ └────────┘
                                                    │
                                                    ▼
                                               ┌────────┐
                                               │ Closed │
                                               │ 已关闭  │
                                               └────────┘
```

## 二、核心实体

### 2.1 报价单

```
Quotation (报价单)
├── Id: Guid
├── TenantId: Guid
├── QuotationNo: string(30)            # 报价单号 QT-{YYYYMMDD}-{SEQ}
├── CustomerId: Guid
├── CustomerName: string(200)
├── CustomerContactName: string(50)
├── QuotationDate: DateTime            # 报价日期
├── ValidUntil: DateTime               # 有效期至
├── SalesPersonId: Guid                # 销售员
│
├── CurrencyCode: string(3)
├── ExchangeRate: decimal(18,6)
├── SubTotal: decimal(18,2)
├── DiscountRate: decimal(5,2)?        # 整单折扣率
├── DiscountAmount: decimal(18,2)?
├── TaxAmount: decimal(18,2)
├── TotalAmount: decimal(18,2)
│
├── PaymentTermDays: int               # 付款条件
├── DeliveryTerms: string(100)?        # 交货条件
├── Remark: string(1000)               # 备注/条款
│
├── Status: QuotationStatus
├── ConvertedOrderId: Guid?            # 转为 SO 后的 ID
└── Lines: List<QuotationLine>

QuotationLine (报价行)
├── Id: Guid
├── QuotationId: Guid
├── LineNo: int
├── ItemId: Guid
├── ItemCode: string(50)
├── ItemName: string(200)
├── Specification: string(200)
├── UnitOfMeasure: string(20)
├── Quantity: decimal(18,4)
├── ListPrice: decimal(18,6)           # 目录价
├── UnitPrice: decimal(18,6)           # 报价（可能有折扣）
├── DiscountRate: decimal(5,2)?        # 行级折扣
├── Amount: decimal(18,2)
├── TaxRate: decimal(5,2)
├── DeliveryDate: DateTime?            # 预计交期
└── Remark: string(200)

枚举:
  QuotationStatus: Draft=0, Submitted=1, Approved=2, Sent=3, 
                   Accepted=4, Rejected=5, Expired=6, Converted=7
```

### 2.2 销售订单

```
SalesOrder (销售订单)
├── Id: Guid
├── TenantId: Guid
├── OrderNo: string(30)                # SO 编号
├── CustomerId: Guid
├── CustomerName: string(200)
├── CustomerContactName: string(50)
├── OrderDate: DateTime                # 订单日期
├── RequestedDeliveryDate: DateTime    # 客户要求交期
├── PromisedDeliveryDate: DateTime?    # 承诺交期
├── ShippingAddressId: Guid            # 收货地址
├── SalesPersonId: Guid                # 销售员
│
├── CurrencyCode: string(3)
├── ExchangeRate: decimal(18,6)
├── TaxRate: decimal(5,2)
├── SubTotal: decimal(18,2)
├── DiscountRate: decimal(5,2)?
├── DiscountAmount: decimal(18,2)?
├── TaxAmount: decimal(18,2)
├── TotalAmount: decimal(18,2)
│
├── PaymentTermDays: int
├── PaymentMethod: PaymentMethod
│
├── Status: SOStatus
├── ApprovalStatus: ApprovalStatus
├── CreditCheckPassed: bool?           # 信用检查结果
├── CreditCheckDate: DateTime?
│
├── QuotationId: Guid?                 # 关联报价单
├── Remark: string(500)
└── Lines: List<SOLine>

SOLine (销售订单行)
├── Id: Guid
├── OrderId: Guid
├── LineNo: int
├── ItemId: Guid
├── ItemCode: string(50)
├── ItemName: string(200)
├── Specification: string(200)
├── UnitOfMeasure: string(20)
├── Quantity: decimal(18,4)            # 订购数量
├── UnitPrice: decimal(18,6)          # 单价（不含税）
├── DiscountRate: decimal(5,2)?
├── Amount: decimal(18,2)
├── TaxRate: decimal(5,2)
├── TaxAmount: decimal(18,2)
├── TotalAmount: decimal(18,2)
├── ShippedQuantity: decimal(18,4)    # 已发货数量
├── InvoicedQuantity: decimal(18,4)   # 已开票数量
├── RequestedDeliveryDate: DateTime    # 行级交期
├── WarehouseId: Guid?                 # 发货仓库
├── QuotationLineId: Guid?
└── Remark: string(200)

枚举:
  SOStatus: Draft=0, Submitted=1, Approved=2, Processing=3,
            PartShipped=4, Shipped=5, Closed=6, Cancelled=-1
```

## 三、价格确定逻辑

```
定价优先级 (从高到低):
  ① 合同协议价 (客户特殊约定)
  ② 促销价格 (限时活动)
  ③ 阶梯价格 (按数量折扣)
  ④ 客户级别价目表 (VIP/Key等)
  ⑤ 标准价目表
```

## 六、业务规则

| 规则 | 描述 |
|------|------|
| 报价有效期 | 超过有效期的报价自动标记为 Expired |
| 信用检查 | 订单审批通过后必须通过信用检查才能执行 |
| 库存检查 | 发货前检查可用库存是否充足 |
| 价格审批 | 低于成本价的报价/订单需特别审批 |
| 部分发货 | 支持多次发货，跟踪每行已发数量 |
| 已审批不可改 | Approved 以后状态需取消后重建 |
| 订单关闭条件 | 全部发货且全部开票后可关闭 |
| 超发限制 | 发货数量不得超过订单数量 |
