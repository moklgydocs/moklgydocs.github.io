# 销售模块

销售模块管理企业从客户接触到回款的完整销售流程，涵盖客户管理、报价、销售订单、发货、开票和回款。它是企业营收的核心驱动模块，与财务（应收账款）、库存（出库）、生产（按单生产）模块紧密集成。
