# 操作系统

> 进程调度、内存管理、文件系统、经典 PV 问题——操作系统的全貌。

## 原著参考

| 原著 | 作者 | 说明 |
|------|------|------|
| 《图解操作系统》 | 小林coding | 面试导向，图解核心概念，覆盖进程/内存/文件系统 |
| 《操作系统》 | 王道考研 | 考研体系完整，知识点严谨，适合系统学习 |
| 《深入理解计算机系统》（CSAPP） | Randal E. Bryant | 从程序员视角理解系统，连接底层与工程实践的经典 |

> 本章以小林coding的图解为骨架串联核心概念，以王道考研的体系确保知识完整性，以 CSAPP 的视角深化底层理解。
