# 汇编语言

> 基于 Linux 环境的 x86 汇编，从指令到系统调用，理解程序的本质。

## 原著参考

| 原著 | 作者 | 说明 |
|------|------|------|
| 《汇编语言：基于Linux环境（第3版）》 | Jeff Duntemann | 从零开始的 x86 汇编教程，以 Linux 为平台，注重概念理解而非死记指令 |

> 本书以"理解计算机如何工作"为出发点，不追求汇编的工程实用性，而是帮你建立对 CPU、内存、指令的直觉认知。搭配 GDB 调试器和 NASM 汇编器实战。
