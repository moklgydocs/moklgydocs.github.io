> 如果把计算机比作一个只会"0"和"1"的世界，那么"数据的表示与运算"就是这个世界的基本语法——它规定了现实世界中的数字、文字如何被翻译成 0 和 1，以及这些 0 和 1 如何进行加、减、乘、除的运算。

## 📖 章节导览
