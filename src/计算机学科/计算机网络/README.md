| 原著 | 作者 | 说明 |
|------|------|------|
| 《图解网络》 | 小林coding | 面试导向，500+ 张图解，覆盖 HTTP/TCP/IP 核心知识点 |
| 《TCP/IP网络编程》 | 尹圣雨 | 网络编程经典，C 语言从 Socket 到 epoll 全链路实战 |
