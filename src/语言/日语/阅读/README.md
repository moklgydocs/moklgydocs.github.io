## 使用说明

1. 默认显示汉字表层形 + 声调核圈号
2. 悬停（桌面）/ 点击（移动端）词块 → 弹出假名读法 + 高低调折线
3. 高调拍显示为主题色，低调拍为灰色
4. 句末"显示译文"按钮切换中文

## 声调标注说明

声调核位置数字含义：⓪平板型 / ①頭高型 / ②以上中高·尾高型。助词已并入前一词作为一个声调短语标注，与 OJAD 一致。标注参考 [OJAD](http://www.gavo.t.u-tokyo.ac.jp/ojad/)（東京語アクセント）。

## 学习建议

1. **先尝试不看译文通读**——遇到不认识的词悬停查看假名和释义
2. **留意声调折线**——高调拍和低调拍的落差是日语语调的核心
3. **跟读模仿**——虽然页面没有音频，但可以按折线提示的高低节奏自己读
4. **对照语法点**——句子里的语法点大多在[核心语法](../语法/04-核心语法.html)里有讲解，遇到不懂可回查
