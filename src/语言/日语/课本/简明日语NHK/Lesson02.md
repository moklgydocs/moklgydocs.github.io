# 第2课　これは何ですか

## 语法要点

### ① これ は 何です か（这是什么？）

- 「か」是助词。
- 放在句尾，用升调来读，就变成了疑问句。

例如：それは何ですか。（那是什么？）

### ② 名词A の 名词B

- 「の」是连接名词和名词的助词，在日语里，修饰语放在名词前面。

例如：<ruby>東京<rt>とうきょう</rt></ruby>のお<ruby>土産<rt>みやげ</rt></ruby>（东京的礼物）

## 声临其境

**すたすた**

- 形容走得很快的样子。

**のろのろ**

- 形容人或物缓慢移动的样子。
