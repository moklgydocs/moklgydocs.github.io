# 简明日语NHK（2015 版）

《简明日语》是 NHK WORLD RADIO JAPAN 用 18 种语言播出的日语讲座的 2015 年版本，共 48 课。讲座讲述了留学生安娜的故事，可通过音频、文字教材和插画，学习基本语法和实用语句。

**每课均配有音频**（点击课内播放器收听，也可配合本站学习）。

## 剧中人物

- **安娜**（アンナ）—— 来自海外的留学生，本剧主人公
- **小樱**（さくら）—— 安娜的朋友
- **罗德里戈**（ロドリゴ）—— 留学生
- **铃木教授**（鈴木教授）—— 安娜的老师
- **舍监**（寮母）—— 宿舍管理员
- **健太**（健太）—— 安娜的朋友

## 每课结构

- **会话** —— 短剧会话（日语带振假名 / 罗马音 / 中文对照）
- **语法要点** —— 导师点津：每课的学习要点
- **声临其境** —— 日语的拟声拟态词
- 另设**假名表**（参见本站[五十音图](../../五十音图.html)）、**单词表与小测验**（见附录）
