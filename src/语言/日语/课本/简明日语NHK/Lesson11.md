## 语法要点

### ① 星期

| 日语 | 中文 |
| --- | --- |
| 月曜日（げつようび） | 星期一 |
| 火曜日（かようび） | 星期二 |
| 水曜日（すいようび） | 星期三 |
| 木曜日（もくようび） | 星期四 |
| 金曜日（きんようび） | 星期五 |
| 土曜日（どようび） | 星期六 |
| 日曜日（にちようび） | 星期日 |

### ② 辞书形动词

> 动词：参见原书第54页、第55页

- 动词在日语辞典里以这个形式出现。
- 使用辞书形动词可以给人以更轻松的印象。

例如：行きます（去）⇒ 行く<br>
　　　<ruby>食<rt>た</rt></ruby>べます（吃）⇒ 食べる

## 声临其境

**わくわく**

- 形容因为期待或喜悦而兴奋紧张的样子。

**うきうき**

- 形容心情激动无法平静的样子。
