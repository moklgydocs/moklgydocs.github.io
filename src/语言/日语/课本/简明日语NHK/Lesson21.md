## 语法要点

### ① ナイ形动词

- 以「ない」结尾的动词，叫做"ナイ形"。
- ナイ形表示轻松语气的否定。

| マス形 | ナイ形 |
| --- | --- |
| <ruby>食<rt>た</rt></ruby>べます（吃） | <ruby>食<rt>た</rt></ruby>べない（不吃） |
| <ruby>起<rt>お</rt></ruby>きます（起来） | <ruby>起<rt>お</rt></ruby>きない（不起来） |
| <ruby>行<rt>い</rt></ruby>きます（去） | <ruby>行<rt>い</rt></ruby>かない（不去） |
| <ruby>使<rt>つか</rt></ruby>います（用） | <ruby>使<rt>つか</rt></ruby>わない（不用） |
| <ruby>来<rt>き</rt></ruby>ます（来） | <ruby>来<rt>こ</rt></ruby>ない（不来） |

> 动词：参见原书第54页、第55页

### ② いいえ、それほどでも（哪里，没那么……）

- 「いいえ」是否定的应答用语，「それほどでも」的意思是"没那么……"。
- 「いいえ、それほどでも」是表示谦虚的说法。
