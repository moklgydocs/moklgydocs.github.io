# 简明日语（NHK 2019 版）

《简明日语》是 NHK（日本广播协会）对外播出平台 NHK 日本国际传媒制作的日语讲座，共 48 课。通过生动有趣的短剧会话，学习自我介绍、购物等简单实用的日常用语，同时获取丰富的日本旅游信息，了解日本的文化和礼仪。

本讲座依照国际交流基金开发的《JF 日语教育标准》，对应 **A1～A2** 级别（与 CEFR 分级相同）。

## 剧情简介

位于东京的共享公寓"春奶奶之家"。这里居住着来自不同国家、富于个性的人们，他们的共同语言是日语。为房客们排忧解难的房东居然是个机器人！来自越南的留学生心心也成为这里的一员。短剧讲述心心和她的新朋友们一起探访日本、学习日语、追求梦想的故事。

**剧中人物**：阮美心（心心，越南留学生）、米亚（中国摄影师）、岩元海斗（日本大学生）、迈克·哈德森（美国研究生）、本田绫香（心心的朋友）、星悠辉（日本钢琴家）、春奶奶（AI 机器人房东）。

## 每课结构

- **今日短剧** —— 短剧会话（日语 / 罗马音 / 中文对照）
- **单词和语句** —— 本课单词表
- **重点语句** —— Can-do 目标句型的语法讲解
- **说说看！** —— 句型会话应用实例
- **试试看！** —— 造句练习（附答案）
- **常用语句 / 进阶** —— 寒暄语、数字、星期等有用表达
- **拓展阅读** —— 与课程相关的旅游、文化、美食、礼仪等趣味信息
