# 日语课本

收录两套 NHK《简明日语》官方免费教材的完整数字化版本，均为 48 课、对应 JFS A1～A2 级别，适合零基础入门。

## 收录教材

### [简明日语NHK（2015 版）](简明日语NHK/)

NHK WORLD RADIO JAPAN 2015 年播出的版本，讲述留学生安娜在日本的学习生活。

- 48 课会话，带振假名标注、罗马音、中文对照
- **每课配有原版音频**（约 10 分钟/课）
- 语法要点（导师点津）+ 声临其境（拟声拟态词）
- 附形容词/动词活用表、量词表

### [简明日语（NHK 2019 版）](简明日语/)

NHK 日本国际传媒 2019 年新版，讲述越南留学生心心在共享公寓"春奶奶之家"的故事。

- 48 课短剧会话（日语 / 罗马音 / 中文对照）
- 重点语句语法讲解、说说看！、试试看！（附答案）
- 每课 3 页：短剧 + 语法 + 旅游文化拓展
- 常用语句 / 进阶表达（数字、星期、寒暄语等）

## 学习建议

1. 两版内容互补：2015 版侧重语法体系与音频输入，2019 版侧重实用表达与文化信息。
2. 先学[五十音图](../五十音图.html)，再按课序推进；每课先听音频盲听，再对照文本精读。
3. 配合本站[日语语法](../语法/)与[新标日单词](../00.新标日初级(二)单词.html)同步积累。
