# 复合动词与补助动词

日语动词可以通过组合表达更丰富的含义。复合动词和补助动词是中级语法的重点，掌握它们能让表达更地道。

## 复合动词

**复合动词** = 动词1（ます形词干）+ 动词2，两个动词组合产生新含义。

### 常见复合动词

| 复合动词 | 构成 | 含义 | 示例 |
| --- | --- | --- | --- |
| **〜始める** | Vます + 始める | 开始做... | 食べ始める（开始吃） |
| **〜出す** | Vます + 出す | 开始/涌出 | 泣き出す（哭起来） |
| **〜続ける** | Vます + 続ける | 持续做... | 走り続ける（持续走） |
| **〜終わる** | Vます + 終わる | 做完... | 読み終わる（读完） |
| **〜過ぎる** | Vます + 過ぎる | 过度... | 食べ過ぎる（吃太多） |
| **〜直す** | Vます + 直す | 重新做... | 書き直す（重写） |
| **〜返す** | Vます + 返す | 反复/回 | 思い返す（回想） |
| **〜込む** | Vます + 込む | 进入/深入 | 入り込む（进入深处） |
| **〜上げる** | Vます + 上げる | 向上/完成 | 作り上げる（制作完成） |
| **〜上げる** | Vます + 上げる | 彻底完成 | 書き上げる（写完） |
| **〜下げる** | Vます + 下げる | 向下 | 見下げる（俯视） |
| **〜付く** | Vます + 付く | 附带 | 言い付く（嘱咐） |
| **〜切る** | Vます + 切る | 彻底/切断 | 読み切る（读完）、分かり切る（完全明白） |
| **〜切れない** | Vます + 切れない | 无法穷尽 | 数え切れない（数不清） |
| **〜抜く** | Vます + 抜く | 贯穿/坚持到底 | やり抜く（坚持做完） |
| **〜通す** | Vます + 通す | 贯穿到底 | 言い通す（坚持说） |
| **〜合う** | Vます + 合う | 互相... | 話し合う（互相讨论） |
| **〜かける** | Vます + かける | 开始/未完成 | 食べかける（开始吃/没吃完） |
| **〜慣れる** | Vます + 慣れる | 习惯于... | 使い慣れる（用习惯） |
| **〜忘れる** | Vます + 忘れる | 忘记做... | 書き忘れる（忘记写） |
| **〜得る** | Vます + 得る | 能够... | あり得る（可能有） |

### 按功能分类

#### 1. 表示开始/结束

| 复合动词 | 含义 | 示例 |
| --- | --- | --- |
| 〜始める | 开始 | 雨が降り**始めた**（开始下雨了） |
| 〜出す | 突然开始 | 突然泣き**出した**（突然哭起来） |
| 〜終わる | 结束 | 宿題をやり**終わった**（写完作业了） |
| 〜上がる | 完成 | 踊りが終わり**上がった**（舞蹈结束了） |

::: tip 始める vs 出す
- **始める**：平稳开始（雨が降り始める）
- **出す**：突然、意外地开始（突然降り出した）
:::

#### 2. 表示持续/反复

| 复合动词 | 含义 | 示例 |
| --- | --- | --- |
| 〜続ける | 持续 | 3時間歩き**続けた**（持续走了3小时） |
| 〜通す | 贯穿到底 | 一晩中話し**通した**（聊了一整夜） |
| 〜抜く | 坚持到底 | 最後までやり**抜いた**（坚持到最后） |

#### 3. 表示程度

| 复合动词 | 含义 | 示例 |
| --- | --- | --- |
| 〜過ぎる | 过度 | 食べ**過ぎて**腹が痛い（吃太多肚子疼） |
| 〜切る | 彻底 | 信じ**切る**（深信不疑） |
| 〜切れない | 无法穷尽 | 数え**切れない**星（数不清的星星） |

#### 4. 表示互相

| 复合动词 | 含义 | 示例 |
| --- | --- | --- |
| 〜合う | 互相 | 助け**合う**（互相帮助） |
|  |  | 話し**合う**（讨论） |
|  |  | 愛し**合う**（相爱） |

#### 5. 表示重新/修正

| 复合动词 | 含义 | 示例 |
| --- | --- | --- |
| 〜直す | 重做 | 書き**直す**（重写） |
|  |  | 考え**直す**（重新考虑） |
|  |  | やり**直す**（重做） |

#### 6. 表示未完成

| 复合动词 | 含义 | 示例 |
| --- | --- | --- |
| 〜かける | 没做完 | 食べ**かけ**のパン（吃了一半的面包） |
|  |  | 読み**かけた**が、やめた（读了开头但放弃了） |

### 复合动词的注意事项

::: warning 不是所有动词都能复合
- ✗ 食べ始める ✓（他动词 + 始める）
- ✗ 降り始める ✓（自动词 + 始める）
- 但部分动词组合不自然，需查词典确认
:::

::: tip 〜切る vs 〜抜く
- **読み切る**：读完（强调完成）
- **読み抜く**：坚持读完（强调克服困难）
:::

## 补助动词

**补助动词**：失去独立意义，附在て形/ます形后增添语法功能的动词。

### て形 + 补助动词

这是最重要的补助动词用法。

#### 1. 〜ている（正在进行/状态）

| 用法 | 示例 | 翻译 |
| --- | --- | --- |
| 动作进行 | 食べて**いる** | 正在吃 |
| 结果状态 | 死んで**いる** | 死了（状态） |
| 习惯 | 毎日走って**いる** | 每天跑步 |
| 经验 | 結婚して**いる** | 已婚 |

::: tip ている 的口语缩略
口语中常省略「い」：
- 食べてる（食べている）
- 読んでる（読んでいる）
:::

#### 2. 〜てある（结果状态）

**他动词 + てある**：表示某人做了某事后留下的状态。

- 窓が開けて**ある**（窗户开着 —— 有人开的）
- 字が書いて**ある**（写着字）
- 部屋が片付けて**ある**（房间收拾好了）

::: tip ている vs てある
- **窓が開いている**：窗户开着（客观状态，可能是风吹的）
- **窓が開けてある**：窗户开着（有人故意开的）
:::

#### 3. 〜ておく（预先/放任）

| 用法 | 示例 | 翻译 |
| --- | --- | --- |
| 预先做 | 電話して**おく** | 提前打电话 |
| 放任不管 | そのままにして**おく** | 就那样放着 |
| 事后处理 | メモして**おく** | 记下来（备用） |

口语缩略：ておく → とく
- 電話し**とく**（電話しておく）
- 見**とく**（見ておく）

#### 4. 〜てみる（尝试）

- 食べて**みる**（尝尝看）
- やって**みる**（试试做）
- 読んで**みて**ください（请读读看）

#### 5. 〜てしまう（完成/遗憾）

| 用法 | 示例 | 翻译 |
| --- | --- | --- |
| 彻底完成 | 宿題をやって**しまった** | 作业做完了 |
| 遗憾/不小心 | 落として**しまった** | 不小心掉了 |
| 无可挽回 | 遅刻して**しまった** | 迟到了（遗憾） |

口语缩略：てしまう → ちゃう / てしまう → ちまう
- 食べ**ちゃう**（食べてしまう）
- 忘れ**ちゃった**（忘れてしまった）

#### 6. 〜てくる / 〜ていく（趋势/方向）

| 形式 | 含义 | 示例 |
| --- | --- | --- |
| 〜てくる | 向说话人方向/到现在为止 | 走って**きた**（跑过来了） |
|  | 状态变化出现 | 寒くなって**きた**（变冷了） |
|  | 持续到现在 | ずっと勉強して**きた**（一直学到现-在） |
| 〜ていく | 离开说话人/今后继续 | 走って**いった**（跑过去了） |
|  | 状态变化持续 | これも寒くなって**いく**（今后会继续变冷） |
|  | 持续到未来 | これも勉強して**いく**（今后继续学） |

::: tip てくる vs ていく
- **てくる**：变化发生到现在（到现在为止）
- **ていく**：变化从现在持续到未来（今后）
- 寒くなって**きた**（已经变冷了）
- これから寒くなって**いく**（今后会变冷）
:::

#### 7. 〜てくれる / 〜てもらう / 〜てあげる（授受）

| 形式 | 谁做 | 谁受益 | 示例 |
| --- | --- | --- | --- |
| 〜てあげる | 我/己方 | 对方 | 本を貸して**あげる**（我借书给你） |
| 〜てくれる | 对方 | 我 | 田中さんが教えて**くれる**（田中教我） |
| 〜てもらう | 对方 | 我（主动请求） | 田中さんに教えて**もらう**（请田中教我） |

敬体：
- 〜て**さしあげる**（谦让：给对方）
- 〜て**くださる**（尊敬：对方给我）
- 〜て**いただく**（谦让：我接受对方）

::: warning てあげる 的注意
对长辈或上级用「てあげる」显得不礼貌（有施恩意味），应改用：
- お/ご + ます形 + する（谦让语）
- 或避免直接表达「我为你做」
:::

#### 8. 〜てほしい（希望对方做）

- 来て**ほしい**（希望你来）
- 手伝って**ほしい**（希望你帮忙）
- 早く来て**ほしい**（希望你早点来）

#### 9. 〜ても（让步）

- 食べ**ても**いい（可以吃）
- 行か**なくても**いい（不去也行）
- いくら読ん**でも**分からない（怎么读都不懂）

#### 10. 〜て済む / 〜て済ませる（解决）

- 謝って**済む**問題だ（道个歉就能解决的问题）
- 金で**済ませる**（用钱解决）

### ます形 + 补助动词

| 形式 | 含义 | 示例 |
| --- | --- | --- |
| Vます + たい | 想做 | 食べ**たい** |
| Vます + たがる | 想做（第三人称） | 田中さんは食べ**たがる** |
| Vます + そうだ（样态） | 看起来要... | 雨が降り**そうだ** |
| Vます + ながら | 一边...一边 | 食べ**ながら**話す |
| Vます + つもり | 打算 | 行く**つもり**だ |
| Vます + 予定 | 预定 | 3時に着く**予定**だ |
| Vます + ことができる | 能够 | 食べる**ことができる** |

## 小结

| 要点 | 说明 |
| --- | --- |
| 复合动词 | Vます + V2，产生新含义 |
| 补助动词 | て形/ます形 + 辅助动词，增添语法功能 |
| ている | 进行/状态/习惯/经验 |
| てある | 他动词结果的存续 |
| ておく | 预先/放任 |
| てしまう | 完成/遗憾 |
| てくる/ていく | 时间方向趋势 |
| てあげる/くれる/もらう | 授受关系 |

掌握复合动词和补助动词是日语从初级迈向中级的关键，建议结合[动词变形](动词变形.html)反复练习。
