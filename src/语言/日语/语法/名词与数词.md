# 名词分类与数词表达

日语名词没有性别、格的变化，但数量表达体系独特而复杂——不同类别的物品使用不同的量词（助数词），这是学习难点。

## 名词的特征

### 1. 无性别、无单复数

日语名词不区分阴阳性，也不通过词形变化表示单复数：

| 中文 | 日语 |
| --- | --- |
| 一本书 | 本 |
| 三本书 | 本（三冊） |
| 男人/女人 | 男 / 女 |

表示复数可用**复数后缀**：

| 后缀 | 用途 | 示例 |
| --- | --- | --- |
| たち | 人（通用） | 私たち（我们）、子供たち（孩子们） |
| がた | 人（敬语） | 先生方（老师们）、あなたがた（您们） |
| ら | 人（随意） | 彼ら（他们）、僕ら（我们） |
| 達（たち） | 人/动物 | 鳥たち（鸟儿们） |

### 2. 无冠词

日语没有相当于「a/the」的冠词，通过上下文或指示词区分：

| 指示词 | 读音 | 指代 |
| --- | --- | --- |
| これ | これ | 这个（近） |
| それ | それ | 那个（中） |
| あれ | あれ | 那个（远） |
| どれ | どれ | 哪个 |

### 3. 指示代词体系

日语指示代词按「こそあど」四段体系组织：

| 距离 | こ（近） | そ（中） | あ（远） | ど（疑问） |
| --- | --- | --- | --- | --- |
| **事物** | これ | それ | あれ | どれ |
| **场所** | ここ | そこ | あそこ | どこ |
| **方向** | こちら | そちら | あちら | どちら |
| **修饰** | この | その | あの | どの |
| **方式** | こう | そう | ああ | どう |
| **程度** | こんな | そんな | あんな | どんな |

::: tip こそあど 记忆
- **こ**系：说话人身边（这）
- **そ**系：听话人身边（那）
- **あ**系：远离双方（那）
- **ど**系：疑问（哪）
:::

## 名词的分类

### 按来源分类

| 类别 | 特征 | 示例 |
| --- | --- | --- |
| **和语词** | 日本固有词 | 山、川、木、水 |
| **汉语词** | 中文借词 | 学校、先生、電話 |
| **外来语** | 西方借词（片假名） | パン、テレビ、コンピュータ |
| **混种词** | 混合来源 | 夕方（和+汉）、鉛筆（汉） |

### 按性质分类

| 类别 | 说明 | 示例 |
| --- | --- | --- |
| **普通名词** | 同类事物通称 | 本、人、学校 |
| **专有名词** | 特定事物名称 | 東京、田中、日本 |
| **代名词** | 替代名词 | 私、これ、それ |
| **形式名词** | 只起语法作用 | の、こと、もの、ところ |

### 形式名词详解

形式名词本身意义虚化，需接修饰语：

| 形式名词 | 用法 | 示例 |
| --- | --- | --- |
| **の** | 名词化、所属 | 食べる**の**が好き（喜欢吃） |
| **こと** | 抽象事态 | 日本へ行った**こと**がある（去过日本） |
| **もの** | 具体事物/人 | 高い**もの**だ（真贵啊） |
| **ところ** | 时间/场所 | 今勉強している**ところ**です（正在学） |
| **つもり** | 打算 | 行く**つもり**だ（打算去） |
| **はず** | 应该 | もう着いている**はず**だ（应该到了） |

## 数词

### 基数词

日语数字有两套读法——**音读**（汉语音）和**训读**（日本固有读法）：

| 数字 | 音读 | 训读 |
| --- | --- | --- |
| 1 | いち | ひと（つ） |
| 2 | に | ふた（つ） |
| 3 | さん | みっ（つ） |
| 4 | し / よん | よっ（つ） |
| 5 | ご | いつ（つ） |
| 6 | ろく | むっ（つ） |
| 7 | しち / なな | なな（つ） |
| 8 | はち | やっ（つ） |
| 9 | きゅう / く | ここの（つ） |
| 10 | じゅう | とお |

::: tip 4 和 7 的两种读法
- **4**：し（音读，但避讳死）/ よん（更常用）
- **7**：しち（音读）/ なな（更常用）

实际使用中**よん**和**なな**更普遍。
:::

### 序数词

| 表达 | 示例 |
| --- | --- |
| 第 + 数字 | 第一（だいいち）、第二（だいに） |
| 数字 + 番目 | 一番目（いちばんめ）、二番目（にばんめ） |
| 数字 + 号 | 1号（いちごう）、3号線 |

### 大数字

| 单位 | 读法 | 数值 |
| --- | --- | --- |
| 百 | ひゃく | 100 |
| 千 | せん | 1,000 |
| 万 | まん | 10,000 |
| 億 | おく | 100,000,000 |
| 兆 | ちょう | 1,000,000,000,000 |

::: warning 百/千的特殊读音
- 300：**さんびゃく**（不是 さんひゃく）
- 600：**ろっぴゃく**（不是 ろくひゃく）
- 800：**はっぴゃく**（不是 はちひゃく）
- 3000：**さんぜん**（不是 さんせん）
- 8000：**はっせん**（不是 はちせん）
:::

## 助数词（量词）

日语的量词系统比中文更细致——不同类别的物品用不同的助数词。

### 常用助数词

| 助数词 | 读法 | 用途 | 示例 |
| --- | --- | --- | --- |
| **個** | こ | 通用（小物品） | りんご3個 |
| **つ** | つ | 通用（1-9） | 1つ、2つ |
| **人** | にん | 人 | 学生3人 |
| **名** | めい | 人（正式） | ご来場50名 |
| **匹** | ひき | 小动物 | 犬2匹 |
| **頭** | とう | 大动物 | 牛10頭 |
| **羽** | わ | 鸟、兔 | 鳥3羽 |
| **尾** | び | 鱼 | 魚5尾 |
| **冊** | さつ | 书、笔记本 | 本3冊 |
| **枚** | まい | 薄平物（纸、衣） | 紙5枚、シャツ2枚 |
| **本** | ほん | 细长物 | 鉛筆3本、瓶1本 |
| **台** | だい | 机械、车辆 | 車2台、テレビ1台 |
| **軒** | けん | 房屋 | 家5軒 |
| **階** | かい | 楼层 | 3階 |
| **番** | ばん | 顺序 | 1番、3番 |
| **回** | かい | 次数 | 3回 |
| **度** | ど | 次数/温度 | 1度、36度 |
| **時間** | じかん | 小时（时长） | 3時間 |
| **時間** | じ | 点钟（时刻） | 3時 |
| **分** | ふん | 分钟 | 30分 |
| **秒** | びょう | 秒 | 10秒 |
| **日** | にち | 日（1-31日） | 3日 |
| **ヶ月** | かげつ | 个月 | 3ヶ月 |
| **年** | ねん | 年 | 3年 |
| **歳** | さい | 岁 | 20歳 |
| **杯** | はい | 杯、碗 | ビール2杯 |
| **着** | ちゃく | 衣服 | 3着 |
| **足** | そく | 鞋袜 | 靴2足 |
| **組** | くみ | 套、组 | 1組 |
| **セット** | せっと | 套（外来语） | 1セット |

### 助数词的读音变化

助数词前的数字会发生音变（促音化/浊音化）：

#### 本（ほん）的音变

| 数字 + 本 | 读音 | 变化 |
| --- | --- | --- |
| 1本 | いっぽん | 促音 + 半浊音 |
| 2本 | にほん | 无变化 |
| 3本 | さんぼん | 浊音化 |
| 4本 | よんほん | 无变化 |
| 5本 | ごほん | 无变化 |
| 6本 | ろっぽん | 促音 + 半浊音 |
| 7本 | ななほん | 无变化 |
| 8本 | はっぽん | 促音 + 半浊音 |
| 9本 | きゅうほん | 无变化 |
| 10本 | じゅっぽん | 促音 + 半浊音 |

#### 匹（ひき）的音变

| 数字 + 匹 | 读音 |
| --- | --- |
| 1匹 | いっぴき |
| 2匹 | にひき |
| 3匹 | さんびき |
| 6匹 | ろっぴき |
| 8匹 | はっぴき |
| 10匹 | じゅっぴき |

#### 階（かい）的音变

| 数字 + 階 | 读音 |
| --- | --- |
| 1階 | いっかい |
| 3階 | さんがい |
| 6階 | ろっかい |
| 8階 | はっかい |
| 10階 | じゅっかい |

::: tip 音变规律
- **1、6、8、10** 后常促音化（っ）
- **3** 后常浊音化（は→ば、は→ぱ）
- 用「よん」「なな」代替「し」「しち」避免歧义
:::

### つ 系列通用量词

1-9 可用「つ」通用计数，10 用「とお」：

| 数量 | 读音 | 数量 | 读音 |
| --- | --- | --- | --- |
| 1つ | ひとつ | 6つ | むっつ |
| 2つ | ふたつ | 7つ | ななつ |
| 3つ | みっつ | 8つ | やっつ |
| 4つ | よっつ | 9つ | ここのつ |
| 5つ | いつつ | 10 | とお |

::: warning つ 的限制
- 只能用于 1-9，10 用とお
- 不用于人、动物、机械
- 常用于抽象事物（年齢、顺序）
:::

## 数量表达句型

### 1. 名词 + 数量 + 助词

数量词放在名词后、动词前：

- りんごを**3個**食べた（吃了3个苹果）
- 学生が**5人**来た（来了5个学生）
- 本を**2冊**買った（买了2本书）

### 2. 数量词 + も（强调多/少）

- りんごを**3個も**食べた（竟然吃了3个苹果 —— 强调多）
- **1人も**来なかった（一个人都没来 —— 强调少）

### 3. 数量词 + で（合计）

- りんごを**3個で**300円です（3个苹果共300日元）
- **全部で**5冊あります（总共有5本）

### 4. 疑问数量

- りんごを**いくつ**買いましたか（买了几个苹果？）
- 学生が**何人**来ましたか（来了几个学生？）
- これは**いくら**ですか（这个多少钱？）

## 时刻与时间表达

### 时刻（钟点）

| 时刻 | 读法 | 时刻 | 读法 |
| --- | --- | --- | --- |
| 1時 | いちじ | 7時 | しちじ / ななじ |
| 2時 | にじ | 8時 | はちじ |
| 3時 | さんじ | 9時 | くじ |
| 4時 | よじ | 10時 | じゅうじ |
| 5時 | ごじ | 11時 | じゅういちじ |
| 6時 | ろくじ | 12時 | じゅうにじ |

**分钟**：半時（はん）= 30分

- 3時**半**（3点半）
- 3時**15分**（さんじじゅうごふん）

### 时间段

| 表达 | 读法 | 含义 |
| --- | --- | --- |
| 〜時間 | 〜じかん | ~小时（时长） |
| 〜分間 | 〜ふんかん | ~分钟（时长） |
| 〜日間 | 〜にちかん | ~天（时长） |
| 〜週間 | 〜しゅうかん | ~周（时长） |
| 〜ヶ月間 | 〜かげつかん | ~个月（时长） |
| 〜年間 | 〜ねんかん | ~年（时长） |

::: tip 时刻 vs 时长
- **3時**（さんじ）：3点（时刻）
- **3時間**（さんじかん）：3小时（时长）
- **3日**（みっか）：3号（日期）
- **3日間**（みっかかん）：3天（时长）
:::

## 实用句型

### 购物

| 句型 | 示例 |
| --- | --- |
| これはいくらですか | 这个多少钱？ |
| これを3つください | 请给我3个这个 |
| りんごを3個買いたい | 想买3个苹果 |
| 全部でいくらですか | 一共多少钱？ |

### 约时间

| 句型 | 示例 |
| --- | --- |
| 3時に会いましょう | 3点见吧 |
| 30分待ってください | 请等30分钟 |
| 3時間勉強した | 学习了3小时 |
| 週に3回ジムに行く | 每周去3次健身房 |

### 数量提问

| 疑问词 | 用途 | 示例 |
| --- | --- | --- |
| いくつ | 几个（1-9） | りんごはいくつありますか |
| 何個 | 几个（通用） | 何個買いましたか |
| 何人 | 几人 | 何人来ますか |
| 何時 | 几点 | 何時に起きますか |
| いくら | 多少钱 | いくらですか |

## 小结

| 要点 | 说明 |
| --- | --- |
| 名词特征 | 无性别、无单复数、无冠词 |
| こそあど | 近/中/远/疑四段体系 |
| 数词读法 | 音读 + 训读两套 |
| 助数词 | 按物品类别选量词（30+种） |
| 音变 | 1/6/8/10促音化，3浊音化 |
| 时刻 vs 时长 | 3時（点）/ 3時間（小时） |
| 日期 vs 时长 | 3日（号）/ 3日間（天） |

掌握数词表达是日语日常交流的基础，建议结合[基本句型](基本句型.html)和[助词详解](助词详解.html)反复练习。
