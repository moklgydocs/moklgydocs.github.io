# 敬语体系

敬语（けいご）是日语的重要特征，用于表达对他人或第三者的尊敬。日语敬语体系庞大但规则清晰，主要分三大类。

## 敬语三大类

| 类别 | 作用 | 对象 | 核心 |
| --- | --- | --- | --- |
| **尊敬语**（そんけいご） | 抬高对方动作 | 对方/第三者（上位） | 动词特殊变形 |
| **谦让语**（けんじょうご） | 贬低自己动作 | 自己/己方（下位） | 动词特殊变形 |
| **郑重语**（ていねいご） | 礼貌表达 | 听者 | です/ます |

::: tip 核心原则
- 对**对方的动作**用尊敬语（抬高对方）
- 对**自己的动作**用谦让语（贬低自己）
- 对**所有表达**加郑重语（礼貌语气）
:::

## 郑重语（ていねいご）

最基础的敬语，表示对听者的礼貌。

### 规则

| 词类 | 普通体 | 郑重语 |
| --- | --- | --- |
| 名词 | 学生だ | 学生**です** |
| い形容词 | 高い | 高い**です** |
| な形容词 | 静かだ | 静か**です** |
| 动词 | 書く | 書き**ます** |
| 否定 | 書かない | 書き**ません** |
| 过去 | 書いた | 書き**ました** |

### 更郑重的表达

在です/ます基础上，用「ござる」「存じる」等更郑重的词：

| 普通 | 郑重 | 更郑重 |
| --- | --- | --- |
| です | です | **でございます** |
| ある | あります | **ございます** |
| ない | ありません | **ございません** |
| だ | です | **でございます** |

示例：
- これは本**です** → これは本**でございます**
- 申し訳ありません → 申し訳**ございません**

## 尊敬语（そんけいご）

用于**对方或上位者的动作**，表示尊敬。

### 构成方式

| 方式 | 规则 | 示例 |
| --- | --- | --- |
| **特殊动词** | 用专门的尊敬动词 | いる→いらっしゃる |
| **お/ご + 动词ます形 + になる** | 规则变形 | 書く→お書きになる |
| **お/ご + 动词ます形 + です** | 规则变形 | 書く→お書きです |
| **れる/られる** | 受身形作尊敬 | 書く→書かれる |

### 常用尊敬动词

| 普通 | 尊敬语 | 中文 |
| --- | --- | --- |
| いる | **いらっしゃる** | 在 |
| 行く | **いらっしゃる / おいでになる** | 去 |
| 来る | **いらっしゃる / おいでになる / 見える** | 来 |
| する | **なさる** | 做 |
| 言う | **おっしゃる** | 说 |
| 食べる / 飲む | **召し上がる** | 吃/喝 |
| 見る | **ご覧になる** | 看 |
| 聞く | **お聞きになる** | 听/问 |
| 思う | **思し召す** | 想 |
| 知っている | **ご存知です** | 知道 |
| 着る | **お召しになる** | 穿 |

::: warning なさる 的变形
なさる、いらっしゃる、おっしゃる、くださる、ござる 这五个动词的ます形特殊：
- なさる → なさいます（不是 なさります）
- いらっしゃる → いらっしゃいます
- おっしゃる → おっしゃいます
- くださる → くださいます
- ござる → ございます
:::

### 规则变形示例

| 普通 | お～になる | お～です | れる/られる |
| --- | --- | --- | --- |
| 書く | お書きになる | お書きです | 書かれる |
| 読む | お読みになる | お読みです | 読まれる |
| 待つ | お待ちになる | お待ちです | 待たれる |
| 話す | お話しになる | お話しです | 話される |

### 尊敬语使用示例

- 先生が**いらっしゃいます**（老师在）
- 社長が**おっしゃいました**（社长说了）
- 田中先生はお茶を**召し上がります**（田中先生喝茶）
- 先生はこの本を**ご覧になりました**（老师看了这本书）
- 社長は明日東京へ**いらっしゃいます**（社长明天去东京）

## 谦让语（けんじょうご）

用于**自己或己方人员的动作**，通过贬低自己来抬高对方。

### 构成方式

| 方式 | 规则 | 示例 |
| --- | --- | --- |
| **特殊动词** | 用专门的谦让动词 | 言う→申し上げる |
| **お/ご + 动词ます形 + する** | 规则变形 | 書く→お書きする |
| **お/ご + 动词ます形 + 申し上げる** | 更谦让 | 書く→お書き申し上げる |

### 常用谦让动词

| 普通 | 谦让语 | 中文 |
| --- | --- | --- |
| 行く | **参る（まいる）** | 去 |
| 来る | **参る** | 来 |
| する | **致す（いたす）** | 做 |
| 言う | **申し上げる / 申す** | 说 |
| 食べる / 飲む | **頂く（いただく）** | 吃/喝 |
| 見る | **拝見する（はいけんする）** | 看 |
| 聞く | **伺う（うかがう） / 拝聴する** | 听/问 |
| 思う | **存じる（ぞんじる）** | 想 |
| 知っている | **存じ上げている** | 知道 |
| 会う | **お目にかかる** | 见面 |
| 借りる | **拝借する（はいしゃくする）** | 借 |
| もらう | **頂く（いただく） / 賜る** | 得到 |
| あげる | **差し上げる（さしあげる）** | 给 |

### 规则变形示例

| 普通 | お～する | お～申し上げる |
| --- | --- | --- |
| 書く | お書きする | お書き申し上げる |
| 読む | お読みする | お読み申し上げる |
| 持つ | お持ちする | お持ち申し上げる |
| 送る | お送りする | お送り申し上げる |

### 谦让语使用示例

- 私が**参ります**（我去）
- 私は明日東京に**参ります**（我明天去东京）
- 先生にお目に**かかりました**（见到了老师）
- これからご説明**いたします**（接下来我来解释）
- お手紙を**拝見しました**（我看了您的信）
- ごちそうを**いただきました**（我吃了美食）

| 来る | いらっしゃる / 見える | 参る |
| する | なさる | 致す |
| 言う | おっしゃる | 申す / 申し上げる |
| 食べる | 召し上がる | 頂く |
| 飲む | 召し上がる | 頂く |
| 見る | ご覧になる | 拝見する |

## 美化语（びかご）

美化语不是严格意义的敬语，而是让词语显得文雅：

| 普通 | 美化语 |
| --- | --- |
| 酒 | **お**酒 |
| 茶 | **お**茶 |
| 飯 | **ご**飯 |
| 金 | **お**金 |
| 肉 | **お**肉 |
| 水 | **お**水 |

::: tip お vs ご
- **お** + 和语词（日本固有词）：お茶、お水、お花
- **ご** + 汉语词（中文借词）：ご飯、ご挨拶、ご連絡
:::

## 实用场景

### 电话用语

| 场景 | 表达 |
| --- | --- |
| 接电话 | もしもし、〇〇**でございます** |
| 请稍等 | 少々**お待ちください** |
| 对方不在 | ただいま**席を外しております** |
| 自报家门 | 〇〇と**申します** |
| 确认对方 | どなた**でしょうか** |

### 商务用语

| 场景 | 表达 |
| --- | --- |
| 初次见面 | 初めまして、〇〇と**申します** |
| 请多关照 | 今後ともよろしく**お願い申し上げます** |
| 传达 | 〇〇に**お伝えします** |
| 拜访 | お伺い**いたします** |
| 失礼 | 失礼**いたします** |

### 邮件用语

| 场景 | 表达 |
| --- | --- |
| 开头 | いつもお世話に**なっております** |
| 附件确认 | ご確認**いただけますでしょうか** |
| 请求 | お手数ですが、ご返信**お願いいたします** |
| 结尾 | よろしく**お願い申し上げます** |

## 敬语使用要点

### 1. 区分内外关系

::: warning 内外关系
对公司外部提到**自己公司的人**时，即使对方是社长也不用尊敬语：
- ✗ 社長が**いらっしゃいます**（对外部说自家社长）
- ✓ 社長が**おります**（对外部说自家社长，用谦让语）
:::

### 2. 避免双重敬语

- ✗ お召し上がりになる（双重）
- ✓ 召し上がる / お食べになる

### 3. 尊敬语 vs 谦让语选择

| 场景 | 选择 |
| --- | --- |
| 对方/上位者的动作 | 尊敬语 |
| 自己/己方的动作 | 谦让语 |
| 无关第三者（一般） | 郑重语即可 |

### 4. 身份关系

| 对象 | 敬语等级 |
| --- | --- |
| 家人（对外） | 不用敬语 |
| 朋友 | 普通体或郑重语 |
| 同事 | 郑重语 |
| 上司/客户 | 尊敬语 + 谦让语 |
| 初次见面 | 郑重语起 |

## 小结

| 要点 | 说明 |
| --- | --- |
| 三大类 | 尊敬语（抬高对方）/ 谦让语（贬低自己）/ 郑重语（礼貌语气） |
| 尊敬语 | 对方动作用，特殊动词或 お～になる |
| 谦让语 | 自己动作用，特殊动词或 お～する |
| 郑重语 | です/ます，最基础礼貌 |
| 内外关系 | 对外提自己人不用尊敬语 |
| 避免双重 | 一个动词只用一种敬语形式 |
