# 形容词变形与活用

日语形容词分两大类，各自有完整的活用（变形）体系。掌握形容词变形，才能表达否定、过去、连接、推测等各种语气。

## 形容词分类

| 类别 | 特征 | 词尾 | 示例 |
| --- | --- | --- | --- |
| **い形容词**（形容词） | 以「い」结尾 | ～い | 高い、新しい、面白い |
| **な形容词**（形容动词） | 词干 + な + 名词 | ～な | 静か、元気、便利 |

::: warning 容易混淆的词
有些词以「い」结尾但不是い形容词：
- **きれい**（漂亮）—— な形容词（来源「綺麗」，汉语词）
- **嫌い**（讨厌）—— な形容词
- **ゆうめい**（有名）—— な形容词

判断技巧：汉字词 + い 多为な形容词；和语词 + い 多为い形容词。
:::

## い形容词活用

以「高い」（高的）为例：

| 活用形 | 形态 | 示例 | 中文 |
| --- | --- | --- | --- |
| **辞书形** | 高い | 高いです | 高 |
| **郑重肯定** | 高いです | 高いです | 高 |
| **郑重否定** | 高くないです / 高くありません | 高くないです | 不高 |
| **普通否定** | 高くない | 高くない | 不高 |
| **过去肯定** | 高かった | 高かったです | 曾经高 |
| **过去否定** | 高くなかった | 高くなかったです | 曾经不高 |
| **て形** | 高くて | 高くて、新しい | 高而且新 |
| **副词形** | 高く | 高くする | 提高 |
| **条件形** | 高ければ | 高ければ買わない | 如果贵就不买 |
| **推量形** | 高かろう / 高いだろう | 高かろう | 大概贵吧 |

### 变形规律

```
高い（辞书形）
  ├─ 肯定：高いです
  ├─ 否定：高く + ないです / ありません
  ├─ 过去：高かっ + たです
  ├─ 过去否定：高く + なかったです
  ├─ て形：高く + て
  ├─ 副词：高く
  ├─ 条件：高けれ + ば
  └─ 推量：高かろ + う
```

::: tip 否定的敬体
い形容词否定有两种敬体：
- 高く**ないです**（较常用）
- 高く**ありません**（更正式）
:::

### 常用い形容词活用示例

| 辞书形 | 否定 | 过去 | て形 |
| --- | --- | --- | --- |
| 高い（高） | 高くない | 高かった | 高くて |
| 新しい（新） | 新しくない | 新しかった | 新しくて |
| 面白い（有趣） | 面白くない | 面白かった | 面白くて |
| 寒い（冷） | 寒くない | 寒かった | 寒くて |
| 暑い（热） | 暑くない | 暑かった | 暑くて |
| 大きい（大） | 大きくない | 大きかった | 大きくて |
| 小さい（小） | 小さくない | 小さかった | 小さくて |
| 良い（好） | 良くない | 良かった | 良くて |

::: warning いい 的特殊变形
「いい」（好）的变形基于「よい」：
- 辞书形：いい / よい
- 否定：よくない（不是 いくない）
- 过去：よかった（不是 いかった）
- て形：よくて
:::

## な形容词活用

な形容词的活用本质上是词干 + 助动词（だ/です/な）的组合。

以「静か」（安静的）为例：

| 活用形 | 形态 | 示例 | 中文 |
| --- | --- | --- | --- |
| **辞书形** | 静かだ | 静かだ | 安静 |
| **郑重肯定** | 静かです | 静かです | 安静 |
| **郑重否定** | 静かじゃないです / 静かではありません | 静かじゃないです | 不安静 |
| **普通否定** | 静かじゃない / 静かではない | 静かじゃない | 不安静 |
| **过去肯定** | 静かだった | 静かでした | 曾经安静 |
| **过去否定** | 静かじゃなかった / 静かではなかった | 静かじゃなかった | 曾经不安静 |
| **て形** | 静かで | 静かで、きれいだ | 安静而且漂亮 |
| **连体形** | 静かな | 静かな部屋 | 安静的房间 |
| **副词形** | 静かに | 静かに話す | 安静地说话 |
| **条件形** | 静かなら（ば） | 静かなら、ここで勉強する | 如果安静就在这学 |
| **推量形** | 静かだろう / 静かでしょう | 静かだろう | 大概安静吧 |

### 变形规律

```
静か（词干）
  ├─ 肯定：静か + です / だ
  ├─ 否定：静か + じゃない / ではない
  ├─ 过去：静か + だった / でした
  ├─ 过去否定：静か + じゃなかった / ではなかった
  ├─ て形：静か + で
  ├─ 修饰名词：静か + な + 名词
  ├─ 副词：静か + に
  ├─ 条件：静か + なら（ば）
  └─ 推量：静か + だろう / でしょう
```

### 常用な形容词活用示例

| 辞书形 | 否定 | 过去 | て形 | 连体形 |
| --- | --- | --- | --- | --- |
| 静か（安静） | 静かじゃない | 静かだった | 静かで | 静かな |
| 元気（健康） | 元気じゃない | 元気だった | 元気で | 元気な |
| 便利（方便） | 便利じゃない | 便利だった | 便利で | 便利な |
| きれい（漂亮） | きれいじゃない | きれいだった | きれいで | きれいな |
| 暇（空闲） | 暇じゃない | 暇だった | 暇で | 暇な |
| 好き（喜欢） | 好きじゃない | 好きだった | 好きで | 好きな |
| 嫌い（讨厌） | 嫌いじゃない | 嫌いだった | 嫌いで | 嫌いな |
| 有名（有名） | 有名じゃない | 有名だった | 有名で | 有名な |

## 两类形容词对照表

| 活用 | い形容词（高い） | な形容词（静か） |
| --- | --- | --- |
| 肯定 | 高いです | 静かです |
| 否定 | 高くないです | 静かじゃないです |
| 过去 | 高かったです | 静かでした |
| 过去否定 | 高くなかったです | 静かじゃなかったです |
| て形 | 高くて | 静かで |
| 修饰名词 | 高い本 | 静かな部屋 |
| 副词 | 高く | 静かに |
| 条件 | 高ければ | 静かなら |
| 推量 | 高かろう | 静かだろう |

## 形容词修饰名词

### い形容词 + 名词

直接连接，不变形：

- 高い**山**（高山）
- 新しい**本**（新书）
- 面白い**映画**（有趣的电影）
- 美しい**花**（美丽的花）

### な形容词 + 名词

词干 + な + 名词：

- 静か**な**町（安静的小镇）
- 元気**な**子供（健康的孩子）
- 便利**な**場所（方便的地方）
- きれい**な**空（美丽的天空）

## 形容词副词化

形容词变为副词，修饰动词：

### い形容词：く + 动词

| 形容词 | 副词 | 示例 |
| --- | --- | --- |
| 高い | 高く | 価段が**高く**なる（变贵） |
| 速い | 速く | **速く**走る（快跑） |
| 大きい | 大きく | 声が**大きく**する（放大声音） |
| 新しく | 新しく | 部屋を**新しく**する（翻新房间） |

### な形容词：に + 动词

| 形容词 | 副词 | 示例 |
| --- | --- | --- |
| 静か | 静かに | **静かに**話す（安静地说） |
| 元気 | 元気に | **元気に**育つ（健康地成长） |
| きれい | きれいに | 部屋を**きれいに**する（打扫干净） |
| 簡単 | 簡単に | **簡単に**解ける（简单解决） |

## 形容词て形连接

て形用于连接多个形容词或句子，表示并列、原因等。

### い形容词て形：～くて

- このりんごは**赤くて**、甘い（这个苹果红而且甜）
- 日本語は**面白くて**、難しい（日语有趣但难）
- 田中さんは**若くて**、元気だ（田中年轻又有精神）

### な形容词て形：～で

- この町は**静かで**、きれいだ（这个小镇安静而且漂亮）
- 田中さんは**元気で**、親切だ（田中健康而且亲切）
- この部屋は**広くて**、便利だ（混合使用：い形容词て形 + な形容词）

### 混合连接

い形容词和な形容词可以混合连接：

- この部屋は**広くて**、**静かだ**（这房间宽敞且安静）
- 彼は**若くて**、**元気だ**（他年轻且有精神）

## 条件形用法

### い形容词：～ければ

- **高ければ**、買わない（如果贵就不买）
- **面白ければ**、見に行こう（如果有趣就去看）

### な形容词：～なら（ば）

- **静かなら**、ここで勉強しよう（如果安静就在这学）
- **便利なら**、そこに住みたい（如果方便就住那里）

## 推量形

表达推测「大概...吧」：

### い形容词

- 高い**だろう** / 高い**でしょう**（大概贵吧）
- 高かろう（古风/书面）

### な形容词

- 静か**だろう** / 静か**でしょう**（大概安静吧）

## 特殊形容词

### いい / よい（好）

| 活用 | 形态 |
| --- | --- |
| 辞书形 | いい / よい |
| 否定 | **よく**ない |
| 过去 | **よかっ**た |
| て形 | **よく**て |
| 条件 | **よけれ**ば |

::: warning 注意
「いい」只能用于辞书形和连体形，变形时必须用「よい」。
:::

### 多い / 少ない（多/少）

这两个词**不能直接修饰名词**：

- ✗ 多い人
- ✓ 多くの人（很多人）
- ✗ 少ない本
- ✓ 少ない数の本 / あまり多くない本

## 实用表达

### 比较句

| 句型 | 示例 |
| --- | --- |
| A は B より... | 日本は中国より**小さい**（日本比中国小） |
| A と B とどちらが... | 日本語と英語とどちらが**難しい**ですか |
| A の方が... | 日本語の方が**難しい**です（日语更难） |
| 一番... | 三人の中で田中さんが**一番高い**（三人中田中最高） |

### 好恶表达

好恶用な形容词「好き/嫌い」：

- 私はりんごが**好きです**（我喜欢苹果）
- 私は肉が**嫌いじゃない**（我不讨厌肉）
- どんな音楽が**好きですか**（喜欢什么音乐？）

::: tip 好恶的对象用が
表示好恶、能力时，对象用「が」而非「を」：
- 私は日本語**が**好きだ（不是 日本語を好きだ）
- 私はスポーツ**が**得意だ（不是 スポーツを得意だ）
:::

### 变化表达

| 句型 | 示例 |
| --- | --- |
| 〜くなる（い形容词） | 価段が**高くなった**（变贵了） |
| 〜になる（な形容词） | 部屋が**きれいになった**（房间变干净了） |
| 〜くする（い形容词） | 価段を**安くする**（降价） |
| 〜にする（な形容词） | 部屋を**きれいにする**（打扫房间） |

## 小结

| 要点 | 说明 |
| --- | --- |
| 分类 | い形容词（～い）/ な形容词（～な + 名词） |
| い否定 | ～くないです / ～くありません |
| な否定 | ～じゃないです / ～ではありません |
| い过去 | ～かったです |
| な过去 | ～でした / ～だった |
| いて形 | ～くて |
| なて形 | ～で |
| 修饰名词 | い直接 / な + な |
| 副词化 | い→～く / な→～に |
| 条件 | い→～ければ / な→～なら |
