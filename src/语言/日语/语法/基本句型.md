# 日语基本句型与语序

::: info 学习导航
- **级别定位**：<Badge type="tip" text="N5" />
- **深入讲解**：状态表达（だ/じゃない/だった）与 は/が 的语感辨析见系统讲解篇 [基础语法](03-基础语法.html)
:::

## SOV 语序

日语是典型的 **SOV 语言**，即「**主语 + 宾语 + 谓语**」的语序。这与中文（SVO）和英文（SVO）都不同。

| 语言 | 语序 | 示例 |
| --- | --- | --- |
| 中文 | SVO | 我（主）吃（谓）苹果（宾） |
| 英语 | SVO | I（S）eat（V）an apple（O） |
| 日语 | SOV | 私（S）が りんご（O）を 食べる（V） |

```
中文：我    吃   苹果
英语：I     eat  an apple
日语：私が  りんごを  食べる
      S     O        V
```

**关键点**：谓语动词永远在句末。这是日语最核心的语序特征。

## 基本句型

### 1. 名词句（A 是 B）

```
A は B です
```

| 日语 | 读音 | 中文 |
| --- | --- | --- |
| 私は学生です | わたしはがくせいです | 我是学生 |
| これは本です | これはほんです | 这是书 |
| 田中さんは先生です | たなかさんはせんせいです | 田中先生是老师 |

**否定**：A は B ではありません / じゃありません

- 私は学生ではありません（我不是学生）
- これは本じゃありません（这不是书）

**疑问**：A は B ですか

- あなたは学生ですか（你是学生吗？）

### 2. 形容词句（A 是...的）

日语形容词分两类：

| 类型 | 词尾 | 示例 |
| --- | --- | --- |
| い形容词 | ～い | 高い（高的）、新しい（新的） |
| な形容词 | ～な + 名词 | 静か（安静的）、元気（健康的） |

**い形容词**：

- この山は**高い**です（这座山很高）
- この本は**新しい**です（这本书很新）

**な形容词**（作谓语时去掉「な」加「です」）：

- この町は**静か**です（这个小镇很安静）
- 田中さんは**元気**です（田中很有精神）

### 3. 动词句（主语做某事）

```
主语 が 动词（ます形）
```

- 私が**食べます**（我吃）
- 田中さんが**行きます**（田中去）
- 犬が**走ります**（狗跑）

### 4. 存在句（有/在）

表示人或动物的存在用「います」，表示事物的存在用「あります」。

| 句型 | 用途 | 示例 |
| --- | --- | --- |
| 場所 に 名词 が あります | 某地有某物（无生命） | 部屋に机があります（房间里有桌子） |
| 場所 に 名词 が います | 某地有某人/动物 | 庭に犬がいます（院子里有狗） |
| 名词 は 場所 に あります | 某物在某地 | 本は机にあります（书在桌子上） |
| 名词 は 場所 に います | 某人/动物在某地 | 田中さんは東京にいます（田中在东京） |

## 核心助词入门

| 助词 | 读音 | 用途 | 示例 |
| --- | --- | --- | --- |
| は | wa | 提示主题 | 私**は**学生です |
| が | ga | 提示主语 | 犬**が**走ります |
| を | wo | 提示宾语 | りんご**を**食べる |
| に | ni | 时间/地点/方向 | 東京**に**行く |
| で | de | 手段/场所 | バス**で**行く |
| と | to | 和/与 | 私**と**田中さん |
| も | mo | 也 | 私**も**学生です |
| か | ka | 疑问 | 学生です**か** |
| の | no | 的 | 私**の**本 |

## は 与 が 的区别

这是日语学习中最经典也最容易混淆的问题。

| 对比项 | は | が |
| --- | --- | --- |
| 功能 | 提示主题 | 提示主语（新信息） |
| 焦点 | 后面的内容（述语） | 前面的主语 |
| 已知/未知 | 已知信息 | 新信息 |
| 疑问句回答 | 不用于特殊疑问句回答 | 用于回答「谁/什么」 |

**示例对比**：

```
私 は 学生です。  → 焦点在「学生」（我是...学生）
私 が 学生です。  → 焦点在「我」（是...我，是学生）
```

**典型场景**：

- 谁是学生？ → **私が**学生です（是我）
- 你是做什么的？ → 私は**学生**です（我是学生）

## 语序灵活性

虽然日语是 SOV，但因为助词标记了词的语法功能，所以语序相对灵活：

```
私は りんごを 食べる     （标准 S O V）
りんごを 私は 食べる     （宾语前置）
私は 食べる りんごを     （口语，动词可后置）
```

但**谓语必须在句末**这一规则不能违反。

## 小结

| 要点 | 说明 |
| --- | --- |
| 语序 | SOV（主-宾-谓），谓语在句末 |
| 名词句 | A は B です |
| 形容词句 | い形容词 / な形容词 + です |
| 动词句 | 主语 が 动词 |
| 存在句 | あります（物）/ います（人/动物） |
| 核心助词 | は が を に で と も か の |

掌握以上基本句型后，就可以进入[动词变形](动词变形.html)的学习了。
