# 动词变形总览

日语动词变形是语法的核心。所有动词变形都从**辞书形**（原形）派生而来。

## 动词分类

日语动词分三类：

| 类别 | 特征 | 示例 |
| --- | --- | --- |
| **一类动词**（五段） | 词尾在 う段，且多为「～る」前是 い/え 段假名 | 書く、飲む、買う、待つ |
| **二类动词**（一段） | 词尾「～る」，る 前是 い/え 段假名 | 食べる、見る、起きる |
| **三类动词**（不规则） | する（做）、来る（来） | 勉強する、来る |

::: tip 辨别技巧
- 二类动词的「る」前一定是 い段（上一段）或 え段（下一段）
- 但一类动词也有「～る」结尾的（如 帰る、知る），需单独记忆
- する、来る 永远是三类
:::

## 变形总览表

以常见动词为例：

| 变形 | 一类（書く） | 二类（食べる） | 三类（する/来る） | 用途 |
| --- | --- | --- | --- | --- |
| **辞书形** | 書く | 食べる | する / 来る | 原形 |
| **ます形** | 書きます | 食べます | します / 来ます | 郑重肯定 |
| **ない形** | 書かない | 食べない | しない / 来ない | 否定 |
| **て形** | 書いて | 食べて | して / 来て | 连接、请求 |
| **た形** | 書いた | 食べた | した / 来た | 过去 |
| **可能形** | 書ける | 食べられる | できる / 来られる | 能、会 |
| **受身形** | 書かれる | 食べられる | される / 来られる | 被动 |
| **使役形** | 書かせる | 食べさせる | させる / 来させる | 让、使 |
| **命令形** | 書け | 食べろ | しろ / 来い | 命令 |
| **仮定形** | 書けば | 食べれば | すれば / 来れば | 如果 |
| **意志形** | 書こう | 食べよう | しよう / 来よう | 打算、邀请 |

## 一类动词（五段）变形规律

一类动词变形最复杂，词尾う段假名会移到同一行的其他段。

### ます形（う段 → い段 + ます）

| 辞书形 | 词尾变化 | ます形 |
| --- | --- | --- |
| 書く | く → き | 書きます |
| 飲む | む → み | 飲みます |
| 買う | う → い | 買います |
| 待つ | つ → ち | 待ちます |
| 話す | す → し | 話します |
| 死ぬ | ぬ → に | 死にます |
| 飛ぶ | ぶ → び | 飛びます |
| 帰る | る → り | 帰ります |

### ない形（う段 → あ段 + ない）

| 辞书形 | 词尾变化 | ない形 |
| --- | --- | --- |
| 書く | く → か | 書かない |
| 飲む | む → ま | 飲まない |
| 買う | う → わ | 買わない（注意：不是 あ） |
| 待つ | つ → た | 待たない |
| 話す | す → さ | 話さない |

::: warning 特殊：ある
「ある」（有）的否定是「ない」，不是「あらない」。
:::

### て形 / た形（最重要的变形）

一类动词的て形/た形词尾变化规律：

| 辞书形词尾 | て形/た形 | 示例 |
| --- | --- | --- |
| く | いて/いた | 書く → 書いて/書いた |
| ぐ | いで/いだ | 泳ぐ → 泳いで/泳いだ |
| う、つ、る | って/った | 買う → 買って/買った |
| ぬ、ぶ、む | んで/んだ | 飲む → 飲んで/飲んだ |
| す | して/した | 話す → 話して/話した |

::: tip 记忆口诀
「きいて、いで、って、んで、して」——按词尾分组记忆最有效。
:::

### 可能形（う段 → え段 + る）

| 辞书形 | 可能形 | 示例句 |
| --- | --- | --- |
| 書く | 書ける | 日本語が書けます |
| 飲む | 飲める | お酒が飲めます |
| 買う | 買える | これが買えます |

### 仮定形（う段 → え段 + ば）

| 辞书形 | 仮定形 | 示例句 |
| --- | --- | --- |
| 書く | 書けば | 書けば、分かります |
| 飲む | 飲めば | 薬を飲めば、治ります |

### 意志形（う段 → お段 + う）

| 辞书形 | 意志形 | 示例句 |
| --- | --- | --- |
| 書く | 書こう | 一緒に書こう |
| 飲む | 飲もう | お酒を飲もう |

### 命令形（う段 → え段）

| 辞书形 | 命令形 | 示例句 |
| --- | --- | --- |
| 書く | 書け | 早く書け！ |
| 飲む | 飲め | これを飲め！ |

## 二类动词（一段）变形规律

二类动词变形最简单：**去掉「る」+ 对应词尾**。

| 变形 | 规律 | 食べる | 見る |
| --- | --- | --- | --- |
| ます形 | 去 る + ます | 食べます | 見ます |
| ない形 | 去 る + ない | 食べない | 見ない |
| て形 | 去 る + て | 食べて | 見て |
| た形 | 去 る + た | 食べた | 見た |
| 可能形 | 去 る + られる | 食べられる | 見られる |
| 受身形 | 去 る + られる | 食べられる | 見られる |
| 使役形 | 去 る + させる | 食べさせる | 見させる |
| 命令形 | 去 る + ろ | 食べろ | 見ろ |
| 仮定形 | 去 る + れば | 食べれば | 見れば |
| 意志形 | 去 る + よう | 食べよう | 見よう |

## 三类动词（不规则）变形

| 变形 | する | 来る（くる） |
| --- | --- | --- |
| ます形 | します | 来ます（きます） |
| ない形 | しない | 来ない（こない） |
| て形 | して | 来て（きて） |
| た形 | した | 来た（きた） |
| 可能形 | できる | 来られる（こられる） |
| 受身形 | される | 来られる（こられる） |
| 使役形 | させる | 来させる（こさせる） |
| 命令形 | しろ | 来い（こい） |
| 仮定形 | すれば | 来れば（くれば） |
| 意志形 | しよう | 来よう（こよう） |

::: warning 来る 的读音
「来る」所有变形都从「こ」行变化：きます、こない、きて、きた、こられる...
:::

## 实用变形组合

### ている（正在进行 / 状态）

- 食べ**ている**（正在吃）
- 結婚**している**（已婚 —— 表示状态）

### たい（想做）

- 食べ**たい**（想吃）
- 行き**たい**（想去）

### ましょう（邀请）

- 食べ**ましょう**（一起吃吧）
- 行き**ましょう**（一起去吧）

### なければならない（必须）

- 食べ**なければならない**（必须吃）
- 行か**なければならない**（必须去）

## 学习建议

1. **先掌握ます形** —— 最常用的礼貌体
2. **死磕て形** —— て形使用频率最高，连接各种表达
3. **分类记忆** —— 一类动词按词尾分组记规律
4. **多造句练习** —— 每个变形至少造 3 个句子
5. **参考[基本句型](基本句型.html)** —— 理解句型后再学变形
