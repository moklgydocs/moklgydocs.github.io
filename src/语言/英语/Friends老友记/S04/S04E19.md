- 歌词用 X is here / X is clear 排比反复，一般现在时呈现"眼前正在展开"的画面（[Ch.3](../../语法俱乐部/Chapter03.md)）

- **make this a nice place**：make + 宾语 + 名词作**宾语补足语**（台：补语），"把这里变成一个像样的地方"（S+V+O+C，[Ch.1](../../语法俱乐部/Chapter01.md)）

<GrammarTip type="long" points="长难句,虚拟语气,副词从句">

**原句回听**：<AudioButton src="/audio/episodes/S04/S04E19.mp3" start="89.592" duration="17.52" />

**原句**：I never would’ve gotten this if it weren’t for you. When I’m with you I’m like this whole other guy, I love that guy!

**层次划分**：

- 主干：<p class="svoc"><span class="s">I</span> <span class="v">never would’ve gotten</span> <span class="o">this</span> <span class="a">if it weren’t for you</span></p>
- **never would’ve gotten**：would’ve = would have——与过去事实相反的**虚拟语气**："（当初）绝不会去打这个耳洞"；get 此处 = 打（耳洞）、弄到（[Ch.9](../../语法俱乐部/Chapter09.md)）
- **if it weren’t for you**：虚拟条件句"要不是你"，与现在事实相反从句用过去式 weren’t（口语也常听到 wasn’t）；if it weren’t for... 是固定句型（[Ch.9](../../语法俱乐部/Chapter09.md)/[Ch.13](../../语法俱乐部/Chapter13.md)）
- **when I’m with you**：时间副词从句用现在式表常态——"每次和你在一起"（[Ch.13](../../语法俱乐部/Chapter13.md)）
- **I’m like this whole other guy**：口语 be like = "就像、变成"；this whole other guy"完全另一个人"，whole 加强语气（[Ch.2](../../语法俱乐部/Chapter02.md)）
- **I mean**：插入语"我是说"，引出口头修正（[Ch.15](../../语法俱乐部/Chapter15.md)）

**翻译**：要不是你，我绝不会打这个耳洞。真的，跟你在一起时，我就像变成了另一个人——我爱那个家伙！我是说，我也很爱你，非常爱，但是那个家伙！我爱那个家伙！

**语法要点**：混合虚拟 would have done + if it weren’t（Ch.9）；时间从句现在式表常态（Ch.13）；be like 口语表"变得"（Ch.8）

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,虚拟语气">

**本集虚拟句型之一：与现在事实相反——wish / if + 过去式**（[Ch.9](../../语法俱乐部/Chapter09.md)）：

- **wish + 过去式从句**：I wish I didn’t have to go. / I wish I could.
<p class="svoc"><span class="s">I</span> <span class="v">wish</span> <span class="o">I didn’t have to go</span></p>
- **if + 过去式，主句 would + 原形**：if it weren’t for you / it would be different if it was way into the future—and we were getting married
<p class="svoc"><span class="s">it</span> <span class="v">would be</span> <span class="c">different</span> <span class="a">if it was way into the future</span></p>
- **口诀**：wish 与 if 虚拟的从句一律"时态退一格"（现在→过去），主句配 would/could + 原形；正式文体 if 从句的 be 动词用 were（If I were you）

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,虚拟语气">

**本集虚拟句型之二：与过去事实相反——would have + 过去分词**（[Ch.9](../../语法俱乐部/Chapter09.md)）：

- **混合虚拟**：I never would’ve gotten this if it weren’t for you（过去的结果 + 现在的条件）
<p class="svoc"><span class="s">I</span> <span class="v">never would’ve gotten</span> <span class="o">this</span> <span class="a">if it weren’t for you</span></p>
- **if + had done 配 would have done**：if you’d just done that right after the last contest, no one would have had to move at all
<p class="svoc"><span class="s">no one</span> <span class="v">would have had to move</span> <span class="a">at all</span></p>
- **should have done 表"悔不该"**：I shouldn’t have said married
- **口诀**：对过去说"早知道"——从句 had done，主句 would/should have done；口语缩略 ’ve 读作 /əv/，书面勿误写成 would of

</GrammarTip>
