**本集"虚拟/委婉"句型大盘点**（[Ch.9](../../语法俱乐部/Chapter09.md)）：

- **would + if 从句过去式（第二条件句骨架）**：you **wouldn't believe** me if I **said**... / it **would help** if you **would** just talk
<p class="svoc"><span class="s">you</span> <span class="v">wouldn't believe</span> <span class="o">me</span> <span class="a">if I said...</span></p>
- **if + were（与现在相反）**：if I **were** going to be with a woman, it'**d be** someone like Michelle
- **you'd think（"按说你会以为"）**：you'**d think** he'**d be** worried about me not showing up
- **must have done（对过去的推测）**：I **must've missed** your call
- **口诀**：看见 if 从句用过去式、主句配 would——先想"虚拟"；看见 must have done——那是"推测过去"

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,关系从句">

**本集定语从句（台：关系从句）省略与保留大赏**（[Ch.14](../../语法俱乐部/Chapter14.md)）：

- **关系代词作宾语 → 可省**：the jacket (that) you picked out / some girl (that) I've never met / nothing (that) I can do / the important thing (that) you must remember

- **the way + 从句**：the way they talk（= in which/that，口语全可省）
- **which 指代整句（非限定）**：**Which** helps him get to Phase Three / **Which** I'm fairly certain are the same thing
- **口诀**：从句缺宾语可省 that，缺主语必须留
