<GrammarTip type="pattern" points="句型总复习,虚拟语气">

**本集句型一：if 从句 × 假设语气——"如果……就……"的花式说法**（[Ch.9](../../语法俱乐部/Chapter09.md)/[Ch.13](../../语法俱乐部/Chapter13.md)）：

- **与现在相反（if + 过去式 / would）**：If these walls could talk, y'know what they'd say? / if I could get you here, I could seduce you / if a cow should die of natural causes（should 表"万一"）
- **真实条件（if + 现在式 / will 或原形）**：If you're going to do something wrong, do it right! / you don't do that if you're just in it for two weeks / if it makes you feel any better
<p class="svoc"><span class="a">If these walls could talk</span> <span class="s">they</span> <span class="v">'d say</span></p>
- **口诀**：说"假话"（虚拟）时态退一步（could/would）；说"真话"（真实条件）从句用现在式

</GrammarTip>
