**原句回听**：<AudioButton src="/audio/episodes/S04/S04E18.mp3" start="13.416" duration="10.968" />

**原句**：No, it’s just I’m so pregnant that I—my guitar doesn’t fit anymore. So I thought ‘til I’m not, I’m just gonna play all my songs on this drum. It sounds really cool!

**层次划分**：

- **I'm so pregnant that...**：so + 形容词 + that 引导结果**副词从句（台：状语从句）**"如此……以至于"；从句没说完，破折号后改换话题（[Ch.13](../../语法俱乐部/Chapter13.md)）
- **my guitar doesn't fit anymore**：not...anymore"不再……"；fit 此处指"（大肚子抱着）放得下"（[Ch.8](../../语法俱乐部/Chapter08.md)）
- **‘til I'm not**：= until I'm not (pregnant) 的紧缩省略；until 时间副词从句用**现在式代未来**（[Ch.13](../../语法俱乐部/Chapter13.md)）
- **I'm just gonna play all my songs on this drum**：gonna = going to——be going to + 原形表"打算/将要"（[Ch.3](../../语法俱乐部/Chapter03.md)）
- **It sounds really cool**：sound 系动词 + 形容词 cool 作表语（[Ch.1](../../语法俱乐部/Chapter01.md)）

**翻译**：不好笑。只是我肚子大到——吉他都搁不下了。所以我想，在肚子消下去之前，我所有的歌就都在这面鼓上弹啦。听起来超酷的！

**语法要点**：so...that 结果从句（Ch.13）；until 从句现在式代未来（Ch.13）；be going to 表打算（Ch.3）

<GrammarTip type="pattern" points="句型总复习,动词时态">

**本集 be going to（ gonna ）的三种将来**（[Ch.3](../../语法俱乐部/Chapter03.md)）：

- **打算/计划**：I'm just gonna play all my songs on this drum. / I'm gonna name the baby Chandler. / I'm either gonna be Mark Johnson or John Markson.
<p class="svoc"><span class="s">I</span> <span class="v">'m gonna name</span> <span class="o">the baby</span> <span class="c">Chandler</span></p>
- **将来进行**：Susan's gonna be shooting a commercial. / There's never gonna be a President Joey.（there be 句型也能套 be going to）
- **过去将来（原打算）**：I was gonna say… / We were going to do that after—（被打断/没说出口的打算）
- **口诀**：be going to = 已有打算的将来；was/were going to = 从过去看的"本来打算"；gonna 是其口语紧缩

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,副词从句">

**本集 if 从句的三种语气**（[Ch.13](../../语法俱乐部/Chapter13.md)/[Ch.9](../../语法俱乐部/Chapter09.md)）：

- **真实条件·主将从现**：If you need him, he'll be there. / If mommy can have a wife, daddy can have a bra.
<p class="svoc"><span class="a">If you need him</span>, <span class="s">he</span> <span class="v">'ll be</span> <span class="c">there</span></p>
- **委婉/假设·过去式**：Would you feel better if we went someplace else? / If you were hoping to sleep with Joshua..., which one would you want to be wearing? / We would be truly honoured if you named the other boy baby.（正式客套）
- **What if 提议**：What if it's like, y'know, Chanoey?
- **口诀**：条件从句里不说 will；想客气、想假装，动词就"退一格"变过去式

</GrammarTip>
