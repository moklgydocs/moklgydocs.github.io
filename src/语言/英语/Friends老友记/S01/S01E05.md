<GrammarTip points="惯用语,关系从句">

- **as far as I'm concerned**：固定句型"就我而言"，as far as 引导范围副词从句（[Ch.13](../../语法俱乐部/Chapter13.md)）
- **nothing a guy can do**：`a guy can do` 是关系从句修饰 nothing，关系代词 that/which 作 do 的宾语故可省略（[Ch.14](../../语法俱乐部/Chapter14.md)）
- **that even comes close**：come close (to) = 接近；整句 = 没有一件事（男人做得到的事）能与之相比

**原句**：All right, as far as I'm concerned, there is nothing a guy can do that even comes close.

**层次划分**：

- 主干 There be 句型：<p class="svoc"><span class="s">There</span> <span class="v">is</span> <span class="c">nothing</span></p> 真正主语是 nothing（[Ch.1](../../语法俱乐部/Chapter01.md)）
- **as far as I'm concerned**：范围副词从句提前作状语（[Ch.13](../../语法俱乐部/Chapter13.md)）
- **a guy can do**：省略关系代词的关系从句，修饰 nothing
- **that even comes close**：that 作主语的关系从句，同样修饰 nothing（作主语不可省略）——两个关系从句共饰一个先行词（[Ch.14](../../语法俱乐部/Chapter14.md)）

**翻译**：就我而言，男人能做的事里，没有一件能接近（它的神奇程度）。

**语法要点**：There be 句型（Ch.1）；双重关系从句（Ch.14）；as far as（Ch.13）

</GrammarTip>

📚 **术语对照**（大陆教材 / 台湾《语法俱乐部》）：定语从句 = 关系从句；宾语从句/主语从句/表语从句 = 名词从句；状语从句 = 副词从句；介词 = 介系词；系动词 = 连缀动词；宾语补足语 = 补语；不定式 = 不定词；主谓一致 = 主语动词一致性

**Q1**：Joey 说 *I never should have broken up with her.* 为什么用 **should have broken** 而不是 should break？

<GrammarTip points="查看答案">

**答**：should have + 过去分词表示**与过去事实相反**的虚拟——"当时不该做却做了"。分手已经发生，若用 should break 则变成对现在/未来的要求。（[Ch.9](../../语法俱乐部/Chapter09.md) 语气·助动词完成式）

</GrammarTip>

**Q2**：*How you get any work done is beyond me.* 为什么从句里用 **you get** 的陈述语序，而不是 do you get？

<GrammarTip points="查看答案">

**答**：因为 **How you get any work done** 是名词从句作主语，不是疑问句。疑问词引导的名词从句内部一律用**陈述语序**（疑问词 + 主语 + 动词），只有独立疑问句才倒装加 do。（[Ch.12](../../语法俱乐部/Chapter12.md) 名词从句）

</GrammarTip>

**Q3**：*There isn't anything I can't do.* 句中有两个否定（isn't / can't），为什么表达的是"什么都能做"的肯定意思？

<GrammarTip points="查看答案">

**答**：这是**双重否定表肯定**："没有〔我做不到的〕事" = 任何事我都做得到。**I can't do** 是省略关系代词 that 的关系从句，修饰 anything；两个否定相消，语气比肯定句更强。（[Ch.14](../../语法俱乐部/Chapter14.md)/[Ch.8](../../语法俱乐部/Chapter08.md)）

</GrammarTip>
