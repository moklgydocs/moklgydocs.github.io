# The One with George Stephanopoulos
> *乔治·斯蒂芬诺普洛斯*

---

🎬 *Central Perk, everyone is there except Joey.*
> 🎬 *中央公园，除了乔伊，所有人都在那里。*

🎯 **本场景语法重点**：虚拟语气（if 过去式 + would）/ make+宾语+补语 / 助动词替代省略

<AudioButton src="/audio/episodes/S01/S01E04.mp3" start="0.0" duration="3.096" /> **Monica Geller:** Alright. Phoebe?
> 好的。菲比？

<AudioButton src="/audio/episodes/S01/S01E04.mp3" start="3.096" duration="8.424" /> **Phoebe Buffay:** Okay, okay. <Note>If I were omnipotent for a day</Note>, <Note>I would want</Note>, um, world peace, no more hunger, good things for the rain-forest...And bigger boobs!
> 好的，好的。如果有一天我无所不能，我会想要，嗯，世界和平，不再饥饿，热带雨林的好东西……还有更大的胸部！
<GrammarTip points="语气,对等连接词">

- **If I were omnipotent for a day, I would want...**：**虚拟语气**——与现在事实相反的假设，if 从句用过去式（be 动词一律用 were），主句用 would + 原形动词（[Ch.9](../../语法俱乐部/Chapter09.md) 语气·虚拟）
- **for a day**：介词 for + 时间长度作时间状语（[Ch.10](../../语法俱乐部/Chapter10.md) 介词）
- **world peace, no more hunger, good things... and bigger boobs**：四个名词词组并列作 want 的宾语，最后一项用 and 收尾（[Ch.15](../../语法俱乐部/Chapter15.md) 对等连接词）

</GrammarTip>

<GrammarTip type="long" points="长难句,虚拟语气">

**原句回听**：<AudioButton src="/audio/episodes/S01/S01E04.mp3" start="3.096" duration="8.424" />

**原句**：If I were omnipotent for a day, I would want, um, world peace, no more hunger, good things for the rain-forest...And bigger boobs!

**层次划分**：

- 条件从句：<p class="svoc"><span class="a">If</span> <span class="s">I</span> <span class="v">were</span> <span class="c">omnipotent</span> <span class="a">for a day</span></p> 虚拟语气中 be 动词统一用 were（正式文体不用 was），表示"现在并非如此"
- 主句：<p class="svoc"><span class="s">I</span> <span class="v">would want</span> <span class="o">world peace / no more hunger / good things / bigger boobs</span></p> would + 原形动词是虚拟主句的标记
- 四个名词词组作 want 的并列宾语，**bigger** 是比较级 + 名词（[Ch.7](../../语法俱乐部/Chapter07.md) 形容词·比较级）

**翻译**：如果有一天我无所不能，我想要世界和平、消除饥饿、雨林安好……还有更大的胸！

**语法要点**：if...were + would do 虚拟（[Ch.9](../../语法俱乐部/Chapter09.md)）；并列宾语 A, B, C and D（[Ch.15](../../语法俱乐部/Chapter15.md)）；比较级（Ch.7）

</GrammarTip>

<AudioButton src="/audio/episodes/S01/S01E04.mp3" start="11.52" duration="6.216" /> **Ross Geller:** Yeah, see.. you <Note>took mine</Note>. Chandler, <Note>what about you</Note>?
> 是的，看。。你拿了我的。钱德勒，你呢？
<GrammarTip points="名词词组,口语省略">

- **you took mine**：过去简单式 took；**mine** 是名词性物主代词 = my wish（我的愿望），避免重复名词（[Ch.2](../../语法俱乐部/Chapter02.md) 名词词组·代词）
- **What about you?**：固定句型 = How about you?，"你呢？"，属省略句，后接名词/代词/动名词

</GrammarTip>

<AudioButton src="/audio/episodes/S01/S01E04.mp3" start="17.736" duration="6.696" /> **Chandler Bing:** Uh, <Note>if I were omnipotent for a day</Note>, <Note>I'd.. make myself omnipotent</Note> forever.
> 嗯，如果有一天我是全能的，我会。。让自己永远无所不能。
<GrammarTip points="语气,基本句型">

<p class="svoc"><span class="s">I</span> <span class="v">'d make</span> <span class="o">myself</span> <span class="c">omnipotent</span> <span class="a">forever</span></p>

- 套用同一虚拟句型：if + 过去式（were），主句 **I'd** = I would（[Ch.9](../../语法俱乐部/Chapter09.md)）
- **make myself omnipotent**：`make + 宾语 + 形容词补语`，S+V+O+C 句型，omnipotent 补充说明 myself 的状态（[Ch.1](../../语法俱乐部/Chapter01.md) 基本句型）

</GrammarTip>

<AudioButton src="/audio/episodes/S01/S01E04.mp3" start="24.432" duration="6.408" /> **Rachel Green:** See, <Note>there's always one guy</Note>. (Mocking) "<Note>If I had a wish</Note>, <Note>I'd wish for three more wishes</Note>." (Joey enters.)
> 看，总有一个人。（嘲弄）“如果我有一个愿望，我会多许三个愿望。”（乔伊进来。）
<GrammarTip points="语气,基本句型">

- **there's always one guy**：There be 存在句 + 频率副词 always，"总有这么一个（耍小聪明的）人"（[Ch.1](../../语法俱乐部/Chapter01.md)）
- **If I had a wish, I'd wish for...**：虚拟语气——if 从句过去式 had，主句 would + 原形；**wish for** 是短语动词"祈求得到"（[Ch.9](../../语法俱乐部/Chapter09.md)/[Ch.10](../../语法俱乐部/Chapter10.md)）
- **three more wishes**：数词 + more + 复数名词，"再多三个"（[Ch.2](../../语法俱乐部/Chapter02.md)）

</GrammarTip>

</GrammarTip>

<GrammarTip points="口语省略">

- 省略句：完整为 **(I'd) probably kill myself**——承接上句问句的 would，口语直接省略主语和助动词
- **kill myself**：反身代词 myself 作宾语，动作回指主语自身

<AudioButton src="/audio/episodes/S01/S01E04.mp3" start="41.616" duration="4.128" /> **Joey Tribbiani:** Hey, <Note>if Little Joey's dead</Note>, then I <Note>got no reason to live</Note>!
> 嘿，如果小乔伊死了，那我就没有活下去的理由了！
<GrammarTip points="副词从句,不定词">

- **if Little Joey's dead**：if 引导条件副词从句，'s dead = is dead，形容词 dead 作主语补语（[Ch.13](../../语法俱乐部/Chapter13.md) 副词从句）
- **I got no reason to live**：口语 = I've got no reason；不定词 **to live** 作后置定语修饰 reason——"活下去的理由"（[Ch.4](../../语法俱乐部/Chapter04.md) 不定词作形容词）
- 否定形式 **no + 名词** = not...any + 名词

</GrammarTip>

<AudioButton src="/audio/episodes/S01/S01E04.mp3" start="45.744" duration="2.784" /> **Ross Geller:** Joey, uh- OMnipotent.
> 乔伊，嗯，全能的。
<GrammarTip points="词汇">

- 单词纠音句：Ross 重读首音节 **OM**-，纠正 Joey 的误听——Joey 把 omnipotent（全能的）听成了 impotent（性无能的），这是本场景的笑点
- **omnipotent** = omni-（全）+ potent（有力的）

</GrammarTip>

<AudioButton src="/audio/episodes/S01/S01E04.mp3" start="48.528" duration="3.888" /> **Joey Tribbiani:** <Note>You are</Note>? Ross, I'm sorry..
> 是吗？罗斯，对不起。。
<GrammarTip points="口语省略,助动词">

- **You are?** = You are omnipotent?——be 动词单独保留，替代整个补语部分以避免重复；Joey 以为 Ross 在说自己"不行"，连忙致歉（[Ch.9](../../语法俱乐部/Chapter09.md) 助动词替代）

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,虚拟语气">

**本场景虚拟语气句型一览**（[Ch.9](../../语法俱乐部/Chapter09.md)）——与现在事实相反：if 从句用过去式，主句用 would + 原形：

<p class="svoc"><span class="a">If</span> <span class="s">I</span> <span class="v">were</span> <span class="c">omnipotent</span>, <span class="s">I</span> <span class="v">would want</span> <span class="o">...</span></p>

- **If I had a wish, I'd wish for three more wishes.**（had → would wish）
- **What would you do if you were omnipotent?**（疑问句只倒装主句：would you do）
- 口语中 be 的虚拟式也有人用 was（If I was...），正式文体一律 **were**

</GrammarTip>

**语法要点**：and/so 并列连接（[Ch.15](../../语法俱乐部/Chapter15.md)）；that 名词从句与 how 同位语从句（Ch.12）；have a good time 固定短语

</GrammarTip>

📚 **术语对照**（大陆教材 / 台湾《语法俱乐部》）：定语从句 = 关系从句；宾语从句/主语从句/表语从句 = 名词从句；状语从句 = 副词从句；介词 = 介系词；系动词 = 连缀动词；宾语补足语 = 补语；不定式 = 不定词；主谓一致 = 主语动词一致性

**Q1**：Phoebe 说 *If I were omnipotent for a day, I would want...* 为什么 be 动词用 **were** 而不用 was 或 am？

<GrammarTip points="查看答案">

**答**：这是**虚拟语气**——假设"我无所不能"与现在事实相反，if 从句动词用过去式形式，be 动词不论人称一律用 **were**（正式文体不用 was）；主句配 would + 原形。Phoebe 此刻并非无所不能，所以不能用 am。（[Ch.9](../../语法俱乐部/Chapter09.md) 语气·虚拟）

</GrammarTip>

**Q2**：Phoebe 辩解 *You'd already broken up.*（你们早就分手了）为什么要用过去完成式 **had broken up** 而不是过去式 broke up？

<GrammarTip points="查看答案">

**答**：因为参照点是过去的另一件事——Phoebe 和 Jason 上床（slept，过去式）。"分手"发生在"上床"**之前**，是"过去的过去"，所以用过去完成式 had broken up 把动作推到更早一层。already 是完成式的常见搭档。（[Ch.3](../../语法俱乐部/Chapter03.md) 时态·过去完成）

</GrammarTip>

**Q3**：*There he is!*（他在那儿！）为什么不说 *There is he!*？副词 there 放句首不是应该倒装吗？

<GrammarTip points="查看答案">

**答**：副词 there/here 置于句首时，**只有名词主语才倒装**（There goes the bus.）；主语是**代词**时不倒装，保持"代词 + 动词"语序，所以是 There **he is**，不是 There is he。（[Ch.22](../../语法俱乐部/Chapter22.md) 倒装句）

</GrammarTip>
