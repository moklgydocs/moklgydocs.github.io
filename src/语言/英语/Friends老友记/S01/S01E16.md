<AudioButton src="/audio/episodes/S01/S01E16.mp3" start="1.296" duration="9.144" /> **Chandler Bing:** This is unbelievable. <Note>It’s been like a half an hour</Note>. <Note>If this was a cartoon</Note>, you’d be <Note>looking like a ham</Note> right about now.
> 这真是难以置信。差不多半个小时了。如果这是一幅漫画，你现在看起来就像个火腿。
<GrammarTip type="long" points="长难句,虚拟语气,动词时态">

**原句回听**：<AudioButton src="/audio/episodes/S01/S01E16.mp3" start="1.296" duration="9.144" />

**原句**：It's been like a half an hour. If this was a cartoon, you'd be looking like a ham right about now.

**层次划分**：

- <p class="svoc"><span class="s">This</span> <span class="v">is</span> <span class="c">unbelievable</span></p> is 是**系动词**（台：连缀动词），形容词 unbelievable 作主语补语（[Ch.1](../../语法俱乐部/Chapter01.md)）
- **It's been like a half an hour**：= It has been... **现在完成式**配时段，"（到现在）已经快半小时了"（[Ch.3](../../语法俱乐部/Chapter03.md)）
- **If this was a cartoon, you'd be looking like a ham**：**虚拟语气**——与现在事实相反，if 条件**状语从句**（台：副词从句）用**过去式 was**，主句用 **would + 原形**；would be looking 用进行式画出"这会儿正在变成火腿"的即时感（[Ch.9](../../语法俱乐部/Chapter09.md)/[Ch.13](../../语法俱乐部/Chapter13.md)）
- **like a ham**：like 此处是**介词**（台：介系词）"像……一样"（[Ch.10](../../语法俱乐部/Chapter10.md)）；**right about now**：口语时间状语"就现在这时候"（[Ch.8](../../语法俱乐部/Chapter08.md)）

**翻译**：太离谱了，都等了快半小时了。要是这是卡通片，你这会儿早就饿成一只火腿了。

**语法要点**：虚拟语气 if 过去式 + would（Ch.9）；完成式 + 时段（Ch.3）；系动词 + 形容词补语（Ch.1）

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,将来与义务">

**本集句型一：be gonna / be supposed to——"将来打算"与"理应如此"**（[Ch.3](../../语法俱乐部/Chapter03.md)/[Ch.9](../../语法俱乐部/Chapter09.md)）：

- **be gonna + 原形**（= be going to，口语缩略）表"就要、打算"：
<p class="svoc"><span class="s">I</span> <span class="v">'m gonna be</span> <span class="c">a father</span></p>
I'm gonna be over here. / Susan's gonna be there too. / We're gonna start with... / It's just gonna have to stay in. / everything's gonna be alright / You're not gonna lose him.
- **be supposed to + 原形**表"按理说应该"（常含"却没做到"）：
<p class="svoc"><span class="s">someone</span> <span class="v">was supposed</span> <span class="c">to take them down</span></p>
someone was supposed to take them down（却没做）/ I am supposed to be the mommy?（升调反问）
- **注意**：be gonna 问句把 be 提前（Is this gonna be...?）；否定直接加 not（You're not gonna...）

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,完成式家族">

**本集句型二：现在完成式 vs 现在完成进行式**（[Ch.3](../../语法俱乐部/Chapter03.md)）：

- **have + 过去分词**表"至今的经验/结果"，常配 never / ever / yet / since：
<p class="svoc"><span class="s">We</span> <span class="v">haven't seen</span> <span class="o">an ANUS this bad</span> <span class="a">since the seventies</span></p>
I've done that. / I've never done that. / you guys haven't talked in like years / you still haven't told her...yet / They haven't even slept together yet. / Have you ever had a boyfriend...?
- **have been + V-ing** 强调"一直持续/反复到现在"：
<p class="svoc"><span class="s">people</span> <span class="v">have been avoiding</span> <span class="o">me</span></p>
I've just been going over your data. / you've been post-dating your Friday numbers / people have been avoiding me / they've been going out a week
- **口诀**：问"到现在为止怎么样"用完成式；强调"一直在……"用完成进行式

</GrammarTip>
