**原句**：But you'll have to live with the knowledge that you sent an honest man to die.

**层次划分**：

- 主干：<p class="svoc"><span class="s">you</span> <span class="v">'ll have to live with</span> <span class="o">the knowledge</span></p>
- **that you sent an honest man to die**：that 从句与 the knowledge **同位**——它就是 knowledge 的具体内容（同位语从句，名词从句的一种，[Ch.12](../../语法俱乐部/Chapter12.md)）。判断法：that 在从句中**不作任何成分**（从句自身完整），即为同位语从句，区别于关系从句
- 从句内部：<p class="svoc"><span class="s">you</span> <span class="v">sent</span> <span class="o">an honest man</span> <span class="c">to die</span></p> send + 宾语 + 不定词补语（S+V+O+C，[Ch.1](../../语法俱乐部/Chapter01.md)）
- 时态对照：主句 will（未来）vs 从句 sent（过去）——"送人去死"已成事实

**翻译**：但你将不得不背负着"你曾把一个清白的人送上死路"这个认知活下去。

**语法要点**：同位语从句 that...（Ch.12）；have to（[Ch.9](../../语法俱乐部/Chapter09.md)）；send + O + 不定词补语（[Ch.4](../../语法俱乐部/Chapter04.md)）

📚 **术语对照**（大陆教材 / 台湾《语法俱乐部》）：定语从句 = 关系从句；宾语从句/主语从句/表语从句 = 名词从句；状语从句 = 副词从句；介词 = 介系词；系动词 = 连缀动词；宾语补足语 = 补语；不定式 = 不定词；主谓一致 = 主语动词一致性

**Q1**：Phoebe 说 *If I kept it, it would be like stealing.* 钱明明就在她账户里（留不留是现在的事），为什么动词用过去式 **kept**？

<GrammarTip points="查看答案">

**答**：这是**虚拟语气**——表示"与现在事实相反的假设"时，if 从句的动词要**后退一个时态**（现在→过去），主句配 would + 原形。kept 不是过去时间，而是"非真实"的标记。对照本集真实条件句 If you never **smoke** again, I'**ll** give you...（真可能戒烟，所以从句用现在式）。（[Ch.9](../../语法俱乐部/Chapter09.md) 语气·虚拟）

</GrammarTip>

**Q2**：*If only he were a woman.* 主语是 he，为什么 be 动词用 **were** 而不用 was？

<GrammarTip points="查看答案">

**答**：if only（要是……就好了）后面接**虚拟语气**，表达对现实的惋惜；虚拟语气中 be 动词的过去形式**所有人称一律用 were**（正式文体不接受 was）。此句还省略了主句（= I would be so happy），只留 if 从句表感叹。（[Ch.9](../../语法俱乐部/Chapter09.md) 语气·虚拟）

</GrammarTip>

**Q3**：*Alan will become the yardstick against which all future boyfriends will be measured.* 为什么 **which** 前面带着 against？可以写成 *the yardstick which all future boyfriends will be measured against* 吗？

<GrammarTip points="查看答案">

**答**：可以。which 指代 the yardstick，它在从句里作介词 **against** 的宾语（measure sb. against the yardstick 拿某人跟标尺比）。正式文体把"介词 + which"一起提到从句句首（against which）；口语则让 which 提前、介词**搁浅**在句尾（...measured against），两种语序都正确，语体不同。（[Ch.14](../../语法俱乐部/Chapter14.md) 关系从句/[Ch.10](../../语法俱乐部/Chapter10.md)）

</GrammarTip>
