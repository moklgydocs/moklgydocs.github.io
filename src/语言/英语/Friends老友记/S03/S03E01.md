# The One with the Princess Leia Fantasy
> *莱娅公主幻想曲*

The One With the Princess Leia Fantasy
> 有莱娅公主幻想的那个

<GrammarTip points="名词词组,所有格">

- **The One with the Princess Leia Fantasy**：《老友记》命名传统——**The One + 介词（台：介系词）短语**="……的那一集"（[Ch.2](../../语法俱乐部/Chapter02.md)/[Ch.10](../../语法俱乐部/Chapter10.md)）
- **the Princess Leia Fantasy**：**名词 + 名词**构成的复合名词词组——Princess Leia 作定语修饰 fantasy，"（关于）莱娅公主的幻想"（[Ch.2](../../语法俱乐部/Chapter02.md)）

</GrammarTip>

- **作动词宾语**：stopped crying / quit yankin' me / remember not having sex / it's worth mentioning
