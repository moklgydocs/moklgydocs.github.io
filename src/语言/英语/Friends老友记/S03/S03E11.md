<GrammarTip type="pattern" points="句型总复习,基本句型">

**本集头号句型：动词 + 宾语 + 补语的花式补位**（S+V+O+C，[Ch.1](../../语法俱乐部/Chapter01.md)）：

- **补语 = 形容词**：it makes me gassy / kill you dead / she got all happy
<p class="svoc"><span class="s">he</span> <span class="v">'s going to kill</span> <span class="o">you</span> <span class="c">dead</span></p>
- **补语 = 过去分词**：I need these hangers separated / has a lid stuck（被动含义）
<p class="svoc"><span class="s">I</span> <span class="v">need</span> <span class="o">these hangers</span> <span class="c">separated</span></p>
- **补语 = 原形动词**：you've got to make stuff happen
<p class="svoc"><span class="s">you</span> <span class="v">'ve got to make</span> <span class="o">stuff</span> <span class="c">happen</span></p>
- **补语 = 不定式**：ask him to step lightly / want you to know that... / get them to agree / I want only good things for you（介词短语补语变体）
<p class="svoc"><span class="v">ask</span> <span class="o">him</span> <span class="c">to step lightly</span></p>
- **形式宾语 it + 不定式真宾语**：it's gonna make **it** so much harder **for me to hate him**
<p class="svoc"><span class="s">it</span> <span class="v">'s gonna make</span> <span class="o">it</span> <span class="c">so much harder</span></p>
- **口诀**：补语紧跟宾语后；不定式太长的，用 it 占位、真身甩到句尾

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,动名词">

**本集"介词后面的动词一律 -ing"实战集锦**（[Ch.5](../../语法俱乐部/Chapter05.md)）：

- **end up + V-ing**：I end up apologizing to him / you ended up having sex with both of them
- **for + V-ing**：feel bad for whipping that kid's pretzel / in exchange for helping her / thank you for...
- **by + V-ing**：by walking Mira to the bathroom / by groping my sister
- **to 是介词（不是不定式）**：go back to talking to my friend / go back to enjoying your hamburger
<p class="svoc"><span class="s">I</span> <span class="v">'m going back to</span> <span class="o">talking to my friend</span></p>
- **stop / mind / start 等动词 + V-ing**：haven't stopped thinking about you / don't mind paying my dues / started talking about the fall line
- **口诀**：见介词就 -ing；拿不准 to 的身份时，换成名词试试——能说 go back to **it** 的，to 就是介词，后面跟 talking
