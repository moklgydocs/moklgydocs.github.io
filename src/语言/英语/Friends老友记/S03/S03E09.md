<GrammarTip points="动名词,语气">

- **instead of + 动名词**：**instead of watching football**"与其看橄榄球（不如……）"——of 是**介词**（台：介系词），后接动词必须用 V-ing（[Ch.10](../../语法俱乐部/Chapter10.md)/[Ch.5](../../语法俱乐部/Chapter05.md)）

- **it's your Thanksgiving too**：it 指"今天这个日子"；y'know = you know 插入语（[Ch.2](../../语法俱乐部/Chapter02.md)）

</GrammarTip>

<GrammarTip points="语气,省略">

- **We will (help)**：应答句用**助动词 will 替代整个动词短语**"我们会的"——助动词后承前省略；身体却不动，喜剧反差（[Ch.9](../../语法俱乐部/Chapter09.md)）

</GrammarTip>

- **put the marshmallows in concentric circles**：put + 宾语 + 处所状语"把……摆成同心圆"；concentric"同心的"（[Ch.10](../../语法俱乐部/Chapter10.md)）

**原句**：That's not true! I wanted to wear my bathrobe and eat peanut clusters all day. I wanted to start drinking in the morning. Don't say that I don't have goals!

**层次划分**：

- **That's not true**：<p class="svoc"><span class="s">That</span> <span class="v">'s not</span> <span class="c">true</span></p> 's = is，此处为**系动词**（台：连缀动词），形容词 true 作主语补语（[Ch.1](../../语法俱乐部/Chapter01.md)）

- **I wanted to start drinking**：**start + 动名词** drinking"开始喝"（[Ch.5](../../语法俱乐部/Chapter05.md)）
- **Don't say (that) I don't have goals**：否定祈使句 + 省略 that 的宾语从句"别说我没有目标"（[Ch.9](../../语法俱乐部/Chapter09.md)/[Ch.12](../../语法俱乐部/Chapter12.md)）

**语法要点**：want + 不定式 vs start + 动名词；否定祈使 + 宾语从句

<p class="svoc"><span class="v">Huddle</span> <span class="a">up</span></p>
- **Let's + 原形（咱们）**：Let's do it! / Let's bring it in. / Let's play some ball. / Let's just call this tie score.
<p class="svoc"><span class="v">Let's</span> <span class="v">call</span> <span class="o">this</span> <span class="c">tie score</span></p>
- **保留主语 you 的分工指令**（语气更强）：you sweep behind / you throw it down field / You let go!
<p class="svoc"><span class="s">you</span> <span class="v">sweep</span> <span class="a">behind</span></p>
- **否定祈使 Don't + 原形**：Don't say that I don't have goals! / Don't make me go long. / Don't feel bad.
<p class="svoc"><span class="v">Don't make</span> <span class="o">me</span> <span class="c">go long</span></p>
- **口诀**：祈使句无（显性）主语、动词一律原形；否定只在句首加 Don't

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,不定词,动词时态">

**本集 wanna / gonna 口语缩略对**（[Ch.4](../../语法俱乐部/Chapter04.md)/[Ch.3](../../语法俱乐部/Chapter03.md)）：

- **wanna = want to + 原形（想做）**：you wanna put the marshmallows in concentric circles / do you wanna play football? / you wanna win by cheating / you wanna play rough
<p class="svoc"><span class="s">you</span> <span class="v">wanna</span> <span class="o">［不定式宾语］</span></p>
- **gonna = be going to + 原形（将做/正要做）**：we're gonna play / how are we gonna get there? / I'm not gonna go through this with you again / you're gonna have to win it
<p class="svoc"><span class="s">we</span> <span class="v">'re gonna</span> <span class="v">play</span></p>
- **注意**：wanna/gonna 只用于口语；gonna 前面必须有 be（I'm gonna，不能省 am）；书面写作请还原为 want to / be going to

</GrammarTip>
