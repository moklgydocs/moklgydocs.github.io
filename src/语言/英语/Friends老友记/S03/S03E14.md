<GrammarTip type="pattern" points="句型总复习,语气">

**本集"情态动词 + have + 过去分词"**——对过去的推测与虚拟（[Ch.9](../../语法俱乐部/Chapter09.md)）：

- **must have + p.p.（对过去的肯定推测，"一定"）**：she must have hurt you pretty bad / you two must have been so cute running around on a barge
<p class="svoc"><span class="s">she</span> <span class="v">must have hurt</span> <span class="o">you</span> <span class="a">pretty bad</span></p>
- **should(n't) have + p.p.（"本该/本不该"）**：I probably should've told you about Ginger / I Shouldn't Have Left You That Way / I know it shouldn't have (freaked me out)
<p class="svoc"><span class="s">I</span> <span class="v">should've told</span> <span class="o">you</span></p>
- **would have + p.p.（虚拟过去，"本会"）**：five years ago I probably would've done anything to play with you
<p class="svoc"><span class="s">I</span> <span class="v">would've done</span> <span class="o">anything</span></p>
- **口诀**：must have done = 现在回头看"肯定发生了"；should have done = 事后检讨"该做没做"；would have done = 与过去事实相反"当时本会"

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,关系从句">

**本集定语从句（台：关系从句）：关系代词作宾语可省，作主语不可省**（[Ch.14](../../语法俱乐部/Chapter14.md)）：

- **作宾语→可省略**：all (that) I'm looking for / anything (that) we might have heard of / the girl (that) I was hiding from / the best kiss (that) I've had / this little bone (that) we didn't know it had / all (that) I have so far
<p class="svoc"><span class="s">the girl (that) I was hiding from</span></p>
- **作主语→不可省**：something **that** sounded like Ginger / a song **that**'s really, really sad / that thing **that**'s been dead for a gazillion years
<p class="svoc"><span class="s">something that sounded like Ginger</span></p>
- **口诀**：看关系代词在从句里"干不干活"——当主语干活（不可省），当宾语歇着（可省）

</GrammarTip>
