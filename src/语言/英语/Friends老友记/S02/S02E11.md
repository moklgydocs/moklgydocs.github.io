**原句回听**：<AudioButton src="/audio/episodes/S02/S02E11.mp3" start="53.88" duration="11.328" />

**原句**：Why shouldn't I be happy for you? What would it say about me if I couldn't revel in your joy? I'm revelling baby, believe me!

**层次划分**：

- **why shouldn't I be happy for you?**：否定疑问句表反问；be happy for sb"为某人高兴"（[Ch.9](../../语法俱乐部/Chapter09.md)）
- 主干：<p class="svoc"><span class="o">What</span> <span class="v">would</span> <span class="s">it</span> <span class="v">say</span> <span class="a">about me</span></p> 疑问句 what 作 say 的宾语被前置，还原为 it would say what about me——"那会说明我这人怎么样？"say 在此=「说明、显示」（[Ch.1](../../语法俱乐部/Chapter01.md)）
- **if I couldn't revel in your joy**：**虚拟语气**——与现在事实相反：条件副词从句用过去式 couldn't，主句用 would + 原形动词（would say）；revel in"陶醉于"（[Ch.9](../../语法俱乐部/Chapter09.md)/[Ch.13](../../语法俱乐部/Chapter13.md)/[Ch.10](../../语法俱乐部/Chapter10.md)）
- **I'm revelling, baby**：现在进行式表强调"我正在陶醉呢"——越强调越显勉强，配合下文手指被椅子卡住，谎言当场穿帮

**翻译**：嘿，我有什么理由不替你高兴？要是我不能为你的喜悦而狂欢，那我成什么人了？宝贝，我正在狂欢，真的！

**语法要点**：虚拟语气·与现在相反 = if + 过去式 → would + 原形（Ch.9）；否定疑问句表反问（Ch.9）；revel in（Ch.10）

</GrammarTip>

**原句**：They want me to do it, which is really cool, seeing as I've never catered before, and I really need the money, and this isn't a problem for you, is it?

**层次划分**：

**语法要点**：which 指代整句的非限定从句（Ch.14）；seeing as 原因从句（Ch.13）；附加疑问前否后肯（Ch.9）

<GrammarTip type="pattern" points="句型总复习,虚拟语气">

**本集虚拟语气大盘点——"要不是 / 要是……就好了"**（[Ch.9](../../语法俱乐部/Chapter09.md)）：

- **与现在相反：if + 过去式（were/didn't/couldn't）→ would + 原形**
  - What **would** it **say** about me if I **couldn't** revel in your joy?
  - If she **were** marrying a guy, none of you'**d expect** me to be there. / she'**d be** like the worst lesbian ever.
  - If you **didn't pour** the coffee, no one **would have** anything to drink.
- **与过去相反 / 对过去的假设：would have + 过去分词**
  - Otherwise the movie **would've been called** Silence of the Ducks.
  - If my parents **didn't want** me to marry you, no way that **would have stopped** me.（错综：从句表现在、主句落过去）
- **情态动词 + have done 表"（过去）本该/本可以"**
  - **couldn't** she have just **copied** my haircut?（反问表惋惜）
- **公式**：if + 过去式 → would do（现在反）；if + had done → would have done（过去反）；从句主句的"时间"可以错开，各管各的事实

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,不定式">

**本集不定式（台：不定词）三大后置用法**（[Ch.4](../../语法俱乐部/Chapter04.md)）：

- **疑问词 + 不定式（作宾语）**：I don't know **how to say this** / **what to tell you** / **what to do** / all about **how to work the cameras**
- **名词 + 不定式（后置定语，名词是不定式的宾语）**：a big dinosaur bone **to inspect** / anything **to drink** / enough time **to actually do it** / a tendency **to blame themselves**
- **序数词/排序词 + 不定式**：the first one **to get married** / the last **to get married**
- **附·不定式省略**：we'd like you to come, if you don't want **to**（省略重复内容、保留 to）；If you want (to).（连 to 一起省）

</GrammarTip>
