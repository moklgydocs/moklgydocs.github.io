**原句回听**：<AudioButton src="/audio/episodes/S02/S02E05.mp3" start="15.144" duration="13.008" />

**原句**：I figure if I'm always answering the phone, people'll think I don't have a life. Rodrigo never gets pinned.

**层次划分**：

- 主干：<p class="svoc"><span class="s">I</span> <span class="v">figure</span> <span class="o">(that) people'll think...</span></p> figure 后接宾语从句，that 省略
- **if I'm always answering the phone**：if 条件**状语从句**（台：副词从句），从句用现在式（此处为进行式）代替将来式；**be always + V-ing** 不表"正在"，而表"老是、总是"，带不耐烦色彩（[Ch.13](../../语法俱乐部/Chapter13.md)/[Ch.3](../../语法俱乐部/Chapter03.md)）
- **people'll think I don't have a life**：think 后接宾语从句（that 省略）；'ll = will，主句用将来式呼应 if 从句的"现在式代将来"；have a life"有自己的生活"（[Ch.12](../../语法俱乐部/Chapter12.md)）
- **Rodrigo never gets pinned**：**get + 过去分词** = 口语被动"被……"，相当于 is never pinned（摔跤"被压制双肩着地"）（[Ch.6](../../语法俱乐部/Chapter06.md)）

**翻译**：你看，我在试这种新的"电话筛选"玩法。你想啊，要是我总是秒接电话，人家会觉得我闲得没事干。我的天，罗德里戈从没被压制过。

**语法要点**：if 从句现在式代将来（Ch.13）；be always + 进行式表抱怨（Ch.3）；get + 过去分词表被动（Ch.6）

</GrammarTip>

**原句回听**：<AudioButton src="/audio/episodes/S02/S02E05.mp3" start="28.152" duration="16.296" />

**原句**：I don't know if you're still at this number, but I was just thinking about us, and how great it was. I know it's been three years, but I was kinda hoping we could hook up again.

**层次划分**：

- **I don't know if you're still at this number**：<p class="svoc"><span class="s">I</span> <span class="v">don't know</span> <span class="o">if you're still at this number</span></p> **if 引导宾语从句**（= whether"是否"），从句内陈述语序（[Ch.12](../../语法俱乐部/Chapter12.md)）
- **I was just thinking about us, and how great it was**：介词 about 后接两个宾语——名词 us 与名词从句 **how great it was**（感叹句变来的名词从句，语序不倒装）；**过去进行式 was thinking** 此处表"刚才一直在想"，语气更委婉（[Ch.12](../../语法俱乐部/Chapter12.md)/[Ch.3](../../语法俱乐部/Chapter03.md)）
- **it's been three years**：**现在完成式**——"（从那时到现在）已经三年了"，完成式把时间括弧拉到现在（[Ch.3](../../语法俱乐部/Chapter03.md)）
- **I was kinda hoping we could hook up again**：**过去进行式 was hoping + 过去式 could** 双重"后退"表委婉试探；kinda = kind of"有点"；hope 后接宾语从句（that 省略）；hook up"再续前缘"（[Ch.9](../../语法俱乐部/Chapter09.md)）
- **I barely had t he nerve to make this call**：⚠️ 原文 `t he` 应为 **the**（抄写断字）；have the nerve **to make**——不定式作后置定语修饰 nerve"打这个电话的勇气"；barely"几乎不"（[Ch.4](../../语法俱乐部/Chapter04.md)）
- **you know what I did**：what 引导宾语从句，陈述语序 what **I did**（[Ch.12](../../语法俱乐部/Chapter12.md)）

**翻译**：喂，我找鲍勃。我是简。我不知道你是不是还用这个号码，但我一直在想我们俩的事，想那时候有多好。唉，我知道都三年了，可我还是有点盼着我们能再续前缘。我好不容易才鼓起勇气打这个电话——你猜我怎么着？

**语法要点**：if/whether 宾语从句（Ch.12）；完成式 + 时段（Ch.3）；过去式/过去进行式表委婉（Ch.9）；感叹句变名词从句语序不倒装（Ch.12）

**层次划分**：

- 主干：<p class="svoc"><span class="a">Even though you do do a good Bob impression</span> <span class="s">I</span> <span class="v">'m thinkin'</span> <span class="o">(that)...she's gonna realize...</span></p>

- **Let me get that**：使役 let + 原形 get——抢单惯用语"这单我来（付）"；get 此处 = pay for（[Ch.1](../../语法俱乐部/Chapter01.md)）

**原句回听**：<AudioButton src="/audio/episodes/S02/S02E05.mp3" start="1100.832" duration="12.984" />

**原句**：I'm probably way out of line here. It has been 3 years, and you're probably seeing someone else now, but if we could just have one night together, just for old time's sake, one hot, steamy, wild night...

**层次划分**：

- **I'm probably way out of line**：**out of line** 惯用语"越界、过分"；way 程度副词"……得多"（[Ch.10](../../语法俱乐部/Chapter10.md)/[Ch.8](../../语法俱乐部/Chapter08.md)）
- **It has been 3 years**：⚠️ 原文 `I mean, It has been` 的 **It** 不应大写（抄写字母误大写）；**现在完成式**"已经三年了"（呼应开场她的 it's been three years）（[Ch.3](../../语法俱乐部/Chapter03.md)）
- **you're probably seeing someone else**：**现在进行式**表"（现阶段）正在交往"——see sb"和某人约会"；someone else"别人"，else 后置（[Ch.3](../../语法俱乐部/Chapter03.md)/[Ch.2](../../语法俱乐部/Chapter02.md)）
- **if we could just have one night together**：<p class="svoc"><span class="a">if we could just have one night together</span></p> if 从句用**过去式 could**——非真实条件的委婉试探，主句 (then...) 故意不说完，留无限遐想（[Ch.13](../../语法俱乐部/Chapter13.md)/[Ch.9](../../语法俱乐部/Chapter09.md)）
- **for old time's sake**：惯用语"看在往日情分上"——sake"缘故"，名词所有格 + sake（[Ch.2](../../语法俱乐部/Chapter02.md)）
- **one hot, steamy, wild night**：三个形容词并列定语收尾，省略号 = 未说完的条件句（[Ch.7](../../语法俱乐部/Chapter07.md)/[Ch.15](../../语法俱乐部/Chapter15.md)）

**翻译**：喂，是我。听着 Bob，我可能有点越界了。我是说，都三年了，你现在多半也有别人了。但要是我们能再共度一晚——就看在老交情的份上——一个火热、滚烫、放纵的夜晚……

**语法要点**：完成式 + 时段（Ch.3）；if + 过去式表委婉假设（Ch.13/Ch.9）；for old time's sake（Ch.2）

<GrammarTip type="pattern" points="句型总复习,使役动词">

**本集使役句型：make / let + 宾语 + 补语**（S+V+O+C，[Ch.1](../../语法俱乐部/Chapter01.md)）：

- **make + O + 原形动词**：your nice thing makes us **feel** this big / if it makes anybody **feel** better
<p class="svoc"><span class="s">it</span> <span class="v">makes</span> <span class="o">anybody</span> <span class="c">feel better</span></p>
- **make + O + 形容词**：it'll just make everyone **uncomfortable**
<p class="svoc"><span class="s">it</span> <span class="v">'ll make</span> <span class="o">everyone</span> <span class="c">uncomfortable</span></p>
- **make + O + 名词**：they made me **head of purchasing**
<p class="svoc"><span class="s">they</span> <span class="v">made</span> <span class="o">me</span> <span class="c">head of purchasing</span></p>
- **let + O + 原形**：**let** me **be** happy / **let** me **know** / **let** me **get** that / **let** me **grab** my jacket and **tell** you
- **注意**：补语一律**用原形/形容词/名词，不加 to**；改被动后 to 才回来（She was made **to** pay）

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,副词从句">

**本集 it's like / feel like + 从句句型**——口语"感觉就像……"（[Ch.13](../../语法俱乐部/Chapter13.md)）：

- **it's like + 从句**：it's **like** they're always saying "let's go here" / it's **like** we can't win with you guys
<p class="svoc"><span class="s">it</span> <span class="v">'s like</span> <span class="c">we can't win</span></p>
- **it's not like + 从句**：it's **not like** we can say anything about it（"又不是能说……"）
- **feel like + 从句**：we three **feel like** you guys don't get it / you **feel like** we hold you back / it just **feels like** charity
<p class="svoc"><span class="s">you</span> <span class="v">feel like</span> <span class="o">we hold you back</span></p>
- **注意**：此处的 like 已从介词"升级"为**连接词**接整句——口语万能；正式文体写作请换成 **as if / as though**

</GrammarTip>
