🎬 *Joey's new apartment. Everyone but Chandler is there. Joey has decorated the place with tons of tacky stuff.*
> 🎬 *乔伊的新公寓。除了钱德勒，所有人都在。乔伊用很多俗气的东西装饰了这个地方。*

🎯 **本场景语法重点**：口语缩约（whaddya / wanna / c'mon）/ 使役动词 make + 原形补语 / 建议句型 why don't you / 陈述语序疑问句

<AudioButton src="/audio/episodes/S02/S02E17.mp3" start="0.0" duration="9.288" /> **JOEY TRIBBIANI:** Huh? So <Note>whaddya think</Note>? Casa de Joey. Huh? I <Note>decorated it myself</Note>.

<GrammarTip points="口语缩约,动词时态">

- **whaddya think?**：**whaddya = what do you** 的口语连读拼写——"你觉得怎么样？"；疑问句靠 wh- 词开头，助动词 do 已缩进 whaddya 里（[Ch.9](../../语法俱乐部/Chapter09.md)）
- **Casa de Joey**：西班牙语"乔伊之家"（casa = house，de = of）， Joey 给公寓起的洋气名字
- **I decorated it myself**：一般过去式 decorated 表"（入住前）装饰好了"；**反身代词 myself** 作强调——"我亲手弄的"（[Ch.3](../../语法俱乐部/Chapter03.md)）

</GrammarTip>

**本集"使役/感官动词 + 宾语 + 补语"句型**（S+V+O+C，[Ch.1](../../语法俱乐部/Chapter01.md)）：

- **make + O + 原形**：it makes me wanna pee.（它让我想尿尿）
<p class="svoc"><span class="s">it</span> <span class="v">makes</span> <span class="o">me</span> <span class="c">(wanna) pee</span></p>
- **keep + O + 现在分词**：always keep them running.（让她们一直跑）
<p class="svoc"><span class="s">(you)</span> <span class="v">keep</span> <span class="o">them</span> <span class="c">running</span></p>
- **hear + O + 原形**：I've never heard myself sing before.（从没听过自己唱）
<p class="svoc"><span class="s">I</span> <span class="v">'ve heard</span> <span class="o">myself</span> <span class="c">sing</span></p>
- **see + O + 原形**：Did you see me write one down?（你看见我记了吗？）
<p class="svoc"><span class="s">you</span> <span class="v">saw</span> <span class="o">me</span> <span class="c">write one down</span></p>
- **口诀**：make/let/hear/see 后补语**用原形，不加 to**；keep 后补语**用 V-ing** 表"持续"

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,倒装">

**本集"陈述语序 + 升调"的口语疑问句**（不倒装，[Ch.22](../../语法俱乐部/Chapter22.md)）：

- **一般疑问不倒装**：you have a phone in here? / You really think he'd take me? / you think this is fun? / you like that show? / You don't keep it over here any more?
- **否定反问不倒装**：You don't like that show? / You hated me when we were kids?
- **回声疑问**：Get the what? / Blow drying what?（疑问词滞留原位）
- **对照**：正式疑问句才倒装——Do you have...? / Did she leave...?；口语升调疑问 = 陈述句 + 惊讶/求确认
- **同源句型**：how come Chandler didn't come?（how come 后也不倒装）/ why don't you ask him yourself?（建议句型）（[Ch.9](../../语法俱乐部/Chapter09.md)）
