🎯 **本场景语法重点**：宾语从句省略 that / 现在完成式 / 否定疑问句 / 时间状语从句 + 祈使句

<AudioButton src="/audio/episodes/S02/S02E16.mp3" start="0.0" duration="6.696" /> **JOEY TRIBBIANI:** Man this is weird. You <Note>ever realize</Note> <Note>Captain Crunch's eyebrows are actually on his hat</Note>?
> 伙计，这太奇怪了。你有没有意识到克朗奇船长的眉毛其实在他的帽子上？
<GrammarTip points="名词从句,省略">

<p class="svoc"><span class="s">You</span> <span class="v">(ever) realize</span> <span class="o">(that) Captain Crunch's eyebrows are actually on his hat</span></p>

- 口语疑问句常省略句首助动词：**(Do) you ever realize...?**，疑问靠升调（[Ch.9](../../语法俱乐部/Chapter09.md)）
- **Captain Crunch's eyebrows are actually on his hat**：realize 后接**宾语从句**（台：名词从句），连词 that 口语中常省。从句内部：eyebrows(S) + are(V) + on his hat(补语)；Captain Crunch's 名词所有格作定语（[Ch.12](../../语法俱乐部/Chapter12.md)/[Ch.2](../../语法俱乐部/Chapter02.md)）
- **actually on his hat**：副词 actually 修饰**介词**（台：介系词）短语，"竟然在帽子上"（[Ch.8](../../语法俱乐部/Chapter08.md)/[Ch.10](../../语法俱乐部/Chapter10.md)）

</GrammarTip>

<AudioButton src="/audio/episodes/S02/S02E16.mp3" start="6.696" duration="6.72" /> **CHANDLER BING:** <Note>That's what's weird</Note>? Joey, the man's <Note>been captain of a cereal</Note> <Note>for the last 40 years</Note>.
> 这就是奇怪的地方？乔伊，这个人在过去的40年里一直是一种麦片粥的船长。
<GrammarTip points="名词从句,动词时态">

<p class="svoc"><span class="s">That</span> <span class="v">'s</span> <span class="c">what's weird</span></p>

- **That's what's weird?**：That is + **表语从句**（台：名词从句）what's weird；what = the thing that"奇怪的地方"。句尾升调表"这就算奇怪了？"（[Ch.12](../../语法俱乐部/Chapter12.md)）
- **the man's been captain of a cereal**：man's = man **has**；现在完成式 has been"（从过去至今）一直当着"；**captain 表职位作补语，零冠词**（[Ch.3](../../语法俱乐部/Chapter03.md)/[Ch.2](../../语法俱乐部/Chapter02.md)）
- **for the last 40 years**：for + 时段是现在完成式的标志状语（[Ch.3](../../语法俱乐部/Chapter03.md)）

</GrammarTip>

**原句**：Well don't you see how gross that is? I mean that's like you using my toothbrush. You used my toothbrush?

**层次划分**：

- 主干：<p class="svoc"><span class="s">you</span> <span class="v">see</span> <span class="o">how gross that is</span></p> **don't you see...?** 否定疑问句表反问"难道你看不出……"（[Ch.9](../../语法俱乐部/Chapter09.md)）
- **how gross that is**：see 的宾语从句（台：名词从句），how + 形容词 gross 带感叹意味；从句内**陈述语序** that is，不倒装（[Ch.12](../../语法俱乐部/Chapter12.md)）
- **that's like you using my toothbrush**：like 介词"像"，后接**动名词复合结构** you using——逻辑主语 you + 动名词 using（[Ch.10](../../语法俱乐部/Chapter10.md)/[Ch.5](../../语法俱乐部/Chapter05.md)）
- **You used my toothbrush?**：陈述语序 + 升调 = 回声式反问"你（居然）用了我的牙刷？"（[Ch.9](../../语法俱乐部/Chapter09.md)）

**翻译**：你没看出来这有多恶心吗？我是说，那就跟你用我的牙刷一个道理。（乔伊面露愧色）你用过我的牙刷？

**语法要点**：否定疑问句表反问（Ch.9）；how 宾语从句不倒装（Ch.12）；逻辑主语 + 动名词（Ch.5）

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,基本句型">

**本集使役/感官句型：let / make / get / help + 宾语 + 补语**（S+V+O+C，[Ch.1](../../语法俱乐部/Chapter01.md)）：

- **let + O + 原形**：let's switch places / let me get that / would you let it go / let me live vicariously / lemme see
<p class="svoc"><span class="v">let</span> <span class="o">me</span> <span class="c">get that</span></p>
- **make + O + 原形**：you made me do this
<p class="svoc"><span class="s">you</span> <span class="v">made</span> <span class="o">me</span> <span class="c">do this</span></p>
- **get + O + 过去分词/副词**：get that heart tattooed / got her back in the chair / gonna get scored on
<p class="svoc"><span class="v">get</span> <span class="o">that heart</span> <span class="c">tattooed</span></p>
- **help + O + (to) 原形**：help me to grow（to 可省）
- **口诀**：let / make 后的补语**用原形、不加 to**；get + O + 过去分词 = "让某事被做/遭遇"

</GrammarTip>

<GrammarTip type="pattern" points="句型总复习,名词从句">

**本集名词从句（台：名词从句）三大高频用法**（[Ch.12](../../语法俱乐部/Chapter12.md)）：

- **宾语从句省 that**：You ever realize (that)...? / I can't believe you guys are getting tattoos / I hear he's got some 20-year-old twinkie / I think you should tell them
<p class="svoc"><span class="s">I</span> <span class="v">can't believe</span> <span class="o">(that) you guys are getting tattoos</span></p>
- **what 从句**：what Ross said / this is what I wanted / it's not what you think / sorry about what happened
<p class="svoc"><span class="s">it</span> <span class="v">'s not</span> <span class="c">what you think</span></p>
- **否定前移**：I don't think mom and dad would mind / I didn't think that was serious——not 在形式上否定主句，语义上否定从句
- **口诀**：think / believe / know / hear + (that) 从句；what = the thing that，从句内一律陈述语序

</GrammarTip>
