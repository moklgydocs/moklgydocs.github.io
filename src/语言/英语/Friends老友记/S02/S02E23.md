<GrammarTip points="存在句,主谓一致,原文勘误">

<p class="svoc"><span class="a">There</span> <span class="v">'s</span> <span class="s">only one bananna nut muffin left</span></p>

- **there's only one ... muffin**：There be 存在句"有……"，真正主语是后面的 one muffin（单数），故动词用 's（[Ch.2](../../语法俱乐部/Chapter02.md)/[Ch.11](../../语法俱乐部/Chapter11.md)）
- **left**：过去分词作后置定语 = that is left"剩下的"（[Ch.6](../../语法俱乐部/Chapter06.md)/[Ch.17](../../语法俱乐部/Chapter17.md)）
- ⚠️ 原文 **bananna** 应为 **banana**（抄写多字母）

</GrammarTip>

<GrammarTip type="long" points="长难句,关系从句,介词">

**原句回听**：<AudioButton src="/audio/episodes/S02/S02E23.mp3" start="45.84" duration="3.168" />

**原句**：Ryan, that guy I went out with, who's in the Navy.

**层次划分**：

- 主干不是句子，而是同位语结构：**Ryan = that guy**，后面挂两个定语从句（台：关系从句）层层修饰 guy
- **(that) I went out with**：限定性关系从句，关系代词 that 作介词 with 的宾语，故**可省略**；go out with sb"和某人约会"，介词 with 留在句尾（[Ch.14](../../语法俱乐部/Chapter14.md)/[Ch.10](../../语法俱乐部/Chapter10.md)）
- **who's in the Navy**：**非限定性**关系从句（前面有逗号），补充说明"他在海军服役"；who 在从句中作主语，**不可省略**，也不能换成 that（[Ch.14](../../语法俱乐部/Chapter14.md)）
- **in the Navy**：介词（台：介系词）短语"在海军（服役）"（[Ch.10](../../语法俱乐部/Chapter10.md)）

**翻译**：就是 Ryan——跟我约会过的那个家伙，在海军服役的那个。

**语法要点**：关系代词作宾语可省、作主语不可省（Ch.14）；限定 vs 非限定从句的逗号（Ch.14）；go out with（Ch.10）

**本集句型总复习①：现在完成式——"经验"与"持续到现在"**（[Ch.3](../../语法俱乐部/Chapter03.md)）：

- **表经验（做过/没做过）**：I've had it. / I've **never** had it. / My grandmother's **never** had chicken pox. / I **never** had 'em.（美口语用过去式替代）

<p class="svoc"><span class="s">I</span> <span class="v">have spent</span> <span class="o">the last eight months</span> <span class="a">in a steel tube</span></p>
- **配最高级/ever**：the most romantic disease I've **ever** had.

**本集句型总复习②：虚拟语气——与事实相反的 if / wish / would**（[Ch.9](../../语法俱乐部/Chapter09.md)）：

- **if + 过去式 … would + 原形**（与现在事实相反）：If I **had** one wish, it **would be** to build a time machine. / if I **could** just fire Joseph, I **would**.
<p class="svoc"><span class="a">If I had one wish</span> <span class="s">it</span> <span class="v">would be</span> <span class="c">to build a time machine</span></p>
- **wish + 从句用过去式**：you could just wish that I **didn't have** them now.
- **含蓄虚拟（无 if）**：otherwise the ocean **would be** on the wrong side. / Your face **could be** covered with lochs, I **wouldn't** care. / so I **would have** you believe.
- **口诀**：虚拟不只靠 if——otherwise、wish、as if 语境里，动词一律"退一个时态"（现在→过去）。
