# 健康检查端点

Docker、Nginx、K8s、负载均衡器都需要知道你的应用是否健康。ASP.NET Core 内置了健康检查机制。

---

## 最简健康检查

```csharp
// Program.cs
builder.Services.AddHealthChecks();

app.MapHealthChecks("/health");
```

```bash
curl http://localhost:5000/health
# Healthy
# HTTP 200 = 健康
# HTTP 503 = 不健康
```

够用了吗？不够。你的应用跑着但数据库挂了，`/health` 还是返回 200。

## 检查依赖服务

```bash
# 安装 NuGet 包
dotnet add package AspNetCore.HealthChecks.NpgSql
dotnet add package AspNetCore.HealthChecks.Redis
dotnet add package AspNetCore.HealthChecks.Uris
```

```csharp
builder.Services.AddHealthChecks()
    // 检查 PostgreSQL
    .AddNpgSql(
        builder.Configuration.GetConnectionString("Default")!,
        name: "postgresql",
        tags: new[] { "db", "ready" })
    // 检查 Redis
    .AddRedis(
        builder.Configuration["Redis:Connection"]!,
        name: "redis",
        tags: new[] { "cache", "ready" })
    // 检查外部 API
    .AddUrlGroup(
        new Uri("https://sso.company.com/health"),
        name: "sso-server",
        tags: new[] { "external" });
```

## /health vs /ready

```csharp
// /health — 存活检查（Liveness）
// 应用进程还活着吗？
app.MapHealthChecks("/health", new HealthCheckOptions
{
    // 不检查任何依赖，只要进程在就返回 Healthy
    Predicate = _ => false
});

// /ready — 就绪检查（Readiness）
// 应用能处理请求吗？（依赖的数据库、Redis 都正常？）
app.MapHealthChecks("/ready", new HealthCheckOptions
{
    Predicate = check => check.Tags.Contains("ready")
});
```

```
Docker HEALTHCHECK → 用 /health（进程存活）
负载均衡器         → 用 /ready （能处理请求）
K8s livenessProbe  → 用 /health
K8s readinessProbe → 用 /ready
```

## 返回详细信息

默认只返回 "Healthy" 字符串，加个 ResponseWriter 返回 JSON 详情：

```csharp
using Microsoft.Extensions.Diagnostics.HealthChecks;
using System.Text.Json;

app.MapHealthChecks("/ready", new HealthCheckOptions
{
    Predicate = check => check.Tags.Contains("ready"),
    ResponseWriter = WriteDetailedResponse
});

static async Task WriteDetailedResponse(HttpContext context, HealthReport report)
{
    context.Response.ContentType = "application/json";

    var result = new
    {
        status = report.Status.ToString(),
        duration = report.TotalDuration.TotalMilliseconds + "ms",
        checks = report.Entries.Select(e => new
        {
            name = e.Key,
            status = e.Value.Status.ToString(),
            duration = e.Value.Duration.TotalMilliseconds + "ms",
            description = e.Value.Description,
            error = e.Value.Exception?.Message
        })
    };

    await context.Response.WriteAsync(
        JsonSerializer.Serialize(result, new JsonSerializerOptions { WriteIndented = true }));
}
```

```bash
curl http://localhost:5000/ready
```

```json
{
  "status": "Healthy",
  "duration": "125ms",
  "checks": [
    {
      "name": "postgresql",
      "status": "Healthy",
      "duration": "15ms",
      "description": null,
      "error": null
    },
    {
      "name": "redis",
      "status": "Healthy",
      "duration": "3ms",
      "description": null,
      "error": null
    }
  ]
}
```

## 与 Docker 对接

```dockerfile
# Dockerfile
HEALTHCHECK --interval=30s --timeout=5s --retries=3 --start-period=15s \
    CMD curl -f http://localhost:5000/health || exit 1
```

```yaml
# docker-compose.yml
services:
  erp-api:
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:5000/health"]
      interval: 30s
      timeout: 5s
      retries: 3
      start_period: 15s
```

## 与 Nginx 对接

```nginx
upstream erp-api {
    server 127.0.0.1:5000 max_fails=3 fail_timeout=30s;
    # Nginx 检测到 3 次失败后，30秒内不再转发到这个节点
}

# 或者用 nginx_upstream_check_module（需要编译安装）
```

## 自定义健康检查

```csharp
public class DiskSpaceHealthCheck : IHealthCheck
{
    public Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken cancellationToken = default)
    {
        var drive = new DriveInfo("/");
        var freeSpacePercent = (double)drive.AvailableFreeSpace / drive.TotalSize * 100;

        if (freeSpacePercent < 5)
            return Task.FromResult(HealthCheckResult.Unhealthy($"磁盘剩余 {freeSpacePercent:F1}%"));

        if (freeSpacePercent < 15)
            return Task.FromResult(HealthCheckResult.Degraded($"磁盘剩余 {freeSpacePercent:F1}%"));

        return Task.FromResult(HealthCheckResult.Healthy($"磁盘剩余 {freeSpacePercent:F1}%"));
    }
}

// 注册
builder.Services.AddHealthChecks()
    .AddCheck<DiskSpaceHealthCheck>("disk-space", tags: new[] { "infra" });
```

## 速查

| 端点 | 用途 | 检查内容 |
|------|------|---------|
| `/health` | 存活探针 | 进程在就 200 |
| `/ready` | 就绪探针 | DB + Redis 正常才 200 |
| Docker HEALTHCHECK | 容器健康 | 调 `/health` |
| 负载均衡 | 转发决策 | 调 `/ready` |
