# .NET + 数据库 + Redis 编排

最典型的三件套：.NET Web API + PostgreSQL + Redis。一个 compose 文件搞定开发/测试/生产环境。

---

## 完整的 docker-compose.yml

```yaml
services:
  # ========== .NET API ==========
  erp-api:
    image: registry.company.com/erp-api:${APP_VERSION:-latest}
    container_name: erp-api
    restart: unless-stopped
    ports:
      - "5000:5000"
    environment:
      - ASPNETCORE_ENVIRONMENT=Production
      - ASPNETCORE_URLS=http://+:5000
      - ConnectionStrings__Default=Host=postgres;Port=5432;Database=erp;Username=postgres;Password=${DB_PASSWORD}
      - Redis__Connection=redis:6379,password=${REDIS_PASSWORD}
    volumes:
      - ./config/appsettings.Production.json:/app/appsettings.Production.json:ro
      - erp-logs:/app/logs
    depends_on:
      postgres:
        condition: service_healthy
      redis:
        condition: service_healthy
    networks:
      - app-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:5000/health"]
      interval: 30s
      timeout: 5s
      retries: 3
      start_period: 15s
    logging:
      driver: json-file
      options:
        max-size: "50m"
        max-file: "3"

  # ========== PostgreSQL ==========
  postgres:
    image: postgres:16
    container_name: postgres
    restart: unless-stopped
    ports:
      - "5432:5432"    # 开发时开放，生产可以去掉
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: ${DB_PASSWORD}
      POSTGRES_DB: erp
      TZ: Asia/Shanghai
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./init-sql:/docker-entrypoint-initdb.d    # 首次启动执行的初始化SQL
    networks:
      - app-net
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 5s
      timeout: 3s
      retries: 10
    logging:
      driver: json-file
      options:
        max-size: "50m"
        max-file: "3"

  # ========== Redis ==========
  redis:
    image: redis:7-alpine
    container_name: redis
    restart: unless-stopped
    ports:
      - "6379:6379"    # 开发时开放，生产可以去掉
    command: redis-server --requirepass ${REDIS_PASSWORD} --maxmemory 256mb --maxmemory-policy allkeys-lru
    volumes:
      - redis-data:/data
    networks:
      - app-net
    healthcheck:
      test: ["CMD", "redis-cli", "-a", "${REDIS_PASSWORD}", "ping"]
      interval: 5s
      timeout: 3s
      retries: 10
    logging:
      driver: json-file
      options:
        max-size: "20m"
        max-file: "3"

volumes:
  pgdata:
  redis-data:
  erp-logs:

networks:
  app-net:
    driver: bridge
```

## .env 文件

```bash
# .env（和 docker-compose.yml 同目录）
APP_VERSION=v1.2.3
DB_PASSWORD=MySecretPassword123
REDIS_PASSWORD=RedisPass456
```

::: danger
`.env` 文件包含密码，**不要提交到 Git**。在 `.gitignore` 里加上 `.env`。服务器上手动创建。
:::

## 操作命令

```bash
# 进入项目目录
cd /opt/apps/erp

# 启动所有服务（后台）
docker compose up -d

# 查看状态
docker compose ps

# 查看日志
docker compose logs -f              # 所有服务
docker compose logs -f erp-api      # 只看 API
docker compose logs --tail 50 postgres  # 最近50行

# 重启单个服务
docker compose restart erp-api

# 停止所有服务
docker compose down

# 停止并删除数据卷（⚠️ 数据库数据会丢失！）
docker compose down -v

# 重新构建并启动（代码更新后）
docker compose up -d --build

# 拉取最新镜像并重启
docker compose pull
docker compose up -d

# 只启动某个服务
docker compose up -d postgres redis
```

## 加上 Nginx 反向代理

四件套的典型架构：

```yaml
services:
  # Nginx 反向代理
  nginx:
    image: nginx:alpine
    container_name: nginx
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro
      - ./nginx/conf.d:/etc/nginx/conf.d:ro
      - ./nginx/ssl:/etc/nginx/ssl:ro
      - nginx-logs:/var/log/nginx
    depends_on:
      - erp-api
    networks:
      - app-net

  erp-api:
    # ... 同上，但去掉 ports（不直接对外暴露）
    expose:
      - "5000"    # 只在 Docker 网络内可见
    # ports 不要了
```

Nginx 配置 `nginx/conf.d/erp.conf`：

```nginx
server {
    listen 80;
    server_name erp.company.com;

    location / {
        proxy_pass http://erp-api:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 部署更新流程

```bash
# 1. 更新 .env 里的版本号
vim .env
# APP_VERSION=v1.2.4

# 2. 拉取新镜像
docker compose pull erp-api

# 3. 重启 API（数据库和Redis不受影响）
docker compose up -d erp-api

# 4. 检查
docker compose ps
docker compose logs -f erp-api --tail 20
curl http://localhost:5000/health
```
