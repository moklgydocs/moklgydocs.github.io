# Jenkins 安装与初始化

Docker 部署 Jenkins，5 分钟搞定。装完插件、配好安全，就能用了。

---

## Docker Compose 部署

### docker-compose.yml

```yaml
services:
  jenkins:
    image: jenkins/jenkins:lts
    container_name: jenkins
    restart: unless-stopped
    ports:
      - "8080:8080"       # Web 界面
      - "50000:50000"     # Agent 通信
    volumes:
      - jenkins-data:/var/jenkins_home
      - /var/run/docker.sock:/var/run/docker.sock    # 让 Jenkins 能调用 Docker
      - /usr/bin/docker:/usr/bin/docker               # Docker 命令
    environment:
      - TZ=Asia/Shanghai
      - JAVA_OPTS=-Xmx1024m -Xms512m
    user: root    # 需要 root 才能访问 docker.sock
    deploy:
      resources:
        limits:
          memory: 2G
    logging:
      driver: json-file
      options:
        max-size: "50m"
        max-file: "3"

volumes:
  jenkins-data:
```

### 启动

```bash
mkdir -p /opt/apps/jenkins && cd /opt/apps/jenkins

# 启动
docker compose up -d

# 查看日志（等待初始化完成）
docker compose logs -f jenkins
```

### 获取初始密码

```bash
# 方式1：从日志里看
docker compose logs jenkins | grep "initial admin password" -A 5

# 方式2：直接读文件
docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword
```

### 首次配置向导

```
1. 浏览器打开 http://jenkins-server:8080
2. 输入初始密码
3. 选择 "Install suggested plugins"（装推荐插件）
4. 等 5-10 分钟插件安装完
5. 创建管理员账户
6. 配置 Jenkins URL: http://jenkins.company.com:8080
7. 完成！
```

## 推荐安装的插件

首次安装后，还需要额外装几个：

```
Jenkins → 系统管理 → 插件管理 → Available plugins

必装：
  ✅ GitLab Plugin           → GitLab 集成
  ✅ Docker Pipeline          → Pipeline 里用 Docker
  ✅ Pipeline: Stage View     → 流水线可视化
  ✅ Blue Ocean               → 现代化 UI
  ✅ Publish Over SSH          → SSH 部署到服务器
  ✅ Credentials Binding      → 凭据绑定

推荐：
  ✅ Timestamper              → 日志加时间戳
  ✅ AnsiColor                → 彩色日志
  ✅ Workspace Cleanup        → 构建后清理
  ✅ Build Timeout            → 构建超时控制
  ✅ Rebuild                  → 重新构建按钮
```

## 安全配置

### 关闭匿名访问

```
系统管理 → 安全配置（Configure Global Security）
  → Authorization: Matrix-based security
  → 取消 Anonymous 的所有权限
  → 给管理员勾选所有权限
  → Save
```

### 配置用户

```
系统管理 → 用户管理
  → 创建用户：开发者、运维等
  → 分配权限（基于角色或矩阵）
```

### API Token

```
用户 → Settings → API Token
  → Generate New Token
  → 用于脚本调用 Jenkins API
```

## 系统配置

### 全局工具

```
系统管理 → 全局工具配置（Global Tool Configuration）

Git:
  → Name: Default
  → Path: git（Docker 里已有）

Docker:
  → Name: docker
  → Install automatically（或指定路径）

# .NET SDK 不在这里配，用 Docker 构建
```

### 环境变量

```
系统管理 → 系统配置（Configure System）

全局属性 → Environment variables:
  → DOCKER_REGISTRY=registry.company.com
  → DEPLOY_USER=deploy
```

### 邮件通知

```
系统管理 → 系统配置 → Extended E-mail Notification

SMTP server: smtp.company.com
SMTP Port: 465
Credentials: 创建邮箱账号凭据
Use SSL: ✅
Default Recipients: dev-team@company.com
```

## 备份

```bash
#!/bin/bash
# backup-jenkins.sh
BACKUP_DIR="/opt/backup/jenkins"
DATE=$(date +%Y%m%d)
mkdir -p $BACKUP_DIR

# 备份 Jenkins 数据
docker exec jenkins tar -czf /tmp/jenkins-backup.tar.gz \
  -C /var/jenkins_home \
  config.xml \
  credentials.xml \
  secrets/ \
  users/ \
  jobs/ \
  nodes/

docker cp jenkins:/tmp/jenkins-backup.tar.gz $BACKUP_DIR/jenkins-${DATE}.tar.gz
docker exec jenkins rm /tmp/jenkins-backup.tar.gz

# 清理 7 天前
find $BACKUP_DIR -mtime +7 -delete
echo "Jenkins 备份完成"
```

## 硬件要求

```
规模          CPU    内存    磁盘
─────────────────────────────
1-5 个 Job    2核    2GB    50GB
5-20 个 Job   4核    4GB    100GB
20+ 个 Job    4核+   8GB    200GB
```

::: tip
Jenkins 的内存主要被 Java 吃掉。如果经常 OOM，调大 `JAVA_OPTS=-Xmx2048m`。
:::
