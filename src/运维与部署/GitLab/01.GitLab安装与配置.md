# GitLab 安装与配置

自建 GitLab，代码不出公司。Docker 部署最省事，10 分钟搞定。

---

## Docker Compose 部署

### docker-compose.yml

```yaml
services:
  gitlab:
    image: gitlab/gitlab-ce:latest
    container_name: gitlab
    restart: unless-stopped
    hostname: gitlab.company.com
    ports:
      - "80:80"
      - "443:443"
      - "2222:22"       # SSH 用 2222 避免和宿主机冲突
    volumes:
      - gitlab-config:/etc/gitlab
      - gitlab-logs:/var/log/gitlab
      - gitlab-data:/var/opt/gitlab
    environment:
      GITLAB_OMNIBUS_CONFIG: |
        external_url 'http://gitlab.company.com'
        gitlab_rails['time_zone'] = 'Asia/Shanghai'

        # SSH 端口
        gitlab_rails['gitlab_shell_ssh_port'] = 2222

        # 邮件配置（用于通知和密码重置）
        gitlab_rails['smtp_enable'] = true
        gitlab_rails['smtp_address'] = "smtp.company.com"
        gitlab_rails['smtp_port'] = 465
        gitlab_rails['smtp_user_name'] = "gitlab@company.com"
        gitlab_rails['smtp_password'] = "EmailPassword"
        gitlab_rails['smtp_domain'] = "company.com"
        gitlab_rails['smtp_authentication'] = "login"
        gitlab_rails['smtp_enable_starttls_auto'] = false
        gitlab_rails['smtp_tls'] = true
        gitlab_rails['gitlab_email_from'] = 'gitlab@company.com'
        gitlab_rails['gitlab_email_display_name'] = 'GitLab'

        # 减少内存占用（小团队够用）
        puma['worker_processes'] = 2
        sidekiq['max_concurrency'] = 10
        prometheus_monitoring['enable'] = false
        grafana['enable'] = false
    shm_size: '256m'
    deploy:
      resources:
        limits:
          memory: 4G
    logging:
      driver: json-file
      options:
        max-size: "100m"
        max-file: "3"

volumes:
  gitlab-config:
  gitlab-logs:
  gitlab-data:
```

### 启动

```bash
# 创建目录
mkdir -p /opt/apps/gitlab && cd /opt/apps/gitlab

# 创建 docker-compose.yml（内容如上）
# 启动（首次启动需要 3-5 分钟初始化）
docker compose up -d

# 查看启动日志
docker compose logs -f gitlab

# 等看到 "gitlab Reconfigured!" 就好了
```

### 获取初始密码

```bash
# GitLab 首次启动会生成 root 密码
docker exec gitlab cat /etc/gitlab/initial_root_password

# 浏览器打开 http://gitlab.company.com
# 用户名: root
# 密码: 上面获取的密码

# ⚠️ 登录后立即修改 root 密码！
# ⚠️ 密码文件 24 小时后自动删除
```

## 基础配置

登录后在 **Admin Area** → **Settings** 里配置：

### 关闭注册

```
Settings → General → Sign-up restrictions
→ 取消勾选 "Sign-up enabled"
→ Save changes

# 用户由管理员手动创建
```

### 修改默认分支名

```
Settings → Repository → Default branch
→ 改为 main 或 master
```

### 项目大小限制

```
Settings → General → Account and limit
→ Maximum size per repository: 2048 (MB)
→ Maximum attachment size: 50 (MB)
```

## 备份与恢复

### 手动备份

```bash
# 执行备份
docker exec gitlab gitlab-backup create

# 备份文件在 /var/opt/gitlab/backups/
docker exec gitlab ls /var/opt/gitlab/backups/
# 1713100800_2024_04_14_16.10.0_gitlab_backup.tar

# 复制到宿主机
docker cp gitlab:/var/opt/gitlab/backups/1713100800_2024_04_14_16.10.0_gitlab_backup.tar /opt/backup/
```

### 自动备份

```bash
#!/bin/bash
# backup-gitlab.sh
BACKUP_DIR="/opt/backup/gitlab"
mkdir -p $BACKUP_DIR

# 执行备份
docker exec gitlab gitlab-backup create STRATEGY=copy

# 复制最新备份
LATEST=$(docker exec gitlab ls -t /var/opt/gitlab/backups/ | head -1)
docker cp gitlab:/var/opt/gitlab/backups/$LATEST $BACKUP_DIR/

# 同时备份配置和密钥（这两个不在 gitlab-backup 里）
docker exec gitlab tar -cf - /etc/gitlab/gitlab-secrets.json /etc/gitlab/gitlab.rb | \
  gzip > $BACKUP_DIR/gitlab-config-$(date +%Y%m%d).tar.gz

# 清理 7 天前的备份
find $BACKUP_DIR -mtime +7 -delete

echo "备份完成: $BACKUP_DIR"
```

```bash
# crontab 每天凌晨 2 点备份
0 2 * * * /opt/scripts/backup-gitlab.sh >> /var/log/gitlab-backup.log 2>&1
```

### 恢复

```bash
# 1. 停止相关服务
docker exec gitlab gitlab-ctl stop puma
docker exec gitlab gitlab-ctl stop sidekiq

# 2. 恢复备份
docker exec gitlab gitlab-backup restore BACKUP=1713100800_2024_04_14_16.10.0

# 3. 恢复配置
docker cp gitlab-config-20240414.tar.gz gitlab:/tmp/
docker exec gitlab bash -c "cd / && tar -xzf /tmp/gitlab-config-20240414.tar.gz"

# 4. 重启
docker restart gitlab
```

## HTTPS 配置

```ruby
# GITLAB_OMNIBUS_CONFIG 里修改
external_url 'https://gitlab.company.com'

# 自动 Let's Encrypt
letsencrypt['enable'] = true
letsencrypt['contact_emails'] = ['admin@company.com']

# 或者手动指定证书
nginx['ssl_certificate'] = "/etc/gitlab/ssl/gitlab.company.com.pem"
nginx['ssl_certificate_key'] = "/etc/gitlab/ssl/gitlab.company.com.key"
```

```yaml
# docker-compose.yml 挂载证书
volumes:
  - ./ssl:/etc/gitlab/ssl:ro
```

## 硬件要求

```
用户数       CPU    内存     磁盘
─────────────────────────────
1-10人       2核    4GB     50GB
10-50人      4核    8GB     100GB
50-100人     8核    16GB    200GB
```

::: tip
GitLab 吃内存，4GB 是最低要求。内存不够会非常卡。
:::
