# Nginx 安装与基础配置

Nginx 是最流行的 Web 服务器/反向代理。高性能、低内存、配置简洁。

---

## 安装方式

### Docker（推荐）

```yaml
# docker-compose.yml
services:
  nginx:
    image: nginx:alpine
    container_name: nginx
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
      - ./conf.d:/etc/nginx/conf.d:ro
      - ./ssl:/etc/nginx/ssl:ro
      - nginx-logs:/var/log/nginx
    logging:
      driver: json-file
      options:
        max-size: "50m"
        max-file: "3"

volumes:
  nginx-logs:
```

### CentOS/RHEL

```bash
sudo yum install -y epel-release
sudo yum install -y nginx
sudo systemctl enable --now nginx
```

### Ubuntu

```bash
sudo apt update
sudo apt install -y nginx
sudo systemctl enable --now nginx
```

## 目录结构

```
/etc/nginx/
├── nginx.conf              ← 主配置文件
├── conf.d/                 ← 站点配置目录（推荐放这里）
│   ├── erp.conf
│   └── sso.conf
├── sites-available/        ← 可用站点（Ubuntu）
├── sites-enabled/          ← 启用站点（Ubuntu，符号链接）
├── mime.types              ← MIME 类型映射
└── ssl/                    ← 证书目录（自建）
```

## 配置语法

```nginx
# nginx.conf 基本结构

# 全局配置
user nginx;
worker_processes auto;          # CPU 核心数
error_log /var/log/nginx/error.log warn;
pid /run/nginx.pid;

# 事件配置
events {
    worker_connections 1024;    # 每个 worker 最大连接数
    multi_accept on;
}

# HTTP 配置
http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    # 日志格式
    log_format main '$remote_addr - $remote_user [$time_local] '
                    '"$request" $status $body_bytes_sent '
                    '"$http_referer" "$http_user_agent"';
    access_log /var/log/nginx/access.log main;

    # 性能
    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout 65;

    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml;
    gzip_min_length 1000;

    # 引入站点配置
    include /etc/nginx/conf.d/*.conf;
}
```

## 常用命令

```bash
# 检查配置语法
nginx -t

# 重新加载配置（不停服务）
nginx -s reload

# 停止
nginx -s stop

# Docker 环境
docker exec nginx nginx -t
docker exec nginx nginx -s reload
```

## 一个完整的站点配置

```nginx
# /etc/nginx/conf.d/erp.conf
server {
    listen 80;
    server_name erp.company.com;

    # HTTP 跳转 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name erp.company.com;

    # SSL
    ssl_certificate /etc/nginx/ssl/erp.company.com.pem;
    ssl_certificate_key /etc/nginx/ssl/erp.company.com.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    # 请求限制
    client_max_body_size 50m;

    # 日志
    access_log /var/log/nginx/erp-access.log;
    error_log /var/log/nginx/erp-error.log;

    # 反向代理到 .NET 应用
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection keep-alive;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }

    # 静态文件
    location /static/ {
        alias /opt/apps/erp/wwwroot/static/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```
