# 镜像与容器管理

Docker 日常操作就这些命令，用熟了就够了。

---

## 镜像操作

```bash
# 拉取镜像
docker pull mcr.microsoft.com/dotnet/aspnet:8.0
docker pull postgres:16
docker pull redis:7-alpine

# 查看本地镜像
docker images
docker images --format "table {{.Repository}}\t{{.Tag}}\t{{.Size}}"

# 搜索镜像（Docker Hub）
docker search nginx

# 删除镜像
docker rmi erp-api:v1.0
docker rmi abc123def456          # 用 IMAGE ID

# 批量删除
docker rmi $(docker images -q erp-api)           # 删 erp-api 所有版本
docker image prune                                # 删除悬空镜像（<none>）
docker image prune -a                             # 删除所有未使用的镜像

# 导出/导入（离线环境传镜像）
docker save -o erp-api-v1.0.tar erp-api:v1.0     # 导出
docker load -i erp-api-v1.0.tar                   # 导入

# 查看镜像详情
docker inspect erp-api:v1.0
docker history erp-api:v1.0      # 查看每一层
```

## 容器操作

### 启动容器

```bash
# 最简单的启动
docker run -d --name erp-api erp-api:v1.0

# 完整的生产级启动
docker run -d \
  --name erp-api \
  --restart=unless-stopped \
  -p 5000:5000 \
  -v /opt/apps/erp-api/appsettings.Production.json:/app/appsettings.Production.json:ro \
  -v /opt/apps/erp-api/logs:/app/logs \
  -e ASPNETCORE_ENVIRONMENT=Production \
  --memory=512m \
  --cpus=1.5 \
  --log-opt max-size=50m \
  --log-opt max-file=3 \
  erp-api:v1.0
```

参数解释：

| 参数 | 作用 |
|------|------|
| `-d` | 后台运行 |
| `--name` | 容器名 |
| `--restart=unless-stopped` | 崩溃自动重启（手动 stop 的不重启） |
| `-p 5000:5000` | 端口映射（宿主机:容器） |
| `-v 宿主机路径:容器路径` | 挂载数据卷 |
| `:ro` | 只读挂载 |
| `-e KEY=VALUE` | 环境变量 |
| `--memory=512m` | 内存限制 |
| `--cpus=1.5` | CPU 限制 |

### 容器生命周期

```bash
# 查看运行中的容器
docker ps
docker ps -a                     # 包括已停止的
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"

# 停止/启动/重启
docker stop erp-api
docker start erp-api
docker restart erp-api

# 删除容器
docker stop erp-api && docker rm erp-api
docker rm -f erp-api             # 强制删除（包括运行中的）

# 批量清理已停止的容器
docker container prune
```

### 进入容器

```bash
# 进入容器的 shell
docker exec -it erp-api /bin/bash
docker exec -it erp-api /bin/sh     # alpine 镜像用 sh

# 在容器里执行单条命令
docker exec erp-api dotnet --info
docker exec erp-api cat /app/appsettings.json
docker exec erp-api ls -la /app/

# 查看容器内的进程
docker top erp-api
```

### 查看日志

```bash
# 查看容器日志
docker logs erp-api
docker logs erp-api --tail 100        # 最近 100 行
docker logs erp-api -f                # 实时追踪
docker logs erp-api --since 1h        # 最近 1 小时
docker logs erp-api --since "2024-04-14T10:00:00"  # 指定时间
```

### 资源监控

```bash
# 实时资源使用
docker stats
docker stats erp-api sso-server      # 只看指定容器

# CONTAINER   CPU %   MEM USAGE / LIMIT   MEM %   NET I/O       BLOCK I/O
# erp-api     2.35%   256MiB / 512MiB     50.0%   1.2MB/500KB   10MB/5MB

# 查看容器详情
docker inspect erp-api
docker inspect erp-api --format '{{.State.Status}}'    # 运行状态
docker inspect erp-api --format '{{.NetworkSettings.IPAddress}}'  # 容器IP
```

## 容器更新流程

部署新版本的标准流程：

```bash
#!/bin/bash
APP_NAME="erp-api"
IMAGE="registry.company.com/erp-api"
VERSION="v1.2.3"

# 1. 拉取新镜像
docker pull ${IMAGE}:${VERSION}

# 2. 停掉旧容器
docker stop ${APP_NAME}
docker rm ${APP_NAME}

# 3. 用新镜像启动
docker run -d \
  --name ${APP_NAME} \
  --restart=unless-stopped \
  -p 5000:5000 \
  -v /opt/apps/erp-api/appsettings.Production.json:/app/appsettings.Production.json:ro \
  -v /opt/apps/erp-api/logs:/app/logs \
  -e ASPNETCORE_ENVIRONMENT=Production \
  ${IMAGE}:${VERSION}

# 4. 检查
sleep 3
docker ps | grep ${APP_NAME}
curl -s http://localhost:5000/health
```

## 清理磁盘

```bash
# 查看 Docker 磁盘占用
docker system df
# TYPE            TOTAL   ACTIVE  SIZE      RECLAIMABLE
# Images          15      5       3.2GB     2.1GB (65%)
# Containers      5       3       500MB     200MB (40%)
# Build Cache     10              1.5GB     1.5GB

# 一键清理未使用的资源
docker system prune           # 清理停止的容器 + 悬空镜像 + 未使用网络
docker system prune -a        # 再加上所有未使用的镜像（⚠️ 慎用）
docker system prune --volumes # 再加上未使用的数据卷

# 只清理特定类型
docker container prune        # 停止的容器
docker image prune            # 悬空镜像
docker volume prune           # 未使用的数据卷
docker builder prune          # 构建缓存
```
