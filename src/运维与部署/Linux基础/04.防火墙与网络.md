# 防火墙与网络

应用跑起来了，浏览器访问 404？十有八九是防火墙没开端口。

---

## firewalld（CentOS 7/8 默认）

```bash
# 查看状态
systemctl status firewalld
firewall-cmd --state

# 开放端口
firewall-cmd --zone=public --add-port=5000/tcp --permanent
firewall-cmd --zone=public --add-port=80/tcp --permanent
firewall-cmd --zone=public --add-port=443/tcp --permanent

# 重载使生效
firewall-cmd --reload

# 查看已开放的端口
firewall-cmd --zone=public --list-ports

# 移除端口
firewall-cmd --zone=public --remove-port=5000/tcp --permanent
firewall-cmd --reload

# 一次性开一段端口
firewall-cmd --zone=public --add-port=5000-5010/tcp --permanent

# 开放服务（比端口号更语义化）
firewall-cmd --zone=public --add-service=http --permanent
firewall-cmd --zone=public --add-service=https --permanent
```

::: tip --permanent 参数
不加 `--permanent` 只临时生效，重启后失效。加了必须 `--reload` 才生效。
:::

### .NET 应用常开端口

```bash
# Kestrel 端口（被 Nginx 代理，通常不需要对外开放）
# 5000, 5001

# 对外只开这几个
firewall-cmd --zone=public --add-port=80/tcp --permanent     # HTTP
firewall-cmd --zone=public --add-port=443/tcp --permanent    # HTTPS
firewall-cmd --zone=public --add-port=22/tcp --permanent     # SSH（默认已开）
firewall-cmd --reload
```

## 网络排查命令

### 端口检查

```bash
# 看某个端口谁在监听
ss -tlnp | grep 5000
# 或
netstat -tlnp | grep 5000
# t=TCP, l=LISTEN, n=数字显示, p=显示进程

# 看所有监听端口
ss -tlnp

# 看某个进程监听了哪些端口
ss -tlnp | grep dotnet
```

### 连通性测试

```bash
# ping（测网络可达）
ping 192.168.1.100

# telnet（测端口是否打开）
telnet 192.168.1.100 5000
# 连上了 = 端口开放
# Connection refused = 端口没监听
# 超时 = 防火墙挡了

# curl（测 HTTP 接口）
curl http://localhost:5000/health
curl -v http://192.168.1.100:5000/api/test  # -v 看详细过程
curl -o /dev/null -s -w "%{http_code}" http://localhost:5000/health  # 只看状态码
```

### DNS 排查

```bash
# 域名解析
nslookup erp.company.com
dig erp.company.com

# 本机 hosts 文件（优先级高于 DNS）
cat /etc/hosts
# 127.0.0.1   localhost
# 192.168.1.100 erp.company.com
```

### 网络接口和路由

```bash
# 查看IP地址
ip addr show
# 或 ifconfig（旧）

# 查看路由表
ip route show

# 查看网关
ip route | grep default
```

## 排错流程

```
浏览器访问不了？按这个顺序查：

1. 应用跑起来了吗？
   → systemctl status erp-api
   → curl http://localhost:5000/health

2. 端口在监听吗？
   → ss -tlnp | grep 5000

3. 本机能访问吗？
   → curl http://127.0.0.1:5000/health

4. 防火墙开了吗？
   → firewall-cmd --list-ports

5. 安全组开了吗？（云服务器）
   → 去云控制台检查安全组规则

6. Nginx 配了吗？
   → nginx -t && curl http://localhost:80

7. DNS 解析对吗？
   → nslookup your-domain.com
```
