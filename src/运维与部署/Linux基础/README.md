# Linux 基础

后端开发绕不开 Linux。不需要你成为运维专家，但你得能在服务器上查日志、改配置、排问题、写部署脚本。

这个系列只讲 .NET 后端工程师日常会碰到的 Linux 知识，不扯用不上的。
