# Linux 学习指南

> 从命令行基础到内核原理，从三剑客文本处理到生产级运维实战 —— 一份覆盖 Linux 全栈的学习与实践指南

Linux 是现代软件基础设施的基石 —— 从云服务器到容器编排，从嵌入式设备到超级计算机，Linux 无处不在。本专栏以系统化的路径，带你从基础命令行走向内核级理解，从文本处理三剑客到生产环境实战。

## 📚 专栏结构

| 篇章 | 主题 | 核心内容 |
|------|------|----------|
| [01 · Linux 基础](01_Linux基础/) | 入门基石 | 文件系统、用户权限、软件包、网络基础 |
| [02 · Linux 进阶](02_Linux进阶/) | 系统管理 | 进程管理、磁盘管理、网络配置、Shell脚本 |
| [03 · Linux 高级](03_Linux高级/) | 深入原理 | Systemd、安全加固、性能分析、容器化 |
| [04 · 三剑客](04_三剑客/) | 文本处理 | grep/sed/awk 精通、正则表达式、实战案例 |
| [05 · 生产级实战](05_生产级实战/) | 运维实战 | 服务器初始化、Nginx部署、监控告警、故障排查 |
| [06 · 内核级](06_内核级/) | 底层原理 | 进程调度、内存管理、文件系统、网络协议栈 |
| [07 · Nginx](07_Nginx/) | Web服务器与反向代理 | 基础架构、核心配置、虚拟主机、反向代理与负载均衡、HTTPS、限流、缓存优化、OpenResty、生产实战 |
