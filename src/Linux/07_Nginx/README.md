# 07 · Nginx

Nginx 是当今最流行的高性能 Web 服务器与反向代理，从基础配置到生产级架构，本专栏系统讲解 Nginx 核心原理与实战技巧。

## 本章内容

- [01 · Nginx 基础与架构](01_Nginx基础与架构/) — 概述与生态、安装与版本选型、架构与请求处理流程、配置文件体系
- [02 · 核心配置指令](02_核心配置指令/) — 配置结构与指令语法、变量体系、模块化架构、配置最佳实践与调试
- [03 · HTTP 核心与虚拟主机](03_HTTP核心与虚拟主机/) — 请求处理流程、虚拟主机、location 匹配、子域名解析、rewrite 与重定向
- [04 · 反向代理与负载均衡](04_反向代理与负载均衡/) — 反向代理原理、proxy_pass 详解、负载均衡策略、健康检查、长连接与连接池
- [05 · SSL/TLS 与 HTTPS](05_SSL_TLS与HTTPS/) — TLS 握手原理、证书管理、HTTPS 安全加固、Let's Encrypt 自动化
- [06 · 限流与访问控制](06_限流与访问控制/) — 请求限流与连接限流、IP 与地理位置控制、认证与 JWT、WAF 防护、灰度发布
- [07 · 缓存与性能优化](07_缓存与性能优化/) — 静态文件与 Gzip、浏览器缓存、代理缓存、性能调优参数、内核级优化
- [08 · 高级特性与扩展](08_高级特性与扩展/) — 日志体系、Stream 四层代理、gRPC 代理、OpenResty 与 Lua、Service Mesh
- [09 · 生产级实战](09_生产级实战/) — 生产部署方案、监控告警、故障排查、容器化与 K8s Ingress、速查手册
