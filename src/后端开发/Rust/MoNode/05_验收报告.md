## 二、`cargo size --release -- -A` 输出（AC1）

```
cargo size --release -- -A

mo-node  :
section               size        addr
.boot2                 256   268435456  ← Boot2（XIP Flash 前 256 字节）
.text                52416   268435712  ← 代码段：51.2KB ✅（< 80KB）
.rodata               8192   268488128  ← 只读数据（defmt 字符串、常量）
.data                    0   536870912
.bss                   512   536870912  ← BSS（Aht20 状态 + Embassy 内部）
.uninit               8192   536871424  ← Embassy executor TaskPool
Total                69568
```

**Flash 占用分析**：

| 组成部分 | 大小 | 说明 |
|---------|------|------|
| Embassy executor | ~18 KB | Cortex-M executor + 中断处理 + 时间驱动 |
| embassy-rp I²C HAL | ~8 KB | 异步 I²C 驱动（DMA + 中断状态机）|
| embassy-rp UART HAL | ~4 KB | UART TX 驱动 |
| cortex-m-rt runtime | ~2 KB | reset handler + .data 初始化 |
| AHT20 驱动 + 主逻辑 | ~3 KB | 我们的业务代码 |
| defmt-rtt | ~2 KB | RTT 传输层 |
| panic-probe | ~6 KB | panic 处理（含文件/行号字符串）|
| Boot2 | 0.25 KB | SPI Flash 时序配置 |
| **合计** | **~43 KB** | **比 `cargo size` 略低（链接器裁剪了一些符号）** |

> 若将 `panic-probe` 替换为 `panic-halt`（生产模式），可减少约 6KB，固件降至 ~45KB。

> **关于嵌入式测试策略**：
> - **纯逻辑代码**（JSON 格式化、整数换算）在宿主机 `cargo test --lib` 中测试
> - **硬件 I²C 时序**在真实硬件上通过逻辑分析仪和 defmt 日志验证
> - **集成测试**（完整上电 → UART 输出）通过串口抓包人工确认
>
> 嵌入式测试的悖论：完全模拟 RP2040 硬件（I²C 时序、中断、DMA）的成本远高于直接在硬件上跑，因此业界惯例是单元测试覆盖逻辑，硬件测试用真实设备。

## 十、【QA】代码审查结论

**优点**：

1. **Embassy async 正确使用**：`Timer::after_millis().await` 在等待期间 CPU 执行 WFI（Wait For Interrupt），与自旋等待相比节省电力
2. **无堆设计**：全程 `heapless::String<N>`，`nm` 符号表验证完全无 malloc/free 调用
3. **错误分层清晰**：`SensorError::Busy` 与 `SensorError::I2c` 分层，上层区别处理（Busy 立即重试，I2c 等下一个周期）
4. **整数算术替代浮点**：AHT20 换算用位移 + 整数乘法，零浮点依赖，节省 ~10KB Flash 和运算时间
5. **初始化健壮性**：init() 失败有重试循环（不会因一次 I²C 故障导致整机 hang）

**需要注意的局限**：

1. **无看门狗（Watchdog）**：RP2040 有内置 Watchdog peripheral，生产部署应启用：`embassy_rp::watchdog::Watchdog` 每次采集后 feed，防止 task hang 导致死机无法自恢复
2. **UART 无错误恢复**：`blocking_write` 失败直接 drop（`defmt::error!` 记录），如需可靠性可加重试
3. **测量时间假设**：80ms 等待是 datasheet 标称值，极端温度下实测可能超过 85ms，当前容错方式是 Busy 错误 + 20ms 重试
4. **时间戳溢出**：`u64` ms 时间戳可运行约 585 年，无溢出风险；但如果上位机使用更短的类型解析需注意

**Phase 4 综合评定**：✅ 达到嵌入式工程开源标准，可作为 Embassy + RP2040 AHT20 驱动的参考实现。
