# 搭建基于 OpenIddict 的生产级单点登录鉴权中心

## 整体架构设计

```
┌─────────────────────────────────────────────────────────────────┐
│                        SSO 鉴权中心                              │
├─────────────────────────────────────────────────────────────────┤
│  API Layer (Controllers)                                         │
│  ├── AuthorizationController  (OAuth2/OIDC 端点)                 │
│  ├── AccountController        (登录/注册/密码)                    │
│  ├── ClientManageController   (客户端管理API)                     │
│  ├── ScopeManageController    (Scope管理API)                     │
│  ├── UserManageController     (用户管理API)                       │
│  └── TenantController         (多租户管理API - 可选)              │
├─────────────────────────────────────────────────────────────────┤
│  Application Layer (Services)                                    │
│  ├── AuthorizationService     (授权逻辑)                         │
│  ├── ClientAppService         (客户端CRUD)                       │
│  ├── ScopeAppService          (Scope CRUD)                       │
│  ├── UserAppService           (用户CRUD)                         │
│  └── ConsentService           (用户授权同意)                      │
├─────────────────────────────────────────────────────────────────┤
│  Domain Layer                                                    │
│  ├── Entities (User, Role, Permission, Tenant...)               │
│  ├── Events   (UserCreated, ClientRegistered...)                │
│  └── Specs    (查询规约)                                         │
├─────────────────────────────────────────────────────────────────┤
│  Infrastructure Layer                                            │
│  ├── EF Core + OpenIddict EF Stores                             │
│  ├── Identity (ASP.NET Core Identity)                           │
│  ├── Caching  (Redis / Memory)                                  │
│  └── Configuration (DB-backed + Options binding)                │
└─────────────────────────────────────────────────────────────────┘
```

---

## 第一步：项目结构搭建

```
Sso/
├── src/
│   ├── Sso.AuthServer/              # 主 Web API 项目
│   │   ├── Controllers/
│   │   ├── Program.cs
│   │   └── appsettings.json
│   ├── Sso.Application/             # 应用服务层
│   │   ├── Contracts/               # DTO / 接口
│   │   └── Services/
│   ├── Sso.Domain/                  # 领域层
│   │   ├── Entities/
│   │   ├── Repositories/
│   │   └── Events/
│   ├── Sso.Infrastructure/          # 基础设施
│   │   ├── Data/
│   │   ├── Identity/
│   │   └── OpenIddict/
│   └── Sso.Shared/                  # 共享内核
│       ├── Options/
│       ├── Extensions/
│       └── Results/
└── tests/
```

**创建解决方案：**

```bash
dotnet new sln -n Sso
dotnet new webapi -n Sso.AuthServer -o src/Sso.AuthServer
dotnet new classlib -n Sso.Application -o src/Sso.Application
dotnet new classlib -n Sso.Domain -o src/Sso.Domain
dotnet new classlib -n Sso.Infrastructure -o src/Sso.Infrastructure
dotnet new classlib -n Sso.Shared -o src/Sso.Shared

dotnet sln add src/Sso.AuthServer
dotnet sln add src/Sso.Application
dotnet sln add src/Sso.Domain
dotnet sln add src/Sso.Infrastructure
dotnet sln add src/Sso.Shared

# 引用关系
cd src/Sso.AuthServer && dotnet add reference ../Sso.Application ../Sso.Infrastructure
cd ../Sso.Application && dotnet add reference ../Sso.Domain ../Sso.Shared
cd ../Sso.Infrastructure && dotnet add reference ../Sso.Domain ../Sso.Shared
cd ../Sso.Domain && dotnet add reference ../Sso.Shared
```
