# SQL Server 进阶训练营

从"会写 CRUD"到"精通 SQL"的系统化进阶路径。面向 .NET 后端工程师，以 SQL Server 为主，涵盖查询能力、性能优化、企业级规范、复杂业务建模和实战练习。

```
│ ❌ 性能优化      │                              │ ✅ 复杂业务建模   │
│ ❌ 索引设计      │                              │ ✅ 面试无压力    │
└─────────────────┘                              └─────────────────┘
```
