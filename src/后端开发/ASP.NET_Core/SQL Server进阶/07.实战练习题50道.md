### 题1：每个分类销量前3的商品 ⭐⭐

```
要求：输出分类名、商品名、销量、排名
同销量算并列
```

::: details 参考答案
```sql
SELECT CategoryName, ProductName, TotalSold, Rnk
FROM (
    SELECT c.CategoryName, p.ProductName, SUM(oi.Quantity) AS TotalSold,
        DENSE_RANK() OVER(PARTITION BY c.CategoryId ORDER BY SUM(oi.Quantity) DESC) AS Rnk
    FROM OrderItems oi
    INNER JOIN Products p ON oi.ProductId = p.ProductId
    INNER JOIN Categories c ON p.CategoryId = c.CategoryId
    GROUP BY c.CategoryId, c.CategoryName, p.ProductId, p.ProductName
) t WHERE Rnk <= 3;
```
:::

### 题2：每个用户最近3次订单 ⭐⭐

```
要求：每个用户最近3笔已完成订单的金额和日期
```

::: details 参考答案
```sql
SELECT * FROM (
    SELECT UserId, OrderDate, TotalAmount,
        ROW_NUMBER() OVER(PARTITION BY UserId ORDER BY OrderDate DESC) AS Rn
    FROM Orders WHERE Status = 'Completed'
) t WHERE Rn <= 3;
```

### 题3：累计销售额和占比 ⭐⭐

```
要求：按日期统计每日销售额、累计销售额、累计占总额的百分比
```

::: details 参考答案
```sql
;WITH DailySales AS (
    SELECT CAST(OrderDate AS DATE) AS SaleDate, SUM(TotalAmount) AS DayAmount
    FROM Orders WHERE Status IN ('Paid','Shipped','Completed')
    GROUP BY CAST(OrderDate AS DATE)
)
SELECT SaleDate, DayAmount,
    SUM(DayAmount) OVER(ORDER BY SaleDate) AS RunningTotal,
    CAST(SUM(DayAmount) OVER(ORDER BY SaleDate) * 100.0 / SUM(DayAmount) OVER() AS DECIMAL(5,2)) AS CumulativePercent
FROM DailySales ORDER BY SaleDate;
```

### 题4：月度环比增长率 ⭐⭐⭐

```
要求：每月销售额、上月销售额、环比增长率
```

::: details 参考答案
```sql
;WITH Monthly AS (
    SELECT YEAR(OrderDate) AS Y, MONTH(OrderDate) AS M, SUM(TotalAmount) AS Amount
    FROM Orders WHERE Status <> 'Cancelled'
    GROUP BY YEAR(OrderDate), MONTH(OrderDate)
)
SELECT Y, M, Amount,
    LAG(Amount) OVER(ORDER BY Y, M) AS PrevMonth,
    CAST((Amount - LAG(Amount) OVER(ORDER BY Y, M)) * 100.0 / NULLIF(LAG(Amount) OVER(ORDER BY Y, M), 0) AS DECIMAL(5,2)) AS GrowthRate
FROM Monthly ORDER BY Y, M;
```

### 题5：连续登录7天以上的用户 ⭐⭐⭐

::: details 参考答案
```sql
;WITH LoginDays AS (
    SELECT DISTINCT UserId, CAST(LoginTime AS DATE) AS LoginDate FROM UserLogins
),
Grouped AS (
    SELECT UserId, LoginDate,
        DATEADD(DAY, -ROW_NUMBER() OVER(PARTITION BY UserId ORDER BY LoginDate), LoginDate) AS Grp
    FROM LoginDays
)
SELECT UserId, MIN(LoginDate) StartDate, MAX(LoginDate) EndDate, COUNT(*) ConsecutiveDays
FROM Grouped GROUP BY UserId, Grp
HAVING COUNT(*) >= 7 ORDER BY ConsecutiveDays DESC;
```

::: details 参考答案
```sql
SELECT UserId,
    MIN(OrderDate) AS FirstOrder,
    MAX(OrderDate) AS LastOrder,
    DATEDIFF(DAY, MIN(OrderDate), MAX(OrderDate)) AS DaySpan,
    COUNT(*) AS OrderCount

ORDER BY DaySpan DESC;
```

### 题8：每笔订单与用户历史平均对比 ⭐⭐⭐

```
要求：每笔订单金额、该用户截至此笔的历史平均金额、是否高于平均
```

::: details 参考答案
```sql
SELECT OrderId, UserId, OrderDate, TotalAmount,
    AVG(TotalAmount) OVER(PARTITION BY UserId ORDER BY OrderDate ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS RunningAvg,
    CASE WHEN TotalAmount > AVG(TotalAmount) OVER(PARTITION BY UserId ORDER BY OrderDate ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) THEN '高于' ELSE '低于' END AS VsAvg
FROM Orders WHERE Status = 'Completed' ORDER BY UserId, OrderDate;
```

### 题9：第二高薪资的部门版 ⭐⭐

```

```

::: details 参考答案
```sql
;WITH UserSpend AS (
    SELECT u.UserId, u.UserName, u.City, SUM(o.TotalAmount) AS TotalSpend,
        DENSE_RANK() OVER(PARTITION BY u.City ORDER BY SUM(o.TotalAmount) DESC) AS Rnk
    FROM Users u INNER JOIN Orders o ON u.UserId = o.UserId
    WHERE o.Status = 'Completed'
    GROUP BY u.UserId, u.UserName, u.City

SELECT City, UserName, TotalSpend FROM UserSpend WHERE Rnk = 2;
```

::: details 参考答案

```sql
;WITH UserTotal AS (
    SELECT UserId, SUM(TotalAmount) AS Total
    FROM Orders WHERE Status = 'Completed' GROUP BY UserId
),
Bucketed AS (
    SELECT *, NTILE(4) OVER(ORDER BY Total) AS Quartile FROM UserTotal
)
SELECT 
    Quartile,
    COUNT(*) AS UserCount,
    MIN(Total) AS MinSpend,
    MAX(Total) AS MaxSpend,
    AVG(Total) AS AvgSpend
```

### 题16：电商漏斗转化率 ⭐⭐⭐

```
要求：计算每天的 浏览→加购→下单→支付 的转化率
```

::: details 参考答案
```sql
SELECT 
    CAST(EventTime AS DATE) AS D,
    COUNT(DISTINCT CASE WHEN EventType='view' THEN UserId END) AS Views,
    COUNT(DISTINCT CASE WHEN EventType='add_cart' THEN UserId END) AS Carts,
    COUNT(DISTINCT CASE WHEN EventType='order' THEN UserId END) AS Ords,
    COUNT(DISTINCT CASE WHEN EventType='payment' THEN UserId END) AS Pays,
    CAST(COUNT(DISTINCT CASE WHEN EventType='payment' THEN UserId END) * 100.0 /
         NULLIF(COUNT(DISTINCT CASE WHEN EventType='view' THEN UserId END), 0) AS DECIMAL(5,2)) AS ConversionRate
FROM UserEvents
GROUP BY CAST(EventTime AS DATE) ORDER BY D;
```
:::

### 题17：RFM 客户分层 ⭐⭐⭐⭐

```
R(Recency): 最近一次消费距今天数
F(Frequency): 消费次数
M(Monetary): 消费总额
按每个维度分3档（高中低），输出用户RFM标签
```

::: details 参考答案
```sql
;WITH RFM AS (
    SELECT UserId,
        DATEDIFF(DAY, MAX(OrderDate), GETDATE()) AS Recency,
        COUNT(*) AS Frequency,
        SUM(TotalAmount) AS Monetary
    FROM Orders WHERE Status = 'Completed'
    GROUP BY UserId
),
Scored AS (
    SELECT *,
        NTILE(3) OVER(ORDER BY Recency ASC) AS R_Score,   -- 越近越高
        NTILE(3) OVER(ORDER BY Frequency DESC) AS F_Score,
        NTILE(3) OVER(ORDER BY Monetary DESC) AS M_Score
    FROM RFM
)
SELECT *, CONCAT(R_Score, F_Score, M_Score) AS RFM_Tag,
    CASE 
        WHEN R_Score >= 2 AND F_Score >= 2 AND M_Score >= 2 THEN '高价值客户'
        WHEN R_Score >= 2 AND F_Score >= 2 THEN '忠实客户'
        WHEN R_Score >= 2 AND M_Score >= 2 THEN '潜力客户'
        WHEN R_Score <= 1 AND F_Score <= 1 THEN '流失客户'
        ELSE '一般客户'
    END AS CustomerType
FROM Scored;
```

### 题20：用户留存率分析 ⭐⭐⭐⭐

```
要求：计算次日留存、7日留存、30日留存
```

::: details 参考答案
```sql
;WITH FirstLogin AS (
    SELECT UserId, MIN(CAST(LoginTime AS DATE)) AS FirstDate FROM UserLogins GROUP BY UserId
),
RetentionCheck AS (
    SELECT f.UserId, f.FirstDate,
        MAX(CASE WHEN DATEDIFF(DAY, f.FirstDate, CAST(l.LoginTime AS DATE)) = 1 THEN 1 ELSE 0 END) AS Day1,
        MAX(CASE WHEN DATEDIFF(DAY, f.FirstDate, CAST(l.LoginTime AS DATE)) BETWEEN 1 AND 7 THEN 1 ELSE 0 END) AS Day7,
        MAX(CASE WHEN DATEDIFF(DAY, f.FirstDate, CAST(l.LoginTime AS DATE)) BETWEEN 1 AND 30 THEN 1 ELSE 0 END) AS Day30
    FROM FirstLogin f
    LEFT JOIN UserLogins l ON f.UserId = l.UserId
    GROUP BY f.UserId, f.FirstDate
)
SELECT 
    COUNT(*) AS TotalNewUsers,
    SUM(Day1) AS RetainedDay1,
    CAST(SUM(Day1) * 100.0 / COUNT(*) AS DECIMAL(5,2)) AS RetentionDay1,
    SUM(Day7) AS RetainedDay7,
    CAST(SUM(Day7) * 100.0 / COUNT(*) AS DECIMAL(5,2)) AS RetentionDay7,
    SUM(Day30) AS RetainedDay30,
    CAST(SUM(Day30) * 100.0 / COUNT(*) AS DECIMAL(5,2)) AS RetentionDay30
FROM RetentionCheck;
```

### 题31：优化慢查询——给出索引建议 ⭐⭐⭐

```sql
-- 以下查询在100万数据量下需要5秒，请优化
SELECT o.OrderId, o.OrderDate, o.TotalAmount, u.UserName
FROM Orders o INNER JOIN Users u ON o.UserId = u.UserId
WHERE o.Status = 'Pending' AND o.OrderDate >= '2024-01-01'
ORDER BY o.OrderDate DESC;
```

::: details 参考答案
```sql
-- 创建筛选+覆盖索引
CREATE NONCLUSTERED INDEX IX_Orders_Pending
ON Orders(OrderDate DESC)
INCLUDE (OrderId, TotalAmount, UserId)
WHERE Status = 'Pending';

-- Users表主键已有索引，不需要额外索引
-- 优化后：Index Seek → Nested Loops → Clustered Index Seek
```
:::
