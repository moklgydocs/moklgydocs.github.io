# 命名规范与代码风格

SQL 没有编译器帮你检查风格，全靠团队自觉。写得乱的 SQL 几个月后自己都看不懂，更别说交给别人维护了。这篇整理了一套在 .NET + SQL Server 项目中落地过的规范。

## 对象命名

### 表名

- **PascalCase，单数名词**：`Order`、`Customer`、`ProductCategory`
- 不要用复数：`Orders` ❌（虽然 EF Core 默认加 s，但 SQL 层面单数更清晰）
- 不要加前缀：`tbl_Order` ❌、`T_Order` ❌（这种前缀完全是噪音）
- 业务模块可以用 Schema 隔离：`Sales.Order`、`HR.Employee`

### 列名

- **PascalCase**：`CustomerId`、`OrderDate`、`TotalAmount`
- 主键统一叫 `Id`，外键叫 `关联表名Id`：`CustomerId`、`ProductId`
- 布尔列用 `Is` 开头：`IsActive`、`IsDeleted`
- 日期列带后缀：`CreateTime`、`UpdateTime`、`ExpireDate`
- 不要用保留字做列名：`Name`、`Order`、`Group`、`Key`、`Value` 这些虽然能用方括号 `[Name]`，但还是换个名字比较好，比如 `CustomerName`

### 索引

```
IX_{表名}_{列1}_{列2}           -- 普通索引
UIX_{表名}_{列}                 -- 唯一索引
FIX_{表名}_{描述}               -- 筛选索引
IX_{表名}_{列1}_INC_{列2}_{列3}  -- 带 INCLUDE 的
```

### 存储过程

```
sp_{模块}_{动作}{对象}
-- sp_Order_GetByCustomer
-- sp_Report_MonthlySales
-- sp_User_UpdateProfile
```

不要用 `sp_` 前缀——SQL Server 内部存储过程用 `sp_`，你的自定义过程用了同名前缀，SQL Server 每次都会先到 master 数据库找一遍再找你的数据库。性能微小但能避免就避免。

**更好**：用 `usp_`（user stored procedure）或者直接不要前缀。

### 视图

```
v_{描述}
-- v_ActiveCustomers
-- v_OrderSummary
```

### 函数

```
fn_{描述}
-- fn_GetAge
-- fn_CalcTax
```

## SQL 代码风格

### 关键字大写

```sql
-- ✅
SELECT c.CustomerName, o.OrderDate, o.Amount
FROM Orders o
INNER JOIN Customers c ON o.CustomerId = c.CustomerId
WHERE o.Status = 1
ORDER BY o.OrderDate DESC;

-- ❌ 大小写混用
select C.customerName, o.orderdate
from orders O inner join customers c on O.customerid = C.customerid
```

所有 SQL 关键字大写：`SELECT`、`FROM`、`WHERE`、`JOIN`、`ON`、`ORDER BY`、`GROUP BY`、`HAVING`、`INSERT`、`UPDATE`、`DELETE`、`CREATE`、`ALTER`、`DROP`。

### 每行一个查询元素

```sql
-- ✅ 一行一个列，一行一个条件
SELECT
    c.CustomerName,
    c.Phone,
    o.OrderDate,
    o.Amount
FROM Orders o
INNER JOIN Customers c ON o.CustomerId = c.CustomerId
WHERE o.Status = 1
    AND o.OrderDate >= '2024-01-01'
    AND o.Amount > 100
ORDER BY o.OrderDate DESC;

-- ❌ 全挤一行
SELECT c.CustomerName, c.Phone, o.OrderDate, o.Amount FROM Orders o INNER JOIN Customers c ON o.CustomerId = c.CustomerId WHERE o.Status = 1 AND o.OrderDate >= '2024-01-01' AND o.Amount > 100 ORDER BY o.OrderDate DESC;
```

### 表别名

- 用有意义的缩写：`o` 代表 Orders，`c` 代表 Customers
- 多表查询必须用别名，不要裸列名

```sql
-- ❌ 不知道 Name 是哪个表的
SELECT Name, OrderDate FROM Orders JOIN Customers ON ...

-- ✅
SELECT c.CustomerName, o.OrderDate
FROM Orders o
JOIN Customers c ON o.CustomerId = c.CustomerId;
```

### JOIN 写法

```sql
-- ✅ 显式 JOIN
SELECT ...
FROM Orders o
INNER JOIN Customers c ON o.CustomerId = c.CustomerId
LEFT JOIN ShippingRecords s ON o.OrderId = s.OrderId;

-- ❌ 隐式 JOIN（老写法，不直观）
SELECT ...
FROM Orders o, Customers c
WHERE o.CustomerId = c.CustomerId;
```

### 缩进

主句关键字左对齐，子句缩进 4 个空格：

```sql
SELECT
    c.CustomerName,
    COUNT(*) AS OrderCount,
    SUM(o.Amount) AS TotalAmount
FROM Orders o
INNER JOIN Customers c
    ON o.CustomerId = c.CustomerId
WHERE o.Status = 1
    AND o.OrderDate >= @StartDate
GROUP BY c.CustomerName
HAVING SUM(o.Amount) > 10000
ORDER BY TotalAmount DESC;
```

### 逗号位置

有两派：前置逗号和后置逗号。

```sql
-- 后置逗号（主流）
SELECT
    CustomerName,
    Phone,
    Email
FROM Customers;

-- 前置逗号（注释掉某列更方便）
SELECT
    CustomerName
    ,Phone
    ,Email
FROM Customers;
```

团队统一就行，不要一半前置一半后置。

## 存储过程模板

```sql
CREATE OR ALTER PROCEDURE usp_Order_GetByCustomer
    @CustomerId INT,
    @StartDate DATE = NULL,
    @PageIndex INT = 1,
    @PageSize INT = 20
AS
BEGIN
    SET NOCOUNT ON;

    SELECT
        o.OrderId,
        o.OrderDate,
        o.Amount,
        o.Status
    FROM Orders o
    WHERE o.CustomerId = @CustomerId
        AND (@StartDate IS NULL OR o.OrderDate >= @StartDate)
    ORDER BY o.OrderDate DESC
    OFFSET (@PageIndex - 1) * @PageSize ROWS
    FETCH NEXT @PageSize ROWS ONLY;
END;
```

**SET NOCOUNT ON**：必须加。不加的话每条语句都会返回 "xx rows affected"，浪费网络带宽，某些 ORM 还可能误解析。

## 注释规范

```sql
-- 单行注释：用双横线

/*
多行注释
用于复杂逻辑说明
*/

-- 存储过程头部注释
/*
    名称: usp_Order_GetByCustomer
    描述: 按客户查询订单带分页
    作者: zhangsan
    日期: 2024-01-15
    修改记录:
        2024-03-01 lisi: 增加了日期过滤参数
*/
```

不要注释掉大段代码留在那不删——用版本控制，不要把代码库当备份。

## 反模式清单

| 反模式 | 正确做法 |
|--------|---------|
| `SELECT *` | 列出需要的列 |
| 隐式 JOIN（逗号连接） | 显式 `INNER JOIN` |
| 硬编码魔法数字 `WHERE Status = 3` | 注释说明或用常量 |
| 存储过程几百行不分段 | 拆成多个过程或用注释块分段 |
| 变量名不加 @ 之外没任何含义 `@a, @b` | 有意义的名字 `@CustomerId, @StartDate` |
| 用 `sp_` 前缀 | 用 `usp_` 或无前缀 |
