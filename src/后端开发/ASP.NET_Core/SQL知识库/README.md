## 提问模板

> 用以下模板向 AI 提问，可以高效地扩充知识库内容。

::: details 模板1：知识点系统学习
```
【角色】你是一位有10年经验的SQL Server DBA兼开发专家
【我的水平】.NET开发6年，SQL停留在JOIN和GROUP BY层面
【请求】请系统讲解「窗口函数」，要求：
1. 核心概念用大白话解释，配生活类比
2. 所有常用函数分类列表，标注使用频率
3. 每个函数给出：语法、使用场景、完整可运行示例
4. 和GROUP BY的本质区别
5. 性能注意事项
6. 3道由浅入深的练习题
【输出格式】Markdown格式，适合存入知识文档库
```
:::
