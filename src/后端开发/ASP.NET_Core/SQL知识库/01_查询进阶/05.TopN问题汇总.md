# TopN 问题汇总

"每个部门工资最高的前 3 名""每个类别销量前 5 的产品"——TopN 是 SQL 面试和实际工作里出现频率极高的题型。核心思路就一个：**先排名，再取前 N**。

## 准备数据

```sql
CREATE TABLE #Emp (
    Id INT IDENTITY, Name NVARCHAR(20),
    DeptId INT, Salary INT
);
INSERT INTO #Emp (Name, DeptId, Salary) VALUES
('张三', 1, 12000), ('李四', 1, 15000), ('王五', 1, 15000),
('赵六', 1, 18000), ('钱七', 1, 9000),
('孙八', 2, 20000), ('周九', 2, 16000), ('吴十', 2, 16000),
('郑一', 2, 13000), ('冯二', 2, 11000);
```

---

## 全局 TopN

### TOP N

```sql
-- 全公司工资最高的 3 人
SELECT TOP 3 * FROM #Emp ORDER BY Salary DESC;
```

### TOP N WITH TIES

如果第 3 名有并列，`WITH TIES` 会把并列的都带出来：

```sql
SELECT TOP 3 WITH TIES * FROM #Emp ORDER BY Salary DESC;
-- 如果第 3、4 名都是 16000，会返回 4 行
```

### OFFSET-FETCH

SQL Server 2012+ 的标准分页写法：

```sql
SELECT * FROM #Emp
ORDER BY Salary DESC
OFFSET 0 ROWS FETCH NEXT 3 ROWS ONLY;
```

---

## 分组 TopN（重点）

"每个部门工资最高的前 3 名"——这才是 TopN 的难点。TOP 不能直接按分组取，得用窗口函数。

### 方法一：ROW_NUMBER（最常用）

```sql
;WITH ranked AS (
    SELECT *,
        ROW_NUMBER() OVER (PARTITION BY DeptId ORDER BY Salary DESC) AS rn
    FROM #Emp
)
SELECT * FROM ranked WHERE rn <= 3;
```

| Name | DeptId | Salary | rn |
|------|--------|--------|----|
| 赵六 | 1 | 18000 | 1 |
| 李四 | 1 | 15000 | 2 |
| 王五 | 1 | 15000 | 3 |
| 孙八 | 2 | 20000 | 1 |
| 周九 | 2 | 16000 | 2 |
| 吴十 | 2 | 16000 | 3 |

ROW_NUMBER 不管并列，强制编号。李四和王五都是 15000，但一个是 2 一个是 3。谁是 2 谁是 3 取决于物理存储顺序（不确定的），如果你在意顺序，ORDER BY 里再加一个确定性列（比如 Id）。

### 方法二：RANK（允许并列，可能多于 N 条）

```sql
;WITH ranked AS (
    SELECT *,
        RANK() OVER (PARTITION BY DeptId ORDER BY Salary DESC) AS rk
    FROM #Emp
)
SELECT * FROM ranked WHERE rk <= 3;
```

RANK 会给相同值相同名次，然后跳号。如果前 2 名并列，第 3 就变成了第 3（跳过 2），所以 `rk <= 3` 可能返回 4 行（2 个并列第 2 + 1 个第 3 = 4 行）。

### 方法三：DENSE_RANK（前 N 个薪资等级）

```sql
;WITH ranked AS (
    SELECT *,
        DENSE_RANK() OVER (PARTITION BY DeptId ORDER BY Salary DESC) AS dr
    FROM #Emp
)
SELECT * FROM ranked WHERE dr <= 3;
```

DENSE_RANK 不跳号。"前 3" 意味着"薪资排名前 3 个不同的薪资值"。如果第 2 名有 2 个人并列，`dr <= 3` 会返回 4 行。

### 三者怎么选

| 需求 | 用哪个 |
|------|--------|
| 严格取 N 条，不多不少 | ROW_NUMBER |
| 允许并列，想要"排名前 N"的语义 | RANK |
| "前 N 个不同值"的语义 | DENSE_RANK |

实际开发中 **ROW_NUMBER 用得最多**，因为业务上通常就是要 N 条记录，不想多也不想少。

## 方法四：CROSS APPLY（另一种思路）

如果你不想用窗口函数，CROSS APPLY 也能实现分组 TopN：

```sql
SELECT d.DeptId, t.*
FROM (SELECT DISTINCT DeptId FROM #Emp) d
CROSS APPLY (
    SELECT TOP 3 *
    FROM #Emp e
    WHERE e.DeptId = d.DeptId
    ORDER BY Salary DESC
) t;
```

原理：对每个部门，CROSS APPLY 里面的子查询独立执行一次 `TOP 3`。

**什么时候用这个**：DeptId 上有索引、部门数量少、数据量大的时候，CROSS APPLY 可能比窗口函数快。因为窗口函数要对全表排序，CROSS APPLY 是分别对每个部门的数据排序。

## 实战场景

### 每个客户最新的 3 笔订单

```sql
;WITH cte AS (
    SELECT *,
        ROW_NUMBER() OVER (PARTITION BY CustomerId ORDER BY OrderDate DESC) AS rn
    FROM Orders
)
SELECT * FROM cte WHERE rn <= 3;
```

### 每个类别销量最高的产品（只取 1 条）

```sql
;WITH cte AS (
    SELECT *,
        ROW_NUMBER() OVER (PARTITION BY CategoryId ORDER BY SalesCount DESC) AS rn
    FROM Products
)
SELECT * FROM cte WHERE rn = 1;
```

取 Top 1 是 TopN 的特例，也是最常见的场景——"每组取最新/最大的那条"。

### 每个员工最近一次的打卡记录

```sql
;WITH cte AS (
    SELECT *,
        ROW_NUMBER() OVER (PARTITION BY EmpId ORDER BY CheckTime DESC) AS rn
    FROM CheckRecords
)
SELECT * FROM cte WHERE rn = 1;
```

### 全局 Top 10 但要去重

比如"热搜前 10 个关键词"，同一个关键词可能出现多次：

```sql
SELECT TOP 10 Keyword, COUNT(*) AS SearchCount
FROM SearchLog
GROUP BY Keyword
ORDER BY SearchCount DESC;
```

这里用 GROUP BY 先合并再排序取 Top，不需要窗口函数。

## TopN 的性能优化

### 索引覆盖

分组 TopN 最大的性能问题是排序。如果数据量大，确保有合适的索引：

```sql
-- 针对 "每个部门工资 Top3" 的查询
CREATE INDEX IX_Emp_Dept_Salary ON #Emp(DeptId, Salary DESC) INCLUDE (Name);
-- 这样窗口函数的 PARTITION BY DeptId ORDER BY Salary DESC 直接走索引，不用排序
```

### 大表的 Top 1 优化

如果只取每组 Top 1，而且分组数量不多（比如几十个部门），CROSS APPLY 往往比窗口函数快：

```sql
-- 窗口函数：先给 100 万行都编号，再过滤
-- CROSS APPLY：每个部门只扫前 1 条就停

SELECT d.DeptId, t.*
FROM Departments d
CROSS APPLY (
    SELECT TOP 1 *
    FROM Employees e
    WHERE e.DeptId = d.DeptId
    ORDER BY Salary DESC
) t;
-- 前提：Employees(DeptId, Salary DESC) 上有索引
```

### 避免 TOP 在子查询里的误用

```sql
-- ❌ 这不是分组 TopN！这是整张表取 Top 3 然后再 JOIN
SELECT e.* FROM #Emp e
WHERE e.Id IN (SELECT TOP 3 Id FROM #Emp ORDER BY Salary DESC);

-- ✅ 分组 TopN 必须用窗口函数或 CROSS APPLY
```
