# 高频 SQL 面试题精选

面试中经常问的 SQL 题目，附带解法和分析。

## 第二高薪水

> 查询 Employee 表中第二高的薪水，如果不存在返回 NULL。

```sql
-- 方法 1：OFFSET
SELECT MAX(Salary) AS SecondHighestSalary
FROM Employee
WHERE Salary < (SELECT MAX(Salary) FROM Employee);

-- 方法 2：DENSE_RANK
SELECT Salary AS SecondHighestSalary
FROM (
    SELECT Salary, DENSE_RANK() OVER (ORDER BY Salary DESC) AS rk
    FROM Employee
) t WHERE rk = 2;

-- 方法 3：通用第 N 高
SELECT DISTINCT Salary FROM Employee
ORDER BY Salary DESC
OFFSET 1 ROWS FETCH NEXT 1 ROWS ONLY;
```

## 连续登录 N 天的用户

> 找出连续登录 3 天以上的用户。

```sql
;WITH daily AS (
    SELECT DISTINCT UserId, CAST(LoginTime AS DATE) AS LoginDate
    FROM UserLogins
),
grouped AS (
    SELECT *, DATEADD(DAY, -ROW_NUMBER() OVER (PARTITION BY UserId ORDER BY LoginDate), LoginDate) AS Grp
    FROM daily
)
SELECT UserId, MIN(LoginDate) AS StartDate, MAX(LoginDate) AS EndDate,
    COUNT(*) AS ConsecutiveDays
FROM grouped
GROUP BY UserId, Grp
HAVING COUNT(*) >= 3;
```

**核心思想**：连续日期减去行号得到一个常数，用这个常数分组。

## 每组 Top N

> 每个部门工资最高的 3 名员工。

```sql
SELECT * FROM (
    SELECT *, ROW_NUMBER() OVER (PARTITION BY DeptId ORDER BY Salary DESC) AS rn
    FROM Employees
) t WHERE rn <= 3;
```

**追问**：ROW_NUMBER vs RANK vs DENSE_RANK 的区别？
- ROW_NUMBER：相同值也编不同号 → 1,2,3
- RANK：相同值编同号，跳号 → 1,1,3
- DENSE_RANK：相同值编同号，不跳号 → 1,1,2

## 行转列

> 把学生成绩从行格式转成列格式。

```sql
SELECT StudentName,
    MAX(CASE WHEN Subject = '语文' THEN Score END) AS 语文,
    MAX(CASE WHEN Subject = '数学' THEN Score END) AS 数学,
    MAX(CASE WHEN Subject = '英语' THEN Score END) AS 英语
FROM Scores
GROUP BY StudentName;
```

## 找出缺失的数字

> 1-100 中缺了哪些数字？

```sql
;WITH nums AS (
    SELECT 1 AS n UNION ALL SELECT n + 1 FROM nums WHERE n < 100
)
SELECT n FROM nums
WHERE n NOT IN (SELECT Number FROM MyTable)
OPTION (MAXRECURSION 100);
```

## 删除重复行保留一条

```sql
;WITH dup AS (
    SELECT *, ROW_NUMBER() OVER (PARTITION BY Name, Email ORDER BY Id) AS rn
    FROM Customers
)
DELETE FROM dup WHERE rn > 1;
```

## 自连接：找出比经理工资还高的员工

```sql
SELECT e.Name AS Employee
FROM Employees e
JOIN Employees m ON e.ManagerId = m.Id
WHERE e.Salary > m.Salary;
```

## 累计求和

```sql
SELECT OrderDate, Amount,
    SUM(Amount) OVER (ORDER BY OrderDate) AS RunningTotal
FROM Orders;
```

## EXISTS vs IN 的区别

```sql
-- EXISTS：外表驱动，子查询找到一条就返回
SELECT * FROM Customers c
WHERE EXISTS (SELECT 1 FROM Orders o WHERE o.CustomerId = c.Id);

-- IN：先执行子查询得到结果集，再匹配
SELECT * FROM Customers WHERE Id IN (SELECT CustomerId FROM Orders);
```

- 外表小、子查询大 → EXISTS 快
- 外表大、子查询小 → IN 快
- 子查询结果有 NULL → NOT IN 出问题，NOT EXISTS 不会

## 面试常问概念题

| 问题 | 要点 |
|------|------|
| WHERE vs HAVING | WHERE 过滤行（GROUP BY 前），HAVING 过滤组（GROUP BY 后） |
| DELETE vs TRUNCATE vs DROP | DELETE 逐行删可回滚；TRUNCATE 清空重置标识；DROP 删表 |
| 聚集索引 vs 非聚集索引 | 聚集=数据按索引顺序物理排列；非聚集=额外的指针结构 |
| 视图能更新吗 | 简单视图可以，复杂视图（JOIN/聚合）不行 |
| 临时表 vs 表变量 | 临时表有统计信息、可加索引；表变量估算永远 1 行 |
