# SQL Server vs MySQL 差异对照

很多开发者同时接触 SQL Server 和 MySQL，两边语法有不少差异。这篇列出最常见的对照。

## 语法差异

| 功能 | SQL Server | MySQL |
|------|-----------|-------|
| 分页 | `OFFSET ... FETCH NEXT` | `LIMIT ... OFFSET` |
| 自增列 | `IDENTITY(1,1)` | `AUTO_INCREMENT` |
| 字符串拼接 | `+` 或 `CONCAT()` | `CONCAT()` |
| 当前时间 | `GETDATE()` / `SYSDATETIME()` | `NOW()` / `CURRENT_TIMESTAMP` |
| 判空 | `ISNULL(col, default)` | `IFNULL(col, default)` |
| 条件 | `IIF(cond, a, b)` | `IF(cond, a, b)` |
| Top N | `SELECT TOP 10 *` | `SELECT * LIMIT 10` |
| 临时表 | `#temp` | `CREATE TEMPORARY TABLE` |
| 插入并获取ID | `SCOPE_IDENTITY()` | `LAST_INSERT_ID()` |
| 字符串截取 | `SUBSTRING(str, start, len)` | `SUBSTRING(str, start, len)` 相同 |
| 递归 CTE | ✅ 支持 | ✅ 8.0+ 支持 |
| PIVOT | ✅ 内置 | ❌ 手写 CASE WHEN |
| CROSS APPLY | ✅ 支持 | ❌ 8.0+ 用 LATERAL |
| MERGE | ✅ 支持 | ❌ 用 INSERT ON DUPLICATE KEY |

## 分页写法对比

```sql
-- SQL Server (2012+)
SELECT * FROM Orders ORDER BY OrderId
OFFSET 20 ROWS FETCH NEXT 10 ROWS ONLY;

-- MySQL
SELECT * FROM Orders ORDER BY OrderId LIMIT 10 OFFSET 20;
```

## 索引差异

| | SQL Server | MySQL (InnoDB) |
|---|---|---|
| 聚集索引 | 默认主键 | 默认主键 |
| 非聚集索引叶子 | 存聚集索引 key | 存主键值 |
| INCLUDE 列 | ✅ 支持 | ❌ 不支持 |
| 筛选索引 | ✅ `WHERE` 子句 | ❌ 不支持 |
| 全文索引 | ✅ 内置 | ✅ 5.6+ |
| 索引类型 | B+ 树 | B+ 树、Hash（Memory引擎） |

## 事务和锁

| | SQL Server | MySQL (InnoDB) |
|---|---|---|
| 默认隔离级别 | READ COMMITTED | REPEATABLE READ |
| MVCC | 需手动开启 RCSI | 默认就是 MVCC |
| 间隙锁 | SERIALIZABLE 下有 | REPEATABLE READ 下就有 |
| 死锁检测 | 有（自动选 victim 回滚） | 有 |

## 数据类型对照

| SQL Server | MySQL | 说明 |
|-----------|-------|------|
| INT | INT | 相同 |
| BIGINT | BIGINT | 相同 |
| NVARCHAR(n) | VARCHAR(n) + utf8mb4 | MySQL 用字符集控制 |
| VARCHAR(n) | VARCHAR(n) | |
| DATETIME2 | DATETIME(3) | 都可以到毫秒 |
| BIT | TINYINT(1) / BOOLEAN | MySQL 把 BOOLEAN 当 TINYINT |
| DECIMAL(p,s) | DECIMAL(p,s) | 相同 |
| UNIQUEIDENTIFIER | CHAR(36) / BINARY(16) | MySQL 没有原生 UUID 类型 |
| NTEXT / TEXT | TEXT / LONGTEXT | SQL Server 已弃用 NTEXT |
| IMAGE | BLOB / LONGBLOB | SQL Server 已弃用 IMAGE |

## 存储过程差异

```sql
-- SQL Server
CREATE PROCEDURE usp_GetOrders @CustomerId INT AS
BEGIN
    SELECT * FROM Orders WHERE CustomerId = @CustomerId;
END;

-- MySQL
DELIMITER //
CREATE PROCEDURE usp_GetOrders(IN p_CustomerId INT)
BEGIN
    SELECT * FROM Orders WHERE CustomerId = p_CustomerId;
END //
DELIMITER ;
```

## 常见迁移注意点

从 SQL Server 迁到 MySQL 时：

1. **TOP → LIMIT**
2. **IDENTITY → AUTO_INCREMENT**
3. **ISNULL → IFNULL**
4. **方括号 [] → 反引号 \`\`**
5. **NVARCHAR → VARCHAR + utf8mb4 字符集**
6. **CROSS APPLY → 改写为子查询或 LATERAL（8.0+）**
7. **PIVOT → CASE WHEN 手写**
8. **CTE 递归** MySQL 8.0+ 才支持
9. **没有 INCLUDE 索引**，覆盖索引只能把列加到索引键里
10. **MERGE 不支持**，用 `INSERT ... ON DUPLICATE KEY UPDATE`
