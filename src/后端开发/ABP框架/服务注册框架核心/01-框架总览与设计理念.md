# 01 - 框架总览与设计理念

## 为什么要做这个框架？

在大型 .NET 项目中，我们面临几个核心问题：

1. **服务注册爆炸** — `Program.cs` 里堆满了 `services.AddScoped<IXxx, Xxx>()`，难以维护
2. **模块化困难** — 功能模块之间的依赖关系靠人肉管理，没有统一的加载/初始化机制
3. **框架锁定** — 使用 ABP 等成熟框架虽然方便，但引入了大量不需要的功能和依赖

MokFramework 的目标是：**实现 ABP 的核心架构模式，但保持极简**。

## 设计原则

### 1. 约定优于配置 (Convention over Configuration)

```csharp
// ❌ 传统方式：每个服务都要手动注册
services.AddTransient<IGreetingService, GreetingService>();
services.AddScoped<IOrderService, OrderService>();
services.AddSingleton<ICacheService, CacheService>();

// ✅ MokFramework：实现标记接口即可自动注册
public class GreetingService : IGreetingService, ITransientDependency { }
public class OrderService : IOrderService, IScopedDependency { }
public class CacheService : ICacheService, ISingletonDependency { }
```

### 2. 模块化组织

```csharp
// 每个功能领域是一个模块，通过 [DependsOn] 声明依赖
[DependsOn(typeof(InfrastructureModule))]
[DependsOn(typeof(MokFrameworkAspNetCoreModule))]
public class AppModule : MokFrameworkModule
{
    public override void ConfigureServices(ServiceConfigurationContext context)
    {
        // 只需注册不符合约定的服务
    }
}
```

### 3. 可插拔的基础设施

```csharp
// DI 容器：默认 MS DI，可选 Autofac
builder.Host.UseAutofac();

// 日志：默认 ILogger，可选 Serilog
builder.Host.UseMokSerilog();
```

### 4. 兼容 ASP.NET Core 生态

```csharp
// 完全融入 ASP.NET Core 的编程模型
var builder = WebApplication.CreateBuilder(args);
builder.Host.AddAppSettingsSecretsJson()
    .UseAutofac()
    .UseMokSerilog();
await builder.AddApplicationAsync<AppModule>();
var app = builder.Build();
await app.InitializeApplicationAsync();
await app.RunAsync();
```

## 核心概念

### 模块 (Module)

模块是功能的组织单元。每个模块：
- 继承 `MokFrameworkModule`
- 可以声明对其他模块的依赖
- 有完整的生命周期（配置服务 → 初始化 → 关闭）
- 拥有自己的程序集，框架自动扫描其中的服务类

### 约定注册器 (ConventionalRegistrar)

自动扫描模块所在程序集中的类，根据标记接口或特性自动注册到 DI 容器。

### Application

应用程序的入口，负责：
- 加载所有模块（递归发现 + 拓扑排序）
- 按顺序执行模块生命周期
- 管理 DI 容器的创建和销毁

## 搭建顺序

本文档库按照实际搭建顺序组织：

1. **先搭核心** — 模块系统 + 依赖注入（没有任何外部依赖）
2. **再建 Application** — 把模块系统和 DI 串起来
3. **然后集成** — ASP.NET Core / Autofac / Serilog（都是可选的薄包装层）
4. **最后验证** — Demo 项目验证全部功能
