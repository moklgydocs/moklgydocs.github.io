# 属性设计与策略表达式

## 属性建模原则

好的属性设计遵循以下原则：

1. **最小化**：只收集鉴权决策真正需要的属性
2. **稳定性**：属性应该相对稳定，频繁变化的属性不适合做鉴权依据
3. **标准化**：相同含义的属性在全系统使用统一命名（如 `department` 而非 `dept`/`deptId` 混用）
4. **层次性**：复杂系统使用命名空间隔离，如 `user.profile.city`

## 策略表达式语法

ABAC 的策略本质上是一个**布尔表达式**：

```
Effect = IF (Condition1 AND Condition2 AND ...) THEN Allow ELSE Deny
```

### 基础运算符

```
比较: ==  !=  >  <  >=  <=
逻辑: AND  OR  NOT
集合: IN  NOT_IN  CONTAINS  ANY_OF
字符串: STARTS_WITH  ENDS_WITH  MATCHES (正则)
```

### 策略示例：销售合同查看

```json
{
  "policyId": "sales-contract-read-v2",
  "description": "销售经理可查看本部门工作时间内的合同",
  "effect": "Allow",
  "conditions": [
    {
      "attribute": "subject.roles",
      "operator": "CONTAINS",
      "value": "SalesManager"
    },
    {
      "attribute": "resource.ownerDepartment",
      "operator": "==",
      "value": "${subject.department}"    // 引用主体属性
    },
    {
      "attribute": "resource.amount",
      "operator": "<=",
      "value": 1000000
    },
    {
      "attribute": "environment.isWorkingHour",
      "operator": "==",
      "value": true
    }
  ],
  "combiningAlgorithm": "AND"
}
```

### 策略组合算法

当多条策略同时匹配时，需要一个合并规则：

| 算法 | 说明 | 适用场景 |
|------|------|---------|
| `deny-overrides` | 有任何一条 Deny 则最终 Deny | 高安全要求场景 |
| `permit-overrides` | 有任何一条 Permit 则最终 Permit | 宽松访问场景 |
| `first-applicable` | 按顺序取第一条匹配结果 | 有优先级的策略集 |
| `only-one-applicable` | 只有一条策略匹配时才生效 | 防止策略冲突 |

## C# 策略模型

```csharp
public enum EffectType { Allow, Deny }
public enum CombiningAlgorithm { And, Or }

public class PolicyCondition
{
    public string Attribute { get; set; }   // "subject.department"
    public string Operator { get; set; }    // "=="
    public object Value { get; set; }       // "BJ-Sales" 或 "${subject.department}"
}

public class AbacPolicy
{
    public string PolicyId { get; set; }
    public string Description { get; set; }
    public EffectType Effect { get; set; }
    public List<PolicyCondition> Conditions { get; set; } = new();
    public CombiningAlgorithm CombiningAlgorithm { get; set; } = CombiningAlgorithm.And;
    public int Priority { get; set; } = 0;
    public string Version { get; set; } = "1.0";
}
```

## 属性上下文构建

```csharp
public class AttributeContext
{
    public Dictionary<string, object> Subject { get; set; } = new();
    public Dictionary<string, object> Resource { get; set; } = new();
    public Dictionary<string, object> Action { get; set; } = new();
    public Dictionary<string, object> Environment { get; set; } = new();
}

public class AttributeContextBuilder
{
    private readonly IHttpContextAccessor _httpContextAccessor;
    private readonly IUserAttributeService _userAttrService;

    public async Task<AttributeContext> BuildAsync(
        ClaimsPrincipal user,
        object resource,
        string action)
    {
        var userId = user.FindFirstValue(ClaimTypes.NameIdentifier);
        var userAttrs = await _userAttrService.GetAttributesAsync(userId);

        return new AttributeContext
        {
            Subject = new()
            {
                ["userId"]     = userId,
                ["roles"]      = user.FindAll(ClaimTypes.Role).Select(c => c.Value).ToList(),
                ["department"] = userAttrs.Department,
                ["city"]       = userAttrs.City,
                ["level"]      = userAttrs.Level
            },
            Resource = BuildResourceAttributes(resource),
            Action = new() { ["name"] = action },
            Environment = new()
            {
                ["requestTime"]    = DateTime.UtcNow,
                ["isWorkingHour"]  = IsWorkingHour(),
                ["clientIp"]       = _httpContextAccessor.HttpContext?.Connection.RemoteIpAddress?.ToString(),
                ["dayOfWeek"]      = DateTime.UtcNow.DayOfWeek.ToString()
            }
        };
    }

    private static Dictionary<string, object> BuildResourceAttributes(object resource)
    {
        // 利用反射或约定接口提取资源属性
        if (resource is IAttributeProvider provider)
            return provider.GetAttributes();

        return new() { ["type"] = resource.GetType().Name };
    }

    private static bool IsWorkingHour()
    {
        var now = DateTime.Now;
        return now.DayOfWeek is not (DayOfWeek.Saturday or DayOfWeek.Sunday)
            && now.Hour is >= 9 and < 18;
    }
}
```
