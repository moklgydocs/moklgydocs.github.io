## 权限模型横向对比

| 维度 | ACL | RBAC | ABAC | PBAC |
|------|-----|------|------|------|
| 管理粒度 | 粗 | 中 | 细 | 极细 |
| 动态能力 | 无 | 弱 | 强 | 最强 |
| 管理复杂度 | 低 | 中 | 高 | 高 |
| 性能开销 | 低 | 低 | 高 | 高 |
| 适用规模 | 小型系统 | 中大型企业 | 数据密集型 | 合规驱动型 |
| .NET 支持 | 原生 | 原生 | 需扩展 | 需规则引擎 |

## 学习建议

::: tip 学习路径建议
1. **第一阶段**：理解权限模型演进史，建立宏观视角
2. **第二阶段**：深入 RBAC，这是绝大多数系统的基础
3. **第三阶段**：学习 ABAC，理解动态属性计算的价值
4. **第四阶段**：掌握混合架构，这是现代权限系统的标准形态
5. **第五阶段**：关注性能与工程实践，让架构在生产中稳定运行
:::

::: warning 常见误区
- 不要认为 ABAC 可以完全替代 RBAC，二者是互补关系
- 不要在简单系统中过度设计，RBAC 够用就是最好的选择
- 不要忽略权限缓存，每次请求实时查库是灾难性的设计
- 不要混淆认证（Authentication）与授权（Authorization），它们是两个独立关注点
:::
