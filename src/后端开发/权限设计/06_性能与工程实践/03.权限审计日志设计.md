# 权限审计日志设计

## 审计日志的价值

审计日志回答四个问题：**谁（Who）在什么时间（When）对什么资源（What）做了什么操作（How），结果如何（Result）。**

这是合规（SOX、GDPR、等保三级）的强制要求，也是安全事件溯源的核心工具。

## 审计日志数据模型

```csharp
public class AuthorizationAuditLog
{
    // 基础标识
    public Guid LogId { get; set; } = Guid.NewGuid();
    public DateTime Timestamp { get; set; } = DateTime.UtcNow;
    public string RequestId { get; set; }       // 与 HTTP 请求关联

    // 主体（Who）
    public string UserId { get; set; }
    public string Username { get; set; }
    public string TenantId { get; set; }
    public string[] UserRoles { get; set; }
    public string ClientIp { get; set; }

    // 资源（What）
    public string ResourceType { get; set; }    // Contract / Order
    public string ResourceId { get; set; }
    public Dictionary<string, object> ResourceSnapshot { get; set; }  // 关键属性快照

    // 操作（How）
    public string Action { get; set; }          // read / write / delete
    public string HttpMethod { get; set; }
    public string Endpoint { get; set; }

    // 决策结果（Result）
    public string Decision { get; set; }        // Allow / Deny
    public string DenyReason { get; set; }
    public string MatchedPolicyId { get; set; }
    public long EvaluationTimeMs { get; set; }  // 鉴权耗时

    // 上下文
    public string UserAgent { get; set; }
    public Dictionary<string, object> AdditionalContext { get; set; }
}
```

## 审计日志写入（异步，不阻塞鉴权链路）

```csharp
public class AuditLogMiddleware
{
    private readonly RequestDelegate _next;
    private readonly ILogger<AuditLogMiddleware> _logger;
    private readonly Channel<AuthorizationAuditLog> _channel;  // 异步写入通道

    public async Task InvokeAsync(HttpContext context)
    {
        var sw = Stopwatch.StartNew();
        AuthorizationDecision decision = null;

        // 注入决策结果捕获
        context.Items["CaptureDecision"] = (Action<AuthorizationDecision>)(d => decision = d);

        await _next(context);

        sw.Stop();

        // 异步写入审计日志（不阻塞响应）
        var log = BuildAuditLog(context, decision, sw.ElapsedMilliseconds);
        await _channel.Writer.WriteAsync(log);
    }

    private AuthorizationAuditLog BuildAuditLog(
        HttpContext context,
        AuthorizationDecision decision,
        long elapsedMs)
    {
        return new AuthorizationAuditLog
        {
            RequestId         = context.TraceIdentifier,
            UserId            = context.User.FindFirstValue(ClaimTypes.NameIdentifier),
            Username          = context.User.FindFirstValue(ClaimTypes.Name),
            TenantId          = context.User.FindFirstValue("tenant_id"),
            UserRoles         = context.User.FindAll(ClaimTypes.Role).Select(c => c.Value).ToArray(),
            ClientIp          = context.Connection.RemoteIpAddress?.ToString(),
            HttpMethod        = context.Request.Method,
            Endpoint          = context.Request.Path,
            Action            = MapHttpMethodToAction(context.Request.Method),
            Decision          = decision?.Effect.ToString() ?? "Unknown",
            DenyReason        = decision?.DenyReason,
            MatchedPolicyId   = decision?.MatchedPolicyId,
            EvaluationTimeMs  = elapsedMs,
            UserAgent         = context.Request.Headers.UserAgent
        };
    }
}

// 后台消费者：批量写入数据库（减少 DB 压力）
public class AuditLogConsumer : BackgroundService
{
    private readonly Channel<AuthorizationAuditLog> _channel;
    private readonly IAuditLogRepository _repo;
    private const int BatchSize = 100;
    private const int FlushIntervalMs = 1000;

    protected override async Task ExecuteAsync(CancellationToken ct)
    {
        var batch = new List<AuthorizationAuditLog>(BatchSize);
        var timer = new PeriodicTimer(TimeSpan.FromMilliseconds(FlushIntervalMs));

        while (!ct.IsCancellationRequested)
        {
            // 批量收集或定时刷新
            while (batch.Count < BatchSize && _channel.Reader.TryRead(out var log))
                batch.Add(log);

            if (batch.Count > 0 || await timer.WaitForNextTickAsync(ct))
            {
                if (batch.Count > 0)
                {
                    await _repo.BatchInsertAsync(batch, ct);
                    batch.Clear();
                }
            }
        }
    }
}
```

## 敏感操作的同步审计

对于高风险操作（删除、大额审批），需要同步记录，不能用异步队列（避免丢失）：

```csharp
[HttpDelete("{id}")]
[Authorize(Policy = "CanDeleteContract")]
public async Task<IActionResult> DeleteContract(Guid id)
{
    var contract = await _repo.GetAsync(id);
    if (contract == null) return NotFound();

    // 同步审计（删除前记录快照）
    await _auditLogger.LogSynchronousAsync(new AuthorizationAuditLog
    {
        Action           = "delete",
        ResourceType     = "Contract",
        ResourceId       = id.ToString(),
        ResourceSnapshot = new()
        {
            ["amount"]   = contract.Amount,
            ["status"]   = contract.Status,
            ["deptId"]   = contract.DepartmentId
        },
        Decision = "Allow"
    });

    await _repo.DeleteAsync(id);
    return NoContent();
}
```

## 审计日志查询 API

```csharp
// 供合规审计员使用的查询接口
[HttpGet("audit/logs")]
[Authorize(Roles = "Auditor,Admin")]
public async Task<IActionResult> QueryAuditLogs([FromQuery] AuditLogQueryFilter filter)
{
    // 支持按用户、时间范围、资源类型、决策结果过滤
    var logs = await _auditRepo.QueryAsync(filter);
    return Ok(logs);
}

// 查询某用户在某时间段的所有拒绝记录（安全分析用）
[HttpGet("audit/suspicious")]
[Authorize(Roles = "SecurityAdmin")]
public async Task<IActionResult> GetSuspiciousActivity([FromQuery] string userId, DateTime from, DateTime to)
{
    var deniedCount = await _auditRepo.CountAsync(new AuditLogQueryFilter
    {
        UserId   = userId,
        Decision = "Deny",
        From     = from,
        To       = to
    });

    // 短时间内大量拒绝可能是暴力探测
    if (deniedCount > 100)
        await _alertService.SendSecurityAlertAsync(userId, deniedCount);

    return Ok(new { userId, deniedCount, period = $"{from:s} ~ {to:s}" });
}
```
