## 一、算法定位

| 维度 | 说明 |
|------|------|
| 所属分类 | 核心算法思想 / 线性扫描技巧 |
| 解决的问题 | 对有序数组或链表进行高效的两端/快慢扫描 |
| 典型场景 | 两数之和、三数之和、反转数组、链表找环、删除重复元素、接雨水 |

---

## 二、一句话理解

> **双指针就是用两个下标/指针从不同位置（两端或不同速度）同时遍历，用一次扫描代替暴力的两层循环，把 O(n²) 降为 O(n)。**

---

## 三、生活化比喻

**对折找中点：**

把一根绳子对折，两端同时向中间靠拢。这就是"对撞指针"——左指针从头走，右指针从尾走，直到相遇。

**龟兔赛跑：**

快指针（兔子）每次走两步，慢指针（乌龟）每次走一步。如果路径有环，兔子最终会追上乌龟。这就是"快慢指针"——用于检测链表环。

---

## 四、核心思想

### 4.1 双指针的两种形式

| 类型 | 初始位置 | 移动方式 | 典型场景 |
|------|---------|---------|---------|
| **对撞指针** | 一头一尾 | 向中间靠拢 | 有序数组两数之和、回文判断 |
| **快慢指针** | 同一起点（或不同起点）| 不同速度前进 | 链表找中点/环、原地删除重复 |

### 4.2 为什么能从 O(n²) 降到 O(n)？

暴力法：外层循环选第一个数，内层循环遍历剩余 → O(n²)

双指针：利用**有序**或**单调性**，让两个指针根据当前情况**有方向地移动**，每次移动都排除了一批无效情况 → O(n)

## 五、图解推演

### 5.1 对撞指针：两数之和（有序数组）

```
数组：[2, 7, 11, 15]，目标：9

初始：L=0(2)，R=3(15)
  sum = 2+15 = 17 > 9 → R 向左移

  L=0(2)，R=2(11)
  sum = 2+11 = 13 > 9 → R 向左移

  L=0(2)，R=1(7)
  sum = 2+7 = 9 == 9 → 找到！返回 [0, 1]

全程只扫描了一遍，O(n)
```

### 5.2 快慢指针：找链表中点

```
链表：1 → 2 → 3 → 4 → 5

初始：slow=1, fast=1
步骤1：slow→2, fast→3
步骤2：slow→3, fast→5
步骤3：fast.next==null，停止

slow 停在 3，正好是中点！

偶数链表：1 → 2 → 3 → 4
初始：slow=1, fast=1
步骤1：slow→2, fast→3
步骤2：slow→3, fast=null（fast.next.next==null），停止
slow 停在 3（偏右中点）
```

### 5.3 对撞指针：原地反转数组

```
数组：[1, 2, 3, 4, 5]

L=0, R=4：交换 1↔5 → [5, 2, 3, 4, 1]
L=1, R=3：交换 2↔4 → [5, 4, 3, 2, 1]
L=2, R=2：L>=R，停止

结果：[5, 4, 3, 2, 1]
```

## 六、执行步骤

**对撞指针：**
1. 初始化 `left = 0`，`right = n - 1`
2. 当 `left < right` 时循环：
   - 计算当前值
   - 若满足条件，记录结果
   - 若当前值偏大，`right--`（排除右侧不可能的组合）
   - 若当前值偏小，`left++`（排除左侧不可能的组合）

**快慢指针：**
1. 初始化 `slow = head`，`fast = head`
2. 每次 `slow` 走一步，`fast` 走两步
3. 根据问题条件决定何时停止

## 七、C# 实现

### 7.1 两数之和（有序数组，对撞指针）

```csharp
using System;

class TwoSum
{
    /// <summary>
    /// 有序数组中找两个数之和等于 target
    /// 利用有序性：sum 大了就缩右边，sum 小了就扩左边
    /// 时间复杂度：O(n)，空间复杂度：O(1)
    /// </summary>
    static int[] TwoSumSorted(int[] numbers, int target)
    {
        int left = 0;               // 左指针，从最小数开始
        int right = numbers.Length - 1; // 右指针，从最大数开始

        while (left < right)
        {
            int sum = numbers[left] + numbers[right];

            if (sum == target)
                return new int[] { left, right }; // 找到，返回下标

            if (sum < target)
                left++;  // 和太小，左指针右移（增大和）
            else
                right--; // 和太大，右指针左移（减小和）
        }

        return new int[] { -1, -1 }; // 无解
    }

    static void Main()
    {
        int[] nums = { 2, 7, 11, 15 };
        var result = TwoSumSorted(nums, 9);
        Console.WriteLine($"下标：[{result[0]}, {result[1]}]"); // [0, 1]
    }
}
```

### 7.2 三数之和（对撞指针）

```csharp
using System;
using System.Collections.Generic;

class ThreeSum
{
    /// <summary>
    /// 找所有三元组 nums[i] + nums[j] + nums[k] = 0（不重复）
    /// 思路：排序 + 固定一个数 + 剩余两个用对撞指针
    /// </summary>
    static List<List<int>> ThreeSumZero(int[] nums)
    {
        var result = new List<List<int>>();
        Array.Sort(nums); // 先排序！这是双指针的前提

        for (int i = 0; i < nums.Length - 2; i++)
        {
            // 剪枝：最小数都大于0，不可能凑出0
            if (nums[i] > 0) break;

            // 去重：跳过相同的 nums[i]
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int left = i + 1;
            int right = nums.Length - 1;

            while (left < right)
            {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum == 0)
                {
                    result.Add(new List<int> { nums[i], nums[left], nums[right] });

                    // 去重：跳过左侧重复元素
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    // 去重：跳过右侧重复元素
                    while (left < right && nums[right] == nums[right - 1]) right--;

                    left++;
                    right--;
                }
                else if (sum < 0)
                    left++;  // 和太小
                else
                    right--; // 和太大
            }
        }

        return result;
    }

    static void Main()
    {
        int[] nums = { -1, 0, 1, 2, -1, -4 };
        var result = ThreeSumZero(nums);
        Console.WriteLine("三数之和为0的组合：");
        foreach (var trio in result)
            Console.WriteLine($"  [{string.Join(", ", trio)}]");
        // 输出：[-1,-1,2], [-1,0,1]
    }
}
```

### 7.3 快慢指针：链表找环

```csharp
using System;

class ListNode
{
    public int Val;
    public ListNode Next;
    public ListNode(int val) { Val = val; }
}

class LinkedListCycle
{
    /// <summary>
    /// 检测链表是否有环（Floyd 判圈算法）
    /// 快指针每次走2步，慢指针每次走1步
    /// 若有环：快指针最终会追上慢指针（在环内相遇）
    /// 若无环：快指针到达 null
    /// </summary>
    static bool HasCycle(ListNode head)
    {
        if (head == null || head.Next == null) return false;

        ListNode slow = head;      // 慢指针，每次走1步
        ListNode fast = head.Next; // 快指针，每次走2步

        while (slow != fast)
        {
            // 快指针到头了，说明无环
            if (fast == null || fast.Next == null) return false;

            slow = slow.Next;       // 慢指针走1步
            fast = fast.Next.Next;  // 快指针走2步
        }

        return true; // slow == fast，相遇，有环
    }

    /// <summary>
    /// 找链表中间节点
    /// 快指针到末尾时，慢指针正好在中间
    /// </summary>
    static ListNode FindMiddle(ListNode head)
    {
        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.Next != null)
        {
            slow = slow.Next;       // 慢指针走1步
            fast = fast.Next.Next;  // 快指针走2步
        }

        return slow; // fast 到末尾时，slow 在中间
    }

    static void Main()
    {
        // 创建链表：1 → 2 → 3 → 4 → 5 → (指向节点3，形成环)
        var n1 = new ListNode(1); var n2 = new ListNode(2);
        var n3 = new ListNode(3); var n4 = new ListNode(4);
        var n5 = new ListNode(5);
        n1.Next = n2; n2.Next = n3; n3.Next = n4; n4.Next = n5;
        n5.Next = n3; // 创建环

        Console.WriteLine($"有环：{HasCycle(n1)}"); // 输出 True

        // 无环链表
        var a = new ListNode(1); var b = new ListNode(2);
        var c = new ListNode(3); var d = new ListNode(4);
        a.Next = b; b.Next = c; c.Next = d;
        Console.WriteLine($"中间节点：{FindMiddle(a).Val}"); // 输出 3（偏右中点）
    }
}
```

### 7.4 原地删除重复元素（快慢指针）

```csharp
using System;

class RemoveDuplicates
{
    /// <summary>
    /// 有序数组原地删除重复元素
    /// slow：下一个待填入位置
    /// fast：当前扫描位置
    /// </summary>
    static int RemoveDuplicatesInPlace(int[] nums)
    {
        if (nums.Length == 0) return 0;

        int slow = 0; // 慢指针：结果数组的末尾

        for (int fast = 1; fast < nums.Length; fast++)
        {
            // 当 fast 遇到新的不重复元素时，才写入 slow 位置
            if (nums[fast] != nums[slow])
            {
                slow++;
                nums[slow] = nums[fast]; // 将新元素写到 slow 位置
            }
            // 如果相同则 fast 继续前进，slow 不动（相当于跳过重复元素）
        }

        return slow + 1; // 不重复元素的个数
    }

    static void Main()
    {
        int[] nums = { 1, 1, 2, 2, 3, 4, 4, 5 };
        int len = RemoveDuplicatesInPlace(nums);
        Console.Write($"去重后长度={len}，数组：");
        for (int i = 0; i < len; i++) Console.Write(nums[i] + " ");
        // 输出：1 2 3 4 5
    }
}
```

## 八、示例演示

### 手动推演：三数之和 [-1, 0, 1, 2, -1, -4]

```
排序后：[-4, -1, -1, 0, 1, 2]

i=0, nums[i]=-4:
  left=1(-1), right=5(2): sum=-4-1+2=-3 < 0, left++
  left=2(-1), right=5(2): sum=-4-1+2=-3 < 0, left++
  left=3(0),  right=5(2): sum=-4+0+2=-2 < 0, left++
  left=4(1),  right=5(2): sum=-4+1+2=-1 < 0, left++
  left=5 >= right，结束

i=1, nums[i]=-1:
  left=2(-1), right=5(2): sum=-1-1+2=0 ✓ 记录 [-1,-1,2]，left++, right--
  left=3(0),  right=4(1): sum=-1+0+1=0 ✓ 记录 [-1,0,1]，left++, right--
  left=4 >= right，结束

i=2, nums[i]=-1: 与 nums[1] 相同，跳过（去重）

i=3, nums[i]=0 > 0? 不是，继续
  left=4(1), right=5(2): sum=0+1+2=3 > 0, right--
  left=4 >= right，结束

结果：[[-1,-1,2], [-1,0,1]]
```

## 十、易错点

| 易错点 | 后果 | 正确做法 |
|--------|------|----------|
| 对撞指针用在无序数组 | 结论不成立 | 先排序再用对撞指针 |
| 三数之和漏写去重逻辑 | 结果有重复三元组 | 相邻相同元素跳过 |
| 快慢指针中 fast 越界 | 空指针异常 | 先判断 `fast != null && fast.Next != null` |
| 删除重复时用两个变量混淆 | 逻辑错误 | slow 是写入位置，fast 是读取位置 |

## 十四、面试常问点

1. **双指针适合解决什么类型的问题？**
   - 有序数组的搜索/配对、链表的快慢扫描、原地修改

2. **为什么对撞指针能保证不漏解？**
   - 每次移动都因为单调性排除了不可能的情况

3. **快慢指针为什么能检测环？**
   - 有环时快指针最终会追上慢指针（相对速度1，会在环内相遇）

4. **三数之和为什么要先排序？**
   - 排序后才有单调性，对撞指针才能有方向地移动

5. **链表找中点时，快指针奇偶链表结果有什么不同？**
   - 奇数长度：slow 恰好在正中；偶数长度：slow 在中间偏右
