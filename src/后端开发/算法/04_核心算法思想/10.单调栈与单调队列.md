## 二、一句话理解

> **单调栈：维护一个单调的栈，帮你以 O(n) 时间找到每个元素"左边/右边第一个比它大/小的数"；单调队列：维护一个单调的双端队列，帮你以 O(n) 时间求滑动窗口的最大/最小值。**

## 三、生活化比喻

**单调栈 → 站队看演出：**

大家排队等候进场，你站在队伍中想知道"前面第一个比我高的人在哪里"。来一个高个子，他就把前面所有比他矮的人"遮住"了（弹出），自己站上去。这就是单调栈的工作原理。

**单调队列 → 候诊室的动态最老病人：**

候诊室是一个有限容量的窗口，新来的人（右边进）比队里某些人年轻，那些年老且已超出窗口范围的人先离开（左边出）。你随时都能知道当前候诊室里"最老"的人是谁。

## 四、核心思想

### 4.1 单调栈

**单调递增栈**：栈内元素从栈底到栈顶单调递增  
**单调递减栈**：栈内元素从栈底到栈顶单调递减

```
求"下一个更大元素"的思路：
  用单调递减栈（从顶到底递减 = 从底到顶递增）：
  遇到比栈顶大的元素 → 栈顶元素的"下一个更大"就是当前元素，弹出栈顶
  直到当前元素 ≤ 栈顶 或 栈空，把当前元素压栈
```

### 4.2 单调队列

**单调递减队列**：队头是最大值，队尾是最小值  
核心：在 O(1) 时间内获取当前窗口的最大（或最小）值

```
滑动窗口最大值思路：
  维护一个单调递减的双端队列（存下标）：
  右边加入：将队尾所有 ≤ 当前值的元素删掉，再加入当前元素
  左边删除：若队头元素已不在窗口内（下标 < left），删除队头
  当前最大值：队头元素
```

## 五、图解推演

### 5.1 单调栈：下一个更大元素

```
数组：[2, 1, 5, 6, 2, 3]

i=0, num=2: 栈空，压入 2。栈=[2]
i=1, num=1: 1≤2，压入 1。栈=[2,1]
i=2, num=5: 5>1 → 1的下一个更大是5，弹出1
            5>2 → 2的下一个更大是5，弹出2
            栈空，压入5。栈=[5]
i=3, num=6: 6>5 → 5的下一个更大是6，弹出5
            栈空，压入6。栈=[6]
i=4, num=2: 2≤6，压入2。栈=[6,2]
i=5, num=3: 3>2 → 2的下一个更大是3，弹出2
            3≤6，压入3。栈=[6,3]

遍历结束，栈中剩余元素无下一个更大：6→-1, 3→-1

结果：[5, 5, 6, -1, 3, -1]
```

### 5.2 单调队列：滑动窗口最大值

```
数组：[1, 3, -1, -3, 5, 3, 6, 7]，k=3

队列存下标，维护单调递减。

i=0(1):  队列=[0]，窗口未满
i=1(3):  3>1，弹出0，队列=[1]，窗口未满
i=2(-1): -1≤3，队列=[1,2]，窗口满，最大=nums[1]=3
i=3(-3): -3≤-1，队列=[1,2,3]，队头1在窗口[1,3]内，最大=nums[1]=3
i=4(5):  5>nums[3]→弹3，5>nums[2]→弹2，5>nums[1]→弹1，队列=[4]
         最大=nums[4]=5
i=5(3):  3≤5，队列=[4,5]，最大=nums[4]=5
i=6(6):  6>nums[5]→弹5，6>nums[4]→弹4，队列=[6]，最大=nums[6]=6
i=7(7):  7>nums[6]→弹6，队列=[7]，最大=nums[7]=7

结果：[3, 3, 5, 5, 6, 7]
```

## 六、执行步骤

**单调栈（下一个更大元素）：**
1. 遍历数组，维护一个存下标（或值）的栈
2. 当前元素 > 栈顶元素时：弹出栈顶，记录"栈顶的下一个更大 = 当前元素"
3. 重复步骤2直到栈空或栈顶 ≥ 当前元素
4. 当前元素入栈

**单调队列（滑动窗口最大值）：**
1. 遍历数组，维护一个存下标的双端队列（单调递减）
2. 队头元素超出窗口范围时，队头出队
3. 当前元素 ≥ 队尾元素时，队尾出队（维护递减性）
4. 当前元素下标入队队尾
5. 窗口满时，队头即为当前窗口最大值

## 七、C# 实现

### 7.1 下一个更大元素（单调栈）

```csharp
using System;
using System.Collections.Generic;

class NextGreaterElement
{
    /// <summary>
    /// 找每个元素右侧第一个比它大的元素
    /// 用单调递减栈（栈顶最小）：当遇到更大值时，弹出栈顶并记录答案
    /// </summary>
    static int[] NextGreater(int[] nums)
    {
        int n = nums.Length;
        int[] result = new int[n];
        Array.Fill(result, -1); // 默认无更大元素

        Stack<int> stack = new Stack<int>(); // 存下标

        for (int i = 0; i < n; i++)
        {
            // 当前元素比栈顶元素大：栈顶元素找到了它的"下一个更大"
            while (stack.Count > 0 && nums[i] > nums[stack.Peek()])
            {
                int idx = stack.Pop();
                result[idx] = nums[i]; // 记录答案
            }
            stack.Push(i); // 当前元素入栈，等待后续更大的元素
        }

        return result;
    }

    static void Main()
    {
        int[] nums = { 2, 1, 5, 6, 2, 3 };
        int[] result = NextGreater(nums);
        Console.WriteLine(string.Join(", ", result)); // 5, 5, 6, -1, 3, -1
    }
}
```

### 7.2 柱状图中最大矩形（单调栈）

```csharp
using System;
using System.Collections.Generic;

class LargestRectangle
{
    /// <summary>
    /// 柱状图中最大矩形面积
    /// 对每根柱子，找到它左边和右边第一个比它矮的柱子
    /// 单调递增栈（栈顶最高）：遇到更矮的柱子时，弹出并计算矩形面积
    /// </summary>
    static int LargestRectangleArea(int[] heights)
    {
        int n = heights.Length;
        int maxArea = 0;

        // 使用哨兵：在数组首尾各加一个高度为0的柱子
        // 这样所有柱子最终都会被弹出栈进行计算
        int[] h = new int[n + 2];
        h[0] = 0;
        for (int i = 0; i < n; i++) h[i + 1] = heights[i];
        h[n + 1] = 0;

        Stack<int> stack = new Stack<int>(); // 存下标，维护单调递增栈
        stack.Push(0); // 先压入左哨兵

        for (int i = 1; i < h.Length; i++)
        {
            // 当前柱子比栈顶矮：弹出栈顶，计算以弹出柱子为高的矩形面积
            while (stack.Count > 0 && h[i] < h[stack.Peek()])
            {
                int top = stack.Pop();  // 弹出的柱子高度
                // 宽度 = 当前下标 - 新栈顶下标 - 1（左右第一个更矮柱子之间的距离）
                int width = i - stack.Peek() - 1;
                int area = h[top] * width;
                maxArea = Math.Max(maxArea, area);
            }
            stack.Push(i);
        }

        return maxArea;
    }

    static void Main()
    {
        int[] heights = { 2, 1, 5, 6, 2, 3 };
        Console.WriteLine($"最大矩形面积：{LargestRectangleArea(heights)}"); // 10
    }
}
```

### 7.3 滑动窗口最大值（单调队列）

```csharp
using System;
using System.Collections.Generic;

class SlidingWindowMaximum
{
    /// <summary>
    /// 大小为 k 的滑动窗口中的最大值
    /// 单调递减双端队列（队头是当前窗口最大值的下标）
    /// </summary>
    static int[] MaxSlidingWindow(int[] nums, int k)
    {
        int n = nums.Length;
        int[] result = new int[n - k + 1];
        // 双端队列存下标，队列中对应的 nums 值保持单调递减
        LinkedList<int> deque = new LinkedList<int>();

        for (int i = 0; i < n; i++)
        {
            // 1. 移除队头中已离开窗口的元素
            while (deque.Count > 0 && deque.First.Value < i - k + 1)
                deque.RemoveFirst();

            // 2. 从队尾移除所有 ≤ 当前值的元素（它们不可能是未来窗口的最大值）
            while (deque.Count > 0 && nums[deque.Last.Value] <= nums[i])
                deque.RemoveLast();

            // 3. 当前下标加入队尾
            deque.AddLast(i);

            // 4. 窗口满时，队头即为当前窗口最大值
            if (i >= k - 1)
                result[i - k + 1] = nums[deque.First.Value];
        }

        return result;
    }

    static void Main()
    {
        int[] nums = { 1, 3, -1, -3, 5, 3, 6, 7 };
        int[] result = MaxSlidingWindow(nums, 3);
        Console.WriteLine(string.Join(", ", result)); // 3, 3, 5, 5, 6, 7
    }
}
```

### 7.4 接雨水（单调栈）

```csharp
using System;
using System.Collections.Generic;

class TrappingRainWater
{
    /// <summary>
    /// 接雨水：计算柱状图能接到多少雨水
    /// 单调递减栈：当遇到更高的柱子时，弹出计算两侧柱子间的积水
    /// </summary>
    static int Trap(int[] height)
    {
        int water = 0;
        Stack<int> stack = new Stack<int>(); // 存下标，维护单调递减

        for (int i = 0; i < height.Length; i++)
        {
            // 当前柱子比栈顶高：可以形成积水
            while (stack.Count > 0 && height[i] > height[stack.Peek()])
            {
                int bottom = stack.Pop(); // 低点（积水底部）

                if (stack.Count == 0) break; // 左边没有柱子，无法积水

                int left = stack.Peek();   // 左边的柱子下标
                int right = i;             // 右边的柱子下标（当前）

                int width = right - left - 1;
                // 积水高度 = min(左柱高, 右柱高) - 底部高度
                int waterHeight = Math.Min(height[left], height[right]) - height[bottom];
                water += width * waterHeight;
            }
            stack.Push(i);
        }

        return water;
    }

    static void Main()
    {
        int[] height = { 0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1 };
        Console.WriteLine($"可接雨水：{Trap(height)}"); // 6
    }
}
```

## 八、示例演示

### 手动推演：柱状图最大矩形 [2,1,5,6,2,3]

```
加哨兵后：[0, 2, 1, 5, 6, 2, 3, 0]
下标：      0  1  2  3  4  5  6  7

i=0(0): 栈=[0]
i=1(2): 2>0，压入。栈=[0,1]
i=2(1): 1<2，弹出1:
  top=1, h[1]=2, 宽=2-0-1=1, 面积=2×1=2
  h[2]=1 ≥ h[0]=0，停止
  压入2。栈=[0,2]
i=3(5): 5>1，压入。栈=[0,2,3]
i=4(6): 6>5，压入。栈=[0,2,3,4]
i=5(2): 2<6，弹出4:
  top=4, h[4]=6, 宽=5-3-1=1, 面积=6×1=6
  2<5，弹出3:
  top=3, h[3]=5, 宽=5-2-1=2, 面积=5×2=10  ← 最大！
  2≥1，停止，压入5。栈=[0,2,5]
...最终最大面积=10
```

## 九、复杂度分析

| 算法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 单调栈（下一更大）| O(n) | O(n) | 每个元素至多入栈/出栈一次 |
| 单调栈（最大矩形）| O(n) | O(n) | 同上 |
| 单调队列（窗口最大值）| O(n) | O(k) | 每个元素至多入队/出队一次 |
| 接雨水（单调栈）| O(n) | O(n) | 同上 |

> 核心优势：每个元素**至多**进出栈（队）一次，所以总体是 O(n)，而非 O(n²)。

## 十、易错点

| 易错点 | 后果 | 正确做法 |
|--------|------|----------|
| 栈中存值而非下标 | 无法计算宽度 | 存下标，需要值时用 `nums[index]` |
| 单调栈方向搞错 | 找的是错误的极值 | 找"下一个更大"用递减栈，找"下一个更小"用递增栈 |
| 滑动窗口忘记移除过期队头 | 队头不在窗口内仍被使用 | 先检查队头是否 `< i - k + 1` |
| 柱状图忘加哨兵 | 栈末尾元素未被处理 | 在数组首尾各加高度为0的柱子 |

## 十一、相似算法对比

| 对比项 | 单调栈 | 单调队列 | 普通栈/队列 |
|--------|--------|---------|-----------|
| 维护的性质 | 单调性 | 单调性 | 无 |
| 解决的问题 | 左/右第一个更大/小 | 滑动窗口极值 | 一般 LIFO/FIFO |
| 时间复杂度 | O(n) | O(n) | 取决于使用方式 |
| 关键操作 | 弹出不满足单调的元素 | 队头、队尾各自弹出 | 无特殊操作 |

## 十四、面试常问点

1. **单调栈的核心思想是什么？**
   - 维护栈的单调性，利用"弹出时一定找到了答案"来 O(n) 解决问题

2. **单调栈求"下一个更大元素"为什么能保证 O(n)？**
   - 每个元素最多入栈一次、出栈一次，共 2n 次操作

3. **滑动窗口最大值为什么用单调队列而不是最大堆？**
   - 单调队列 O(n)；最大堆 O(n log k)，且堆中需要懒惰删除

4. **接雨水有哪些解法？**
   - 动态规划（预处理左右最大值）、双指针、单调栈

5. **柱状图最大矩形中加哨兵的作用是什么？**
   - 确保所有元素都能被处理（最后的高柱在遇到右哨兵时被弹出）
