## 算法定位

选择排序（Selection Sort）属于**选择类排序**算法，是一种简单直观的排序方法。

它解决的问题是：给定一个无序数组，通过每轮从未排序部分选出最小（或最大）的元素，放到已排序部分的末尾，逐步完成排序。

选择排序的特点是**交换次数最少**（每轮最多一次交换），但它是**不稳定**排序。

---

## 一句话理解

> 每一轮从剩下的元素中找到最小的那个，放到前面已排好的位置后面。

---

## 生活化比喻

想象你面前有一堆大小不同的苹果，你要从小到大排成一排：
- 第一次，你扫一眼所有苹果，挑出最小的，放到第一个位置
- 第二次，你从剩下的苹果里再挑最小的，放到第二个位置
- 以此类推，每次都"选择"剩余中最小的

就像考试发成绩单，老师从全班找到最低分排第一名，再找剩余里最低的排第二名……

---

## 核心思想

1. **分区思想**：数组被分为"已排序"和"未排序"两部分
2. **选择最小值**：每轮从未排序部分找到最小元素
3. **交换到位**：将最小元素与未排序部分的第一个元素交换
4. **扩展已排序区域**：已排序部分向右扩展一位

**为什么会想到这种方法？** 因为"每次选最小的放前面"是最符合人类直觉的排序策略，简单明了。

## 图解推演

以数组 `[29, 10, 14, 37, 13]` 为例：

```
初始状态：[29, 10, 14, 37, 13]
           |← 未排序 →|

=== 第 1 轮：从全部元素中找最小值 ===
扫描：29, 10, 14, 37, 13 → 最小值是 10（位置 1）
交换 arr[0] 和 arr[1]：
  [10, 29, 14, 37, 13]
   ✓   |← 未排序 →|

=== 第 2 轮：从位置 1 开始找最小值 ===
扫描：29, 14, 37, 13 → 最小值是 13（位置 4）
交换 arr[1] 和 arr[4]：
  [10, 13, 14, 37, 29]
   ✓   ✓  |← 未排序 →|

=== 第 3 轮：从位置 2 开始找最小值 ===
扫描：14, 37, 29 → 最小值是 14（位置 2）
14 已经在正确位置，无需交换：
  [10, 13, 14, 37, 29]
   ✓   ✓   ✓  |未排序|

=== 第 4 轮：从位置 3 开始找最小值 ===
扫描：37, 29 → 最小值是 29（位置 4）
交换 arr[3] 和 arr[4]：
  [10, 13, 14, 29, 37]
   ✓   ✓   ✓   ✓   ✓

最终结果：[10, 13, 14, 29, 37] ✓
```

---

## 执行步骤

1. 设定已排序区域的边界 `i = 0`
2. 从位置 `i` 到数组末尾，找到最小元素的下标 `minIndex`
3. 将 `arr[minIndex]` 与 `arr[i]` 交换
4. `i` 向右移动一位，扩大已排序区域
5. 重复步骤 2~4，直到 `i` 到达数组末尾前一个位置

## C# 实现

```csharp
using System;

class SelectionSortDemo
{
    /// <summary>
    /// 选择排序 - 标准版本
    /// 每轮从未排序部分选出最小值，放到已排序部分的末尾
    /// </summary>
    static void SelectionSort(int[] arr)
    {
        int n = arr.Length;

        // 外层循环：i 表示已排序区域的边界
        for (int i = 0; i < n - 1; i++)
        {
            int minIndex = i; // 假设当前位置就是最小值

            // 内层循环：从 i+1 开始找真正的最小值
            for (int j = i + 1; j < n; j++)
            {
                if (arr[j] < arr[minIndex])
                {
                    minIndex = j; // 更新最小值的下标
                }
            }

            // 如果最小值不在位置 i，交换
            if (minIndex != i)
            {
                int temp = arr[i];
                arr[i] = arr[minIndex];
                arr[minIndex] = temp;
            }
        }
    }

    /// <summary>
    /// 选择排序 - 双向优化版本
    /// 每轮同时找最小值和最大值，分别放到两端
    /// </summary>
    static void SelectionSortBidirectional(int[] arr)
    {
        int n = arr.Length;
        int left = 0;       // 左边界（已排序最小部分）
        int right = n - 1;  // 右边界（已排序最大部分）

        while (left < right)
        {
            int minIndex = left;
            int maxIndex = left;

            // 同时找最小值和最大值
            for (int i = left; i <= right; i++)
            {
                if (arr[i] < arr[minIndex])
                    minIndex = i;
                if (arr[i] > arr[maxIndex])
                    maxIndex = i;
            }

            // 将最小值交换到左边界
            if (minIndex != left)
            {
                int temp = arr[left];
                arr[left] = arr[minIndex];
                arr[minIndex] = temp;
            }

            // 注意：如果最大值恰好在 left 位置，
            // 经过上面的交换后，最大值已经被换到 minIndex 位置
            if (maxIndex == left)
                maxIndex = minIndex;

            // 将最大值交换到右边界
            if (maxIndex != right)
            {
                int temp = arr[right];
                arr[right] = arr[maxIndex];
                arr[maxIndex] = temp;
            }

            left++;
            right--;
        }
    }

    /// <summary>
    /// 打印数组内容
    /// </summary>
    static void PrintArray(int[] arr)
    {
        Console.WriteLine("[" + string.Join(", ", arr) + "]");
    }

    static void Main(string[] args)
    {
        Console.WriteLine("===== 选择排序演示 =====\n");

        // 标准版本演示
        int[] arr1 = { 29, 10, 14, 37, 13 };
        Console.Write("排序前：");
        PrintArray(arr1);
        SelectionSort(arr1);
        Console.Write("排序后：");
        PrintArray(arr1);

        Console.WriteLine();

        // 双向优化版本演示
        int[] arr2 = { 64, 25, 12, 22, 11, 90, 45 };
        Console.Write("排序前：");
        PrintArray(arr2);
        SelectionSortBidirectional(arr2);
        Console.Write("排序后：");
        PrintArray(arr2);
    }
}
```

## 示例演示

以输入 `[3, 1, 4, 1, 5]` 手动推演：

```
初始：[3, 1, 4, 1, 5]

--- 第 1 轮（i=0）---
  扫描 arr[1..4]：1, 4, 1, 5
  最小值 = 1，位置 = 1
  交换 arr[0] 和 arr[1] → [1, 3, 4, 1, 5]
  已排序：[1]  未排序：[3, 4, 1, 5]

--- 第 2 轮（i=1）---
  扫描 arr[2..4]：4, 1, 5
  最小值 = 1，位置 = 3
  交换 arr[1] 和 arr[3] → [1, 1, 4, 3, 5]
  已排序：[1, 1]  未排序：[4, 3, 5]

--- 第 3 轮（i=2）---
  扫描 arr[3..4]：3, 5
  最小值 = 3，位置 = 3
  交换 arr[2] 和 arr[3] → [1, 1, 3, 4, 5]
  已排序：[1, 1, 3]  未排序：[4, 5]

--- 第 4 轮（i=3）---
  扫描 arr[4]：5
  最小值 = 4，位置 = 3（已在正确位置）
  无需交换 → [1, 1, 3, 4, 5]

最终结果：[1, 1, 3, 4, 5] ✓
```

**注意不稳定性**：原数组中两个 `1` 的相对顺序可能被改变（第一个 `1` 在位置 1，第二个在位置 3，交换后位置 3 的 `1` 跑到了前面）。

## 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| **最好时间** | O(n²) | 即使有序，仍需逐个比较找最小值 |
| **最坏时间** | O(n²) | 与数据状态无关，始终是 n(n-1)/2 次比较 |
| **平均时间** | O(n²) | 比较次数固定 |
| **空间复杂度** | O(1) | 只需常数个额外变量 |
| **稳定性** | 不稳定 | 交换可能打乱相等元素的顺序 |

**通俗解释**：
- 不管数组是什么样的，选择排序都要比较同样多的次数，所以最好和最坏情况一样
- 虽然比较次数多，但**交换次数最多只有 n-1 次**，所以当交换代价很大时，选择排序有优势
- 不稳定的例子：`[5a, 5b, 3]`，第一轮 5a 和 3 交换，变成 `[3, 5b, 5a]`，两个 5 的顺序变了

## 易错点

1. **内层循环起点错误**：应该从 `i + 1` 开始，不是从 `0` 开始
2. **只记录最小值而非下标**：需要记录下标才能交换，只记录值无法完成交换
3. **忘记判断 `minIndex != i`**：当最小值已在正确位置时不需要交换（虽然交换也不会出错，但是浪费操作）
4. **误以为选择排序是稳定的**：这是常见误区，选择排序是不稳定排序

## 相似算法对比

| 特征 | 选择排序 | 冒泡排序 | 堆排序 |
|------|----------|----------|--------|
| **核心操作** | 选最小值交换 | 相邻比较交换 | 堆操作提取最大值 |
| **时间复杂度** | O(n²) | O(n²) | O(n log n) |
| **交换次数** | 最多 n-1 次 | 可能 O(n²) 次 | O(n log n) 次 |
| **稳定性** | 不稳定 | 稳定 | 不稳定 |
| **是否可提前终止** | 不能 | 可以（优化版） | 不能 |
| **关系** | 简单选择 | 简单交换 | 选择排序的升级版 |

**延伸学习**：

- **冒泡排序**：同为 O(n²) 基础排序，但是稳定的

## 记忆口诀

> **每轮选个最小的，放到队伍最前面。比较次数永不变，交换次数最划算。**

## 面试常问点

1. **选择排序是稳定排序吗？为什么？**
   - 不稳定。例如 `[5a, 5b, 3]`，选最小值 3 和 5a 交换后变为 `[3, 5b, 5a]`，5a 和 5b 的相对顺序改变了

2. **选择排序和冒泡排序的区别？**
   - 选择排序每轮只交换一次，冒泡排序每轮可能交换多次
   - 选择排序不稳定，冒泡排序稳定
   - 选择排序最好情况也是 O(n²)，冒泡最好是 O(n)

3. **选择排序的优势是什么？**
   - 交换次数少（最多 n-1 次），当数据交换代价大于比较代价时（例如大对象排序），选择排序有优势

4. **如何把选择排序变成稳定的？**
   - 用"插入"代替"交换"：找到最小值后，不是直接交换，而是把它前面的元素依次后移，然后插入到正确位置。但这样就变成了插入排序的思想

5. **选择排序和堆排序有什么关系？**
   - 堆排序可以看作选择排序的优化版。选择排序每次线性扫描找最值需要 O(n)，堆排序用堆结构将"找最值"优化到了 O(log n)
