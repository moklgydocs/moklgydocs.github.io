## 算法定位

堆排序（Heap Sort）属于**选择类排序**算法，可以看作选择排序的"升级版"。

它解决的问题是：选择排序每轮需要 O(n) 线性扫描找最大值，效率太低。堆排序利用**堆（Heap）**这种数据结构，将"找最大值"的操作优化到 O(log n)，从而将总时间降到 O(n log n)。

堆排序的最大优势是**原地排序 + 保证 O(n log n)**，不需要额外空间。

---

## 一句话理解

> 先把数组建成一个大顶堆（最大值在堆顶），然后反复取出堆顶元素放到数组末尾，再调整堆结构，直到所有元素有序。

---

## 生活化比喻

想象一个公司的组织架构（树形结构），总裁在最上面，每个领导都比下属的能力值高：
- 首先，组织架构调整，确保能力最强的人当总裁（建堆）
- 然后，总裁"毕业"（取出堆顶，放到最终位置）
- 副总裁中能力最强的补上来当新总裁（堆调整）
- 新总裁再"毕业"……
- 反复执行，最终所有人按能力从低到高排列

## 核心思想

### 什么是堆？

堆是一棵**完全二叉树**，分为：
- **大顶堆**：每个节点的值 >= 其子节点的值（根是最大值）
- **小顶堆**：每个节点的值 <= 其子节点的值（根是最小值）

**用数组表示堆**（0-indexed）：
- 父节点：`(i - 1) / 2`
- 左子节点：`2 * i + 1`
- 右子节点：`2 * i + 2`

### 堆排序两步走：

1. **建堆（Build Heap）**：将无序数组调整为大顶堆
2. **排序（Sort）**：反复取堆顶元素，放到数组末尾，调整堆

## 图解推演

以数组 `[4, 10, 3, 5, 1]` 为例：

```
=== 第一步：建大顶堆 ===

原始数组：[4, 10, 3, 5, 1]

对应的完全二叉树：
        4
       / \
     10    3
    / \
   5   1

从最后一个非叶节点开始调整（索引 = n/2 - 1 = 1）

--- 调整节点 1（值=10）---
  左子 = 5，右子 = 1
  10 > 5 且 10 > 1，不需要调整

--- 调整节点 0（值=4）---
  左子 = 10，右子 = 3
  最大子节点 = 10（位置 1）
  4 < 10 → 交换
        10
       / \
      4    3
     / \
    5   1
  继续调整节点 1（值=4）
  左子 = 5，右子 = 1
  最大子节点 = 5（位置 3）
  4 < 5 → 交换
        10
       / \
      5    3
     / \
    4   1

建堆完成：[10, 5, 3, 4, 1]

=== 第二步：排序 ===

--- 第 1 轮 ---
取堆顶 10，与末尾 1 交换 → [1, 5, 3, 4, | 10]
调整堆 [1, 5, 3, 4]：
        1             5            5
       / \    →      / \    →     / \
      5    3        1    3       4    3
     /             /            /
    4             4            1
结果：[5, 4, 3, 1, | 10]

--- 第 2 轮 ---
取堆顶 5，与末尾 1 交换 → [1, 4, 3, | 5, 10]
调整堆 [1, 4, 3]：
        1             4
       / \    →      / \
      4    3        1    3
结果：[4, 1, 3, | 5, 10]

--- 第 3 轮 ---
取堆顶 4，与末尾 3 交换 → [3, 1, | 4, 5, 10]
调整堆 [3, 1]：
        3
       /
      1     → 不需要调整
结果：[3, 1, | 4, 5, 10]

--- 第 4 轮 ---
取堆顶 3，与末尾 1 交换 → [1, | 3, 4, 5, 10]
只剩一个元素，排序完成

最终结果：[1, 3, 4, 5, 10] ✓
```

## 执行步骤

1. **建堆**：从最后一个非叶节点开始，自底向上对每个节点执行"下沉"操作
2. **排序循环**：
   - 将堆顶（最大值）与当前堆的最后一个元素交换
   - 堆的大小减 1（最后一个位置已确定）
   - 对新的堆顶执行"下沉"操作，恢复堆性质
3. 重复步骤 2，直到堆只剩一个元素

**下沉操作（Heapify）**：将一个节点与其较大的子节点交换，直到该节点大于等于其所有子节点。

## C# 实现

```csharp
using System;

class HeapSortDemo
{
    /// <summary>
    /// 堆排序主方法
    /// </summary>
    static void HeapSort(int[] arr)
    {
        int n = arr.Length;

        // 第一步：建大顶堆
        // 从最后一个非叶节点开始，自底向上调整
        // 最后一个非叶节点的索引 = n / 2 - 1
        for (int i = n / 2 - 1; i >= 0; i--)
        {
            Heapify(arr, n, i);
        }

        Console.Write("  建堆完成：");
        PrintArray(arr);

        // 第二步：逐个取出堆顶元素
        for (int i = n - 1; i > 0; i--)
        {
            // 将堆顶（最大值）与当前末尾交换
            Swap(arr, 0, i);

            // 对剩余的 i 个元素重新调整堆
            // 注意堆的大小是 i，不是 n
            Heapify(arr, i, 0);
        }
    }

    /// <summary>
    /// 下沉操作（核心方法）
    /// 将位置 i 的元素下沉到正确位置，维护大顶堆性质
    /// heapSize：当前堆的有效大小
    /// i：需要下沉的节点索引
    /// </summary>
    static void Heapify(int[] arr, int heapSize, int i)
    {
        int largest = i;        // 假设当前节点最大
        int left = 2 * i + 1;  // 左子节点索引
        int right = 2 * i + 2; // 右子节点索引

        // 如果左子节点存在且大于当前最大值
        if (left < heapSize && arr[left] > arr[largest])
        {
            largest = left;
        }

        // 如果右子节点存在且大于当前最大值
        if (right < heapSize && arr[right] > arr[largest])
        {
            largest = right;
        }

        // 如果最大值不是当前节点，交换并继续下沉
        if (largest != i)
        {
            Swap(arr, i, largest);
            // 递归调整被交换的子树
            Heapify(arr, heapSize, largest);
        }
    }

    /// <summary>
    /// 下沉操作 - 迭代版本（避免递归栈开销）
    /// </summary>
    static void HeapifyIterative(int[] arr, int heapSize, int i)
    {
        while (true)
        {
            int largest = i;
            int left = 2 * i + 1;
            int right = 2 * i + 2;

            if (left < heapSize && arr[left] > arr[largest])
                largest = left;
            if (right < heapSize && arr[right] > arr[largest])
                largest = right;

            if (largest == i) break; // 已经满足堆性质，停止

            Swap(arr, i, largest);
            i = largest; // 继续向下调整
        }
    }

    /// <summary>
    /// 堆排序 - 使用小顶堆实现降序排序
    /// </summary>
    static void HeapSortDescending(int[] arr)
    {
        int n = arr.Length;

        // 建小顶堆
        for (int i = n / 2 - 1; i >= 0; i--)
        {
            HeapifyMin(arr, n, i);
        }

        // 逐个取出堆顶（最小值）放到末尾
        for (int i = n - 1; i > 0; i--)
        {
            Swap(arr, 0, i);
            HeapifyMin(arr, i, 0);
        }
        // 结果是降序
    }

    /// <summary>
    /// 小顶堆的下沉操作
    /// </summary>
    static void HeapifyMin(int[] arr, int heapSize, int i)
    {
        int smallest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < heapSize && arr[left] < arr[smallest])
            smallest = left;
        if (right < heapSize && arr[right] < arr[smallest])
            smallest = right;

        if (smallest != i)
        {
            Swap(arr, i, smallest);
            HeapifyMin(arr, heapSize, smallest);
        }
    }

    /// <summary>
    /// 交换数组中两个位置的元素
    /// </summary>
    static void Swap(int[] arr, int i, int j)
    {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

    /// <summary>
    /// 打印数组内容
    /// </summary>
    static void PrintArray(int[] arr)
    {
        Console.WriteLine("[" + string.Join(", ", arr) + "]");
    }

    static void Main(string[] args)
    {
        Console.WriteLine("===== 堆排序演示 =====\n");

        // 升序排序（大顶堆）
        int[] arr1 = { 4, 10, 3, 5, 1 };
        Console.Write("排序前：");
        PrintArray(arr1);
        HeapSort(arr1);
        Console.Write("排序后：");
        PrintArray(arr1);

        Console.WriteLine();

        // 降序排序（小顶堆）
        int[] arr2 = { 12, 11, 13, 5, 6, 7 };
        Console.Write("降序排序前：");
        PrintArray(arr2);
        HeapSortDescending(arr2);
        Console.Write("降序排序后：");
        PrintArray(arr2);

        Console.WriteLine();

        // 大数据量测试
        int[] arr3 = { 64, 34, 25, 12, 22, 11, 90, 45, 78, 56 };
        Console.Write("排序前：");
        PrintArray(arr3);
        HeapSort(arr3);
        Console.Write("排序后：");
        PrintArray(arr3);
    }
}
```

## 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| **最好时间** | O(n log n) | 与数据状态无关 |
| **最坏时间** | O(n log n) | 与数据状态无关 |
| **平均时间** | O(n log n) | 稳定的 O(n log n) |
| **空间复杂度** | O(1) | 原地排序，不需要额外数组 |
| **稳定性** | 不稳定 | 堆调整中的交换可能改变相等元素顺序 |

**通俗解释**：
- **建堆**：O(n)（不是 O(n log n)！因为大部分节点在底层，调整距离短）
- **排序**：每次取堆顶后调整需要 O(log n)，共 n-1 次，所以是 O(n log n)
- **总计**：O(n) + O(n log n) = O(n log n)
- 堆排序的优势：**O(n log n) 保证 + O(1) 空间**，这是归并排序做不到的

## 易错点

1. **建堆起始位置错误**：应该从 `n/2 - 1` 开始（最后一个非叶节点），不是从 0 或 n-1
2. **Heapify 的 heapSize 参数**：排序阶段每轮 heapSize 要减小，不能用数组长度
3. **子节点索引越界**：必须检查 `left < heapSize` 和 `right < heapSize`
4. **混淆大顶堆和小顶堆**：升序排序用大顶堆，降序排序用小顶堆
5. **忘记递归/迭代下沉**：交换后必须继续对被交换的子节点执行 Heapify

```csharp
// 容易忽略的点：排序阶段的 heapSize
for (int i = n - 1; i > 0; i--)
{
    Swap(arr, 0, i);
    Heapify(arr, i, 0);   // 注意这里是 i，不是 n！
    // Heapify(arr, n, 0); // 错误！会把已排好的元素又搅乱
}
```

## 记忆口诀

> **建堆从下往上调，排序每次取堆顶。大堆升序小堆降，原地排序不需空间。**

## 面试常问点

1. **建堆的时间复杂度是多少？为什么不是 O(n log n)？**
   - O(n)。因为大部分节点在树的底层，调整距离很短。数学上可以证明总操作次数约为 2n

2. **堆排序为什么实际速度不如快速排序？**
   - 堆排序的内存访问模式不好（跳跃式访问），CPU 缓存命中率低
   - 快速排序是顺序访问，缓存友好，常数因子更小

3. **什么时候应该选堆排序？**
   - 需要 O(n log n) 最坏时间保证 + O(1) 空间时
   - Top-K 问题（不需要全排序，只需要维护大小为 K 的堆）

4. **堆排序是稳定排序吗？**
   - 不稳定。堆顶与末尾元素交换时，可能改变相等元素的相对顺序

5. **大顶堆排升序，小顶堆排降序，为什么？**
   - 大顶堆每次取最大值放到末尾，从右往左依次确定位置，所以是升序
   - 反之小顶堆取最小值放末尾，得到降序
