## 算法定位

归并排序（Merge Sort）属于**归并类排序**算法，是经典的**分治法**应用。

它解决的问题是：给定一个无序数组，通过不断拆分、排序、合并的方式，高效且稳定地完成排序。

归并排序由 John von Neumann 于 1945 年发明，是**唯一能保证 O(n log n) 最坏时间复杂度的通用比较排序之一**，也是**稳定排序**中效率最高的算法。

---

## 一句话理解

> 把数组不断对半拆分直到每组只有一个元素（天然有序），然后从底向上两两合并成有序数组。

---

## 生活化比喻

想象你和朋友一起整理一大堆打乱的考试卷子（按学号排序）：
- 你们先把卷子分成两半，各自负责一半
- 各自再把自己的一半继续分，分给更多人
- 直到每个人手上只有 1 张卷子（一张卷子天然就是有序的）
- 然后两人一组合并：各自拿出最上面的那张，学号小的先放，依次进行
- 合并后的结果再跟另一组合并，直到所有卷子合并成一摞有序的

这就是"先分后合"的归并排序。

---

## 核心思想

1. **分（Divide）**：将数组从中间一分为二
2. **治（Conquer）**：对左右两半分别递归排序
3. **合（Merge）**：将两个有序子数组合并为一个有序数组

**为什么会想到这种方法？** 合并两个有序数组是一个 O(n) 的简单操作。如果能把数组拆到足够小（1个元素），天然有序，再逐步合并，就能高效排序。

## 执行步骤

1. 如果数组长度小于等于 1，直接返回（基本情况）
2. 找到数组中间位置 `mid`
3. 递归排序左半部分 `arr[left..mid]`
4. 递归排序右半部分 `arr[mid+1..right]`
5. 将两个有序的半部分合并为一个有序数组
6. 合并过程：用两个指针分别指向两个子数组的开头，依次比较，较小的先放入结果数组

## C# 实现

```csharp
using System;

class MergeSortDemo
{
    /// <summary>
    /// 归并排序 - 自顶向下递归版本（主流实现）
    /// </summary>
    static void MergeSort(int[] arr, int left, int right)
    {
        // 基本情况：只有一个元素或无元素
        if (left >= right) return;

        // 计算中间位置（防止整数溢出的写法）
        int mid = left + (right - left) / 2;

        // 递归排序左半部分
        MergeSort(arr, left, mid);

        // 递归排序右半部分
        MergeSort(arr, mid + 1, right);

        // 合并两个有序的半部分
        Merge(arr, left, mid, right);
    }

    /// <summary>
    /// 合并操作：将 arr[left..mid] 和 arr[mid+1..right] 合并为有序数组
    /// 这是归并排序的核心操作
    /// </summary>
    static void Merge(int[] arr, int left, int mid, int right)
    {
        // 创建临时数组来存储合并结果
        int[] temp = new int[right - left + 1];

        int i = left;      // 左半部分的指针
        int j = mid + 1;   // 右半部分的指针
        int k = 0;         // 临时数组的指针

        // 两个子数组都还有元素时，比较并放入较小的
        while (i <= mid && j <= right)
        {
            if (arr[i] <= arr[j])  // <= 保证稳定性
            {
                temp[k++] = arr[i++];
            }
            else
            {
                temp[k++] = arr[j++];
            }
        }

        // 左半部分还有剩余元素，全部放入
        while (i <= mid)
        {
            temp[k++] = arr[i++];
        }

        // 右半部分还有剩余元素，全部放入
        while (j <= right)
        {
            temp[k++] = arr[j++];
        }

        // 将临时数组的结果复制回原数组
        for (int t = 0; t < temp.Length; t++)
        {
            arr[left + t] = temp[t];
        }
    }

    /// <summary>
    /// 归并排序 - 自底向上迭代版本
    /// 不使用递归，直接从最小的子数组开始合并
    /// 避免了递归调用的栈开销
    /// </summary>
    static void MergeSortBottomUp(int[] arr)
    {
        int n = arr.Length;

        // size：当前合并的子数组大小，从 1 开始，每次翻倍
        for (int size = 1; size < n; size *= 2)
        {
            // 遍历所有相邻的 size 大小的子数组对
            for (int left = 0; left < n - size; left += 2 * size)
            {
                int mid = left + size - 1;
                int right = Math.Min(left + 2 * size - 1, n - 1);

                Merge(arr, left, mid, right);
            }
        }
    }

    /// <summary>
    /// 归并排序 - 优化版本
    /// 1. 小数组使用插入排序
    /// 2. 如果左半部分最大值 <= 右半部分最小值，跳过合并
    /// </summary>
    static void MergeSortOptimized(int[] arr, int left, int right)
    {
        // 优化1：小数组使用插入排序（阈值通常取 7~15）
        if (right - left < 15)
        {
            InsertionSort(arr, left, right);
            return;
        }

        int mid = left + (right - left) / 2;
        MergeSortOptimized(arr, left, mid);
        MergeSortOptimized(arr, mid + 1, right);

        // 优化2：如果已经有序，跳过合并
        if (arr[mid] <= arr[mid + 1])
            return;

        Merge(arr, left, mid, right);
    }

    /// <summary>
    /// 辅助方法：对 arr[left..right] 进行插入排序
    /// </summary>
    static void InsertionSort(int[] arr, int left, int right)
    {
        for (int i = left + 1; i <= right; i++)
        {
            int key = arr[i];
            int j = i - 1;
            while (j >= left && arr[j] > key)
            {
                arr[j + 1] = arr[j];
                j--;
            }
            arr[j + 1] = key;
        }
    }

    /// <summary>
    /// 打印数组内容
    /// </summary>
    static void PrintArray(int[] arr)
    {
        Console.WriteLine("[" + string.Join(", ", arr) + "]");
    }

    static void Main(string[] args)
    {
        Console.WriteLine("===== 归并排序演示 =====\n");

        // 自顶向下递归版本
        int[] arr1 = { 38, 27, 43, 3, 9, 82, 10 };
        Console.Write("递归版 - 排序前：");
        PrintArray(arr1);
        MergeSort(arr1, 0, arr1.Length - 1);
        Console.Write("递归版 - 排序后：");
        PrintArray(arr1);

        Console.WriteLine();

        // 自底向上迭代版本
        int[] arr2 = { 12, 11, 13, 5, 6, 7 };
        Console.Write("迭代版 - 排序前：");
        PrintArray(arr2);
        MergeSortBottomUp(arr2);
        Console.Write("迭代版 - 排序后：");
        PrintArray(arr2);

        Console.WriteLine();

        // 优化版本
        int[] arr3 = { 50, 23, 9, 18, 61, 32, 45, 7, 29, 15, 3, 41 };
        Console.Write("优化版 - 排序前：");
        PrintArray(arr3);
        MergeSortOptimized(arr3, 0, arr3.Length - 1);
        Console.Write("优化版 - 排序后：");
        PrintArray(arr3);
    }
}
```

## 示例演示

以输入 `[5, 2, 8, 3]` 手动推演：

```
MergeSort([5, 2, 8, 3], left=0, right=3)

=== 拆分 ===
mid = 1
左半：[5, 2]（left=0, right=1）
右半：[8, 3]（left=2, right=3）

--- 排序左半 [5, 2] ---
  mid = 0
  左：[5]  右：[2]
  合并 [5] 和 [2]：
    比较 5 和 2 → 2 小 → temp=[2]
    左剩 [5] → temp=[2, 5]
  结果：[2, 5]

--- 排序右半 [8, 3] ---
  mid = 2
  左：[8]  右：[3]
  合并 [8] 和 [3]：
    比较 8 和 3 → 3 小 → temp=[3]
    左剩 [8] → temp=[3, 8]
  结果：[3, 8]

=== 合并 [2, 5] 和 [3, 8] ===
  i=0, j=0：比较 2 和 3 → 2 小 → temp=[2]        i=1
  i=1, j=0：比较 5 和 3 → 3 小 → temp=[2, 3]      j=1
  i=1, j=1：比较 5 和 8 → 5 小 → temp=[2, 3, 5]    i=2
  左用完，右剩 [8] → temp=[2, 3, 5, 8]

最终结果：[2, 3, 5, 8] ✓
```

## 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| **最好时间** | O(n log n) | 即使有序也要拆分和合并 |
| **最坏时间** | O(n log n) | 无论何种输入，复杂度不变 |
| **平均时间** | O(n log n) | 稳定的 O(n log n) |
| **空间复杂度** | O(n) | 合并时需要额外的临时数组 |
| **稳定性** | 稳定 | 合并时相等元素优先取左边的 |

**通俗解释**：
- 无论数据怎么排列，归并排序都是 O(n log n)，这是它最大的优势——**没有最坏情况**
- 代价是需要 O(n) 的额外空间来存储合并结果
- 递归深度为 log n，每层处理 n 个元素，所以总时间是 n * log n
- 稳定性来自合并操作中的 `<=` 判断：相等时优先放左边的元素

---

## 易错点

1. **合并时忘记处理剩余元素**：当一个子数组遍历完后，另一个的剩余元素要全部追加
2. **中间位置计算溢出**：`(left + right) / 2` 可能溢出，应该用 `left + (right - left) / 2`
3. **合并后忘记复制回原数组**：临时数组的结果必须写回到 `arr` 的对应位置
4. **稳定性被破坏**：合并时必须用 `arr[i] <= arr[j]`（不是 `<`），相等时优先取左边的
5. **自底向上版本的边界**：右边界需要 `Math.Min(left + 2*size - 1, n - 1)` 防止越界

> **拆到最小再合并，两个有序变一个。先分后治稳如山，时间始终 n log n。**

## 面试常问点

1. **归并排序的时间复杂度在最坏情况下是多少？**
   - O(n log n)，这是归并排序的最大优势——无论何种输入，时间复杂度都不变

2. **归并排序为什么需要 O(n) 的额外空间？**
   - 因为合并两个有序子数组时，不能原地操作（会覆盖还没比较的元素），需要临时数组暂存

3. **归并排序是稳定排序吗？如何保证的？**
   - 是稳定的。在合并时，当两边元素相等时，优先选取左边的元素（`<=` 而非 `<`），保持了相对顺序

4. **归并排序和快速排序如何选择？**
   - 需要稳定性 → 归并；内存紧张 → 快排；需要保证最坏情况 → 归并
   - 实际开发中，大多数语言的标准库对对象排序用归并（稳定），对基本类型用快排（快速）

5. **如何用归并排序求逆序对数量？**
   - 在合并过程中，每当右半部分的元素被选中时（即 `arr[j] < arr[i]`），说明左半部分从 i 到 mid 的所有元素都与 arr[j] 构成逆序对，数量为 `mid - i + 1`

6. **归并排序适合外部排序吗？为什么？**
   - 非常适合。归并排序的合并操作只需要顺序访问数据，不需要随机访问，非常适合磁盘等外部存储设备
