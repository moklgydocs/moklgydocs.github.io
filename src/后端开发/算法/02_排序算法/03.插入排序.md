## 算法定位

插入排序（Insertion Sort）属于**插入类排序**算法，是最贴近人类日常排序习惯的算法。

它解决的问题是：给定一个无序数组，通过将每个元素插入到前面已排序部分的正确位置，使整个数组逐步变为有序。

插入排序在**数据基本有序**时表现极佳，是很多高级排序算法（如 TimSort）的组成部分。

---

## 一句话理解

> 像打扑克牌一样，每摸到一张新牌，就把它插到手中已排好的牌里合适的位置。

---

## 生活化比喻

你在打扑克牌，每次从牌堆摸一张新牌：
- 手里的牌已经从小到大排好了
- 你拿到新牌后，从右往左比较，找到第一个比新牌小的位置
- 把新牌插在它后面
- 这样手里的牌始终是有序的

插入排序就是这个过程的数组版本。

---

## 核心思想

1. **维护有序区**：数组前半部分始终保持有序
2. **逐个插入**：每次取出一个未排序的元素
3. **移位腾位**：在有序区中从后往前比较，把比它大的元素依次后移
4. **插入到位**：找到正确位置后插入

**为什么会想到这种方法？** 因为这就是人类日常整理有序序列的方式——拿到新元素，找到合适位置插进去。

## 图解推演

以数组 `[5, 2, 4, 6, 1, 3]` 为例：

```
初始状态：[5, 2, 4, 6, 1, 3]
          [已排序] [未排序部分]

=== 第 1 轮：取出 2，插入到 [5] 中 ===
  2 < 5 → 5 后移 → [_, 5, 4, 6, 1, 3]
  插入 2 → [2, 5, 4, 6, 1, 3]
            [已排序]

=== 第 2 轮：取出 4，插入到 [2, 5] 中 ===
  4 < 5 → 5 后移 → [2, _, 5, 6, 1, 3]
  4 > 2 → 停止
  插入 4 → [2, 4, 5, 6, 1, 3]
            [已排序 ]

=== 第 3 轮：取出 6，插入到 [2, 4, 5] 中 ===
  6 > 5 → 不需要移动
  → [2, 4, 5, 6, 1, 3]
     [已排序    ]

=== 第 4 轮：取出 1，插入到 [2, 4, 5, 6] 中 ===
  1 < 6 → 6 后移
  1 < 5 → 5 后移
  1 < 4 → 4 后移
  1 < 2 → 2 后移
  插入 1 → [1, 2, 4, 5, 6, 3]
            [已排序       ]

=== 第 5 轮：取出 3，插入到 [1, 2, 4, 5, 6] 中 ===
  3 < 6 → 6 后移
  3 < 5 → 5 后移
  3 < 4 → 4 后移
  3 > 2 → 停止
  插入 3 → [1, 2, 3, 4, 5, 6]
            [全部有序         ] ✓

最终结果：[1, 2, 3, 4, 5, 6] ✓
```

---

## 执行步骤

1. 从第二个元素开始（第一个元素默认已排序）
2. 取出当前元素 `key`
3. 从已排序部分的末尾开始，与 `key` 比较
4. 如果已排序的元素大于 `key`，将该元素后移一位
5. 重复步骤 4，直到找到不大于 `key` 的元素或到达数组开头
6. 将 `key` 放入空出的位置
7. 重复步骤 2~6，直到所有元素处理完

## C# 实现

```csharp
using System;

class InsertionSortDemo
{
    /// <summary>
    /// 插入排序 - 标准版本
    /// 从第二个元素开始，每个元素向前找到合适位置插入
    /// </summary>
    static void InsertionSort(int[] arr)
    {
        int n = arr.Length;

        // 从第二个元素开始，逐个插入
        for (int i = 1; i < n; i++)
        {
            int key = arr[i]; // 取出当前要插入的元素
            int j = i - 1;    // 从已排序部分的最后一个元素开始比较

            // 将比 key 大的元素依次后移
            while (j >= 0 && arr[j] > key)
            {
                arr[j + 1] = arr[j]; // 后移
                j--;
            }

            // 将 key 插入到正确位置
            arr[j + 1] = key;
        }
    }

    /// <summary>
    /// 插入排序 - 二分查找优化版本
    /// 使用二分查找来寻找插入位置，减少比较次数
    /// 注意：移动次数不变，只优化了比较次数
    /// </summary>
    static void InsertionSortBinary(int[] arr)
    {
        int n = arr.Length;

        for (int i = 1; i < n; i++)
        {
            int key = arr[i];

            // 用二分查找在 arr[0..i-1] 中找到 key 应该插入的位置
            int left = 0, right = i - 1;
            while (left <= right)
            {
                int mid = left + (right - left) / 2;
                if (arr[mid] > key)
                    right = mid - 1;
                else
                    left = mid + 1; // 保证稳定性：相等时插入到右边
            }

            // left 就是插入位置，将 left 到 i-1 的元素后移
            for (int j = i - 1; j >= left; j--)
            {
                arr[j + 1] = arr[j];
            }

            arr[left] = key;
        }
    }

    /// <summary>
    /// 插入排序 - 递归版本（仅供理解，实际不推荐使用）
    /// </summary>
    static void InsertionSortRecursive(int[] arr, int n)
    {
        // 基本情况：只有一个元素
        if (n <= 1) return;

        // 先排序前 n-1 个元素
        InsertionSortRecursive(arr, n - 1);

        // 将第 n 个元素插入到已排序部分
        int key = arr[n - 1];
        int j = n - 2;
        while (j >= 0 && arr[j] > key)
        {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }

    /// <summary>
    /// 打印数组内容
    /// </summary>
    static void PrintArray(int[] arr)
    {
        Console.WriteLine("[" + string.Join(", ", arr) + "]");
    }

    static void Main(string[] args)
    {
        Console.WriteLine("===== 插入排序演示 =====\n");

        // 标准版本
        int[] arr1 = { 5, 2, 4, 6, 1, 3 };
        Console.Write("排序前：");
        PrintArray(arr1);
        InsertionSort(arr1);
        Console.Write("排序后：");
        PrintArray(arr1);

        Console.WriteLine();

        // 二分查找优化版本
        int[] arr2 = { 12, 11, 13, 5, 6 };
        Console.Write("排序前：");
        PrintArray(arr2);
        InsertionSortBinary(arr2);
        Console.Write("排序后：");
        PrintArray(arr2);

        Console.WriteLine();

        // 基本有序数组（最佳情况）
        int[] arr3 = { 1, 2, 4, 3, 5, 6, 7 };
        Console.Write("基本有序数组排序前：");
        PrintArray(arr3);
        InsertionSort(arr3);
        Console.Write("基本有序数组排序后：");
        PrintArray(arr3);
    }
}
```

以输入 `[7, 3, 5, 1]` 手动推演：

```
初始：[7, 3, 5, 1]
      已排序：[7]  待处理：3, 5, 1

--- 第 1 轮（i=1，key=3）---
  j=0：arr[0]=7 > 3 → 后移 → [7, 7, 5, 1]
  j=-1：到达开头，停止
  插入 key=3 到位置 0 → [3, 7, 5, 1]
  已排序：[3, 7]

--- 第 2 轮（i=2，key=5）---
  j=1：arr[1]=7 > 5 → 后移 → [3, 7, 7, 1]
  j=0：arr[0]=3 < 5 → 停止
  插入 key=5 到位置 1 → [3, 5, 7, 1]
  已排序：[3, 5, 7]

--- 第 3 轮（i=3，key=1）---
  j=2：arr[2]=7 > 1 → 后移 → [3, 5, 7, 7]
  j=1：arr[1]=5 > 1 → 后移 → [3, 5, 5, 7]
  j=0：arr[0]=3 > 1 → 后移 → [3, 3, 5, 7]
  j=-1：到达开头，停止
  插入 key=1 到位置 0 → [1, 3, 5, 7]

最终结果：[1, 3, 5, 7] ✓
```

## 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| **最好时间** | O(n) | 数组已经有序，每个元素只比较一次 |
| **最坏时间** | O(n²) | 数组完全逆序，每个元素要移动到最前面 |
| **平均时间** | O(n²) | 平均需要移动约 n²/4 次 |
| **空间复杂度** | O(1) | 只需一个 key 变量，原地排序 |
| **稳定性** | 稳定 | 相等元素不会交换相对顺序 |

**通俗解释**：
- 最好情况：数组已有序，如 `[1,2,3,4,5]`，每次 while 循环都不执行，只需 n-1 次比较
- 最坏情况：数组逆序，如 `[5,4,3,2,1]`，每个元素都要移动到最前面
- **插入排序在基本有序的数据上表现接近 O(n)**，这是它的最大优势

---

## 易错点

1. **外层循环从 0 开始**：应该从 `i = 1` 开始，因为第一个元素自身就是有序的
2. **while 循环条件顺序**：`j >= 0` 必须在 `arr[j] > key` 前面，否则 j=-1 时数组越界
3. **插入位置写错**：应该是 `arr[j + 1] = key` 而不是 `arr[j] = key`（因为循环结束时 j 已经多减了一次）
4. **混淆"移位"和"交换"**：插入排序是移位而非交换，每个元素后移一位腾出位置

```csharp
// 常见错误：j >= 0 的检查必须放在前面（短路求值）
while (arr[j] > key && j >= 0)  // 错误！j=-1 时会越界
while (j >= 0 && arr[j] > key)  // 正确！j<0 时不会访问 arr[j]
```

## 相似算法对比

| 特征 | 插入排序 | 冒泡排序 | 希尔排序 |
|------|----------|----------|----------|
| **核心操作** | 找位置插入 | 相邻比较交换 | 分组插入排序 |
| **最好时间** | O(n) | O(n) | O(n log n) |
| **平均时间** | O(n²) | O(n²) | O(n^1.3) |
| **稳定性** | 稳定 | 稳定 | 不稳定 |
| **基本有序表现** | 非常好 | 较好 | 好 |
| **实际效率** | 优于冒泡 | 较低 | 优于插入 |
| **应用场景** | 小数据/基本有序 | 教学 | 中等数据 |

## 面试常问点

1. **插入排序的最好时间复杂度是多少？什么时候出现？**
   - O(n)，当数组已经有序时，每个元素只需比较一次就能确定位置

2. **为什么说插入排序适合基本有序的数据？**
   - 因为数据越有序，需要后移的元素越少，时间越接近 O(n)

3. **插入排序是稳定排序吗？为什么？**
   - 是稳定的。因为插入时遇到相等的元素就停止移动，不会改变相等元素的相对顺序

4. **插入排序和冒泡排序哪个更快？**
   - 一般情况下插入排序更快，因为它用"移位"代替"交换"，赋值次数约为冒泡排序的 1/3

5. **在哪些高级排序算法中会用到插入排序？**
   - TimSort（Python/Java 默认排序）在子数组较小时使用插入排序
   - 快速排序的优化版本在子数组小于某个阈值时切换为插入排序
   - 希尔排序本质上就是改进的插入排序
