## 1. 算法定位

组合数学是计数问题的核心工具，排列（有序选取）和组合（无序选取）是最基础的计数方法。杨辉三角提供了高效计算组合数的途径，卡特兰数则解决了一类经典的递推计数问题。

## 2. 一句话理解

> **排列**是"从n个中选k个并排成一列"的方案数；**组合**是"从n个中选k个不管顺序"的方案数；两者关系：C(n,k) = P(n,k) / k!。

## 3. 生活化比喻

- **排列 P(5,3)**：从5个人中选3个站成一排拍照，不同站位算不同方案
- **组合 C(5,3)**：从5个人中选3个组成小组，谁站哪里无所谓
- **杨辉三角**：每个数等于上方两个数之和，像一个自动生成组合数的"金字塔"

## 4. 核心思想

### 基本公式

| 概念 | 公式 | 说明 |
|------|------|------|
| 排列 | P(n,k) = n! / (n-k)! | 有序选取 |
| 组合 | C(n,k) = n! / (k!(n-k)!) | 无序选取 |
| 关系 | C(n,k) = P(n,k) / k! | 组合去掉排序 |

### 组合数性质

```
C(n, 0) = C(n, n) = 1
C(n, k) = C(n, n-k)              (对称性)
C(n, k) = C(n-1, k-1) + C(n-1, k) (递推关系/杨辉三角)
C(n, 0) + C(n, 1) + ... + C(n, n) = 2^n
```

### 杨辉三角（Pascal's Triangle）

```
行0:                1
行1:              1   1
行2:            1   2   1
行3:          1   3   3   1
行4:        1   4   6   4   1
行5:      1   5  10  10   5   1
行6:    1   6  15  20  15   6   1

第n行第k列的值 = C(n, k)
```

## 5. 图解推演

### 排列示例：P(4,2) = 从ABCD中选2个排列

```
A开头: AB, AC, AD     (3种)
B开头: BA, BC, BD     (3种)
C开头: CA, CB, CD     (3种)
D开头: DA, DB, DC     (3种)

总数 = 4 × 3 = 12 = P(4,2) = 4!/(4-2)! = 24/2 = 12 ✓
```

### 组合示例：C(4,2) = 从ABCD中选2个组合

```
{A,B} {A,C} {A,D}
{B,C} {B,D}
{C,D}

总数 = 6 = C(4,2) = 4!/(2!×2!) = 24/4 = 6 ✓
也等于 P(4,2)/P(2,2) = 12/2 = 6
```

### 杨辉三角递推

```
C(4,2) = C(3,1) + C(3,2) = 3 + 3 = 6

图示:
         C(3,1)=3   C(3,2)=3
              \      /
           C(4,2) = 6

每个数 = 左上方 + 右上方
```

### 卡特兰数

```
卡特兰数: 1, 1, 2, 5, 14, 42, 132, ...
Cn = C(2n, n) / (n+1)

应用场景:
- n对合法括号组合数
- n个节点的不同BST数量
- n+1个矩阵连乘的括号化方式
- 进出栈的合法序列数
- 凸n+2边形的三角剖分数

n=3时的5种合法括号:
((())), (()()), (())(), ()(()), ()()()
```

## 6. 执行步骤

### 计算C(n,k)的方法

**方法1：递推法（杨辉三角）**
1. 建立二维DP表
2. dp[i][0] = dp[i][i] = 1
3. dp[i][j] = dp[i-1][j-1] + dp[i-1][j]

**方法2：公式法**
1. C(n,k) = n × (n-1) × ... × (n-k+1) / k!
2. 边乘边除避免溢出

**方法3：取模用逆元**
1. 预处理阶乘和逆阶乘
2. C(n,k) = fact[n] × inv_fact[k] × inv_fact[n-k] % mod

## 7. C# 实现

```csharp
using System;
using System.Collections.Generic;

/// <summary>
/// 组合数学算法
/// </summary>
public class Combinatorics
{
    /// <summary>
    /// 计算排列数 P(n, k) = n! / (n-k)!
    /// </summary>
    public long Permutation(int n, int k)
    {
        if (k > n || k < 0) return 0;

        long result = 1;
        for (int i = n; i > n - k; i--)
        {
            result *= i;
        }
        return result;
    }

    /// <summary>
    /// 计算组合数 C(n, k) - 直接计算法
    /// 利用 C(n,k) = C(n, n-k) 和 边乘边除 避免溢出
    /// </summary>
    public long Combination(int n, int k)
    {
        if (k > n || k < 0) return 0;

        // 利用对称性减少计算
        if (k > n - k) k = n - k;

        long result = 1;
        for (int i = 0; i < k; i++)
        {
            result *= (n - i);    // 分子: n, n-1, ..., n-k+1
            result /= (i + 1);   // 分母: 1, 2, ..., k
        }
        return result;
    }

    /// <summary>
    /// 杨辉三角法计算组合数（DP方式）
    /// 适用于需要多次查询C(n,k)的场景
    /// 时间: O(n²), 空间: O(n²)
    /// </summary>
    public long[,] BuildPascalTriangle(int maxN)
    {
        var C = new long[maxN + 1, maxN + 1];

        for (int i = 0; i <= maxN; i++)
        {
            C[i, 0] = 1;  // C(n, 0) = 1
            C[i, i] = 1;  // C(n, n) = 1

            for (int j = 1; j < i; j++)
            {
                // 核心递推: C(n,k) = C(n-1,k-1) + C(n-1,k)
                C[i, j] = C[i - 1, j - 1] + C[i - 1, j];
            }
        }

        return C;
    }

    /// <summary>
    /// 模运算下的组合数（使用费马小定理求逆元）
    /// 适用于大数取模的场景，mod必须是素数
    /// </summary>
    public class CombinationMod
    {
        private long[] _fact;     // 阶乘
        private long[] _invFact;  // 逆阶乘
        private long _mod;

        public CombinationMod(int maxN, long mod)
        {
            _mod = mod;
            _fact = new long[maxN + 1];
            _invFact = new long[maxN + 1];

            // 预处理阶乘
            _fact[0] = 1;
            for (int i = 1; i <= maxN; i++)
            {
                _fact[i] = _fact[i - 1] * i % mod;
            }

            // 预处理逆阶乘（费马小定理: a^(p-2) ≡ a^(-1) mod p）
            _invFact[maxN] = PowerMod(_fact[maxN], mod - 2, mod);
            for (int i = maxN - 1; i >= 0; i--)
            {
                _invFact[i] = _invFact[i + 1] * (i + 1) % mod;
            }
        }

        /// <summary>
        /// O(1) 查询 C(n, k) mod p
        /// </summary>
        public long Query(int n, int k)
        {
            if (k > n || k < 0) return 0;
            return _fact[n] * _invFact[k] % _mod * _invFact[n - k] % _mod;
        }

        private long PowerMod(long baseNum, long exp, long mod)
        {
            long result = 1;
            baseNum %= mod;
            while (exp > 0)
            {
                if ((exp & 1) == 1)
                    result = result * baseNum % mod;
                baseNum = baseNum * baseNum % mod;
                exp >>= 1;
            }
            return result;
        }
    }

    /// <summary>
    /// 计算卡特兰数 Cn = C(2n, n) / (n+1)
    /// </summary>
    public long CatalanNumber(int n)
    {
        // Cn = C(2n, n) / (n + 1)
        return Combination(2 * n, n) / (n + 1);
    }

    /// <summary>
    /// 卡特兰数取模
    /// </summary>
    public long CatalanNumberMod(int n, long mod)
    {
        var comb = new CombinationMod(2 * n, mod);
        long c2n_n = comb.Query(2 * n, n);
        // Cn = C(2n,n) * inverse(n+1) mod p
        long invN1 = PowerMod(n + 1, mod - 2, mod);
        return c2n_n * invN1 % mod;
    }

    private long PowerMod(long baseNum, long exp, long mod)
    {
        long result = 1;
        baseNum %= mod;
        while (exp > 0)
        {
            if ((exp & 1) == 1)
                result = result * baseNum % mod;
            baseNum = baseNum * baseNum % mod;
            exp >>= 1;
        }
        return result;
    }

    /// <summary>
    /// 生成排列（全排列）
    /// </summary>
    public List<List<int>> GeneratePermutations(int[] nums)
    {
        var result = new List<List<int>>();
        Permute(nums, 0, result);
        return result;
    }

    private void Permute(int[] nums, int start, List<List<int>> result)
    {
        if (start == nums.Length)
        {
            result.Add(new List<int>(nums));
            return;
        }

        for (int i = start; i < nums.Length; i++)
        {
            (nums[start], nums[i]) = (nums[i], nums[start]);  // 交换
            Permute(nums, start + 1, result);
            (nums[start], nums[i]) = (nums[i], nums[start]);  // 回溯
        }
    }

    /// <summary>
    /// 生成组合
    /// </summary>
    public List<List<int>> GenerateCombinations(int n, int k)
    {
        var result = new List<List<int>>();
        Combine(n, k, 1, new List<int>(), result);
        return result;
    }

    private void Combine(int n, int k, int start, List<int> current, List<List<int>> result)
    {
        if (current.Count == k)
        {
            result.Add(new List<int>(current));
            return;
        }

        // 剪枝: 剩余元素不够时不继续
        for (int i = start; i <= n - (k - current.Count) + 1; i++)
        {
            current.Add(i);
            Combine(n, k, i + 1, current, result);
            current.RemoveAt(current.Count - 1);  // 回溯
        }
    }

    /// <summary>
    /// 打印杨辉三角
    /// </summary>
    public void PrintPascalTriangle(int rows)
    {
        Console.WriteLine("杨辉三角 (Pascal's Triangle):");
        var C = BuildPascalTriangle(rows);

        for (int i = 0; i < rows; i++)
        {
            // 打印前导空格
            Console.Write(new string(' ', (rows - i) * 2));
            for (int j = 0; j <= i; j++)
            {
                Console.Write($"{C[i, j],4}");
            }
            Console.WriteLine();
        }
    }
}

/// <summary>
/// 测试程序
/// </summary>
public class Program
{
    public static void Main()
    {
        var comb = new Combinatorics();

        // 排列与组合
        Console.WriteLine("=== 排列与组合 ===");
        Console.WriteLine($"P(5,3) = {comb.Permutation(5, 3)}");  // 60
        Console.WriteLine($"P(4,2) = {comb.Permutation(4, 2)}");  // 12
        Console.WriteLine($"C(5,3) = {comb.Combination(5, 3)}");  // 10
        Console.WriteLine($"C(4,2) = {comb.Combination(4, 2)}");  // 6
        Console.WriteLine($"C(10,4) = {comb.Combination(10, 4)}"); // 210

        // 杨辉三角
        Console.WriteLine("\n=== 杨辉三角 ===");
        comb.PrintPascalTriangle(7);

        // 验证杨辉三角
        Console.WriteLine("\n验证: 杨辉三角第5行 = C(5,0)..C(5,5):");
        var pascal = comb.BuildPascalTriangle(10);
        for (int k = 0; k <= 5; k++)
        {
            Console.Write($"C(5,{k})={pascal[5, k]} ");
        }
        Console.WriteLine();

        // 组合数取模
        Console.WriteLine("\n=== 组合数取模 (mod 10^9+7) ===");
        long mod = 1000000007;
        var combMod = new Combinatorics.CombinationMod(100000, mod);
        Console.WriteLine($"C(10, 3) mod 10^9+7 = {combMod.Query(10, 3)}");
        Console.WriteLine($"C(100, 50) mod 10^9+7 = {combMod.Query(100, 50)}");
        Console.WriteLine($"C(1000, 500) mod 10^9+7 = {combMod.Query(1000, 500)}");

        // 卡特兰数
        Console.WriteLine("\n=== 卡特兰数 ===");
        Console.Write("Catalan数列: ");
        for (int i = 0; i <= 8; i++)
        {
            Console.Write($"C{i}={comb.CatalanNumber(i)} ");
        }
        Console.WriteLine();
        Console.WriteLine("应用: C3=5 表示3对括号有5种合法排列");

        // 生成组合
        Console.WriteLine("\n=== 生成C(4,2)的所有组合 ===");
        var combinations = comb.GenerateCombinations(4, 2);
        foreach (var c in combinations)
        {
            Console.Write($"{{{string.Join(",", c)}}} ");
        }
        Console.WriteLine();

        // 生成全排列
        Console.WriteLine("\n=== 生成{1,2,3}的全排列 ===");
        var perms = comb.GeneratePermutations(new[] { 1, 2, 3 });
        foreach (var p in perms)
        {
            Console.Write($"[{string.Join(",", p)}] ");
        }
        Console.WriteLine($"\n共 {perms.Count} 种 = P(3,3) = 3! = 6");
    }
}
```

## 9. 复杂度分析

| 计算方法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---------|-----------|-----------|---------|
| 直接公式 | O(k) | O(1) | 单次查询 |
| 杨辉三角DP | O(n²) | O(n²) | 多次查询 |
| 逆元预处理 | O(n)预处理, O(1)查询 | O(n) | 大量取模查询 |
| 生成排列 | O(n!) | O(n) | 枚举所有排列 |
| 生成组合 | O(C(n,k)) | O(k) | 枚举所有组合 |

## 10. 易错点

1. **溢出问题**：C(30,15)已超过int范围，需要用long或取模
2. **边乘边除**：直接算法中必须保证整除（数学上保证的）
3. **杨辉三角边界**：C[i][0] = C[i][i] = 1 必须初始化
4. **取模逆元**：mod必须是素数才能用费马小定理
5. **卡特兰数溢出**：直接用公式容易溢出，取模时用逆元

## 11. 对比表

| 对比维度 | 排列 P(n,k) | 组合 C(n,k) |
|---------|-------------|-------------|
| 含义 | 有序选取 | 无序选取 |
| 公式 | n!/(n-k)! | n!/(k!(n-k)!) |
| 大小关系 | P(n,k) ≥ C(n,k) | C(n,k) = P(n,k)/k! |
| 特殊值 | P(n,n) = n! | C(n,n) = 1 |
| 应用 | 排队、编号、密码 | 分组、选取、路径 |

| 计算C(n,k)的方法 | 优点 | 缺点 |
|-----------------|------|------|
| 直接公式 | 简单 | 大数溢出 |
| 杨辉三角 | 多次查询快 | 空间大 |
| 逆元法 | O(1)查询+取模 | mod必须素数 |

## 14. 面试常问点

1. **C(n,k)的计算方法有哪些？** → 公式法/杨辉三角DP/逆元法
2. **如何避免组合数溢出？** → 边乘边除 或 取模
3. **杨辉三角的递推关系？** → C(n,k) = C(n-1,k-1) + C(n-1,k)
4. **卡特兰数是什么？有什么应用？** → C(2n,n)/(n+1)，括号/BST等
5. **如何在O(1)时间查询C(n,k) mod p？** → 预处理阶乘+逆阶乘
6. **如何生成所有组合/排列？** → 回溯法
