## 1. 算法定位

快速幂（Binary Exponentiation）是计算 a^n 的高效算法，通过**二进制分解指数**，将朴素O(n)的连续乘法优化为O(log n)。是模运算、密码学（RSA）的核心技术。

## 2. 一句话理解

> 将指数用**二进制分解**，利用 a^(2k) = (a^k)² 的性质，通过反复平方将乘法次数从n次减少到log(n)次。

## 3. 生活化比喻

计算 2^10：
- **朴素方法**：2×2×2×2×2×2×2×2×2×2 = 做9次乘法
- **快速幂**：2→4→16→256→1024，利用平方跳跃式增长
  - 2² = 4
  - 4² = 16
  - 16² = 256（但我们要2^10不是2^8）
  - 10 = 8 + 2，所以 2^10 = 2^8 × 2^2 = 256 × 4 = 1024

就像翻倍增长代替逐一增长。

## 4. 核心思想

### 二进制分解

将指数n表示为二进制，例如 n=13 = (1101)₂ = 8+4+1

```
a^13 = a^(8+4+1) = a^8 × a^4 × a^1
```

每一位对应一个 a 的 2^k 次方，而 a^(2^k) 可以通过不断平方得到：
- a^1 = a
- a^2 = (a^1)²
- a^4 = (a^2)²
- a^8 = (a^4)²

### 算法逻辑

```
result = 1
base = a
while n > 0:
    if n 的最低位是 1:
        result *= base    // 乘入结果
    base *= base          // 底数平方
    n >>= 1              // 右移（去掉最低位）
```

## 5. 图解推演

### 示例：计算 3^13

```
13 的二进制: 1101

步骤   n(二进制)   n最低位   base      result
初始   1101        -        3         1
1      1101        1        3         1 × 3 = 3
       (右移→)     
2      110         0        3²=9      3 (不乘)
       (右移→)
3      11          1        9²=81     3 × 81 = 243
       (右移→)
4      1           1        81²=6561  243 × 6561 = 1594323

验证: 3^13 = 1594323 ✓
总共只做了 4次平方 + 3次乘法 = 7次运算（而非12次连乘）
```

### 模运算示例：计算 2^10 mod 1000

```
10 的二进制: 1010

步骤   n(二进制)   n最低位   base(mod1000)   result(mod1000)
初始   1010        -        2               1
1      1010        0        2               1 (不乘)
       (右移→)
2      101         1        4               1 × 4 = 4
       (右移→)
3      10          0        16              4 (不乘)
       (右移→)
4      1           1        256             4 × 256 = 1024 mod 1000 = 24

结果: 2^10 mod 1000 = 24
验证: 2^10 = 1024, 1024 mod 1000 = 24 ✓
```

### 乘法次数对比

```
指数n     朴素法乘法次数    快速幂乘法次数
4         3                2 (平方两次)
8         7                3 (平方三次)
16        15               4
64        63               6
1000      999              ~10
10^9      10^9-1           ~30

快速幂: ≈ 2*log₂(n) 次乘法
```

## 6. 执行步骤

1. 初始化 result = 1，base = a
2. 当 n > 0 时循环：
   - 如果 n 的最低位为1（n & 1 == 1）→ result = result * base
   - base = base * base（平方）
   - n 右移一位（n >>= 1）
3. 返回 result

对于模运算，每次乘法后取模即可。

## 7. C# 实现

```csharp
using System;

/// <summary>
/// 快速幂算法
/// </summary>
public class FastPower
{
    /// <summary>
    /// 快速幂（不取模版本）
    /// 计算 base^exp
    /// 时间复杂度: O(log n)
    /// </summary>
    public long Power(long baseNum, long exp)
    {
        long result = 1;

        while (exp > 0)
        {
            // 如果指数的最低位为1，乘入结果
            if ((exp & 1) == 1)
            {
                result *= baseNum;
            }

            // 底数平方
            baseNum *= baseNum;

            // 指数右移（去掉最低位）
            exp >>= 1;
        }

        return result;
    }

    /// <summary>
    /// 快速幂取模（最常用版本）
    /// 计算 (base^exp) % mod
    /// 关键：每步取模防止溢出
    /// </summary>
    public long PowerMod(long baseNum, long exp, long mod)
    {
        if (mod == 1) return 0;  // 任何数mod1都是0

        long result = 1;
        baseNum %= mod;  // 先对底数取模

        while (exp > 0)
        {
            // 如果指数的最低位为1
            if ((exp & 1) == 1)
            {
                result = result * baseNum % mod;  // 乘入结果并取模
            }

            // 底数平方并取模
            baseNum = baseNum * baseNum % mod;

            // 指数右移
            exp >>= 1;
        }

        return result;
    }

    /// <summary>
    /// 递归版快速幂（更直观）
    /// </summary>
    public long PowerRecursive(long baseNum, long exp, long mod)
    {
        if (exp == 0) return 1 % mod;  // 任何数的0次方为1

        // 递归计算 base^(exp/2)
        long half = PowerRecursive(baseNum, exp / 2, mod);

        // 平方
        long result = half * half % mod;

        // 如果指数是奇数，还要多乘一个base
        if (exp % 2 == 1)
        {
            result = result * (baseNum % mod) % mod;
        }

        return result;
    }

    /// <summary>
    /// 大数快速幂（使用BigInteger防溢出）
    /// 用于超大数的情况
    /// </summary>
    public long PowerModSafe(long baseNum, long exp, long mod)
    {
        // 对于可能溢出的大mod情况，使用128位运算
        // 这里简化处理，实际大数应用用BigInteger
        if (mod == 1) return 0;

        long result = 1;
        baseNum %= mod;

        while (exp > 0)
        {
            if ((exp & 1) == 1)
            {
                result = MultiplyMod(result, baseNum, mod);
            }
            baseNum = MultiplyMod(baseNum, baseNum, mod);
            exp >>= 1;
        }

        return result;
    }

    /// <summary>
    /// 防溢出的模乘法（用于mod接近long上限时）
    /// </summary>
    private long MultiplyMod(long a, long b, long mod)
    {
        // 简单版本：对于mod < 2^31的情况直接乘即可
        return a * b % mod;
        // 对于更大的mod，需要使用__int128或BigInteger
    }

    /// <summary>
    /// 矩阵快速幂（用于求斐波那契数列等）
    /// </summary>
    public long[,] MatrixPower(long[,] matrix, long exp, long mod)
    {
        int n = matrix.GetLength(0);
        // 初始化单位矩阵
        var result = new long[n, n];
        for (int i = 0; i < n; i++) result[i, i] = 1;

        while (exp > 0)
        {
            if ((exp & 1) == 1)
            {
                result = MatrixMultiply(result, matrix, mod);
            }
            matrix = MatrixMultiply(matrix, matrix, mod);
            exp >>= 1;
        }

        return result;
    }

    /// <summary>
    /// 矩阵乘法
    /// </summary>
    private long[,] MatrixMultiply(long[,] A, long[,] B, long mod)
    {
        int n = A.GetLength(0);
        var C = new long[n, n];

        for (int i = 0; i < n; i++)
        {
            for (int j = 0; j < n; j++)
            {
                for (int k = 0; k < n; k++)
                {
                    C[i, j] = (C[i, j] + A[i, k] * B[k, j]) % mod;
                }
            }
        }

        return C;
    }

    /// <summary>
    /// 应用：用矩阵快速幂求第n个斐波那契数
    /// F(n) = [[1,1],[1,0]]^n 的 [0,0] 元素
    /// </summary>
    public long Fibonacci(long n, long mod)
    {
        if (n <= 1) return n;

        // 斐波那契矩阵
        var matrix = new long[,] { { 1, 1 }, { 1, 0 } };

        var result = MatrixPower(matrix, n - 1, mod);
        return result[0, 0];
    }

    /// <summary>
    /// 带过程输出的快速幂
    /// </summary>
    public long PowerWithTrace(long baseNum, long exp, long mod)
    {
        Console.WriteLine($"计算 {baseNum}^{exp} mod {mod}");
        Console.WriteLine($"指数 {exp} 的二进制: {Convert.ToString(exp, 2)}");
        Console.WriteLine();

        long result = 1;
        long origBase = baseNum;
        baseNum %= mod;
        int step = 0;

        while (exp > 0)
        {
            step++;
            bool bit = (exp & 1) == 1;

            if (bit)
            {
                long oldResult = result;
                result = result * baseNum % mod;
                Console.WriteLine($"步骤{step}: 位=1, result = {oldResult} × {baseNum} mod {mod} = {result}");
            }
            else
            {
                Console.WriteLine($"步骤{step}: 位=0, result 不变 = {result}");
            }

            long oldBase = baseNum;
            baseNum = baseNum * baseNum % mod;
            Console.WriteLine($"       base = {oldBase}² mod {mod} = {baseNum}");

            exp >>= 1;
        }

        Console.WriteLine($"\n结果: {origBase}^原指数 mod {mod} = {result}");
        return result;
    }
}

/// <summary>
/// 测试程序
/// </summary>
public class Program
{
    public static void Main()
    {
        var fp = new FastPower();

        // 基础快速幂
        Console.WriteLine("=== 基础快速幂 ===");
        Console.WriteLine($"2^10 = {fp.Power(2, 10)}");
        Console.WriteLine($"3^13 = {fp.Power(3, 13)}");

        // 带过程的快速幂取模
        Console.WriteLine("\n=== 快速幂取模（详细过程）===");
        fp.PowerWithTrace(2, 10, 1000);

        Console.WriteLine();
        fp.PowerWithTrace(3, 13, 100);

        // 常见应用
        Console.WriteLine("\n=== 常见应用 ===");
        Console.WriteLine($"7^256 mod 13 = {fp.PowerMod(7, 256, 13)}");
        Console.WriteLine($"2^1000000007 mod 1000000007 = {fp.PowerMod(2, 1000000007, 1000000007)}");

        // 矩阵快速幂求斐波那契
        Console.WriteLine("\n=== 矩阵快速幂 - 斐波那契数列 ===");
        long mod = 1000000007;
        for (int n = 1; n <= 10; n++)
        {
            Console.Write($"F({n})={fp.Fibonacci(n, mod)} ");
        }
        Console.WriteLine();
        Console.WriteLine($"F(50) mod 10^9+7 = {fp.Fibonacci(50, mod)}");
        Console.WriteLine($"F(100) mod 10^9+7 = {fp.Fibonacci(100, mod)}");
    }
}
```

## 9. 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 朴素连乘 | O(n) | O(1) | n次乘法 |
| 快速幂(迭代) | O(log n) | O(1) | 最优 |
| 快速幂(递归) | O(log n) | O(log n) | 递归栈 |
| 矩阵快速幂 | O(k³ log n) | O(k²) | k为矩阵大小 |

## 10. 易错点

1. **溢出问题**：`base * base` 可能溢出long，需要及时取模
2. **mod=1**：任何数对1取模都是0，需要特判
3. **指数为0**：任何数的0次方是1（0^0 在算法中也定义为1）
4. **底数为0**：0的正数次方是0，注意特殊处理
5. **位运算优先级**：`(exp & 1) == 1` 注意加括号，& 的优先级低于 ==

## 11. 对比表

| 对比维度 | 朴素法 | 快速幂 | 矩阵快速幂 |
|---------|--------|--------|-----------|
| 时间 | O(n) | O(log n) | O(k³ log n) |
| 用途 | 小指数 | 大指数取模 | 线性递推 |
| 实现难度 | 简单 | 简单 | 中等 |
| 应用 | 少 | 密码学/竞赛 | 斐波那契/状态转移 |

## 12. 前置知识与延伸

### 前置知识
- 二进制表示
- 位运算（与、右移）
- 模运算性质：(a*b) mod m = ((a mod m) * (b mod m)) mod m

### 延伸学习
- **RSA加密** → 大数快速幂取模是核心操作
- **费马小定理** → a^(p-1) ≡ 1 (mod p)，求模逆元
- **矩阵快速幂** → 加速线性递推（斐波那契、状态转移）
- **欧拉定理** → a^φ(m) ≡ 1 (mod m)，费马小定理的推广

### RSA概念

```
RSA密钥生成:
1. 选两个大素数 p, q
2. n = p * q
3. 公钥 e, 私钥 d, 满足 e*d ≡ 1 (mod φ(n))

加密: C = M^e mod n    ← 快速幂!
解密: M = C^d mod n    ← 快速幂!
```
