## 1. 算法定位

图是描述**多对多关系**的数据结构，广泛应用于社交网络、地图导航、网络拓扑等领域。掌握图的存储方式（邻接矩阵/邻接表）和遍历算法（DFS/BFS）是所有图算法的基础。

## 2. 一句话理解

> 图由**顶点**和**边**组成，通过邻接矩阵或邻接表存储连接关系，通过DFS（深度优先）和BFS（广度优先）系统地访问所有顶点。

## 3. 生活化比喻

- **图的结构**：城市（顶点）之间的公路网（边），有些公路是单行道（有向图），有些有距离标注（带权图）
- **DFS遍历**：像一个探险者，一条路走到黑，走不通了再回头换路
- **BFS遍历**：像水波扩散，先访问所有近邻，再访问邻居的邻居

## 4. 核心思想

### 图的分类

| 类型 | 说明 |
|------|------|
| 有向图/无向图 | 边是否有方向 |
| 带权图/无权图 | 边是否有权重 |
| 连通图/非连通图 | 是否所有顶点可达 |
| 稀疏图/稠密图 | 边数相对顶点数的多少 |

### 两种存储方式

| 存储方式 | 空间 | 查边 | 适用场景 |
|---------|------|------|---------|
| 邻接矩阵 | O(V²) | O(1) | 稠密图 |
| 邻接表 | O(V+E) | O(度) | 稀疏图 |

## 5. 图解推演

### 示例图

```
无向图:                    有向图:
  0 --- 1                    0 → 1
  |   / |                    ↓   ↗ |
  |  /  |                    |  /  ↓
  | /   |                    | /   |
  2 --- 3                    2 → 3

边: (0,1)(0,2)(1,2)(1,3)(2,3)    边: (0,1)(0,2)(1,3)(2,1)(2,3)
```

### 邻接矩阵表示（无向图）

```
    0  1  2  3
0 [ 0  1  1  0 ]
1 [ 1  0  1  1 ]
2 [ 1  1  0  1 ]
3 [ 0  1  1  0 ]

特点：对称矩阵（无向图）
matrix[i][j] = 1 表示 i 和 j 之间有边
```

### 邻接表表示（无向图）

```
0 → [1, 2]
1 → [0, 2, 3]
2 → [0, 1, 3]
3 → [1, 2]

特点：每个顶点存储其邻居列表
```

### DFS遍历过程（从顶点0开始）

```
访问 0 → 标记已访问
  访问 1（0的邻居）→ 标记已访问
    访问 2（1的邻居）→ 标记已访问
      访问 3（2的邻居）→ 标记已访问
        1已访问，2已访问 → 回溯
      回溯到2
    回溯到1
  回溯到0

DFS序列: 0 → 1 → 2 → 3
```

### BFS遍历过程（从顶点0开始）

```
队列: [0]          访问: {0}
弹出0, 邻居1,2入队
队列: [1, 2]      访问: {0, 1, 2}
弹出1, 邻居3入队(0,2已访问)
队列: [2, 3]      访问: {0, 1, 2, 3}
弹出2, 邻居都已访问
队列: [3]
弹出3, 邻居都已访问
队列: []           完成

BFS序列: 0 → 1 → 2 → 3
```

## 6. 执行步骤

### DFS步骤（递归）
1. 标记当前顶点为已访问
2. 处理当前顶点
3. 遍历当前顶点的所有邻居
4. 对未访问的邻居递归执行DFS

### BFS步骤
1. 将起始顶点入队并标记已访问
2. 循环：取出队首顶点
3. 处理该顶点
4. 将其所有未访问邻居入队并标记
5. 直到队列为空

## 7. C# 实现

```csharp
using System;
using System.Collections.Generic;

/// <summary>
/// 邻接矩阵实现的图
/// 适用于稠密图，查询两点是否相连为O(1)
/// </summary>
public class GraphMatrix
{
    private int[,] _matrix;   // 邻接矩阵
    private int _vertexCount; // 顶点数量
    private bool _isDirected; // 是否有向图

    public GraphMatrix(int vertexCount, bool isDirected = false)
    {
        _vertexCount = vertexCount;
        _isDirected = isDirected;
        _matrix = new int[vertexCount, vertexCount];
    }

    /// <summary>
    /// 添加边（无权图，权重默认为1）
    /// </summary>
    public void AddEdge(int from, int to, int weight = 1)
    {
        _matrix[from, to] = weight;
        if (!_isDirected)
        {
            _matrix[to, from] = weight;  // 无向图对称
        }
    }

    /// <summary>
    /// 查询两点之间是否有边
    /// </summary>
    public bool HasEdge(int from, int to)
    {
        return _matrix[from, to] != 0;
    }

    /// <summary>
    /// 获取某个顶点的所有邻居
    /// </summary>
    public List<int> GetNeighbors(int vertex)
    {
        var neighbors = new List<int>();
        for (int i = 0; i < _vertexCount; i++)
        {
            if (_matrix[vertex, i] != 0)
                neighbors.Add(i);
        }
        return neighbors;
    }

    /// <summary>
    /// 打印邻接矩阵
    /// </summary>
    public void Print()
    {
        Console.Write("    ");
        for (int i = 0; i < _vertexCount; i++)
            Console.Write($"{i,3}");
        Console.WriteLine();

        for (int i = 0; i < _vertexCount; i++)
        {
            Console.Write($"{i,3} ");
            for (int j = 0; j < _vertexCount; j++)
            {
                Console.Write($"{_matrix[i, j],3}");
            }
            Console.WriteLine();
        }
    }

    public int VertexCount => _vertexCount;
    public int[,] Matrix => _matrix;
}

/// <summary>
/// 邻接表实现的图
/// 适用于稀疏图，空间效率高
/// </summary>
public class GraphList
{
    private List<List<(int vertex, int weight)>> _adjList;  // 邻接表
    private int _vertexCount;
    private bool _isDirected;

    public GraphList(int vertexCount, bool isDirected = false)
    {
        _vertexCount = vertexCount;
        _isDirected = isDirected;
        _adjList = new List<List<(int, int)>>();

        for (int i = 0; i < vertexCount; i++)
        {
            _adjList.Add(new List<(int, int)>());
        }
    }

    /// <summary>
    /// 添加边
    /// </summary>
    public void AddEdge(int from, int to, int weight = 1)
    {
        _adjList[from].Add((to, weight));
        if (!_isDirected)
        {
            _adjList[to].Add((from, weight));
        }
    }

    /// <summary>
    /// 获取某个顶点的所有邻居
    /// </summary>
    public List<(int vertex, int weight)> GetNeighbors(int vertex)
    {
        return _adjList[vertex];
    }

    /// <summary>
    /// 打印邻接表
    /// </summary>
    public void Print()
    {
        for (int i = 0; i < _vertexCount; i++)
        {
            Console.Write($"{i} → ");
            var neighbors = _adjList[i];
            for (int j = 0; j < neighbors.Count; j++)
            {
                var (v, w) = neighbors[j];
                Console.Write(w == 1 ? $"{v}" : $"{v}(权重{w})");
                if (j < neighbors.Count - 1) Console.Write(", ");
            }
            Console.WriteLine();
        }
    }

    public int VertexCount => _vertexCount;
}

/// <summary>
/// 图的遍历算法
/// </summary>
public class GraphTraversal
{
    /// <summary>
    /// 深度优先搜索（递归实现）
    /// 类似树的前序遍历，一路深入到底再回溯
    /// </summary>
    public List<int> DFS(GraphList graph, int start)
    {
        var visited = new bool[graph.VertexCount];
        var result = new List<int>();
        DFSHelper(graph, start, visited, result);
        return result;
    }

    private void DFSHelper(GraphList graph, int vertex, bool[] visited, List<int> result)
    {
        visited[vertex] = true;    // 标记当前顶点已访问
        result.Add(vertex);        // 记录访问顺序

        // 遍历所有邻居
        foreach (var (neighbor, _) in graph.GetNeighbors(vertex))
        {
            if (!visited[neighbor])
            {
                DFSHelper(graph, neighbor, visited, result);  // 递归深入
            }
        }
    }

    /// <summary>
    /// 深度优先搜索（迭代实现，使用栈）
    /// </summary>
    public List<int> DFSIterative(GraphList graph, int start)
    {
        var visited = new bool[graph.VertexCount];
        var result = new List<int>();
        var stack = new Stack<int>();

        stack.Push(start);

        while (stack.Count > 0)
        {
            int vertex = stack.Pop();

            if (visited[vertex]) continue;  // 跳过已访问
            visited[vertex] = true;
            result.Add(vertex);

            // 将未访问的邻居压入栈（逆序压入保证顺序一致）
            var neighbors = graph.GetNeighbors(vertex);
            for (int i = neighbors.Count - 1; i >= 0; i--)
            {
                if (!visited[neighbors[i].vertex])
                {
                    stack.Push(neighbors[i].vertex);
                }
            }
        }

        return result;
    }

    /// <summary>
    /// 广度优先搜索（使用队列）
    /// 逐层扩散，先访问所有距离为1的，再访问距离为2的...
    /// </summary>
    public List<int> BFS(GraphList graph, int start)
    {
        var visited = new bool[graph.VertexCount];
        var result = new List<int>();
        var queue = new Queue<int>();

        visited[start] = true;   // 入队时就标记，避免重复入队
        queue.Enqueue(start);

        while (queue.Count > 0)
        {
            int vertex = queue.Dequeue();
            result.Add(vertex);

            // 将所有未访问邻居入队
            foreach (var (neighbor, _) in graph.GetNeighbors(vertex))
            {
                if (!visited[neighbor])
                {
                    visited[neighbor] = true;  // 入队时标记
                    queue.Enqueue(neighbor);
                }
            }
        }

        return result;
    }

    /// <summary>
    /// BFS求最短路径（无权图）
    /// 返回从start到所有顶点的最短距离
    /// </summary>
    public int[] BFSShortestPath(GraphList graph, int start)
    {
        int n = graph.VertexCount;
        var dist = new int[n];
        Array.Fill(dist, -1);  // -1表示不可达

        var queue = new Queue<int>();
        dist[start] = 0;
        queue.Enqueue(start);

        while (queue.Count > 0)
        {
            int vertex = queue.Dequeue();

            foreach (var (neighbor, _) in graph.GetNeighbors(vertex))
            {
                if (dist[neighbor] == -1)
                {
                    dist[neighbor] = dist[vertex] + 1;  // 距离+1
                    queue.Enqueue(neighbor);
                }
            }
        }

        return dist;
    }

    /// <summary>
    /// 处理非连通图：遍历所有连通分量
    /// </summary>
    public List<List<int>> FindAllComponents(GraphList graph)
    {
        var visited = new bool[graph.VertexCount];
        var components = new List<List<int>>();

        for (int i = 0; i < graph.VertexCount; i++)
        {
            if (!visited[i])
            {
                var component = new List<int>();
                DFSHelper(graph, i, visited, component);
                components.Add(component);
            }
        }

        return components;
    }
}

/// <summary>
/// 测试程序
/// </summary>
public class Program
{
    public static void Main()
    {
        // === 邻接矩阵演示 ===
        Console.WriteLine("=== 邻接矩阵（无向图）===");
        var matrixGraph = new GraphMatrix(4);
        matrixGraph.AddEdge(0, 1);
        matrixGraph.AddEdge(0, 2);
        matrixGraph.AddEdge(1, 2);
        matrixGraph.AddEdge(1, 3);
        matrixGraph.AddEdge(2, 3);
        matrixGraph.Print();

        // === 邻接表演示 ===
        Console.WriteLine("\n=== 邻接表（无向图）===");
        var listGraph = new GraphList(4);
        listGraph.AddEdge(0, 1);
        listGraph.AddEdge(0, 2);
        listGraph.AddEdge(1, 2);
        listGraph.AddEdge(1, 3);
        listGraph.AddEdge(2, 3);
        listGraph.Print();

        // === 遍历演示 ===
        var traversal = new GraphTraversal();

        Console.WriteLine("\n=== DFS遍历（从顶点0开始）===");
        Console.WriteLine("递归DFS: " + string.Join(" → ", traversal.DFS(listGraph, 0)));
        Console.WriteLine("迭代DFS: " + string.Join(" → ", traversal.DFSIterative(listGraph, 0)));

        Console.WriteLine("\n=== BFS遍历（从顶点0开始）===");
        Console.WriteLine("BFS: " + string.Join(" → ", traversal.BFS(listGraph, 0)));

        // BFS最短路径
        Console.WriteLine("\n=== BFS最短路径 ===");
        var dist = traversal.BFSShortestPath(listGraph, 0);
        for (int i = 0; i < dist.Length; i++)
        {
            Console.WriteLine($"  顶点0到顶点{i}的最短距离: {dist[i]}");
        }

        // 非连通图
        Console.WriteLine("\n=== 非连通图的连通分量 ===");
        var disconnected = new GraphList(6);
        disconnected.AddEdge(0, 1);
        disconnected.AddEdge(0, 2);
        disconnected.AddEdge(3, 4);  // 独立的连通分量
        // 顶点5是孤立的

        var components = traversal.FindAllComponents(disconnected);
        for (int i = 0; i < components.Count; i++)
        {
            Console.WriteLine($"  连通分量{i + 1}: {{{string.Join(", ", components[i])}}}");
        }
    }
}
```

## 9. 复杂度分析

| 操作 | 邻接矩阵 | 邻接表 |
|------|---------|--------|
| 空间 | O(V²) | O(V+E) |
| 添加边 | O(1) | O(1) |
| 查询边 | O(1) | O(度) |
| 遍历邻居 | O(V) | O(度) |
| DFS/BFS | O(V²) | O(V+E) |

> V = 顶点数，E = 边数。稀疏图中 E << V²，邻接表更高效

## 10. 易错点

1. **BFS标记时机**：应该在**入队时**标记已访问，而非出队时（否则会重复入队）
2. **非连通图**：单次DFS/BFS只能遍历一个连通分量，需要循环处理所有顶点
3. **有向图无向图混淆**：无向图添加边要双向都加
4. **DFS栈溢出**：顶点数很大时递归DFS可能溢出，需改用迭代
5. **带权图遍历**：BFS只能求无权图最短路径，带权图需要Dijkstra等算法

## 11. 对比表

| 对比维度 | DFS | BFS |
|---------|-----|-----|
| 数据结构 | 栈（递归/显式） | 队列 |
| 搜索策略 | 深入到底再回溯 | 逐层扩散 |
| 空间复杂度 | O(V) 最差 | O(V) 最差 |
| 最短路径 | 不保证 | 保证（无权图） |
| 适用场景 | 连通性、环检测、拓扑排序 | 最短路径、层级遍历 |
| 实现难度 | 递归简单 | 略复杂 |

## 13. 记忆口诀

```
图有两种存，矩阵与邻表。
矩阵查边快O(1)，空间大是V方。
邻表省空间V+E，查边需遍历邻居。
稠密用矩阵，稀疏用邻表。
DFS用栈深入底，BFS用队逐层扩。
BFS天然最短路（无权），DFS适合找连通。
```

## 14. 面试常问点

1. **邻接矩阵和邻接表各自的优缺点？** → 空间/查询效率权衡
2. **DFS和BFS的区别和适用场景？** → 最短路径用BFS，连通性用DFS
3. **如何处理非连通图？** → 循环所有顶点，对未访问的执行遍历
4. **BFS为什么能求无权图最短路？** → 层次递增保证第一次到达即最短
5. **如何检测图中是否有环？** → DFS中遇到已在栈中的节点
6. **图的遍历时间复杂度？** → 邻接表O(V+E)，邻接矩阵O(V²)
