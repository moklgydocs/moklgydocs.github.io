## 1. 算法定位

Trie（字典树/前缀树）是一种专门用于**字符串检索**的树形数据结构，能够高效地实现字符串的插入、查找和前缀匹配，是自动补全、拼写检查等功能的核心数据结构。

## 2. 一句话理解

> 将字符串按**字符逐层存储**在树中，共享公共前缀，使得查找任意字符串的时间只与字符串长度相关。

## 3. 生活化比喻

Trie就像一本**多级目录的字典**：
- 第一层是首字母分类（A-Z）
- 第二层是第二个字母
- 逐层深入直到完整单词
- 查词时只需沿着字母路径走下去，不需要逐页翻找

## 4. 核心思想

- 根节点为空，不存储字符
- 每条边代表一个字符
- 从根到某节点的路径拼接起来就是一个前缀
- 标记"结束节点"表示一个完整的单词
- **所有具有相同前缀的字符串共享前缀路径**

| 特性 | 说明 |
|------|------|
| 查找时间 | O(m)，m为字符串长度 |
| 前缀查找 | 天然支持，无需额外操作 |
| 空间换时间 | 每个节点可能有多个子节点指针 |

## 5. 图解推演

### 插入单词 "cat", "car", "card", "dog", "dot"

```
         [root]
        /      \
      c          d
      |          |
      a          o
     / \        / \
    t*  r*     g*  t*
        |
        d*

标注 * 表示该节点是某个单词的结尾

路径解读：
root → c → a → t  = "cat" ✓
root → c → a → r  = "car" ✓
root → c → a → r → d = "card" ✓
root → d → o → g  = "dog" ✓
root → d → o → t  = "dot" ✓
```

### 查找过程

```
查找 "car":
root → [c] 存在? ✓ → [a] 存在? ✓ → [r] 存在? ✓ → 是结尾? ✓ → 找到!

查找 "ca":
root → [c] 存在? ✓ → [a] 存在? ✓ → 是结尾? ✗ → 不是完整单词

前缀查找 "ca":
root → [c] 存在? ✓ → [a] 存在? ✓ → 前缀存在!
以"ca"为前缀的单词: cat, car, card
```

### 节点详细结构

```
节点结构：
┌──────────────────────┐
│ children[26]         │  ← 26个子节点指针(a-z)
│ isEndOfWord: bool    │  ← 是否为单词结尾
└──────────────────────┘

root节点:
children: [null, null, c→节点, d→节点, ..., null]
          索引: a=0, b=1, c=2, d=3, ...
```

## 6. 执行步骤

### 插入步骤
1. 从根节点开始
2. 对字符串中每个字符：
   - 计算索引（字符 - 'a'）
   - 如果对应子节点不存在，创建新节点
   - 移动到子节点
3. 将最后一个节点标记为单词结尾

### 查找步骤
1. 从根节点开始
2. 对字符串中每个字符：
   - 如果对应子节点不存在 → 返回false
   - 移动到子节点
3. 检查最后节点是否标记为单词结尾

### 前缀查找步骤
1. 同查找，但最后不需要检查结尾标记
2. 只要路径存在就返回true

## 7. C# 实现

```csharp
using System;
using System.Collections.Generic;

/// <summary>
/// Trie节点定义
/// </summary>
public class TrieNode
{
    public TrieNode[] Children;  // 子节点数组（26个字母）
    public bool IsEndOfWord;     // 是否是某个单词的结尾
    public int PrefixCount;      // 经过该节点的单词数量（用于统计前缀）

    public TrieNode()
    {
        Children = new TrieNode[26];  // a-z 共26个位置
        IsEndOfWord = false;
        PrefixCount = 0;
    }
}

/// <summary>
/// Trie字典树完整实现
/// </summary>
public class Trie
{
    private readonly TrieNode _root;  // 根节点

    public Trie()
    {
        _root = new TrieNode();
    }

    /// <summary>
    /// 插入一个单词到Trie中
    /// 时间复杂度: O(m)，m为单词长度
    /// </summary>
    public void Insert(string word)
    {
        var current = _root;

        foreach (char ch in word)
        {
            int index = ch - 'a';  // 计算字符对应的索引

            // 如果对应子节点不存在，创建新节点
            if (current.Children[index] == null)
            {
                current.Children[index] = new TrieNode();
            }

            current = current.Children[index];  // 移动到子节点
            current.PrefixCount++;               // 经过此节点的单词数+1
        }

        current.IsEndOfWord = true;  // 标记单词结尾
    }

    /// <summary>
    /// 查找一个完整单词是否存在
    /// 时间复杂度: O(m)
    /// </summary>
    public bool Search(string word)
    {
        var node = FindNode(word);
        return node != null && node.IsEndOfWord;
    }

    /// <summary>
    /// 判断是否存在以指定前缀开头的单词
    /// 时间复杂度: O(m)
    /// </summary>
    public bool StartsWith(string prefix)
    {
        return FindNode(prefix) != null;
    }

    /// <summary>
    /// 统计以指定前缀开头的单词数量
    /// </summary>
    public int CountWordsWithPrefix(string prefix)
    {
        var node = FindNode(prefix);
        return node == null ? 0 : node.PrefixCount;
    }

    /// <summary>
    /// 获取所有以指定前缀开头的单词（自动补全功能）
    /// </summary>
    public List<string> GetWordsWithPrefix(string prefix)
    {
        var result = new List<string>();
        var node = FindNode(prefix);

        if (node != null)
        {
            // 从前缀节点开始，DFS收集所有单词
            CollectWords(node, prefix, result);
        }

        return result;
    }

    /// <summary>
    /// DFS收集所有单词
    /// </summary>
    private void CollectWords(TrieNode node, string currentWord, List<string> result)
    {
        if (node.IsEndOfWord)
        {
            result.Add(currentWord);  // 找到一个完整单词
        }

        for (int i = 0; i < 26; i++)
        {
            if (node.Children[i] != null)
            {
                char ch = (char)('a' + i);
                CollectWords(node.Children[i], currentWord + ch, result);
            }
        }
    }

    /// <summary>
    /// 删除一个单词
    /// </summary>
    public bool Delete(string word)
    {
        return DeleteHelper(_root, word, 0);
    }

    private bool DeleteHelper(TrieNode node, string word, int depth)
    {
        if (node == null) return false;

        // 到达单词末尾
        if (depth == word.Length)
        {
            if (!node.IsEndOfWord) return false;  // 单词不存在
            node.IsEndOfWord = false;             // 取消标记
            return true;
        }

        int index = word[depth] - 'a';
        bool deleted = DeleteHelper(node.Children[index], word, depth + 1);

        if (deleted)
        {
            node.Children[index].PrefixCount--;

            // 如果子节点没有单词经过且不是结尾，可以删除
            if (node.Children[index].PrefixCount == 0)
            {
                node.Children[index] = null;
            }
        }

        return deleted;
    }

    /// <summary>
    /// 辅助方法：沿着字符串路径找到对应节点
    /// </summary>
    private TrieNode FindNode(string str)
    {
        var current = _root;

        foreach (char ch in str)
        {
            int index = ch - 'a';
            if (current.Children[index] == null)
                return null;  // 路径不存在
            current = current.Children[index];
        }

        return current;
    }
}

/// <summary>
/// 测试程序
/// </summary>
public class Program
{
    public static void Main()
    {
        var trie = new Trie();

        // 插入单词
        string[] words = { "cat", "car", "card", "care", "careful", "dog", "dot", "does" };
        Console.WriteLine("插入单词: " + string.Join(", ", words));
        foreach (var word in words)
            trie.Insert(word);

        // 查找测试
        Console.WriteLine("\n=== 查找测试 ===");
        Console.WriteLine($"查找 'car': {trie.Search("car")}");       // True
        Console.WriteLine($"查找 'ca': {trie.Search("ca")}");         // False（不是完整单词）
        Console.WriteLine($"查找 'cars': {trie.Search("cars")}");     // False

        // 前缀测试
        Console.WriteLine("\n=== 前缀测试 ===");
        Console.WriteLine($"前缀 'car' 存在: {trie.StartsWith("car")}");  // True
        Console.WriteLine($"前缀 'ca' 存在: {trie.StartsWith("ca")}");    // True
        Console.WriteLine($"前缀 'cx' 存在: {trie.StartsWith("cx")}");    // False

        // 自动补全
        Console.WriteLine("\n=== 自动补全 ===");
        Console.WriteLine($"以 'car' 开头的单词: {string.Join(", ", trie.GetWordsWithPrefix("car"))}");
        Console.WriteLine($"以 'do' 开头的单词: {string.Join(", ", trie.GetWordsWithPrefix("do"))}");
        Console.WriteLine($"以 'car' 为前缀的单词数: {trie.CountWordsWithPrefix("car")}");

        // 删除测试
        Console.WriteLine("\n=== 删除测试 ===");
        trie.Delete("car");
        Console.WriteLine($"删除 'car' 后查找 'car': {trie.Search("car")}");
        Console.WriteLine($"删除 'car' 后查找 'card': {trie.Search("card")}");  // 仍然存在
        Console.WriteLine($"前缀 'car' 仍存在: {trie.StartsWith("car")}");      // True（card还在）
    }
}
```

## 9. 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 插入 | O(m) | O(m) | m为单词长度 |
| 查找 | O(m) | O(1) | 只遍历路径 |
| 前缀查找 | O(m) | O(1) | 同查找 |
| 自动补全 | O(m + k) | O(k) | k为结果单词总字符数 |
| 空间总计 | - | O(N * 26) | N为所有节点数 |

> 与哈希表对比：哈希表查找O(1)但不支持前缀查询；Trie查找O(m)且天然支持前缀

## 10. 易错点

1. **忘记标记结尾**：插入后必须设置 `IsEndOfWord = true`
2. **查找与前缀查找混淆**：`Search` 需要检查结尾标记，`StartsWith` 不需要
3. **字符索引计算**：确保 `ch - 'a'` 不会越界（输入需要预处理）
4. **删除操作**：不能简单置null，要考虑是否有其他单词共享前缀
5. **空间浪费**：每个节点26个指针，大部分为null。可用HashMap优化

## 11. 对比表

| 对比维度 | Trie | HashMap | 有序数组+二分 |
|---------|------|---------|-------------|
| 精确查找 | O(m) | O(m) 哈希 | O(m*logn) |
| 前缀查找 | O(m) 天然支持 | 不支持 | O(m*logn) |
| 自动补全 | 高效 | 需遍历全部 | 可实现 |
| 空间效率 | 较差(26指针) | 较好 | 最好 |
| 有序性 | 字典序 | 无序 | 有序 |
