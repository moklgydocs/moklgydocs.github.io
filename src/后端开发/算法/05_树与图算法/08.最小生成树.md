## 1. 算法定位

最小生成树（MST, Minimum Spanning Tree）是图论中的经典问题：在连通无向图中找到一棵包含所有顶点的树，使得边的总权重最小。Prim和Kruskal是两种经典的贪心算法。

## 2. 一句话理解

> 用**最少的总花费**把所有节点连通起来，不形成环，恰好选V-1条边。

## 3. 生活化比喻

- **Prim算法**：像一座城市逐步扩张，每次把最近的村庄纳入版图（从一个点开始生长）
- **Kruskal算法**：像选择最便宜的公路修建，每次修最短的路，只要不形成环路（按边排序选择）

## 4. 核心思想

**MST性质：**
- 包含图中所有V个顶点
- 恰好有V-1条边
- 无环（是一棵树）
- 总权重最小

| 算法 | 策略 | 适用场景 | 时间复杂度 |
|------|------|---------|-----------|
| Prim | 从顶点生长，每次加入最近邻 | 稠密图 | O(V²) 或 O(ElogV) |
| Kruskal | 按边排序，逐条加入不成环的边 | 稀疏图 | O(ElogE) |

### Kruskal算法执行过程

```
所有边按权重排序:
(1,3,1) (0,1,2) (1,2,3) (0,2,4) (3,4,4) (2,3,5) (1,4,6)

步骤1: 取(1,3,1) → 1和3不在同一集合 → 加入! 合并{1,3}
步骤2: 取(0,1,2) → 0和1不在同一集合 → 加入! 合并{0,1,3}
步骤3: 取(1,2,3) → 1和2不在同一集合 → 加入! 合并{0,1,2,3}
步骤4: 取(0,2,4) → 0和2在同一集合 → 跳过!（会形成环）
步骤5: 取(3,4,4) → 3和4不在同一集合 → 加入! 合并{0,1,2,3,4}

已选V-1=4条边，完成!

MST边: (1,3,1) (0,1,2) (1,2,3) (3,4,4)  总权重 = 10
```

## 6. 执行步骤

### Prim步骤
1. 任选一个起始顶点加入MST集合
2. 找到连接MST内外的**最小权重边**
3. 将该边和对应外部顶点加入MST
4. 重复2-3直到所有顶点都加入
5. 总共选择V-1条边

### Kruskal步骤
1. 将所有边按权重**升序排序**
2. 初始化并查集（每个顶点独立）
3. 按顺序取边，如果两端点不在同一集合则加入MST
4. 否则跳过（加入会形成环）
5. 直到选够V-1条边

## 7. C# 实现

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

/// <summary>
/// 并查集（用于Kruskal算法判断是否成环）
/// </summary>
public class UnionFind
{
    private int[] _parent;  // 父节点数组
    private int[] _rank;    // 秩（树高度的上界）

    public UnionFind(int size)
    {
        _parent = new int[size];
        _rank = new int[size];
        for (int i = 0; i < size; i++)
        {
            _parent[i] = i;  // 初始时每个节点是自己的父节点
            _rank[i] = 0;
        }
    }

    /// <summary>
    /// 查找根节点（带路径压缩）
    /// </summary>
    public int Find(int x)
    {
        if (_parent[x] != x)
            _parent[x] = Find(_parent[x]);  // 路径压缩
        return _parent[x];
    }

    /// <summary>
    /// 合并两个集合（按秩合并）
    /// </summary>
    /// <returns>是否成功合并（false表示已在同一集合）</returns>
    public bool Union(int x, int y)
    {
        int rootX = Find(x);
        int rootY = Find(y);

        if (rootX == rootY) return false;  // 已在同一集合

        // 按秩合并：矮树接到高树下
        if (_rank[rootX] < _rank[rootY])
            _parent[rootX] = rootY;
        else if (_rank[rootX] > _rank[rootY])
            _parent[rootY] = rootX;
        else
        {
            _parent[rootY] = rootX;
            _rank[rootX]++;
        }

        return true;
    }
}

/// <summary>
/// 边的定义
/// </summary>
public class Edge : IComparable<Edge>
{
    public int From;    // 起点
    public int To;      // 终点
    public int Weight;  // 权重

    public Edge(int from, int to, int weight)
    {
        From = from;
        To = to;
        Weight = weight;
    }

    public int CompareTo(Edge other)
    {
        return Weight.CompareTo(other.Weight);
    }

    public override string ToString() => $"({From},{To},权重{Weight})";
}

/// <summary>
/// 最小生成树算法
/// </summary>
public class MinimumSpanningTree
{
    /// <summary>
    /// Kruskal算法：按边排序 + 并查集判环
    /// 适用于稀疏图 O(E log E)
    /// </summary>
    public List<Edge> Kruskal(int vertexCount, List<Edge> edges)
    {
        // 按权重升序排序所有边
        edges.Sort();

        var uf = new UnionFind(vertexCount);
        var mstEdges = new List<Edge>();
        int totalWeight = 0;

        foreach (var edge in edges)
        {
            // 尝试合并两端点
            if (uf.Union(edge.From, edge.To))
            {
                // 合并成功 → 不会形成环 → 加入MST
                mstEdges.Add(edge);
                totalWeight += edge.Weight;

                Console.WriteLine($"  加入边 {edge}，当前总权重: {totalWeight}");

                // 已选V-1条边，完成
                if (mstEdges.Count == vertexCount - 1)
                    break;
            }
            else
            {
                Console.WriteLine($"  跳过边 {edge}（会形成环）");
            }
        }

        Console.WriteLine($"  MST总权重: {totalWeight}");
        return mstEdges;
    }

    /// <summary>
    /// Prim算法：从顶点生长，每次加入最近的外部顶点
    /// 适用于稠密图 O(V²)（朴素版本）
    /// </summary>
    public List<Edge> PrimNaive(int vertexCount, List<(int to, int weight)>[] adjList)
    {
        var inMST = new bool[vertexCount];     // 是否已在MST中
        var minEdge = new int[vertexCount];    // 到MST的最小边权重
        var minFrom = new int[vertexCount];    // 最小边来自哪个MST顶点
        Array.Fill(minEdge, int.MaxValue);

        var mstEdges = new List<Edge>();
        int totalWeight = 0;

        // 从顶点0开始
        minEdge[0] = 0;
        minFrom[0] = -1;

        for (int i = 0; i < vertexCount; i++)
        {
            // 找到不在MST中且距离MST最近的顶点
            int u = -1;
            for (int v = 0; v < vertexCount; v++)
            {
                if (!inMST[v] && (u == -1 || minEdge[v] < minEdge[u]))
                    u = v;
            }

            inMST[u] = true;  // 加入MST

            if (minFrom[u] != -1)
            {
                var edge = new Edge(minFrom[u], u, minEdge[u]);
                mstEdges.Add(edge);
                totalWeight += minEdge[u];
                Console.WriteLine($"  加入边 {edge}，当前总权重: {totalWeight}");
            }

            // 更新u的邻居到MST的最小距离
            foreach (var (v, weight) in adjList[u])
            {
                if (!inMST[v] && weight < minEdge[v])
                {
                    minEdge[v] = weight;
                    minFrom[v] = u;
                }
            }
        }

        Console.WriteLine($"  MST总权重: {totalWeight}");
        return mstEdges;
    }

    /// <summary>
    /// Prim算法（优先队列优化版）
    /// 适用于稀疏图 O(E log V)
    /// </summary>
    public List<Edge> PrimPQ(int vertexCount, List<(int to, int weight)>[] adjList)
    {
        var inMST = new bool[vertexCount];
        var mstEdges = new List<Edge>();
        int totalWeight = 0;

        // 优先队列: (权重, 目标顶点, 来源顶点)
        var pq = new SortedSet<(int weight, int to, int from)>();
        pq.Add((0, 0, -1));  // 从顶点0开始

        while (pq.Count > 0 && mstEdges.Count < vertexCount - 1)
        {
            var (w, u, from) = pq.Min;
            pq.Remove(pq.Min);

            if (inMST[u]) continue;  // 已在MST中则跳过
            inMST[u] = true;

            if (from != -1)
            {
                mstEdges.Add(new Edge(from, u, w));
                totalWeight += w;
            }

            // 将u的邻居加入优先队列
            foreach (var (v, weight) in adjList[u])
            {
                if (!inMST[v])
                {
                    pq.Add((weight, v, u));
                }
            }
        }

        return mstEdges;
    }
}

/// <summary>
/// 测试程序
/// </summary>
public class Program
{
    public static void Main()
    {
        int V = 5;

        // 边列表
        var edges = new List<Edge>
        {
            new Edge(0, 1, 2),
            new Edge(0, 2, 4),
            new Edge(1, 2, 3),
            new Edge(1, 3, 1),
            new Edge(1, 4, 6),
            new Edge(2, 3, 5),
            new Edge(3, 4, 4)
        };

        // 邻接表（无向图，双向添加）
        var adjList = new List<(int, int)>[V];
        for (int i = 0; i < V; i++)
            adjList[i] = new List<(int, int)>();

        foreach (var e in edges)
        {
            adjList[e.From].Add((e.To, e.Weight));
            adjList[e.To].Add((e.From, e.Weight));
        }

        var mst = new MinimumSpanningTree();

        // Kruskal
        Console.WriteLine("=== Kruskal算法 ===");
        var kruskalResult = mst.Kruskal(V, new List<Edge>(edges));
        Console.WriteLine("MST边集: " + string.Join(", ", kruskalResult));

        // Prim（朴素版）
        Console.WriteLine("\n=== Prim算法（朴素版，从顶点0开始）===");
        var primResult = mst.PrimNaive(V, adjList);
        Console.WriteLine("MST边集: " + string.Join(", ", primResult));
    }
}
```

## 9. 复杂度分析

| 算法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| Kruskal | O(E log E) | O(V+E) | 排序O(ElogE) + 并查集近O(1) |
| Prim(朴素) | O(V²) | O(V) | 每轮扫描所有顶点 |
| Prim(优先队列) | O(E log V) | O(V+E) | 优先队列优化 |

## 10. 易错点

1. **Kruskal判环**：必须用并查集，不能简单检查顶点是否访问过
2. **无向图双向**：邻接表要双向添加边
3. **并查集优化**：路径压缩 + 按秩合并缺一不可
4. **MST不唯一**：相同权重的边可能产生不同MST，但总权重相同
5. **图必须连通**：非连通图没有生成树（只有生成森林）

## 11. 对比表

| 对比维度 | Prim | Kruskal |
|---------|------|---------|
| 策略 | 从顶点生长 | 从边选择 |
| 数据结构 | 优先队列 | 排序 + 并查集 |
| 适用图 | 稠密图 | 稀疏图 |
| 时间(朴素) | O(V²) | O(E log E) |
| 时间(优化) | O(E log V) | O(E log E) |
| 实现难度 | 中等 | 中等（需并查集） |
| 类似算法 | 类似Dijkstra | 类似贪心选边 |
