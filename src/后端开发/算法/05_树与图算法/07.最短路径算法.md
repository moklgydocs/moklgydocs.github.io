## 1. 算法定位

最短路径算法是图论中最重要的算法之一，解决"从一个顶点到另一个顶点的最短距离"问题。三大经典算法（Dijkstra、Bellman-Ford、Floyd-Warshall）各有适用场景。

## 2. 一句话理解

> Dijkstra用**贪心**逐步确定最短路径（不能有负权）；Bellman-Ford通过**松弛所有边**处理负权；Floyd用**动态规划**求所有顶点对之间的最短路径。

## 3. 生活化比喻

- **Dijkstra**：像水波从源头扩散，总是先到达最近的点，然后从那里继续扩散
- **Bellman-Ford**：像广播通知，每轮所有人把自己知道的最短路信息告诉邻居，重复V-1轮
- **Floyd**：像一个全知的导航系统，穷举所有可能的中转站，计算任意两点间的最短路

## 4. 核心思想

| 算法 | 思想 | 适用场景 | 时间复杂度 |
|------|------|---------|-----------|
| Dijkstra | 贪心+松弛 | 非负权，单源 | O((V+E)logV) |
| Bellman-Ford | 逐轮松弛 | 可有负权，单源 | O(VE) |
| Floyd-Warshall | DP | 任意权重，全源 | O(V³) |

**松弛操作**：如果通过某个中间点能缩短距离，则更新距离
```
if dist[u] + weight(u,v) < dist[v]:
    dist[v] = dist[u] + weight(u,v)
```

### Dijkstra执行过程（从顶点0出发）

```
初始: dist = [0, ∞, ∞, ∞]  visited = [F,F,F,F]

轮次1: 选择未访问中dist最小的顶点 → 顶点0 (dist=0)
  松弛邻居: dist[1] = min(∞, 0+1) = 1  ✓更新
            dist[2] = min(∞, 0+4) = 4  ✓更新
  dist = [0, 1, 4, ∞]  visited = [T,F,F,F]

轮次2: 选择未访问中dist最小的顶点 → 顶点1 (dist=1)
  松弛邻居: dist[3] = min(∞, 1+2) = 3  ✓更新
  dist = [0, 1, 4, 3]  visited = [T,T,F,F]

轮次3: 选择未访问中dist最小的顶点 → 顶点3 (dist=3)
  无未访问邻居可松弛
  dist = [0, 1, 4, 3]  visited = [T,T,F,T]

轮次4: 选择未访问中dist最小的顶点 → 顶点2 (dist=4)
  松弛邻居: dist[1] = min(1, 4+3) = 1  不更新
            dist[3] = min(3, 4+5) = 3  不更新
  dist = [0, 1, 4, 3]  visited = [T,T,T,T]

最终结果: 0→0:0  0→1:1  0→2:4  0→3:3
```

### Bellman-Ford执行过程

```
初始: dist = [0, ∞, ∞, ∞]
边集: (0,1,1) (0,2,4) (2,1,3) (1,3,2) (2,3,5)

第1轮（松弛所有边）:
  边(0,1,1): dist[1] = min(∞, 0+1) = 1  ✓
  边(0,2,4): dist[2] = min(∞, 0+4) = 4  ✓
  边(2,1,3): dist[1] = min(1, 4+3) = 1  不变
  边(1,3,2): dist[3] = min(∞, 1+2) = 3  ✓
  边(2,3,5): dist[3] = min(3, 4+5) = 3  不变
  dist = [0, 1, 4, 3]

第2轮: 无变化 → 提前结束
第3轮: 如果还有变化 → 存在负权环！

最终结果: [0, 1, 4, 3]
```

### Floyd-Warshall执行过程

```
初始距离矩阵 (∞表示不可直达):
     0    1    2    3
0 [  0    1    4    ∞  ]
1 [  ∞    0    ∞    2  ]
2 [  ∞    3    0    5  ]
3 [  ∞    ∞    ∞    0  ]

经过顶点0中转 (k=0):
  无改善

经过顶点1中转 (k=1):
  dist[0][3] = min(∞, dist[0][1]+dist[1][3]) = min(∞, 1+2) = 3 ✓
     0    1    2    3
0 [  0    1    4    3  ]
1 [  ∞    0    ∞    2  ]
2 [  ∞    3    0    5  ]
3 [  ∞    ∞    ∞    0  ]

经过顶点2中转 (k=2):
  dist[0][1]通过2? min(1, 4+3) = 1 不变
  dist[2][3]通过?  已是5 不变
  dist[0][3]通过2? min(3, 4+5) = 3 不变

经过顶点3中转 (k=3): 无改善

最终全源最短路径矩阵:
     0    1    2    3
0 [  0    1    4    3  ]
```

## 6. 执行步骤

### Dijkstra步骤
1. 初始化：源点距离为0，其余为∞
2. 选择未访问顶点中距离最小的
3. 标记为已访问
4. 松弛其所有邻居
5. 重复2-4直到所有顶点已访问

### Bellman-Ford步骤
1. 初始化：源点距离为0，其余为∞
2. 执行V-1轮，每轮松弛所有边
3. 第V轮再检查：如果还能松弛 → 存在负权环

### Floyd-Warshall步骤
1. 初始化距离矩阵（直接相连为权重，否则∞）
2. 三重循环：枚举中转点k、起点i、终点j
3. `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`

## 7. C# 实现

```csharp
using System;
using System.Collections.Generic;

/// <summary>
/// 最短路径算法集合
/// </summary>
public class ShortestPath
{
    /// <summary>
    /// Dijkstra算法（优先队列优化）
    /// 适用：非负权重的单源最短路径
    /// 时间复杂度: O((V+E) * log V)
    /// </summary>
    public int[] Dijkstra(int vertexCount, List<(int to, int weight)>[] adjList, int source)
    {
        var dist = new int[vertexCount];
        Array.Fill(dist, int.MaxValue);  // 初始距离为无穷大
        dist[source] = 0;

        // 优先队列：(距离, 顶点)，距离小的优先
        var pq = new SortedSet<(int dist, int vertex)>();
        pq.Add((0, source));

        var visited = new bool[vertexCount];

        while (pq.Count > 0)
        {
            // 取出距离最小的未访问顶点
            var (d, u) = pq.Min;
            pq.Remove(pq.Min);

            if (visited[u]) continue;  // 已处理过则跳过
            visited[u] = true;

            // 松弛所有邻居
            foreach (var (v, weight) in adjList[u])
            {
                int newDist = dist[u] + weight;
                if (newDist < dist[v])
                {
                    // 更新距离（如果在PQ中需要先移除再添加）
                    pq.Remove((dist[v], v));
                    dist[v] = newDist;
                    pq.Add((dist[v], v));
                }
            }
        }

        return dist;
    }

    /// <summary>
    /// Bellman-Ford算法
    /// 适用：可处理负权边，能检测负权环
    /// 时间复杂度: O(V * E)
    /// </summary>
    /// <returns>距离数组，如果存在负权环返回null</returns>
    public int[] BellmanFord(int vertexCount, List<(int from, int to, int weight)> edges, int source)
    {
        var dist = new int[vertexCount];
        Array.Fill(dist, int.MaxValue);
        dist[source] = 0;

        // 执行 V-1 轮松弛
        for (int i = 0; i < vertexCount - 1; i++)
        {
            bool updated = false;

            foreach (var (from, to, weight) in edges)
            {
                // 如果起点可达，且通过起点到达终点更短
                if (dist[from] != int.MaxValue && dist[from] + weight < dist[to])
                {
                    dist[to] = dist[from] + weight;
                    updated = true;
                }
            }

            // 如果本轮没有更新，可以提前退出
            if (!updated) break;
        }

        // 第V轮检测负权环
        foreach (var (from, to, weight) in edges)
        {
            if (dist[from] != int.MaxValue && dist[from] + weight < dist[to])
            {
                Console.WriteLine("检测到负权环！");
                return null;  // 存在负权环
            }
        }

        return dist;
    }

    /// <summary>
    /// Floyd-Warshall算法
    /// 适用：求所有顶点对之间的最短路径
    /// 时间复杂度: O(V³)
    /// </summary>
    public int[,] FloydWarshall(int vertexCount, List<(int from, int to, int weight)> edges)
    {
        const int INF = int.MaxValue / 2;  // 用一半防止溢出

        // 初始化距离矩阵
        var dist = new int[vertexCount, vertexCount];
        for (int i = 0; i < vertexCount; i++)
        {
            for (int j = 0; j < vertexCount; j++)
            {
                dist[i, j] = (i == j) ? 0 : INF;
            }
        }

        // 填入边的权重
        foreach (var (from, to, weight) in edges)
        {
            dist[from, to] = weight;
        }

        // 核心：三重循环，枚举中转点k
        for (int k = 0; k < vertexCount; k++)       // 中转点
        {
            for (int i = 0; i < vertexCount; i++)   // 起点
            {
                for (int j = 0; j < vertexCount; j++) // 终点
                {
                    // 如果经过k中转更短，则更新
                    if (dist[i, k] + dist[k, j] < dist[i, j])
                    {
                        dist[i, j] = dist[i, k] + dist[k, j];
                    }
                }
            }
        }

        return dist;
    }

    /// <summary>
    /// Dijkstra + 路径记录（可回溯最短路径经过的节点）
    /// </summary>
    public (int[] dist, int[] prev) DijkstraWithPath(int vertexCount, List<(int to, int weight)>[] adjList, int source)
    {
        var dist = new int[vertexCount];
        var prev = new int[vertexCount];  // 记录前驱节点
        Array.Fill(dist, int.MaxValue);
        Array.Fill(prev, -1);
        dist[source] = 0;

        var pq = new SortedSet<(int dist, int vertex)>();
        pq.Add((0, source));
        var visited = new bool[vertexCount];

        while (pq.Count > 0)
        {
            var (d, u) = pq.Min;
            pq.Remove(pq.Min);

            if (visited[u]) continue;
            visited[u] = true;

            foreach (var (v, weight) in adjList[u])
            {
                int newDist = dist[u] + weight;
                if (newDist < dist[v])
                {
                    pq.Remove((dist[v], v));
                    dist[v] = newDist;
                    prev[v] = u;   // 记录前驱
                    pq.Add((dist[v], v));
                }
            }
        }

        return (dist, prev);
    }

    /// <summary>
    /// 根据prev数组回溯路径
    /// </summary>
    public List<int> GetPath(int[] prev, int target)
    {
        var path = new List<int>();
        for (int v = target; v != -1; v = prev[v])
        {
            path.Add(v);
        }
        path.Reverse();
        return path;
    }
}

/// <summary>
/// 测试程序
/// </summary>
public class Program
{
    public static void Main()
    {
        int V = 4;  // 顶点数

        // 构建邻接表
        var adjList = new List<(int, int)>[V];
        for (int i = 0; i < V; i++)
            adjList[i] = new List<(int, int)>();

        // 添加边: (to, weight)
        adjList[0].Add((1, 1));
        adjList[0].Add((2, 4));
        adjList[2].Add((1, 3));
        adjList[1].Add((3, 2));
        adjList[2].Add((3, 5));

        // 边列表
        var edges = new List<(int, int, int)>
        {
            (0, 1, 1), (0, 2, 4), (2, 1, 3), (1, 3, 2), (2, 3, 5)
        };

        var sp = new ShortestPath();

        // Dijkstra
        Console.WriteLine("=== Dijkstra算法（从顶点0出发）===");
        var dijkDist = sp.Dijkstra(V, adjList, 0);
        for (int i = 0; i < V; i++)
            Console.WriteLine($"  0 → {i}: 距离 = {(dijkDist[i] == int.MaxValue ? "∞" : dijkDist[i].ToString())}");

        // 带路径的Dijkstra
        Console.WriteLine("\n=== Dijkstra + 路径回溯 ===");
        var (dist, prev) = sp.DijkstraWithPath(V, adjList, 0);
        for (int i = 0; i < V; i++)
        {
            var path = sp.GetPath(prev, i);
            Console.WriteLine($"  0 → {i}: 距离={dist[i]}, 路径={string.Join("→", path)}");
        }

        // Bellman-Ford
        Console.WriteLine("\n=== Bellman-Ford算法（从顶点0出发）===");
        var bfDist = sp.BellmanFord(V, edges, 0);
        if (bfDist != null)
        {
            for (int i = 0; i < V; i++)
                Console.WriteLine($"  0 → {i}: 距离 = {(bfDist[i] == int.MaxValue ? "∞" : bfDist[i].ToString())}");
        }

        // Floyd-Warshall
        Console.WriteLine("\n=== Floyd-Warshall算法（全源最短路径）===");
        var floydDist = sp.FloydWarshall(V, edges);
        Console.WriteLine("距离矩阵:");
        Console.Write("     ");
        for (int j = 0; j < V; j++) Console.Write($"{j,5}");
        Console.WriteLine();
        for (int i = 0; i < V; i++)
        {
            Console.Write($"  {i}: ");
            for (int j = 0; j < V; j++)
            {
                string val = floydDist[i, j] >= int.MaxValue / 2 ? "  ∞" : $"{floydDist[i, j],3}";
                Console.Write($"{val,5}");
            }
            Console.WriteLine();
        }
    }
}
```

## 9. 复杂度分析

| 算法 | 时间复杂度 | 空间复杂度 | 负权边 | 负权环检测 |
|------|-----------|-----------|--------|-----------|
| Dijkstra(优先队列) | O((V+E)logV) | O(V+E) | 不支持 | 不支持 |
| Dijkstra(朴素) | O(V²) | O(V) | 不支持 | 不支持 |
| Bellman-Ford | O(VE) | O(V) | 支持 | 支持 |
| Floyd-Warshall | O(V³) | O(V²) | 支持 | 支持 |

## 10. 易错点

1. **Dijkstra不能处理负权边**：贪心假设"已确定的不会更短"在负权下不成立
2. **Bellman-Ford松弛轮数**：恰好V-1轮，不是V轮
3. **Floyd溢出问题**：INF不能用int.MaxValue，加法会溢出
4. **优先队列更新**：C# SortedSet不支持直接修改key，需先删后加
5. **路径回溯**：prev数组记录前驱，回溯后需要反转

## 11. 对比表

| 对比维度 | Dijkstra | Bellman-Ford | Floyd-Warshall |
|---------|----------|--------------|----------------|
| 问题类型 | 单源 | 单源 | 全源 |
| 负权边 | 不支持 | 支持 | 支持 |
| 时间复杂度 | O((V+E)logV) | O(VE) | O(V³) |
| 适用场景 | 地图导航 | 金融汇率 | 小图全对最短路 |
| 算法思想 | 贪心 | 动态规划 | 动态规划 |
| 实现难度 | 中等 | 简单 | 简单 |

## 14. 面试常问点

1. **Dijkstra的原理和时间复杂度？** → 贪心选最近未访问点松弛，O((V+E)logV)
2. **为什么Dijkstra不能处理负权边？** → 贪心假设被破坏
3. **Bellman-Ford如何检测负权环？** → 第V轮还能松弛说明有负环
4. **三种算法如何选择？** → 看是否单源/是否有负权
5. **如何回溯最短路径？** → prev数组记录前驱节点
6. **Dijkstra优先队列版本如何实现？** → 入队(距离,顶点)，弹出最小
