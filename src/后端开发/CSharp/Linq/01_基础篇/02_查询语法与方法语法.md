# 查询语法与方法语法

## 一、查询语法详解

查询语法（Query Syntax）是一种声明式的SQL风格语法，以 `from` 子句开头，以 `select` 或 `group` 子句结尾。

### 完整语法结构

```csharp
var result = from rangeVariable in dataSource
             [where condition]
             [orderby field [ascending|descending]]
             [select projection]
             [group projection by key];
```

### from子句 — 指定数据源

`from` 子句声明范围变量并指定数据源，是查询语法的起点。

```csharp
// 基本from子句
var query = from p in products
            select p;

// 多个from子句（等价于SelectMany）
var query = from o in orders
            from d in o.Details
            select new { o.OrderId, d.ProductName, d.Quantity };
```

::: info 范围变量
范围变量（如 `p`）类似于 `foreach` 中的迭代变量，它代表数据源中的当前元素。作用域从 `from` 到查询结束。
:::

### where子句 — 筛选条件

```csharp
// 单条件
var query = from p in products
            where p.Price > 100
            select p;

// 多条件
var query = from p in products
            where p.Price > 100 && p.IsActive
            select p;
```

### orderby子句 — 排序

```csharp
// 升序（默认）
var query = from p in products
            orderby p.Price
            select p;

// 降序
var query = from p in products
            orderby p.Price descending
            select p;

// 多字段排序
var query = from p in products
            orderby p.Category, p.Price descending
            select p;
```

### select子句 — 投影

```csharp
// 直接选取
var query = from p in products
            select p.Name;

// 匿名类型投影
var query = from p in products
            select new { p.Name, p.Price, IsExpensive = p.Price > 1000 };
```

### group...by子句 — 分组

```csharp
// 基本分组
var query = from p in products
            group p by p.Category;

// 分组后继续查询（使用into）
var query = from p in products
            group p by p.Category into g
            where g.Count() > 5
            select new { Category = g.Key, Count = g.Count() };
```

### join...on...equals子句 — 连接

```csharp
// 内连接
var query = from o in orders
            join c in customers on o.CustomerId equals c.Id
            select new { o.OrderId, c.Name };

// 分组连接
var query = from c in customers
            join o in orders on c.Id equals o.CustomerId into co
            select new { c.Name, Orders = co };
```

### into子句 — 延续查询

`into` 子句将查询结果存入新的范围变量，允许继续操作：

```csharp
// group ... into
var query = from p in products
            group p by p.Category into g
            orderby g.Count() descending
            select new { Category = g.Key, Count = g.Count() };

// select ... into（较少使用）
var query = from p in products
            select new { p.Name, p.Price }
            into item
            where item.Price > 100
            select item;
```

### let子句 — 引入中间变量

`let` 子句在查询中引入临时变量，避免重复计算：

```csharp
var query = from p in products
            let discount = p.Price * 0.9
            let finalPrice = discount > 50 ? discount : 50
            where finalPrice < 100
            select new { p.Name, OriginalPrice = p.Price, FinalPrice = finalPrice };
```

## 二、方法语法详解

方法语法（Method Syntax）基于扩展方法链式调用，以Lambda表达式作为参数。

### 扩展方法链式调用

```csharp
var result = products
    .Where(p => p.Price > 100)
    .OrderBy(p => p.Name)
    .Select(p => p.Name);
```

### Lambda表达式作为参数

LINQ方法接受 `Func<T, TResult>` 或 `Expression<Func<T, TResult>>` 类型的参数：

```csharp
// Where: Func<T, bool> —— 条件谓词
products.Where(p => p.Price > 100)

// Select: Func<T, TResult> —— 投影函数
products.Select(p => p.Name)

// OrderBy: Func<T, TKey> —— 排序键选择器
products.OrderBy(p => p.Price)

// 带索引的重载
products.Select((p, index) => new { Index = index, p.Name })
```

### 常用方法签名

```csharp
// 筛选
IEnumerable<T> Where(Func<T, bool> predicate)
IEnumerable<T> Where(Func<T, int, bool> predicate)  // 带索引

// 投影
IEnumerable<TResult> Select<TResult>(Func<T, TResult> selector)
IEnumerable<TResult> Select<TResult>(Func<T, int, TResult> selector)  // 带索引

IEnumerable<TResult> SelectMany<TResult>(Func<T, IEnumerable<TResult>> selector)
IEnumerable<TResult> SelectMany<TCollection, TResult>(
    Func<T, IEnumerable<TCollection>> collectionSelector,
    Func<T, TCollection, TResult> resultSelector)

// 排序
IOrderedEnumerable<T> OrderBy<TKey>(Func<T, TKey> keySelector)
IOrderedEnumerable<T> OrderByDescending<TKey>(Func<T, TKey> keySelector)
IOrderedEnumerable<T> ThenBy<TKey>(Func<T, TKey> keySelector)
IOrderedEnumerable<T> ThenByDescending<TKey>(Func<T, TKey> keySelector)
```

## 三、两种语法的完整对照

| 操作 | 查询语法 | 方法语法 |
|------|----------|----------|
| 筛选 | `from p in ps where p.X > 0 select p` | `ps.Where(p => p.X > 0)` |
| 投影 | `from p in ps select p.Name` | `ps.Select(p => p.Name)` |
| 排序 | `from p in ps orderby p.X select p` | `ps.OrderBy(p => p.X)` |
| 降序 | `from p in ps orderby p.X descending select p` | `ps.OrderByDescending(p => p.X)` |
| 分组 | `from p in ps group p by p.X` | `ps.GroupBy(p => p.X)` |
| 连接 | `from a in as join b in bs on a.X equals b.X select ...` | `as.Join(bs, a => a.X, b => b.X, (a, b) => ...)` |
| 展平 | `from a in as from b in a.Xs select ...` | `as.SelectMany(a => a.Xs)` |
| 去重 | （无查询语法） | `ps.Distinct()` |
| 计数 | （无查询语法） | `ps.Count()` |
| 取前N | （无查询语法） | `ps.Take(n)` |

### 等价转换规则

编译器将查询语法**翻译**为方法语法，两者完全等价：

```csharp
// 查询语法
from p in products
where p.Price > 100
orderby p.Name
select p.Name

// 编译器翻译为
products
    .Where(p => p.Price > 100)
    .OrderBy(p => p.Name)
    .Select(p => p.Name)
```

## 四、必须用方法语法的场景

### 聚合操作

```csharp
int count = products.Count();
decimal total = products.Sum(p => p.Price);
decimal avg = products.Average(p => p.Price);
decimal max = products.Max(p => p.Price);
decimal min = products.Min(p => p.Price);
```

### 分区操作

```csharp
// 分页：第2页，每页10条
var page2 = products
    .OrderBy(p => p.Id)
    .Skip(10)  // 跳过第1页
    .Take(10); // 取第2页
```

### 元素操作

```csharp
var first = products.First();
var firstOrDefault = products.FirstOrDefault(p => p.Price > 999);
var single = products.Single(p => p.Id == 42);
```

### 无查询语法等价的操作

```csharp
// Zip：按位置合并两个序列
var names = new[] { "Alice", "Bob", "Charlie" };
var ages = new[] { 25, 30, 35 };
var combined = names.Zip(ages, (name, age) => $"{name}: {age}");

// Aggregate：自定义聚合
var sentence = words.Aggregate((current, next) => current + " " + next);

// 自定义扩展方法
public static IEnumerable<T> MyFilter<T>(this IEnumerable<T> source, Func<T, bool> predicate)
{
    foreach (var item in source)
        if (predicate(item)) yield return item;
}
```

## 五、混合语法

实际开发中，混合使用查询语法和方法语法是常态。

### 基本混合模式

```csharp
// 查询语法筛选 → 方法语法排序和分页
var result = (from p in products
              where p.IsActive && p.Stock > 0
              select p)
             .OrderByDescending(p => p.Sales)
             .ThenBy(p => p.Price)
             .Take(20);
```

### 推荐混合方式

在查询语法的 `select` 后接方法语法是最自然的混合方式：

```csharp
// 用查询语法处理join/group（更清晰）
// 用方法语法处理排序/分区/聚合（更方便）
var result = (from o in orders
              join c in customers on o.CustomerId equals c.Id
              group o by c.Name into g
              select new { Customer = g.Key, Total = g.Sum(o => o.Amount) })
             .OrderByDescending(x => x.Total)
             .Take(10);
```

### 选择建议

| 场景 | 推荐语法 |
|------|----------|
| 简单筛选+投影 | 方法语法 |
| 多表Join | 查询语法（更易读） |
| GroupBy + 后续操作 | 查询语法 + 方法语法混合 |
| 链式Where/Select | 方法语法 |
| 需要索引参数 | 方法语法 |

## 六、业务场景示例

### 场景1：商品列表筛选排序（电商）

```csharp
// 需求：根据搜索条件筛选商品，按相关度排序，分页展示
public class ProductSearchService
{
    public PagedResult<ProductDto> Search(ProductSearchRequest request)
    {
        var query = from p in _db.Products
                    where p.IsActive
                    select p;

        // 动态筛选（方法语法更方便）
        if (!string.IsNullOrEmpty(request.Keyword))
            query = query.Where(p => p.Name.Contains(request.Keyword));

        if (request.CategoryId.HasValue)
            query = query.Where(p => p.CategoryId == request.CategoryId);

        if (request.MinPrice.HasValue)
            query = query.Where(p => p.Price >= request.MinPrice);

        if (request.MaxPrice.HasValue)
            query = query.Where(p => p.Price <= request.MaxPrice);

        // 排序 + 分页
        var result = query
            .OrderByDescending(p => p.Sales)
            .ThenBy(p => p.Price)
            .Skip((request.Page - 1) * request.PageSize)
            .Take(request.PageSize)
            .Select(p => new ProductDto
            {
                Id = p.Id,
                Name = p.Name,
                Price = p.Price
            })
            .ToList();

        return new PagedResult<ProductDto>(result, query.Count());
    }
}
```

### 场景2：日志查询（运维）

```csharp
// 需求：按时间范围、级别、关键词筛选日志
public class LogQueryService
{
    public List<LogEntry> QueryLogs(LogQueryRequest request)
    {
        var query = from log in _logs
                    where log.Timestamp >= request.StartTime
                       && log.Timestamp <= request.EndTime
                    select log;

        // 级别筛选
        if (request.Levels.Any())
            query = query.Where(log => request.Levels.Contains(log.Level));

        // 关键词搜索
        if (!string.IsNullOrEmpty(request.Keyword))
            query = query.Where(log => log.Message.Contains(request.Keyword));

        return query
            .OrderByDescending(log => log.Timestamp)
            .Take(request.Limit)
            .ToList();
    }
}
```

### 场景3：配置项过滤（系统配置）

```csharp
// 需求：从混合类型的配置列表中提取有效配置
public class ConfigService
{
    public Dictionary<string, string> GetActiveConfigs(IEnumerable<object> rawConfigs)
    {
        // 从混合类型中筛选配置项
        return (from c in rawConfigs.OfType<ConfigEntry>()
                where c.IsActive && !string.IsNullOrEmpty(c.Value)
                orderby c.Priority descending
                select c)
               .DistinctBy(c => c.Key)  // .NET 6+ 按Key去重
               .ToDictionary(c => c.Key, c => c.Value);
    }
}

public record ConfigEntry(string Key, string Value, int Priority, bool IsActive);
```

## 总结

| 要点 | 说明 |
|------|------|
| 查询语法 | SQL风格，适合复杂join/group |
| 方法语法 | 链式调用，覆盖全部操作符 |
| 混合使用 | 实际开发常态，取长补短 |
| 编译结果 | 查询语法编译为方法语法，完全等价 |
| 选择原则 | 可读性优先，团队一致性其次 |
