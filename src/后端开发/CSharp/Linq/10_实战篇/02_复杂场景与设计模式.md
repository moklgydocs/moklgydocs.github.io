# 复杂场景与设计模式

LINQ 不仅是一门查询语言，更是一种**声明式数据流**的思维方式。本章将 LINQ 与经典设计模式结合，展示如何在复杂场景中写出可维护、可组合、可测试的数据处理代码。

## 一、管道模式（Pipeline Pattern）

### 核心思想

LINQ 方法链本身就是管道模式——数据流经一系列操作节点，每个节点做一件事：

```
source → Where(过滤) → Select(转换) → OrderBy(排序) → Take(截取) → 结果
```

### 日志处理管道

```csharp
public class LogEntry
{
    public DateTime Timestamp { get; set; }
    public string Level { get; set; } = "";  // INFO, WARN, ERROR
    public string Module { get; set; } = "";
    public string Message { get; set; } = "";
}

// 管道：过滤 → 解析 → 聚合 → 输出
var errorSummary = rawLogs
    // 第1步：过滤 ERROR 级别
    .Where(log => log.Level == "ERROR")
    // 第2步：按模块分组
    .GroupBy(log => log.Module)
    // 第3步：聚合统计
    .Select(g => new
    {
        Module = g.Key,
        ErrorCount = g.Count(),
        FirstOccur = g.Min(l => l.Timestamp),
        LastOccur = g.Max(l => l.Timestamp),
        Messages = g.Select(l => l.Message).Distinct().ToList()
    })
    // 第4步：排序输出
    .OrderByDescending(s => s.ErrorCount)
    .ToList();
```

### 数据清洗管道

```csharp
// 可配置的清洗管道
var pipeline = rawData
```

## 二、规约模式（Specification Pattern）

### 接口定义

```csharp
public interface ISpecification<T>
{
    bool IsSatisfiedBy(T candidate);
    Expression<Func<T, bool>> ToExpression();
}
```

### 基类与组合规约

```csharp
public abstract class Specification<T> : ISpecification<T>
{
    public abstract Expression<Func<T, bool>> ToExpression();

    public bool IsSatisfiedBy(T candidate)
    {
        return ToExpression().Compile()(candidate);
    }

    public Specification<T> And(ISpecification<T> other)
    {
        return new AndSpecification<T>(this, other);
    }

    public Specification<T> Or(ISpecification<T> other)
    {
        return new OrSpecification<T>(this, other);
    }

    public Specification<T> Not()
    {
        return new NotSpecification<T>(this);
    }
}

public class AndSpecification<T> : Specification<T>
{
    private readonly ISpecification<T> _left;
    private readonly ISpecification<T> _right;

    public AndSpecification(ISpecification<T> left, ISpecification<T> right)
    {
        _left = left;
        _right = right;
    }

    public override Expression<Func<T, bool>> ToExpression()
    {
        var leftExpr = _left.ToExpression();
        var rightExpr = _right.ToExpression();
        var param = Expression.Parameter(typeof(T));

        var body = Expression.AndAlso(
            Expression.Invoke(leftExpr, param),
            Expression.Invoke(rightExpr, param));

        return Expression.Lambda<Func<T, bool>>(body, param);
    }
}

public class OrSpecification<T> : Specification<T>
{
    private readonly ISpecification<T> _left;
    private readonly ISpecification<T> _right;

    public OrSpecification(ISpecification<T> left, ISpecification<T> right)
    {
        _left = left;
        _right = right;
    }

    public override Expression<Func<T, bool>> ToExpression()
    {
        var leftExpr = _left.ToExpression();
        var rightExpr = _right.ToExpression();
        var param = Expression.Parameter(typeof(T));

        var body = Expression.OrElse(
            Expression.Invoke(leftExpr, param),
            Expression.Invoke(rightExpr, param));

        return Expression.Lambda<Func<T, bool>>(body, param);
    }
}

public class NotSpecification<T> : Specification<T>
{
    private readonly ISpecification<T> _spec;

    public NotSpecification(ISpecification<T> spec) => _spec = spec;

    public override Expression<Func<T, bool>> ToExpression()
    {
        var expr = _spec.ToExpression();
        var param = Expression.Parameter(typeof(T));
        var body = Expression.Not(Expression.Invoke(expr, param));
        return Expression.Lambda<Func<T, bool>>(body, param);
    }
}
```

### 业务规约示例

```csharp
public class Product
{
    public int ProductId { get; set; }
    public string Name { get; set; } = "";
    public decimal Price { get; set; }
    public string Category { get; set; } = "";
    public bool IsInStock { get; set; }
    public int StockQuantity { get; set; }
}

// 具体规约
public class InStockSpecification : Specification<Product>
{
    public override Expression<Func<Product, bool>> ToExpression()
        => p => p.IsInStock && p.StockQuantity > 0;
}

public class PriceRangeSpecification : Specification<Product>
{
    private readonly decimal _min;
    private readonly decimal _max;

    public PriceRangeSpecification(decimal min, decimal max)
    {
        _min = min;
        _max = max;
    }

    public override Expression<Func<Product, bool>> ToExpression()
        => p => p.Price >= _min && p.Price <= _max;
}

public class CategorySpecification : Specification<Product>
{
    private readonly string _category;

    public CategorySpecification(string category) => _category = category;

    public override Expression<Func<Product, bool>> ToExpression()
        => p => p.Category == _category;
}

// 使用：组合规约
var spec = new InStockSpecification()
    .And(new PriceRangeSpecification(50, 500))
    .And(new CategorySpecification("电子产品"));

// 对内存集合使用
var filtered = products.Where(spec.ToExpression().Compile()).ToList();

// 对 IQueryable 使用（可翻译为 SQL）
var result = dbContext.Products.Where(spec.ToExpression()).ToList();
```

```csharp
public static IEnumerable<TreeNode> Flatten(this TreeNode node)
{
    yield return node;
    foreach (var child in node.Children.SelectMany(Flatten))
        yield return child;

// 用法
```

### 从扁平数据构建树

```csharp
public static List<TreeNode> BuildTree(List<TreeNode> flatNodes)
{
    var lookup = flatNodes.ToLookup(n => n.ParentId);

    foreach (var node in flatNodes)
    {
        node.Children = lookup[node.Id].ToList();
    }

    return lookup[null].ToList();  // 根节点 ParentId == null
}

// 用法
var flatList = new List<TreeNode>
{
    new() { Id = 1, Name = "根", ParentId = null },
    new() { Id = 2, Name = "子1", ParentId = 1 },
    new() { Id = 3, Name = "子2", ParentId = 1 },
    new() { Id = 4, Name = "孙1", ParentId = 2 },
};
var tree = BuildTree(flatList);
```

### 树形过滤（保留路径）

需求：过滤树中满足条件的节点，但保留其祖先路径。

```csharp
public static List<TreeNode> FilterTree(
    List<TreeNode> roots,
    Func<TreeNode, bool> predicate)
{
    return roots
        .Select(r => FilterNode(r, predicate))
        .Where(r => r != null)
        .ToList()!;
}

private static TreeNode? FilterNode(TreeNode node, Func<TreeNode, bool> predicate)
{
    var filteredChildren = node.Children
        .Select(c => FilterNode(c, predicate))
        .Where(c => c != null)
        .Cast<TreeNode>()
        .ToList();

    if (predicate(node) || filteredChildren.Count > 0)
    {
        return new TreeNode
        {
            Id = node.Id,
            Name = node.Name,
            ParentId = node.ParentId,
            Children = filteredChildren
        };
    }

    return null;
}
```

### 树形遍历

```csharp
// 深度优先
public static IEnumerable<TreeNode> DepthFirst(this TreeNode node)
{
    yield return node;
    foreach (var child in node.Children.SelectMany(DepthFirst))
        yield return child;
}

// 广度优先
public static IEnumerable<TreeNode> BreadthFirst(this TreeNode node)
{
    var queue = new Queue<TreeNode>();
    queue.Enqueue(node);

    while (queue.Count > 0)
    {
        var current = queue.Dequeue();
        yield return current;
        foreach (var child in current.Children)
            queue.Enqueue(child);
    }
}

// 深度计算
public static int MaxDepth(this TreeNode node)
{
    if (node.Children.Count == 0) return 1;
    return 1 + node.Children.Max(MaxDepth);
}
```

### 缓存模式

```csharp
public class DataCache<T>
{
    private List<T>? _cached;
    private ILookup<string, T>? _byCategory;
    private readonly Func<IEnumerable<T>> _loader;

    public DataCache(Func<IEnumerable<T>> loader) => _loader = loader;

    public List<T> All()
    {
        _cached ??= _loader().ToList();
        return _cached;
    }

    public ILookup<string, T> ByCategory(Func<T, string> keySelector)
    {
        _byCategory ??= All().ToLookup(keySelector);
        return _byCategory;
    }

    public void Invalidate()
    {
        _cached = null;
        _byCategory = null;
    }
}

// 使用
var cache = new DataCache<Product>(() => dbContext.Products.ToList());
var electronics = cache.ByCategory(p => p.Category)["电子产品"];
```

### DistinctBy（.NET 6 前版本）

```csharp
public static IEnumerable<TSource> DistinctBy<TSource, TKey>(
    this IEnumerable<TSource> source,
    Func<TSource, TKey> keySelector) where TKey : notnull
{
    var seen = new HashSet<TKey>();
    foreach (var item in source)
    {
        if (seen.Add(keySelector(item)))
            yield return item;
    }
}

// 使用
var uniqueByCity = customers.DistinctBy(c => c.City);
```

### LeftJoin 扩展

```csharp
public static IEnumerable<TResult> LeftJoin<TLeft, TRight, TKey, TResult>(
    this IEnumerable<TLeft> left,
    IEnumerable<TRight> right,
    Func<TLeft, TKey> leftKey,
    Func<TRight, TKey> rightKey,
    Func<TLeft, TRight?, TResult> resultSelector) where TKey : notnull
{
    var rightDict = right.ToLookup(rightKey);
    return left.SelectMany(
        l => rightDict[leftKey(l)].DefaultIfEmpty(),
        (l, r) => resultSelector(l, r));
}

// 使用
var result = orders.LeftJoin(
    customers,
    o => o.CustomerId,
    c => c.CustomerId,
    (o, c) => new { o.OrderId, CustomerName = c?.Name ?? "未知" });
```

### Batch / Chunk 分批处理

```csharp
public static IEnumerable<List<TSource>> Batch<TSource>(
    this IEnumerable<TSource> source,
    int batchSize)
{
    var batch = new List<TSource>(batchSize);
    foreach (var item in source)
    {
        batch.Add(item);
        if (batch.Count == batchSize)
        {
            yield return batch;
            batch = new List<TSource>(batchSize);
        }
    }
    if (batch.Count > 0)
        yield return batch;
}

// 使用：每100条一批写入数据库
foreach (var batch in largeList.Batch(100))
{
    dbContext.Products.AddRange(batch);
    await dbContext.SaveChangesAsync();
}
```

### Flatten 递归展平

```csharp
public static IEnumerable<T> Flatten<T>(
    this IEnumerable<T> source,
    Func<T, IEnumerable<T>> childrenSelector)

    foreach (var item in source)
    {
        yield return item;
        foreach (var child in childrenSelector(item).Flatten(childrenSelector))
```

### Shuffle 随机排序

```csharp
public static IEnumerable<TSource> Shuffle<TSource>(
    this IEnumerable<TSource> source)
{
    var list = source.ToList();
    var rng = new Random();
    for (int i = list.Count - 1; i > 0; i--)
    {
        int j = rng.Next(i + 1);
        (list[i], list[j]) = (list[j], list[i]);
    }
    return list;
}

// 使用：随机抽题
var examQuestions = questionBank.Shuffle().Take(50).ToList();
```

### Pivot 数据透视

```csharp
public static IEnumerable<Dictionary<string, object>> Pivot<TSource, TKey, TCol, TValue>(
    this IEnumerable<TSource> source,
    Func<TSource, TKey> rowKeySelector,
    Func<TSource, TCol> colKeySelector,
    Func<IEnumerable<TSource>, TValue> valueSelector)
{
    return source
        .GroupBy(rowKeySelector)
        .Select(rowGroup =>
        {
            var dict = new Dictionary<string, object>
            {
                ["Key"] = rowGroup.Key!
            };
            foreach (var colGroup in rowGroup.GroupBy(colKeySelector))
            {
                dict[colGroup.Key!.ToString()!] = valueSelector(colGroup)!;
            }
            return dict;
        });
}

// 使用：按部门×月份透视销售额
var pivot = sales
    .Pivot(
        s => s.Department,
        s => s.Month,
        g => g.Sum(x => x.Amount))
    .ToList();
```

## 七、LINQ 最佳实践总结

### 10 条最佳实践

| # | 实践 | 说明 |
|---|------|------|
| 1 | **可读性优先** | 优先写出同事能一眼看懂的代码，除非是热路径否则不要为了性能牺牲可读性 |
| 2 | **方法链换行** | 每个操作符独占一行，对齐缩进，方便 diff 审查 |
| 3 | **用 Where 先过滤再 Select** | 减少后续操作的数据量，尤其在 IQueryable 中能生成更优 SQL |
| 4 | **避免在 Where 里做计算** | `Where(x => x.Price > threshold)` 比 `Where(x => x.Price > CalculateThreshold())` 更利于 EF 翻译 |
| 5 | **IQueryable 不用 AsEnumerable** | 除非你需要内存端操作，否则不要提前拉取数据 |
| 6 | **注意多次枚举** | 同一个 `IEnumerable` 被 `foreach` 两次可能触发两次数据库查询，用 `ToList()` 缓存 |
| 7 | **用匿名类型做复合键** | `GroupBy(x => new { x.Year, x.Month })` 比拼字符串更安全 |
| 8 | **Select 投影减少数据** | 只 select 需要的字段，避免传输无用数据 |
| 9 | **命名意图明确** | `activeOrders` 比 `result1` 好；中间变量可以代替过长的链 |
| 10 | **写测试验证复杂查询** | 超过 3 个操作符的链，写单元测试确认行为 |

### 方法链换行规范

```csharp
// 推荐：每个操作符一行，点号对齐
var result = orders
    .Where(o => o.Status == OrderStatus.Paid)
    .GroupBy(o => o.CustomerId)
    .Select(g => new { CustomerId = g.Key, Total = g.Sum(o => o.TotalAmount) })
    .OrderByDescending(x => x.Total)
    .Take(10)
    .ToList();

// 不推荐：全部挤在一行
var result = orders.Where(o => o.Status == OrderStatus.Paid).GroupBy(o => o.CustomerId).Select(g => new { CustomerId = g.Key, Total = g.Sum(o => o.TotalAmount) }).OrderByDescending(x => x.Total).Take(10).ToList();
```

### 命名规范

```csharp
// Lambda 参数命名：短小有意义
.Where(order => order.Status == OrderStatus.Paid)   // 好
.Where(x => x.Status == OrderStatus.Paid)           // 可接受（上下文清晰时）
.Where(o => o.Status == OrderStatus.Paid)            // 常见约定

// 中间变量：表达意图
var paidOrders = orders.Where(o => o.Status == OrderStatus.Paid);
var customerTotals = paidOrders.GroupBy(o => o.CustomerId)
    .Select(g => new { g.Key, Total = g.Sum(o => o.TotalAmount) });

// 而非
var list1 = orders.Where(...);
var list2 = list1.GroupBy(...);
```

### 注释规范

```csharp
// 好：注释"为什么"，而非"是什么"
var q1Orders = orders
    .Where(o => o.OrderDate >= start && o.OrderDate < end)
    .Where(o => o.Status >= OrderStatus.Paid)  // 业务规则：已取消的不计入
    .ToList();

// 不好：重复代码含义
// 按日期过滤
.Where(o => o.OrderDate >= start && o.OrderDate < end)
// 按状态过滤
.Where(o => o.Status >= OrderStatus.Paid)
```

## 小结

| 模式 | 核心价值 | LINQ 映射 |
|------|---------|-----------|
| 管道模式 | 数据流分步处理 | 方法链本身就是管道 |
| 规约模式 | 业务规则可组合 | Expression + And/Or/Not |
| 树形处理 | 递归展平与构建 | SelectMany 递归 + ToLookup |
| 缓存索引 | 避免重复计算 | ToDictionary / ToLookup |
| 扩展方法 | 复用通用操作 | this IEnumerable + yield return |

关键心得：

1. **管道模式是 LINQ 的灵魂**——每个操作符只做一件事，链式组合解决复杂问题
2. **规约模式让业务规则可组合、可测试**——把 `if-else` 森林变成类型安全的组合式规则
3. **树形结构的关键是"展平"**——用递归 SelectMany 把树变成线性序列后，LINQ 的所有能力都可以使用
4. **扩展方法是对 LINQ 最好的补充**——但不要过度扩展，每个扩展方法都要有真实业务场景驱动
5. **可读性永远优先**——LINQ 的价值在于让意图清晰，而不是让代码更短
